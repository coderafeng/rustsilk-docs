# 期权池与员工激励

期权是"未来以约定价格买入股权的权利"——**用今天的低价锁定明天的人才，用公司的增值替老板付工资**。国内早期公司做期权，核心难点不是法律不允许，而是"怎么落地登记 + 怎么让员工真正拿到钱"。

## 期权池的比例与来源

- **比例惯例**：设立时预留**10%—20%**；投资人Term Sheet通常也要求在**投前**先建池（池子算在创始人稀释里，不单独由投资人买单——谈的时候注意）。
- **来源**：从创始人持股中划出（最常见，本质是创始人让利），或未来增资稀释形成；**不要由全体股东按比例出**，否则没人真正让利，激励变摊薄。
- **载体**：直发股权给员工会让股东名单膨胀（有限公司50人上限）且退出极难，**标准做法是预置一家有限合伙持股平台**（见05篇）：期权行权=入伙成为LP，员工不进主公司股东名册。

## ESOP 方案设计

一套完整方案回答六个问题：

| 设计项 | 要点 |
|---|---|
| **给谁** | 分层：核心团队给实股/期权，骨干给期权，普惠层给虚拟股（分红权） |
| **给多少** | 单个高管0.5%—2%，核心工程师0.05%—0.5%量级；池子留20%—30%余量给未来 |
| **通过什么给** | 首选有限合伙平台LP份额；预算小/外籍员工用**虚拟股（合同制分红权，不涉及工商登记）** |
| **授予节奏** | 入职授予 + 晋升追授（Refresh），避免"一次给够躺平" |
| **退出规则** | 离职未行权部分作废；已行权部分由GP指定主体按约定价回售——**回购条款是期权方案的命门** |
| **治理文件** | 期权计划（池子层面）+ 个人授予协议（约定成熟与价格）两层，别混签 |

> **坑位提示**："口头承诺年底给你1个点"是劳动仲裁里最高频的争议。承诺不落书面，要么不发，要么发出去收不回。

## 行权价与归属安排

- **归属（Vesting）**：与联创同构——4年/1年Cliff、按月成熟是行业标准；也可叠加业绩里程碑（销售/产品负责人适用）。
- **行权价**：≥授予时公允参考价（净资产、最近轮估值折价、评估价均可作依据）——**定太低有税务被核定和利益输送争议，定太高期权变废纸**；早期常用"净资产价或象征价"换取税务与谈判空间。
- **行权窗口**：离职后90天内须行权（或作废），在职期间到期分批行权；未上市前员工"行权=掏真金白银换一张卖不掉的纸"，所以实务中多用**GP递延实缴/代持待行权**技术，甚至"**只分红不行权**"的过渡形态，降低员工掏钱顾虑。
