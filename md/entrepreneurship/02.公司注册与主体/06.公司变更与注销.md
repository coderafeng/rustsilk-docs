# 公司变更与注销

## 股权、地址、名称变更流程

三类变更共用一个主干流程：**内部决议（修改章程，涉及增减资/改章程需代表三分之二以上表决权的股东通过）→ 市场监管办理变更登记 → 下游联动更新**。

容易漏的是第三步"联动"——执照变了不等于全变了：

- **股权变更**：工商变更后30日内做**税务报备**，转让方为自然人的，按"财产转让所得"**20%**缴个税（受让方为扣缴义务人），印花税万分之五双方各缴；**平价/低价转让且无正当理由的，税务局有权核定股权转让收入**——"0元转让逃税"走不通；直系亲属、继承等情形有正当事由可偏低转让。变更后同步更新股东名册、出资证明书；若有对赌/期权安排，一并核查章程与股东协议是否需要同步修订。
- **地址变更**：同区变更较简单；**跨区迁移要先办税务迁出（清税意见）再办工商迁入**，税务有留抵、有未申报记录的会卡住，预留时间。别忘了银行账户信息、各类许可证上的地址要跟着改。
- **名称变更**：新名称过核名 → 变更登记 → **重刻全部印章、缴销旧章** → 商标、域名、许可、合同模板、开票系统逐一更新。名字改一次掉一层皮，起名时尽量留足扩展性。

## 注销的普通流程与简易流程

**简易注销**（未开业或无债权债务的企业）：

1. 国家企业信用信息公示系统发布《全体投资人承诺书》+ **20天公告**；
2. 公告期内无人异议，期满后即可向登记机关申请注销。

不适用的情形：被列入经营异常名录或严重违法名单、有在办案件、欠税务/社保、投资企业含外资特殊准入等——**有领过发票、开过社保户的公司大概率走不了简易**，别硬试。

**普通注销**：

1. 成立**清算组**并备案，通知债权人并公告（公示系统或报纸，公告期45天）；
2. 清理资产、处理员工（经济补偿）、**税务注销是最大关卡**：补申报、缴清税款滞纳金、缴销发票和税控设备，拿《清税证明》；
3. 工商注销登记，缴回执照；
4. 依次注销银行户、社保公积金户、各类许可、印章缴销。

全程顺利2—3个月，有历史账务问题则数倍于此——**注销比设立贵和慢得多**，代注销行情通常是代注册的数倍。

## 吊销与注销的区别

| | 吊销 | 注销 |
|---|---|---|
| 性质 | **行政处罚**（被执法吊销执照） | 合法退出（主动清算注销） |
| 触发原因 | 连续两年不年报、长期不经营、违法经营 | 股东决议解散/破产 |
| 主体资格 | **公司主体仍然存续**，只是失去经营资格 | 主体资格终止 |
| 后续义务 | **仍须依法清算并注销**，债权债务不因吊销消灭 | 无 |

吊销是最糟糕的"被动选择"：处罚决定上信用系统全国公示，且**公司被吊销后仍要办注销**——"放着不管就自动消失"是错觉，不清算注销，债务和处罚永远挂着。

## 不注销的后果

"生意停了，公司不管了"——这条路的尽头是：

- **税务**：欠税按日万分之五产生**滞纳金**（上不封顶）→ 非正常户 → 追征期对偷税抗税骗税**无限期**；
- **市场监管**：未年报列入异常 → 满3年进**严重违法失信名单**；
- **法定代表人**：被吊销企业的法定代表人**自吊销之日起3年内**不得担任任何公司的董监高，且名下新公司注册会被限制；
- **股东**：公司未经清算即注销或怠于清算导致无法清算的，债权人可主张**股东对公司债务承担连带清偿责任**——有限责任的保护伞直接消失；
- **信用连带**：失信记录影响贷款、招投标、高铁机票（被列入失信被执行人时），合作方尽调一眼可见。
