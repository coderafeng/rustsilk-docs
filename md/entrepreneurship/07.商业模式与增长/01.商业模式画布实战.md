# 商业模式画布实战

商业模式画布（Business Model Canvas）是一张把"生意怎么做成"摊开在一页纸上的检查表——它的价值不在填完，而在**暴露你心虚的那一格**。

## 商业模式画布九要素

| 要素 | 一句话拷问 | 常见自欺 |
|---|---|---|
| **客户细分** | 谁**必须**用你？ | "所有人都是用户" = 没人是用户 |
| **价值主张** | 你替客户解决的那**一个**问题是什么？ | 功能清单 ≠ 价值主张 |
| **渠道通路** | 用户在哪里知道你、比较、下单？ | 只答"线上推广" |
| **客户关系** | 自助、专属服务还是社区？养熟还是收割？ | 忽视复购关系成本 |
| **收入来源** | 谁付钱、为什么付、一次还是持续？ | 把GMV当收入 |
| **核心资源** | 没了一样事做不成的资产是什么？ | 把"团队很强"当资源 |
| **关键业务** | 让飞轮转起来的那件主业是什么？ | 业务线铺 too 多 |
| **重要伙伴** | 谁供货、谁引流、谁替你干不擅长的事？ | 什么都自建 |
| **成本结构** | 最大成本项是什么？随规模怎么变？ | 算漏人力与获客成本 |

用法：创业初期每月重画一次，**用不同颜色标"已验证 / 假设 / 已证伪"**——证伪的格子比亮眼的格子值钱。融资BP的章节顺序（见《融资前的准备》）本质就是这张画布的叙事版。

## 案例：技术型创业（开发者工具 / SaaS）

- **客户细分**：中小团队的后端工程师（自下而上采用），付费决策人却是工程负责人；
- **价值主张**：把"部署排障从半天缩到10分钟"——省时间可量化，是技术产品最好的卖点；
- **收入**：订阅制（按席位/用量），辅以企业版的私有化部署费；
- **核心资源与关键业务**：代码与文档质量、模板生态；**产品自增长（PLG）**——免费额度即获客渠道；
- **成本重心**：研发人力 + 云资源；毛利改善靠规模摊薄固定成本；
- **最容易虚的一格**：渠道——"工程师口口相传"不是策略，要落到内容SEO、开源社区、集成市场上（见03篇）。

## 案例：内容型创业（知识付费 / 垂类媒体）

- **客户细分**：某垂直领域的"想入门且怕踩坑"人群（例：摄影后期、跨境电商新手）；
- **价值主张**：信息压缩与路径保证——"替我省300小时筛选成本"；
- **收入结构**：免费内容引流 → 训练营/专栏（99—999元）→ 高价陪跑/咨询（数千元）——**漏斗型产品矩阵**，每层为下一层供流量；
- **关键资源**：创作者IP与选题体系；风险是**收入与个人强绑定**——规模化要靠"标准化课件 + 助教体系"去IP化；
- **成本结构**：内容制作人力为主，边际成本接近零，但**获客成本随平台算法波动**——私域沉淀率是生死线（见03篇）；
- **容易虚的一格**：客户关系——内容型最易"卖完即失联"，复购靠社群与会员体系。

## 案例：贸易型创业（选品分销 / 跨境电商）

- **价值主张**：不在"产品创新"，在**供应链效率与信息差**——同款更便宜、更快、或组合不同；
- **渠道与收入**：平台店铺（亚马逊/1688/即时零售）赚差价，收入=选品命中率 × 流量运营；
- **核心资源与伙伴**：工厂账期与独家供货协议是命脉——**账期就是现金流武器**（见《现金流管理》）；
- **成本结构**：货款占大头，附加物流、平台佣金、退货损耗与汇率；**毛利被平台佣金和广告费两头挤**——很多贸易型死法不是没销量，是算完账不赚钱（定价时务必用真实全成本算单位毛利，见02篇）；
- **最容易虚的一格**：客户细分——"谁买算谁"不是细分；没有复购画像就没法定选品；
- 护城河构建路径：分销 → 自有品牌 → 私域复购，三级跳每一跳都换一套画布。

> **三案例对照的启示**：技术型赚"规模边际成本递减"的钱，内容型赚"信任转化"的钱，贸易型赚"周转效率"的钱——**画布九格里你们的胜负手不同，老板精力就该压在哪一格上。**
