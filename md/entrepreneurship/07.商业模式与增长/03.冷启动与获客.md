# 冷启动与获客

从0到1000个用户，靠的不是渠道预算，是**手工**——创始人亲自找人、亲自交付、亲自听骂声。冷启动的目标不是量，是**拿到"用户为什么买单"的真实因果**。

## 种子用户画像与找到他们

种子用户三个特征缺一不可：**痛得最早最深**（愿意为不完美产品付钱）、**有表达欲**（反馈+转介绍源头）、**圈层节点**（他一句话带来二十个人）。

找他们的路径，按转化率从高到低：

1. **创始人自己的职业网络**：前同事、客户、行业群——第一批付费客户八成藏在这里；
2. **垂直社群蹲点**：细分领域的贴吧/知识星球/QQ群/线下行业聚会——先贡献价值混脸熟，再私聊高频提问者；
3. **竞品的不满用户**：去竞品应用商店差评区、社媒吐槽贴下找"想要但没得到"的人；
4. **内容被动吸引**（慢但复利，见下节）。

> **坑位提示**：种子用户数量建议**30—100个，宁少勿泛**——1000个"还行"不如30个"没你不行"；前者给你数据，后者给你产品方向和第一波口碑。

## 渠道选择与测试

渠道没有好坏，只有**与产品决策链的匹配度**：

| 产品形态 | 首选渠道假设 | 验证指标 |
|---|---|---|
| 低客单C端（<100元） | 短视频种草、社群团购、应用商店ASO | 单渠道CAC、自然量占比 |
| 高客单C端/知识付费 | 内容平台专业号 + 私域转化 | 内容→添加率、私域→成交率 |
| 小微B端 | 行业展会、协会、老客转介绍 | 线索→商机转化 |
| 中大型B端 | 创始人人脉 + 标杆案例公关 | 见04篇B端销售流程 |

测试纪律：**一次只动一个变量**（同素材换渠道 / 同渠道换素材，别一起换）、单渠道测试预算封顶（如5000元内出结论）、**判定看后端指标（激活、付费、留存）不看前端指标（曝光、点击、加粉数）**——加粉成本1块钱的渠道，可能付费转化率为零。

## 内容营销与私域

内容是唯一**边际成本递减的获客资产**：

- **选题公式**：目标用户搜什么、焦虑什么、被什么骗过——写"问题"别写"产品"；技术创业者写教程与踩坑复盘（开发者信任来自专业展示，不来自广告）；
- **平台选择**：一个主战场打透（SEO/公众号/知乎/B站/小红书按人群挑一个）再分发，多平台齐发是团队>5人后的事；
- **节奏**：周更起步但**不断更**——内容获客的效果曲线前3个月是平的，熬过拐点靠复利；
- **私域**的本质是**可反复触达的自有关系**：公域内容 → 钩子（资料/工具/社群）→ 企业微信/社群沉淀 → SOP运营（欢迎语、价值内容、案例、限时转化）；
- 私域红线：拉群不聊天等于没群，但**刷屏推销等于骚扰**——8:2法则（80%价值内容、20%销售信息），员工离职带不走客户（企业微信资产归属，参考《数据安全与个人信息保护》的用户个人同意边界）。
