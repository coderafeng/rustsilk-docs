# 增值税入门

增值税是对"卖东西/提供服务过程中的增值额"征税，**只要你开票、只要客户要专票，就绕不开它**。它的两个特征决定了创业者的所有选择题：一是**道道征收、环环抵扣**（进项抵销项），二是**纳税人的身份决定玩法**。

## 小规模纳税人 vs 一般纳税人

| | 小规模纳税人 | 一般纳税人 |
|---|---|---|
| **判定标准** | 年应征增值税销售额 ≤ 500万元 | 超过500万**强制转**，也可主动申请 |
| **计税方式** | 简易计税：销售额 × 征收率，**进项不得抵扣** | 一般计税：销项 − 进项，税率为13%/9%/6% |
| **税率体验** | 征收率3%，现行优惠**减按1%（至2027年底）** | 名义税率高，但成本进项可抵扣 |
| **开票** | 可开专票（客户能按1%抵）和普票 | 专票普票随便开，抵扣力度大 |
| **申报频率** | 通常按季 | 按月 |
| **适合谁** | 轻资产、人工成本为主（进项少）、客户不挑抵扣 | 客户多为企业（要9%/13%专票）、采购进项大 |

> **坑位提示**：**"转登记"容易"转回"难**——一般纳税人原则上不能随意退回小规模（现行政策偶有窗口期）。业务模式一旦确定进项结构（人力为主还是货物为主），身份要一步选对。

## 税率与征收速查

| 档位 | 适用范围 |
|---|---|
| **13%** | 销售货物（商品、设备）、加工修理修配 |
| **9%** | 交通运输、建筑、不动产销售/租赁、农产品 |
| **6%** | 现代服务（信息技术、咨询）、生活服务、金融服务、销售无形资产 |
| **5%** | 不动产相关业务简易计税、劳务派遣差额等特定情形 |
| **0%** | 出口货物、跨境服务 |
| 征收率 | 小规模法定3%（现行减按**1%**）；个别业务5% |

同一公司多项业务适用不同税率时，务必**分别核算**，否则**从高适用税率**（见02篇《注册地址与经营范围》的混业提醒）。

## 起征点与免税政策

现行对小规模纳税人的优惠（执行至**2027年12月31日**）：

- **月销售额10万元以下（季度30万元以下）免征增值税**——开**普票**的部分才免；
- 适用3%征收率的应税销售收入**减按1%**征收；
- 随增值税附征的城建税、教育费附加等"六税两费"**减半**。

> **开票必知**：享受免税要开**免税普通发票**（税率栏显示"免税"或"***"）；只要给客户开了**1%专票，该笔就要照章交税**，不能享受免税——"专票普票的选择"本质是"客户要不要抵扣 vs 我要不要交税"的谈判。放弃免税、开全量专票用于大客户要求时，36个月内不得再放弃，谨慎决策。
