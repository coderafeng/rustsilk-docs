# 现金流管理

创业公司的死法里，"账面赚钱、现金断流而死"远多于"业务亏损而死"。**利润决定公司能不能活得好，现金决定公司还有没有明天。**

## 利润是观点，现金是事实

- **权责发生制**让收入在"确认"那天就计入利润，而**钱可能90天后才到账**——一份100万的软件项目合同，签约确认收入60万（按完工进度），服务器和外包先付现30万，尾款验收后收，账上利润30万，实际现金流可能是负的；
- 资产负债表上**应收账款和存货每涨一块，都是从现金流里抽走一块**；
- 老板每月只看三个数就够：**① 账上可用资金（含理财、可提现额）② 固定月支出（工资+社保+房租+服务器等刚性） ③ 净消耗（Burn Rate）= 支出 − 流入**。

> **Runway（现金跑道）= 账上可用资金 ÷ 月净消耗**——这是融资谈判、裁员降本、接大单垫资等所有决策的共同分母。低于**6个月**进入警戒，低于**3个月**进入生存模式。

## 现金流预测表的编制

标准做法是**13周（一个季度）滚动预测**，每周更新：

| 行 | 内容 | 要点 |
|---|---|---|
| 期初现金 | 上周期末数 | 与银行对账单核对 |
| (+) 预计回款 | 按合同节点/账期逐笔列，乘**历史回款率**折扣 | 宁可保守：客户说"月底付"按次月15日记 |
| (−) 刚性支出 | 工资、社保公积金、房租、贷款、云服务 | 全量列支，一分不漏 |
| (−) 经营性支出 | 采购、外包、报销、营销费 | 按周/双周节奏 |
| (−) 税费支出 | 增值税季/月、所得税预缴、个税代扣 | 别漏季度缴税大月 |
| = 期末现金 | 滚动至未来13周 | **任何一周期末为负 → 当周就是问题，不是"到时候再说"** |

## 应收应付管理

**应收（向客户收钱）**：

- 合同是第一催收工具：**预付款 + 阶段付款 + 验收条款 + 逾期违约金**四件套，能谈就多谈节点少留尾款；
- 客户授信分级：新客户小单试账期，老客户按回款记录给额度；
- 催收节奏化：**到期前3天提醒 → 到期日对账开票确认 → 逾期7天函件 → 30天暂停服务 → 60天升级法务**——把"要钱"做成流程而不是情绪；
- 对赌回款不如对赌开票：先开票意味着先产生增值税纳税义务，**回款没到税先交了**，账期谈判里"见款开票"是有价值的筹码。

**应付（向供应商付钱）**：

- 在**不伤信用的前提下尽量拉长账期**（月结60天 > 月结30天 > 现结），账期就是免费融资；
- 但工资、社保、税款、核心供应商的货款**永远排最优先**——欠税影响法人信用，欠核心供应商会断供，省下的利息远不够赔。
