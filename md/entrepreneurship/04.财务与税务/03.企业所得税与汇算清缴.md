# 企业所得税与汇算清缴

企业所得税对"年度利润"征税，是继增值税之后第二大宗。它的规则比增值税"讲理"——**利润多少决定税多少**，所以每一分成本票据、每一项优惠资格，都直接等于现金。

## 税率与计算方法

- **应纳税所得额 = 收入总额 − 不征税收入 − 免税收入 − 各项扣除 − 以前年度亏损**；注意它不等于会计利润——业务招待费、罚款滞纳金、无票支出等要**纳税调增**，加计扣除项目可以**调减**；
- **基本税率25%**；优惠税率：**小型微利企业实际税负5%**（见下）、**高新技术企业15%**（见07篇）、部分重点软件/集成电路企业有更优惠安排；
- **亏损弥补**：年度亏损可用以后5年所得弥补；**高新技术企业及科技型中小企业**的结转年限延长至**10年**——创业前三年亏损是常态，这张"亏损抵税额度"是未来盈利的隐性资产。

## 小型微利企业优惠

三项条件**同时满足**（从事国家非限制行业 + 年度应纳税所得额**不超过300万** + 从业人数**不超过300人** + 资产总额**不超过5000万**），现行优惠为：**对年应纳税所得额不超过300万元的部分，实际按5%计税（政策执行至2027年底）**，且**不区分征收方式**，预缴时自行判断、汇算时统一计算。

> **临界点提醒**：应纳税所得额**300万是"悬崖线"**——超过即全额按25%（无优惠），利润做到290万和310万，税差可能上百万元。年末前测算临近临界点的，通过**提前确认费用、设备加速折旧（500万以下器具器具一次性税前扣除）**等合规方式做收入费用节奏管理，别硬砍业务。

## 成本税前扣除规则

"真实、相关、合理"三原则之下，重点记住限额与凭据两类：

| 项目 | 扣除标准 | 备注 |
|---|---|---|
| **职工福利费** | 工资总额14%以内 | 超支不结转 |
| **职工教育经费** | 工资总额8%以内 | **超额部分准予结转以后年度扣除** |
| **工会经费** | 2%以内 | 凭工会经费收据 |
| **业务招待费** | 发生额的60% 与 营业收入的5‰ **孰低** | 最容易爆表的科目，请客户吃饭大半不能抵 |
| **广告费、业务宣传费** | 营业收入15%以内 | 超额可结转（化妆品制造/医药制造/饮料酒制造30%） |
| **公益性捐赠** | 年度利润总额12%以内 | 须通过合规公益性组织 |

**凭据规则**：企业所得税税前扣除以发票（或合规财政票据等）为原则——**没有发票的成本，汇算时要纳税调增补税**。小额例外：与**个人**发生的、单次**不超过500元**的小额零星支出，凭载明收款人信息与金额的**收款凭证（收据）**即可扣除（如临时请搬运工、菜市场采购）。
