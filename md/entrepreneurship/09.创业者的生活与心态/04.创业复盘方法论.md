# 创业复盘方法论

复盘是把"经历"加工成"认知"的唯一工序——**创业一年不复盘，等于只上了一天课，重复了三百次**。本篇讲个人与经营的双层复盘模板（组织级月度复盘见《目标管理》，公司终局复盘见《公司倒闭与止损》）。

## 复盘的通用框架

所有复盘共用四步（AAR/GRAI 的合并简化版），任何时间尺度通用：

1. **目标回看**：当初承诺什么？（必须翻出原始记录——**没有写下来的目标，复盘必然被记忆美化**）；
2. **结果对照**：实际发生了什么？（用数据说话，口径见《经营数据分析》；事实与解读分开列）；
3. **差异归因**：差距为什么产生？——连续问五个为什么，区分三种成因：**执行没到位 / 假设被证伪 / 运气（外部变量）**——各自对应改流程、改策略、改风险敞口，**把运气当实力复盘的人，下次会把实力当赌注**；
4. **行动沉淀**：停止什么、开始什么、继续什么？每条有负责人和时限，**下个复盘周期的第一件事是检查上期行动的完成情况**（不闭环的复盘=情绪按摩）。

三条纪律：**对事不对人**（团队复盘追责到人后，再没人敢报坏消息）、**固定时间不等心情**（每周同一时段，30分钟也比跳过强）、**复盘文档进档案库**（它们是你个人"决策算法"的训练集，也是内容创业的素材库——参考《冷启动与获客》的内容选题逻辑）。

## 周复盘模板

每周五收工前或周日晚，30—45分钟，个人为主（团队周会可共用前四问）：

1. **本周三件大事完成了吗？**（对照周一的承诺——未完成的原因归类：高估产能/突发插入/目标本身错了）；
2. **数字快照**（5分钟）：现金与runway、本周回款与新签、漏斗新增（口径见《经营数据分析》仪表盘）；
3. **本周最大意外**：一个好消息一个坏消息，各写一行"说明了什么"；
4. **决策日志巡检**：本周拍板的2—3个决定，各留一行依据与"何时回看"——**周复盘是决策命中率的最小统计单元**；
5. **浪费清单**：本周最没价值的5小时花在哪了（这类问题连续出现两周，就是流程或授权要动手术的信号，见《精力与时间管理》）；
6. **下周三件大事 + 一条"不做清单"**+ 精力自评（1—10）与睡眠/运动执行情况（联动02篇）。

> 周复盘的产出一页纸以内；超过一页说明你在写周报，不是在复盘。

## 月度经营复盘（联动 08.02 目标管理）

月度是"经营复盘"与"个人复盘"并轨的最佳周期——公司五段式流程（数字→归因→三件大事→风险→决议）照《目标管理》的模板执行，**额外为自己加一页**：

- **老板时间账单**：本月工时按"销售交付/产品/管理/救火/学习"拆分——与季初设定对比，偏差最大的那类时间就是下月日程手术的对象；
- **授权审计**：月底列"本月只有我能做的事"清单——如果比上月更长，要么组织在退化（回看《组织设计》），要么你在用亲力亲为逃避决策；
- **关系盘点**：投资人、核心客户、核心团队、家庭四类关系各答一题——"这个月我为TA做了什么TA不知道的事？"（都没有=关系在吃老本）；
- **承诺兑现率**：对个人定下的底线（家庭日、运动、无手机时段）统计执行率并公示给配偶——**把家庭共识做成可考核KPI，是03篇"日历公开制"的闭环**；
- OKR信心指数按月校准（0.7为健康线，见《目标管理》）——连续三个月全绿，通常意味着目标定怂了。
