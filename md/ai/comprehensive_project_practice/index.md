# 概述

五个综合项目把前面各章串成完整交付能力，每个项目按统一七节模板推进：介绍 → 需求选型 → 架构 → 核心实现 → 评测测试 → 部署运维 → 复盘扩展。所有项目以 Spring Boot 为主线、PGVector 为向量库，边做边回链知识章节。
