# 公司倒闭与止损

止损是创业的暗面必修：**判断放弃的理性和启动放弃的程序，和判断入局同样重要**。体面退场保住的是比公司更值钱的东西——你和联合创始人的信用与法律清白。

## 什么信号说明该止损了

把以下信号当成"预设死亡条款"写进自己的决策清单（触发两项以上，启动退出评估；**评估期不超过一个月**，防止"再撑一下"的沉没成本心理）：

- **现金**：runway < 3个月，且融资路径在TS/报价层面已确认关闭、应收加速与债权工具（见《融不到钱的 Plan B》）都试过无效；
- **模型**：单位经济修不动——连续两轮pivot（改客群/改定价/改渠道）后，留存曲线仍不收敛、LTV/CAC始终 < 1.5（判据见《增长飞轮与留存》《定价与单位经济模型》）；说明市场不需要这个产品，不是执行不够努力；
- **团队**：核心成员成建制离职或创始人团队实质决裂且无法修复——人可以再找，**信任破产的团队比现金流断裂更难续命**；
- **市场**：最大客户/渠道被政策或平台规则清零且无第二支柱；行业进入"烧钱淘汰赛"终局而你不在弹药足够的那一批。

> **止损纪律的反面案例不是"放弃"，是"拖着"**：拖到欠薪欠税、拖到个人担保被行权、拖到供应商集体起诉——那时失去的才真正不可逆。

## 清算与注销的流程

法定顺序不可颠倒（详细工商税务操作见《公司变更与注销》）：

1. **股东会决议解散**（代表2/3以上表决权的股东通过），成立**清算组**并备案；
2. **通知债权人 + 公告**（公示系统或报纸，公告期45天起）；
3. **清算财产、编制资产负债表与财产清单**：催收应收（打折现结也是钱）、处置存货设备、**知识产权与域名挂牌转让**（专利软著往往最后才想起，其实能换回几万残值）；
4. **清偿顺序（法定）**：清算费用 → **职工工资、社保、经济补偿金** → 所欠税款 → 普通债务 → 剩余财产按出资比例分配给股东——**顺序错误（先还股东借款、先给股东分钱）导致债权人追责，清算组成员个人担责**；
5. 税务注销拿清税证明 → 工商注销 → 银行、社保、公积金、许可、印章收尾；
6. **资不抵债时不要硬清算**：走**破产清算/重整**（法院程序，有限责任的真正终点）或与大额债权人协商**债务重组**（打折一次性清偿）——发现资不抵债仍私分资产，是股东个人连带甚至拒不退赔类刑事风险的入口。

## 债务、员工与客户的妥善收尾

四类关系人，按法律和道义双重排序处理：

- **员工最先**：欠薪在清偿序列里仅次于清算费用——**优先保工资和N的补偿**（标准见《劳动用工合规》）；拖欠工资经责令仍不付可能构成拒不支付劳动报酬罪（见《公司风险隔离》刑事红线）；如实告知、结清凭证留档，员工是你下一次创业的第一批推荐人和内推池；
- **客户预付费**：能退退、退不了**转让给同行承接**（服务包折价移交+公告）——拿钱跑路式消失，金额大且对象多会滑向非法吸收公众存款/诈骗的定性风险，这是倒闭案里创始人个人风险最高的一档；
- **供应商与债权人**：主动开沟通会给出清偿方案（分期、打折现结、债转股），比被集体起诉后当被执行人+限制消费体面得多；**每笔达成书面和解**；
- **个人担保与家庭**：逐一盘点你签过的连带担保（银行贷款、投资协议、供应商合同——见《公司风险隔离》《TermsSheet》的警告），**这是倒闭时真正烧到家里的火线**：尽早与担保权人谈替换/减免方案；配偶共同债务的认定以"用于家庭共同生活/共同签名"为要件，家庭资产隔离的正确姿势是事前合规架构而非事后转移（恶意转移可被撤销并涉嫌拒执罪）。

> 房东违约金、车辆设备等大额固定支出按合同谈解约（押金抵违约金换快速腾退）；**注销了执照不等于注销了责任**——未了结债务不会因为公司注销自然消灭，该留的预留款与和解协议别省。
