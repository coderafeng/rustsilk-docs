# 工商注册全流程

## 核名

公司名称四段式：**行政区划 + 字号 + 行业 + 组织形式**（如"深圳 + 腾达 + 科技 + 有限公司"）。现在多为线上自主申报，系统自动查重：

- **字号是唯一的真门槛**：两字字号极易重名，建议3—4字、生造词优先（"腾讯""字节"这类双字都注册晚了）。
- **禁用规则**：不得使用国家级/国际级词汇（"中国""环球"需特批）、不得使用拼音数字、不得误导公众。
- 核名通过后名称有一定**保留期**（一般2个月左右，各省不同），须在保留期内完成设立登记，否则失效。
- 一次多报几个备选字号，避免"最喜欢的第一名称被驳回"浪费时间。

## 提交材料与实名认证

现在各省"一网通办"平台线上提交，材料清单：

- **公司章程**：平台有模板可套用，但股东比例、分红与表决权安排、退出条款建议按01篇的股权结构自行调整——模板默认"按出资比例"，不一定符合你的设计。
- **主体资格证明**：全体股东、法定代表人、董事、监事、经理的身份证件信息。
- **住所使用证明**：产权证复印件或租赁合同（挂靠地址由服务商出具场所证明）。
- **任职文件**：董监高任命。注意**监事不能由法定代表人兼任，财务负责人不能兼任执行公司事务的董事/经理**（新法下规模较小的公司可不设监事会，设一名监事或依法由审计委员会替代）。

提交后全体相关人员做**实名认证 + 电子签名**（各省App人脸核身）。材料齐全、符合法定形式的，登记部门当场或3—5个工作日内办结。

## 领取营业执照

审核通过后领取**营业执照**（正、副本），同步发放**电子营业执照**——电子执照在税务、银行、社保等场景已广泛使用，法定代表人用小程序即可下载。

执照上的核心信息：**统一社会信用代码**（企业的身份证号，终身唯一）、公司名称、法定代表人、注册资本、类型、成立日期（公司从这一天起"出生"）、营业期限、住所、经营范围。

> 现在执照、印章、税务、社保已"多证合一"，领照后社保登记信息自动生成，但**银行账户、税种核定、公积金仍需自行办理**（见04篇）。

## 刻章与备案

领照后刻制印章需到**公安备案**的正规刻章点，常见"四章/五章"：

| 印章 | 用途 | 风险点 |
|---|---|---|
| 公章 | 效力最广，对外发文、签合同、办登记 | **等于公司意志**，保管人必须可信 |
| 财务章 | 银行票据、结算 | 与法人章配套使用 |
| 法人章 | 代表法定代表人签章（银行预留印鉴） | 通常与财务章分开保管 |
| 发票章 | 开具发票 | 仅发票场景 |
| 合同章 | 签合同 | 与公章签合同的效力相同，分开管理便于留痕 |

多数城市新设企业**免费赠送一套印章**（领照时同步申领）。注意：萝卜章（未备案私刻章）签订的合同，只要构成表见代理公司照样担责——印章管理混乱本身就是经营风险。
