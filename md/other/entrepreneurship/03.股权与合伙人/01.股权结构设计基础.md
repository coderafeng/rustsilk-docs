# 股权结构设计基础

股权同时承载三种权利：**分钱（资产收益）、分权（表决权）、分名（股东身份）**。结构设计的目标，是在融资稀释发生之前，就让"控制权、分红权、进入退出机制"三件事各归其位。

## 67% / 51% / 34% 三条关键线

以有限责任公司为例（表决权默认按出资比例，**章程可另行约定**——这是后面所有设计工具的法律基础）：

| 持股比例 | 名称 | 意味着什么 |
|---|---|---|
| **≥67%（2/3以上）** | 绝对控制线 | 单独通过所有重大事项：修改章程、增减注册资本、合并/分立/解散/变更公司形式——**章程和生死都说了算** |
| **≥51%** | 相对控制线 | 通过普通决议、任免董事/监事、控制股东会与董事会多数席位，实际掌握日常经营决策 |
| **>33.4%（即34%）** | 一票否决线 | 达不到2/3，任何特别决议都过不了——**三分之一股权 = 对重大事项的否决权** |
| ≥30% | 收购线（股份公司） | 触及上市公司要约收购边界；持股变动达5%须权益披露 |
| ≥10% | 请求解散/提议开会线 | 可请求召开临时股东会；公司僵局时可诉请司法解散 |
| 有限公司查阅账簿 | 知情权 | 股东可要求查阅会计账簿、凭证（新法扩大到**凭证**），股份公司持股3%以上可查 |

> **速记**：67%是"我的地盘"，51%是"我说了算"，34%是"我不同意"。创始人可以在多轮融资中从67%→51%→34%逐步退守，但**守住34%之前，一切都只是"被代表"**。

## 创始人控股的常见方案

- **同股不同权（章程约定表决权）**：有限公司层面完全合法——章程可约定某类出资份额享有复数表决权，或某股东"只分红不投票"。这是成本最低的控制权工具。
- **有限合伙持股平台**：投资人/员工做LP拿收益，创始人做GP掌表决权——详见本篇05节与《公司类型的选择》对比表。
- **一致行动人协议**：联合中小股东把票集中到创始人手里（见05篇）。
- **董事会控制**：章程约定董事提名权归属（如"创始人有权提名半数以上董事"），股权丢了还能钉住董事会。
- **预留稀释空间**：初始结构按"创始人60%+ + 联合创始人20% + 期权池15% + 天使10%"这类格局起步，为后续2—3轮融资稀释留出余量，避免A轮后创始人就跌破51%。

## 股权代持的风险

代持（隐名股东）在无法登记（身份限制、竞业、公务员）或图省事时常见，但风险双方各占一半：

- **对隐名股东**：代持协议原则上有效，但**要"浮出水面"须经其他股东半数以上同意**；显名之前你对公司没有直接权利，名义股东擅自转让、质押股权，第三人善意取得的，你只能向名义股东追偿；名义股东的**债权人可以查封登记在其名下的股权**，离婚、继承、破产时股权还会被卷入纠纷。
- **对名义股东**：登记公示意味着你可能被要求承担出资义务——代持协议不能对抗公司和债权人的实缴要求。
- **对公司/投资人**：上市审核要求股权清晰，代持必须在申报前清理，处理不好就是IPO障碍。

> **坑位提示**：非用不可时，签齐三件套——**代持协议（明确出资、权利归属、处分限制、违约责任）+ 公司和其他股东的书面确认 + 名义股东配偶的同意函**。能显名尽量显名，能走持股平台不要走自然人代持。
