# 创业者的素质与能力模型

"我适合创业吗"是个坏问题——适合创业的不是一种性格，是一组**可评估、部分可速补的能力与条件**。本篇给你一台体检仪，而不是一碗鸡汤。

## 创业者能力雷达图

八个维度，每项1—5分自评（找两位共事过的人他评一遍，**自他评分差大于1.5的维度，才是你的认知盲区**）：

| 维度 | 5分的样子 | 短板后果 |
|---|---|---|
| **专业/产品能力** | 在细分领域有拿得出手的作品 | 无法定义"好"，交付失控 |
| **销售与说服** | 能卖产品、卖愿景、卖自己 | 融资、招人、获客全面卡死 |
| **财务与数字素养** | 看得懂三张表、算得清单位经济 | 公司死于"不知道为什么不赚钱" |
| **用人与带队** | 能找到比自己强的人并留住 | 永远单干，规模天花板=个人产能 |
| **资源与人脉** | 有可激活的客户、供应链、行业关系 | 冷启动成本高一倍以上 |
| **学习与认知迭代** | 每季度能推翻自己一个旧判断 | 路径依赖，抱残守缺到现金流枯竭 |
| **身心抗压** | 高压下睡眠与决策质量稳定 | 见下节，这是"一票否决"项 |
| **家庭与后方支持** | 家人知情、共识、有兜底安排 | 见《家庭与创业的平衡》 |

两条使用规则：

- **长板决定上限，短板决定生死**——销售、现金流、抗压这三项有致命短板的，先补再上路；其余短板可以用合伙人、外包、股权交换来补（见《合伙人选择与协议》）；
- 能力可以边做边长，**但"愿不愿意亲自去卖、去算账、去求人"的态度伪装不了**——态度分比能力分更重要。

## 抗压与决策能力

创业的心理内核是三块肌肉：

- **模糊容忍度**：能否在只有60%信息时拍板并承担后果？大公司训练出的"等数据齐了再决策"习惯，在初创是致命惰性——正确姿势是**把"可逆的事快定、不可逆的事慢定"作为原则**（单向门/双向门方法，展开见《创业者的心理建设》）；
- **挫折归因模式**：被投资人拒10次、被大客户毁约后，你把它解释为"我不行"（内部稳定归因，易抑郁）还是"这个假设/渠道/人不匹配"（外部可变归因，可迭代）——**健康的答案是"事情可归因、自己可修复"**：既不甩锅到底，也不PUA自己；
- **责任内化（内控型人格）**：相信结果主要由自己的动作决定——这不是盲目自信，而是唯一有用的工作假设（外控者在创业里每件事都等风来）；
- 压力耐受有生理底线：连续失眠两周后决策质量显著滑坡（科学结论，不是感受）——**"扛压能力"的一半是睡眠、运动与家庭账户的管理能力**（见09目录）。

## 销售与资金管理能力

两个最常被技术型创始人声明"我不擅长"的能力，恰恰是创始人的**第一全职岗位**：

- **销售**：创业早期你至少要亲自卖——因为只有创始人能边卖边收集"客户为什么买/为什么不买"的一手信息（这正是需求验证的原料，见下下篇）；"不喜欢跟人打交道、不好意思谈钱"是可以练的行为问题，**拒绝练才是态度问题**；至少要会三种推销：把产品卖给客户、把愿景卖给候选人、把逻辑卖给投资人；
- **资金管理**：不需要会做账（可以请代账），但三件事必须长在老板脑子里——① **账上现金与runway每周更新**（见《经营数据分析》五指标）；② 每笔支出的"回本假设"说得出口；③ **单位经济模型**（LTV/CAC，见《定价与单位经济模型》）能徒手画出来——"钱的事交给财务"的老板，第一次大规模失血都是毫无预兆的。
