# 公司风险隔离与创始人责任

注册有限公司不是买了张免死金牌——**有限责任只保护"合规经营的股东"，不保护"把公司当钱包的人"**。本篇讲清楚这道保护伞什么时候会失效，以及创始人个人还有哪些直接责任。

## 有限责任的保护与失效（法人人格否认）

- **正常状态**：公司欠债，债权人只能追公司资产，股东以出资额为限担责——这是01篇《公司类型的选择》里公司制的核心价值；
- **失效开关（《公司法》第23条）**：股东**滥用法人独立地位和有限责任逃避债务、严重损害债权人利益**的，对公司债务承担**连带责任**——即"刺破公司面纱"；
- **横向否认**（2024新法明确）：股东利用其控制的**两家以上公司之间人格混同**逃债的，各公司互负连带——"一老板多壳、资产左挪右移"的老玩法已被法条点名；
- **一人公司**：不能证明公司财产独立于股东自己财产的，对公司债务连带（**举证责任倒置**）；
- 触发人格否认的高频行为清单，全在下一节。

## 公私财产混同的后果

混同不看"感情好不好"，只看证据——法院审查的就是这几件事：

| 混同信号 | 隔离动作 |
|---|---|
| 公司款项进个人卡/个人微信支付宝长期收款 | **一律对公账户收付款**（个人卡收款还会同时触发隐匿收入税务问题，见《创业公司账务基础》） |
| 家庭消费入公司账、公司账给老板个人消费买单 | 老板取酬只走工资/分红/合规借款三通道 |
| 公司与股东、公司与公司之间**资金随意划转、无合同无记账** | 每一笔关联往来都有借款合同或服务合同 + 公允定价 + 挂账 |
| 共用办公场所、人员、账户不分（多壳公司） | 关联公司之间场所、人员、账户、业务独立留痕 |
| 账簿混乱或缺失，无法区分财产 | 独立建账核算，**一人公司强烈建议每年审计**（自证财产独立靠的就是审计底稿） |

**另一记个人重拳是未履行出资义务**：认缴不是"口头承诺"——新法5年实缴期内未缴足，公司不能清偿到期债务的，**债权人可请求已认缴未届期股东提前缴纳（加速到期）**；股权转让时未实缴出资的义务会转移给受让人，转让人对受让人未按期缴纳部分承担**补充责任**（别拿"1元转让未实缴股权"逃出资，法条已堵死）。

## 对外担保与连带责任

- **公司给别人担保**：须按章程由董事会或股东会决议；**为股东/实控人担保必须股东会决议且该股东回避表决**。法定代表人越权签的担保，相对人未审查决议的多被认定无效——但公司仍可能按过错承担部分赔偿责任，**公章管理制度把"用印必有决议"落成流程**；
- **创始人给别人/给公司担保**：投资协议里的创始人个人连带担保、银行贷款要求法定代表人夫妻双签个人连带担保——**签了就是拿全部家产换公司信用**，个人破产制度目前仅深圳有地方试点，兜不住全国债权人；能谈就谈成**以持股为限的担保或股权质押**，并把担保范围（本金/利息/费用）、期限、追偿条款逐项压缩；
- 给配偶、亲戚公司"顺手"做担保的，按上面同样的审查标准对待——**没有"顺手"这回事**。
