# 纠纷处理与常见诉讼

公司成长到一定规模，纠纷不是"会不会来"而是"什么时候来"。原则一句话：**纠纷处理是经营问题，不是面子问题——目标是回款和止损，不是"争口气"。**

## 协商、调解、仲裁与诉讼的选择

| 路径 | 特点 | 适用 |
|---|---|---|
| **协商** | 成本最低；但口头让步无保障——谈成的方案**落成书面《和解协议/补充协议》**，写清金额、期限、违约即恢复原债权全额 | 所有纠纷的第一步 |
| **调解** | 人民调解/行业调解/法院诉前调解；**调解协议经法院司法确认后具备强制执行力** | 想快速拿钱、关系还要维护的 |
| **商事仲裁** | 一裁终局（快但无退路）、保密、费用较高、可选仲裁员；**须合同有仲裁条款**；裁决跨境执行力强（《纽约公约》） | 金额大、条款完备的商事合同；注意与诉讼二选一，写"可仲裁可诉讼"约定无效 |
| **诉讼** | 两审终审、公开、周期6—18个月常见；**小额诉讼程序**（标的额低于当地上年度就业人员年平均工资一定比例的简单债务）**一审终审、3个月内结案** | 合同有管辖法院条款/无仲裁条款 |
| **劳动仲裁** | **劳动争议的前置程序**（先仲裁后诉讼），不收费 | 员工纠纷（见02篇） |

**程序武器**：担心对方转移财产的，起诉前/诉中申请**财产保全**（冻结账户、查封资产，通常需提供担保，保险公司保函成本约1%—3%）——实务中**"一保就和解"**是中小额债务纠纷的常态。

## 支付令与快速回款

对付"欠钱不还但对方不吱声"的货款/借款，有比打官司快得多的三件套：

1. **支付令（督促程序）**：债权债务关系明确、无对价的金钱债务，向法院申请向债务人发出支付令——**债务人15日内既不履行又不书面异议的，直接申请强制执行**；申请成本约为诉讼费三分之一；对方一提出书面异议即失效转入诉讼（适合"对方没底气争"的账）；
2. **赋强公证**：还款协议、欠款确认书办理**赋予强制执行效力的债权文书公证**，对方违约时**跳过诉讼直接申请执行**——对"拖字诀"客户的补充协议是核武器；
3. **调解+司法确认**：诉前调解达成协议后申请司法确认，同样获得执行力且免诉讼费。

**证据链决定速度**：以上三条全部要求债权"白纸黑字无争议"——回款慢的公司，先回头补《合同基础与常用合同》里对账单、验收单、催款的功课。

## 证据留存清单

民事诉讼的基本格局是"谁主张谁举证"，平时按这张表归档，打官司时就是压倒性优势：

| 类别 | 留存要点 |
|---|---|
| **合同与订单** | 原件（含骑缝）、补充协议、变更签证单、招投标/报价往来 |
| **履行过程** | 送货签收单、物流记录、验收报告、对账单（**定期对账并要求盖章回传，是对债权的反复确认，同时中断诉讼时效**） |
| **资金** | 银行回单、流水（与合同主体一一对应，**备注栏写明"XX合同货款"**） |
| **沟通** | 微信记录保全三原则：**不删原对话、能指明对方身份（实名/绑定信息/名片佐证）、导出+关键页公证**；邮件用企业邮箱存档；**自己参与的对话录音合法可用**（未经对方同意的私下录音不当然非法，但不得侵入他人住宅/窃听第三方） |
| **催款** | EMS寄送《催款函》，**面单"内件品名"栏写明"催款函"**并留寄送与签收记录——书面催告是中断时效、证明对方恶意、支持违约金的关键 |
| **权利凭证** | 知识产权登记证书、股权/出资凭证、股东会董事会决议（公司治理纠纷用） |

**诉讼时效**：一般民事债权**3年**（自知道权利受损起算），逾期不告丧失胜诉权——催款函、对账单、部分履行都能重新起算，**每年至少让"中断时效"动作发生一次**。
