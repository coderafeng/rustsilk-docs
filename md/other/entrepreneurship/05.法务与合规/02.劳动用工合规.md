# 劳动用工合规

劳动争议是创业公司败诉率最高的官司——**因为举证责任几乎全在公司**：合同、考勤、工资记录、解除依据，拿不出来就是输。本篇按"入职→在职→离职"全流程给要点。

## 劳动合同的签订与试用期

- **用工之日起30日内必须签书面劳动合同**；超过1个月不满1年未签的，员工可主张**双倍工资**；满1年仍未签的，视为已订立无固定期限合同——这是劳动仲裁第一大赔案；
- **试用期上限**与合同期限挂钩：合同3个月—1年 → 试用期≤1个月；1—3年 → ≤2个月；3年以上或无固定期限 → ≤6个月；**同一员工只能约定一次试用期**；
- 试用期工资≥转正工资的80%且≥当地最低工资；
- 试用期辞退不是"随便辞"：须证明员工**不符合录用条件**，且录用条件要事先书面告知并由员工签收——入职时不发《岗位录用条件确认书》，试用期解雇等于白给N；
- 无社保、无合同、现金发薪的"草台开局"，员工离职时一告一个准，三案并罚。

## 社保公积金合规

- **社保是法定强制义务，"员工自愿放弃社保协议书"一律无效**，签了也照样被责令补缴；
- 员工可以"未依法缴纳社保"为由**被迫解除劳动合同，并反向主张经济补偿（N）**——不给社保，最后连补偿金一起赔；
- 缴费基数按员工**上年度月均工资**在当地上下限（60%—300%）内核定，"按最低基数全员缴"是普遍违规状态，金税系统下社保入税后稽查能力大增，**至少把工资表、申报基数、个税申报三方数据做一致**；
- 住房公积金依《住房公积金管理条例》应缴未缴的，员工可投诉至公积金中心责令补缴（不属于劳动仲裁受理范围，但跑不掉）；
- 初创期的现实折中：**全员足额一步到位有困难的，优先保证"全员有缴+新增员工规范起步"**，历史欠缴的风险敞口和应对预案让律师评估。

## 辞退与经济补偿（N / N+1 / 2N）

先分清三个数：

| 概念 | 适用情形 | 计算 |
|---|---|---|
| **N（经济补偿）** | 协商解除（公司提出）、合同到期公司不续、员工被迫解除（欠薪欠保）、无过失性辞退（医疗期满、不能胜任经培训调岗仍不能胜任、客观情况重大变化）、合规裁员 | N = 工作年限 × 离职前12个月平均工资（超当地社平3倍的按3倍封顶、最长12年）；不满半年按0.5个月计 |
| **N+1** | 上述"无过失性辞退"三情形，**未提前30日书面通知**的，额外付1个月代通知金 | +1 即"代通知金"，提前30天通知了就只有N |
| **2N（赔偿金）** | **违法解除**（拿不出合法依据或程序违法） | 员工可选继续履行合同，或主张2N |

实操铁律：

- **过失性辞退（第39条：严重违纪、严重失职营私舞弊造成重大损害、被追究刑责等）无需补偿**，但前提是规章制度里把"严重违纪"写清楚了——**经民主程序制定 + 向员工公示送达的员工手册**，是过失性辞退唯一的武器；
- "能力不行所以裁掉"几乎必输：法定路径是**培训或调岗 → 仍不能胜任 → N+1**，直接开 = 2N；
- 绝大多数场景**协商解除优于单方辞退**：谈一个 N 或 N+X，签《协商解除协议》写清"双方再无其他争议"，比打一年仲裁便宜；
- 孕期、产期、哺乳期及医疗期内员工不得适用无过失辞退与裁员，**别碰红线**。
