# 成本发票与合规报销

"发票"是创业公司最高频的财务冲突现场：员工觉得报销繁琐，老板想省税，财务两头受挤。本篇只讲一件事——**真实的支出如何合规地变成税前扣除的成本**。

## 无票支出的合规处理

先破一个误区：**没有发票 ≠ 一定不能在所得税前扣除**，关键看"能不能补"和"是不是真实"：

1. **小额零星（对个人，单次≤500元）**：直接凭载明收款人姓名、身份证号、项目、金额的**收款收据**扣除，无需发票（搬运费、临时劳务菜场采购等）；
2. **应当取得而无法取得的特殊情形**：对方已注销、吊销、死亡、失联的，凭**合同 + 非现金支付凭证 + 对方注销/失联的佐证材料**可扣除（国家税务总局2018年28号公告）——前提是业务真实；
3. **能补的赶紧补**：汇算清缴期（次年5月31日）前补回发票的，当年正常扣除；之后才发现缺失的，**追补至支出发生年度扣除，追补期不超过5年**；
4. **工资、社保、公积金、利息（金融机构外部分按规定）、罚金、行政事业性收费**等本就无发票，凭完税凭证、缴费单据、收款收据等即可。

> **底线**："无法取得"要留下证据链；"懒得取得"就是给汇算调增埋雷——**证据链 = 合同 + 支付记录 + 业务过程记录（聊天/验收/物流）**。

## 报销制度的建立

初创公司 10 人以内，一张A4纸讲清即可：

- **类目 + 标准**：差旅（实报或包干）、市内交通、招待（**事前审批制**，单笔超X元需老板批）、办公用品；
- **凭证要求**：一律要发票（公司抬头 + 税号），发票信息模板直接发给全员；微信/支付宝账单截图只能作辅助，不能替代发票；
- **支付路径**：**报销一律打员工个人银行卡并备注"报销款"**，现金支付单笔超限额不予认可——资金流可追溯是保护员工也是保护公司；
- **审批链**：金额分层（员工→主管→老板），财务只做形式审核（发票真伪、金额一致），业务真实性责任回到申请人签字承诺；
- **税务敏感项单列**：给员工的**餐费/住房/交通补贴**若属"福利性普惠"进职工福利费（14%限额），**出差途中误餐补助、因公出差交通误餐包干**按差旅费处理不占福利额度——同一笔钱两个科目，扣除限额差出14%。

## 常见税务雷区清单

| 雷区 | 后果 |
|---|---|
| **买发票抵成本** | 虚开发票，补税+罚款+刑责，代账公司"打包服务"送来的票全部有毒 |
| 老板家庭消费（孩子学费、家用轿车油费）入公司账 | 调增补税 + 财产混同信号（一人公司连带责任的证据） |
| 用invoice凑数冲抵工资（拆成"报销款"发） | 偷逃个税，扣缴义务人罚款0.5—3倍，员工社保基数同样被追 |
| 大额现金支付采购/工资 | 无凭据不得扣除；反洗钱推送；工资现金发等于承认没申报 |
| 拆分合同、拆分发票"化整为零" | 超限额招待费、超标福利换个马甲照样被还原 |
| 房租、水电长期由个人账户代付不入公账 | 视同隐匿收入/视同借款分红，双重炸 |
