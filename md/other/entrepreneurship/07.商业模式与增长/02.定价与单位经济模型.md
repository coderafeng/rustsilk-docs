# 定价与单位经济模型

定价是创业公司**杠杆最大的杠杆**——涨价10%，利润往往涨30%以上；而单位经济模型（Unit Economics）回答那个终极问题：**每服务一个客户，公司是赚钱还是在有节奏地失血？**

## 定价策略与心理

三种定价逻辑，按适用度排序：

- **价值定价**（首选）：按"你替客户创造/省下多少钱"的百分比定价——B端软件省一个人力成本一年8万，收1—2万合理；**说不清客户价值的定价都是拍脑袋**；
- **竞争定价**：有明确对标时围绕市场价±定位差异；低价切入是消耗战，初创别主动挑；
- **成本加成**：仅用于贸易与项目制（成本 ÷ 目标毛利率），且**成本必须是全成本**（含退货损耗、资金占用、你的时间）。

心理与结构设计：

- **三档锚定**：放一个明显偏贵的"顶配档"当锚，中间档才是主推——用户不是买最差的，是买"性价比"；
- **诱饵效应**：新增一个略差的中间选项可以改变两端选择比例；
- **尾数与表述**：C端用99/199（便宜感），B端用整数（专业感）；**"每月每人39元"比"每年1400元"好卖**，但现金流与续费率会教你做人——年付折扣换现金流是正经设计（年付8折很常见）；
- **涨价纪律**：对新客户涨价容易、对老客户涨价难——发布前把价格定在对的位置，**长期低价是隐性违约未来涨价义务**；老客保价1年 + 新客新价是体面过渡。

## LTV / CAC 与回本周期

核心公式（**务必用毛利口径**，新手最大的坑在这）：

- **LTV（客户生命周期价值）** = 年均客单收入 × 毛利率 ÷ 年流失率（如：客单1200、毛利70%、年流失30% → LTV = 2800元）；
- **CAC（获客成本）** = （市场费用 + **销售/内容团队薪酬** + 渠道费用）÷ 同期新增付费客户数——只算广告费的CAC是自欺；
- **健康线**：**LTV / CAC ≥ 3**（< 1 直接亏损；1—3 之间看回本周期）；**CAC 回本周期**：B端SaaS ≤ 12个月、B端大客户 ≤ 24个月、C端 ≤ 3个月——回本周期比LTV/CAC更能反映现金压力（两者口径与融资预算的联动见《现金流管理》）；
- **分渠道算账**：不同渠道CAC差5倍是常态——混合CAC掩盖"付费投放拖死全模型"的事实，**每月按渠道出这组数**；
- 提升杠杆的只有三个动作：提客单/毛利（02节）、降流失（05篇留存）、降CAC（品牌与转介绍），**顺序反了（先砸投放）烧的都是估值**。

## 毛利率的结构设计

毛利不是算出来的，是**设计**出来的：

- **先定红线再定业务**：软件类目标 ≥ 70%、内容/数字产品 ≥ 80%、服务/项目制 ≥ 40%、贸易 ≥ 15%——低于红线还没规模效应，投资人一眼看穿模型不成立（对标《融资轮次全景》各轮看点）；
- **变动成本逐项瘦身**：履约成本（客服、物流、云资源）与规模的关系是"线性"还是"递减"——线性毛利永远等不来规模红利；
- **服务产品化**：定制开发毛利60%人力成本吃掉，沉淀成标准模块后毛利80%——**项目制是SaaS的孵化器，不是终局**（见下节）；
- **警惕"混合毛利"幻觉**：把低毛利硬件与高毛利订阅捆绑讲"综合毛利"——尽调时被拆开重算（DD财务章节口径），不如一开始就分层定价。
