# 尽职调查与交割

TS签完只是恋爱成功，**DD（尽职调查）才见家长，交割才是领证**。多数"临门一脚被砍价或崩盘"的交易，问题在DS打开前就已注定——DD不是考试，是平时成绩的单子。

## DD 的范围与流程

四个模块，权重按投资人类型调整：

| 模块 | 查什么 | 常用手段 |
|---|---|---|
| **业务DD** | 市场真实性、竞争壁垒、数据可信度 | 高管访谈、**客户/供应商回访与函证**、终端抽核流水 |
| **财务DD** | 收入确认、毛利、现金与往来、体外循环 | 报表+序时账+银行流水**三方比对**、发票与回款抽查 |
| **法律DD** | 股权清晰与出资、重大合同、劳动社保、诉讼、资质合规 | 工商档案、裁判文书检索、合同台账抽样 |
| **技术DD** | 代码自主率、架构可扩展、安全与数据合规 | 代码审计（第三方）、开源清单扫描、系统演示 |

流程：DD清单 → 数据室分批开放 → 管理层会议（Management Meeting，**唯一一次"人对人"的考核**）→ 专项问答 → DD报告与投决会。周期2—6周，**响应速度本身就是尽调项**——拖延一周，对方耐心降一档。

## 常见卡点与整改

按发现频率排序的雷区，以及**正确的处理方式（主动披露 + 整改方案 + 列为交割先决条件）**：

1. **两套账/个人卡收款**：收入真实性一票否决项，且是刑事红线（逃税、虚开）——融资前6—12个月就应启动"业务并账"，把流水、申报、账面拉成一条线；
2. **社保公积金欠缴**：全员补缴成本可控、金额可测算——DD前让员工纠纷清零，测算欠缴总额报给对方做**专项陈述与保证**处理；
3. **股权代持/历史出资瑕疵**：代持还原要其他股东过半数同意、出资瑕疵要补足——**在DD启动前做完**，别留给投资人"要求整改+延长排他"；
4. **知识产权权属**：核心代码外包无权属约定、职务发明未签协议、商标在法人个人名下——DD前补合同、做转让登记（成本几十元官费级别，影响估值千万级）；
5. **公私混同与关联往来**：其他应收款挂账老板借款（视同分红风险）、关联交易无定价依据——先规范再开门；
6. **缺票与无票支出**：成本票不全 = 利润虚高 = 所得税风险，量化成金额讲清，比被翻出来体面；
7. **未决诉讼与数据合规**：败诉风险量化披露 + 预留机制（价款分期/赔偿专户）。

> **铁律**：投资人可以接受问题，**不能接受被隐瞒的问题**——披露是谈判筹码（"已知风险、已定价、给整改方案"），隐瞒是信任违约（重谈条款、加个人担保、直接散伙）。

## SPA 股东协议签署

TS落到正式文件一般是三件套：**增资协议/股权转让协议（SPA）+ 股东协议（SHA）+ 新公司章程**：

- **陈述与保证（R&W）**：对 founders 部分争取三项修饰——"就创始人**所知**"（knowledge qualifier）、设定**披露函（Disclosure Letter）** 把已知例外逐项列出、赔偿责任设**上限（一般以持股价值为限）与期限（12—24个月，税务/知产可略长）**；
- **赔偿条款**：违反R&W的损失如何计算与分担——警惕"创始人个人连带+无上限"；
- **SHA vs 章程**：两者冲突时，股东之间按协议（合同效力），**对外与治理执行靠章程**——SHA核心条款（否决事项、董事提名、分红安排）**必须同步写进章程并完成登记**，否则"协议赢了、执行不了"；
- 交割条件（CP）要区分：哪些是你的义务（限期可完成）、哪些是对方的（付款能力证明）；**"重大不利变化（MAC）"条款写得越模糊，对方毁约越方便**——尽量列举化。
