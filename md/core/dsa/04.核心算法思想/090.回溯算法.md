# 概述

回溯（Backtracking）= **带剪枝的深度优先搜索**：在状态空间树上「选择 → 递归 → 撤销」逐层推进，走不通就退回上一步换分支——它不生产新算法，而是**所有穷举类问题的系统化骨架**；配上可行性剪枝、最优性剪枝与去重技巧，能把「理论 O(n!)」的暴力裁剪到实际可跑的规模。

- 时间复杂度：最坏与解空间同阶——排列 O(n!)、子集 O(2ⁿ)、N 皇后约 O(n!)（剪枝后实际远小于）；空间 O(h) 递归栈 + 当前路径。
- 与相邻思想的关系：分治要求子问题独立、DP 要求重叠子问题+无后效，回溯则**不做记录只做遍历**，靠剪枝砍树；[100.分支界定法](./100.分支界定法.md) 是它的「最佳优先」表亲。
- 应用场景：约束求解全家（数独、N 皇后、地图着色、SAT 求解器的 DPLL 本质是回溯+剪枝）、组合生成（测试用例、排班、菜单）、正则引擎的回溯匹配、编译器的歧义消解、博弈搜索（α-β 剪枝的极小极大 = 回溯 + 上下界）、密码分析字典攻击；NP 问题小规模精确解的第一选择（见 [030.NP完全与近似算法](./030.NP完全与近似算法.md)）。

- 所属章节：[000.核心算法思想概述](./000.核心算法思想概述.md)

按列放置（棋盘 4×4），每列选一行：

1. 列 0 放行 0 → 列 1 行 0/1 冲突（同行/对角），放行 2 → 列 2 所有行都被「(0,0)(1,2)」压制，**死路**；
2. **撤销**列 1 的棋子，回到列 0 换行：列 0 放行 1 → 列 1 可行 3 → 列 2 可行 0 → 列 3 可行 2 → **命中一个解** `[1,3,0,2]`；
3. 继续撤销-换分支找第二个解 `[2,0,3,1]`；全部分支穷尽后算法结束；
4. 剪枝视角：每放一枚棋子就把它攻击过的行/对角线标记（三个布尔数组 O(1) 判冲突），冲突分支**不进入下一层**——树上被砍掉的节点就是回溯比裸暴力快的全部原因；
5. 动画里「棋子下落-弹起」= 递归进入与 `path.pop()` 撤销；树上灰掉的子树 = 被剪枝分支。

# 详解

## 通用框架（三行半的模板）

```text
 backtrack(路径, 选择列表):
   if 满足结束条件: 收集结果; return
   for 选择 in 选择列表:
     剪枝检查（不可行/必不优/重复 → continue）
     做选择;  backtrack(新路径, 新选择列表); 撤销选择
```

「撤销」是回溯的灵魂：DFS 递归天然带栈，做选择/撤销必须**成对**出现（改了 `used[]` 要还原、加了 `path` 要 pop）——90% 的回溯 bug 来自某处状态改了没还原。

## 范例一：全排列（含去重）

::: code-group

```java [Java]
List<List<Integer>> res = new ArrayList<>();
void permute(int[] nums, boolean[] used, List<Integer> path) {
    if (path.size() == nums.length) { res.add(new ArrayList<>(path)); return; }
    for (int i = 0; i < nums.length; i++) {
        if (used[i]) continue;
        // 去重：同层不选相同值（需先排序）——i>0 && nums[i]==nums[i-1] && !used[i-1] 时跳过
        if (i > 0 && nums[i] == nums[i - 1] && !used[i - 1]) continue;
        used[i] = true; path.add(nums[i]);
        permute(nums, used, path);
        path.remove(path.size() - 1); used[i] = false;   // 撤销与做选择严格成对
    }
}
// 入口：Arrays.sort(nums); permute(nums, new boolean[n], new ArrayList<>());
```

```rust [Rust]
fn backtrack(a: &[i32], used: &mut [bool], path: &mut Vec<i32>, res: &mut Vec<Vec<i32>>) {
    if path.len() == a.len() { res.push(path.clone()); return; }
    for i in 0..a.len() {
        if used[i] { continue; }
        if i > 0 && a[i] == a[i - 1] && !used[i - 1] { continue; }   // 同层去重
        used[i] = true; path.push(a[i]);
        backtrack(a, used, path, res);
        path.pop(); used[i] = false;
    }
}
```

```typescript [TypeScript]
function permuteUnique(nums: number[]): number[][] {
  const res: number[][] = [], path: number[] = [];
  const used = new Array(nums.length).fill(false);
  nums.sort((x, y) => x - y);
  function bt(): void {
    if (path.length === nums.length) { res.push([...path]); return; }
    for (let i = 0; i < nums.length; i++) {
      if (used[i]) continue;
      if (i > 0 && nums[i] === nums[i - 1] && !used[i - 1]) continue;
      used[i] = true; path.push(nums[i]);
      bt();
      path.pop(); used[i] = false;
    }
  }
  bt();
  return res;
}
```

```python [Python]
def permute_unique(nums: list[int]) -> list[list[int]]:
    nums.sort()
    res, path = [], []
    used = [False] * len(nums)
    def bt():
        if len(path) == len(nums):
            res.append(path[:])
            return
        for i in range(len(nums)):
            if used[i]:
                continue
            if i > 0 and nums[i] == nums[i - 1] and not used[i - 1]:
                continue                       # 同层去重
            used[i] = True; path.append(nums[i])
            bt()
            path.pop(); used[i] = False
    bt()
    return res
```

:::

去重条件 `!used[i-1]` 的含义：**同一层**里前一个相同值没被选（它刚被撤销），当前值也不许选——保证重复元素只按「从左到右第一次出现」的顺序用一次；写成 `used[i-1]` 是另一种合法约定（强制同序），两者别混。

## 范例二：N 皇后（三数组 O(1) 剪枝）

冲突检查别写 O(n) 扫描——用三个标记数组：行 `cols[n]`、主对角线 `diag1[2n]`（r+c）、副对角线 `diag2[2n]`（r−c+n）。放置即置位、撤销即清位，剪枝从 O(n) 降为 O(1)，每层分支从 n 收窄到「实际可用列数」。

## 范例三：子集/组合与剪枝三件套

- 子集（LeetCode 78）：每层「选/不选」二叉分支或 `start` 指针 for 循环，收集**每个节点**（不要求叶子）；组合总和：`start` 控制不回头 + 排序后 `剩余量 < 当前数 → break`（**最优性剪枝**：后面的更大，整层不用试）。
- 剪枝三分类：**可行性剪枝**（约束不满足直接不进入）、**最优性剪枝**（当前代价已超已知最优则放弃）、**对称性剪枝/去重**（同层同值只取一次、组合用 start 保证升序）。

## 回溯 vs 迭代：什么时候换写法

递归版爆栈风险在「深度」：数独/皇后深度 ≤ 26 无压力；但「字符串拆分、括号生成」类深度可到 n=10⁵ 时改显式栈迭代；竞赛中求方案数/最优值且状态可缓存时，回溯 + 记忆化 = 自顶向下 DP（见 [060.动态规划基础](./060.动态规划基础.md)）——「回溯 TLE 就加 memo」是刷题的最后一公里。

## 常见陷阱

- 撤销遗漏：`path` 弹了但 `used` 没清（或反之），产生幽灵占用/漏解——「做/撤」两行代码必须贴着写。
- 收集结果没拷贝（Java `res.add(path)` 存引用）：后续撤销把已收集的答案也「撤」空了，务必 `new ArrayList<>(path)`。
- 去重排序前置条件忘了：同层去重依赖数组有序，没排序的 `nums[i]==nums[i-1]` 判断毫无意义。
- 边界/结束条件与题目语义不符：子集收集于每个节点，排列收集于叶子——把「何时记录」写成统一叶子是子集题漏解的头号原因。
- 数独/皇后用 O(n) 冲突检查导致常数爆炸；剪枝数组的设计（对角线编号 `r+c`、`r-c+n`）值得单独记。
- 组合与排列混淆：组合用 `start`（不回头、无序、可复用传 i 而非 i+1），排列用 `used[]`（每层全扫）——模板选错方向，去重与剪枝全乱。

# 总结

- 回溯 = DFS 遍历状态空间树 + 「选择-递归-撤销」成对协议，剪枝是唯一能改变其指数命运的杠杆；
- 三大模板记牢：排列（used）、组合/子集（start）、棋盘（多数组 O(1) 冲突判定）；去重看「同层」，剪枝分「可行/最优/对称」三类；
- 它适合「n 小、约束硬、要全部方案」的场景；一旦只要最优值且状态可复用，就向记忆化 DP 滑过去——回溯与 DP 本是同一条谱系的两端。
