# 概述

贪心（Greedy）每一步都取**当前看来最优**的选择，期望由此滚动到全局最优——不回头、不重试。它比 DP 更快（常常 O(n log n) 排序 + O(n) 扫描），但**正确性不天然成立**：必须证明「贪心选择性质」（局部最优能纳入某个全局最优）+「最优子结构」（选完后剩余子问题同型），常用**交换论证**：任一最优解都可经有限次替换调整成贪心解且不变差。

- 时间复杂度：多为 `O(n log n)`（排序主导）或 `O(n)`（已有有序性/计数排序），远快于同题 DP 的 O(nW)/O(n²)。
- 空间复杂度：O(1)~O(n)。
- 应用场景：
  - **可证最优**：区间调度（活动选择、会议室排期）、哈夫曼编码（见 [010.无损压缩算法](../10.应用与专题/010.无损压缩算法.md)）、Dijkstra 最短路（贪心 + 优先队列，见 [020.最短路径](../05.图结构与并查集/020.最短路径.md)）、Kruskal/Prim 最小生成树（见 [030.最小生成树](../05.图结构与并查集/030.最小生成树.md)）、分数背包、任务调度交换论证经典；
  - **近似与启发**：集合覆盖 ln n 近似、TSP 最近邻（无保证，见 [030.NP完全与近似算法](./030.NP完全与近似算法.md)）；
  - **日常系统**：缓存淘汰（LRU/LFU 本质是「未来视角贪心」的近似）、CPU 时间片、磁盘调度 SCAN、货币找零（特定面额）、防火墙规则归并。

# 详解

## 贪心正确性的证明套路

1. **交换论证（exchange argument）**：取任一最优解 O，从左往右找第一个位置 i 使得 O 的选择 ≠ 贪心选择 g；把 O 中的第 i 个元素替换成 g，证明可行性与目标值都不变差 → 存在一个与贪心解前缀更一致的最优解 → 归纳到全程一致。
2. **拟阵（matroid）**：当可行解族满足遗传性 + 交换性（如森林的边集），贪心必最优——最小生成树就是图上拟阵的贪心，这给了「何时无脑贪心」的终极答案。
3. **反证/归纳**：对「剩余子问题与原问题同型」（最优子结构）+「当前选择不排除未来更优」（贪心选择性质）分别论证。

## 范例：区间调度（结束时间贪心）

::: code-group

```java [Java]
// 最多互不重叠区间数：按结束升序，能要就要
int eraseOverlapIntervals(int[][] iv) {
    java.util.Arrays.sort(iv, (a, b) -> a[1] - b[1]);
    int cnt = 0, end = Integer.MIN_VALUE;
    for (int[] x : iv) {
        if (x[0] >= end) { cnt++; end = x[1]; }   // 不冲突就选，贪心安全
    }
    return iv.length - cnt;   // LeetCode 435 答案：需移除数 = 总数 - 最多保留
}
```

```rust [Rust]
pub fn max_non_overlapping(mut iv: Vec<[i32; 2]>) -> usize {
    iv.sort_by_key(|x| x[1]);                      // 按结束升序
    let (mut cnt, mut end) = (0, i32::MIN);
    for x in iv {
        if x[0] >= end { cnt += 1; end = x[1]; }
    }
    cnt
}
```

```typescript [TypeScript]
function maxNonOverlapping(iv: [number, number][]): number {
  iv.sort((a, b) => a[1] - b[1]);
  let cnt = 0, end = -Infinity;
  for (const [s, e] of iv) {
    if (s >= end) { cnt++; end = e; }
  }
  return cnt;
}
```

```python [Python]
def max_non_overlapping(iv: list[tuple[int, int]]) -> int:
    cnt, end = 0, float("-inf")
    for s, e in sorted(iv, key=lambda x: x[1]):    # 按结束升序
        if s >= end:
            cnt += 1
            end = e
    return cnt
```

## 贪心 vs DP：决策依据对照

| 维度 | DP | 贪心 |
|------|----|------|
| 决策方式 | 枚举所有转移取最优 | 直接取「看起来最好」 |
| 需要证明 | 最优子结构 + 无后效 | 额外需要**贪心选择性质** |
| 复杂度 | 状态数×转移 | 通常排序 + 线性扫描 |
| 失败案例 | — | 0-1 背包按性价比贪心：`W=10`，物品 `(v,w)=A(10,10)、B(9,8)、C(2,3)`，密度 `B(1.125)>A(1.0)>C`：贪心先装 B 剩 2 谁也放不下得 9，最优是单装 A 得 10；凑币 `[1,3,4]` 凑 6：贪心 4+1+1=3 枚，最优 3+3=2 枚 |
| 成功边界 | 通用 | 区间/调度/生成树/哈夫曼/拟阵 |

记忆钩子：**「找零钱能贪心是因为面额体系（人民币 1/2/5/10）满足规范币制性质」，随便给一组面额就要回 DP（完全背包）**。

## 哈夫曼贪心与 Dijkstra 的贪心本质

- 哈夫曼：每次合并**权重最小**的两棵树——「频率低的离根远」是带权路径最小的必要条件，交换论证可证（见 [010.无损压缩算法](../10.应用与专题/010.无损压缩算法.md) 的构造细节）；
- Dijkstra：每次敲定**dist 最小**的未定点——非负权保证「已定集合外不存在更短路绕过你」（若有，其前驱也必在候选中且更小，矛盾），这正是贪心选择性质在图上的体现；有负权即失效（见 [020.最短路径](../05.图结构与并查集/020.最短路径.md)）。

## 常见陷阱

- **没证明就贪**：贪心解看着顺眼 ≠ 最优；先花两分钟构造小反例（面额 1/3/4、背包性价比、按开始/时长排序的区间），找不到再尝试证明。
- 排序键选择敏感：结束最早 vs 开始最晚 vs 时长最短，三个键只有第一个对；写代码前明确「贪心安全引理」是哪一条。
- 贪心策略的适用边界会被悄悄破坏：无释放时间的单机最小化总完成时间，最短作业优先（SJSP）交换论证可证最优；一旦加上**释放时间或截止期**，同一贪心立刻失效（1|rⱼ|ΣCⱼ 已是 NP 难）——参数一变，安全贪心变反例制造机。
- 区间端点开闭：`[1,4)` 与 `[4,5)` 是否冲突取决于题意；`>=` 写成 `>` 整体错一步。
- 把贪心当近似用却宣称有界：最近邻 TSP 无常数近似比（见 [030.NP完全与近似算法](./030.NP完全与近似算法.md)），产品里用启发式就承认没有保证。

# 总结

- 贪心是「用证明换速度」：一旦拟阵结构或交换论证成立，就甩开 DP 的表换 O(n log n)；
- 判定三问：当前选择安全吗（贪心选择性质）？选完剩下还是原问题吗（最优子结构）？能否把任意最优解逐步改成贪心解（交换论证）——答不出就别贪；
- 经典安全贪心四件套记牢：区间按结束、MST 按轻边、Dijkstra 按最近未定、哈夫曼按最小双堆——它们分别是四类结构的代表元。
