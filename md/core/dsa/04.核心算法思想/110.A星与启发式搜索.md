# 概述

启发式搜索用一个问题特定的「估价函数」引导搜索方向，在巨大状态空间里避开盲目 BFS/Dijkstra 的全网铺摊：**A\* 算法** = Dijkstra + 启发项，`f(n)=g(n)+h(n)`（已付代价 + 到终点估计），配**可采纳**（不高估）与**一致性**（满足三角不等式）的启发函数即可保证最优；**集束搜索（Beam Search）**则反向取舍——每层只保留 b 个最好候选，牺牲最优换可控资源，是序列生成模型的默认解码器。

- 时间复杂度：A\* 最坏指数（状态空间），实际由 `h` 质量主导——`h=0` 退化为 Dijkstra，`h` 越准开口（open list）越小；beam search 每步 O(b·分支)，总 O(步数·b·分支)。
- 空间复杂度：A\* 的 open/closed 集是真正痛点（可指数）→ IDA\* 用迭代加深换 O(depth) 空间；beam search O(b)。
- 应用场景：
  - **A\***：地图导航路径规划（高德/Google Maps 的底层家族）、游戏寻路（NPC 移动、星际争霸单位寻路）、机器人运动规划、电路布线、拼图/魔方求解（15-puzzle 是教科书例）；
  - **IDA\***：内存受限的深度搜索（魔方 Kociemba 两步法、Hole-In-One 机器人规划）；
  - **Beam Search**：机器翻译/语音识别/图像描述 Transformer 解码、OCR 候选重排、拼写纠错；
  - 贪心最佳优先（只用 h）作为快速近似在实时策略游戏中常见。

起点左下、终点右上，曼哈顿距离做 `h`：

1. **Dijkstra**（等价 `h=0` 的 A\*）：从起点向外均匀扩「同心圆」，四面八方一视同仁——终点方向与反方向节点同样入队，扩展节点数 ≈ 到终点距离的平方级；
2. **贪心最佳优先**（`f=h`）：直奔终点看起来最近的方向，走得快但**不保证最优**（遇到凹形障碍会绕冤枉路甚至卡死）；
3. **A\***（`f=g+h`）：优先队列里既有「已走代价」也有「预估剩余」——扩张形状是**沿起点-终点轴的尖锥形**，障碍背后 h 虚高的节点被 g 拉回现实、推迟出队；
4. 关键画面：h 可采纳 ⇒ 任何「在真实最短路径上」的节点 f ≤ 最优解代价，永远排在「劣解终点」前面先被展开 ⇒ 首个弹出的终点即最优（证明主线一句话）；
5. 对比收尾：h=0 圆（最广）→ A\* 锥（适中）→ 贪心射线（最快可错）→ h=真实剩余距离 一条线（完美但不可知）——**启发式的信息量决定搜索的聚焦度**。

# 详解

## A\*：数据结构与主循环

```text
open   = 优先队列（按 f = g + h 升序）
g[start] = 0; open.push(start)
while open 非空:
    cur = open.pop_min()
    if cur == goal: 沿 parent 回溯即最短路径   # h 可采纳 ⇒ 此时必最优
    for nb in neighbors(cur):
        tentative = g[cur] + cost(cur, nb)
        if tentative < g.get(nb, ∞):
            g[nb] = tentative
            parent[nb] = cur
            open.push_or_decrease(nb, f = tentative + h(nb))
```

- 与 Dijkstra 的唯一区别是出队优先级 `g` → `g+h`；因此**所有 Dijkstra 的变形（惰性删除、双向搜索）都适用**。
- **可采纳**（admissible）：`h(n) ≤ h*(n)` 从不高估——树的证明靠它；**一致性/单调**（consistent）：`h(u) ≤ c(u,v)+h(v)`（三角不等式）——保证每个节点首次弹出即定稿，无需 decrease-key 反复刷新，图上也最优。一致 ⇒ 可采纳，反之不然（树图差异）。

## 启发函数从哪来：松弛问题

好 `h` 的标准生产法是「**删约束求易题**」：15-puzzle 的 `h1=错位置数`（去掉「必须一次滑动」约束）、`h2=曼哈顿距离和`（更紧）；实际路径规划的 `h=欧氏/曼哈顿距离` 对应「忽略障碍走直线」的松弛；导航里 ALT 地标三角不等式界是工业级做法。**h 越接近真值、扩张越少；h 若高估则可能次优**——工程常见「加权 A\*」`f=g+w·h (w>1)` 主动换最优为速度。

```java [Java]
// 网格 4 邻域，障碍物，h=曼哈顿距离；返回路径长度，-1 不可达
int astar(int[][] grid, int sx, int sy, int tx, int ty) {
    int m = grid.length, n = grid[0].length;
    int[][] g = new int[m][n];
    for (int[] row : g) java.util.Arrays.fill(row, Integer.MAX_VALUE);
    var pq = new java.util.PriorityQueue<int[]>(
            (a, b) -> (a[2] + a[3]) - (b[2] + b[3]));   // 按 f = g + h
    g[sx][sy] = 0;
    pq.offer(new int[]{sx, sy, 0, Math.abs(sx - tx) + Math.abs(sy - ty)});
    int[][] dirs = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
    while (!pq.isEmpty()) {
        int[] cur = pq.poll();
        if (cur[0] == tx && cur[1] == ty) return cur[2];
        if (cur[2] > g[cur[0]][cur[1]]) continue;        // 惰性删除：陈旧条目
        for (int[] d : dirs) {
            int x = cur[0] + d[0], y = cur[1] + d[1];
            if (x < 0 || x >= m || y < 0 || y >= n || grid[x][y] == 1) continue;
            if (g[x][y] > cur[2] + 1) {
                g[x][y] = cur[2] + 1;
                pq.offer(new int[]{x, y, g[x][y], Math.abs(x - tx) + Math.abs(y - ty)});
            }
        }
    }
    return -1;
}
```

```rust [Rust]
use std::collections::BinaryHeap;
use std::cmp::Reverse;

pub fn astar(grid: &[Vec<i32>], start: (usize, usize), goal: (usize, usize)) -> Option<i32> {
    let (m, n) = (grid.len(), grid[0].len());
    let h = |x: usize, y: usize| (x.abs_diff(goal.0) + y.abs_diff(goal.1)) as i32;
    let mut g = vec![vec![i32::MAX; n]; m];
    let mut pq = BinaryHeap::new();                      // 小顶：Reverse(f, x, y)
    g[start.0][start.1] = 0;
    pq.push(Reverse((h(start.0, start.1), start.0, start.1)));
    while let Some(Reverse((f, x, y))) = pq.pop() {
        if (x, y) == goal { return Some(f - h(x, y)); }
        if g[x][y] > f - h(x, y) { continue; }           // 惰性删除
        for (dx, dy) in [(1i32, 0i32), (-1, 0), (0, 1), (0, -1)] {
            let (nx, ny) = (x as i32 + dx, y as i32 + dy);
            if nx < 0 || nx >= m as i32 || ny < 0 || ny >= n as i32 { continue; }
            let (nx, ny) = (nx as usize, ny as usize);
            if grid[nx][ny] == 1 { continue; }
            let ng = g[x][y] + 1;
            if ng < g[nx][ny] {
                g[nx][ny] = ng;
                pq.push(Reverse((ng + h(nx, ny), nx, ny)));
            }
        }
    }
    None
}
```

```typescript [TypeScript]
function astar(grid: number[][], s: [number, number], t: [number, number]): number {
  const m = grid.length, n = grid[0].length;
  const h = (x: number, y: number) => Math.abs(x - t[0]) + Math.abs(y - t[1]);
  const g = Array.from({ length: m }, () => new Array(n).fill(Infinity));
  // 极简优先队列：排序数组（教学用；生产换二叉堆）
  const pq: [number, number, number][] = [];            // [f, x, y]
  g[s[0]][s[1]] = 0;
  pq.push([h(s[0], s[1]), s[0], s[1]]);
  while (pq.length) {
    pq.sort((a, b) => a[0] - b[0]);
    const [f, x, y] = pq.shift()!;
    if (x === t[0] && y === t[1]) return g[x][y];
    if (f - h(x, y) > g[x][y]) continue;                 // 陈旧条目
    for (const [dx, dy] of [[1, 0], [-1, 0], [0, 1], [0, -1]]) {
      const nx = x + dx, ny = y + dy;
      if (nx < 0 || nx >= m || ny < 0 || ny >= n || grid[nx][ny] === 1) continue;
      if (g[x][y] + 1 < g[nx][ny]) {
        g[nx][ny] = g[x][y] + 1;
        pq.push([g[nx][ny] + h(nx, ny), nx, ny]);
      }
    }
  }
  return -1;
}
```

```python [Python]
import heapq

def astar(grid, start, goal):
    m, n = len(grid), len(grid[0])
    h = lambda x, y: abs(x - goal[0]) + abs(y - goal[1])
    g = [[float("inf")] * n for _ in range(m)]
    g[start[0]][start[1]] = 0
    pq = [(h(*start), start)]
    while pq:
        f, (x, y) = heapq.heappop(pq)
        if (x, y) == goal:
            return g[x][y]
        if f - h(x, y) > g[x][y]:        # 惰性删除：跳过陈旧条目
            continue
        for dx, dy in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nx, ny = x + dx, y + dy
            if 0 <= nx < m and 0 <= ny < n and grid[nx][ny] == 0:
                if g[x][y] + 1 < g[nx][ny]:
                    g[nx][ny] = g[x][y] + 1
                    heapq.heappush(pq, (g[nx][ny] + h(nx, ny), (nx, ny)))
    return -1
```

## IDA\* 与 Beam Search：两个方向的取舍

- **IDA\***（迭代加深 A\*）：以 `h(start)` 为阈值做 DFS，超过阈值的节点把「最小超出值」记为下一轮阈值——**空间 O(深度)**，时间多常数轮重搜；魔方/十五拼图/硬件竞赛首选。
- **Beam Search**：每步扩展当前 b 条最优前缀，排序后截断到 b——不保证最优、不保证完备，但资源**硬上界**；NLP 解码的变体：top-k sampling、宽度和搜索（WBS）、分组 beam（grouped beam）都是它的采样化。与 A\* 对照：A\* 精确但内存不可控，beam 可控但随时可能丢掉最优序列——一个「全都要」，一个「先活着」。

## 常见陷阱

- **h 高估 ⇒ 丢最优**：欧氏距离用于 4 邻域网格会**低估**（可采纳 ✓）但欧氏用于 8 邻域也可能高估切角穿墙——可采纳性与移动模型强绑定，换约束先重验 h。
- 图上「已定稿」处理：一致性不满足时，节点可能以更小 g 再入队；「弹出即 finalized + 不再更新」的经典 Dijkstra 写法在纯可采纳（非一致）h 下会出错——要么保证一致，要么允许 decrease-key/惰性重复入队。
- 相等 f 的打破规则影响效率：优先大 g（离目标更近）通常更快收敛；tie-break 不当会让 A\* 退化出大量冗余扩展。
- beam 宽度 b 是超参：太小直接漏好解（翻译幻觉/语音识别丢词常与 beam 相关）、太大退化成穷举——报告指标时注明 b。
- 动态/未知环境里用静态 h 会误导：重规划（D\* Lite、LPA\*）更新的是 g 的增量传播，不是换 h——别把启发式当环境模型。

# 总结

- A\* = Dijkstra 出队序换成 `f=g+h`：h 可采纳 ⇒ 树上最优、一致 ⇒ 图上最优且免刷新；启发函数的信息量直接决定搜索锥的尖锐程度；
- 好 h 从「松弛问题」里来（直线/错位数/曼哈顿/地标三角界）；要省内存上 IDA\*，要硬资源上限换 Beam Search；
- 谱系一句话：`h=0` 是 Dijkstra，`只用 h` 是贪心最佳优先，`g+w·h(w>1)` 是加权 A\*，「宽度截断」是 beam——同一条设计轴上的四个刻度，按最优性/速度/内存三点选位。
