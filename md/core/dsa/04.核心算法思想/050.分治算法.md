# 概述

分治（Divide and Conquer）把问题**分解**为若干个规模更小的同构子问题，**递归解决**后把答案**合并**回原问题——「各个击破 + 汇总」。凡「规模可折半、答案可合并」的问题都该先想分治：归并与快排、二分查找、大数乘法、最近点对、最大子数组和都在这条线上。

- 时间复杂度：由递归式 `T(n) = a·T(n/b) + f(n)` 决定，用主定理查表（见 [010.算法分析基础](./010.算法分析基础.md)）：归并 `a=2,b=2,f=n` → Θ(n log n)；二分 `a=1,b=2,f=O(1)` → Θ(log n)；Karatsuba `a=3,b=2,f=n` → Θ(n^1.585)。
- 空间复杂度：递归栈 O(log n)~O(n)；归并需 O(n) 辅助数组，快排原地 O(log n) 栈。
- 应用场景：
  - **排序内核**：归并/快排/TimSort（见 [050.归并排序](../02.基础算法/050.归并排序.md)、[060.快速排序](../02.基础算法/060.快速排序.md)）、外排序的多路归并（大文件分块排序再合并）；
  - **查找家族**：二分、快排式选择（第 K 大期望 O(n)）、旋转数组二分；
  - **数值与多项式**：Karatsuba/Toom-Cook 大整数乘法（GMP、RSA 库底层）、FFT 多项式乘法（见 [070.Karatsuba乘法](../07.数值计算/070.Karatsuba乘法.md)、[060.快速傅里叶变换FFT](../07.数值计算/060.快速傅里叶变换FFT.md)）；
  - **几何与统计**：平面最近点对、凸包分治、逆序对计数（归并树上顺带统计）；
  - **系统工程**：MapReduce 的分治思想、并行归并、递归下降解析器、分治式 diff/合并算法（Git）。

- 所属章节：[000.核心算法思想概述](./000.核心算法思想概述.md)

对 `[3, -2, 5, -1, -4, 2, 6, -3]` 求「和最大的连续子数组」：

1. **分解**：切成左右两半 `[3,-2,5,-1]` 与 `[-4,2,6,-3]`；
2. **解决**：递归各得左半最优 6（`[3,-2,5]`）、右半最优 8（`[2,6]`）；
3. **合并**：最优可能**横跨中线**——从中线向左扫最大后缀（`{-1}=−1、{5,−1}=4、{−2,5,−1}=2、{3,−2,5,−1}=5`，取 **5**），从中线向右扫最大前缀（`{−4}=−4、{−4,2}=−2、{−4,2,6}=4`，取 **4**），拼接得跨线候选 **9**（即子数组 `[3,-2,5,-1,-4,2,6]`）；
4. 三答案取 max：`max(6, 8, 9) = 9`——跨中线解胜出，证明合并步骤不可省；**正确性来自完备三分：任何子数组要么全左、要么全右、要么跨中**；
5. 复杂度 `T(n)=2T(n/2)+O(n)`（跨中线只需两次线性扫描）→ 主定理情形 2 → O(n log n)；而动态规划可到 O(n)，见 [060.动态规划基础](./060.动态规划基础.md)——**同一问题分治与 DP 是不同切割视角**。

# 详解

## 分治三要素与适用判据

1. **可分**：能划成规模更小的同类型子问题（折半、分块、按枢轴分区）；
2. **可独**：子问题相互**独立**（这是与 DP 的分水岭——子问题重叠时盲目分治会指数爆炸，朴素斐波那契 `T(n)=T(n-1)+T(n-2)` 即反例）；
3. **可合**：存在多项式（最好是线性）的合并规则；合并太贵（如某些几何问题合并 O(n²)）会吃掉递归收益。

设计模板：

```text
solve(S):
  if |S| ≤ 阈值: 直接暴力解        # 小问题兜底，也是常数优化点
  划分 S → S1..Sa
  各自递归 solve(Si)
  return merge(结果)
```

## 范例一：归并排序（先分后合，稳定）

::: code-group

```java [Java]
static void mergeSort(int[] a, int[] tmp, int l, int r) {   // [l, r)
    if (r - l <= 1) return;
    int mid = (l + r) >>> 1;
    mergeSort(a, tmp, l, mid);
    mergeSort(a, tmp, mid, r);
    int i = l, j = mid, k = l;
    while (i < mid && j < r) tmp[k++] = a[i] <= a[j] ? a[i++] : a[j++];  // <= 保稳定
    while (i < mid) tmp[k++] = a[i++];
    while (j < r)   tmp[k++] = a[j++];
    System.arraycopy(tmp, l, a, l, r - l);
}
```

```rust [Rust]
fn merge_sort(a: &mut Vec<i32>) {
    if a.len() <= 1 { return; }
    let mid = a.len() / 2;
    let (left, right) = a.split_at_mut(mid);
    merge_sort(left);                       // 递归原地排两半
    merge_sort(right);
    let mut merged: Vec<i32> = Vec::with_capacity(a.len());
    let (mut i, mut j) = (0, 0);
    while i < left.len() && j < right.len() {
        if left[i] <= right[j] { merged.push(left[i]); i += 1; }
        else { merged.push(right[j]); j += 1; }
    }
    merged.extend_from_slice(&left[i..]);
    merged.extend_from_slice(&right[j..]);
    a.copy_from_slice(&merged);
}
```

```typescript [TypeScript]
function mergeSort(a: number[]): number[] {
  if (a.length <= 1) return a;
  const mid = a.length >> 1;
  const left = mergeSort(a.slice(0, mid));
  const right = mergeSort(a.slice(mid));
  const res: number[] = [];
  let i = 0, j = 0;
  while (i < left.length && j < right.length) {
    res.push(left[i] <= right[j] ? left[i++] : right[j++]);   // <= 保稳定
  }
  return res.concat(left.slice(i), right.slice(j));
}
```

```python [Python]
def merge_sort(a: list[int]) -> list[int]:
    if len(a) <= 1:
        return a
    mid = len(a) >> 1
    left, right = merge_sort(a[:mid]), merge_sort(a[mid:])
    res, i, j = [], 0, 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:            # <= 保稳定
            res.append(left[i]); i += 1
        else:
            res.append(right[j]); j += 1
    res.extend(left[i:]); res.extend(right[j:])
    return res
```

## 范例二：逆序对计数（合并时「顺路」统计）

归并合并时，每当右半元素先出，它的贡献 = 左半剩余元素数（都比它大且排在其前）。`T(n)=2T(n/2)+O(n)` = O(n log n)，远胜暴力 O(n²)——「分治顺带完成一次统计」的范式，同款：约瑟夫环、卷绕数、Kendall tau 相关系数。

## 范例三：第 K 小（BFPRT / quickselect）

快排划分后只**递归目标所在一侧**：`T(n) = T(n/2) + O(n)` → O(n)（随机化下期望线性，见 [040.随机化算法](./040.随机化算法.md)）。要点：**分治不一定要递归所有子问题**——「只走一边」把 O(n log n) 降到 O(n)，是 Top-K 与中位数选择的核心；最坏保证 O(n) 的中位数的中位数（BFPRT）存在但常数大，工程用随机版或 `nth_element`（C++）/`partition` 循环（Go `slices`）。

## 主定理对照下的三个分层

| 算法 | 递归式 | 主导方 | 解 |
|------|--------|--------|----|
| 二分查找 | `T(n/2)+O(1)` | 叶子 | Θ(log n) |
| 归并排序 | `2T(n/2)+Θ(n)` | 平手 | Θ(n log n) |
| 快速排序（平均） | `2T(n/2)+Θ(n)` 同构 | 平手 | Θ(n log n) |
| Karatsuba | `3T(n/2)+Θ(n)` | 子问题 | Θ(n^1.585) |
| 最近点对 | `2T(n/2)+Θ(n log n)` | 平手带 log | Θ(n log n) |

## 常见陷阱

- **子问题重叠却当分治做**：朴素递归斐波那契就是教训——重叠即转向记忆化/DP（[060.动态规划基础](./060.动态规划基础.md)）。
- 合并写成 O(n²) 而分解照旧：总代价被合并主导（主定理情形 3），分治白做——先算清合并成本再决定切多细。
- 递归边界与栈深：n=10⁶ 的递归归并栈深 log n 无碍，但「每次只减 1」的伪分治（如 `T(n-1)` 链式）在 JVM 可能 StackOverflow，改迭代或尾递归；工程归并（TimSort）对小 run 用插入排序兜底（见 [110.TimSort](../02.基础算法/110.TimSort与自然归并.md)）。
- 归并稳定性依赖 `<=` 取左：比较写成 `<` 会把相等元素换边，稳定性丢失。
- 分治 vs DP 的选择看**子问题个数与重叠度**：a 个独立子问题、每层合并便宜 → 分治；同一批子问题被反复引用 → DP。

# 总结

- 分治 = 分解 + 递归 + 合并，适用判据三条：可分、子问题独立、合并便宜；代价方程交给主定理查表；
- 三个高频变形值得单独记：只递归一侧（quickselect 线性选第 K 大）、合并顺带统计（逆序对）、分块外排（内存放不下时的多路归并）；
- 分治与 DP 是一体两面：子问题独立用分治，重叠用 DP——最大子数组和两种解法的对照就是这句话的注脚。
