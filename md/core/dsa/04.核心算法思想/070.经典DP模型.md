# 概述

四大经典 DP 套路——背包（容量维度的选与不选）、LCS（两序列对齐）、LIS（偏序链最长）、区间 DP（由内向外合并）——覆盖了笔试面试与工程建模的绝大多数场景；把它们练成「看到问题能归类的条件反射」，比再多刷十道新题更有杠杆。

**本篇收录**：背包、最长公共子序列、最长递增子序列、区间 DP

- 所属章节：[000.核心算法思想概述](./000.核心算法思想概述.md)

- 复杂度总览：

  | 模型 | 状态 | 转移 | 时间 | 空间优化 |
  |------|------|------|------|---------|
  | 0-1 背包 | `f[i][w]` 前 i 件容量 w | 选/不选 | O(nW) | 一维数组**逆序** |
  | 完全背包 | 同上，物品可重复 | 选/不再选 | O(nW) | 一维数组**正序** |
  | LCS | `f[i][j]` 前两串长度 | 匹配/跳一边 | O(nm) | 滚动两行 |
  | LIS（朴素） | `f[i]` 以 i 结尾 | 枚举前身 | O(n²) | — |
  | LIS（二分） |  tails 数组 |  lower_bound 替换 | **O(n log n)** | O(n) |
  | 区间 DP | `f[l][r]` 区间内最优 | 枚举断点/最后操作 | O(n³) | 按长度递推 |

**动画：0-1 背包二维表 → 一维滚动（为什么必须逆序）**
<!-- dsa.assets/dp/knapsack-01.gif -->

物品 `(价值,重量)= (6,3)(4,2)(5,4)`，容量 W=5：

1. 二维视角：`f[i][w]` = 前 i 件、容量 w 的最大价值；每件物品一行，逐格问「装这件吗」；
2. 压成一维：只保留「当前行」，转移 `f[w] = max(f[w], f[w-v]+p)` 读的是**上一行**的 `f[w-v]`；
3. **逆序枚举 w**：`f[w-v]` 尚未被本轮更新 → 拿到的确实是上一行值 → 每件最多选一次；
4. 若正序：`f[w-v]` 已被本物品更新 → 等于允许同一物品重复装入 → 0-1 背包偷偷变成完全背包——**枚举方向就是物品复用次数开关**；
5. 对照实验：完全背包反而**要正序**——「故意让当前行覆盖上一行」表示无限取。

**动画：LIS 的 tails 数组演化**
<!-- dsa.assets/dp/lis-tails.gif -->

序列 `[2, 1, 5, 3, 7, 4]`，`tails[k]` = 「长度为 k+1 的递增子序列中，结尾最小的那个」：

1. 2 → tails `[2]`；1 比 2 小，**替换**成 `[1]`（更小的尾巴更有潜力）；
2. 5 比 1 大 → 追加 `[1,5]`；3 介于之间 → 替换 5 得 `[1,3]`；
3. 7 追加 `[1,3,7]`；4 替换 7 → `[1,3,4]`；
4. **tails 长度 3 即答案**（注意 tails 本身不一定是某个真实子序列，只是「潜力表」）；
5. 每次操作 = 在有序 tails 上 lower_bound，O(log n) → 总 O(n log n)。

# 详解

## 一、背包家族

::: code-group

```java [Java]
// 0-1 背包：一维逆序；返回最大价值，方案可另存 parent 回溯
int knapsack01(int[] w, int[] p, int W) {
    int[] f = new int[W + 1];
    for (int i = 0; i < w.length; i++) {
        for (int c = W; c >= w[i]; c--) {            // 逆序 = 每件至多选一次
            f[c] = Math.max(f[c], f[c - w[i]] + p[i]);
        }
    }
    return f[W];
}

// 完全背包：一维正序
int knapsackFull(int[] w, int[] p, int W) {
    int[] f = new int[W + 1];
    for (int i = 0; i < w.length; i++) {
        for (int c = w[i]; c <= W; c++) {            // 正序 = 可重复选
            f[c] = Math.max(f[c], f[c - w[i]] + p[i]);
        }
    }
    return f[W];
}
// 变形速记：恰好装满 → f[0]=0 其余 -∞；求方案数 → max 换 +=；
// 多重背包 → 二进制拆分件数后跑 0-1；二维费用 → 两维都逆序
```

```python [Python]
def knapsack_01(w: list[int], p: list[int], W: int) -> int:
    f = [0] * (W + 1)
    for wi, pi in zip(w, p):
        for c in range(W, wi - 1, -1):    # 逆序 = 每件至多一次
            f[c] = max(f[c], f[c - wi] + pi)
    return f[W]

def knapsack_full(w: list[int], p: list[int], W: int) -> int:
    f = [0] * (W + 1)
    for wi, pi in zip(w, p):
        for c in range(wi, W + 1):        # 正序 = 可重复
            f[c] = max(f[c], f[c - wi] + pi)
    return f[W]
```

:::

背包是「伪多项式」的代表：O(nW) 里的 W 是数值不是长度，输入按二进制编码时它是指数——这正是 [030.NP完全与近似算法](./030.NP完全与近似算法.md) 中「背包 NP 难却有 FPTAS」的由来。

## 二、最长公共子序列（LCS）

两字符串对齐问题的原型（编辑距离、diff、生物序列比对同族）：

::: code-group

```java [Java]
int lcs(String a, String b) {
    int n = a.length(), m = b.length();
    int[][] f = new int[n + 1][m + 1];
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            f[i][j] = a.charAt(i - 1) == b.charAt(j - 1)
                    ? f[i - 1][j - 1] + 1                       // 尾字符相同：对角+1
                    : Math.max(f[i - 1][j], f[i][j - 1]);       // 不同：删一边
        }
    }
    return f[n][m];   // 还原公共串：从 (n,m) 沿「对角来源」回溯
}
```

```rust [Rust]
pub fn lcs(a: &str, b: &str) -> usize {
    let (aa, bb) = (a.as_bytes(), b.as_bytes());
    let (n, m) = (aa.len(), bb.len());
    let mut prev = vec![0usize; m + 1];                 // 滚动两行
    let mut cur = vec![0usize; m + 1];
    for i in 1..=n {
        for j in 1..=m {
            cur[j] = if aa[i - 1] == bb[j - 1] { prev[j - 1] + 1 }
                     else { cur[j - 1].max(prev[j]) };
        }
        std::mem::swap(&mut prev, &mut cur);
        cur.fill(0);
    }
    prev[m]
}
```

```typescript [TypeScript]
function lcs(a: string, b: string): number {
  const n = a.length, m = b.length;
  const f: number[][] = Array.from({ length: n + 1 }, () => new Array(m + 1).fill(0));
  for (let i = 1; i <= n; i++) {
    for (let j = 1; j <= m; j++) {
      f[i][j] = a[i - 1] === b[j - 1]
        ? f[i - 1][j - 1] + 1
        : Math.max(f[i - 1][j], f[i][j - 1]);
    }
  }
  return f[n][m];
}
```

```python [Python]
def lcs(a: str, b: str) -> int:
    prev = [0] * (len(b) + 1)              # 滚动行
    for ca in a:
        cur = [0]
        for j, cb in enumerate(b, 1):
            cur.append(prev[j - 1] + 1 if ca == cb else max(cur[j], prev[j]))
        prev = cur
    return prev[-1]
```

## 三、最长递增子序列（LIS）

::: code-group

```java [Java]
int lis(int[] a) {                       // O(n log n)：tails[k]=长度k+1的递增子序列最小尾
    int[] tails = new int[a.length];
    int size = 0;
    for (int x : a) {
        int l = 0, r = size;             // lower_bound 第一个 >= x
        while (l < r) {
            int mid = (l + r) >>> 1;
            if (tails[mid] < x) l = mid + 1; else r = mid;
        }
        tails[l] = x;
        if (l == size) size++;
    }
    return size;
}
```

```python [Python]
import bisect

def lis(a: list[int]) -> int:
    tails: list[int] = []
    for x in a:
        i = bisect.bisect_left(tails, x)   # 第一个 >= x 的位置
        if i == len(tails):
            tails.append(x)                # 能延长
        else:
            tails[i] = x                   # 换更小的尾巴
    return len(tails)
```

```rust [Rust]
pub fn lis(a: &[i32]) -> usize {
    let mut tails: Vec<i32> = Vec::new();
    for &x in a {
        let i = tails.partition_point(|&t| t < x);   // 第一个 >= x
        if i == tails.len() { tails.push(x); }
        else { tails[i] = x; }
    }
    tails.len()
}
```

```typescript [TypeScript]
function lis(a: number[]): number {
  const tails: number[] = [];
  for (const x of a) {
    let l = 0, r = tails.length;              // lower_bound
    while (l < r) {
      const mid = (l + r) >> 1;
      if (tails[mid] < x) l = mid + 1; else r = mid;
    }
    if (l === tails.length) tails.push(x);
    else tails[l] = x;
  }
  return tails.length;
}
```

:::

O(n²) 版 `f[i] = max(f[j]+1 | j<i, a[j]<a[i])` 是「以 i 结尾」状态定义的最佳教具；二分版记住口诀：**tails 有序、延长 append、否则 lower_bound 替换**。严格递增用 `bisect_left`，非递减改 `bisect_right`。

## 四、区间 DP：合并类问题的统一框架

状态 `f[l][r]` = 区间内做完某事的最优值，转移枚举**断点**或**最后操作位置**。代表：矩阵链乘、戳气球（LeetCode 312，「最后戳哪个」倒推）、石子合并、最优 BST。

::: code-group

```java [Java]
// 戳气球：添加 1 于两端，p[i]*p[k]*p[j] 为「最后戳 k」的得分
int maxCoins(int[] nums) {
    int n = nums.length + 2;
    int[] p = new int[n];
    p[0] = p[n - 1] = 1;
    System.arraycopy(nums, 0, p, 1, nums.length);
    int[][] f = new int[n][n];
    for (int len = 2; len < n; len++) {              // 按区间长度递推
        for (int i = 0; i + len < n; i++) {
            int j = i + len;
            for (int k = i + 1; k < j; k++) {        // k = 区间内最后被戳
                f[i][j] = Math.max(f[i][j],
                        f[i][k] + f[k][j] + p[i] * p[k] * p[j]);
            }
        }
    }
    return f[0][n - 1];
}
```

```python [Python]
def max_coins(nums: list[int]) -> int:
    p = [1] + nums + [1]
    n = len(p)
    f = [[0] * n for _ in range(n)]
    for length in range(2, n):                   # 区间长度从小到大
        for i in range(n - length):
            j = i + length
            for k in range(i + 1, j):            # 最后戳 k
                f[i][j] = max(f[i][j], f[i][k] + f[k][j] + p[i] * p[k] * p[j])
    return f[0][n - 1]
```

```typescript [TypeScript]
function maxCoins(nums: number[]): number {
  const p = [1, ...nums, 1];
  const n = p.length;
  const f: number[][] = Array.from({ length: n }, () => new Array(n).fill(0));
  for (let len = 2; len < n; len++) {
    for (let i = 0; i + len < n; i++) {
      const j = i + len;
      for (let k = i + 1; k < j; k++) {
        f[i][j] = Math.max(f[i][j], f[i][k] + f[k][j] + p[i] * p[k] * p[j]);
      }
    }
  }
  return f[0][n - 1];
}
```

:::

区间 DP 两条铁律：**按长度从小到大填表**（保证子区间先算）、**倒推「最后一步」**（戳气球想「最后戳谁」而非「先戳谁」——先戳会改变邻居，最后戳则两侧独立，子问题才干净）。

## 常见陷阱

- 一维滚动方向错（0-1/完全互换）是背包第一大 bug；拿不准就退回二维表验证小样例。
- LCS 与「最长公共**子串**」别混：子串状态是「以 i,j 结尾且必须相邻」，不匹配清零而非取 max。
- LIS 二分版 tails 不是真实子序列：直接输出 tails 当答案是错的；要方案需用「前驱记录 + 二分位置」重建。
- 区间 DP 枚举顺序写成按 i 递减/任意序，子区间未算先被引用；以长度为主维度最稳。
- 求方案数的背包与求最值的背包初值不同：`f[0]=1`（空方案）起步，且转移是加法——两类题混做会全表错。

# 总结

- 四大模型各一句心法：背包看「容量维 + 枚举方向」，LCS 看「两序列对齐的三来源转移」，LIS 看「以 i 结尾 + tails 二分」，区间 DP 看「按长度递推 + 倒推最后一步」；
- 它们是 [060.动态规划基础](./060.动态规划基础.md) 四步法的标准答案库——新问题先归类，归不进再自造状态；
- 变形（恰好装满、方案数、多重、树形/图上加容量维）都是在骨架上换转移或初值，背骨架不背代码。
