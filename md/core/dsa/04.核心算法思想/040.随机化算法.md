# 概述

随机化算法在决策时引入真随机数：不靠「输入分布均匀」的侥幸，而是**自己掷骰子**把坏输入的概率与算法绑定。两大流派——**Las Vegas**：结果永远正确，运行时间是随机变量（期望有限）；**Monte Carlo**：时间固定，结果以高概率正确。随机性还常让实现陡然变简单（跳表 vs 红黑树）。

- 时间复杂度（代表）：
  - 随机化快排：任意输入下**期望 O(n log n)**，最坏 O(n²) 概率被压到极低；
  - **Reservoir 水塘采样**：O(n) 时间、O(k) 空间取 k 个样本；
  - Miller-Rabin 素性测试：O(k·log³n)，错判概率 ≤ 4⁻ᵏ（Monte Carlo 一侧）。
- 空间复杂度：与原算法同级；随机性通常用「期望/概率界」换「确定性最坏界」。
- 应用场景：
  - **随机化快排**是各标准库排序内核的一部分（C qsort 历史、Java `Arrays.sort` 对偶枢轴策略）；
  - **跳表**：Redis 有序集合、LevelDB/RocksDB MemTable（见 [040.跳表](../01.基础数据结构/040.跳表.md)）；
  - **一致性哈希/布隆过滤器**：分布式分流与缓存预判（见 [070.一致性哈希](../10.应用与专题/070.一致性哈希.md)、[060.布隆过滤器](../10.应用与专题/060.布隆过滤器.md)）；
  - **哈希函数随机种子**：防哈希碰撞 DoS（见 [070.哈希函数设计](../01.基础数据结构/070.哈希函数设计.md)）；
  - 质数判定与密钥生成（[110.素性测试](../06.字符串与数论/110.素性测试.md)）、蒙特卡洛积分与渲染、模拟退火（[030.NP完全与近似算法](./030.NP完全与近似算法.md) 的启发式退路）、ML 权重初始化与小批量采样。

- 所属章节：[000.核心算法思想概述](./000.核心算法思想概述.md)

<!-- dsa.assets/randomized/rquicksort-pivot.gif -->

1. 对手构造数组 `[1,2,3,…,n]`（或任何让固定取首/取尾枢轴的算法退化的序列）——确定性快排每次选中最小/最大元，划分只剩一边，代价 `T(n)=T(n-1)+O(n)` = O(n²)；
2. 随机化快排先**随机打乱**（或随机选枢轴换到首位）：枢轴落在「中间 50% 排名」的概率是 1/2；
3. 每次落在中间区间就至少把规模砍半；落在外的「霉运」序列期望次数为几何分布，总期望 `O(n log n)`；
4. 关键视角转换：确定性算法的最坏界要对**所有输入**成立，随机化算法只需对**所有「输入 × 骰子」组合**中的少数派坏——**把最坏情况的担子从输入转移到硬币**；
5. Monte Carlo 分支示意：掷 k 次骰子答案多数表决，错误概率随 k 指数衰减（`≤ 2⁻ᵏ`），时间恒定——与 Las Vegas「答案必对、时间随机」形成镜像。

# 详解

## 两大流派与一个「打乱」原语

| 流派 | 正确性 | 运行时间 | 代表 |
|------|--------|---------|------|
| Las Vegas | **100% 正确** | 随机变量，看期望 | 随机化快排、随机抽样本、跳表查找 |
| Monte Carlo | 概率 1-δ（可调 δ） | 固定多项式 | Miller-Rabin、哈希估计基数（HyperLogLog）、随机割 |

Fisher-Yates 洗牌是随机化的地基（每个位置等概率取未用元素，n! 种排列各 1/n!）：

::: code-group

```java [Java]
void shuffle(int[] a, java.util.Random rnd) {
    for (int i = a.length - 1; i > 0; i--) {
        int j = rnd.nextInt(i + 1);        // [0, i] 均匀
        int t = a[i]; a[i] = a[j]; a[j] = t;
    }
}
```

```rust [Rust]
// 工程直接用 rand::seq::SliceRandom::shuffle；下面是手动实现
fn shuffle<T>(a: &mut [T], mut rnd: impl FnMut(usize) -> usize) {
    for i in (1..a.len()).rev() {
        let j = rnd(i + 1);                // [0, i] 均匀
        a.swap(i, j);
    }
}
```

```typescript [TypeScript]
function shuffle<T>(a: T[], rand: (n: number) => number): void {
  for (let i = a.length - 1; i > 0; i--) {
    const j = Math.floor(rand(i + 1));     // [0, i] 均匀
    [a[i], a[j]] = [a[j], a[i]];
  }
}
```

```python [Python]
import random

def shuffle(a: list) -> None:
    random.shuffle(a)   # CPython 即 Fisher-Yates；面试手写见下
```

## 随机化快排（Las Vegas 代表）

::: code-group

```java [Java]
// 枢轴随机：先与首位交换再划分——任意输入期望 O(n log n)
public static void quickSort(int[] a, int l, int r, java.util.Random rnd) {
    if (l >= r) return;
    int p = l + rnd.nextInt(r - l + 1);
    int t = a[l]; a[l] = a[p]; a[p] = t;
    int pivot = a[l], i = l, j = r + 1;
    for (;;) {
        do i++; while (i < r && a[i] < pivot);
        do j--; while (a[j] > pivot);
        if (i >= j) break;
        t = a[i]; a[i] = a[j]; a[j] = t;
    }
    t = a[l]; a[l] = a[j]; a[j] = t;
    quickSort(a, l, j - 1, rnd);
    quickSort(a, j + 1, r, rnd);
}
```

```python [Python]
import random

def quick_sort(a: list[int]) -> list[int]:
    """Las Vegas：结果必对，比较次数是随机变量，期望 O(n log n)"""
    if len(a) <= 1:
        return a
    pivot = random.choice(a)                       # 随机枢轴
    lo = [x for x in a if x < pivot]
    eq = [x for x in a if x == pivot]
    hi = [x for x in a if x > pivot]
    return quick_sort(lo) + eq + quick_sort(hi)
```

```rust [Rust]
pub fn quick_sort(a: &mut [i32], rnd: &mut impl FnMut(usize) -> usize) {
    let n = a.len();
    if n <= 1 { return; }
    let p = rnd(n);                                // [0, n) 随机枢轴下标
    a.swap(0, p);
    let pivot = a[0];
    // 三路划分（< == >），等值段天然免疫「全部相同元素」退化
    let (mut l, mut m, mut g) = (0usize, 0usize, n);
    while m < g {
        if a[m] < pivot { a.swap(l, m); l += 1; m += 1; }
        else if a[m] > pivot { g -= 1; a.swap(m, g); }
        else { m += 1; }
    }
    quick_sort(&mut a[..l], rnd);
    quick_sort(&mut a[g..], rnd);
}
```

```typescript [TypeScript]
function quickSort(a: number[], rand: (n: number) => number): number[] {
  if (a.length <= 1) return a;
  const pivot = a[Math.floor(rand(a.length))];     // 随机枢轴
  const lo: number[] = [], eq: number[] = [], hi: number[] = [];
  for (const x of a) {
    if (x < pivot) lo.push(x);
    else if (x === pivot) eq.push(x);
    else hi.push(x);
  }
  return [...quickSort(lo, rand), ...eq, ...quickSort(hi, rand)];
}
```

期望分析一句话：随机枢轴「平衡划分」（子问题规模落在 [n/3, 2n/3]）的概率 ≥ 1/3，把连续霉运打包成几何分布，期望层数 O(log n) → 期望总代价 O(n log n)；最坏 O(n²) 依然存在但概率随 n 指数级小——**期望界对任意固定输入成立**，这是它强于「假设输入随机」的确定性分析之处。

## Monte Carlo 侧：重复换置信度

单次错误概率 ≤ 1/2 的判定/估计，独立重复 k 次取多数，错误率 ≤ 2⁻ᵏ。Miller-Rabin（k=40 已足够密码学工程使用）、HyperLogLog 基数估计、随机数生成器检验都属此类。与 Las Vegas 的互转技巧：Monte Carlo 若错误可高效验证（如给出一组合并验），升级成 Las Vegas（「拉斯维加斯化」）。

## 伪随机与可复现工程提醒

`Math.random`/`rand()` 多为 PRNG（线性同余/MT/Xoshiro），**不是**真随机：密码学场景必须用 CSPRNG（`java.security.SecureRandom`、Rust `rand::rngs::OsRng`、Node `crypto.randomBytes`、Python `secrets`）；可复现实验（调试、训练）固定随机种子；模拟并发/分布式时 PRNG 周期与相关性可能制造假象。

## 常见陷阱

- 随机化快排最坏 O(n²) **并未消失**，只是从「对手可构造」变成「小概率自爆」——实时/安全场景可配 IntroSort（深度超限转堆排，彻底消除最坏），见 [120.排序算法综合对比](../02.基础算法/120.排序算法综合对比.md)。
- 洗牌偏差：`j = rand() % (i+1)` 用有偏取模或在 `rnd.nextInt(i)`（区间开闭差一）上写错，产生非均匀排列——Fisher-Yates 必须 **i 从 n-1 递减、j ∈ [0, i]**。
- 拿伪随机当密码随机：种子可猜 ⇒ 攻击者能重现你的「随机」枢轴/盐值/密钥。
- Monte Carlo 的「错误概率」是**算法内在概率**，重复 k 次要独立；共享随机源的重复不降噪。
- 期望 O(1) 的哈希/跳表在极端小概率下长链出现是常态，告警阈值别设得过敏感。

# 总结

- 随机化的本质是「把最坏情况的担子从输入转移到骰子」：Las Vegas 保正确赌时间，Monte Carlo 保时间赌正确；
- 一枚 Fisher-Yates 洗牌 + 随机枢轴换来任意输入的期望 O(n log n)，掷骰子的跳表用半页指针替代整套旋转规则——随机让简单成为可能；
- 工程红线：密码学要 CSPRNG、调试要固定种子、实时系统给随机算法配确定兜底（IntroSort/超时转策略）。
