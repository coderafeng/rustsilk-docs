# 概述

欧拉函数 φ(n)：`1..n` 中与 n **互素**的整数个数（φ(1)=1）。三条计算主线：积性公式 `φ(n) = n·∏(1 − 1/p)`（p 跑遍 n 的素因子）、与 [060.素数筛法](./060.素数筛法.md) 联动的线性筛递推、单点 O(√n) 分解版。**欧拉定理** `a^φ(m) ≡ 1 (mod m)`（gcd(a,m)=1）是费马小定理的母公司——指数的「汇率换算器」，RSA 正确性证明的核心引理。

- 所属章节：[000.字符串与数论概述](./000.字符串与数论概述.md)

- 复杂度：单点公式法 O(√n)（含分解）；线性筛批量 O(n)；判定/性质查询皆近 O(1)（查表后）。
- 关键性质：p 素数 ⇔ φ(p)=p−1；φ(pᵏ)=pᵏ−pᵏ⁻¹；gcd(a,m)=1 时 a 的乘法阶 ord(a) | φ(m)；`Σ_{d|n} φ(d) = n`（按最大公约数分类数数）。
- 应用场景：RSA 中 λ(n)=lcm(p−1,q−1) / φ(n)=(p−1)(q−1) 定私钥指数空间（[09.密码学算法/020.RSA](../09.密码学算法/020.RSA非对称加密.md)）、既约剩余群 `(Z/mZ)*` 的阶计数（Diffie-Hellman 子群选取）、竞赛数论求和（Σgcd、互素计数）、循环长度分析（1/7 的六位循环节 = ord_7(10) | φ(7)）、哈希/同余发生器的满周期条件。

# 详解

## 单点 φ（公式法）

::: code-group

```java [Java]
static long phi(long n) {                       // O(√n)：边试除边乘 (1-1/p)
    if (n == 0) return 0;
    long result = n;
    for (long p = 2; p * p <= n; p++) {
        if (n % p == 0) {                       // p 是素因子
            while (n % p == 0) n /= p;          // 除干净，防重复计入
            result -= result / p;               // result *= (1 - 1/p)，整型写法
        }
    }
    if (n > 1) result -= result / n;            // 剩余的大素因子
    return result;
}
```

```rust [Rust]
pub fn phi(mut n: u64) -> u64 {
    if n == 0 { return 0; }
    let mut result = n;
    let mut p = 2u64;
    while p * p <= n {
        if n % p == 0 {
            while n % p == 0 { n /= p; }
            result -= result / p;
        }
        p += 1;
    }
    if n > 1 { result -= result / n; }
    result
}
```

```typescript [TypeScript]
function phi(n: number): number {
  if (n === 0) return 0;
  let result = n;
  for (let p = 2; p * p <= n; p++) {
    if (n % p === 0) {
      while (n % p === 0) n /= p;
      result -= Math.floor(result / p);       // 整型化：先除后减防浮点
    }
  }
  if (n > 1) result -= Math.floor(result / n);
  return result;
}
```

```python [Python]
def phi(n):
    """O(√n) 单点欧拉函数"""
    if n == 0:
        return 0
    result = n
    p = 2
    while p * p <= n:
        if n % p == 0:
            while n % p == 0:
                n //= p
            result -= result // p
        p += 1
    if n > 1:
        result -= result // n
    return result
```

## 批量 φ（线性筛搭车）

::: code-group

```java [Java]
// 与 060 线性筛同步递推：i % p == 0 ⇒ φ(i·p) = φ(i)·p；否则 φ(i·p) = φ(i)·(p-1)
static long[] phiSieve(int n) {
    long[] phi = new long[n + 1];
    int[] lp = new int[n + 1];
    java.util.List<Integer> primes = new ArrayList<>();
    phi[1] = 1;
    for (int i = 2; i <= n; i++) {
        if (lp[i] == 0) { lp[i] = i; phi[i] = i - 1; primes.add(i); }
        for (int p : primes) {
            if (p > lp[i] || (long) i * p > n) break;
            lp[i * p] = p;
            phi[i * p] = (i % p == 0) ? phi[i] * p : phi[i] * (p - 1);
        }
    }
    return phi;
}
```

```python [Python]
def phi_sieve(n):
    """线性筛批量 φ；返回 phi[0..n]"""
    phi = [0] * (n + 1)
    lp = [0] * (n + 1)
    primes = []
    phi[1] = 1
    for i in range(2, n + 1):
        if lp[i] == 0:
            lp[i] = i
            phi[i] = i - 1
            primes.append(i)
        for p in primes:
            if p > lp[i] or i * p > n:
                break
            lp[i * p] = p
            # 积性递推：p | i 时 φ(i·p)=φ(i)·p（新增素因子不新增「互素比例」）
            phi[i * p] = phi[i] * p if i % p == 0 else phi[i] * (p - 1)
    return phi
```

```rust [Rust]
pub fn phi_sieve(n: usize) -> Vec<u64> {
    let mut phi = vec![0u64; n + 1];
    let mut lp = vec![0usize; n + 1];
    let mut primes: Vec<usize> = Vec::new();
    if n >= 1 { phi[1] = 1; }
    for i in 2..=n {
        if lp[i] == 0 { lp[i] = i; phi[i] = (i - 1) as u64; primes.push(i); }
        for &p in &primes {
            if p > lp[i] || i * p > n { break; }
            lp[i * p] = p;
            phi[i * p] = if i % p == 0 { phi[i] * p as u64 }
                         else { phi[i] * (p as u64 - 1) };
        }
    }
    phi
}
```

```typescript [TypeScript]
function phiSieve(n: number): number[] {
  const phi = new Array<number>(n + 1).fill(0);
  const lp = new Array<number>(n + 1).fill(0);
  const primes: number[] = [];

  for (let i = 2; i <= n; i++) {

    for (const p of primes) {
      if (p > lp[i] || i * p > n) break;
      lp[i * p] = p;
      phi[i * p] = i % p === 0 ? phi[i] * p : phi[i] * (p - 1);
    }
  }
  return phi;
}
```

## 欧拉定理与家族

- **欧拉定理**：`gcd(a,m)=1 ⇒ a^φ(m) ≡ 1 (mod m)`。证明骨架：既约剩余群 `(Z/mZ)*` 是 φ(m) 阶有限群，a 的乘法阶整除群阶（拉格朗日）⇒ a^φ(m)=1。
- **费马小定理** = m 为素数的特例（φ(p)=p−1）：`a^p ≡ a (mod p)`（对全体 a 成立，无需互素前提的第二形态）。
- **卡迈克尔函数 λ(n)**：使 `a^λ ≡ 1` 对**一切**互素 a 成立的最小指数——比 φ 更紧（λ(8)=2 < φ(8)=4），RSA 的真实私钥空间是 lcm(p−1,q−1)。
- **降幂实战**：求 `a^E mod m` 且 E 巨大（塔式幂/阶乘指数）：`a^E ≡ a^(E mod φ(m) + φ(m)) (mod m)`——加 φ(m) 的扩展式兼容 gcd(a,m)≠1（推广欧拉降幂），竞赛题「a^(b^) mod m」标准解。
- **原根**：`(Z/pZ)*` 是循环群，存在 g 使 ord(g)=p−1——离散对数/DH 的生成元；`a 是模 p 原根 ⇔ 对 φ(p−1) 每个素因子 q：a^((p−1)/q) ≢ 1`。

## 常见陷阱

- `result -= result / p` 是整数域里 `result·(1−1/p)` 的正确写法（p | result 恒成立吗？——在按素因子升序处理时 result 保留了必要因子，可以证明整除）；写 `result * (p-1) / p` 顺序反了可能先溢。
- 忘了剩余大素因子：循环后 `n > 1` 必须补一刀（`result -= result/n`）——漏掉则 φ 偏大（例 φ(6) 算成 6·1/2=3 ≠ 2）。
- φ(1)=1、φ(0) 无定义：边界两行特判，筛法版 phi[1]=1 别忘了初始化。
- 用欧拉定理前**不查 gcd(a,m)=1**：`2^φ(6) mod 6 ≠ 1`——前提破功是数论第一大假证明。
- 把 φ(n) 当「素数个数 π(n)」：两者增长截然不同（φ≈6n/π² 平均，π≈n/ln n）——缩写歧义在注释里写全称。
- 批量筛里 `i*p` 越界：先判 `i*p > n` 再写表；int 乘积先转 long/usize。

# 总结

- φ 的一面镜子三种照法：容斥公式 `n·∏(1−1/p)`、线性筛积性递推（p|i 时 ×p、否则 ×(p−1)）、[080.EXGCD](./080.扩展欧几里得与同余方程.md) 式的群论视角（既约剩余群的阶）；
- 欧拉定理的价值是**给指数降维**：a^φ(m)≡1 让天文数字的幂缩到 φ(m) 以内——费马、卡迈克尔、降幂公式是同一条定理的三档火力；
- RSA 的生死状写在 φ 上：pq → φ=(p−1)(q−1) → ed ≡ 1 (mod λ)——分解难所以 φ 难算，整个公钥密码悬在这一点上。
