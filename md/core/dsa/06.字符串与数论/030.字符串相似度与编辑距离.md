# 概述

编辑距离家族：用「把 A 变成 B 最少需要几次编辑」度量字符串差异——这是 [04.核心算法思想/060.动态规划基础](../04.核心算法思想/060.动态规划基础.md) 的二维 DP 招牌应用。四兄弟共享同一张 DP 表，只差**代价函数与初始化**：Levenshtein 求最小距离；Needleman-Wunsch 做**全局比对**（生物序列首尾对齐）；Smith-Waterman 做**局部比对**（找高相似片段）；Gotoh 版补上空位**仿射惩罚**（开 gap 贵、延长 gap 便宜，贴合生物真实）。

**本篇收录**：Levenshtein、Needleman-Wunsch、Smith-Waterman、Smith-Waterman-Gotoh

- 所属章节：[000.字符串与数论概述](./000.字符串与数论概述.md)

- 复杂度：全部时间 O(n·m)、空间可压至 O(min(n,m))（滚动数组）；回溯最优路径需保留方向表或 Hirschberg 分治。
- 关系图：Levenshtein = NW 的特例（match=0/indel=1 时「最大得分」⇔「最小编辑」）；SW = NW 把「负分截断为 0」；SWG = SW/NW 把 indel 换成 `open + extend·(k-1)`。
- 应用场景：拼写纠错与输入法候选（编辑距离≤2 词典查询）、DNA/蛋白质序列比对（BLAST 的思想内核）、Git 差异与 diff 工具（Myers 算法=编辑距离变体）、语音识别 N-best 对齐、OCR 后处理、实体对齐/查重（与 [040.字符串近似匹配与语音相似度](./040.字符串近似匹配与语音相似度.md) 互补）、编译器报错行对齐。

**动画：Levenshtein——DP 表从左上角滚到右下角**
<!-- dsa.assets/edit-distance/levenshtein.gif -->

A=`kitten`，B=`sitting`（7×8 表，`d[i][j]`=A 前 i 个变 B 前 j 个的最少步数）：

1. 边界：`d[i][0]=i`（全删）、`d[0][j]=j`（全插）——「空串互变只能纯编辑」；
2. 每格取三邻居 **+对应代价** 的 min：左上 `d[i-1][j-1] + (A[i]≠B[j] ? 1 : 0)`（替换/匹配）、上 `d[i-1][j]+1`（删 A 字符）、左 `d[i][j-1]+1`（插 B 字符）；
3. 例算 `d[1][1]`：k vs s 不等 → min(0+1, 1+1, 1+1)=1；一路填到 `d[6][7]=3`——k→s、e→i、补 g 共 3 步；
4. 从右下角**回溯**（每步选来源邻居）即得具体编辑脚本；
5. 观察：表呈「对角线谷地」，相似串谷深、无关串整体爬升。

**动画：NW 全局 vs SW 局部——同源两张表**
<!-- dsa.assets/edit-distance/global-local.gif -->

打分：match +2，mismatch −1，gap −2：

1. **NW**：边界按 gap 累计（第 0 行/列 = −2·k），右下角即答案——强制两端对齐，序列整体相似时得分高；
2. **SW**：边界全 0，每格再取 `max(0, …)`——**负分就地清零**，表格现「岛屿」；全表最大值处回溯到 0，就是最佳**局部**比对片段；
3. 同一段 `AGGT vs GG`：NW 被两端大 gap 拖负，SW 亮出中间的 `GG` 高分岛——「全局看像不像」与「哪段最像」是两个问题；
4. Gotoh：把「跳一格 −2」改「开 gap −5、之后每延一格 −1」——岛形更肥、更符合突变学。

# 详解

## Levenshtein（最小编辑距离）

::: code-group

```java [Java]
int levenshtein(String a, String b) {
    int n = a.length(), m = b.length();
    int[] prev = new int[m + 1], cur = new int[m + 1];   // 滚动两行
    for (int j = 0; j <= m; j++) prev[j] = j;
    for (int i = 1; i <= n; i++) {
        cur[0] = i;
        for (int j = 1; j <= m; j++) {
            int cost = a.charAt(i - 1) == b.charAt(j - 1) ? 0 : 1;
            cur[j] = Math.min(Math.min(prev[j] + 1,        // 删
                                        cur[j - 1] + 1),   // 插
                               prev[j - 1] + cost);        // 替/匹配
        }
        int[] t = prev; prev = cur; cur = t;
    }
    return prev[m];
}
```

```python [Python]
def levenshtein(a, b):
    if len(a) < len(b):
        a, b = b, a                       # 让内环短些，滚动一维
    prev = list(range(len(b) + 1))
    for i, ca in enumerate(a, 1):
        cur = [i]
        for j, cb in enumerate(b, 1):
            cost = 0 if ca == cb else 1
            cur.append(min(prev[j] + 1, cur[j - 1] + 1, prev[j - 1] + cost))
        prev = cur
    return prev[-1]
```

```rust [Rust]
pub fn levenshtein(a: &str, b: &str) -> usize {
    let (va, vb): (Vec<char>, Vec<char>) = (a.chars().collect(), b.chars().collect());
    let (n, m) = (va.len(), vb.len());
    let mut prev: Vec<usize> = (0..=m).collect();
    let mut cur = vec![0usize; m + 1];
    for i in 1..=n {
        cur[0] = i;
        for j in 1..=m {
            let cost = if va[i - 1] == vb[j - 1] { 0 } else { 1 };
            cur[j] = (prev[j] + 1).min(cur[j - 1] + 1).min(prev[j - 1] + cost);
        }
        std::mem::swap(&mut prev, &mut cur);
    }
    prev[m]
}
```

```typescript [TypeScript]
  }
```

## Needleman-Wunsch（全局比对）与 Smith-Waterman（局部比对）

同一家族只差三行：边界、是否允许 0、答案位置。合并演示：

```java [Java]
// mode: GLOBAL=Needleman-Wunsch / LOCAL=Smith-Waterman
// 打分函数 score(a,b)：match 正、mismatch 负、gap = gapPenalty
int[][] alignDP(String a, String b, int match, int mismatch,
                int gapPenalty, boolean local) {
    int n = a.length(), m = b.length();
    int[][] d = new int[n + 1][m + 1];
    for (int i = 1; i <= n; i++)
        if (!local) d[i][0] = -gapPenalty * i;         // 全局：首列累计 gap
    for (int j = 1; j <= m; j++)
        if (!local) d[0][j] = -gapPenalty * j;         // 全局：首行累计 gap
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++) {
            int s = a.charAt(i - 1) == b.charAt(j - 1) ? match : mismatch;
            int best = Math.max(Math.max(d[i - 1][j - 1] + s, d[i - 1][j] - gapPenalty),
                                 d[i][j - 1] - gapPenalty);
            d[i][j] = local ? Math.max(0, best) : best; // 局部：负分清零
        }
    return d;
}
// 全局答案 = d[n][m]；局部答案 = 全表最大值及其回溯（回溯到 0 止）
```

```python [Python]
def align_dp(a, b, match=2, mismatch=-1, gap=-2, local=False):
    """返回 (dp 表, 答案值, 答案坐标)；local=True 即 Smith-Waterman"""
    n, m = len(a), len(b)
    d = [[0] * (m + 1) for _ in range(n + 1)]
    if not local:
        for i in range(1, n + 1): d[i][0] = gap * i
        for j in range(1, m + 1): d[0][j] = gap * j
    best, at = (0, None), None
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            s = match if a[i - 1] == b[j - 1] else mismatch
            val = max(d[i - 1][j - 1] + s, d[i - 1][j] + gap, d[i][j - 1] + gap)
            if local:
                val = max(0, val)
            d[i][j] = val
            if local and val > best:
                best, at = val, (i, j)
    return (d, best, at) if local else (d, d[n][m], (n, m))

def traceback(d, a, b, i, j, match=2, mismatch=-1, gap=-2, local=False):
    """从答案坐标回溯出比对串（局部遇到 0 即停）"""
    sa, sb = [], []
    while i > 0 and j > 0:
        cur = d[i][j]
        if local and cur == 0:
            break
        s = match if a[i - 1] == b[j - 1] else mismatch
        if cur == d[i - 1][j - 1] + s:
            sa.append(a[i - 1]); sb.append(b[j - 1]); i -= 1; j -= 1
        elif cur == d[i - 1][j] + gap:
            sa.append(a[i - 1]); sb.append("-"); i -= 1
        else:
            sa.append("-"); sb.append(b[j - 1]); j -= 1
    return "".join(reversed(sa)), "".join(reversed(sb))
```

```rust [Rust]
    let mut d = vec![vec![0i32; m + 1]; n + 1];

                .max(d[i - 1][j] + gap)
                .max(d[i][j - 1] + gap);
            d[i][j] = if local { val.max(0) } else { val };
        }
    }
    d
}
```

## Smith-Waterman-Gotoh：仿射空位

生物上「一次大片段插入」比「连续单点插入」概率高得多 → gap 代价 `W(k) = ρ + (k-1)·ε`（ρ 开闸费、ε 延长费）。DP 从 1 表变 **3 表**：M（末端对齐）、Ix（A 侧连续 gap）、Iy（B 侧连续 gap）：

::: code-group

```python [Python]
def sw_gotoh(a, b, match=2, mismatch=-1, open_=5, extend=1, local=True):
    """仿射空位的 Gotoh DP；local=False 即 NW-Gotoh 全局版"""
    n, m = len(a), len(b)
    NEG = float("-inf")
    M  = [[NEG] * (m + 1) for _ in range(n + 1)]
    IX = [[NEG] * (m + 1) for _ in range(n + 1)]   # 最后动作：在 B 上开口（A 出 gap）
    IY = [[NEG] * (m + 1) for _ in range(n + 1)]   # 最后动作：在 A 上开口（B 出 gap）
    M[0][0] = 0
    if not local:
        for i in range(1, n + 1): IX[i][0] = -open_ - extend * (i - 1)
        for j in range(1, m + 1): IY[0][j] = -open_ - extend * (j - 1)
    else:
        for i in range(n + 1): M[i][0] = 0
        for j in range(m + 1): M[0][j] = 0
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            s = match if a[i - 1] == b[j - 1] else mismatch
            IX[i][j] = max(IX[i - 1][j] - extend, M[i - 1][j] - open_)
            IY[i][j] = max(IY[i][j - 1] - extend, M[i][j - 1] - open_)
            val = M[i - 1][j - 1] + s
            M[i][j] = max(val, IX[i][j], IY[i][j])
            if local:
                M[i][j] = max(M[i][j], 0)            # 局部版负分清零
    best, at = 0, (n, m) if not local else (0, None)
    if local:
        for i in range(n + 1):
            for j in range(m + 1):
                if M[i][j] > best:
                    best, at = M[i][j], (i, j)
        return best, at
    return M[n][m], at
```

```java [Java]
// 三表 Gotoh（local=false 全局 / true 局部），gap 惩罚均为正数
int gotohScore(String a, String b, int match, int mismatch,
               int open, int extend, boolean local) {
    int n = a.length(), m = b.length(), NEG = Integer.MIN_VALUE / 4;
    int[][] M = new int[n + 1][m + 1], IX = new int[n + 1][m + 1], IY = new int[n + 1][m + 1];
    for (int[] r : M) java.util.Arrays.fill(r, NEG);
    for (int[] r : IX) java.util.Arrays.fill(r, NEG);
    for (int[] r : IY) java.util.Arrays.fill(r, NEG);
    M[0][0] = 0;
    if (!local) {
        for (int i = 1; i <= n; i++) IX[i][0] = -open - extend * (i - 1);
        for (int j = 1; j <= m; j++) IY[0][j] = -open - extend * (j - 1);
    } else {
        for (int i = 0; i <= n; i++) M[i][0] = 0;
        for (int j = 0; j <= m; j++) M[0][j] = 0;
    }
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++) {
            int s = a.charAt(i - 1) == b.charAt(j - 1) ? match : mismatch;
            if (IX[i - 1][j] != NEG) IX[i][j] = Math.max(IX[i - 1][j] - extend, M[i - 1][j] == NEG ? NEG : M[i - 1][j] - open);
            if (IY[i][j - 1] != NEG) IY[i][j] = Math.max(IY[i][j - 1] - extend, M[i][j - 1] == NEG ? NEG : M[i][j - 1] - open);
            int val = (M[i - 1][j - 1] == NEG) ? NEG : M[i - 1][j - 1] + s;
            if (local) val = Math.max(val, 0);
            M[i][j] = Math.max(Math.max(val, IX[i][j]), IY[i][j]);
            if (local) M[i][j] = Math.max(M[i][j], 0);
        }
    if (!local) return M[n][m];
    int best = 0;
    for (int i = 0; i <= n; i++)
        for (int j = 0; j <= m; j++) best = Math.max(best, M[i][j]);
    return best;
}
```

```rust [Rust]
// 同构三表；此处给出滚动 O(m) 空间的局部版（对表间依赖做“上一行/本行”拆分）
pub fn sw_gotoh_local(a: &[char], b: &[char], match_: i32, mismatch: i32,
                      open: i32, extend: i32) -> i32 {
    let m = b.len();
    let neg = i32::MIN / 4;
    let mut m_row = vec![0i32; m + 1];            // M 上一行
    let mut ix_prev = vec![neg; m + 1];           // IX 上一行（跨行递推）
    let mut iy_row = vec![neg; m + 1];            // IY 本行（同行左推）
    let mut best = 0;
    for i in 1..=a.len() {
        let mut ix_cur = vec![neg; m + 1];
        iy_row = vec![neg; m + 1];
        let mut cur_row = vec![0i32; m + 1];
        for j in 1..=m {
            let s = if a[i - 1] == b[j - 1] { match_ } else { mismatch };
            ix_cur[j] = (ix_prev[j] - extend).max(m_row[j].saturating_sub(open));      // IX[i][j] 依赖 M[i-1][j]
            iy_row[j] = (iy_row[j - 1] - extend).max(cur_row[j - 1].saturating_sub(open));
            cur_row[j] = (m_row[j - 1] + s).max(ix_cur[j]).max(iy_row[j]).max(0);
            best = best.max(cur_row[j]);
        }
        std::mem::swap(&mut m_row, &mut cur_row);
        std::mem::swap(&mut ix_prev, &mut ix_cur);
    }
    best
}
```

```typescript [TypeScript]
function swGotohLocal(a: string, b: string, match: number, mismatch: number,
                      open: number, extend: number): number {
  const NEG = -1e15, n = a.length, m = b.length;
  const M = Array.from({ length: n + 1 }, () => new Array(m + 1).fill(NEG));
  const IX = Array.from({ length: n + 1 }, () => new Array(m + 1).fill(NEG));
  const IY = Array.from({ length: n + 1 }, () => new Array(m + 1).fill(NEG));
  for (let i = 0; i <= n; i++) M[i][0] = 0;
  for (let j = 0; j <= m; j++) M[0][j] = 0;
  let best = 0;
  for (let i = 1; i <= n; i++)
    for (let j = 1; j <= m; j++) {
      const s = a[i - 1] === b[j - 1] ? match : mismatch;
      IX[i][j] = Math.max(IX[i - 1][j] - extend, M[i - 1][j] - open);
      IY[i][j] = Math.max(IY[i][j - 1] - extend, M[i][j - 1] - open);
      M[i][j] = Math.max(M[i - 1][j - 1] + s, IX[i][j], IY[i][j], 0);
      best = Math.max(best, M[i][j]);
    }
  return best;
}
```

## 家族参数速查表

| | 边界首行/列 | 负分处理 | 答案位置 | 语义 |
|---|---|---|---|---|
| Levenshtein | `d[i][0]=i, d[0][j]=j` | — | `d[n][m]` | 最少编辑次数（距离） |
| NW | `−gap·k` | 保留 | `d[n][m]` | 全局最优得分 |
| SW | `0` | `max(0, ·)` | **全表 max** 回溯到 0 | 最优局部片段 |
| NW/SW-Gotoh | 三表按 open+extend | 同上 | 同上 | gap 仿射代价 |

- 距离↔得分互译：令 match=0、mismatch=gap=1 时 NW 的「最大 0-代价」就是「最小编辑」；一般地 `编辑距离 = (最大得分问题取负)` 需统一记号。
- **Damerau-Levenshtein** 再加「相邻换位」一档（转置也算一步）：多一张字母 last-position 表，经典误拼 `teh→the` 从此 1 步可达。
- 长序列空间优化：滚动数组只出分；要**路径**用 Hirschberg 分治（O(n) 空间两次线性 DP）或存方向位图。
- BLAST 不是这套 DP——它先用 k-mer 词命中播种再局部延伸，正是「O(nm) 全表太贵」的工程绕行，思路上呼应 [010.字符串匹配算法](./010.字符串匹配算法.md) 的 Rabin-Karp。

## 常见陷阱

- **下标偏移**：`d[i][j]` 对应 `A[i-1]` vs `B[j-1]`，差一错误在边界与回溯里连环爆；写一遍小例（`"a"` vs `""`）手验。
- gap 惩罚「加法负数」vs「减法正数」两套记号混用（上文各语言示例即两种流派）——一个项目里定死一种。
- SW 忘在回溯时**以 0 为终点**（而非左上角），或把答案位置记成 `(n,m)`——那是 NW 的坐标。
- 滚动数组做 SW 时全表最大值需要逐格记录 `(值,i,j)`——只留最后一行会错过峰值行。
- 相似度归一化：把距离当「相似度」直接比较长度悬殊的串会误导，常用 `1 - d/max(len)` 或对短串设最小长度门槛。
- Unicode：按 code point 建表（Python str 天然、Rust `chars`、JS 用 `Array.from(s)` 先拆），否则 emoji 半子母各算一编辑。

# 总结

- 一张 DP 表四种活法：边界与「是否清零」两列开关，在 Levenshtein / NW / SW / Gotoh 间自由切换——理解家族同源性比背四个算法划算；
- 全局问「整串像不像」、局部问「哪段最像」、编辑距离问「差几步」、仿射 gap 问「突变怎么解释最省」——先选对语义再调参数；
- 它是「二维序列 DP」的教学母题：后续 RNA 折叠（区间 DP）、多重比对（指数维）、HMM/Viterbi（加状态）全是这张表的延长线。
