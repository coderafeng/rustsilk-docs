# 概述

欧几里得算法（辗转相除法）：求两整数最大公约数 `gcd(a,b) = gcd(b, a mod b)`，直到余数为 0——**有文字记载至今仍在生产环境跑的最古老算法**（《几何原本》约公元前 300 年）。正确性核心：`a、b 的公因数集合 = b、a mod b 的公因数集合`；效率核心：每两步余数至少减半 → **O(log min(a,b))**。

- 所属章节：[000.字符串与数论概述](./000.字符串与数论概述.md)

- 时间复杂度：O(log min(a,b))（按位运算计 O(log²n)）；最坏输入恰是**相邻斐波那契数**（拉梅定理）；空间：迭代版 O(1)，递归版 O(log n) 栈。
- 延伸：扩展欧几里得求贝祖系数（见 [080.扩展欧几里得与同余方程](./080.扩展欧几里得与同余方程.md)）；`lcm(a,b) = a/gcd·b`。
- 应用场景：分数化简（有理数库 `Fraction` 构造器标配）、RSA 中挑互素 e 与验证、日历/齿轮/采样率的最简比换算（44.1kHz→分数周期）、化液滴/棋盘格纹理为最简格点比、密码学里的域元素互素检查、竞赛数学全家桶（同余/逆元/CRT）的第一块基石。

```java [Java]
static int gcd(int a, int b) {
    a = Math.abs(a); b = Math.abs(b);
    while (b != 0) { int t = a % b; a = b; b = t; }
    return a;
}
static long gcd(long a, long b) {
    a = Math.abs(a); b = Math.abs(b);
    while (b != 0) { long t = a % b; a = b; b = t; }
    return a;
}
static long lcm(long a, long b) {
    return a == 0 || b == 0 ? 0 : Math.abs(a) / gcd(a, b) * Math.abs(b); // 先除后乘防溢出
}
```

```rust [Rust]
// 标准库路线（推荐）：num-integer trait
use num_integer::Integer;
fn gcd(a: i64, b: i64) -> i64 { a.gcd(&b) }
fn lcm(a: i64, b: i64) -> i64 { a.lcm(&b) }

// 手写版：欧几里得迭代
fn gcd_manual(mut a: u64, mut b: u64) -> u64 {
    while b != 0 { let t = a % b; a = b; b = t; }
    a
}

// 二进制 GCD（Stein）：无除法，硬件更快
fn gcd_stein(mut a: u64, mut b: u64) -> u64 {
    if a == 0 { return b; }
    if b == 0 { return a; }
    let shift = (a | b).trailing_zeros();
    a >>= a.trailing_zeros();
    loop {
        b >>= b.trailing_zeros();
        if a > b { std::mem::swap(&mut a, &mut b); }
        b -= a;
        if b == 0 { break; }
    }
    a << shift
}
```

```typescript [TypeScript]
function gcd(a: number, b: number): number {
  a = Math.abs(a); b = Math.abs(b);
  while (b !== 0) { [a, b] = [b, a % b]; }
  return a;
}
// 大整数用 BigInt：安全整数域外 % 已失真
function gcdBig(a: bigint, b: bigint): bigint {
  [a, b] = [a < 0n ? -a : a, b < 0n ? -b : b];
  while (b !== 0n) { [a, b] = [b, a % b]; }
  return a;
}
```

## 正确性与复杂度

- **正确性**：设 `a = qb + r`。d 整除 a、b ⇒ d 整除 r=a−qb ⇒ d 是 (b,r) 公因数；反向 d 整除 b、r ⇒ 整除 a=qb+r 同理。两对数的公因数集**完全相同** ⇒ 最大者相同。递归到底 `gcd(b,0)=b`。
- **拉梅定理**（1844）：`gcd(a,b)` 的取模次数 ≤ 5·(b 的十进制位数)。等号逼近者正是相邻斐波那契对 `gcd(F(n+1),F(n))`——每步商都是 1、余数缩得最慢。
- 逆命题有用：**测一个 GCD 实现的平均性能**，斐波那契对就是最坏用例；随机大整数的 gcd 通常 O(1) 步即出 1（互素概率 6/π²≈61%）。
- **二进制 GCD（Stein 1961）**：用「减半+相减」替代取模——`gcd(偶,偶)=2·gcd`、`gcd(偶,奇)=gcd(奇,偶/2)`、奇奇先减再化偶。纯移位减法，适合无除法器的 MCU 与大整数库（GMP/OpenSSL 的底层选型之一）。

## 一眼看懂的兄弟用法

- `lcm(a,b) = a / gcd(a,b) * b`——**先除后乘**，防溢出（顺序写反是经典 overflow bug）。
- 分数化简：`p/g, q/g`；判定互素：`gcd == 1`。
- 多路周期对齐：三颗行星会合周期 = 三数 lcm；`gcd` 顺带回答「步长 a 模 m 能否遍历剩余类」（⇔ gcd(a,m)=1，为 [070.快速幂与模运算](./070.快速幂与模运算.md) 的乘法群做铺垫）。

## 常见陷阱

- `gcd(0,0)`：数学上未定义（任何数都是公约数），实现约定返回 0——依赖它的化简逻辑要单独拦；负数先取绝对值。
- `%` 在负数下的语言差异（JS 结果随被除数符号、Python 随除数）——求 gcd 前先取 abs 可完全绕开，但别把 `a % b` 的负数行为想当然用在别处。
- `int` 溢出：`a % b` 本身不溢，但 `lcm` 的乘法会——务必先除；输入接近 2³¹ 时升级到 long/BigInt。
- 递归版在极端深度（n>10⁵ 位大整数的斐波那契对）爆栈——改迭代。
- 把「扩展欧几里得」的需求（要求 x、y）误用普通 gcd——普通版丢商信息回不了头，见 080。

# 总结

- 一行循环 `while b: a, b = b, a % b` 承载两千三百年：公因数集不变性保证正确，余数减半保证对数级快；
- 性能档案：最坏=斐波那契对（拉梅），平均=几步内互素；无除法器场景换 Stein 二进制 GCD；
- 它是数论大厦的地基：逆元、CRT、RSA 参数校验全部从 `gcd` 出发——先有辗转相除，才谈同余方程。
