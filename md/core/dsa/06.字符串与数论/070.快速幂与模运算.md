# 概述

快速幂（binary exponentiation / 平方求幂）：算 `b^e` 不傻乘 e-1 次，而是把指数**二进制拆位**——`b^13 = b^8·b^4·b^1`（13=1101₂），每步「底数平方、按位选取」，O(log e) 次乘法收工。它是数论与密码学的**乘法引擎**：所有「模意义下的幂」都靠它，且过程中随时取模把数值钉在 64 位内。

- 所属章节：[000.字符串与数论概述](./000.字符串与数论概述.md)

- 时间复杂度：O(log e) 次模乘（大整数时按位计为 O(log e · M(n))）；空间 O(1)。
- 模运算三规则（全程可用的原因）：`(a+b) mod m`、`(a·b) mod m` 可**随时取模不改变结果**；除法不行——除法要换成乘**逆元**（见 [080.扩展欧几里得与同余方程](./080.扩展欧几里得与同余方程.md)）。
- 应用场景：RSA/ElGamal 的加解密核心（`c = m^e mod n`）、Diffie-Hellman 密钥交换（`g^ab mod p`）、组合数取模大杀器（阶乘+逆元预处理）、哈希滚动函数与 Miller-Rabin 的幂运算内核（[110.素性测试](./110.素性测试.md)）、斐波那契第 n 项 O(log n)（矩阵快速幂，配 [07.数值计算](../07.数值计算/000.数值计算概述.md) 的矩阵乘）、NPC 随机游走转移矩阵、模幂硬件（智能卡里的 montgomery 模块）。

**动画：3^13 mod 7——指数按位读，底数一路平方**
<!-- dsa.assets/modpow/binary-exp.gif -->

13 = 1101₂（从高位到低位读）：

1. 摆出 13 的二位位：`1 1 0 1`，答案寄存器 `res=1`，底数寄存器 `base=3`；
2. 读最高位 **1**：`res = res·base = 3`；base 平方 → 9≡2；
3. 读下位 **1**：`res = 3·2 = 6`；base 平方 → 4；
4. 读位 **0**：**不乘**（该位无贡献）；base 平方 → 16≡2；
5. 读位 **1**：`res = 6·2 = 12 ≡ 5`；end——`3^13 mod 7 = 5`；
6. 对照左列轨道：base 序列恰为 `3^1, 3^2, 3^4, 3^8`（mod 7 后 3,2,4,2），凡指数该位为 1 就乘进账——**4 次平方+3 次乘**顶掉 12 次直乘；
7. 每步都取模是合法的：模乘同余律保证中间取模不动最终结果。

## 迭代快速幂（标准型）

::: code-group

```java [Java]
// b^e mod m，m < 2^31 时 long 中间量不溢出；更大模数见「溢出处理」节
static long modPow(long b, long e, long m) {
    long res = 1 % m;                          // 兼容 m=1
    b %= m;
    while (e > 0) {
        if ((e & 1) == 1) res = res * b % m;   // 当前二进制位为 1 才乘
        b = b * b % m;                         // 底数平方进入下一位
        e >>>= 1;
    }
    return res;
}

static long pow(long b, int e) {               // 无模快速幂（整数不溢出的场景）
    long res = 1;
    while (e > 0) {
        if ((e & 1) == 1) res *= b;
        b *= b;
        e >>= 1;
    }
    return res;
}
// 生产密码学场景：BigInteger.modPow（Montgomery 模乘 + 常数时间防侧信道）
```

```rust [Rust]
pub fn mod_pow(mut b: u64, mut e: u64, m: u64) -> u64 {
    if m == 1 { return 0; }
    let mut res = 1u64 % m;
    b %= m;
    while e > 0 {
        if e & 1 == 1 {
            res = ((res as u128) * b as u128 % m as u128) as u64;   // 128 位防溢出
        }
        b = ((b as u128) * b as u128 % m as u128) as u64;
        e >>= 1;
    }
    res
}
```

```python [Python]
def mod_pow(b, e, m):
```

## 递归型与矩阵快速幂

::: code-group

```java [Java]
// 递归版：b^e = (b^(e/2))² · [e 为奇再乘 b]
static long modPowRec(long b, long e, long m) {
    if (e == 0) return 1 % m;
    long half = modPowRec(b, e >>> 1, m);
    long sq = half * half % m;
    return (e & 1) == 1 ? sq * (b % m) % m : sq;
}

// 矩阵快速幂：fib(n) mod m 在 O(log n)（2×2 矩阵乘法结合律撑腰）
static long fib(long n, long m) {
    long[][] r = {{1, 1}, {1, 0}};             // 转移矩阵 M
    long[][] res = {{1, 0}, {0, 1}};           // 单位阵
    while (n > 0) {
        if ((n & 1) == 1) res = mul(res, r, m);
        r = mul(r, r, m);
        n >>>= 1;
    }
    return res[0][1];        // M^n = [[F(n+1),F(n)],[F(n),F(n-1)]]；n=0 时单位阵给 F(0)=0
}
static long[][] mul(long[][] a, long[][] b, long m) {
    int k = a.length;
    long[][] c = new long[k][k];
    for (int i = 0; i < k; i++)
        for (int j = 0; j < k; j++)
            for (int t = 0; t < k; t++)
                c[i][j] = (c[i][j] + a[i][t] * b[t][j]) % m;
    return c;
}
```

```python [Python]
def mat_mul(A, B, m):
    k = len(A)
    return [[sum(A[i][t] * B[t][j] for t in range(k)) % m for j in range(k)]
            for i in range(k)]

def mat_pow(M, n, m):
    k = len(M)
    R = [[int(i == j) for j in range(k)] for i in range(k)]   # 单位阵
    while n:
        if n & 1:
            R = mat_mul(R, M, m)
        M = mat_mul(M, M, m)
        n >>= 1
    return R

def fib(n, m):
    if n == 0:
        return 0
    M = mat_pow([[1, 1], [1, 0]], n - 1, m)
    return M[0][0]                             # F(n) = M^(n-1)[0][0]
```

```typescript [TypeScript]
function matMul(A: number[][], B: number[][], m: number): number[][] {
  const k = A.length;
  const C = Array.from({ length: k }, () => new Array(k).fill(0));
  for (let i = 0; i < k; i++)
    for (let t = 0; t < k; t++)
      for (let j = 0; j < k; j++)
        C[i][j] = (C[i][j] + A[i][t] * B[t][j]) % m;   // i-t-j 顺序缓存友好
  return C;
}

function fibMod(n: number, m: number): number {
  if (n === 0) return 0;
  let r = [[1, 0], [0, 1]], base = [[1, 1], [1, 0]];
  let e = n - 1;
  while (e > 0) {
    if (e & 1) r = matMul(r, base, m);
    base = matMul(base, base, m);
    e >>= 1;
  }
  return r[0][0];
}
```

## 模运算军规

- **加减乘随便取模**；**除法禁止直接取模**：`(a/b) mod m ≠ (a mod m)/(b mod m)`，须换 `a · b⁻¹ mod m`（b⁻¹ 存在 ⇔ gcd(b,m)=1）。
- 幂的指数可降：底数与 m 互素时 `b^e mod m = b^(e mod φ(m)) mod m`（欧拉定理，见 [100.欧拉函数与欧拉定理](./100.欧拉函数与欧拉定理.md)）——e 是 10¹⁸ 位数时的救命稻草。
- 溢出三件套（m 接近 2⁶³ 时）：① Rust/Java 用 128 位中间量（`u128`/`Math.multiplyHigh` 手写模乘）；② 乘加改「俄罗斯农民乘法」：把 `a·b mod m` 也做成 log 次「加倍+按位加」，每次加法前判 `x >= m - x` 防溢；③ 交给 BigInteger/GMP。
- 竞赛组合数套餐：预处理 `fac[i] = i! mod p` 与 `invFac`（费马小定理 `invFac[n] = fac[n]^(p-2)`，p 素数），C(n,k)=fac[n]·invFac[k]·invFac[n-k]，单次查询 O(1)。
- **常数时间**：密码学实现中 `if (bit) res *= base` 的分支耗时泄露指数位——生产用无分支 select 或 Montgomery 阶梯（这也是推荐成熟库而非手搓的核心原因，参见 [09.密码学算法](../09.密码学算法/000.密码学算法概述.md)）。

## 常见陷阱

- `1 % m` 初始化：m=1 时正确答案是 0，`res=1` 会漏网——第一行特判 `if (m == 1) return 0`。
- 溢出高发点在**平方步** `b*b`：Java long 到 2³⁰ 级别的 m 就危险，别等炸了再换——写模幂先写溢出评估注释。
- 指数为负数（求 `b^-1 mod m`）：只有逆元存在时可做（换扩展欧几里得），快速幂本体只吃非负指数。
- 矩阵快速幂的乘序：`res = res·base` 还是 `base·res`——矩阵乘法**不交换**！向列向量递推（`v_n = M·v_{n-1}`）时统一左乘顺序并从小例验证。
- 用 `Math.pow` 算大整数幂再取模：double 早把低位丢光——「pow 之后 mod」在 2⁵³ 以上全是幻觉。

# 总结

- 快速幂 = 「指数的二进制读法」：一路平方维护 `b^(2^k)`，哪一位是 1 就把对应幂乘进答案，O(log e) 定终身；
- 模运算能全程贴身取模（加减乘同余律），唯独除法要绕道逆元、指数可降到 φ(m) 层——这三条军规比算法本身更容易出事；
- 同一引擎三种马力：整数模幂（RSA）、矩阵快速幂（线性递推）、多项式/模塔（tetration）——凡是「重复结合运算求 n 次」的加速，都是它。
