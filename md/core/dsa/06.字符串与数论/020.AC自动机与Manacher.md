# 概述

两个「把预处理做到极致」的线性算法：**AC 自动机** = Trie（见 [03.树结构/060.字典树Trie](../03.树结构/060.字典树Trie.md)）+ KMP 的 fail 指针推广到树——一次扫描文本，同时命中**全部**模式串；**Manacher** 利用回文的对称性，把「求每个位置的最长回文半径」做到 O(n)，其 `p[]` 数组一次算完即答所有回文子串问题。

**本篇收录**：AC 自动机、Manacher

- 所属章节：[000.字符串与数论概述](./000.字符串与数论概述.md)

- 复杂度：AC 建树 O(Σ|Pᵢ|·log σ)（数组转移则 O(Σ|Pᵢ|)），匹配 **O(|T| + 命中数)**——与模式个数无关；Manacher 时间/空间 O(n)。
- 应用场景：AC——敏感词过滤、IDS 入侵特征串扫描（SNAPSHOT 系）、病毒签名匹配、广告关键词定向、日志多模式告警（一个文本找一万个子串）；Manacher——回文计数/判定、DNA 回文序列（限制性内切酶识别位点）、构造回文约束题（合法化改名）、序列对称压缩评估。

**动画：AC——Trie 上长出「KMP 式退路」**
<!-- dsa.assets/ac-manacher/ac-automaton.gif -->

模式集 `{he, she, his, hers}`，文本 `ushers`：

1. 先把四个模式插入 **Trie**（根=空串状态）；
2. 建 **fail 指针**（BFS 逐层）：状态 v（对应串 s）的 fail = 「s 的最长真后缀且该后缀是某模式前缀」的 Trie 节点——he 的 fail→e?（不存在则到根）；she 的末节点 fail→**he** 的末节点（"she" 去头="he" 是模式）；
3. 匹配走文本：状态机吃到 `u→sh→she`——到 `she` 末点，沿 fail 链输出：命中 `she` 与 `he`（一个字符吃进、多条命中沿链吐出）；
4. 继续 `h→he→her…` 到 `hers` 末点命中 `hers`，同时经 fail 命中 `he`；
5. 全程文本指针**只前进**，每个字符至多沿 fail 回退均摊常数次——总代价 O(|T|)，模式再多不拖慢扫描。

**动画：Manacher——已算回文「镜像免费」**
<!-- dsa.assets/ac-manacher/manacher.gif -->

对插入分隔符的串 `#a#b#b#a#`（原 `abba`），维护「目前伸得最右的回文 [L,R]」与其中心 C：

1. 处理位置 i < R 时，先取它关于 C 的**镜像 i′=2C−i**；i 的半径至少是 i′ 的半径「裁剪到 R−i」——镜像里的回文不可能越过 R 边界白送；
2. 下界拿到后再**逐格外扩**尝试；一旦超过 R，就更新 (C,R) 交给后面用；
3. 半径只增不减地「摊」下来——外扩总次数 O(n)；
4. `#` 哨兵统一奇偶回文（`abba` 与 `aba` 都变成长度对称的奇数形态），不用分情况；
5. 算完的 `p[i]` 还原：原串以 i 为中心的最长回文长 = `p[i]`（插 # 版的半径恰等于原串回文长度）。

## AC 自动机

::: code-group

```java [Java]
class AhoCorasick {
    static class Node {
        Map<Character, Node> next = new HashMap<>();
        Node fail;
        List<String> outputs = new ArrayList<>();   // 终点挂的模式（含 fail 链汇入）
    }
    final Node root = new Node();

    void addPattern(String p) {                      // ① 建树 = Trie 插入
        Node cur = root;
        for (char c : p.toCharArray())
            cur = cur.next.computeIfAbsent(c, k -> new Node());
        cur.outputs.add(p);
    }

    void build() {                                   // ② BFS 建 fail
        Queue<Node> q = new ArrayDeque<>();
        for (Node child : root.next.values()) { child.fail = root; q.offer(child); }
        while (!q.isEmpty()) {
            Node v = q.poll();
            for (var e : v.next.entrySet()) {
                Node to = e.getValue();
                Node f = v.fail;
                while (f != null && !f.next.containsKey(e.getKey())) f = f.fail;
                to.fail = (f == null) ? root : f.next.get(e.getKey());
                to.outputs.addAll(to.fail.outputs);  // 命中即全链输出（可剪成 out 指针）
                q.offer(to);
            }
        }
    }

    List<String> search(String text) {               // ③ 单遍扫描
        List<String> hits = new ArrayList<>();
        Node cur = root;
        for (char c : text.toCharArray()) {
            while (cur != root && !cur.next.containsKey(c)) cur = cur.fail;
            cur = cur.next.getOrDefault(c, root);
            if (!cur.outputs.isEmpty()) hits.addAll(cur.outputs);
        }
        return hits;
    }
}
```

```python [Python]
from collections import deque

class AhoCorasick:
    def __init__(self):
        self.nodes = [{"next": {}, "fail": 0, "out": []}]   # 节点 0 = 根

    def add(self, pat):                               # ① Trie 插入
        cur = 0
        for ch in pat:
            nxt = self.nodes[cur]["next"]
            if ch not in nxt:
                nxt[ch] = len(self.nodes)
                self.nodes.append({"next": {}, "fail": 0, "out": []})
            cur = nxt[ch]
        self.nodes[cur]["out"].append(pat)

    def build(self):                                  # ② BFS 建 fail
        q = deque()
        for v in self.nodes[0]["next"].values():
            self.nodes[v]["fail"] = 0
            q.append(v)
        while q:
            u = q.popleft()
            for ch, v in self.nodes[u]["next"].items():
                f = self.nodes[u]["fail"]
                while f and ch not in self.nodes[f]["next"]:
                    f = self.nodes[f]["fail"]
                self.nodes[v]["fail"] = self.nodes[f]["next"].get(ch, 0)
                self.nodes[v]["out"] += self.nodes[self.nodes[v]["fail"]]["out"]
                q.append(v)

    def search(self, text):                           # ③ 扫描
        hits, cur = [], 0
        for idx, ch in enumerate(text):
            while cur and ch not in self.nodes[cur]["next"]:
                cur = self.nodes[cur]["fail"]
            cur = self.nodes[cur]["next"].get(ch, 0)
            for p in self.nodes[cur]["out"]:           # 含 fail 链并入的短模式
                hits.append((idx - len(p) + 1, p))
        return hits
```

```rust [Rust]
// 数组版（大写字母表/小写英文场景最常用），节点即下标
#[derive(Default)]
pub struct Aho {
    next: Vec<[usize; 26]>,
    fail: Vec<usize>,
    out: Vec<Vec<String>>,
}

impl Aho {
    pub fn new() -> Self {
        Self { next: vec![[0; 26]], fail: vec![0], out: vec![Vec::new()] }
    }
    pub fn add(&mut self, pat: &str) {
        let mut cur = 0;
        for b in pat.bytes() {
            let c = (b - b'a') as usize;
            if self.next[cur][c] == 0 {
                self.next[cur][c] = self.next.len();
                self.next.push([0; 26]);
                self.fail.push(0);
                self.out.push(Vec::new());
            }
            cur = self.next[cur][c];
        }
        self.out[cur].push(pat.to_string());
    }
    pub fn build(&mut self) {
        use std::collections::VecDeque;
        let mut q = VecDeque::new();
        for c in 0..26 { if self.next[0][c] != 0 { q.push_back(self.next[0][c]); } }
        while let Some(u) = q.pop_front() {
            for c in 0..26 {
                let v = self.next[u][c];
                if v != 0 {
                    let mut f = self.fail[u];
                    while f != 0 && self.next[f][c] == 0 { f = self.fail[f]; }
                    self.fail[v] = if self.next[f][c] != 0 && self.next[f][c] != v { self.next[f][c] } else { 0 };
                    let outs = self.out[self.fail[v]].clone();
                    self.out[v].extend(outs);        // fail 链输出并入
                    q.push_back(v);
                }
            }
        }
    }
}
```

```typescript [TypeScript]
// 简化教学版：Map 转移 + fail 指针 + 输出并入（结构同 Java）
class AhoCorasick {
  private nodes: { next: Map<string, number>; fail: number; out: string[] }[] =
    [{ next: new Map(), fail: 0, out: [] }];

  add(pat: string): void {
    let cur = 0;
    for (const ch of pat) {
      const n = this.nodes[cur].next;
      if (!n.has(ch)) {
        n.set(ch, this.nodes.length);
        this.nodes.push({ next: new Map(), fail: 0, out: [] });
      }
      cur = n.get(ch)!;
    }
    this.nodes[cur].out.push(pat);
  }

  build(): void {
    const q: number[] = [];
    for (const v of this.nodes[0].next.values()) q.push(v);
    for (let h = 0; h < q.length; h++) {
      const u = q[h];
      for (const [ch, v] of this.nodes[u].next) {
        let f = this.nodes[u].fail;
        while (f && !this.nodes[f].next.has(ch)) f = this.nodes[f].fail;
        this.nodes[v].fail = this.nodes[f].next.get(ch) ?? 0;
        this.nodes[v].out.push(...this.nodes[this.nodes[v].fail].out);
        q.push(v);
      }
    }
  }

  search(text: string): string[] {
    const hits: string[] = [];
    let cur = 0;
    for (const ch of text) {
      while (cur && !this.nodes[cur].next.has(ch)) cur = this.nodes[cur].fail;
      cur = this.nodes[cur].next.get(ch) ?? 0;
      hits.push(...this.nodes[cur].out);
    }
    return hits;
  }
}
```

:::

- **本质**：KMP 的 fail（next）是「单模式的失配退路」，AC 把它升到「模式集合构成的前缀树」上——状态=已读文本是某模式前缀，fail=退到「当前已读串的最长可续后缀」。
- **三种加速形态**：① 数组转移表（编译成 DFA，每字符 O(1) 无 while 回退）；② `out` 改「出口链接」懒合并（省内存）；③ 树上记忆化 goto（同字符重复回退只算一次）。

## Manacher

::: code-group

```java [Java]
// 返回 p[i]：变换串 s' 中以 i 为中心的回文半径（=原串对应位置最长回文长度）
int[] manacher(String original) {
    // ① 插哨兵：^a#b#b#a$（^/$ 免越界判断）
    StringBuilder sb = new StringBuilder("^#");
    for (char c : original.toCharArray()) sb.append(c).append('#');
    sb.append("$");
    char[] s = sb.toString().toCharArray();
    int n = s.length;
    int[] p = new int[n];
    int C = 0, R = 0;                       // 当前最右回文中心/右边界（不含）
    for (int i = 1; i < n - 1; i++) {
        int iMirror = 2 * C - i;
        if (i < R) p[i] = Math.min(R - i, p[iMirror]);   // 镜像下界（裁剪）
        while (s[i + 1 + p[i]] == s[i - 1 - p[i]]) p[i]++;  // 逐格外扩
        if (i + p[i] > R) { C = i; R = i + p[i]; }            // 刷新最右
    }
    return p;
}
int longestPalindrome(String t) {
    int best = 0;
    for (int r : manacher(t)) best = Math.max(best, r);     // 半径即原串回文长
    return best;
}
```

```python [Python]
def manacher(s):
    """返回 p[i]：变换串以 i 为中心的回文半径（原串回文长度）"""
    t = "^#" + "#".join(s) + "#$"          # 哨兵免边界判断
    n = len(t)
    p = [0] * n
    c = r = 0                              # 当前最右回文的中心/右边界
    for i in range(1, n - 1):
        mir = 2 * c - i
        if i < r:
            p[i] = min(r - i, p[mir])      # 镜像信息只敢用到 r 为止
        while t[i + 1 + p[i]] == t[i - 1 - p[i]]:
            p[i] += 1                      # 越过 r 才产生真实比较
        if i + p[i] > r:
            c, r = i, i + p[i]
    return p

def longest_palindrome_len(s):
    return max(manacher(s))                # 半径恰等于原串最长回文长度
```

```rust [Rust]
pub fn manacher(s: &str) -> Vec<usize> {
    // 变换串用 Vec<char>，^ 与 $ 哨兵
    let mut t: Vec<char> = vec!['^', '#'];
    for ch in s.chars() { t.push(ch); t.push('#'); }
    t.push('$');
    let n = t.len();
    let mut p = vec![0usize; n];
    let (mut c, mut r) = (0usize, 0usize);
    for i in 1..n - 1 {
        let mir = 2 * c - i;
        if i < r {
            p[i] = (r - i).min(p[mir]);
        }
        while t[i + 1 + p[i]] == t[i - 1 - p[i]] {
            p[i] += 1;
        }
        if i + p[i] > r { c = i; r = i + p[i]; }
    }
    p
}

pub fn longest_palindrome_len(s: &str) -> usize {
    manacher(s).into_iter().max().unwrap_or(0)
}
```

```typescript [TypeScript]
function manacher(s: string): number[] {
  const t = ["^", "#", ...s.split(""), "#", "$"].join("");
  const n = t.length, p = new Array(n).fill(0);
  let c = 0, r = 0;
  for (let i = 1; i < n - 1; i++) {
    const mir = 2 * c - i;
    if (i < r) p[i] = Math.min(r - i, p[mir]);
    while (t[i + 1 + p[i]] === t[i - 1 - p[i]]) p[i]++;
    if (i + p[i] > r) { c = i; r = i + p[i]; }
  }
  return p;
}
const longestPalindromeLen = (s: string): number =>
  s.length ? Math.max(...manacher(s)) : 0;
```

:::

- **为什么是 O(n)**：外层循环 n 次，内层 while 每成功一次 R 就右移一格，R ≤ n——外扩总成功次数均摊 O(n)；失败的那一次比较总共也只有 n 次。
- **读答案**：`p[i]` = 原串中最长回文长度；中心映射回原串：i 为插 # 位 ⇔ 偶中心，字母位 ⇔ 奇中心——「统计回文子串数」「判断子串是否回文」都从 p[] 直接导出（配区间查询可再上 [03.树结构/070.线段树与树状数组](../03.树结构/070.线段树与树状数组.md) 思想离线处理）。
- 姊妹工具 **eertree（回文树）**：所有本质不同回文串组成 Tree+后缀链，支持在线回文 DP——AC 之于前缀、eertree 之于回文。

## 常见陷阱

- AC 建 fail 时根的子女必须显式 `fail=root` 并入队——漏一层则整棵子树的退路全错；深度 1 以下忘并入 `fail.outputs` 会漏报「短模式藏在长命中尾部」的匹配。
- AC 的 `out` 懒链（只存本节点、命中时沿 fail 走）最坏 O(n·模式数)，务必用「输出链接」压缩或直接并入。
- Manacher 忘 `min(R-i, p[mir])` 的裁剪：镜像回文超出当前 [C,R] 时不可全信（那段没验证过），半径虚高导致答案错。
- 哨兵 `^`/`$` 不能出现在字符集里，否则免越界判断失效；Python 用列表索引注意 `$` 位。
- Unicode 串按 code point 处理（Python3 原生、Rust chars、TS 用扩展运算符迭代），JS 的 UTF-16 code unit 会把 emoji 劈成两半。

# 总结

- AC 自动机 = 「KMP 思想对模式集合的推广」：Trie 存状态、BFS 挂 fail、扫描时文本指针永不动——O(|T|+命中) 一次读完结案，是全部多模匹配工业场景的地基；
- Manacher = 「回文对称性的动态规划」：中心 C、边界 R 单调右推，镜像给下界、外扩补差额，O(n) 拿到全部回文半径；
- 两算法共同的方法论：**把「已知结果」编码成可复用结构**（fail 链/镜像表），扫描类问题的下限就从「乘模式数/乘长度」塌缩到线性。
