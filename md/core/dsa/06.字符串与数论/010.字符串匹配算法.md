# 概述

字符串匹配：在文本 T（长 n）中找模式 P（长 m）的出现位置——搜索引擎、编辑器查找、grep、DNA 序列比对的第一道工序。四个代表算法展示了三种提速思路：**KMP** 用「模式自相似性」让指针永不回退，**Rabin-Karp** 用滚动哈希换取空间换时间的 flexibility，**BM** 靠坏字符/好后缀规则让指针大幅跳跃（工程最快），**BF** 朴素暴力是理解一切的下界基准。

**本篇收录**：BF（暴力）、KMP、Rabin-Karp、BM

- 所属章节：[000.字符串与数论概述](./000.字符串与数论概述.md)

- 复杂度对照：

  | 算法 | 预处理 | 匹配（最坏） | 指针方向 | 特点 |
  |------|:------:|:----------:|---------|------|
  | BF | O(1) | O(n·m) | 文本可回退 | 简单，随机数据实际 O(n+m) |
  | KMP | O(m)（next 数组） | **O(n+m)** | 文本**永不回退** | 流式匹配首选 |
  | Rabin-Karp | O(m)（哈希） | 最坏 O(n·m)，期望 **O(n+m)** | 滑动窗口 | 多模式/二维匹配利器 |
  | BM | O(σ)（两张表，σ=字符集） | 最好 O(n/m)，实践亚线性 | 模式窗**右移跳读** | grep/编辑器实装 |

- 应用场景：Ctrl+F 与编辑器高亮（BM 系）、grep/ripgrep（ Boyer-Moore-Horspool + 位并行）、DNA/protein 搜索（KMP/RK 变体）、 plagiarism 检测的 k-gram 指纹（RK 家族）、文件名通配符匹配、网络入侵检测里的特征串扫描、`String.indexOf`（JDK 朴素变体，.NET 用 BM 混合）。

**动画：KMP——失配时文本指针 i 不倒退**
<!-- dsa.assets/string-match/kmp.gif -->

T=`abababc`，P=`aba`（next：`[-1,0,0]`，含义「最长相等真前后缀长」）：

1. i、j 同步推进：`a=a, b=b, a=a` —— 第 3 位 j=3 越尾，命中一次，记录位置 i-m=0；
2. 续配到 T[3]=`b` 与 P 下一位失配时，j 沿 next 回退到「已匹配前缀的最长可复用后缀」长度——**i 一动不动**；
3. 已比过的 `ab` 既是 P 的前缀又是刚匹配段的后缀 → 这段信息**白拿**，直接当 P 的后缀继续；
4. 反复「匹配→失配→只退 j」直到 i 走到文本尾；总比较次数 ≤ 2n。

**动画：BM——窗从右往左比，坏字符大步跳**
<!-- dsa.assets/string-match/bm.gif -->

T=`dabcabdabc`，P=`abd`（坏字符表记每字符到窗右端的最远距离）：

1. 窗口对齐，**从模式最右字符开始**向左比：`c` vs `d` 失配；
2. 坏字符规则：文本里的 `c` 根本不在 P 中 → 整个窗口可以**跳过 c** 直接后移 3 位（一步顶 BF 三步）；
3. 若失配字符在 P 中出现（如在窗内偏左位置），则移到「该字符与 P 中它最右出现」对齐——甚至可能**负移**，此时交给好后缀规则兜底取 max；
4. 好后缀规则：已匹配的后缀部分在 P 内部找上一次出现的位置，按其距离跳；
5. 每步移动 ≥1，文本端常呈「跳读」，平均远优于 KMP——代价是坏字符表只保证「不比文本回退」的正确性边界要小心维护。

# 详解

## BF：暴力但有用的基线

::: code-group

```java [Java]
List<Integer> bf(String text, String pat) {
    List<Integer> hits = new ArrayList<>();
    int n = text.length(), m = pat.length();
    outer:
    for (int i = 0; i + m <= n; i++) {          // 每个对齐位置
        for (int j = 0; j < m; j++)
            if (text.charAt(i + j) != pat.charAt(j)) continue outer;
        hits.add(i);
    }
    return hits;
}
```

```python [Python]
def bf(text, pat):
    n, m = len(text), len(pat)
    return [i for i in range(n - m + 1) if text[i:i + m] == pat]
```

```rust [Rust]
fn bf(text: &[u8], pat: &[u8]) -> Vec<usize> {
    let (n, m) = (text.len(), pat.len());
    (0..=n.saturating_sub(m))
        .filter(|&i| &text[i..i + m] == pat)
        .collect()
}
```

```typescript [TypeScript]
function bf(text: string, pat: string): number[] {
  const hits: number[] = [], n = text.length, m = pat.length;
  for (let i = 0; i + m <= n; i++) {
    let ok = true;
    for (let j = 0; j < m; j++)
      if (text[i + j] !== pat[j]) { ok = false; break; }
    if (ok) hits.push(i);
  }
  return hits;
}
```

## KMP：next 数组 + 永不回退

`next[j]` = 子串 `P[0..j)` 的最长相等真前后缀长度；失配时 j 退到 `next[j]` 再比（退无可退即 -1，此时 i、j 同进）。

::: code-group

```java [Java]
int[] buildNext(String p) {
    int m = p.length();
    int[] next = new int[m + 1];
    next[0] = -1;                             // 约定：j=0 失配时 i 进 j 归 0
    int j = 0, k = -1;
    while (j < m) {
        if (k == -1 || p.charAt(j) == p.charAt(k)) {
            j++; k++;
            next[j] = k;
        } else k = next[k];                   // 继续退到次短候选
    }
    return next;
}

List<Integer> kmp(String text, String pat) {
    int[] next = buildNext(pat);
    List<Integer> hits = new ArrayList<>();
    int i = 0, j = 0;
    while (i < text.length()) {
        if (j == -1 || text.charAt(i) == pat.charAt(j)) { i++; j++; }
        else j = next[j];                     // 文本指针 i 不回退
        if (j == pat.length()) {
            hits.add(i - j);
            j = next[j];                      // 找下一处（可重叠）
        }
    }
    return hits;
}
```

```python [Python]
def build_next(p):
    m = len(p)
```

```rust [Rust]
fn build_next(p: &[u8]) -> Vec<i32> {
    let m = p.len();
    let mut nxt = vec![-1i32; m + 1];
    let (mut j, mut k) = (0usize, -1i32);

        if k == -1 || p[j] == p[k as usize] {
            j += 1; k += 1;
            nxt[j] = k;
        } else {
            k = nxt[k as usize];
        }
    }
    nxt
}

fn kmp(text: &[u8], pat: &[u8]) -> Vec<usize> {
    let nxt = build_next(pat);
    let (mut hits, mut i, mut j) = (Vec::new(), 0usize, 0i32);
    while i < text.len() {
        if j == -1 || text[i] == pat[j as usize] { i += 1; j += 1; }
        else { j = nxt[j as usize]; }
        if j as usize == pat.len() {
            hits.push(i - j as usize);
            j = nxt[j as usize];
        }
    }
    hits
```

```typescript [TypeScript]
function kmp(text: string, pat: string): number[] {
  const m = pat.length;
  const next = new Array<number>(m + 1).fill(0);
  next[0] = -1;
  let j = 0, k = -1;
  while (j < m) {
    if (k === -1 || pat[j] === pat[k]) { next[++j] = ++k; }
    else k = next[k];
  }
  const hits: number[] = [];
  let i = 0, q = 0;
  while (i < text.length) {
    if (q === -1 || text[i] === pat[q]) { i++; q++; }
    else q = next[q];
    if (q === m) { hits.push(i - q); q = next[q]; }
  }
  return hits;
}
```

## Rabin-Karp：滚动哈希

窗口哈希 `h(T[i+1..i+m]) = (h - T[i]·base^(m-1))·base + T[i+m]`（mod 质数），一次移动 O(1) 更新；哈希命中再做 O(m) 验证防碰撞。

::: code-group

```java [Java]
List<Integer> rabinKarp(String text, String pat) {
    final long MOD = (1L << 61) - 1;          // Mersenne 质数，乘法不易溢
    final long BASE = 131;
    int n = text.length(), m = pat.length();
    long pow = 1;                              // BASE^(m-1) % MOD
    for (int i = 0; i < m - 1; i++) pow = pow * BASE % MOD;
    long hT = 0, hP = 0;
    for (int i = 0; i < m; i++) {              // 初始窗口与模式的哈希
        hT = (hT * BASE + text.charAt(i)) % MOD;
        hP = (hP * BASE + pat.charAt(i)) % MOD;
    }
    List<Integer> hits = new ArrayList<>();
    for (int i = 0; i + m <= n; i++) {
        if (hT == hP && text.substring(i, i + m).equals(pat)) hits.add(i);
        if (i + m < n) {                       // 滚动：去头加尾
            hT = ((hT - (long) text.charAt(i) * pow % MOD + MOD) * BASE
                    + text.charAt(i + m)) % MOD;
        }
    }
    return hits;
}
```

```python [Python]
def rabin_karp(text, pat):
    MOD, BASE = (1 << 61) - 1, 131
    n, m = len(text), len(pat)
    pow_ = pow(BASE, m - 1, MOD)
    h_t = h_p = 0
    for i in range(m):
        h_t = (h_t * BASE + ord(text[i])) % MOD
        h_p = (h_p * BASE + ord(pat[i])) % MOD
    hits = []
    for i in range(n - m + 1):
        if h_t == h_p and text[i:i + m] == pat:   # 命中必验证，防哈希碰撞
            hits.append(i)
        if i + m < n:
            h_t = ((h_t - ord(text[i]) * pow_) % MOD * BASE
                   + ord(text[i + m])) % MOD
    return hits
```

```rust [Rust]
fn rabin_karp(text: &[u8], pat: &[u8]) -> Vec<usize> {
    const MOD: u64 = (1u64 << 61) - 1;
    const BASE: u64 = 131;
    let (n, m) = (text.len(), pat.len());
    if m == 0 || m > n { return vec![]; }
    let mut pow = 1u64;
    for _ in 0..m - 1 { pow = pow.wrapping_mul(BASE) % MOD; }
    let (mut h_t, mut h_p) = (0u64, 0u64);
    for i in 0..m {
        h_t = (h_t.wrapping_mul(BASE) + text[i] as u64) % MOD;
        h_p = (h_p.wrapping_mul(BASE) + pat[i] as u64) % MOD;
    }
    let mut hits = Vec::new();
    for i in 0..=n - m {
        if h_t == h_p && &text[i..i + m] == pat { hits.push(i); }
        if i + m < n {
            h_t = ((h_t + MOD - (text[i] as u64).wrapping_mul(pow) % MOD)
                    .wrapping_mul(BASE) + text[i + m] as u64) % MOD;
        }
    }
    hits
}
```

```typescript [TypeScript]
function rabinKarp(text: string, pat: string): number[] {
  // 1e9+7 模数 + 双精度安全乘（BASE*MOD < 2^53）；BigInt 亦可
  const MOD = 1_000_000_007n, BASE = 131n;
  const n = text.length, m = pat.length;
  let pow = 1n;
  for (let i = 0; i < m - 1; i++) pow = pow * BASE % MOD;
  let hT = 0n, hP = 0n;
  for (let i = 0; i < m; i++) {
    hT = (hT * BASE + BigInt(text.charCodeAt(i))) % MOD;
    hP = (hP * BASE + BigInt(pat.charCodeAt(i))) % MOD;
  }
  const hits: number[] = [];
  for (let i = 0; i + m <= n; i++) {
    if (hT === hP && text.slice(i, i + m) === pat) hits.push(i);
    if (i + m < n)
      hT = ((hT - BigInt(text.charCodeAt(i)) * pow % MOD + MOD) * BASE
            + BigInt(text.charCodeAt(i + m))) % MOD;
  }
  return hits;
}
```

## BM：坏字符 + 好后缀

::: code-group

```java [Java]
List<Integer> boyerMoore(String text, String pat) {
    int n = text.length(), m = pat.length();
    // ① 坏字符表：字符 -> 其在 P 中最右下标（无则 -1）
    int[] badChar = new int[256];
    java.util.Arrays.fill(badChar, -1);
    for (int i = 0; i < m; i++) badChar[pat.charAt(i)] = i;
    // ② 好后缀表 goodSuffix[j]：与 P[j..m) 这个后缀「前缀化」对齐的最小右移
    int[] goodSuffix = new int[m + 1];
    int[] border = new int[m + 1];             // 辅助：各长度后缀的公共边界
    java.util.Arrays.fill(goodSuffix, m);
    int k = m;
    border[k] = m + 1;
    for (int i = m - 1; i >= 0; i--) {
        int j = border[i + 1];
        while (j <= m && pat.charAt(i) != pat.charAt(j - 1)) {
            if (goodSuffix[j] == m) goodSuffix[j] = m - 1 - i;
            j = border[j];
        }
        border[j] = i + 1;
    }
    j = border[0];                              // 把「整个 P 的前缀也是后缀」情况补齐
    while (j <= m) {
        if (goodSuffix[j] == m) goodSuffix[j] = m - j;
        j = border[j];
    }
    List<Integer> hits = new ArrayList<>();
    int s = 0;
    while (s <= n - m) {
        int i = m - 1;
        while (i >= 0 && pat.charAt(i) == text.charAt(s + i)) i--;
        if (i < 0) {                            // 整窗匹配
            hits.add(s);
            s += goodSuffix[0];                 // 按好后缀（=全匹配）继续跳
        } else {
            s += Math.max(i - badChar[text.charAt(s + i)],   // 坏字符位移（可负）
                          goodSuffix[i + 1]);               // 好后缀位移
        }
    }
    return hits;
}
```

```python [Python]
def boyer_moore_horspool(text, pat):
    """BM 家族工程主力：只查「窗口最右文本字符」，右移恒 ≥1，实现极简。
    完整双表版（坏字符+好后缀）见上方 Java 实现，思路同构。"""
    n, m = len(text), len(pat)
    if m == 0 or m > n:
        return []
    skip = {pat[i]: m - 1 - i for i in range(m - 1)}   # 最右出现距窗尾多远
    hits, s = [], 0
    while s + m <= n:
        i = m
        while i > 0 and pat[i - 1] == text[s + i - 1]:
            i -= 1
        if i == 0:
            hits.append(s)
        # 步长只看窗口最右的文本字符（不管它对齐 P 的哪个位置）
        s += max(1, skip.get(text[s + m - 1], m))
    return hits
```

```rust [Rust]
// 工程最常用的 Horspool 变种：只用「窗口最右字符」的坏字符表，右移恒 ≥ 1
pub fn boyer_moore_horspool(text: &[u8], pat: &[u8]) -> Vec<usize> {
    let (n, m) = (text.len(), pat.len());
    let mut skip = [m; 256];
    for i in 0..m - 1 { skip[pat[i] as usize] = m - 1 - i; }
    let mut hits = Vec::new();
    let mut s = 0usize;
    while s + m <= n {
        let mut i = m;
        while i > 0 && pat[i - 1] == text[s + i - 1] { i -= 1; }
        if i == 0 { hits.push(s); }
        // 以窗口最右文本字符决定步长
        s += skip[text[s + m - 1] as usize].max(1);
    }
    hits
}
```

```typescript [TypeScript]
function boyerMooreHorspool(text: string, pat: string): number[] {
  const n = text.length, m = pat.length;
  const skip = new Map<string, number>();
  for (let i = 0; i < m - 1; i++) skip.set(pat[i], m - 1 - i);
  const hits: number[] = [];
  let s = 0;
  while (s + m <= n) {
    let i = m;
    while (i > 0 && pat[i - 1] === text[s + i - 1]) i--;
    if (i === 0) hits.push(s);
    s += Math.max(1, skip.get(text[s + m - 1]) ?? m);
  }
  return hits;
}
```

## 选型与变体

- **单模式在线匹配**：KMP（文本流不可回退，如网络报文扫描）；**离线大文本**：BM/Horspool 亚线性跳读。
- **多模式**：一批模式一起找 → [020.AC自动机与Manacher](./020.AC自动机与Manacher.md) 的 AC 自动机；RK 思想则给每个模式各算哈希、一次扫描全部命中（哈希集合判重）。
- **二维/相似度匹配**：RK 的滚动哈希可推广到图像块指纹、文件分块去重（rsync 原理）。
- 近似匹配（允许 k 个错）：BK 树 + Levenshtein 自动机，见 [030.字符串相似度与编辑距离](./030.字符串相似度与编辑距离.md)。

## 常见陷阱

- KMP next 有两套约定（`next[0]=-1` 的「失配表」vs `pi[i]=最长前后缀` 的「部分匹配表」），抄代码混用必错——先统一「长度」语义再对下标。
- 找**所有（可重叠）命中**时 KMP 命中后要 `j = next[j]` 继续；忘这步只报第一个；BM 命中后步长要用 goodSuffix[0]/skip 而不是 i-badChar。
- RK 忘二次验证：哈希相等≠串相等（对抗输入可故意造碰撞），命中必须逐字符核对或双哈希。
- RK 滚动更新出现负数取模（`(h - head*pow) % MOD < 0`）——各语言负取模行为不同，先 `+MOD` 再 `%`。
- BM 坏字符表按字节建 256 数组时，非 ASCII（中文/emoji）需按码点建 Map，或整体按 UTF-8 字节匹配（对二进制安全，但下标是字节位）。
- 用 TS/JS 的 number 直接做 RK 大质数乘法会丢精度——用 BigInt（示例做法）或 <2^26 的小模数。

# 总结

- 四算法一条演进线：BF 每次失配**全部重来**；KMP 记住「模式自己是谁」让 i 永不回退（O(n+m) 稳定器）；RK 放弃逐字符、用滚动哈希换整窗比较（多模式/二维好手）；BM 从右往左比+两张跳表，把「平均每字符看几次」压到 1 以下；
- 面试与工程侧重不同：手写常考 KMP next，工程默认 BM 家族（horspool 20 行），多模升 AC，流式用 KMP；
- 一切匹配的通用心智：**已获得的信息绝不浪费**——next、goodSuffix、哈希值都只是把「比过的东西」编译成的可复用知识。
