# 概述

计算几何入门三件套：**叉积**（判转向——一切几何判断的原语）、**凸包**（Graham 扫描 / Andrew 单调链：把点集「橡皮筋」包起来）、**旋转卡壳**（在凸包上配对扫描求直径/宽度）。几何题的通用心法：不用角度和三角函数，全程用**符号化叉积**判方向——又快又稳还免精度陷阱。

- 所属章节：[000.字符串与数论概述](./000.字符串与数论概述.md)

- 复杂度：叉积 O(1)；Graham/Andrew 凸包 O(n log n)（瓶颈在排序）；旋转卡壳在已建凸包上 O(h)（h=包点数）。
- 应用场景：游戏碰撞检测与视线判定（AOI/寻路可视图）、GIS 地理围栏与行政区划合并（凸包/Voronoi 前菜）、机器人避障（凸多边形 Minkowski 和）、CV 里的轮廓分析（OpenCV `convexHull`）、图表异常值剔除、CAD 刀具路径、天文学星群定位、军事「最远两点」侦察问题（直径）。

**动画：叉积——b 在 a 的左边还是右边**
<!-- dsa.assets/geom/cross-product.gif -->

1. 平面向量 `a=(ax,ay)`、`b=(bx,by)`，叉积 `cross = ax·by − ay·bx`（行列式，有符号面积）；
2. `cross > 0`：a **逆时针**转到 b，b 在 a 左手边（屏幕坐标系 y 向下时符号相反！）；
3. `cross < 0`：右转/右手边；`cross = 0`：共线；
4. 三点版：`cross(A,B,C) = (B−A)×(C−A)` 判 `A→B→C` 的转向——「向左拐/向右拐/直走」；
5. 数值彩蛋：|cross| = 平行四边形面积 = 2×三角形面积——点在多边形内、多边形面积都从它来。

**动画：Andrew 单调链——上下壳各扫一遍**
<!-- dsa.assets/geom/graham.gif -->

1. 点按 (x,y) 字典序排序；
2. 从左到右建**下壳**：新点入栈前，若栈顶造成「非左转」（对逆时针凸包即 `cross ≤ 0`）就弹栈——橡皮筋被凹处弹回；
3. 从右到左同样建**上壳**；
4. 两壳拼接（去重端点）即凸包——10 行代码没有 atan2、没有极角排序的特判地狱；
5. Graham 原版等价：先取最低点、按极角排序再同样「非左转就弹」——排序键不同，弹栈灵魂一致：**保持全程左转 = 保持凸性**。

**动画：旋转卡壳——两平行卡尺夹凸包量最大距离**
<!-- dsa.assets/geom/rotating-calipers.gif -->

1. 凸包上对踵点（能被一对平行线夹住的点对）的候选用两根「卡尺」枚举；
2. 边 (i,i+1) 固定，卡尺顶点 j 沿「叉积面积还在增大」方向推进；i 环游一圈，j 也只前进一圈 → O(h)；
3. 途中更新的 `|p_i − p_j|²` 最大值 = **凸包直径**（所有点对最大距离）；
4. 同款推进换个判据可得多边形宽度、最小面积外接矩形——一套骨架四个问题。

## 叉积原语与点在多边形内

::: code-group

```java [Java]
record Pt(long x, long y) {}

static long cross(Pt o, Pt a, Pt b) {          // (a-o)×(b-o)，整数坐标用 long 防爆
    return (a.x - o.x) * (b.y - o.y) - (a.y - o.y) * (b.x - o.x);
}
// >0 逆时针(左转)；<0 顺时针；==0 共线

// 三角形面积 = |cross|/2；多边形有向面积（鞋带公式）：
static double polyArea(Pt[] p) {
    double s = 0;
    for (int i = 0; i < p.length; i++) {
        Pt a = p[i], b = p[(i + 1) % p.length];
        s += a.x * b.y - a.y * b.x;
    }
    return Math.abs(s) / 2.0;
}

// 凸多边形内含点：逐边判「是否同在内侧」（依赖边已逆时针一致）
static boolean inConvex(Pt[] poly, Pt q) {
    int n = poly.length, sign = 0;
    for (int i = 0; i < n; i++) {
        long c = cross(poly[i], poly[(i + 1) % n], q);
        if (c == 0) continue;
        int s = c > 0 ? 1 : -1;
        if (sign == 0) sign = s;
        else if (sign != s) return false;      // 某边外侧 → 不在内
    }
    return true;
}
```

## Andrew 单调链凸包（工程首选）

::: code-group

```java [Java]
static List<Pt> convexHull(Pt[] pts) {
    Pt[] p = pts.clone();
    Arrays.sort(p, (a, b) -> a.x() != b.x() ? Long.compare(a.x(), b.x())
                                            : Long.compare(a.y(), b.y()));
    int n = p.length;
    if (n <= 2) return Arrays.asList(p);
    Pt[] hull = new Pt[2 * n];
    int k = 0;
    for (int i = 0; i < n; i++) {              // 下壳：左→右
        while (k >= 2 && cross(hull[k - 2], hull[k - 1], p[i]) <= 0) k--;  // 非左转弹栈
        hull[k++] = p[i];
    }
    for (int i = n - 2, t = k + 1; i >= 0; i--) {   // 上壳：右→左（端点已占，退一格）
        while (k >= t && cross(hull[k - 2], hull[k - 1], p[i]) <= 0) k--;
        hull[k++] = p[i];
    }
    return Arrays.asList(hull).subList(0, k - 1);   // 首尾同点，去掉重复
}
// cross <= 0：共线点被剔除；要保留边界共线点改 < 0
```

```rust [Rust]
pub fn convex_hull(pts: &[Pt]) -> Vec<Pt> {
    let mut p: Vec<Pt> = pts.to_vec();
    p.sort_unstable_by_key(|q| (q.x, q.y));
    let n = p.len();
    if n <= 2 { return p; }
    let mut lower: Vec<Pt> = Vec::with_capacity(n);
    for pt in &p {
        while lower.len() >= 2
            && cross(&lower[lower.len() - 2], &lower[lower.len() - 1], pt) <= 0 {
            lower.pop();
        }
        lower.push(*pt);
    }
    let mut upper: Vec<Pt> = Vec::with_capacity(n);
    for pt in p.iter().rev() {
        while upper.len() >= 2
            && cross(&upper[upper.len() - 2], &upper[upper.len() - 1], pt) <= 0 {
            upper.pop();
        }
        upper.push(*pt);
    }
    lower.pop();
    upper.pop();
    lower.extend(upper);
    lower                                   // 逆时针凸包（不含端点重复）
}
```

```python [Python]
def convex_hull(points):
    """Andrew 单调链，返回逆时针凸包（无重复端点）"""
    pts = sorted(set(points))
    if len(pts) <= 2:
        return pts
    def half(seq):
        h = []
        for pt in seq:
            while len(h) >= 2 and cross(h[-2], h[-1], pt) <= 0:
                h.pop()                     # 非左转 → 凹点弹出
            h.append(pt)
        return h
    lower, upper = half(pts), half(pts[::-1])
    return lower[:-1] + upper[:-1]
```

```typescript [TypeScript]
function convexHull(pts: Pt[]): Pt[] {
  const p = [...pts].sort((a, b) => a.x - b.x || a.y - b.y);
  const n = p.length;
  if (n <= 2) return p;
  const half = (seq: Pt[]): Pt[] => {
    const h: Pt[] = [];
    for (const pt of seq) {
      while (h.length >= 2 && cross(h[h.length - 2], h[h.length - 1], pt) <= 0)
        h.pop();
      h.push(pt);
    }
    return h;
  };
  const lower = half(p), upper = half([...p].reverse());
  return lower.slice(0, -1).concat(upper.slice(0, -1));
}
```

## 旋转卡壳直径

::: code-group

```java [Java]
static long diameter2(List<Pt> hull) {                // 直径平方（免开根）
    int n = hull.size();
    if (n == 1) return 0;
    if (n == 2) return dist2(hull.get(0), hull.get(1));
    long best = 0;
    int j = 1;
    for (int i = 0; i < n; i++) {
        Pt a = hull.get(i), b = hull.get((i + 1) % n);
        // 下一条边的对踵：三角形面积还在变大就推进 j
        while (Math.abs(cross(a, b, hull.get((j + 1) % n)))
             > Math.abs(cross(a, b, hull.get(j)))) {
            j = (j + 1) % n;
        }
        best = Math.max(best, Math.max(dist2(a, hull.get(j)),
                                       dist2(b, hull.get(j))));
    }
    return best;
}
static long dist2(Pt p, Pt q) {
    return (p.x() - q.x()) * (p.x() - q.x()) + (p.y() - q.y()) * (p.y() - q.y());
}
```

```python [Python]
def diameter2(hull):
    """凸包直径平方；hull 为逆时针顶点列表"""
    n = len(hull)
    if n < 2:
        return 0
    if n == 2:
        return dist2(hull[0], hull[1])
    def dist2(p, q):
        return (p.x - q.x) ** 2 + (p.y - q.y) ** 2
    best, j = 0, 1
    for i in range(n):
        a, b = hull[i], hull[(i + 1) % n]
        while abs(cross(a, b, hull[(j + 1) % n])) > abs(cross(a, b, hull[j])):
            j = (j + 1) % n               # 只前进不回头 → 总共 O(n)
        best = max(best, dist2(a, hull[j]), dist2(b, hull[j]))
    return best
```

```rust [Rust]
pub fn diameter2(hull: &[Pt]) -> i64 {
    let n = hull.len();
    let dist2 = |p: &Pt, q: &Pt| (p.x - q.x) * (p.x - q.x) + (p.y - q.y) * (p.y - q.y);
    match n {
        0 | 1 => return 0,
        2 => return dist2(&hull[0], &hull[1]),
        _ => {}
    }
    let mut best = 0i64;
    let mut j = 1usize;
    for i in 0..n {
        let (a, b) = (hull[i], hull[(i + 1) % n]);
        while (cross(&a, &b, &hull[(j + 1) % n]).abs()
            > cross(&a, &b, &hull[j]).abs()) {
            j = (j + 1) % n;
        }
        best = best.max(dist2(&a, &hull[j])).max(dist2(&b, &hull[j]));
    }
    best
}
```

```typescript [TypeScript]
function diameter2(hull: Pt[]): number {
  const n = hull.length;
  const d2 = (p: Pt, q: Pt) => (p.x - q.x) ** 2 + (p.y - q.y) ** 2;
  if (n < 2) return 0;
  if (n === 2) return d2(hull[0], hull[1]);
  let best = 0, j = 1;
  for (let i = 0; i < n; i++) {
    const a = hull[i], b = hull[(i + 1) % n];
    while (Math.abs(cross(a, b, hull[(j + 1) % n])) > Math.abs(cross(a, b, hull[j])))
      j = (j + 1) % n;
    best = Math.max(best, d2(a, hull[j]), d2(b, hull[j]));
  }
  return best;
}
```

## 进阶地图（入门之后学什么）

- **一般（含凹）多边形**：点在多边形内用射线法/环绕数；三角化（ear-clipping）→ 单调分割 → 查询 O(log n)——GIS 与渲染引擎的流水线。
- **Voronoi / Delaunay**：凸包的孪生对偶（三维单形投影视角），最近邻、插值、有限元网格的发动机；fortune 扫线 O(n log n)。
- **半平面交 / 多边形交并**：约束求解与碰撞（Sutherland-Hodgman 裁剪）；Minkowski 和支撑函数在 O(n+m) 完成凸体碰撞预判。
- **整型几何库**：CGAL / boost::geometry / Shapely——生产系统别手搓浮点版；浮点鲁棒性（robust predicates）是计算几何著名的深坑。

## 常见陷阱

- **屏幕坐标 y 轴向下**：叉积符号的「左右」语义翻转——统一按数学坐标推理，绘制时再镜像；或干脆只依赖「同侧/异侧」不变性质。
- 弹栈条件 `<= 0` 与 `< 0` 之别：前者剔除共线点（返回最小顶点集）、后者保留边界共线点——周长/点数统计题两者答案不同。
- 重复点未去重：`sorted(set(...))` 或去重后 n<3 特判，否则上下壳拼接出错；全部共线的退化点集要能返回两端点。
- 浮点判等：`cross == 0` 对 double 永不成立——整数坐标用整型叉积（首选），必须浮点时用 `eps` 带或精确谓词（Shewchuk adaptive predicates）。
- 旋转卡壳 while 用 `>` 而非 `>=`：等面积（平行边）时不推进会漏对踵候选——配合「两边都取 max」补偿，或直接接受 `>=` 加环形计数器防死循环（j 一圈回到 i 即停）。
- 排序键 `(x,y)` 下 minX 有多个点时 Andrew 仍正确，但 Graham 的「极角排序 + 共线取最近」特判多——入门直接选 Andrew。

# 总结

- 叉积是计算几何的「与或非」：转向、面积、内外、共线全由这一个行列式派生——先用它想题，再动手写；
- 凸包双雄殊途同归：Graham 极角排序+弹栈、Andrew 字典序+上下壳，都是 O(n log n) 且灵魂同为「非左转即弹出」——Andrew 免三角函数、好写，默认选它；
- 旋转卡壳的加速秘诀与双指针同款：凸性保证对踵指针**只进不退**，环游一圈即拿到直径/宽度/外接矩形一族答案。
