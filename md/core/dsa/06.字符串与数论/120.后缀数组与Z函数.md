# 概述

字符串的两大「全局预处理」结构：**后缀数组 SA**——把所有后缀排序后记下出身（配合 LCP 数组，可解最长重复子串/任意两子串 LCS 等一族题，是全文索引的骨架）；**Z 函数**——`z[i]` = 后缀 `s[i..]` 与**全串**的最长公共前缀长度，KMP 的孪生兄弟，线性给出「模式对文本每个位置的前缀匹配长度」。二者都把「两两比较字符串」的暴力 O(n²) 压到 O(n log n) 或 O(n)。

**本篇收录**：后缀数组、LCP 数组、Z 函数

- 所属章节：[000.字符串与数论概述](./000.字符串与数论概述.md)

- 复杂度：后缀数组——倍增 O(n log²n)（模板好写）/ SA-IS O(n)（工业）；Kasai 建 LCP O(n)；Z 函数 O(n) 且 8 行。空间均 O(n)。
- 关联：Z 函数在线匹配见 [010.字符串匹配算法](./010.字符串匹配算法.md) 的 KMP；后缀数组 + RMQ → 任意两后缀 LCP 查询（稀疏表见 [03.树结构/070.线段树与树状数组](../03.树结构/070.线段树与树状数组.md)）；BWT 压缩（[10.应用与专题/010.无损压缩算法](../10.应用与专题/010.无损压缩算法.md)）直接建在排序后缀之上。
- 应用场景：搜索引擎倒排与全文索引（后缀数组=可压缩版后缀树的扁平化）、生物信息（重复序列/MUMmer 基因组比对核心就是 SA）、plagiarism 检测的最长公共片段、版本差异定位、字符串学竞赛题全家桶（不同子串数、k 小字典序子串）、数据压缩的 BWT/LZ 家族。

**动画：SA + LCP——排好的后缀队列，信息全在「邻居」里**
<!-- dsa.assets/suffix-z/suffix-array.gif -->

s=`banana$`（$ 为哨兵，最小字符）：

1. 列出 7 个后缀并排序：`$ < a$ < ana$ < anana$ < banana$ < na$ < nana$`；
2. SA 记排位→出身：`[6,5,3,1,0,4,2]`；
3. 关键观察：`a$` 与 `ana$` 是邻居，LCP=1；`ana$` 与 `anana$` 邻居 LCP=3——**任意两后缀的 LCP = 它们在 SA 区间上的相邻 LCP 最小值**（字典序夹逼），故只需存「相邻」n−1 个值：height=`[0,1,1,3,0,0,2]`；
4. 最长重复子串 = max(height) = 3（`ana`）；不同子串总数 = `Σ (n−SA[i] − height[i])`；
5. 排序若两两比串 O(n² log n)，用倍增「先排 2^k 长再排 2^(k+1) 长」压到 O(n log²n)——像 [02.基础算法/060.快速排序](../02.基础算法/060.快速排序.md) 数轮后的收敛级数。

**动画：Z 函数——[L,R] 最右匹配块的「借力 + 微调」**
<!-- dsa.assets/suffix-z/z-box.gif -->

s=`aabaaab`：

1. 定义 `z[0]=0`（约定），`z[i]` = s 与 s[i..] 的 LCP；期望答案含「模式=全串前缀」的自匹配视角；
2. 维护当前**伸到最右**的匹配块 `[L,R]`（i < R 时借用）：i 的信息向 `i−L` 处问——`z[i] ≥ min(z[i−L], R−i+1)`（块外的部分没验证过，裁到边界）；
3. 拿到下界后逐格外扩、朴素比较更新 [L,R]；
4. 演算：`a a b a a a b` → z=`[0,1,0,3,1,3,0]`；i=4 落在 [3,5] 内，镜像 z[1]=1、边界剩 2 → 下界 1，再外扩 0 格；
5. 用法：把模式 P 与文本 T 拼成 `P#T` 跑一遍 Z——文本位置 i 满足 `z[m+1+i] == m` 即 P 在 T[i] 完整出现：**不用失败指针的线性匹配**。

## Z 函数（8 行核心）

::: code-group

```java [Java]
static int[] zFunction(String s) {
    int n = s.length();
    int[] z = new int[n];
    for (int i = 1, l = 0, r = 0; i < n; i++) {
        if (i <= r) z[i] = Math.min(r - i + 1, z[i - l]);  // 借块内镜像的下界
        while (i + z[i] < n && s.charAt(z[i]) == s.charAt(i + z[i])) z[i]++;
        if (i + z[i] - 1 > r) { l = i; r = i + z[i] - 1; } // 刷新最右块
    }
    return z;                                  // z[0] 约定为 0（或 n 自匹配，看需求）
}

static List<Integer> zSearch(String text, String pat) {
    String comb = pat + "\0" + text;           // 哨兵必须不属于字母表
    int[] z = zFunction(comb);
    List<Integer> hits = new ArrayList<>();
    int m = pat.length();
    for (int i = m + 1; i < comb.length(); i++)
        if (z[i] == m) hits.add(i - m - 1);
    return hits;
}
```

```rust [Rust]
pub fn z_function(s: &[u8]) -> Vec<usize> {
    let n = s.len();
    let mut z = vec![0usize; n];
    let (mut l, mut r) = (0usize, 0usize);
    for i in 1..n {
        if i <= r {
            z[i] = (r - i + 1).min(z[i - l]);  // 镜像下界，裁到块右端
        }
        while i + z[i] < n && s[z[i]] == s[i + z[i]] {
            z[i] += 1;
        }
        if i + z[i] - 1 > r { l = i; r = i + z[i] - 1; }
    }
    z
}

pub fn z_search(text: &[u8], pat: &[u8]) -> Vec<usize> {
    let mut comb = pat.to_vec();
    comb.push(0);                               // 哨兵：不在字母表内
    comb.extend_from_slice(text);
    let z = z_function(&comb);
    let m = pat.len();
    (m + 1..comb.len()).filter(|&i| z[i] == m).map(|i| i - m - 1).collect()
}
```

```python [Python]
def z_function(s):
    n = len(s)
    z = [0] * n
    l = r = 0
    for i in range(1, n):
        if i <= r:
            z[i] = min(r - i + 1, z[i - l])    # 已验证区间的镜像下界
        while i + z[i] < n and s[z[i]] == s[i + z[i]]:
            z[i] += 1
        if i + z[i] - 1 > r:
            l, r = i, i + z[i] - 1
    return z                                   # z[0] 约定 0

def z_search(text, pat):
    """线性单模式匹配：P#T 的 Z 数组里 ==len(P) 的位置即命中"""
    comb = pat + "\0" + text
    z = z_function(comb)
    m = len(pat)
    return [i - m - 1 for i in range(m + 1, len(comb)) if z[i] == m]
```

## 后缀数组：倍增构造 + Kasai LCP

::: code-group

```java [Java]
// 倍增 O(n log² n)：每轮按 (rank[i], rank[i+k]) 二元组排序
static int[] buildSA(String s) {
    int n = s.length();
    Integer[] sa = new Integer[n];
    int[] rank = new int[n], tmp = new int[n];
    for (int i = 0; i < n; i++) { sa[i] = i; rank[i] = s.charAt(i); }
    for (int k = 1; ; k <<= 1) {
        final int kk = k;
        Comparator<Integer> cmp = (a, b) -> {
            if (rank[a] != rank[b]) return rank[a] - rank[b];
            int ra = a + kk < n ? rank[a + kk] : -1;
            int rb = b + kk < n ? rank[b + kk] : -1;
            return ra - rb;
        };
        java.util.Arrays.sort(sa, cmp);                       // 基数排序可提速到 O(n log n)
        tmp[sa[0]] = 0;
        for (int i = 1; i < n; i++)
            tmp[sa[i]] = tmp[sa[i - 1]] + (cmp.compare(sa[i - 1], sa[i]) < 0 ? 1 : 0);
        System.arraycopy(tmp, 0, rank, 0, n);
        if (rank[sa[n - 1]] == n - 1) break;                  // 名次互异 → 排定
    }
    int[] out = new int[n];
    for (int i = 0; i < n; i++) out[i] = sa[i];
    return out;
}

// Kasai O(n)：height[i] = LCP(SA[i-1].., SA[i]..)
static int[] buildLCP(String s, int[] sa) {
    int n = s.length();
    int[] rank = new int[n], h = new int[n];
    for (int i = 0; i < n; i++) rank[sa[i]] = i;
    int k = 0;
    for (int i = 0; i < n; i++) {
        if (k > 0) k--;                                   // 核心引理：LCP(i) ≥ LCP(i−1)−1
        if (rank[i] == 0) continue;
        int j = sa[rank[i] - 1];
        while (i + k < n && j + k < n && s.charAt(i + k) == s.charAt(j + k)) k++;
        h[rank[i]] = k;
    }
    return h;
}
```

```python [Python]
def build_sa(s):
    """倍增法 O(n log^2 n) 后缀数组"""
    n = len(s)
    sa = list(range(n))
    rank = [ord(c) for c in s]
    k = 1
    tmp = [0] * n
    while True:
        sa.sort(key=lambda i: (rank[i], rank[i + k] if i + k < n else -1))
        tmp[sa[0]] = 0
        for i in range(1, n):
            prev, cur = sa[i - 1], sa[i]
            key_p = (rank[prev], rank[prev + k] if prev + k < n else -1)
            key_c = (rank[cur], rank[cur + k] if cur + k < n else -1)
            tmp[cur] = tmp[prev] + (key_p != key_c)
        rank = tmp[:]
        if rank[sa[-1]] == n - 1:
            break
        k <<= 1
    return sa

def build_lcp(s, sa):
    """Kasai：height[rank] = LCP(sa[rank-1], sa[rank])，O(n)"""
    n = len(s)
    rank = [0] * n
    for i, p in enumerate(sa):
        rank[p] = i
    h, k = [0] * n, 0
    for i in range(n):
        if k:
            k -= 1
        r = rank[i]
        if r == 0:
            continue
        j = sa[r - 1]
        while i + k < n and j + k < n and s[i + k] == s[j + k]:
            k += 1
        h[r] = k
    return h

# 应用三连：
# 最长重复子串      → max(h) 对应 SA 邻对
# 不同子串总数      → sum(n - sa[i] - h[i])
# 两串最长公共子串  → 拼 s1 + sep + s2 建 SA+LCP，跨串邻对 LCP 取 max
```

```rust [Rust]
pub fn build_sa(s: &[u8]) -> Vec<usize> {
    let n = s.len();
    let mut sa: Vec<usize> = (0..n).collect();
    let mut rank: Vec<i32> = s.iter().map(|&c| c as i32).collect();
    let mut tmp = vec![0i32; n];
    let mut k = 1usize;
    loop {
        sa.sort_unstable_by_key(|&i| {
            (rank[i], if i + k < n { rank[i + k] } else { -1 })
        });
        tmp[sa[0]] = 0;
        for i in 1..n {
            let (prev, cur) = (sa[i - 1], sa[i]);
            let diff = rank[prev] != rank[cur]
                || (if prev + k < n { rank[prev + k] } else { -1 })
                != (if cur + k < n { rank[cur + k] } else { -1 });
            tmp[cur] = tmp[prev] + diff as i32;
        }
        rank.clone_from(&tmp);
        if rank[sa[n - 1]] == n as i32 - 1 { break; }
        k <<= 1;
    }
    sa
}
```

```typescript [TypeScript]
function buildSA(s: string): number[] {
  const n = s.length;
  let sa = Array.from({ length: n }, (_, i) => i);
  let rank = Array.from(s, c => c.charCodeAt(0));
  for (let k = 1; ; k <<= 1) {
    const key = (i: number): [number, number] =>
      [rank[i], i + k < n ? rank[i + k] : -1];
    sa.sort((a, b) => {
      const [a1, a2] = key(a), [b1, b2] = key(b);
      return a1 !== b1 ? a1 - b1 : a2 - b2;
    });
    const tmp = new Array<number>(n).fill(0);
    for (let i = 1; i < n; i++)
      tmp[sa[i]] = tmp[sa[i - 1]] + (key(sa[i - 1]).join() !== key(sa[i]).join() ? 1 : 0);
    rank = tmp;
    if (rank[sa[n - 1]] === n - 1) break;
  }
  return sa;
}
```

## 三工具一张选择表

| 需求 | 首选 | 理由 |
|------|------|------|
| 单模式在线匹配 | KMP / Z（`P#T`） | 线性、免排序 |
| 多模式一次扫 | [020.AC自动机与Manacher](./020.AC自动机与Manacher.md) AC | 文本单遍 |
| 任意子串问题（重复/LCS/不同子串数/k-th） | SA + LCP（+RMQ） | 后缀全序一网打尽 |
| 全文索引带定位/计数 | SA 二分模式区间 O(m log n) | 后缀树的扁平替代（内存 ~5n vs 数十n） |
| 动态文本（插入/修改） | 平衡树（rope/隐式 treap）或后缀自动机 | SA 重建代价高 |

- **SA 上二分**找模式 P 的出现区间：与 P 比后缀用 LCP 加速，区间长度即频次——「统计词频、前缀补全」的地基。
- **height + 稀疏表 RMQ**：任意两后缀 LCP 一次查询 O(1)；建 O(n log n)。
- **SA-IS**：线性时间工业实现（dc3/skew 也是 O(n)），库选型：divsufsort / sdsl。
- 同族高维选手 **后缀自动机 SAM**：识别全部子串的最小 DFA，O(n·σ) 空间解决「不同子串数/出现次数/首次位置」全家桶——比 SA 更动态，但更难入门。

## 常见陷阱

- 拼串分隔符必须**严格小于**所有字符且不属于字母表（`\0` 或哨兵 `$`）；忘加则 Z/KMP 跨界假命中（模式尾拼上文本头）。
- Z 函数借镜像时忘 `min(R−i+1, …)` 裁剪：块外信息未验证，直接抄会越界高估——这是 Z 版第一大错。
- 倍增排序用语言内建 sort（O(n log n) 比较）总复杂度多一个 log：n ≤ 2·10⁵ 无碍，更大上基数排序（按第二关键字桶排）才是 O(n log n)。
- Kasai 的 `if (k) k--` 引理（LCP(i) ≥ LCP(i−1)−1）忘写：退化成 O(n²) 且没人发现——它才是线性的全部原因。
- 哨兵取舍：SA 版里带不带 `$` 影响「后缀个数与空后缀」边界，height[0] 恒 0——两边定义全文统一。
- Unicode 串：按 code point 数组（`Array.from(s)` / `s.chars()`）建表，JS 直接 charCodeAt 会把代理对拆成两个「假字符」。

# 总结

- Z 函数是「KMP 的另一半灵魂」：不问「失配退哪里」，直接记下「每个位置和串头能拼多远」——`P#T` 一招还能反杀单模式匹配；
- 后缀数组把 n 个后缀排序这件「看似 O(n² log n)」的事做成 O(n log²n)，再配 Kasai 的 height——「后缀两两 LCP 全在相邻之间」这一压缩是字符串学的相对论；
- 工具谱系记忆：点查询用 KMP/Z，批量扫描用 AC，结构型问题（重复/计数/字典序第 k）用 SA(+RMQ)，动态文本用 SAM/rop——四档火力按「查询形态」选配。
