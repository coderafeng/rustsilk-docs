# 概述

扩展欧几里得（EXGCD）：在辗转相除的同时**回溯出贝祖系数**——求 `a·x + b·y = gcd(a,b)` 的一组整数解（贝祖恒等式保证有解）。它是「会记账的欧几里得」：普通 gcd 只留余数，EXGCD 把每步的商串起来，让最后的 gcd 沿原路**表出** a 与 b。由此直接解锁数论两连：解 `ax ≡ c (mod m)` 线性同余方程、求模逆元 `a⁻¹ mod m`——CRT 与 RSA 的原料。

- 所属章节：[000.字符串与数论概述](./000.字符串与数论概述.md)

- 时间复杂度：与 gcd 同级 O(log min(a,b))；空间 O(log n)（递归栈）或 O(1)（迭代）。
- 理论支点：贝祖定理（`∃x,y: ax+by=gcd`）＋解的结构（通解 `x + k·b/g, y − k·a/g`）。
- 应用场景：RSA 求私钥 `d = e⁻¹ mod φ(n)`（[09.密码学算法/020.RSA非对称加密](../09.密码学算法/020.RSA非对称加密.md)）、中国剩余定理合并同余式（日程/排班/大数重构）、组合数除法取模（逆元预处理）、有理数重构（Farey/连分数逼近）、解不定方程（丢番图凑钱问题）、密码协议中的模逆硬件单元。

1. 正向辗转（记下每步商）：`252 = 2·105 + 42`、`105 = 2·42 + 21`、`42 = 2·21 + 0` → gcd=21；
2. 从 gcd 起**沿原路回代**：`21 = 105 − 2·42`；
3. 把 `42 = 252 − 2·105` 代入：`21 = 105 − 2·(252 − 2·105) = −2·252 + 5·105`；
4. 读出系数 **x=−2, y=5**：`252·(−2) + 105·5 = −504 + 525 = 21` ✓；
5. 递归实现把这叠「代入展开」压成两条转移式：孩子返回 `(x',y')`，父亲算 `x = y'`、`y = x' − (a/b)·y'`——动画右侧寄存器同步更新；
6. 通解一族：`x = −2 + 5k, y = 5 + 12k`（k∈ℤ）——要最小非负 x 便取 k 调整（模 252/21=12 下 x≡3）。

# 详解

## 递归与迭代 EXGCD

::: code-group

```java [Java]
// 返回 [gcd, x, y] 使 a·x + b·y = gcd
static long[] exgcd(long a, long b) {
    if (b == 0) return new long[]{a, 1, 0};        // 基：a·1 + 0·0 = a
    long[] r = exgcd(b, a % b);
    long g = r[0], x1 = r[1], y1 = r[2];
    // 由 b·x1 + (a mod b)·y1 = g 推 a·(?) + b·(?) = g：
    // a mod b = a − (a/b)·b  ⇒ g = x1·b + y1·(a − (a/b)b) = y1·a + (x1 − (a/b)y1)·b
    return new long[]{g, y1, x1 - (a / b) * y1};   // x = y1, y = x1 − (a/b)·y1
}

// 迭代版（O(1) 空间，无爆栈之忧）
static long[] exgcdIter(long a, long b) {
    long old_r = a, r = b, old_s = 1, s = 0, old_t = 0, t = 1;
    while (r != 0) {
        long q = old_r / r;
        long tmp;
        tmp = old_r - q * r; old_r = r; r = tmp;          // 辗转
        tmp = old_s - q * s; old_s = s; s = tmp;          // x 系数随行
        tmp = old_t - q * t; old_t = t; t = tmp;          // y 系数随行
    }
    return new long[]{old_r, old_s, old_t};
}

static long modInverse(long a, long m) {            // a⁻¹ mod m（gcd=1 才有）
    long[] r = exgcd(a, m);
    if (r[0] != 1) throw new ArithmeticException("逆元不存在");
    return (r[1] % m + m) % m;
}
```

```rust [Rust]
/// 返回 (g, x, y)：a·x + b·y = g = gcd(a,b)
pub fn exgcd(a: i64, b: i64) -> (i64, i64, i64) {
    if b == 0 {
        (a, 1, 0)
    } else {
        let (g, x1, y1) = exgcd(b, a % b);
        (g, y1, x1 - (a / b) * y1)
    }
}

/// 迭代版 + 模逆
pub fn mod_inverse(a: i64, m: i64) -> Option<i64> {
    let (mut old_r, mut r) = (a, m);
    let (mut old_s, mut s) = (1i64, 0i64);
    while r != 0 {
        let q = old_r / r;
        let t1 = old_r - q * r; old_r = r; r = t1;
        let t2 = old_s - q * s; old_s = s; s = t2;
    }
    if old_r != 1 { return None; }
    Some(((old_s % m) + m) % m)
}
```

## 线性同余方程与 CRT

`a·x ≡ c (mod m)` 有解 ⇔ `g = gcd(a,m) | c`；解有 g 个模 m 不同余，通解 `x₀ + k·(m/g)`：

::: code-group

```java [Java]
static List<Long> solveLinearCongruence(long a, long c, long m) {
    long[] r = exgcd(a, m);
    long g = r[0], x0inv = r[1];
    if (c % g != 0) return List.of();                     // 无解
    long step = m / g;
    long x0 = BigInteger.valueOf(x0inv).multiply(
            BigInteger.valueOf(c / g)).mod(BigInteger.valueOf(m)).longValue();
    List<Long> sols = new ArrayList<>();
    for (long k = 0; k < g; k++) sols.add(Math.floorMod(x0 + k * step, m));
    return sols;                                           // g 个解
}

// CRT（模数两两互素）：x ≡ aᵢ (mod mᵢ) ⇒ x = Σ aᵢ·Mᵢ·(Mᵢ⁻¹ mod mᵢ) (mod M)
static long crt(long[] rem, long[] mod) {
    long M = 1;
    for (long m : mod) M *= m;
    long x = 0;
    for (int i = 0; i < mod.length; i++) {
        long Mi = M / mod[i];
        long inv = modInverse(Mi, mod[i]);                 // 互素保证存在
        x = (x + BigInteger.valueOf(rem[i]).multiply(
                BigInteger.valueOf(Mi).multiply(BigInteger.valueOf(inv)))
                .mod(BigInteger.valueOf(M)).longValue()) % M;
    }
    return (x % M + M) % M;
}
```

```python [Python]
def solve_congruence(a, c, m):
    """ax ≡ c (mod m) 的全部模 m 解"""
    g, x0, _ = exgcd(a, m)
    if c % g:
        return []                              # 无解
    step = m // g
    base = (x0 * (c // g)) % m
    return [(base + k * step) % m for k in range(g)]

def crt(remainders, moduli):
    """模数两两互素的 CRT；返回模 M 下的唯一解"""
    import math
    M = math.prod(moduli)
    x = 0
    for ai, mi in zip(remainders, moduli):
        Mi = M // mi
        x += ai * Mi * mod_inverse(Mi, mi)      # Mi 在模 mi 下的逆
    return x % M
# 例：x≡2(3), x≡3(5), x≡2(7) → crt([2,3,2],[3,5,7]) = 23
```

```rust [Rust]
/// ax ≡ c (mod m)：返回 g 个解（升序），无解返回 None
pub fn solve_congruence(a: i64, c: i64, m: i64) -> Option<Vec<i64>> {
    let (g, x0, _) = exgcd(a, m);
    if c % g != 0 { return None; }
    let step = m / g;
    let base = (((x0 as i128 * (c / g) as i128) % m as i128) + m as i128) as i64 % m;
    Some((0..g).map(|k| (base + k * step) % m).collect())
}
```


- **CRT 直觉**：`Mᵢ` 是「除 mᵢ 外全整除」的调频波，再乘逆元把第 i 维**校准**到余数 1、其余维仍为 0——逐条同余式各写各的位，相加即拼装答案（「物不知数」：三人同行七十稀、五树梅花廿一枝、七子团圆正半月、除百零五便得知）。
- 模数**不互素**的广义 CRT：两两合并 `x ≡ a1 (mod m1), x ≡ a2 (mod m2)` 有解 ⇔ `m1 ≡ m2 (mod gcd(m1,m2))`（即 a1≡a2 mod g），合并后模 lcm——用 EXGCD 求合并系数，过程同 090 的经典题。

## 逆元的三种算法怎么选

| 方法 | 条件 | 复杂度 | 备注 |
|------|------|:------:|------|
| EXGCD | gcd(a,m)=1 即可 | O(log m) | 通用、竞赛首选 |
| 费马小定理 `a^(m−2)` | **m 为素数** | O(log m) 模乘 | 配 [070.快速幂](./070.快速幂与模运算.md)；批量逆元线性递推 `inv[i] = (m − m/i)·inv[m%i] mod m` |
| 欧拉定理 `a^(φ(m)−1)` | gcd=1，已知 φ | O(log φ) | 理论意义为主 |

## 常见陷阱

- 递归 EXGCD 的转移方向写反（`x=x1−q·y1` 与 `x=y1` 混淆）——代一组小数值（252/105）手验；上面注释里给了完整推导，照抄前读懂。
- 逆元存在条件忘查：`gcd(a,m)≠1` 时 x0 是「半路答案」，不减校验直接用作 RSA d 会得到错误私钥。
- 负系数不调整：x0 常是负数，`x % m` 在 C 系语言可为负——统一 `(x % m + m) % m`。
- 溢出：`(a/b)·y1` 与 `x0·c/g` 两个乘法在 long 域都可能爆——中间量升 128 位或 BigInteger 再取模（示例已如此处理）。
- CRT 求和阶段逐项 mod M，否则 30 个 64 位模数连乘的 M² 项轻松溢出。
- 把「解的个数」记成 1：`gcd=g>1` 时模 m 下有 **g 个**不同余解（模 m/g 才是唯一）——输出全解别只报最小者。

# 总结

- EXGCD = 欧几里得+账本：正向辗转的每个商，反向把 gcd 表成 `ax+by`——转移式 `x=y', y=x'−⌊a/b⌋·y'` 值得手推一遍钉进肌肉记忆；
- 一次扩展三连跳：判 `ax≡c` 可解（g|c）、求逆元（g=1 时的 x）、拼 CRT（互素模数下的中国剩余）；
- 它是现代密码的螺丝钉：RSA 的 d、ECDSA 的模逆、同态加密的重缩放——全都跑在这三十行代码上。
