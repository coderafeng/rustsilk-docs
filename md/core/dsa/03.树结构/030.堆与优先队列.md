# 概述

堆是一棵**数组存储的完全二叉树**，满足**堆序性**：任意节点 ≤（或 ≥）其孩子。堆顶永远是全局最值，但堆**只保证局部偏序、不保证整体有序**——它是「随时取最值」的最经济结构，也是优先队列的标准底层。

**本篇收录**：二叉堆、二项堆、斐波那契堆

- 所属章节：[000.树结构概述](./000.树结构概述.md)

- 时间复杂度（二叉堆）：

  | 操作 | 复杂度 | 说明 |
  |------|:------:|------|
  | 取最值 peek | O(1) | 堆顶即答案 |
  | 插入 push | O(log n) | 尾部追加 + 上浮 |
  | 弹出 pop | O(log n) | 顶尾交换 + 下沉 |
  | 建堆 build | **O(n)** | 自底向上批量下沉，非 n 次插入的 O(n log n) |
  | 任意元素 decrease/increase-key | O(log n) | 需额外维护元素位置索引 |

- 空间复杂度：O(n)，且无指针开销——完全二叉树性质让父孩子下标关系固定：`parent = (i-1)/2`，`left = 2i+1`，`right = 2i+2`（0 起）或 `parent = i/2`，`left = 2i`，`right = 2i+1`（1 起）。
- 应用场景：
  - **各语言标准库**：Java `PriorityQueue`（小顶堆）、Rust `std::collections::BinaryHeap`（**默认大顶**）、Python `heapq`（**只有小顶**，取大顶存负数）、Go `container/heap`——C/C++ `std::priority_queue` 同理为大顶；
  - **Top K / 流式最大最小**：海量数据求前 K 大，维护大小为 K 的小顶堆 O(n log K)；
  - **调度**：Linux 进程调度、Netty/Node.js 定时器时间轮+堆、Dijkstra 与 Prim 的优先队列（斐波那契堆理论最优）；
  - **堆排序**（见 [070.堆排序](../02.基础算法/070.堆排序.md)）、合并 K 个有序链表（LeetCode 23）、中位数流（双堆对顶，LeetCode 295）。

<!-- dsa.assets/heap/heap-push-pop.gif -->

以小顶堆依次插入 `7, 2, 5, 1` 为例：

1. **尾部追加**：新元素放在数组末尾（保持完全二叉树形态），`[7, 2, 5, 1]`；
2. **上浮（sift-up）**：1 与父 7 比较，1 < 7 交换 → `[1, 2, 7, 5]`；再看 2 与其父 1，已满足，停止。上浮层数 ≤ 树高，O(log n)；
3. **弹出堆顶**：取走 1，把**末尾元素 5 放到堆顶**并缩短长度：`[5, 2, 7]`；
4. **下沉（sift-down）**：5 与两个孩子中**较小者** 2 交换 → `[2, 5, 7]`；5 已是叶子，停止。弹出后堆序性恢复。

建堆则是从最后一个非叶子节点开始**反向逐个下沉**，大部分节点只下沉 0~1 层，总代价 O(n)（推导见 [010.算法分析基础](../04.核心算法思想/010.算法分析基础.md)）。

# 详解

## 二叉堆实现

核心就两个动作：插入后**上浮**、弹出后**下沉**，全部在数组上完成。

```java [Java]
public class MinHeap {
    private final java.util.List<Integer> data = new java.util.ArrayList<>();

    public int size() { return data.size(); }

    public void push(int x) {
        data.add(x);
        siftUp(data.size() - 1);
    }

    public int pop() {
        if (data.isEmpty()) throw new java.util.EmptyStackException();
        int top = data.get(0);
        int last = data.remove(data.size() - 1);
        if (!data.isEmpty()) {
            data.set(0, last);
            siftDown(0);
        }
        return top;
    }

    private void siftUp(int i) {
        while (i > 0) {
            int p = (i - 1) / 2;
            if (data.get(p) <= data.get(i)) break;
            swap(p, i);
            i = p;
        }
    }

    private void siftDown(int i) {
        int n = data.size();
        while (true) {
            int smallest = i, l = 2 * i + 1, r = 2 * i + 2;
            if (l < n && data.get(l) < data.get(smallest)) smallest = l;
            if (r < n && data.get(r) < data.get(smallest)) smallest = r;
            if (smallest == i) break;
            swap(smallest, i);
            i = smallest;
        }
    }

    private void swap(int a, int b) {
        int t = data.get(a); data.set(a, data.get(b)); data.set(b, t);
    }
}
```

```rust [Rust]
#[derive(Default)]
pub struct MinHeap {
    data: Vec<i32>,
}

impl MinHeap {
    pub fn new() -> Self { Self::default() }
    pub fn size(&self) -> usize { self.data.len() }

    pub fn push(&mut self, x: i32) {
        self.data.push(x);
        self.sift_up(self.data.len() - 1);
    }

    pub fn pop(&mut self) -> Option<i32> {
        if self.data.is_empty() { return None; }
        let top = self.data[0];
        let last = self.data.pop().unwrap();
        if !self.data.is_empty() {
            self.data[0] = last;
            self.sift_down(0);
        }
        Some(top)
    }

    fn sift_up(&mut self, mut i: usize) {
        while i > 0 {
            let p = (i - 1) / 2;
            if self.data[p] <= self.data[i] { break; }
            self.data.swap(p, i);
            i = p;
        }
    }

    fn sift_down(&mut self, mut i: usize) {
        let n = self.data.len();
        loop {
            let (l, r) = (2 * i + 1, 2 * i + 2);
            let mut smallest = i;
            if l < n && self.data[l] < self.data[smallest] { smallest = l; }
            if r < n && self.data[r] < self.data[smallest] { smallest = r; }
            if smallest == i { break; }
            self.data.swap(smallest, i);
            i = smallest;
        }
    }
}
```

```typescript [TypeScript]
class MinHeap {
  private data: number[] = [];

  get size(): number { return this.data.length; }

  push(x: number): void {
    this.data.push(x);
    this.siftUp(this.data.length - 1);
  }

  pop(): number | undefined {
    if (!this.data.length) return undefined;
    const top = this.data[0];
    const last = this.data.pop()!;
    if (this.data.length) {
      this.data[0] = last;
      this.siftDown(0);
    }
    return top;
  }

  private siftUp(i: number): void {
    while (i > 0) {
      const p = (i - 1) >> 1;
      if (this.data[p] <= this.data[i]) break;
      [this.data[p], this.data[i]] = [this.data[i], this.data[p]];
      i = p;
    }
  }

  private siftDown(i: number): void {
    const n = this.data.length;
    for (;;) {
      const l = 2 * i + 1, r = 2 * i + 2;
      let smallest = i;
      if (l < n && this.data[l] < this.data[smallest]) smallest = l;
      if (r < n && this.data[r] < this.data[smallest]) smallest = r;
      if (smallest === i) break;
      [this.data[smallest], this.data[i]] = [this.data[i], this.data[smallest]];
      i = smallest;
    }
  }
}
```

## 建堆为什么是 O(n)

对高度为 `h` 的堆，第 `l` 层有 `2^l` 个节点、每个最多下沉 `h - l` 层，总代价 `\(\sum_{l=0}^{h} 2^l (h-l) = 2^{h+1} - h - 2 = O(n)\)`。直觉：一半节点是叶子根本不动，四分之一的节点只走 1 层——级数收敛到线性。对照 n 次独立插入的 O(n log n)，批量建堆节省一个 log 因子。

## 堆家族对比：二叉堆 / 二项堆 / 斐波那契堆

| 结构 | insert | find-min | delete-min | decrease-key | merge | 特点与用途 |
|------|:---:|:---:|:---:|:---:|:---:|-----------|
| 二叉堆 | O(log n) | O(1) | O(log n) | O(log n) | O(n) | 数组实现、缓存友好，**绝大多数场景的默认选择** |
| 二项堆 | O(log n) 摊还 | O(log n) | O(log n) | O(log n) | **O(log n)** | 由若干二项树 B₀..Bₖ 组成，merge 像二进制加法进位；历史上首个高效可合并堆 |
| 斐波那契堆 | **O(1)** 摊还 | O(1) | O(log n) 摊还 | **O(1)** 摊还 | O(1) 摊还 | 懒惰合并 + 度数坍缩；理论最优，常数大、指针开销重，Dijkstra/Prim 渐近加速的来源 |

斐波那契堆的价值集中在「decrease-key 极多」的图算法：`E` 条边做 `E` 次 decrease-key，二叉堆版 Dijkstra 是 O(E log V)，斐波那契版是 O(V log V + E)。但实测中因缓存不友好，朴素二叉堆往往更快——工程首选二叉堆/配对堆，斐波那契堆主要活在教科书与渐近分析里。

## 常见陷阱

- **方向默认值各语言不同**：Rust `BinaryHeap` 与 C++ `priority_queue` 是**大顶**；Java `PriorityQueue`、Python `heapq` 是**小顶**。Python 要大顶就存负数，Rust 要小顶用 `Reverse` 包装。
- **堆不是排序**：只保证「父 ≤ 子」，同层兄弟无序、数组整体无序；按序输出要反复 pop（即堆排序的代价 O(n log n)）。
- **弹出忘「尾顶交换」**：直接把堆顶删除会破坏完全二叉树形态，必须先让末尾元素补位再下沉。
- **build 用 n 次 push 是 O(n log n)**：批量给定时应自底向上下沉建堆（Python `heapq.heapify`、Rust 从 `Vec` 重建）。
- **Top K 用错堆向**：求前 K **大**要维护大小为 K 的**小**顶堆（堆顶是 K 个候选里最差的，才方便淘汰）。
- decrease-key 若元素在堆中位置未知，需要先 O(n) 查找——想要 O(log n) 必须额外维护「值 → 下标」索引（Dijkstra 惰性删除写法可回避：允许堆里有陈旧条目，弹出时校验）。

# 总结

- 二叉堆 = 数组上的完全二叉树 + 堆序性：peek O(1)、push/pop O(log n)、批量建堆 O(n)，是优先队列、Top K、调度和堆排序的共同底座；
- 上浮/下沉是它的两个原语，任何变体（可索引堆、惰性删除）都在围绕「定位元素」做文章；
- 二项堆解决了「快速 merge」，斐波那契堆把 insert/decrease-key 摊还到 O(1) 服务 Dijkstra 的渐近界——但工程默认仍是一枚小小的数组堆。
