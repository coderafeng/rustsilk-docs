# 概述

二叉树是每个节点**至多两个孩子**（左孩子、右孩子）的树形结构，是树算法的基石。遍历是按某种规则系统性访问每个节点恰好一次的过程——深度优先（前序/中序/后序）用栈或递归，广度优先（层序）用队列。

- 时间复杂度：四种遍历均为 O(n)；空间复杂度：递归深度 O(h)（最坏退化链 O(n)，完全二叉树 O(log n)），层序队列最宽 O(w)。
- 重要性质：
  - 第 `i` 层至多 `2^(i-1)` 个节点；深度 `h` 至多 `2^h - 1` 个节点；
  - 任意二叉树中**叶子数 = 度为 2 的节点数 + 1**（`n0 = n2 + 1`）；
  - 前序 + 中序（或后序 + 中序）可唯一确定一棵二叉树；前序 + 后序不行（无法区分单子树方向）；
  - 二叉搜索树的中序遍历是**有序序列**——这是中序最重要的用途。
- 应用场景：表达式求值（编译器 AST，中序即中缀表达式）、Huffman 编码（后序合并）、DOM/JSON/XML 树解析、文件系统目录（层序即列目录）、LeetCode 树题的通用框架；BFS 层序同时是最短路径搜索（无权图）的模板。

以下面这棵树为例：

```text
        1
      /   \
     2     3
    / \     \
   4   5     6
```

1. **前序（根→左→右）**：访问 1 → 进入左子树访问 2 → 4 → 5 → 回到根的另一侧访问 3 → 6，得 `1 2 4 5 3 6`。前序的第一个元素永远是**根**；
2. **中序（左→根→右）**：先一路走到最左 4 → 回溯访问 2 → 5 → 1 → 3 → 6，得 `4 2 5 1 3 6`。中序把根「夹」在左右子树之间——前序+中序即可切分出左右子树；
3. **后序（左→右→根）**：4 → 5 → 2 → 6 → 3 → 1，得 `4 5 2 6 3 1`。后序的第一个元素永远是**根**，适合「先处理孩子再汇总到父亲」的场景（求树高、删树、表达式求值）；
4. **层序（逐层从左到右）**：`1 → 2 3 → 4 5 6`。借助队列：弹出队首就 push 它的两个孩子，天然保证同层从左到右、层层推进。

# 详解

## 节点定义与递归三要素

遍历代码的骨架完全一致：「处理当前节点 / 递归左 / 递归右」的**顺序不同**产生不同遍历。处理语句放前面是前序、放中间是中序、放最后是后序。

::: code-group

```java [Java]
class TreeNode {
    int val;
    TreeNode left, right;
    TreeNode(int val) { this.val = val; }
}

// 前序：根 → 左 → 右
void preorder(TreeNode node, List<Integer> out) {
    if (node == null) return;          // 递归出口
    out.add(node.val);                 // 处理放最前
    preorder(node.left, out);
    preorder(node.right, out);
}

// 中序：左 → 根 → 右
void inorder(TreeNode node, List<Integer> out) {
    if (node == null) return;
    inorder(node.left, out);
    out.add(node.val);                 // 处理放中间
    inorder(node.right, out);
}

// 后序：左 → 右 → 根
void postorder(TreeNode node, List<Integer> out) {
    if (node == null) return;
    postorder(node.left, out);
    postorder(node.right, out);
    out.add(node.val);                 // 处理放最后
}
```

pub struct TreeNode {
    pub val: i32,
    pub left: Option<Box<TreeNode>>,
    pub right: Option<Box<TreeNode>>,

// 前序：根 → 左 → 右
pub fn preorder(node: &Option<Box<TreeNode>>, out: &mut Vec<i32>) {
    if let Some(n) = node {            // 递归出口 = None
        out.push(n.val);               // 处理放最前
        preorder(&n.left, out);
        preorder(&n.right, out);
    }
}

    }
}

    if let Some(n) = node {

        postorder(&n.right, out);

    }
}

def preorder(node, out: list[int]) -> None:

## 层序遍历（BFS）

层序是「队列弹一 push 二」的模板；`while` 内先记录当前队列长度，即把「一层」与「下一层」分开，这是所有「按层分组」类问题的通用写法。

::: code-group

```java [Java]
List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;
    Queue<TreeNode> queue = new ArrayDeque<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        int size = queue.size();                  // 关键：锁定本层节点数
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            level.add(node.val);
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        res.add(level);
    }
    return res;
}
```

```rust [Rust]
pub fn level_order(root: Option<Box<TreeNode>>) -> Vec<Vec<i32>> {
    use std::collections::VecDeque;
    let mut res = Vec::new();
    let mut queue = VecDeque::new();
    if let Some(r) = root { queue.push_back(r); }
    while !queue.is_empty() {
        let size = queue.len();                   // 锁定本层节点数
        let mut level = Vec::with_capacity(size);
        for _ in 0..size {
            let node = queue.pop_front().unwrap();
            level.push(node.val);
            if let Some(l) = node.left { queue.push_back(l); }
            if let Some(r) = node.right { queue.push_back(r); }
        }
        res.push(level);
    }
    res
}
```

```typescript [TypeScript]
function levelOrder(root: TreeNode | null): number[][] {
  const res: number[][] = [];
  if (!root) return res;
  const queue: TreeNode[] = [root];
  while (queue.length) {
    const size = queue.length;                   // 锁定本层节点数
    const level: number[] = [];
    for (let i = 0; i < size; i++) {
      const node = queue.shift()!;
      level.push(node.val);
      if (node.left) queue.push(node.left);
      if (node.right) queue.push(node.right);
    }
    res.push(level);
  }
  return res;
}
```

```python [Python]
from collections import deque

def level_order(root) -> list[list[int]]:
    res, queue = [], deque([root]) if root else deque()
    while queue:
        level = []
        for _ in range(len(queue)):     # 锁定本层节点数
            node = queue.popleft()
            level.append(node.val)
            if node.left: queue.append(node.left)
            if node.right: queue.append(node.right)
        res.append(level)
    return res
```

## 迭代写法与遍历选择

- DFS 迭代用**显式栈**：把「压栈顺序」调成右→左（弹出即左→右）可模拟前序；中序/后序迭代需要「回溯时已访问左子树」的状态标记，常用技巧是后序 = 前序(根右左) 的逆序。
- 递归过深的退化树（如链表状）会爆调用栈，工程上（浏览器 DOM 遍历、JSON 解析器）普遍用迭代 + 显式栈实现。
- 选型口诀：**复制树/序列化用前序；BST 取有序用中序；先子后父（删树、求高度、表达式求值）用后序；最短步数/按层处理用层序**。

## 常见陷阱

- **只有「前序+中序」或「后序+中序」能唯一还原二叉树**，中序是划分左右子树的唯一信息源；重建二叉树（剑指 Offer 07）核心就是「前序定根、中序定区间」。
- 层序遍历时忘记先 `queue.size()` 锁定层宽，直接 `while (!queue.isEmpty())` 会把整棵树混成一层。
- 递归出口判空遗漏：`node.left.val` 这类访问在单子树节点上会 NPE/panic。
- 求树高、直径等「汇总信息」要在**后序**位置计算（孩子结果已就绪），在前序位置算是经典错误。

# 总结

- 四种遍历是同一递归骨架的三种处理时机 + 一种队列 BFS，记住「前中后由处理语句位置决定，层序由队列保证逐层推进」；
- 前序定根、中序分边、后序汇总、层序按距离——选遍历方式本质是在选信息就绪的时机；
- 面试标配：四种递归信手拈来，层序带层分组，前中序互推能反推重建。
