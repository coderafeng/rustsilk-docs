# 概述

二叉搜索树（BST，Binary Search Tree）是在二叉树之上加了一条**有序不变式**的树：任一节点，左子树所有值 < 节点值 < 右子树所有值。查找时每一步都能扔掉一半子树，因此理想高度下三大操作（查/插/删）都是 O(log n)；但按有序序列逐个插入会**退化成链表**，这正是需要 [AVL/红黑树](./040.AVL树与红黑树.md) 的原因。

- 时间复杂度：

  | 操作 | 平均（树高 h ≈ log n） | 最坏（退化成链 h = n） |
  |------|:----:|:----:|
  | 查找 | O(log n) | O(n) |
  | 插入 | O(log n) | O(n) |
  | 删除 | O(log n) | O(n) |
  | 最大/最小 | O(log n) | O(n) |

- 空间复杂度：O(n)，递归辅助栈 O(h)
- 关键性质：**中序遍历输出升序序列**（见 [010.二叉树与遍历](./010.二叉树与遍历.md)）；任意子树也是 BST（递归结构）。
- 应用场景：数据库索引思想的起点（见 [PostgreSQL 索引](../../../database/postgresql/06.PostgreSQL%20索引/000.索引概述.md)）、内存有序集合的原型（Java `TreeMap`、C++ `std::map` 是其自平衡加强版）、动态有序统计（配合节点计数的 rank/select）、LeetCode 验证 BST（23）/最近公共祖先（235，利用有序性直接走二叉查找）。

- 所属章节：[000.树结构概述](./000.树结构概述.md)

依次插入 `50, 30, 70, 20, 40, 80` 后，查找并插入 42 的过程：

1. 从根 50 出发：42 < 50，**扔掉右半树**，走向左孩子 30；
2. 42 > 30，走向右孩子 40；
3. 42 > 40，应走向右孩子——右孩子为空，查找失败；
4. **插入即「查找失败的位置」**：把 42 挂在这个空位上，树保持有序不变式，全程路径长度 = 树高，未访问的节点一律不碰。

**动画：删除双子树节点——用后继替换**
<!-- dsa.assets/bst/bst-delete.gif -->

删除根节点 50（左右子树都非空）：

1. 在右子树找**最小节点**（中序后继）= 70 左下方的 80？不，沿左走到底：70 → 无左孩子，后继为 70；
2. 用 70 **覆盖**要删除的 50（节点本身不摘除，值被替换）；
3. 转为删除右子树里那个「原 70」节点——它至多只有一个右孩子 80，属于简单情形，直接摘除接上即可。

# 详解

## 结构与查找

BST 的查找就是「比较 → 决定往左还是往右 → 走到空为止」，递归/迭代各写一遍都要熟。

::: code-group

```java [Java]
class BstNode {
    int val;
    BstNode left, right;
    BstNode(int val) { this.val = val; }
}

// 迭代查找：命中返回节点，未命中返回 null
BstNode search(BstNode root, int target) {
    BstNode cur = root;
    while (cur != null) {
        if (target == cur.val) return cur;
        cur = target < cur.val ? cur.left : cur.right;
    }
    return null;
}
```

```rust [Rust]
#[derive(Debug, Default)]
pub struct BstNode {
    pub val: i32,
    pub left: Option<Box<BstNode>>,
    pub right: Option<Box<BstNode>>,
}

impl BstNode {
    /// 查找：命中返回节点引用
    pub fn search<'a>(&'a self, target: i32) -> Option<&'a Self> {
        if target == self.val {
            return Some(self);
        }
        let child = if target < self.val { &self.left } else { &self.right };
        child.as_ref().and_then(|n| n.search(target))
    }
}
```

```typescript [TypeScript]
class BstNode {
  val: number;
  left: BstNode | null = null;
  right: BstNode | null = null;
  constructor(val: number) { this.val = val; }
```

```python [Python]
class BstNode:
    def __init__(self, val: int):
        self.val = val
```

## 插入

「查找失败点即插入点」，迭代版天然拿到父节点引用：

::: code-group

```java [Java]
BstNode insert(BstNode root, int val) {
    if (root == null) return new BstNode(val);
    BstNode cur = root, parent = null;
    while (cur != null) {
        if (val == cur.val) return root;       // 去重：忽略相同键
        parent = cur;
        cur = val < cur.val ? cur.left : cur.right;
    }
    if (val < parent.val) parent.left = new BstNode(val);
    else parent.right = new BstNode(val);
    return root;
}
```

```rust [Rust]
impl BstNode {
    /// 插入（相同值忽略），Rust 用递归 + Option 替换语义
    pub fn insert(node: &mut Option<Box<BstNode>>, val: i32) {
        match node {
            None => *node = Some(Box::new(BstNode { val, ..Default::default() })),
            Some(n) if val == n.val => {}      // 去重
            Some(n) => {
                if val < n.val { Self::insert(&mut n.left, val); }
                else { Self::insert(&mut n.right, val); }
            }
        }
    }
}
```

```typescript [TypeScript]
function insert(root: BstNode | null, val: number): BstNode {
  if (!root) return new BstNode(val);
  let cur = root, parent: BstNode | null = null;
  while (cur) {
    if (val === cur.val) return root;          // 去重
    parent = cur;
    cur = val < cur.val ? cur.left : cur.right;
  }
  const node = new BstNode(val);
  if (val < parent!.val) parent!.left = node;
  else parent!.right = node;
  return root;
}
```

```python [Python]
def insert(root, val: int):
    """插入（相同值忽略），返回根"""
    if root is None:
        return BstNode(val)
    cur, parent = root, None
    while cur:
        if val == cur.val:
            return root                        # 去重
        parent = cur
        cur = cur.left if val < cur.val else cur.right
    if val < parent.val:
        parent.left = BstNode(val)
    else:
        parent.right = BstNode(val)
    return root
```

## 删除：三种情形

删除是 BST 的重头戏，按被删节点的孩子数分类：

1. **叶子**：直接摘除；
2. **只有一个孩子**：孩子顶替自己的位置（类似链表删节点）；
3. **有两个孩子**：用**右子树最小节点（中序后继）**或左子树最大节点（前驱）替换其值，把问题转化为「删除那个后继/前驱」——后继至多有一个右孩子，必落入情形 1/2。

::: code-group

```java [Java]
BstNode delete(BstNode root, int val) {
    if (root == null) return null;
    if (val < root.val) {
        root.left = delete(root.left, val);
    } else if (val > root.val) {
        root.right = delete(root.right, val);
    } else {
        // 命中：情形 1/2 —— 至多一个孩子，孩子直接顶替
        if (root.left == null) return root.right;
        if (root.right == null) return root.left;
        // 情形 3：找右子树最小节点（后继）
        BstNode succ = root.right, succParent = root;
        while (succ.left != null) {
            succParent = succ;
            succ = succ.left;
        }
        root.val = succ.val;                   // 值覆盖
        // 删除原后继：后继至多有右孩子；后继是 root.right 时要接右链
        if (succParent == root) succParent.right = succ.right;
        else succParent.left = succ.right;
    }
    return root;
}
```

```rust [Rust]
// Rust 的所有权使删除样板代码很重，工程上常用索引式（Arena）BST。
// 这里给出概念版：递归返回「删除后的子树」
impl BstNode {
    fn find_min(node: &Box<BstNode>) -> i32 {
        match &node.left {
            Some(l) => Self::find_min(l),
            None => node.val,
        }
    }
    fn remove(node: &mut Option<Box<BstNode>>, val: i32) {
        let Some(n) = node.as_deref_mut() else { return };
        if val < n.val {
            Self::remove(&mut n.left, val);
        } else if val > n.val {
            Self::remove(&mut n.right, val);
        } else {
            match (&n.left, &n.right) {
                (None, _) => { let r = std::mem::take(&mut n.right); *node = r; }
                (_, None) => { let l = std::mem::take(&mut n.left); *node = l; }
                _ => {
                    let succ = Self::find_min(&n.right.clone().unwrap());
                    n.val = succ;
                    Self::remove(&mut n.right, succ);   // 转成删后继
                }
            }
        }
    }
}
```

```typescript [TypeScript]
function remove(root: BstNode | null, val: number): BstNode | null {
  if (!root) return null;
  if (val < root.val) {
    root.left = remove(root.left, val);
  } else if (val > root.val) {
    root.right = remove(root.right, val);
  } else {
    if (!root.left) return root.right;         // 情形 1/2
    if (!root.right) return root.left;
    // 情形 3：后继上移
    let succ = root.right, succParent = root;
    while (succ.left) { succParent = succ; succ = succ.left; }
    root.val = succ.val;
    if (succParent === root) succParent.right = succ.right;   // 后继就是右孩子本人
    else succParent.left = succ.right;
  }
  return root;
}
```

```python [Python]
def remove(root, val: int):
    if root is None:
        return None
    if val < root.val:
        root.left = remove(root.left, val)
    elif val > root.val:
        root.right = remove(root.right, val)
    else:
        if root.left is None: return root.right   # 情形 1/2
        if root.right is None: return root.left
        # 情形 3：用后继覆盖，再删后继
        succ, succ_parent = root.right, root
        while succ.left:
            succ_parent, succ = succ, succ.left
        root.val = succ.val
        if succ_parent is root:
            succ_parent.right = succ.right     # 后继就是右孩子本人
        else:
            succ_parent.left = succ.right
    return root
```

:::

> 特判「后继恰是 `root.right`（右子树没有左链）」是删除最高频的 bug：此时被删后继挂在**右链**上，必须写 `succParent.right = succ.right`；若统一写成 `.left` 会把左子树整个覆盖掉。写完务必用 `{50,30,70,80}` 这棵树测一遍删除 50。

## 常见陷阱

- **有序数据插入导致退化**：依次插入 1,2,3,…,n 得到一条右链，所有操作变 O(n)。生产环境因此几乎不裸用 BST，而是 AVL/红黑树/Splay；随机数据插入的期望树高约 `4.3 log₂ n`，尚可接受。
- **删除双子树节点时「摘出后继节点再拼回树」是错的**——正确姿势是**值覆盖** + 删除后继（把问题降维），别尝试搬动整个子树。
- 验证 BST（LeetCode 98）不能只比较「节点 vs 直接孩子」，要用**中序递增**或**上下界递归**——祖父节点的约束会传递下来。
- 允许重复键时要固定约定「等于走左还是走右」，否则删除找后继可能漏掉重复值。
- 递归版 insert/delete 每层都重新赋值指针（`root.left = insert(...)`），忘记返回值接回会丢子树。

# 总结

- BST 用「左小右大」不变式把查找变成每步减半的二分，平均 O(log n)，中序即有序；
- 插入 = 查找失败点挂新节点；删除双子树节点 = 后继值覆盖 + 删后继（必然降维为单孩子情形）；
- 裸 BST 的致命伤是有序输入退化成链——需要严格平衡时升级到 [AVL/红黑树](./040.AVL树与红黑树.md)，需要磁盘友好时升级到 [B/B+ 树](./050.B树与B+树.md)。
