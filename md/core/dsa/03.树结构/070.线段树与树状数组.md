# 概述

[前缀和](../02.基础算法/190.前缀和与差分.md) 只能「静态数组任意查、改一次全重建」。当**修改与区间查询交错出现**（动态区间统计），需要能增量维护的结构：线段树用一棵覆盖所有区间的二叉树做到「任意区间查询 + 单点/区间修改」皆 O(log n)；树状数组（Fenwick Tree/BIT）用 lowbit 把同样的事做得更省——代码一行、空间一半，代价是只擅长前缀型查询。

**本篇收录**：线段树、树状数组（Fenwick）

- 所属章节：[000.树结构概述](./000.树结构概述.md)

- 时间复杂度：

  | 操作 | 线段树 | 树状数组 |
  |------|:------:|:------:|
  | 单点改 + 前缀/区间查 | O(log n) | O(log n)（代码更短） |
  | 任意结合运算区间查（max/min/gcd） | O(log n) | 仅可逆运算（和/异或）才行 |
  | 区间改 + 区间查 | O(log n)（懒标记） | O(log n)（双 BIT 技巧） |
  | 建表 | O(n) | O(n) |

- 空间复杂度：线段树开 `4n`；树状数组 `n+1`
- 应用场景：逆序对计数（BIT 数经典）、动态排名/频数（值域树状数组）、股票/K 线区间聚合统计、计算几何扫描线（线段树 + 懒标记求覆盖长度）、CPU 缓存/内存区间分配管理、竞赛与引擎里的「区间和/区间最值 + 在线修改」全家桶；离线分治（CDQ）也建立在 BIT 上。

**动画：线段树查询区间 [1,4) 命中哪些节点**
<!-- dsa.assets/segment-tree/seg-build-query.gif -->

对 `a = [5, 8, 6, 3, 2, 7, 2, 6]`：

1. **建树**：区间 `[0,8)` 二分，左半 `[0,4)`、右半 `[4,8)` 各自继续，直到叶子 `[i,i+1)` 存 `a[i]`；父亲 = 两个孩子合并（求和/取 max）——完全二叉树存成数组 `tree[i<<1 | 0/1]`；
2. **查询 `[1,4)`**：从根开始，查询区间**完整覆盖**节点区间就直接采用该节点值并停止下探；
3. 只覆盖一部分就递归左右孩子：`[1,4)` 拆成 `[1,2) [2,4)`——分别命中叶子 8 和节点 `[2,4)`=9，合并得 17；
4. 采用节点的个数 ≤ 2 层各若干个，总计 O(log n)——这就是「区间查询 log 级」的来源；单点修改同理沿一条路径回溯更新 O(log n)。

**动画：树状数组的 lowbit 领地**
<!-- dsa.assets/bit/bit-lowbit.gif -->

`tree[i]` 负责「长度 = lowbit(i)」的左闭右开小段（如 `i=6(110₂)` 管 `[4,6)`，`i=8(1000₂)` 管 `[0,8)`）：

1. **前缀和 `sum(6)`**：把 6 按二进制拆段——`6 → 6-2=4 → 4-4=0`，沿途累加 `tree[6] + tree[4]`，每步抹掉一个 1 bit，至多 log n 步；
2. **单点 +v**：`i += lowbit(i)` 沿「谁的领地包含我」向上全部加 v——`i=3` 影响 `tree[4], tree[8]…`；
3. 线段树与树状数组的分工：可逆运算（和/异或）用 BIT 简洁快速；不可逆结合运算（min/max/gcd）或复杂合并（带信息统计）用线段树。

# 详解

## 树状数组：一行 lowbit

`lowbit(i) = i & (-i)`（补码即取反加一，只保留最低位的 1）。约定下标从 **1** 开始。

::: code-group

```java [Java]
public class Fenwick {
    private final long[] tree;                 // 1-based
    public Fenwick(int n) { tree = new long[n + 1]; }

    private static int lowbit(int i) { return i & -i; }

    // O(n) 建表：tree[i] 先放 a[i-1]，再按低位向父段累加
    public Fenwick(long[] a) {
        this(a.length);
        for (int i = 1; i <= a.length; i++) tree[i] += a[i - 1];
        for (int i = 1; i <= a.length; i++) {
            int j = i + lowbit(i);
            if (j <= a.length) tree[j] += tree[i];
        }
    }

    public void add(int i, long delta) {       // 单点 +delta
        for (; i < tree.length; i += lowbit(i)) tree[i] += delta;
    }

    public long sum(int i) {                   // 前缀和 [1..i]
        long s = 0;
        for (; i > 0; i -= lowbit(i)) s += tree[i];
        return s;
    }

    public long rangeSum(int l, int r) { return sum(r) - sum(l - 1); }  // 闭区间
}
```

```rust [Rust]
pub struct Fenwick {
    tree: Vec<i64>,
}

impl Fenwick {
    pub fn new(n: usize) -> Self { Self { tree: vec![0; n + 1] } }

    fn lowbit(i: usize) -> usize { i & i.wrapping_neg() }

    /// 单点 +delta（1-based）
    pub fn add(&mut self, mut i: usize, delta: i64) {
        let n = self.tree.len() - 1;
        while i <= n {
            self.tree[i] += delta;
            i += Self::lowbit(i);
        }
    }

    /// 前缀和 [1..i]
    pub fn sum(&self, mut i: usize) -> i64 {
        let mut s = 0;
        while i > 0 {
            s += self.tree[i];
            i -= Self::lowbit(i);
        }
        s
    }

    /// 闭区间 [l, r]
    pub fn range_sum(&self, l: usize, r: usize) -> i64 {
        self.sum(r) - self.sum(l - 1)
    }
}
```

### 应用：逆序对

从左到右把每个数 `x` 作为「值域下标」`add(x, 1)`，则「已出现且 > x 的个数」= `sum(n) - sum(x)`——一次遍历得逆序对总数 O(n log n)；同法可求「元素右侧更小/更大计数」（LeetCode 315）。

### 应用：区间改 + 区间查（双 BIT）

对差分 `d` 建两棵 BIT 维护 `Σd[i]` 与 `Σi·d[i]`，即可由 `prefix(x) = x·sum(B1,x) - sum(B2,x)` 还原前缀和，做到「区间加 + 区间和查询」双 O(log n)——比线段树懒标记短一半的代码。

## 线段树：任意结合运算的区间维护

节点管区间 `[l, r)`，数组存储（`i` 的孩子是 `2i, 2i+1`），大小开 `4n`。模板以「区间和」为例，把 `merge` 换成 `max`/`gcd` 即得其它运算——**这是它强于 BIT 的地方**。

::: code-group

```java [Java]
public class SegmentTree {
    private final long[] tree;
    private final int n;

    public SegmentTree(long[] a) {
        n = a.length;
        tree = new long[4 * n];
        build(a, 1, 0, n);
    }

    private void build(long[] a, int i, int l, int r) {
        if (r - l == 1) { tree[i] = a[l]; return; }
        int mid = (l + r) >>> 1;
        build(a, 2 * i, l, mid);
        build(a, 2 * i + 1, mid, r);
        tree[i] = tree[2 * i] + tree[2 * i + 1];     // merge
    }

    public void update(int idx, long val) { update(1, 0, n, idx, val); }

    private void update(int i, int l, int r, int idx, long val) {
        if (r - l == 1) { tree[i] = val; return; }
        int mid = (l + r) >>> 1;
        idx < mid ? update(2 * i, l, mid, idx, val)
                  : update(2 * i + 1, mid, r, idx, val);
        tree[i] = tree[2 * i] + tree[2 * i + 1];
    }

    public long query(int ql, int qr) { return query(1, 0, n, ql, qr); }

    private long query(int i, int l, int r, int ql, int qr) {
        if (qr <= l || r <= ql) return 0;            // 无交集
        if (ql <= l && r <= qr) return tree[i];      // 全包含，直接采用
        int mid = (l + r) >>> 1;
        return query(2 * i, l, mid, ql, qr) + query(2 * i + 1, mid, r, ql, qr);
    }
}
```

```rust [Rust]
pub struct SegmentTree {
    tree: Vec<i64>,
    n: usize,
}

impl SegmentTree {
    pub fn new(a: &[i64]) -> Self {
        let n = a.len();
        let mut t = Self { tree: vec![0; 4 * n], n };
        t.build(a, 1, 0, n);
        t
    }

    fn build(&mut self, a: &[i64], i: usize, l: usize, r: usize) {
        if r - l == 1 { self.tree[i] = a[l]; return; }
        let mid = (l + r) / 2;
        self.build(a, 2 * i, l, mid);
        self.build(a, 2 * i + 1, mid, r);
        self.tree[i] = self.tree[2 * i] + self.tree[2 * i + 1];
    }

    pub fn update(&mut self, idx: usize, val: i64) {
        self.update_(1, 0, self.n, idx, val);
    }

    fn update_(&mut self, i: usize, l: usize, r: usize, idx: usize, val: i64) {
        if r - l == 1 { self.tree[i] = val; return; }
        let mid = (l + r) / 2;
        if idx < mid { self.update_(2 * i, l, mid, idx, val); }
        else { self.update_(2 * i + 1, mid, r, idx, val); }
        self.tree[i] = self.tree[2 * i] + self.tree[2 * i + 1];
    }

    pub fn query(&self, ql: usize, qr: usize) -> i64 {
        self.query_(1, 0, self.n, ql, qr)
    }

    fn query_(&self, i: usize, l: usize, r: usize, ql: usize, qr: usize) -> i64 {
        if qr <= l || r <= ql { return 0; }
        if ql <= l && r <= qr { return self.tree[i]; }
        let mid = (l + r) / 2;
        self.query_(2 * i, l, mid, ql, qr) + self.query_(2 * i + 1, mid, r, ql, qr)
    }
}
```

```typescript [TypeScript]
class SegmentTree {
  private tree: number[];
  private n: number;

  constructor(a: number[]) {
    this.n = a.length;
    this.tree = new Array(4 * this.n).fill(0);
    this.build(a, 1, 0, this.n);
  }

  private merge(x: number, y: number) { return x + y; }   // 换成 Math.max 即区间最值

  private build(a: number[], i: number, l: number, r: number): void {
    if (r - l === 1) { this.tree[i] = a[l]; return; }
    const mid = (l + r) >> 1;
    this.build(a, 2 * i, l, mid);
    this.build(a, 2 * i + 1, mid, r);
    this.tree[i] = this.merge(this.tree[2 * i], this.tree[2 * i + 1]);
  }

  update(idx: number, val: number): void { this.update_(1, 0, this.n, idx, val); }

  private update_(i: number, l: number, r: number, idx: number, val: number): void {
    if (r - l === 1) { this.tree[i] = val; return; }
    const mid = (l + r) >> 1;
    idx < mid ? this.update_(2 * i, l, mid, idx, val)
              : this.update_(2 * i + 1, mid, r, idx, val);
    this.tree[i] = this.merge(this.tree[2 * i], this.tree[2 * i + 1]);
  }

  /** 半开区间 [ql, qr) */
  query(ql: number, qr: number): number { return this.query_(1, 0, this.n, ql, qr); }

  private query_(i: number, l: number, r: number, ql: number, qr: number): number {
    if (qr <= l || r <= ql) return 0;
    if (ql <= l && r <= qr) return this.tree[i];
    const mid = (l + r) >> 1;
    return this.merge(this.query_(2 * i, l, mid, ql, qr),
                      this.query_(2 * i + 1, mid, r, ql, qr));
  }
}
```

```python [Python]
class SegmentTree:
    def __init__(self, a: list[int]):
        self.n = len(a)
        self.tree = [0] * (4 * self.n)
        self._build(a, 1, 0, self.n)

    def _merge(self, x, y):
        return x + y                                  # 换成 max 即区间最值

    def _build(self, a, i, l, r):
        if r - l == 1:
            self.tree[i] = a[l]
            return
        mid = (l + r) >> 1
        self._build(a, 2 * i, l, mid)
        self._build(a, 2 * i + 1, mid, r)
        self.tree[i] = self._merge(self.tree[2 * i], self.tree[2 * i + 1])

    def update(self, idx: int, val: int) -> None:
        self._update(1, 0, self.n, idx, val)

    def _update(self, i, l, r, idx, val):
        if r - l == 1:
            self.tree[i] = val
            return
        mid = (l + r) >> 1
        self._update(2 * i if idx < mid else 2 * i + 1,
                     l if idx < mid else mid,
                     mid if idx < mid else r, idx, val)
        self.tree[i] = self._merge(self.tree[2 * i], self.tree[2 * i + 1])

    def query(self, ql: int, qr: int) -> int:
        """半开区间 [ql, qr)"""
        return self._query(1, 0, self.n, ql, qr)

    def _query(self, i, l, r, ql, qr):
        if qr <= l or r <= ql:
            return 0
        if ql <= l and r <= qr:
            return self.tree[i]
        mid = (l + r) >> 1
        return self._merge(self._query(2 * i, l, mid, ql, qr),
                           self._query(2 * i + 1, mid, r, ql, qr))
```

### 区间修改：懒标记（Lazy Propagation）

给节点加 `lazy[i]`：区间 `[ql,qr)` 全覆盖节点时**不递归下压**，就地合并并记欠账；之后任何人路过该节点才把欠账「pushdown」给两个孩子。口诀：**改时全停、查时补账**，维持每次操作 O(log n)。（代码较长，掌握模板套路后可在竞赛平台对照验证。）

## 常见陷阱

- **BIT 必须 1-based**：下标 0 时 `i += lowbit(i)` 死循环（lowbit(0)=0）；映射数组下标记得 +1。
- **BIT 只适合可逆运算**：`range = sum(r) - sum(l-1)` 需要减法逆元——区间 min/max 查询用 BIT 做不出来（单点修改的区间 max 只可特殊写法），直接上线段树。
- 线段树数组开 **4n** 不是 2n：n 非 2 的幂时完全二叉树补位会超 2n；`2n` 只在迭代式（zkw）写法下成立。
- 懒标记忘 pushdown 顺序错：查询/修改递归进入孩子前必须先下压，否则孩子读到过期值；「改时全停、查时补账」不能只对一半。
- 值域巨大但稀疏（如 1~1e9 的排名）：先离散化再上 BIT/线段树，或直接用动态开点线段树。

# 总结

- 线段树 = 「区间完全二叉树 + 任意结合运算合并」，配懒标记后区间改/区间查全 O(log n)，是动态区间统计的万能模板；
- 树状数组 = lowbit 领地划分，用最短代码吃下「可逆运算的前缀/区间和」，逆序对、值域计数等场景性价比碾压线段树；
- 选型直觉：前缀/差分可逆 → BIT；min/max/gcd/复杂合并 → 线段树；静态无修改 → 回到 [前缀和与差分](../02.基础算法/190.前缀和与差分.md) 就够了。
