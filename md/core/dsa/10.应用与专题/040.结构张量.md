# 概述

给定一幅灰度图，如何用一个 \(2\times2\) 的小矩阵同时回答三个问题：**这里有没有角点？边缘往哪个方向？结构强不强？** 结构张量（Structure Tensor，又称 Second Moment Matrix / Gradient Structure Tensor）就是这台「局部结构测量仪」。它把梯度 \((I_x, I_y)\) 这指向量在外积意义下「二次化」成对称矩阵，再高斯加权平铺求和，得到描述某像素邻域**方向能量分布**的张量：

\[
M = G_\sigma * \begin{pmatrix} I_x^2 & I_x I_y\\ I_x I_y & I_y^2 \end{pmatrix}
= \begin{pmatrix} \sum w\, I_x^2 & \sum w\, I_x I_y\\ \sum w\, I_x I_y & \sum w\, I_y^2 \end{pmatrix}
\]

对它做特征分解 \(\lambda_1 \ge \lambda_2 \ge 0\)：特征值是「两个正交方向上的梯度能量」，特征向量是「主导结构方向」。平坦区 \(\lambda\) 双小、边缘区一大一小、角点区两大——**Harris 角点、Shi-Tomasi、相干性（coherence）、orientation 估计**全是它的不同读法。它也是光流（Lucas-Kanade）、去噪（NLME/Coherence-enhancing）、脊线增强（指纹）等地基。

- 所属章节：[000.应用与专题概述](./000.应用与专题概述.md)
- 时间复杂度：梯度 \(O(n)\) + 逐像素 \(2\times2\) 加权和 \(O(n\cdot k^2)\)（\(k\) 为窗口，可分离高斯降为 \(O(n\cdot k)\)）；特征分解每点常数 \(O(1)\)（\(2\times2\) 闭式解）
- 空间复杂度：\(O(n)\)（\(M_{11},M_{12},M_{22}\) 三个累加通道）
- 应用场景：Harris/Shi-Tomasi 角点检测、指纹/血管脊线增强、相干性去噪、光流结构化张量、医学图像方向分析
- 关联：梯度算子见 [07.数值计算](../07.数值计算/000.数值计算概述.md) 的差分；它直接孵化 [050.特征提取算法](./050.特征提取算法.md)

1. 张量 \(M\) 是 \(2\times2\) 实对称矩阵，半正定 → 总可写成椭圆：长轴沿主特征向量 \(e_1\)、半轴长 \(\propto 1/\sqrt{\lambda_1}\)，短轴沿 \(e_2\)。椭圆「扁」= 结构强且方向明确；「圆而小」= 平坦；「圆而大」= 各向同性角点。
2. **平坦区**（纯色墙）：\(I_x=I_y=0\) → \(M=\begin{pmatrix}0&0\\0&0\end{pmatrix}\)，\(\lambda_1=\lambda_2=0\)，无椭圆。
3. **边缘区**（竖直边缘，左右有梯度、上下无）：\(I_x\ne0,I_y=0\) → 邻域里 \(M\approx\begin{pmatrix}a&0\\0&0\end{pmatrix}\)，\(\lambda_1=a,\lambda_2=0\)，退化成一个**线段**，方向垂直边缘（即梯度方向）。
4. **角点区**（十字交界）：两个方向都有强梯度 → \(\lambda_1\approx\lambda_2\gg0\)，张量近似各向同性，画成**圆**。
5. 可验小例：窗口内只有两个像素，梯度分别 \((1,0)\) 与 \((0,1)\)，等权 → \(M=\begin{pmatrix}1&0\\0&1\end{pmatrix}\)，\(\lambda_1=\lambda_2=1\)（角点，各向同性）；若两者都是 \((1,0)\) → \(M=\begin{pmatrix}2&0\\0&0\end{pmatrix}\)，\(\lambda=(2,0)\)（边缘，单一方向）。

# 详解

## 从梯度到张量：为什么要「外积 + 平滑」

单像素梯度 \(\nabla I = (I_x, I_y)\) 有方向无「结构」——它告诉你最陡上升方向，却不告诉你邻域里梯度是否**一致**。把梯度外积自己：

\[
\nabla I \, \nabla I^{\top} = \begin{pmatrix} I_x^2 & I_x I_y\\ I_x I_y & I_y^2 \end{pmatrix}
\]

得到逐像素的「方向能量张量」：对角元是两轴梯度能量、非对角是相关性。再高斯平滑（window \(w\)）就得到结构张量 \(M\)。它的二次型有直接几何意义——沿单位向量 \(v\) 的邻域方向梯度能量为：

\[
E(v) = v^{\top} M v = \sum_{\text{window}} w\,(v\cdot\nabla I)^2
\]

使 \(E(v)\) 最大/最小的 \(v\) 正是特征向量 \(e_1/e_2\)，极值为 \(\lambda_1/\lambda_2\)。所以「椭圆」就是 \(E(v)=1\) 的水平集 \(\{v : v^{\top}Mv = 1\}\)。

## \(2\times2\) 特征值的闭式解

对称矩阵特征值无需迭代，直接：

\[
\lambda_{1,2} = \frac{T \pm \sqrt{T^2 - 4D}}{2}, \qquad T = M_{11}+M_{22}\ (\text{迹}),\ D = M_{11}M_{22}-M_{12}^2\ (\text{行列式})
\]

主特征向量（\(\lambda_1\) 对应）：当 \(M_{12}\ne0\) 时 \(e_1 \propto (\lambda_1 - M_{22},\; M_{12})\)，否则取坐标轴。工程上常直接算**方向角** \(\theta = \mathrm{atan2}(e_{1y}, e_{1x})\)。判别 Harris 只需 \(T,D\)：响应 \(R = D - k T^2\)（\(k\approx0.04\text{–}0.06\)），\(R>0\) 角点、\(R<0\) 边缘、\(|R|\) 小平坦——**全程不开方不求特征向量**，这是 Harris 快的原因。

```python [Python]
import numpy as np

def structure_tensor(img, sigma_grad=1.0, sigma_int=2.0):
    Iy, Ix = np.gradient(img)                       # 中心差分梯度
    # 高斯加权的外积分量（* 表示可分离高斯卷积）
    M11 = gaussian(Ix * Ix, sigma_int)
    M12 = gaussian(Ix * Iy, sigma_int)
    M22 = gaussian(Iy * Iy, sigma_int)
    return M11, M12, M22

def eigen2x2(M11, M12, M22):
    T = M11 + M22
    D = M11 * M22 - M12 * M12
    disc = np.sqrt(np.maximum(T * T - 4 * D, 0))    # 数值防负
    lam1 = (T + disc) / 2
    lam2 = (T - disc) / 2
    return lam1, lam2

def gaussian(a, sigma):
    r = int(3 * sigma + 1)
    k = np.exp(-0.5 * (np.arange(-r, r + 1) / sigma) ** 2); k /= k.sum()
    return np.apply_along_axis(lambda m: np.convolve(m, k, mode='same'), 0,
                               np.apply_along_axis(lambda m: np.convolve(m, k, mode='same'), 1, a))
```

## 派生度量：一张张量读出多种结构

- ** coherence（相干性）**：\(\display C = \left(\dfrac{\lambda_1-\lambda_2}{\lambda_1+\lambda_2}\right)^2 \in [0,1]\)——1 表示纯边缘（方向高度一致），0 表示各向同性（角点或平坦）。用于脊线增强与去噪的方向场。
- **contrast（强度）**：\(\lambda_1 + \lambda_2\)，即邻域梯度总能量，衡量「结构显著度」。
- **linearity（线性度）**：\(\lambda_1 - \lambda_2\)，突出线状结构（血管、指纹纹线）。
- **purity / isotropy**、方向角 \(\theta\)：组合起来做脊线检测与追踪。

## 多语言实现：Harris 响应与方向

主线给「算张量 → 出 Harris \(R\) 与主方向 \(\theta\)」的最小内核，四语言并列（Java 主线）：

```java [Java]
static double harrisResponse(double M11, double M12, double M22, double k) {
    double T = M11 + M22, D = M11 * M22 - M12 * M12;
    return D - k * T * T;                            // >0 角点, <0 边缘
}
static double principalAngle(double M11, double M12, double M22) {
    double disc = Math.sqrt(Math.max((M11+M22)*(M11+M22) - 4*(M11*M22-M12*M12), 0));
    double lam1 = (M11 + M22 + disc) / 2;            // 主特征值
    if (Math.abs(M12) < 1e-12) return (M11 >= M22) ? 0 : Math.PI / 2;
    return Math.atan2(lam1 - M11, M12);              // e1 = (lam1-M22, M12) 的方向（等价式）
}
```

```rust [Rust]
pub fn harris_response(m11: f64, m12: f64, m22: f64, k: f64) -> f64 {
    let t = m11 + m22;
    let d = m11 * m22 - m12 * m12;
    d - k * t * t
}
pub fn principal_angle(m11: f64, m12: f64, m22: f64) -> f64 {
    let disc = ((m11 + m22).powi(2) - 4.0 * (m11 * m22 - m12 * m12)).max(0.0).sqrt();
    let lam1 = (m11 + m22 + disc) / 2.0;
    if m12.abs() < 1e-12 {
        if m11 >= m22 { 0.0 } else { std::f64::consts::FRAC_PI_2 }
    } else {
        (lam1 - m11).atan2(m12)
    }
}
```

```typescript [TypeScript]
function harrisResponse(M11: number, M12: number, M22: number, k: number): number {
  const T = M11 + M22, D = M11 * M22 - M12 * M12;
  return D - k * T * T;
}
function principalAngle(M11: number, M12: number, M22: number): number {
  const disc = Math.sqrt(Math.max((M11 + M22) ** 2 - 4 * (M11 * M22 - M12 * M12), 0));
  const lam1 = (M11 + M22 + disc) / 2;
  if (Math.abs(M12) < 1e-12) return M11 >= M22 ? 0 : Math.PI / 2;
  return Math.atan2(lam1 - M11, M12);
}
```

## 结构张量与光流：同一块代数的两面

Lucas-Kanade 光流假设局部窗口内运动恒定，最小二乘解 \((u,v)\) 时出现的就是同一个 \(M\)：窗口里 \(\sum (I_x u + I_y v + I_t)^2 = [u\ v]\,M\,[u\ v]^{\top} + \cdots\)。解 \(M\binom{u}{v} = -\sum(I_t \nabla I)\) 的分母矩阵正是结构张量——**当 \(M\) 病态（\(\lambda_2\approx0\)，即单一边缘）时，沿边缘方向的运动不可解，这就是「孔径问题（aperture problem）」的代数显形**。特征值 \(\lambda_{\min}\) 小于阈值即该点光流不可靠。

## 常见陷阱

::: danger 陷阱清单
1. **尺度混淆**：梯度平滑 \(\sigma_{\text{grad}}\) 与积分（累加）平滑 \(\sigma_{\text{int}}\) 是两个独立参数——\(\sigma_{\text{int}}\) 决定「结构在多大范围内算一致」，调大检测粗结构、调小敏感于细节噪声。
2. **\(M_{12}\) 近零时方向翻转**：`atan2` 在主特征向量 \(x\) 分量近 0 时数值不稳，应回退到坐标轴约定或改用 \((M_{11}-M_{22}, 2M_{12})\) 的 \(2\theta\) 表示（避免 \(\pi\) 周期性歧义）。
3. **梯度算子与噪声**：直接 \(I_x^2\) 放大噪声；先做适度高斯，或用 Deriche / 递归小波滤波再算张量，否则 coherence 场布满椒盐。
4. **忘记半正定性**：数值误差可让 \(\lambda_2<0\)，开方/归一化崩溃——计算判据前 `max(·,0)` 钳位（代码已体现）。
5. **张量当角点检测器只取 \(R\)**：Harris \(R=D-kT^2\) 里 \(k\) 对绝对尺度极敏感，跨图阈值不可移植；现代偏好 Shi-Tomasi \(\min(\lambda_1,\lambda_2)\) 更稳。
6. **旋转各向异性采样**：张量本身是旋转协变的（\(R M R^\top\)），但有限窗口离散化会引入方向偏置；精确方向分析用小波张量（WT）或频域构造补偿。
:::

# 总结

- 结构张量 = 「梯度外积 + 高斯平滑」，把逐像素方向升级为邻域**方向能量分布**；特征值 \(\lambda_{1,2}\) 读出「有没有结构 / 强不强」，特征向量读出「朝哪」，椭圆是一目了然的可视化。
- \(2\times2\) 闭式解让一切代价极低：迹 \(T\)、行列式 \(D\) 就够 Harris（\(R=D-kT^2\)）、Shi-Tomasi（\(\min\lambda\)）、coherence、contrast、主方向——无迭代、可分离、逐像素常数。
- 它同时是光流的方程矩阵，孔径问题就是 \(M\) 病态 \((\lambda_2\to0)\) 的别名；角点判据（\(\lambda\) 双大）正是 [050.特征提取算法](./050.特征提取算法.md) 里 Harris/FAST/SIFT 极值点筛选的源头。
- 频域视角下它是局部方向谱的一阶矩，与 [020.有损压缩原理](./020.有损压缩原理.md) 的 DCT 能量集中同源；鲁棒版本（含离群梯度）可借 [030.RANSAC算法](./030.RANSAC算法.md) 的思想改造加权。
