# 概述

要让机器「认出」同一张图在旋转、缩放、光照、视角变化后仍是「同一个地方」，需要一种对这类变换**保持稳定**的局部描述——这就是**局部特征**。它分两半：先找一批「哪里值得记」（**关键点检测器**，角点/_blob/极值），再给每个点编一段「这里长什么样」（**描述子**，一个对视角不变的模式向量）。本章精选三座里程碑，构成一条清晰的技术演化线：

- **SIFT**（Lowe 1999/2004）：DoG 尺度空间极值 + 128 维梯度直方图描述子——**尺度与旋转不变**的奠基之作，慢但稳。
- **SURF**（Bay 2006）：Hessian 行列式（DoH）+ 积分图加速 + 64 维 HOG 描述子——SIFT 的**工程提速版**，用盒式滤波近似高斯。
- **ORB**（Rublee 2011）：FAST 角点 + rAIB 择优评分 + 灰度质心定向 + 旋转 BRIEF（rBRIEF）——**纯整数运算**、实时、免费（SIFT/SURF 曾含专利），SLAM/AR 默认。

三者串起来就是「精度↔速度↔专利」三角的不同解。

1. 对图像反复高斯模糊，得到尺度层 \(O(o,s)\)：octave 内相邻层尺度比 \(k=2^{1/s}\)，每 octave 降采样一半——尺度空间就是「同一场景的不同清晰度/大小」的堆叠。
2. **DoG**：相邻两层相减 \(D = O_{i+1} - O_i\)，近似高斯拉普拉斯（LoG），在差分图上找极值。
3. **三维非极大值抑制**：一个候选点要和它**同层 8 邻 + 上下层各 9 个**共 26 个邻居比，严格最大/最小才留——这就是「尺度 + 平面」联合极值，可验：一个尺度 \(=2\)、位置居中的 blob，只会在匹配它尺寸的那层 DoG 里成为极值。
4. **方向分配**：以关键点为中心，邻域梯度按角度投票进 36 个 bin（幅值加权 + 高斯窗），最高 bin 定主方向——把「旋转」吸收进坐标系，后续描述在旋转归一化帧里做。
5. 描述子可视化：\(4\times4\) 网格 × 每格 8 方向 = 128 维（SIFT），画成带箭头的「梯度流向小图」；SURF 同理取 \(4\times4\) 子块，每块统计 \((\sum dx,\sum dy,\sum|dx|,\sum|dy|)\) 共 64 维（基于 Haar 小波响应）。

# 详解

## SIFT：尺度不变特征四步

### 1) 尺度空间与 DoG 检测

高斯是唯一的尺度核（尺度间再模糊仍等于一次性高斯），故尺度空间用 \(G_\sigma * I\)。检测 LoG 极值代价高，Lowe 证明用 **DoG** 近似足够：

\[
D(x,y,\sigma) = (G_{k\sigma} - G_\sigma) * I = O_{k\sigma} - O_\sigma
\]

对每个 \(D\) 的采样点在 \((x,y,\sigma)\) 三维做非极大值抑制即得候选。每 octave 取 \(s=3\) 组、\(k=2^{1/3}\)，octave 数 \(=\lfloor\log_2(\min(W,H)/2^3)\rfloor\) 左右。

### 2) 亚像素精化 + 低对比度/边缘剔除

用三维泰勒展开求极值偏移 \(\hat X = -H^{-1}g\)（\(H,g\) 为 DoG 的一阶二阶导），插值得亚像素位置尺度；\(|D(\hat X)|<\) 阈剔低对比度；Hessian 主曲率比 \(\frac{\mathrm{tr}^2}{\det}=r^2\frac{(1+k)^2}{k}\) 过大者像边缘，用类似 Harris 的比值剔除——**留下的才是「定位可靠、非边缘」的角点状结构**。

### 3) 方向分配（旋转不变）

邻域梯度由中心差分得，幅值 \(m=\sqrt{I_x^2+I_y^2}\)、方向 \(\theta=\mathrm{atan2}(I_y,I_x)\)，投 36 bin（幅值×高斯×方向高斯加权），取峰为主方向；副峰 >0.8×主峰则复制一个同点不同方向的关键点。

### 4) 描述子（128 维）

以主方向旋转采样窗口，取 \(16\times16\) 区域分 \(4\times4\) 子块，每子块 8 方向梯度直方图（幅值高斯加权、截断 0.2 抗光照、L2 归一化）→ \(4\times4\times8=128\)。**归一化 + 截断归一化（SIFT vs ESSENTIALS）** 是鲁棒性的关键。

```python [Python]
# 描述子核心（以关键点邻域的梯度场 -> 128 维）；坐标已旋转到主轴系，为流程伪码
import numpy as np

def sift_descriptor(dx, dy, ox, oy, orient, grid=4, nbins=8, sigma=2.0):
    m = np.hypot(dx, dy)                                   # 梯度幅值
    theta = (np.degrees(np.arctan2(dy, dx)) - orient) % 360  # 旋到主轴
    bins = (theta * nbins / 360).astype(int)               # 方向 bin
    desc = []
    for gy in range(grid):
        for gx in range(grid):
            # 该子块：像素落在对应格内，按高斯窗加权投方向直方图
            sel = (np.abs(ox - (gx - 1.5)) <= 2) & (np.abs(oy - (gy - 1.5)) <= 2)
            wgt = np.exp(-(ox[sel]**2 + oy[sel]**2) / (2 * sigma**2))
            hist = np.bincount(bins[sel], weights=m[sel] * wgt, minlength=nbins)
            desc.extend(hist)
    desc = np.asarray(desc, dtype=float)
    desc /= (np.linalg.norm(desc) + 1e-9)                  # L2 归一
    desc = np.clip(desc, 0, 0.2)                           # 截断抗光照
    desc /= (np.linalg.norm(desc) + 1e-9)                  # 再归一
    return desc
```

## SURF：用积分图和 Hessian 提速

- **积分图（Integral Image）** \(II(x,y)=\sum_{i\le x,j\le y}I(i,j)\) 让任意矩形区域和 \(O(1)\) 查出（四角加减），高斯/盒式卷积从 \(O(k)\) 降到常数——这是 SURF 提速的地基：

\[
\text{sum}(D)=II(x_2,y_2)-II(x_1{-}1,y_2)-II(x_2,y_1{-}1)+II(x_1{-}1,y_1{-}1)
\]

- **检测器 = Hessian 行列式（DoH）**：用盒式滤波近似二阶高斯 \(I_{xx},I_{yy}\) 及 \(I_{xy}\)，判 \(\det H = I_{xx}I_{yy}-(w I_{xy})^2\) 的尺度空间极值（\(w\) 为平衡因子）。SURF 的「加速版」进一步只用 \(\mathrm{sign}(\det H)>0\) 的近似，把两个 octave 分开并行。
- **描述子**：\(20\times20\) 邻域分 \(4\times4\)，每子块统计 \(dx,dy\) 及 \(|dx|,|dy|\) 两方向和 = 64 维（比 SIFT 少一半，更快）；同样按主方向旋转归一。

## ORB：实时与免专利

- **检测 = FAST**：中心像素比圆周 **连续 12 个**邻域都亮（或都暗）超阈值即为角点；再用 **rAIB**（approx. intensity / 亮度自适应）择优、非极大值抑制、金字塔多尺度。FAST 极快源于「早退」——先查 4 个正交点，16/12 不满足立即淘汰，平均只比 2～3 个点。
- **定向 = 灰度质心法（Intensity Centroid）**：斑块质心 \(C=(\sum xI/\sum I, \sum yI/\sum I)\)，主方向 = 中心指向质心的角——比 SIFT 直方图投票快得多（可查表）。
- **描述子 = rBRIEF（rotated BRIEF）**：BRIEF 是随机选 256 对像素、比灰度得 256-bit 串（汉明距离匹配、极快）；ORB 用关键点主方向**旋转配对模板**恢复旋转不变，并**贪心筛选**方差/均值最优且去相关的 256 对（解决 BRIEF 各分量相关性），得到 **SteerFORS** 型定向。

```java [Java]
// FAST 角点判据：圆周 16 点中连续 12 个同亮/同暗超阈值
static boolean isFastCorner(int[][] img, int x, int y, int thr) {
    int c = img[y][x], p[][] = new int[16][2];       // Breslow 圆盘 16 邻
    int[] xs = {2,3,2,1,0,-1,-2,-3,-2,-1,0,1,2,3,2,1};
    int[] ys = {0,-1,-2,-3,-2,-1,0,1,2,3,2,1,0,-1,-2,-3};
    for (int i = 0; i < 16; i++) { p[i][0]=x+xs[i]; p[i][1]=y+ys[i]; }
    for (int type = 0; type < 2; type++) {           // 0:全亮 1:全暗
        int run = 0;
        for (int i = 0; i < 17; i++) {               // 17 覆盖 12 连续（环形）
            int v = img[p[i%16][1]][p[i%16][0]];
            boolean ok = type == 0 ? v > c + thr : v < c - thr;
            run = ok ? run + 1 : 0;
            if (run >= 12) return true;
        }
    }
    return false;
}
```

```rust [Rust]
// FAST：环形连续 12 同侧判据（早退优化见主描述）
pub fn is_fast_corner(img: &[Vec<i32>], x: usize, y: usize, thr: i32) -> bool {
    const XS: [isize; 16] = [2,3,2,1,0,-1,-2,-3,-2,-1,0,1,2,3,2,1];
    const YS: [isize; 16] = [0,-1,-2,-3,-2,-1,0,1,2,3,2,1,0,-1,-2,-3];
    let c = img[y][x];
    for typ in 0..2 {
        let mut run = 0;
        for i in 0..17 {
            let px = (x as isize + XS[i % 16]) as usize;
            let py = (y as isize + YS[i % 16]) as usize;
            let v = img[py][px];
            let ok = if typ == 0 { v > c + thr } else { v < c - thr };
            run = if ok { run + 1 } else { 0 };
            if run >= 12 { return true; }
        }
    }
    false
}
```

## 匹配与「最近邻比」判别

描述子建好后靠**距离**配对：SIFT/SURF 用欧氏距离 + ** Lowe 比值测试**（最近邻/次近邻 < 0.8 才算可靠，滤掉「哪个都像」的歧义匹配），ORB 用**汉明距离**（popcount of XOR）。匹配完的点对送 [030.RANSAC算法](./030.RANSAC算法.md) 估单应矩阵剔除误配。大规模检索用 **FLANN**（近似 K-D 树/多探针哈希）替代暴力，或 VLAD/Fisher Vector 做词袋。

## 常见陷阱

::: danger 陷阱清单
1. **把 SIFT 当尺度不变的绝对保证**：大视角（>30°）、剧烈透视、重复纹理下描述子仍会混叠；务必配比值测试 + RANSAC，别信单一最近邻。
2. **低对比度/边缘点不过滤**：SIFT 若跳过 \(|D|\) 与主曲率剔除，会留下一堆定位漂移、描述不稳定的「半角点」，匹配噪声暴涨。
3. **归一化截断顺序搞反**：SIFT 必须 L2 归一 → clip(0.2) → **再** L2 归一；漏掉第二次归一会破坏后续欧氏/余量距离的一致性。
4. **积分图溢出与精度**：\(4K\) 大图 \(II\) 需 64-bit 或浮点，32-bit 有符号会溢出——SURF 数值不稳的常见根源。
5. **ORB 的 brief 对不旋转校正**：裸 BRIEF 无旋转不变性，直接用在有旋转的场景效果断崖——必须用 ORB 的方向旋转模板 + 已训练配对。
6. **跨语言/库默认参数不一致**：OpenCV SIFT 的 `nOctaveLayers`/`contrastThreshold`/`sigma`、ORB 的 `FAST` 阈值与 `WTA_K` 默认值差异大，复现论文要对齐参数而非只对齐算法名。
7. **专利合规**：SIFT（2020 前）、SURF 历史上含专利，商用先核当期授权状态；ORB/AKAZE 为免专利替代。
:::

# 总结

- 局部特征 = 检测器（哪里）+ 描述子（长什么样），演化主线是「尺度/旋转不变性」的三种实现：SIFT 用 DoG + 梯度直方图（稳、慢、曾专利），SURF 用积分图 + DoH（提速），ORB 用 FAST + 质心定向 + rBRIEF（实时、免专利）。
- 三者共享同一套「稳定化」动作：尺度空间找极值、主方向归一旋转、邻域统计成描述子、比值测试 + RANSAC 剔误配——理解了这条流水线，换任何新特征（KAZE/BEBLD/LightDesc）都只是替换某个环节。
- 判「哪里是特征」的根基是 [040.结构张量](./040.结构张量.md) 的 \(\lambda_1,\lambda_2\)；「剔除误匹配」交给 [030.RANSAC算法](./030.RANSAC算法.md)；多尺度金字塔思想与 [020.有损压缩原理](./020.有损压缩原理.md) 的频域分层同源。
- 现代趋势是学习型特征（SuperPoint/R2D2/DISK）端到端替代手工描述子，但手工三件套仍是理解「不变性从何而来」的最佳教材，也是在无 GPU/小数据场景的可靠兜底。
