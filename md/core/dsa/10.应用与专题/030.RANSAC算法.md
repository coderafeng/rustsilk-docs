# 概述

真实测量数据里总混着一批「离谱的坏点」——误匹配的特征点对、雷达杂波、标注错误。最小二乘对这些离群点毫无抵抗力：一个飞点就能把整条拟合线拽偏，因为它的目标函数把误差**平方**放大。**RANSAC**（Random Sample Consensus，Fischler-Bolles 1981）反其道而行：不追求「拟合所有点」，而是**反复随机抽取最小可定解的子集**，用这一个候选模型去数「有多少点支持我」（内点），谁的支持者最多谁就是真模型。它假设「好的子集能被抽到」，于是把鲁棒性转化为一个概率问题——只要迭代次数够，以接近 1 的概率命中至少一次纯内点样本。它是计算机视觉里估计单应矩阵、基础矩阵、直线/平面拟合的事实标准。

- 所属章节：[000.应用与专题概述](./000.应用与专题概述.md)
- 时间复杂度：\(O(k \cdot (C_{\text{fit}} + n\cdot C_{\text{dist}}))\)——\(k\) 次迭代、每次定模型 \(C_{\text{fit}}\) + 对 \(n\) 点判内外；期望停止的 \(k\) 由成功率公式给出
- 空间复杂度：\(O(n)\)（点集 + 当前最优内点集）
- 应用场景：图像拼接的单应/基础矩阵估计、点云平面分割、立体匹配去误匹配、多目标轨迹拟合、带 outliers 的回归
- 定位：它是 [04.核心算法思想](../04.核心算法思想/000.核心算法思想概述.md) 里「随机化算法」的鲁棒估计化身；与最小二乘、M 估计、LMEDS 互补

# 详解

## 算法骨架

RANSAC 的一次标准循环：

1. **抽样**：从数据里均匀随机取**确定模型所需的最小子集**（直线 2 点、平面 3 点、单应 4 点对、基础矩阵 8 点）；
2. **拟合**：由该子集闭式解出一个候选模型 \(\theta\)；
3. **计数**：对所有数据点算残差 \(r_i = \rho(x_i, \theta)\)，\(\le\tau\) 者记为内点，统计内点数（即模型的「共识度 score」）；
4. **择优**：若当前内点数 > 历史最优，保存 \(\theta^*\) 与内点集；
5. **停止判定**：达到预设迭代上界、或「至少命中一次好样本」的概率已达标时停；
6. **精修**（Lo，Local Optimization）：用最优内点集重跑一次最小二乘，得到比「最小子集解」更准的最终模型。

阈值 \(\tau\) 常由噪声尺度 \(\sigma\) 与置信度导出：\(\tau = \sigma\sqrt{\chi^2_{p}(1-\epsilon)}\)（\(p\) 为自由度数、\(\epsilon\) 为单点误判率）；「距离比模型」用马氏距离处理各向异性噪声更稳。

```python [Python]
import random, math

def ransac(points, model_fit, model_dist, thresh, max_iter=200, min_inliers=10):
    """points: 数据；model_fit: list->θ 或 None；model_dist: (θ,p)->残差；返回最优 θ + 内点"""
    best = (None, -1, None)
    for _ in range(max_iter):
        subset = random.sample(points, 2)                  # 直线：最小 2 点
        θ = model_fit(subset)
        if θ is None:                                       # 退化样本（两点重合/共线问题）
            continue
        inliers = [p for p in points if model_dist(θ, p) <= thresh]
        if len(inliers) > best[1]:
            best = (θ, len(inliers), inliers)
            if len(inliers) >= min_inliers:                 # 命中充分内点，提前收
                break
    θ, n, inliers = best
    if θ is None:
        return None, []
    return model_fit(inliers), inliers                      # Lo：用全部内点重拟合精修
```

## 迭代次数怎么定：成功率公式

设某次抽样恰好全取到内点的概率为 \(w^s\)（\(s\) 为最小子集大小、\(w\) 为内点比例），则 \(k\) 次里**至少一次**命中纯内点样本的概率：

\[
P(\text{至少一次成功}) = 1 - (1 - w^s)^k
\]

要达到置信度 \(z\)（如 0.99），所需迭代次数：

\[
k = \frac{\log(1 - z)}{\log(1 - w^s)}
\]

手算：直线 \(s=2\)、内点比 \(w=0.7\)、\(z=0.99\) → \(k = \log(0.01)/\log(1-0.49) = \log 0.01/\log 0.51 \approx 6.84\)，取 **7 次**即够。若 \(w\) 掉到 0.3（一半以上是外点），\(k = \log 0.01/\log(1-0.09) \approx 48.8\) 取 **49**——**内点比例稍降，所需迭代暴涨**，这正是 RANSAC 在「外点过半」时失效的数学画像。工程实现边跑边用当前最优内点比更新 \(\hat w\)，动态缩小 \(k\)（早停）。

```java [Java]
static int requiredIters(double w, int s, double z) {
    double denom = Math.log(1 - Math.pow(w, s));
    if (denom >= 0) return Integer.MAX_VALUE;              // w=1 或 s 使概率为 0，永不需迭代
    return (int) Math.ceil(Math.log(1 - z) / denom);
}
// requiredIters(0.7, 2, 0.99) → 7；requiredIters(0.3, 2, 0.99) → 49
```

```rust [Rust]
fn required_iters(w: f64, s: usize, z: f64) -> Option<u64> {
    let denom = (1.0 - w.powi(s as i32)).ln();
    if denom >= 0.0 { return None; }                       // w=1 或概率为 0：无需迭代
    Some(((1.0 - z).ln() / denom).ceil() as u64)
}
// required_iters(0.7, 2, 0.99) → Some(7)；required_iters(0.3, 2, 0.99) → Some(49)
```

```typescript [TypeScript]

  const denom = Math.log(1 - Math.pow(w, s));
  if (denom >= 0) return Infinity;                    // 无需迭代
  return Math.ceil(Math.log(1 - z) / denom);
}
// requiredIters(0.7, 2) → 7；requiredIters(0.3, 2) → 49
```

## 模型选择：直线示例

「最小 2 点定线 + 点到线距离」是最易手验的实例，四语言给出 `model_fit` 与 `model_dist`：

```python [Python]
def fit_line(two_pts):
    (x1, y1), (x2, y2) = two_pts
    if abs(x2 - x1) < 1e-9:                              # 竖直退化
        return ("v", x1)
    k = (y2 - y1) / (x2 - x1); b = y1 - k * x1
    return ("s", k, b)

def line_dist(θ, p):
    x, y = p
    if θ[0] == "v":
        return abs(x - θ[1])
    _, k, b = θ
    return abs(k * x - y + b) / math.hypot(k, 1)        # 点到直线垂距
```

```java [Java]
// 斜率型 θ = {k, b}；退化竖直另标 flag
static double[] fitLine(double[][] two) {
    double dx = two[1][0] - two[0][0], dy = two[1][1] - two[0][1];
    if (Math.abs(dx) < 1e-9) return null;                // 交主循环作退化丢弃
    double k = dy / dx, b = two[0][1] - k * two[0][0];
    return new double[]{k, b};
}
static double lineDist(double[] θ, double[] p) {
    return Math.abs(θ[0]*p[0] - p[1] + θ[1]) / Math.hypot(θ[0], 1);
}
```

```rust [Rust]
fn fit_line(two: &[[f64; 2]; 2]) -> Option<(f64, f64)> {
    let dx = two[1][0] - two[0][0];
    if dx.abs() < 1e-9 { return None; }
    let k = (two[1][1] - two[0][1]) / dx;
    Some((k, two[0][1] - k * two[0][0]))
}
fn line_dist(theta: (f64, f64), p: [f64; 2]) -> f64 {
    (theta.0 * p[0] - p[1] + theta.1).abs() / (theta.0 * theta.0 + 1.0).sqrt()
}
```

```typescript [TypeScript]
function fitLine(two: number[][]): [number, number] | null {
  const dx = two[1][0] - two[0][0];
  if (Math.abs(dx) < 1e-9) return null;
  const k = (two[1][1] - two[0][1]) / dx;
  return [k, two[0][1] - k * two[0][0]];
}
const lineDist = (θ: [number, number], p: number[]) =>
  Math.abs(θ[0] * p[0] - p[1] + θ[1]) / Math.hypot(θ[0], 1);
```

## 变体家族

- **PROSAC**：先用「匹配质量升序」的概率采样替代纯随机，好样本优先，收敛快几倍（SIFT 匹配默认）。
- **LO-MAGSAC / Multi-RANSAC**：一次抽多模型，处理数据里**同时存在多个模型**（多直线、多平面）的场景。
- **LMEDS**：随机取大样本反算「哪些点来定模型」（最小中位残差），适合高外点率（>50%）。
- **C-RANSAC / 约束 RANSAC**：把「内点必须满足额外共面/共线约束」编进计数环节，剔除几何不一致的假内点。
- **RRA（随机区域扩张）**、**GC-RANSAC**（图割全局寻优内点划分）：OpenCV `findFundamentalMat`/`findHomography` 的 `RANSAC`/`LMEDS`/`PROSAC` 选项即这套。

## 常见陷阱

::: danger 陷阱清单
1. **外点过半直接崩**：\(w<0.5\) 时纯内点样本越来越难抽，且「多数点」本身可能就是错误结构——先估 \(w\) 或改 LMEDS/共识阈值策略。
2. **阈值 \(\tau\) 拍脑袋**：太大把外点也招成内点（over-fit consensus）、太小内点太少模型不稳；用噪声 \(\sigma\) 反推 \(\tau=\sigma\sqrt{\chi^2_p}\) 并交叉验证。
3. **退化最小样本**：抽到重合点/共线三点定平面等奇异子集，`model_fit` 返回 None 必须丢弃重抽，别拿 NaN 模型去计数。
4. **忘了 Lo 精修**：最小子集定出的模型只用了 \(s\) 个点，噪声大；找到最优内点后**一定要用全部内点重拟合**，精度差一个量级。
5. **多模型只出一个**：一张图里有两条直线时 RANSAC 只会「吃掉」内点最多的那条——要多次「找模型→剔除其内点→再找」的剥离循环（RANSAC/Sequential）。
6. **迭代数写死太小**：固定 `max_iter=100` 在高外点率下成功率不足；用 \(k=\log(1-z)/\log(1-w^s)\) 动态定并留上限保护。
7. **各向异性噪声用垂距**：单应/基础矩阵重投影误差应使用**对称转移误差或马氏距离**，只用一侧垂距会引入系统性偏置。
:::

# 总结

- RANSAC 把「鲁棒拟合」变成「投票」：抽最小可定解子集 → 数内点 → 取共识最大者，离群点因从不进入多数派而被自动无视。
- 它的可靠性是一条概率账：\(k=\log(1-z)/\log(1-w^s)\)，内点比例 \(w\) 稍降所需迭代暴涨——所以 \(w\) 一旦过半就力不从心，需要 PROSAC/LMEDS 变体救场。
- 三步纪律：**退化样本丢弃重抽**、**\(\tau\) 由噪声尺度反推**、**最优内点后必须 Lo 重拟合**——漏掉任何一步都会让精度或鲁棒性塌方。
- 它是「随机化算法」在视觉里的代表（对比 [04.核心算法思想](../04.核心算法思想/000.核心算法思想概述.md) 的确定性 DP/贪心）；输入的特征点对来自 [050.特征提取算法](./050.特征提取算法.md)，估计出的单应/平面正是 [040.结构张量](./040.结构张量.md) 之外另一类几何分析的落点。
