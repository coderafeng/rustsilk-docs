# 概述

无损压缩撞到熵墙后，**有损压缩**换了一个问题来问：人眼/人耳到底「看不见/听不见」什么？答案是丢掉感知冗余——利用视觉系统对**亮度敏感、对色彩细节迟钝**、对**高频纹理里的误差不敏感**（对比掩蔽）、对**先出现的强信号掩盖后出现的弱信号**（时域/空域掩蔽）这些生理缺陷，大胆丢弃高估起来「不值钱」的信息，换来一到两个数量级的压缩比。JPEG 是这条路的纪念碑：**DCT 变换 → 量化 → 熵编码** 三段式几乎原封不动地被 MPEG、H.26x、AV1 继承。代价是契约变了——解压不再还原原始比特，只还原「看起来一样」的近似。

- 所属章节：[000.应用与专题概述](./000.应用与专题概述.md)
- 时间复杂度：DCT 分块 \(O(N\log N)\)（快速余弦变换，或直接矩阵乘 \(O(N^3)\) for \(8\times8\)）；量化与 zigzag 线性；熵编码同 [010.无损压缩算法](./010.无损压缩算法.md)；整体编码 \(O(\text{像素数})\)
- 空间复杂度：\(O(N^2)\) 单块浮点系数；视频帧间参考缓冲 \(O(\text{分辨率})\)
- 应用场景：照片（JPEG/WebP/HEIF）、视频（H.264/HEVC/AV1）、音频（MP3/AAC/Opus）、纹理压缩（BC/DXT）、流媒体自适应码率（HLS/DASH）
- 关键取舍：不可逆——压缩引入的失真无法靠解压挽回，源文件一旦丢弃原始即永失；评估用 PSNR/SSIM 与主观 MOS 双轨

1. **分块 + 色度次采样**：RGB→YCbCr，亮度 Y 全保留、Cb/Cr 各取 1/4（4:2:0）——人眼对色彩细节迟钝，先丢 2/3 色度数据，肉眼几乎无感。
2. **DCT 变换**：\(8\times8\) 空间块 → \(8\times8\) 频率系数；左上加权最低频（DC，块平均亮度），右下高频（边缘/纹理细节）。可验：常数块 \([100]_{8\times8}\) 变换后只有左上 DC\(\approx 800\) 非零、其余全 0——「平坦区域 = 只有直流」。
3. **量化**：每个系数除以感知量化表对应项并四舍五入。高频项的除数大（如 50+），大部分被压成 0；低频除数小（1～2），信息基本保留——**这一步是唯一真正丢信息的环节，quality 因子就是缩放整张量化表**。
4. **zigzag + RLE + 熵编码**：Z 字形扫描把右下角成片的高频 0 排成连续游程，交给 RLE 与哈夫曼——此时数据已高度稀疏，无损环节效率极高。
5. 解码端逆序走一遍：反量化（把 0 乘回去仍是 0，**丢的高频再也回不来**）→ 逆 DCT → 出现块状失真与振铃——高压缩比的「签名误差」。

# 详解

## 感知模型：为什么敢丢

有损压缩的合法性建立在**人类感知系统的三大缺陷**上：

- **对比敏感度函数（CSF）**：人眼对中频空间细节最敏感、对极高/极低频迟钝 → DCT 高频系数天然「不值钱」，量化步长可放大。
- **掩蔽效应**：强边缘附近的误差被「遮」住看不见（空域掩蔽），响噪声旁的小信号听不见（时/频域掩蔽）→ 在纹理丰富区加大量化不掉主观分。
- **色度钝感**：视网膜视锥细胞对亮度（L/M 总和）分辨率远高于色度 → 色度次采样 4:2:0 省下 2/3 色度带宽（这一半来自 Young-Lai 实验，虽有争议，工程上极为划算）。

信息论语义下这叫**率失真理论**（Shannon）：在允许失真 \(D\) 的前提下，编码速率可压到率失真函数 \(R(D)\) 以下——有损压缩是在「比特预算」与「感知失真」之间求帕累托前沿，量化步长就是那只调节旋钮。

## DCT：把「相关」变成「能量集中」

相邻像素高度相关（图像平坦区多），DCT 是一种正交变换，能把这种空间相关性**能量压缩**到少数低频系数上。二维 DCT-II 定义：

\[
F(u,v) = \frac{1}{4}C(u)C(v)\sum_{x=0}^{7}\sum_{y=0}^{7} f(x,y)\cos\frac{(2x+1)u\pi}{16}\cos\frac{(2y+1)v\pi}{16}
\]

其中 \(C(0)=1/\sqrt2\)、其余 \(C(\cdot)=1\)。选 DCT 而非 DFT 的理由：实数、可分离、边界隐式对称使块效应比 DFT 轻，且有快速算法。下面给出 \(8\times8\) 正向 DCT（矩阵形式 \(F = C \cdot f \cdot C^{\top}\)）四语言实现：

```java [Java]
public static double[][] fdct8(double[][] blk) {
    double[] basis = new double[8];
    for (int x = 0; x < 8; x++) basis[x] = (2 * x + 1) * Math.PI / 16;
    double[][] c = new double[8][8];
    for (int u = 0; u < 8; u++)
        for (int x = 0; x < 8; x++)
            c[u][x] = (u == 0 ? Math.sqrt(0.125) : Math.sqrt(0.25)) * Math.cos(u * basis[x]);
    // F = C · blk · Cᵀ
    double[][] tmp = matMul(c, blk), out = matMul(tmp, transpose(c));
    return out;
}
static double[][] matMul(double[][] a, double[][] b) {
    double[][] r = new double[8][8];
    for (int i = 0; i < 8; i++) for (int j = 0; j < 8; j++) for (int k = 0; k < 8; k++)
        r[i][j] += a[i][k] * b[k][j];
    return r;
}
static double[][] transpose(double[][] a) {
    double[][] r = new double[8][8];
    for (int i = 0; i < 8; i++) for (int j = 0; j < 8; j++) r[j][i] = a[i][j];
    return r;
}
// 常数块 f=100 → F[0][0]≈800，其余≈0（能量集中于 DC，可验）
```

```rust [Rust]
pub fn fdct8(blk: &[[f64; 8]; 8]) -> [[f64; 8]; 8] {
    let mut c = [[0.0f64; 8]; 8];
    for u in 0..8 {
        for x in 0..8 {
            let a = (2 * x + 1) as f64 * std::f64::consts::PI / 16.0;
            c[u][x] = if u == 0 { (0.125f64).sqrt() } else { 0.25f64.sqrt() } * (u as f64 * a).cos();
        }
    }
    let tmp = mat_mul(&c, blk);
    mat_mul(&tmp, &transpose(&c))
}
fn mat_mul(a: &[[f64; 8]; 8], b: &[[f64; 8]; 8]) -> [[f64; 8]; 8] {
    let mut r = [[0.0f64; 8]; 8];
    for i in 0..8 { for j in 0..8 { for k in 0..8 { r[i][j] += a[i][k] * b[k][j]; } } }
    r
}
fn transpose(a: &[[f64; 8]; 8]) -> [[f64; 8]; 8] {
    let mut r = [[0.0f64; 8]; 8];
    for i in 0..8 { for j in 0..8 { r[j][i] = a[i][j]; } }
    r
}
```

```typescript [TypeScript]
function fdct8(blk: number[][]): number[][] {
  const c: number[][] = [];
  for (let u = 0; u < 8; u++) {
    c[u] = [];
    for (let x = 0; x < 8; x++) {
      const a = (2 * x + 1) * Math.PI / 16;
      c[u][x] = (u === 0 ? Math.sqrt(0.125) : Math.sqrt(0.25)) * Math.cos(u * a);
    }
  }
  const mm = (A: number[][], B: number[][]) =>
    A.map(row => B[0].map((_, j) => row.reduce((s, v, k) => s + v * B[k][j], 0)));
  const T = c.map((_, i) => c.map(r => r[i]));          // Cᵀ
  return mm(mm(c, blk), T);
}
```

import math

def fdct8(blk):
    c = [[(math.sqrt(0.125) if u == 0 else math.sqrt(0.25))
          * math.cos(u * (2 * x + 1) * math.pi / 16) for x in range(8)]
         for u in range(8)]
    mm = lambda A, B: [[sum(A[i][k] * B[k][j] for k in range(8)) for j in range(8)]
                       for i in range(8)]
    Ct = [[c[j][i] for j in range(8)] for i in range(8)]
    return mm(mm(c, blk), Ct)

## 量化：唯一真正丢信息的地方

量化表按 CSF 设计——低频小步长（保）、高频大步长（丢）。标准亮度量化表（JPEG Annex K）：

\[
Q_Y = \begin{pmatrix}
16 & 11 & 10 & 16 & 24 & 40 & 51 & 61\\
12 & 12 & 14 & 19 & 26 & 58 & 60 & 55\\
\vdots & & & & & & & \text{（右下增大使高频粗量化）}
\end{pmatrix}
\]

系数除法取整：\(F^q(u,v) = \mathrm{round}(F(u,v) / Q(u,v))\)。quality 因子 \(S\in(0,200]\) 按 \(Q' = \lfloor (Q\cdot S + 50)/100 \rfloor\) 整表缩放。反量化 \(F(u,v) \approx F^q \cdot Q\)——被压成 0 的高频永远回不来，这就是「有损」的本质点。

## 其他范式：不止 DCT

- **变换编码家族**：JPEG XL / HEVC 用自适应块尺寸（4×4～64×64）与 integer 近似 DCT；视频再叠加**帧间运动补偿**（时域冗余才是大头，I/P/B 帧 + 运动矢量）。
- **预测编码**：DPCM/ADPCM（音频）、 lossless WebP 的空间预测——用邻域预测残差再熵编码。
- **向量量化**：GIF 的 256 色调色板、K-means 码本（把一块映射到最近码字，一索引代一簇）。
- **匹配 pursuit / 小波**：JPEG2000 用离散小波（DWT）+ 嵌入式码流，支持渐进传输与无损/有损统一。
- **感知音频**：MP3/AAC 的临界频带子带滤波 + 掩蔽模型 + 比特池——心理声学模型就是「听觉版量化表」。

## 常见陷阱

::: danger 陷阱清单
1. **反复保存 JPEG 的代际损失**：每次重编码都重量化一次，块效应/振铃逐代累积——编辑工作流必须留 PSD/TIFF/PNG 母版，交付时才导出一次 JPEG。
2. **把有损产物当归档源**：视频转码链上每多一次有损就永久丢一份细节；归档请用无损或近无损（quality ≥ 90、CRF ≤ 18），或 FFV1/ProRes 之类中间编码。
3. **只看 PSNR 不看主观**：PSNR 是逐像素 MSE 的对数，与「好不好看」相关性差——两个 PSNR 相同的编码器主观质量可天差地别；SSIM/MSU/VMAF + 人眼 MOS 才是完整评价。
4. **忽略色度次采样的边缘彩边**：4:2:0 在高对比彩色边缘（红字黑底）会产生彩边/染色，文字截图、UI 设计图不该走 4:2:0，改 4:4:4 或直接 PNG。
5. **量化表/码率对内容不敏感**：固定 quality 压星空图（暗部条带）与压噪点图结果迥异——上 VBR/CRF 自适应 + 感兴趣区域（ROI）编码。
6. **把 DCT 块效应当「锐度」**：低码率下 8×8 块边界发虚，用锐化滤镜硬怼只会让下一代更糊——正解是升码率或换更强的编码器（AV1/HEVC）。
:::

# 总结

- 有损压缩的合法性来自**感知缺陷**：CSF、掩蔽、色度钝感让「丢掉一部分比特」在主观上免费；率失真理论给出「给定失真可省多少比特」的极限，量化步长是那枚旋钮。
- JPEG 三段式 = 变换（DCT 能量集中）+ 量化（唯一真丢信息处，quality 缩放整表）+ 熵编码（此时数据已稀疏，无损环节高效收尾）；视频在此之上叠运动补偿吃掉时域冗余。
- 契约是「近似而非还原」：代际损失、归档误用、唯 PSNR 论是有损世界最常见的三类事故——留母版、CRF 保守、主观+客观双评是纪律。
- 变换本体（DCT 是正交基变换）与 [07.数值计算/060.快速傅里叶变换FFT](../07.数值计算/060.快速傅里叶变换FFT.md) 同源；收尾的熵编码就是 [010.无损压缩算法](./010.无损压缩算法.md)；图像侧的频域分析还会在 [040.结构张量](./040.结构张量.md) 与 [050.特征提取算法](./050.特征提取算法.md) 再登场。
