# 概述

1985 年 Miller 与 Koblitz 各自独立提议：**把 Diffie-Hellman 和 RSA 搬到椭圆曲线的点群上**，困难性从「分解大整数/普通域离散对数」换成「椭圆曲线离散对数（ECDLP）」——已知最好的通用攻击 Pollard's rho 只有 \(O(\sqrt{n})\)，于是 **256-bit 椭圆曲线密钥 ≈ 3072-bit RSA** 的安全强度。密钥短一个数量级，意味着更快的握手、更小的证书、能跑在门禁卡和区块链里；今天的 TLS 主力是 X25519（ECDH）+ ECDSA（签名），比特币每一笔交易都由它守护。理解 ECC 只需要一块垫脚石：**曲线上的点怎么「加法」，怎么「数乘」**。

- 所属章节：[000.密码学算法概述](./000.密码学算法概述.md)
- 时间复杂度：标量乘 \(kP\) 用 double-and-add 为 \(O(\log k)\) 次点加/倍点（每步域逆元可用投影坐标或 Montgomery 梯子摊平）；X25519 单次约 50μs 级
- 空间复杂度：一个点 = 两个域元素（256-bit 曲线共 64 字节），公钥可再压到 33 字节（x + 1 比特）
- 应用场景：TLS ECDHE 密钥协商（见 [030.密钥交换算法](./030.密钥交换算法.md)）、ECDSA 证书/代码签名/区块链交易、SM2（国内商用密码体系）、端到端加密的双棘轮
- 曲线家族速览：NIST P-256（海长曲线性优美但常数存疑）、**Curve25519**（Bernstein 设计，Montgomery 形式、抗侧信道基因）、secp256k1（比特币的 K 曲线）、SM2（国标）

3. \(Q \to P\) 时割线变切线 → 得到倍点 \(2P\)；垂直线两交点互为负元，「第三交点」是无穷远点 \(\mathcal{O}\)（群单位元）。

**动画 2：有限域上的循环群（\(E: y^2 = x^3 + 2x + 2\)  over \(\mathbb{F}_{17}\)，\(P=(5,1)\)）**

逐点验证 \(y^2 \equiv x^3+2x+2 \pmod{17}\)：\((5,1): 1 \equiv 125+10+2 = 137 \equiv 1\) ✓

1. \(2P\)：倍点斜率 \(\lambda = \frac{3x_P^2 + a}{2y_P} = \frac{77}{2} \equiv 77 \times 9 = 9 \times 7 = 63 \equiv 12\)（\(2^{-1}\bmod 17 = 9\)），\(x_3 = 12^2 - 10 = 134 \equiv 15\)，\(y_3 = 12(5-15) - 1 = -121 \equiv 14\) → 得反射前的第三交点 \((15,14)\)，**取反** → \(2P = (6,3)\)（验：\(9 \equiv 216+12+2 = 230 = 17\times13+9\) ✓）。
2. \(3P = 2P + P\)：\(\lambda = \frac{3-1}{6-5} = 2\)，第三交点 \((4-11, 2(6-4)-3) = (-7,1) \equiv (10,1)\)，取反 → \(3P = (7,16)\)（验：\(16^2=256\equiv 1\)，\(343+14+2=359 = 17\times21+2\equiv 2\) ✓）。
3. \(4P = 2(2P)\)：对 \(2P=(6,3)\) 倍点，\(\lambda = \frac{3\cdot 36+2}{2\cdot 3} = \frac{110}{6} \equiv 8\times 3 = 24 \equiv 7\)（\(110 \equiv 8\)，\(6^{-1}\bmod 17 = 3\)），\(x_4 = 7^2 - 6 - 6 = 37 \equiv 3\)，\(y_4 = 7(6-3) - 3 = 18 \equiv 1\) → \(4P = (3,1)\)（验：\(1 \equiv 27+6+2 = 35 \equiv 1\) ✓）。
4. 续算 \(5P = 4P+P\)：两点 \(y\) 坐标相同（均为 1）、\(x\) 不同 → 割线水平，\(\lambda = 0\)，\(x_5 = 0 - 3 - 5 = -8 \equiv 9\)，\(y_5 = 0 - 1 = -1 \equiv 16\) → \(5P = (9,16)\)；\(6P = 2(3P) = (6,14)\)、\(7P = (7,1)\)、\(8P = \mathcal{O}\)——**\(P\) 的阶为 8**（逐点代曲线方程均可验：\((9,16): 256\equiv 1\)，\(9^3+18+2 = 749 = 17\times44+1\) ✓；\((6,14): 196 \equiv 9\)，\(216+14 \equiv 9\) ✓；\((7,1): 1\equiv 343+16 \equiv 1\) ✓），循环群 \(\langle P\rangle\) 生成；动画在 8 个点之间画环线。
5. ECDLP 直观：给你 \(Q=(0,6) = 3P\) 与 \(P\)，求「3」——在这盘 8 个点的棋局里穷举即可；把曲线换到 256-bit 域、阶约 \(2^{252}\)，穷举与 Pollard rho 同样绝望。

# 详解

## 群律的有限域公式

短 Weierstrass 式 \(E: y^2 = x^3 + ax + b \pmod p\)（要求 \(4a^3 + 27b^2 \not\equiv 0\) 防奇异点）。两点加法 \(P_1=(x_1,y_1), P_2=(x_2,y_2)\)：

\[
\lambda = \begin{cases}
\dfrac{y_2 - y_1}{x_2 - x_1} \bmod p, & P_1 \ne \pm P_2 \quad (\text{割线})\\[8pt]
\dfrac{3x_1^2 + a}{2y_1} \bmod p, & P_1 = P_2 \quad (\text{切线})
\end{cases}
\qquad
x_3 = \lambda^2 - x_1 - x_2,\quad
y_3 = \lambda(x_1 - x_3) - y_1
\]

除法 = 乘模逆元（扩展欧几里得，见 [06.字符串与数论/080.扩展欧几里得与同余方程](../06.字符串与数论/080.扩展欧几里得与同余方程.md)）；\(P + (-P) = \mathcal{O}\)。动画 2 里阶为 8 的子群只是这条曲线 18 个有理点的一部分——**群结构由 Hasse 定理框住**：\(\lvert \#E(\mathbb{F}_p) - (p+1)\rvert \le 2\sqrt{p}\)（「椭圆曲线上的黎曼猜想」）。

## 标量乘：double-and-add 与它的安全面

\(kP\) 就是把二进制快速幂搬到群上：扫 \(k\) 的比特，遇 1 加当前倍点，每步倍点。在动画 2 的阶 8 群上验证：\(157\,P = (157 \bmod 8)\,P = 5P = (9,16)\)——double-and-add 自动利用群的周期性。

```java [Java]
// 教学版仿射坐标（含逆元）；工程用 P-256/X25519 库
record Pt(long x, long y) {}
static final long P17 = 17, A = 2, B = 2;                      // y² = x³+2x+2 (mod 17)

static Pt add(Pt p1, Pt p2) {
    if (p1 == null) return p2; if (p2 == null) return p1;      // null ≔ 无穷远点 O
    if (p1.x() == p2.x() && (p1.y() + p2.y()) % P17 == 0) return null;
    long lam;
    if (p1.x() == p2.x() && p1.y() == p2.y())
        lam = mulmod((3 * p1.x() % P17 * p1.x() % P17 + A) % P17, inv(2 * p1.y() % P17));
    else
        lam = mulmod((p2.y() - p1.y() + P17) % P17, inv((p2.x() - p1.x() + P17) % P17));
    long x3 = (mulmod(lam, lam) - p1.x() - p2.x() + 2 * P17) % P17;
    long y3 = (mulmod(lam, (p1.x() - x3 + P17) % P17) - p1.y() + P17) % P17;
    return new Pt(x3, y3);
}
static long mulmod(long a, long b) { return a * b % P17; }
static long inv(long x) {                                      // 费马小定理逆元
    long r = 1, e = P17 - 2, base = x % P17;
    while (e > 0) { if ((e & 1) == 1) r = r * base % P17; base = base * base % P17; e >>= 1; }
    return r;
}
static Pt mul(Pt p, long k) {                                   // double-and-add
    Pt r = null, q = p;
    while (k > 0) { if ((k & 1) == 1) r = add(r, q); q = add(q, q); k >>= 1; }
    return r;
}
// mul(new Pt(5,1), 3) → Pt(7,16)；mul(new Pt(5,1), 8) → null（阶 8）
```

```rust [Rust]
// 逻辑同 Java 版：add 由调用方以曲线结构实现（含域逆元），此处核心倍加循环
pub fn mul(p: Option<(i64, i64)>, k: u64, add: &impl Fn(Option<(i64, i64)>,
                                                         Option<(i64, i64)>)
                                                         -> Option<(i64, i64)>)
        -> Option<(i64, i64)> {
    let (mut r, mut q) = (None, p);
    let mut bits = k;
    while bits > 0 {
        if bits & 1 == 1 { r = add(r, q); }
        q = add(q, q);
        bits >>= 1;
    }
    r
}
// mul(Some((5,1)), 3, &add) → Some((7,16))，mul(Some((5,1)), 8, &add) → None
```

```typescript [TypeScript]
function mul(p: [number, number] | null, k: number,
             add: (a: [number, number] | null, b: [number, number] | null)
                  => [number, number] | null) {
  let r: [number, number] | null = null, q = p;
  while (k > 0) { if (k & 1) r = add(r, q); q = add(q, q); k >>= 1; }
  return r;
}
```

```python [Python]
p, a = 17, 2
inv = pow                                    # x^(p-2) mod p 亦可用费马小定理
def add(P, Q):
    if P is None: return Q
    if Q is None: return P
    (x1, y1), (x2, y2) = P, Q
    if x1 == x2 and (y1 + y2) % p == 0: return None
    if P == Q:
        lam = (3 * x1 * x1 + a) * pow(2 * y1, -1, p) % p
    else:
        lam = (y2 - y1) * pow(x2 - x1, -1, p) % p
    x3 = (lam * lam - x1 - x2) % p
    return (x3, (lam * (x1 - x3) - y1) % p)

def mul(P, k):                                # double-and-add
    r, q = None, P
    while k:
        if k & 1: r = add(r, q)
        q = add(q, q); k >>= 1
    return r

assert mul((5, 1), 3) == (7, 16)              # 动画 2 第 2 步
assert mul((5, 1), 8) is None                 # P 的阶为 8
```

## ECDH：三步握手

仿照 DH，把 \(g^a \bmod p\) 换成 \(aG\)（\(G\) 为曲线的公开基点）：Alice 出私钥 \(n_A\)、公钥 \(Q_A = n_A G\)；双方各算 \(n \cdot Q_{对方}\)，取结果的 \(x\) 坐标进 KDF 得会话密钥。密码学含义：**从公钥 \(Q\) 反推 \(n\) 即 ECDLP**，256-bit 曲线给出 128-bit 安全强度——这是它碾压 RSA 效率的根源。

工程默认 **X25519**：Montgomery 曲线 \(y^2 = x^3 + 486662x + x^2\) 上只用 x 坐标的「微分加法」标量乘——一条梯子公式统一处理倍点/加点，天然抵抗「平方测漏」类侧信道，且其扭曲曲线全覆盖小群（协因子 8 在公式内消化）。

## 常见陷阱

::: danger 陷阱清单
1. **曲线参数后门**：NIST 曲线的种子如何生成至今存疑（"4mt nowhere" 传闻与 Dual_EC 先例）；新系统优先 Curve25519——参数公开 derivation、无悬念。
2. **不验证对方公钥**：收到的点可能不在曲线上（**无效曲线攻击**：在弱曲线上 ECDLP 易解，CRT 拼私钥）、或落在小因子子群（小群攻击）——校验点在曲线上且属于大素数阶子群，或用 X25519 的协因子设计。
3. **非常数时间标量乘**：仿射 add/double 公式分支不同 + 是否跳过加点的分支，把 \(k\) 的比特图案写进时间曲线——固定窗口/滑动窗口 + 盲化，或直接用 ladder 实现。
4. **重用临时私钥**：一次会话一对临时密钥才有前向保密；ECDSA 里 nonce \(k\) 重用/低熵则直接**泄露私钥**（PS3 固件事件、Android Bitcoin 钱包事件——攻击手段正是 050 篇的格规约/简单代数）。
5. **自定义曲线图省事**：阶没验、twist 不安全、判别式退化（\(4a^3+27b^2 \equiv 0\)）的「曲线」根本不是群——只用命名曲线。
6. **把 x 坐标当最终密钥**：交换结果分布不均且长度固定——KDF 是必选项（同 030 篇纪律）。
:::

# 总结

- ECC 的代数几何外衣下只有一个小学生模型：**点可以加（弦切法），加法是交换群，数乘 \(kP\) 好算、反推 \(k\)（ECDLP）难**——公钥密码的全部积木凑齐。
- 密钥短是它最大的工程红利：256-bit ≈ 3072-bit RSA，TLS 握手体积与移动端性能直接受益；X25519 + 微分加法梯子把「快」与「抗侧信道」一并打包。
- 纪律与 DH 一脉相承：**公钥要验证、临时密钥一次一换、共享秘密过 KDF**；ECDSA 的 nonce 是「用一次就死」的耗材（详见 [070.数字签名](./070.数字签名.md)）。
- 历史伏笔：椭圆曲线还因 Mordell-Weyl、因谷山-志村猜想证明费马大定理——如今它在密码学里的第三次出场，正被 [050.LLL格基规约](./050.LLL格基规约.md) 与量子的 Shor 算法两面夹击，这也是 TLS 混入 X25519+ML-KEM 双密钥的原因。
