# 概述

一组 \(n\) 维线性无关向量（**基**）张成的格子 \(\Lambda = \{\sum z_i b_i : z_i \in \mathbb{Z}\}\) 有无穷多种基表示——同一格、天壤之别的「好看程度」。**LLL 格基规约**（Lenstra-Lenstra-Lovász，1982）把任意畸形基改造成「几乎正交、向量几乎最短」的好看基，多项式时间 \(O(n^5 \log \max\lVert b_i\rVert)\)。它是密码分析的瑞士军刀：**求格中最短向量（SVP）的近似解、找整数关系、分解带泄漏的 RSA、用几个泄露随机数回收 ECDSA 私钥**；同时又是后量子密码的假想敌（基于格的 cryptosystem 的安全性正以「LLL/BKZ 攻不动」为定义）。2021 年它拿下数学最高奖沃尔夫奖——一个算法能同时服务攻防两侧，历史上不多见。

- 所属章节：[000.密码学算法概述](./000.密码学算法概述.md)
- 时间复杂度：LLL 最坏 \(O(n^5 \log B)\)（\(B = \max \lVert b_i \rVert\)）；实践中远快于最坏界；2 维即经典高斯规约
- 空间复杂度：\(O(n^2)\)（基矩阵 + Gram-Schmidt 系数）
- 应用场景：SVP/CVP 近似、整数关系检测（PSLQ 证实 π/ln2 猜想的引擎）、密码分析（Coppersmith 小根、Hidden Number Problem、低私密 RSA）、格密码参数标定（NISP 估算 BKZ 强度）
- 前置概念： Gram-Schmidt 正交化见 [07.数值计算/020.矩阵运算算法](../07.数值计算/020.矩阵运算算法.md)，同余与逆元见 [06.字符串与数论/080.扩展欧几里得与同余方程](../06.字符串与数论/080.扩展欧几里得与同余方程.md)

初始基 \(b_1=(1,1)\)、\(b_2=(0,1)\)（平行四边形斜而胖）：

1. **Gram-Schmidt**：\(b_1^* = (1,1)\)；\(b_2^* = b_2 - \frac{\langle b_2, b_1^*\rangle}{\langle b_1^*, b_1^*\rangle} b_1^* = (0,1) - \frac{1}{2}(1,1) = (-\tfrac12, \tfrac12)\)；\(\mu_{21} = \frac{\langle b_2, b_1^*\rangle}{\langle b_1^*, b_1^*\rangle} = \frac12\)。
2. **看条件**：尺寸约化要求 \(|\mu_{21}| \le \frac12\)——恰好压线通过；Lovász 条件 \(\lVert b_2^*\rVert^2 \ge (\frac34 - \mu_{21}^2)\lVert b_1^*\rVert^2\)：左 \(=\frac12\)，右 \(= (\frac34-\frac14)\times 2 = 1\)，\(\frac12 < 1\) **违反**。
3. **交换** \(b_1 \leftrightarrow b_2\)：新基 \((0,1),(1,1)\)，重算 \(\mu_{21} = 1\)——违反尺寸约化。
4. **尺寸约化**：\(b_2 \leftarrow b_2 - \mathrm{round}(\mu_{21}) b_1 = (1,1) - (0,1) = (1,0)\)；新 \(\mu_{21} = 0\)。
5. 检查：\(\lVert b_2^*\rVert^2 = 1 \ge (\frac34 - 0)\times 1 = 0.75\) ✓ 收敛——输出标准正交基 \(\{(0,1),(1,0)\}\)，正是这个整数格的最短向量组。

**动画 2：坏基 vs 好基的判格能力**

1. 画同一格的两套基：坏基 \(b_1=(1000,1), b_2=(999,0)\) 张出极扁的斜平行四边形；LLL 输出好基 \(\{(1,0),(0,1)\}\)（该格实为 \(\mathbb{Z}^2\)）。
2. 在「短向量搜索」任务里：坏基下随机取组合几乎碰不到 \((0,1)\)；好基的基向量本身已是最短候选。
3. 密码含义：把秘密藏进「坏基下的短格向量」（如 NTRU 公钥、带噪声的 LWE 样本），防御者赌你找不到那条短向量——LLL/BKZ 就是攻击者的「找短器」。

# 详解

## LLL 的两个条件

规约基（delta 常取 \(3/4\)）需同时满足：

- **尺寸约化（size-reduced）**：对所有 \(j < i\)，\(|\mu_{ij}| \le \frac12\)——每个基向量在之前方向上的「投影分量」都不超过一半；不满足就 \(b_i \leftarrow b_i - \mathrm{round}(\mu_{ij})b_j\)；
- **Lovász 条件**：\(\lVert b_{i+1}^*\rVert^2 \ge (\delta - \mu_{i+1,i}^2)\,\lVert b_i^*\rVert^2\)——正交分量不能「突然变瘦」；不满足就交换 \(b_i, b_{i+1}\) 并回退一步。

保证终止的势函数是**格子行列式上的 GSO 体积乘积** \(\prod_{i}\lVert b_i^*\rVert\)：每次交换使其严格下降，而它下界为 \(\det(\Lambda)^{n}\) 相关常数——有限下降步内必收敛。LLL 输出的最短向量满足 **Hermite 近似** \(\lVert b_1\rVert \le 2^{(n-1)/2} \lambda_1\)——指数级近似对高维 SVP 只是「能用」，求质量要上 **BKZ**（块大小 \(h\) 的增强版，格密码安全估算的行业标尺）。

## 高斯规约（2 维）与 LLL（n 维）

```java [Java]
// 2 维高斯规约：动画里 (1,2,3)+(3,4,5) → (1,2,3)+(-2,-1,0) 的算法版
public static double[][] gaussReduce(double[][] b) {
    for (boolean go = true; go; ) {
        double dot = b[0][0]*b[1][0] + b[0][1]*b[1][1] + b[0][2]*b[1][2];
        double nn  = b[0][0]*b[0][0] + b[0][1]*b[0][1] + b[0][2]*b[0][2];
        double r = Math.rint(dot / nn);                    // ⌊x+½⌋ 最近取整
        for (int t = 0; t < 3; t++) b[1][t] -= r * b[0][t];
        if (norm(b[1]) < norm(b[0])) {                     // 交换并继续
            double[] tmp = b[0]; b[0] = b[1]; b[1] = tmp;
        } else go = false;
    }
    return b;
}
static double norm(double[] v) { return Math.sqrt(v[0]*v[0] + v[1]*v[1] + v[2]*v[2]); }
// gaussReduce({{1,2,3},{3,4,5}}) → {(1,2,3),(-2,-1,0)}（±(2,1,0) 同解）
```

```rust [Rust]
/// n 维 LLL（f64 教学版）：每轮重算 Gram-Schmidt，结构同下 TypeScript 版
pub fn lll(mut b: Vec<Vec<f64>>) -> Vec<Vec<f64>> {
    let n = b.len();
    let dot = |x: &[f64], y: &[f64]| x.iter().zip(y).map(|(a, c)| a * c).sum::<f64>();
    let mut k = 1;
    while k < n {
        // —— Gram-Schmidt：star = 正交化向量，mu = 系数 ——
        let mut star: Vec<Vec<f64>> = Vec::with_capacity(n);
        let mut mu = vec![vec![0.0; n]; n];
        for i in 0..n {
            let mut v = b[i].clone();
            for j in 0..i {
                mu[i][j] = dot(&b[i], &star[j]) / dot(&star[j], &star[j]);
                for t in 0..v.len() { v[t] -= mu[i][j] * star[j][t]; }
            }
            star.push(v);
        }
        for j in (0..k).rev() {                             // 尺寸约化
            let r = mu[k][j].round();
            if r != 0.0 {
                for t in 0..n { b[k][t] -= r * b[j][t]; }
            }
        }
        // 交换后重算一次 GSO 再判 Lovász（与上同构，略去重复代码）
        let (nk, nk1, mu_k) = (dot(&star[k], &star[k]), dot(&star[k-1], &star[k-1]), mu[k][k-1]);
        if nk >= (0.75 - mu_k * mu_k) * nk1 {
            k += 1;                                          // Lovász 满足，前进
        } else {
            b.swap(k, k - 1);
            k = (k - 1).max(1);                              // 回退
        }
    }
    b
}
// lll([[1,2,3],[3,4,5]]) → [[1,2,3],[-2,-1,0]]（f64 舍入边界可能差一个符号，
// 精确复现请用下方 Fraction 版——这正是「浮点 LLL 需小心」的活例）
```

```typescript [TypeScript]
function lll(b: number[][]): number[][] {
  const n = b.length;
  const dot = (x: number[], y: number[]) =>
    x.reduce((s, v, i) => s + v * y[i], 0);
  const gs = (bk: number[][]) => {                          // Gram-Schmidt 系数
    const star = bk.map(r => [...r]);
    const mu: number[][] = [];
    for (let i = 0; i < bk.length; i++) {
      mu[i] = [];
      for (let j = 0; j < i; j++) {
        mu[i][j] = dot(bk[i], star[j]) / dot(star[j], star[j]);
        for (let t = 0; t < bk[i].length; t++) star[i][t] -= mu[i][j] * star[j][t];
      }
    }
    return { star, mu };
  };
  let A = b.map(r => [...r]), k = 1;
  while (k < n) {
    let { star, mu } = gs(A);
    for (let j = k - 1; j >= 0; j--) {                      // 尺寸约化
      const r = Math.round(mu[k][j]);
      if (r !== 0) A[k] = A[k].map((v, t) => v - r * A[j][t]);
    }
    ({ star, mu } = gs(A));
    const nk = dot(star[k], star[k]), nk1 = dot(star[k - 1], star[k - 1]);
    if (nk >= (0.75 - mu[k][k - 1] ** 2) * nk1) k++;        // Lovász
    else { [A[k], A[k - 1]] = [A[k - 1], A[k]]; k = Math.max(k - 1, 1); }
  }
  return A;
}
```

```python [Python]
from fractions import Fraction

def lll(b):
    """教科书 LLL（精确有理数），b 为 list[list[int]]"""
    b = [list(map(Fraction, row)) for row in b]
    n = len(b)

    def dot(x, y): return sum(i * j for i, j in zip(x, y))

    def gso():
        star, mu = [], [[Fraction(0)] * n for _ in range(n)]
        for i in range(n):
            v = b[i][:]
            for j in range(i):
                mu[i][j] = dot(b[i], star[j]) / dot(star[j], star[j])
                v = [t - mu[i][j] * s for t, s in zip(v, star[j])]
            star.append(v)
        return star, mu

    k = 1
    while k < n:
        star, mu = gso()
        for j in range(k - 1, -1, -1):                      # 尺寸约化
            r = round(mu[k][j])                             # 最近取整
            if r:
                b[k] = [x - r * y for x, y in zip(b[k], b[j])]
        star, mu = gso()
        if dot(star[k], star[k]) >= (Fraction(3, 4) - mu[k][k-1] ** 2) \
                * dot(star[k-1], star[k-1]):                # Lovász
            k += 1
        else:
            b[k], b[k-1] = b[k-1], b[k]
            k = max(k - 1, 1)
    return [[int(x) for x in row] for row in b]

assert lll([[1,2,3],[3,4,5]]) == [[1,2,3],[-2,-1,0]]       # 动画手算的算法版
```

## 杀手级应用：用 LLL 解子集和

给定 \(\{a_i\}\) 与目标和 \(S\)，找 \(\sum \epsilon_i a_i = S,\ \epsilon_i \in \{0,1\}\)。把「0/1 选择」嵌进格：构造基行

\[
\begin{pmatrix} M & a_1 & a_2 & \cdots & a_n \\ 0 & \pm 2a_1 & 0 & \cdots & 0 \\ \vdots & & \ddots & & \\ 0 & 0 & \cdots & \pm 2a_n \end{pmatrix}
\qquad \text{目标列 } t = (M,\; 2S,\; 0, \ldots, 0)
\]

LLL/CVP 找出的短向量会把「哪些 \(\epsilon_i=1\)」编码成 \(\pm 2a_i\) 行的组合。手算例 \(\{3,5,7,11,14\}\)、\(S = 15\)：解 \(3+5+7=15\) 存在（\(11+14 \ne 15\)、\(3+11=14\)……逐一穷举可验）。Coppersmith 方法更是把「RSA 明文低位已知/私钥 d 过小」统一改写成「某多项式格上有短向量」→ LLL 一步回收——**格规约是现代密码分析的第一语言**。

## 常见陷阱

::: danger 陷阱清单
1. **把 LLL 当精确 SVP 求解器**：Hermite 近似因子 \(2^{(n-1)/2}\) 在高维很松；安全评估必须报 BKZ-\(h\) 块大小与经验 root-Hermite 因子，否则「LLL 没找到」≠「问题困难」。
2. **浮点 LLL 精度雪崩**：\(n > 40\) 或位长大的基，f64 的 GSO 误差会让算法绕圈甚至给出非基——学术实现一律 fmpz/精确有理（Python 版用 `Fraction` 正是此因），或 LLLFP/Azpard 双精度策略。
3. **生成集不是基**：行数 > 维数时格子仍是整点格，但需先化 Hermite 标准形（HNF）去掉冗余行再规约；直接对冗余行跑 LLL 得到的是错误对象的规约。
4. **嵌入系数 M 选错**：子集和/填充问题里 \(M\) 太小让目标列没资格进短向量、太大稀释信号——\(M \sim \sum a_i\) 量级起步，失败时双向调整。
5. **只规约不读解**：LLL 改变基同时必须同步追踪**幺模变换矩阵**（行列式 ±1 的整数矩阵）\(U\)（\(B' = UB\)），否则找到的短向量不知道对应原基的哪组整数组合——解的坐标在 \(U\) 里，不在 \(B'\) 里。
6. **对「格问题=困难问题」的迷信**：低维（\(n \lesssim 60\)）的 SVP 今天可用 BKZ-40 实时秒掉；格密码的安全参数全部以「几百维 + 大块 BKZ」计价——设计者标 128-bit 强度前先查最新 lattice estimator 表。
:::

# 总结

- LLL = 「尺寸约化 + Lovász 交换」的两步循环 + 一个严格下降的势函数：多项式时间把任意畸形基磨成近正交好基，2 维退化即高斯经典算法。
- 它是**攻防双面刃**：攻击侧——Coppersmith、HNP、ECDSA  nonce 回收、低密 RSA 全都归结为「构造格 → 找短向量」；防御侧——后量子格密码的安全性定义就是「你们把 LLL/BKZ 用到极致也解不动」。
- 实践三句话：教学用精确有理数、科研用 fplll、参数评估查 lattice estimator——「跑了 LLL 没找到短向量」永远不是安全证明。
