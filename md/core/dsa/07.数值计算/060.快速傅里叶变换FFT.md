# 概述

快速傅里叶变换（Fast Fourier Transform, FFT）把离散傅里叶变换（DFT）从朴素 \(O(n^2)\) 加速到 \(O(n \log n)\)：利用 \(n\) 次单位根的对称性 \(\omega_n^{k+n/2} = -\omega_n^k\)，把长度为 \(n\) 的变换拆成两个偶/奇子序列的长度 \(n/2\) 变换，分治合并。它由 Cooley-Tukey（1965）普及、Gaist 在 1880 年代已秘密提出，被《Computing in Science & Engineering》列为十大算法之一——频域分析、多项式/大整数乘法、卷积神经网络，全部跑在这块地基上。

- 所属章节：[000.数值计算概述](./000.数值计算概述.md)
- 时间复杂度：\(T(n) = 2T(n/2) + O(n) = O(n\log n)\)（对比朴素 DFT 的 \(O(n^2)\)：\(n = 1024\) 时约省 200 倍）
- 空间复杂度：递归版 \(O(n\log n)\)（各层子数组之和）；迭代原地版 \(O(n)\)
- 应用场景：音频/图像频谱分析（音乐播放器可视化、MP3 编码的 MDCT 前奏）、卷积定理加速（[08.机器学习算法/050.神经网络与反向传播](../08.机器学习算法/050.神经网络与反向传播.md) 的 FFT 卷积层）、大整数乘法（Python `int` 与 GMP 在数千位以上切换 FFT/Toom-Cook 路线）、OFDM 通信（4G/5G/Wi-Fi 的子载波调制）、多项式插值与乘法（呼应本篇 [070.Karatsuba乘法](./070.Karatsuba乘法.md)）、求解偏微分方程的谱方法
- 前置：分治与主定理见 [04.核心算法思想/050.分治算法](../04.核心算法思想/050.分治算法.md)；复数运算与单位根 \(e^{2\pi i/n}\) 的周期性质

# 详解

## 从 DFT 定义到分治

DFT 定义为 \(X_k = \sum_{j=0}^{n-1} a_j \omega_n^{jk}\)，其中 \(\omega_n = e^{-2\pi i/n}\)。朴素实现是 \(n \times n\) 的 Vandermonde 矩阵乘法，需 \(O(n^2)\) 次复乘。Cooley-Tukey 把和式按奇偶拆分（设 \(n\) 为 2 的幂）：

\[
X_k = \underbrace{\sum_j a_{2j}\,\omega_{n/2}^{jk}}_{\text{偶子序列 DFT } E_k} + \omega_n^k \underbrace{\sum_j a_{2j+1}\,\omega_{n/2}^{jk}}_{\text{奇子序列 DFT } O_k}
\]

关键在 \(\omega^2\) 的周期折叠：\(\omega_n^{2k} = \omega_{n/2}^{k}\)，所以两个子问题正是规模减半的 DFT；再利用 \(\omega_n^{k+n/2} = -\omega_n^k\) 得对称对 \(X_{k+n/2} = E_k - \omega_n^k O_k\)——一次复乘同时算出两个输出点，这就是「蝶形」。递推 \(T(n)=2T(n/2)+O(n)\) 给 \(O(n\log n)\)。

**逆变换**：把 \(\omega\) 换成 \(\bar\omega\)（即旋转共轭）再除以 \(n\)，同一份代码复用。**迭代版本**：先把输入按二进制位逆序重排，再自底向上按层做蝶形，省去递归开销与子数组拷贝——库实现（FFTW 等）在此之上还做缓存分块与混合基分解。

```java [Java]
// 复数用 double[] 交错存储：[re0, im0, re1, im1, ...]
public static double[] fft(double[] re, double[] im) {
    int n = re.length;
    if (n == 1) return new double[]{re[0], im[0]};
    double[] er = new double[n / 2], ei = new double[n / 2];
    double[] qr = new double[n / 2], qi = new double[n / 2];
    for (int i = 0; i < n / 2; i++) {
        er[i] = re[2 * i];     ei[i] = im[2 * i];
        qr[i] = re[2 * i + 1]; qi[i] = im[2 * i + 1];
    }
    double[] fe = fft(er, ei);
    double[] fo = fft(qr, qi);
    double[] out = new double[2 * n];
    for (int k = 0; k < n / 2; k++) {
        double ang = -2 * Math.PI * k / n;
        double wr = Math.cos(ang), wi = Math.sin(ang);
        double tr = wr * fo[2 * k] - wi * fo[2 * k + 1];   // w^k · O_k
        double ti = wr * fo[2 * k + 1] + wi * fo[2 * k];
        out[2 * k] = fe[2 * k] + tr;         out[2 * k + 1] = fe[2 * k + 1] + ti;
        out[2 * (k + n / 2)] = fe[2 * k] - tr;
        out[2 * (k + n / 2) + 1] = fe[2 * k + 1] - ti;
    }
    return out;
}

/** 逆变换：共轭技巧 + 除以 n */
public static double[] ifft(double[] re, double[] im) {
    int n = re.length;
    double[] nim = new double[n];
    for (int i = 0; i < n; i++) nim[i] = -im[i];
    double[] f = fft(re, nim);
    for (int i = 0; i < 2 * n; i++) f[i] /= n;
    return f;
}
```

```rust [Rust]
/// 复数以 (re, im) 元组表示；长度须为 2 的幂
pub fn fft(a: &[(f64, f64)]) -> Vec<(f64, f64)> {
    let n = a.len();
    if n == 1 {
        return a.to_vec();
    }
    let even: Vec<(f64, f64)> = a.iter().step_by(2).copied().collect();
    let odd: Vec<(f64, f64)> = a.iter().skip(1).step_by(2).copied().collect();
    let fe = fft(&even);
    let fo = fft(&odd);
    let mut out = vec![(0.0, 0.0); n];
    for k in 0..n / 2 {
        let ang = -2.0 * std::f64::consts::PI * (k as f64) / (n as f64);
        let (wr, wi) = (ang.cos(), ang.sin());
        let t = (wr * fo[k].0 - wi * fo[k].1, wr * fo[k].1 + wi * fo[k].0);
        out[k] = (fe[k].0 + t.0, fe[k].1 + t.1);
        out[k + n / 2] = (fe[k].0 - t.0, fe[k].1 - t.1);
    }
    out
}

/// 逆变换
pub fn ifft(a: &[(f64, f64)]) -> Vec<(f64, f64)> {
    let n = a.len() as f64;
    let conj: Vec<(f64, f64)> = a.iter().map(|&(r, i)| (r, -i)).collect();
    fft(&conj).iter().map(|&(r, i)| (r / n, -i / n)).collect()
}
```

```typescript [TypeScript]
type C = { re: number; im: number };
const cmul = (a: C, b: C): C =>
  ({ re: a.re * b.re - a.im * b.im, im: a.re * b.im + a.im * b.re });

function fft(a: C[]): C[] {
  const n = a.length;
  if (n === 1) return [...a];
  const fe = fft(a.filter((_, i) => i % 2 === 0));
  const fo = fft(a.filter((_, i) => i % 2 === 1));
  const out = new Array<C>(n);
  for (let k = 0; k < n / 2; k++) {
    const ang = -2 * Math.PI * k / n;
    const w: C = { re: Math.cos(ang), im: Math.sin(ang) };
    const t = cmul(w, fo[k]);
    out[k] = { re: fe[k].re + t.re, im: fe[k].im + t.im };
    out[k + n / 2] = { re: fe[k].re - t.re, im: fe[k].im - t.im };
  }
  return out;
}

function ifft(a: C[]): C[] {
  const n = a.length;
  const conj = a.map(z => ({ re: z.re, im: -z.im }));
  return fft(conj).map(z => ({ re: z.re / n, im: -z.im / n }));
}

// 多项式乘法：fft → 逐点乘 → ifft，图解例返回 [1+0i, 5+0i, 9+0i, 9+0i]
function polyMul(pa: number[], pb: number[]): number[] {
  const size = 1 << Math.ceil(Math.log2(pa.length + pb.length - 1));
  const toC = (p: number[]) =>
    Array.from({ length: size }, (_, i) => ({ re: p[i] ?? 0, im: 0 }));
  const fa = fft(toC(pa)), fb = fft(toC(pb));
  const prod = fa.map((z, i) => cmul(z, fb[i]));
  return ifft(prod).map(z => Math.round(z.re));
}
```

```python [Python]
import cmath

def fft(a):
    n = len(a)
    if n == 1:
        return a
    even = fft(a[0::2])                     # 偶下标子序列
    odd = fft(a[1::2])                      # 奇下标子序列
    wz = [cmath.exp(-2j * cmath.pi * k / n) * o
          for k, o in enumerate(odd)]
    return [e + t for e, t in zip(even, wz)] + \
           [e - t for e, t in zip(even, wz)]

def ifft(a):
    n = len(a)
    return [x / n for x in fft([x.conjugate() for x in a])]

def poly_mul(pa, pb):
    """多项式系数表 → 乘积系数表；图解例 (1+2x+3x²)(1+3x) → [1, 5, 9, 9]"""
    size = 1 << (len(pa) + len(pb) - 2).bit_length()
    fa = fft(pa + [0] * (size - len(pa)))
    fb = fft(pb + [0] * (size - len(pb)))
    return [round(x.real) for x in ifft([x * y for x, y in zip(fa, fb)])]
```

## 卷积定理：FFT 的第二个身份

DFT 把**循环卷积**变成逐点乘：\(\text{DFT}(a * b) = \text{DFT}(a) \cdot \text{DFT}(b)\)。线性卷积（多项式乘法、滤波）通过补零到 \(m+n-1\) 长度化为循环卷积的特例。这一条定理同时解释了三个应用：音频滤波（频域一次乘法替代时域 \(O(n^2)\) 滑动窗口）、CNN 卷积层加速（大卷积核时 FFT 优于 im2col）、大整数乘法（把数位按 3-4 位一组拆成多项式系数，逐点乘后回代进位——Python 在千位级以上的 `int` 乘法就是这么做的）。

## 常见陷阱

1. **`ω` 的连乘漂移**：用 `w *= omega_base` 递推旋转因子，几万层后复乘误差累积可达 \(10^{-6}\) 级；稳定做法是每个 \(k\) 直接 `cos/sin` 计算（本实现如此），或预计算高精度查表。
2. **逆变换忘除 \(n\)**：正变换矩阵 \(F\) 满足 \(F^H F = nI\) 而不是 \(I\)，共轭技巧回来后必须除以 \(n\)——忘除的症状是结果「全放大 n 倍」，恰好能通过卷积形状测试却数值全错。
3. **长度必须是 2 的幂**：本实现 `if n == 1` 之外不做校验，输入 1000 直接栈崩逻辑错。实际使用时先补零到 `nextPowerOfTwo`；非 2 幂且不能补时用 Bluestein/混合基（库的领域）。
4. **大整数乘法的进位地狱**：FFT 系数是浮点，逐点乘后的逆变换带 ±ε 误差；数根基数选太大（如每组 8 位十进制）时舍入误差可越过 0.5 导致进位错——工程上用较小基数 + 三模 NTT，或拆段进位，或在素数域用数论变换 NTT 全程整数（单位根换成原根幂，见 [06.字符串与数论/070.快速幂与模运算](../06.字符串与数论/070.快速幂与模运算.md)）。
5. **递归版常数与栈**：`a.filter` 每层建新数组，真实实现用位逆序 + 原地迭代；Web Audio 等场景直接用浏览器原生 `fft` 库而非贴本篇教学代码。
6. **别把 FFT 当频谱的全部**：对有限长信号做 FFT 前通常加窗（Hann/Hamming），否则时域截断的边沿在频域泄露成 sinc 旁瓣——「泄漏」问题属于信号处理约定，不是算法 bug。

# 总结

FFT 是分治思想在数值计算里最辉煌的样本：借单位根的周期对称，把 DFT 的 \(n^2\) 次复乘压到 \(n\log n\)，代价只是一次奇偶拆分与蝶形合并。它的两副面孔——**频域分析仪**（信号处理、OFDM、谱方法）与**乘法加速器**（多项式、大整数、卷积）——在工程上同样重要：与 [070.Karatsuba乘法](./070.Karatsuba乘法.md) 的「3 次乘法分治」相比，FFT 把渐近线推进到 \(O(n\log n)\)，但 Karatsuba 在小规模与全整数域上仍是主力（GMP 按位数切换两者）。下一站 [070.Karatsuba乘法](./070.Karatsuba乘法.md) 看大整数家族里那位更古老、更简单的成员。
