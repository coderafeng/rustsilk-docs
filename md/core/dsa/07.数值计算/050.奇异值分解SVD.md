# 概述

奇异值分解（Singular Value Decomposition, SVD）把**任意** \(m \times n\) 矩阵 \(A\) 拆成三个几何意义明确的因子：\(A = U \Sigma V^T\)——先旋转（\(V^T\)）、再沿坐标轴缩放（\(\Sigma\)）、再旋转（\(U\)），中间不需要矩阵是方阵、对称或满秩。这使 SVD 成为线性代数的「终极瑞士军刀」：秩、伪逆、主成分、低秩逼近、矩阵求逆的病态诊断，全部可以从同一组奇异值/奇异向量读出。

- 所属章节：[000.数值计算概述](./000.数值计算概述.md)
- 时间复杂度：全量分解 \(O(mn\min(m,n))\)（Golub-Kahan 双对角化 + 隐式 QR）；截断取前 \(k\) 个奇异对可用幂迭代/随机化 SVD 降到约 \(O(mnk)\) 甚至更低
- 空间复杂度：\(O(mn)\)（存储 \(U, \Sigma, V\)；截断版只存 \(k\) 对向量 \(O((m+n)k)\)）
- 应用场景：推荐系统的矩阵分解（MovieLens 用户-物品评分表）、潜在语义分析 LSA（文本向量降维）、图像压缩与去噪（[10.应用与专题/020.有损压缩原理](../10.应用与专题/020.有损压缩原理.md)）、伪逆与最小二乘（[08.机器学习算法/030.监督学习算法](../08.机器学习算法/030.监督学习算法.md) 正规方程的稳定替代）、PCA 的数值实现引擎（[040.主成分分析PCA](./040.主成分分析PCA.md)）、机器人学雅可比零空间分析
- 前置：矩阵乘法与求逆的边界见 [020.矩阵运算算法](./020.矩阵运算算法.md)；特征值视角见 [040.主成分分析PCA](./040.主成分分析PCA.md)

# 详解

## 存在性与定义

对任意 \(A \in \mathbb{R}^{m \times n}\)，\(A^TA\) 是对称半正定的，必可正交对角化：\(A^TA = V\Sigma_0 V^T\)，其特征值 \(\sigma_i^2 \ge 0\) 开方即**奇异值**（按降序排列），\(V\) 的列是右奇异向量；对非零 \(\sigma_i\) 令 \(u_i = \frac{1}{\sigma_i}Av_i\)，再补齐 \(U\) 的正交基即得 \(A = U\Sigma V^T\)。四个基本子空间被同一组向量瓜分干净：\(v_1..v_r\) 张行空间、\(v_{r+1}..v_n\) 张零空间、\(u_1..u_r\) 张列空间、\(\sigma_i\) 给出列空间到行空间的「最佳方向对」——这是《Introduction to Linear Algebra》所谓「线性代数的基本定理终于完整」。

**与特征分解的关系**：\(A\) 对称半正定时 SVD 退化为特征分解；一般情况下奇异值来自 \(A^TA\) 而非 \(A\) 本身，所以**永远存在、数值稳定**（条件数只被 \(\kappa = \sigma_1/\sigma_r\) 影响一次平方，而正规方程路线要平方两次）。

## Eckart-Young 定理：低秩逼近的最优解

在所有秩 \(\le k\) 矩阵中，截断 SVD \(A_k = \sum_{i=1}^k \sigma_i u_i v_i^T\) 同时是谱范数与 Frobenius 范数下的最优逼近，且误差恰为被弃掉的第一个奇异值/尾部奇异值平方和开方：

\[
\min_{\text{rank}(B) \le k} \|A - B\|_2 = \sigma_{k+1}, \qquad
\min_{\text{rank}(B) \le k} \|A - B\|_F = \sqrt{\textstyle\sum_{i>k} \sigma_i^2}
\]

这解释了为什么「矩阵分解 = 压缩」：推荐系统里评分矩阵 \(R \approx \sum_{i\le k}\sigma_i u_iv_i^T\) 的第 \(i\) 项可理解为「第 \(i\) 号用户口味维度」；图像里弃掉的尾部 \(\sigma\) 对应高频细节。**PCA 正是该定理在数据中心化数据矩阵上的化身**（[040.主成分分析PCA](./040.主成分分析PCA.md)：\(X\) 的右奇异向量即主成分）。

## 伪逆：病态系统的音量旋钮

\(A^+ = V\Sigma^+U^T\)，其中 \(\Sigma^+\) 把非零 \(\sigma_i\) 取倒数、并按阈值 `rcond` 丢弃「名义非零实际是噪声」的微小奇异值。它给出最小二乘解的最小范数解：\(x = A^+b\)。对比 [020.矩阵运算算法](./020.矩阵运算算法.md) 的显式求逆：正规方程 \((A^TA)^{-1}A^TA\) 路线的条件数是 \(\kappa^2\)，SVD 路线是 \(\kappa\)，且阈值截断本身就是正则化（「截断伪逆」与岭回归异曲同工）。

## 代码：幂迭代取第一奇异对，deflation 续取

求 \((\sigma_1, u_1, v_1)\) 只需对 \(A^TA\) 幂迭代（与 [040.主成分分析PCA](./040.主成分分析PCA.md) 同款技巧）：\(v \leftarrow A^TA v\) 归一化；得 \(v_1\) 后 \(\sigma_1 = \lVert A v_1\rVert\)、\(u_1 = Av_1/\sigma_1\)。取下一个分量前做 **deflation**：\(A \leftarrow A - \sigma_1u_1v_1^T\)。

```java [Java]
/** 返回 {sigma, u, v}：A 的最大奇异三元组 */
public static Object[] topSingularPair(double[][] a, int iters) {
    int m = a.length, n = a[0].length;
    java.util.function.Function<double[], double[]> av = x -> {
        double[] o = new double[m];
        for (int i = 0; i < m; i++) {
            double s = 0;
            for (int j = 0; j < n; j++) s += a[i][j] * x[j];
            o[i] = s;
        }
        return o;
    };
    java.util.function.Function<double[], double[]> atv = x -> {
        double[] o = new double[n];
        for (int j = 0; j < n; j++) {
            double s = 0;
            for (int i = 0; i < m; i++) s += a[i][j] * x[i];
            o[j] = s;
        }
        return o;
    };
    double[] v = new double[n];
    v[0] = 1.0;
    for (int it = 0; it < iters; it++) {
        double[] atav = atv.apply(av.apply(v));
        double norm = 0;
        for (double x : atav) norm += x * x;
        norm = Math.sqrt(norm);
        if (norm == 0) break;
        for (int j = 0; j < n; j++) v[j] = atav[j] / norm;
    }
    double[] au = av.apply(v);
    double sigma = 0;
    for (double x : au) sigma += x * x;
    sigma = Math.sqrt(sigma);
    double[] u = new double[m];
    for (int i = 0; i < m; i++) u[i] = au[i] / sigma;
    return new Object[]{sigma, u, v};
}
// 例：a = {{1,0,1},{0,1,0}} → sigma=√2, u=(1,0), v=(0.707,0,0.707)
```

```rust [Rust]
/// 返回 (sigma, u, v)
pub fn top_singular_pair(a: &[Vec<f64>], iters: usize) -> (f64, Vec<f64>, Vec<f64>) {
    let m = a.len();
    let n = a[0].len();
    let mat_vec = |x: &[f64]| -> Vec<f64> {
        a.iter().map(|row| row.iter().zip(x).map(|(p, q)| p * q).sum()).collect()
    };
    let tmat_vec = |x: &[f64]| -> Vec<f64> {
        (0..n).map(|j| (0..m).map(|i| a[i][j] * x[i]).sum()).collect()
    };
    let mut v = vec![0.0; n];
    v[0] = 1.0;
    for _ in 0..iters {
        let atav = tmat_vec(&mat_vec(&v));
        let norm = atav.iter().map(|x| x * x).sum::<f64>().sqrt();
        if norm == 0.0 {
            break;
        }
        for j in 0..n {
            v[j] = atav[j] / norm;
        }
    }
    let au = mat_vec(&v);
    let sigma = au.iter().map(|x| x * x).sum::<f64>().sqrt();
    let u: Vec<f64> = au.iter().map(|x| x / sigma).collect();
    (sigma, u, v)
}

/// deflation：A ← A − σ u vᵀ，继续调用可取下一个奇异对
pub fn deflate(a: &mut [Vec<f64>], sigma: f64, u: &[f64], v: &[f64]) {
    for (i, row) in a.iter_mut().enumerate() {
        for (j, cell) in row.iter_mut().enumerate() {
            *cell -= sigma * u[i] * v[j];
        }
    }
}
```

```typescript [TypeScript]
function topSingularPair(a: number[][], iters: number):
    { sigma: number; u: number[]; v: number[] } {
  const m = a.length, n = a[0].length;
  const matVec = (x: number[]) =>
    a.map(row => row.reduce((s, p, j) => s + p * x[j], 0));
  const tMatVec = (x: number[]) =>
    Array.from({ length: n }, (_, j) => {
      let s = 0;
      for (let i = 0; i < m; i++) s += a[i][j] * x[i];
      return s;
    });

  const v = new Array<number>(n).fill(0);
  v[0] = 1;
  for (let it = 0; it < iters; it++) {
    const atav = tMatVec(matVec(v));
    const norm = Math.hypot(...atav);
    if (norm === 0) break;
    atav.forEach((x, j) => { v[j] = x / norm; });
  }
  const au = matVec(v);
  const sigma = Math.hypot(...au);
  return { sigma, u: au.map(x => x / sigma), v };
}

function deflate(a: number[][], sigma: number, u: number[], v: number[]): number[][] {
  return a.map((row, i) => row.map((x, j) => x - sigma * u[i] * v[j]));
}
```

```python [Python]
def top_singular_pair(a, iters=200):
    m, n = len(a), len(a[0])
    def mat_vec(x):
        return [sum(p * q for p, q in zip(row, x)) for row in a]
    def tmat_vec(x):
        return [sum(a[i][j] * x[i] for i in range(m)) for j in range(n)]

    v = [1.0] + [0.0] * (n - 1)
    for _ in range(iters):
        atav = tmat_vec(mat_vec(v))
        norm = sum(x * x for x in atav) ** 0.5
        if norm == 0:
            break
        v = [x / norm for x in atav]
    au = mat_vec(v)
    sigma = sum(x * x for x in au) ** 0.5
    u = [x / sigma for x in au]
    return sigma, u, v


def deflate(a, sigma, u, v):
    return [[x - sigma * u[i] * v[j] for j, x in enumerate(row)]
            for i, row in enumerate(a)]
```

## 常见陷阱

1. **奇异向量符号成对不定**：\((u_i, v_i)\) 同时取反仍是合法分解；比较两个库的输出时先固定约定（如令每对向量第一个非零分量为正），否则「全反号」会被误判为不一致。
2. **重奇异值的子空间漂移**：\(\sigma_i = \sigma_{i+1}\) 时，对应奇异向量只在张成的子空间内确定，数值结果逐向量不可复现——这属于数学不确定性而非 bug，下游用法向要基于子空间。
3. **`full_matrices` 忘关**：\(m \gg n\) 时默认返回 \(m \times m\) 的 \(U\)，内存 \(O(m^2)\) 爆炸；截断模式（经济 SVD）\(m \times n\) 就够重建 \(A\)。
4. **小奇异值当信号用**：\(\sigma < \varepsilon_{machine} \cdot \sigma_1 \cdot \max(m,n)\) 量级的奇异值基本是舍入噪声，取逆前必须设阈值（`rcond`），否则伪逆会把噪声放大成巨大解——正规方程与显式逆翻车的根源（呼应 [020.矩阵运算算法](./020.矩阵运算算法.md) 陷阱 2/3）。
5. **幂迭代只给「头部」**：本实现取第一奇异对，谱中段慢、尾部取不全；需要 \(k \ll \min(m,n)\) 时上 Lanczos/随机化 SVD，需要全谱就直接库。
6. **稀疏 ≠ 自动可 SVD**：CSR 稀疏矩阵用 `svds` 类 Krylov 方法，但收敛取决于 **排序后的** 谱间隙，秩亏或奇异值密集时可能不收敛并给出警告——别默认成功返回。

# 总结

SVD 是线性代数给出的最强「标准形」：任何矩阵、任何形状，都能拆成正交旋转 × 轴缩放 × 正交旋转；奇异值谱同时是秩的身份证、压缩的能量表、病态的晴雨表。Eckart-Young 定理保证了「截断即最优压缩」，于是推荐系统、LSA、图像压缩、伪逆最小二乘全都收敛到同一套计算；而它与 [040.主成分分析PCA](./040.主成分分析PCA.md) 的关系提醒我们：PCA 不过是 SVD 作用在中心化数据矩阵上的特例。把「先 SVD 看奇异值谱再决定怎么算」变成肌肉记忆，数值计算的地基就算打牢了——矩阵分解的下一站回到方程视角，见 [010.线性方程组求解](./010.线性方程组求解.md) 的 LU 分支与 [020.矩阵运算算法](./020.矩阵运算算法.md)。
