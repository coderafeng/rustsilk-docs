# 概述

求解线性方程组 \(A x = b\)（\(A \in \mathbb{R}^{n \times n}\) 非奇异）是数值计算的第一块基石：电路节点电压、结构力学位移、有限元离散、最小二乘正规方程、PageRank 的幂迭代，最终都归结为解一个（或一串）线性方程组。方法分两大阵营：**直接法**在有限步算术操作内给出精确解（舍入误差意义下），代表是高斯消元与 LU 分解，复杂度 \(O(n^3)\)；**迭代法**从初始猜测出发逐步逼近，每步只需 \(O(n^2)\)（稀疏矩阵可降到 \(O(\text{nnz})\)），代表是雅可比迭代，适合超大规模稀疏系统。

**本篇收录**：**高斯消元（带部分选主元）**、**LU 分解（Doolittle）**、**雅可比迭代**

- 所属章节：[000.数值计算概述](./000.数值计算概述.md)
- 时间复杂度：高斯消元 / LU 分解 \(O(n^3)\)；雅可比迭代每步 \(O(n^2)\)，总步数取决于谱半径 \(\rho(I-D^{-1}A)\)
- 空间复杂度：消元原位进行 \(O(1)\) 附加（LU 双矩阵 \(O(n^2)\)）；迭代法 \(O(n)\)
- 应用场景：MATLAB 的 `\` 运算符、LAPACK 的 `dgesv`/`dgetrf`、Spring JDBC 背后求解器、电路仿真 SPICE、图拉普拉斯系统（[05.图结构与并查集/080.网络流](../05.图结构与并查集/080.网络流.md) 的对偶问题）；迭代法是大规模稀疏求解（共轭梯度，见 [030.数值优化方法](./030.数值优化方法.md)）的起点
- 前置：矩阵乘法与分治思想见 [04.核心算法思想/050.分治算法](../04.核心算法思想/050.分治算法.md)、[020.矩阵运算算法](./020.矩阵运算算法.md)

# 详解

## 高斯消元：为什么必须选主元

消元的本质是用初等行变换把 \(A\) 化为上三角 \(U\)。若主元 \(a_{kk}\) 接近 0，乘数 \(m_{ik} = a_{ik}/a_{kk}\) 会爆炸，舍入误差被放大到淹没真解——经典的失败案例是主元 `1e-20` 时，下游行几乎丢失全部有效数字。**部分选主元**（partial pivoting）在第 \(k\) 列中挑绝对值最大的元素换到对角线，可将乘数压制在 \(|m|\le 1\)，是 LAPACK 的标准做法；完全选主元（行列都选）只在病态极严重时才值得。

::: code-group

```java [Java]
public static double[] gaussSolve(double[][] a, double[] b) {
    int n = b.length;
    for (int col = 0; col < n; col++) {
        int pivot = col;
        for (int r = col + 1; r < n; r++)
            if (Math.abs(a[r][col]) > Math.abs(a[pivot][col])) pivot = r;
        if (Math.abs(a[pivot][col]) < 1e-12)
            throw new ArithmeticException("矩阵奇异，方程组无唯一解");
        double[] ta = a[col]; a[col] = a[pivot]; a[pivot] = ta;
        double tb = b[col]; b[col] = b[pivot]; b[pivot] = tb;
        for (int r = col + 1; r < n; r++) {
            double m = a[r][col] / a[col][col];
            for (int c = col; c < n; c++) a[r][c] -= m * a[col][c];
            b[r] -= m * b[col];
        }
    }
    double[] x = new double[n];
    for (int r = n - 1; r >= 0; r--) {
        double s = b[r];
        for (int c = r + 1; c < n; c++) s -= a[r][c] * x[c];
        x[r] = s / a[r][r];
    }
    return x;
}
```

```rust [Rust]
pub fn gauss_solve(mut a: Vec<Vec<f64>>, mut b: Vec<f64>) -> Option<Vec<f64>> {
    let n = b.len();
    for col in 0..n {
        let mut pivot = col;
        for r in col + 1..n {
            if a[r][col].abs() > a[pivot][col].abs() {
                pivot = r;
            }
        }
        if a[pivot][col].abs() < 1e-12 {
            return None; // 奇异
        }
        a.swap(col, pivot);
        b.swap(col, pivot);
        for r in col + 1..n {
            let m = a[r][col] / a[col][col];
            for c in col..n {
                let v = a[col][c];
                a[r][c] -= m * v;
            }
            b[r] -= m * b[col];
        }
    }
    let mut x = vec![0.0; n];
    for r in (0..n).rev() {
        let mut s = b[r];
        for c in r + 1..n {
            s -= a[r][c] * x[c];
        }
        x[r] = s / a[r][r];
    }
    Some(x)
}
```

```typescript [TypeScript]
  const n = b.length;
  for (let col = 0; col < n; col++) {
    let pivot = col;
    for (let r = col + 1; r < n; r++)

    for (let c = r + 1; c < n; c++) s -= a[r][c] * x[c];

  return x;
```

```python [Python]
def gauss_solve(a, b):
    n = len(b)
    a = [row[:] for row in a]   # 不污染调用方数据
    b = b[:]
    for col in range(n):
        pivot = max(range(col, n), key=lambda r: abs(a[r][col]))
        if abs(a[pivot][col]) < 1e-12:
            raise ZeroDivisionError("矩阵奇异，方程组无唯一解")
        a[col], a[pivot] = a[pivot], a[col]
        b[col], b[pivot] = b[pivot], b[col]
        for r in range(col + 1, n):
            m = a[r][col] / a[col][col]
            for c in range(col, n):
                a[r][c] -= m * a[col][c]
            b[r] -= m * b[col]
    x = [0.0] * n
    for r in range(n - 1, -1, -1):
        s = b[r] - sum(a[r][c] * x[c] for c in range(r + 1, n))
        x[r] = s / a[r][r]
    return x
```

## LU 分解：一次分解，多次求解

高斯消元的过程等价于把 \(A\) 拆成下三角 \(L\)（乘数集合）与上三角 \(U\)（消元结果）：\(A = LU\)。Doolittle 版本令 \(L\) 对角线为 1，按「先算 \(U\) 的一行、再算 \(L\) 的一列」顺序递推：

\[
u_{ij} = a_{ij} - \sum_{k<i} l_{ik}u_{kj}, \qquad
l_{ij} = \Big(a_{ij} - \sum_{k<j} l_{ik}u_{kj}\Big) / u_{jj}
\]

价值在于**多右端项**：分解一次 \(O(n^3)\)，之后每个 \(b\) 只需前代 + 回代 \(O(n^2)\)。求逆矩阵、解特征值问题的移位迭代（[020.矩阵运算算法](./020.矩阵运算算法.md)）、以及数值库里的 `factorize/solve` 两段式 API 都建立在此模式上。

::: code-group

```java [Java]
/** 返回 [L, U]；要求 A 非奇异且顺序主子式非零（或已先行选主元重排） */
public static double[][][] luDecompose(double[][] a) {
    int n = a.length;
    double[][] l = new double[n][n];
    double[][] u = new double[n][n];
    for (int i = 0; i < n; i++) l[i][i] = 1.0;
    for (int j = 0; j < n; j++) {
        for (int i = 0; i <= j; i++) {           // U 的第 j 列（i<=j 部分）
            double s = 0;
            for (int k = 0; k < i; k++) s += l[i][k] * u[k][j];
            u[i][j] = a[i][j] - s;
        }
        for (int i = j + 1; i < n; i++) {        // L 的第 j 列
            double s = 0;
            for (int k = 0; k < j; k++) s += l[i][k] * u[k][j];
            l[i][j] = (a[i][j] - s) / u[j][j];
        }
    }
    return new double[][][]{l, u};
}

public static double[] luSolve(double[][] l, double[][] u, double[] b) {
    int n = b.length;
    double[] y = new double[n], x = new double[n];
    for (int i = 0; i < n; i++) {                // 前代 L y = b
        double s = b[i];
        for (int k = 0; k < i; k++) s -= l[i][k] * y[k];
        y[i] = s;
    }
    for (int i = n - 1; i >= 0; i--) {           // 回代 U x = y
        double s = y[i];
        for (int k = i + 1; k < n; k++) s -= u[i][k] * x[k];
        x[i] = s / u[i][i];
    }
    return x;
}
```

```rust [Rust]
/// 返回 (L, U)；教学版不选主元，要求顺序主子式非零
pub fn lu_decompose(a: &[Vec<f64>]) -> Option<(Vec<Vec<f64>>, Vec<Vec<f64>>)> {
    let n = a.len();
    let mut l = vec![vec![0.0; n]; n];
    let mut u = vec![vec![0.0; n]; n];
    for i in 0..n {
        l[i][i] = 1.0;
    }
    for j in 0..n {
        for i in 0..=j {
            let mut s = 0.0;
            for k in 0..i {
                s += l[i][k] * u[k][j];
            }
            u[i][j] = a[i][j] - s;
        }
        for i in j + 1..n {
            let mut s = 0.0;
            for k in 0..j {
                s += l[i][k] * u[k][j];
            }
            if u[j][j].abs() < 1e-12 {
                return None;
            }
            l[i][j] = (a[i][j] - s) / u[j][j];
        }
    }
    Some((l, u))
}
```

## 雅可比迭代：并行的笨办法

把 \(A\) 拆成 \(A = D + R\)（\(D\) 为对角、\(R\) 为余下部分），方程组改写为不动点形式并逐轮代入：

\[
x^{(k+1)} = D^{-1}\big(b - R x^{(k)}\big), \qquad
x_i^{(k+1)} = \frac{1}{a_{ii}}\Big(b_i - \sum_{j \ne i} a_{ij} x_j^{(k)}\Big)
\]

注意两点：其一，第 \(k+1\) 轮所有分量**全部使用第 \(k\) 轮的旧值**——这意味着天然可并行；若改用「本行左边用新值、右边用旧值」就变成**高斯-赛德尔迭代**，收敛约快一倍但失去并行性。其二，收敛的充分条件是 \(A\) **严格对角占优**（每行对角元绝对值大于其余元素绝对值之和，本篇的示例矩阵恰满足），一般条件是迭代矩阵谱半径 \(\rho(D^{-1}R) < 1\)。

::: code-group

```java [Java]
public static double[] jacobi(double[][] a, double[] b, double[] x0,
                              double tol, int maxIter) {
    int n = b.length;
    double[] x = x0.clone();
    for (int it = 0; it < maxIter; it++) {
        double[] xn = new double[n];
        double diff = 0;
        for (int i = 0; i < n; i++) {
            double s = b[i];
            for (int j = 0; j < n; j++)
                if (j != i) s -= a[i][j] * x[j];   // 全用旧值 x
            xn[i] = s / a[i][i];
            diff = Math.max(diff, Math.abs(xn[i] - x[i]));
        }
        x = xn;
        if (diff < tol) break;
    }
    return x;
}
```

```python [Python]
def jacobi(a, b, x0, tol=1e-10, max_iter=1000):
    n = len(b)
    x = list(x0)
    for _ in range(max_iter):
        # 一次推导：所有分量并行地由旧 x 计算

        x = xn
        if diff < tol:
            break
    return x
```

## 常见陷阱

1. **不选主元的高斯消元是雷**：`[1e-20, 1; 1, 1]x = [1, 1]` 这类矩阵，不交换主元会直接算出错得离谱的解。教学代码也必须带上列内取最大绝对值交换。
2. **LU 分解 ≠ 高斯消元的全部**：不带选主元的 Doolittle 遇到顺序主子式为 0（如 `[[0,1],[1,0]]`）直接除零。工程上用的是 **PLU**（\(PA = LU\)），实现时要把行交换记录成置换向量，回代前先对 \(b\) 施加同一置换。
3. **`float` 精度不够**：数值线性代数一律用双精度；`float32` 的 7 位有效数字在 \(n > 100\) 的消元链后误差就可能吃掉小数位。
4. **迭代法判停别只看残差**：`‖b - Ax‖` 小不代表误差 `‖x* - x‖` 小（病态矩阵会把残差放大成倍误差），至少要同时监控相邻两轮解的变化量；对角占优不满足时雅可比可能**发散**，此时先想高斯-赛德尔 / SOR，再上共轭梯度（见 [030.数值优化方法](./030.数值优化方法.md)）。
5. **整数除法吞精度**（Java/C）：乘数写成 `a[i][j] / a[i][i]` 时两侧必须都是 `double`；Python 中 `/` 恒为浮点除，`//` 千万别混进迭代公式。
6. **对稀疏结构视而不见**：\(n = 10^6\) 的稀疏网络拉普拉斯系统用 \(O(n^3)\) 直接法需要算几十年的量；迭代法 + 稀疏存储（CSR）才是正道，这属于「结构决定算法」的第一课。

# 总结

本篇铺好线性方程组的三层地基：带部分选主元的**高斯消元**是通用直接法，\(O(n^3)\) 一步到位；**LU 分解**把消元产物固化成可复用的因子，多右端项时每解只花 \(O(n^2)\)；**雅可比迭代**以最朴素的方式打开迭代法世界——每步 \(O(n^2)\)、天然并行、对角占优保收敛。三者的取舍逻辑（精度需求、矩阵规模、稀疏性、右端项个数）贯穿整个数值计算领域，后续的共轭梯度、特征值分解（[040.主成分分析PCA](./040.主成分分析PCA.md)）与矩阵求逆（[020.矩阵运算算法](./020.矩阵运算算法.md)）都建立在这套「消元-分解-迭代」的语汇之上。
