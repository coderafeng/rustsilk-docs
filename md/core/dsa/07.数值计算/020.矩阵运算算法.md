# 概述

矩阵是线性代数的「一等公民」，矩阵层面的算法决定了整个数值计算链条的速度上限：深度学习的前向/反向传播本质是海量矩阵乘法，科学计算的核函数评估、图形学的变换管线、推荐系统的相似度批量计算都压在这块地基上。本篇挑两个「分解技巧」的代表：用**分治减少乘法次数**的 Strassen 矩阵乘法，和**把方程组批量求解压缩成一次消元**的矩阵求逆。

**本篇收录**：**Strassen 矩阵乘法**、**矩阵求逆（Gauss-Jordan）**

- 所属章节：[000.数值计算概述](./000.数值计算概述.md)
- 时间复杂度：朴素矩阵乘 \(O(n^3)\)；Strassen \(O(n^{\log_2 7}) \approx O(n^{2.807})\)；Gauss-Jordan 求逆 \(O(n^3)\)（与一次消元同阶，但常数约为解单方程组的 3 倍）
- 空间复杂度：Strassen 递归层共 \(O(n^2)\)（每层块为 \(n^2\) 的等比收缩）；增广矩阵求逆 \(O(n^2)\)
- 应用场景：Strassen 及其后继（Winograd、Coppersmith-Winograd，理论下界仍在推进）出现在 GPU 大矩阵库与复杂度教材中——生产 BLAS 更多靠分块 + 缓存友好把朴素 \(n^3\) 压到接近硬件极限；矩阵求逆广泛存在于最小二乘正规方程 \((A^TA)^{-1}A^Tb\)（[08.机器学习算法/030.监督学习算法](../08.机器学习算法/030.监督学习算法.md)）、协方差白化与卡尔曼滤波
- 前置：分治主定理见 [04.核心算法思想/050.分治算法](../04.核心算法思想/050.分治算法.md)；消元与 LU 见 [010.线性方程组求解](./010.线性方程组求解.md)；「减少乘法次数」的同族技巧（整数版）见 [070.Karatsuba乘法](./070.Karatsuba乘法.md)

以 \(A = \begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix}\)、\(B = \begin{pmatrix} 5 & 6 \\ 7 & 8 \end{pmatrix}\) 为例（朴素需 8 次乘法）：

1. 各按四象限切块：\(A_{11}=[1]\)、\(A_{12}=[2]\)、\(A_{21}=[3]\)、\(A_{22}=[4]\)，\(B\) 同理。
2. 做 7 次「加减后相乘」：\(p_1=(1+4)(5+8)=65\)；\(p_2=(3+4)\times5=35\)；\(p_3=1\times(6-8)=-2\)；\(p_4=4\times(7-5)=8\)；\(p_5=(1+2)\times8=24\)；\(p_6=(3-1)(5+6)=22\)；\(p_7=(2-4)(7+8)=-30\)。
3. 拼回四块：\(C_{11}=p_1+p_4-p_5+p_7=19\)；\(C_{12}=p_3+p_5=22\)；\(C_{21}=p_2+p_4=43\)；\(C_{22}=p_1-p_2+p_3+p_6=50\)。
4. 与朴素结果 \(\begin{pmatrix} 19 & 22 \\ 43 & 50 \end{pmatrix}\) 逐块点亮对比——乘法次数 8 → 7，递归展开即 \(n^{2.807}\) 对 \(n^3\) 的规模优势。

**动画：Gauss-Jordan 求逆的「左右同步消元」** <!-- dsa.assets/matrix/gauss-jordan.gif -->

对 \(A=\begin{pmatrix}2&1\\1&3\end{pmatrix}\)，增广矩阵 \([A \mid I]\)：

1. 第 0 列选主元：\(|2|>|1|\)，第 0 行不动；主元行除以 2 → \([1,\ 0.5 \mid 0.5,\ 0]\)。
2. **对所有其他行**（不只下方）消去第 0 列：第 1 行减 \(1\times\) 第 0 行 → \([0,\ 2.5 \mid -0.5,\ 1]\)。
3. 第 1 列主元行除以 2.5 → \([0,\ 1 \mid -0.2,\ 0.4]\)。
4. 向上消元：第 0 行减 \(0.5\times\) 第 1 行 → \([1,\ 0 \mid 0.6,\ -0.2]\)。
5. 左侧变成单位阵的瞬间，右侧自然长成 \(A^{-1}=\begin{pmatrix}0.6 & -0.2\\ -0.2 & 0.4\end{pmatrix}\)——动画高亮扫过每一列，展示「消一列、左右同步」的镜像感。

# 详解

## Strassen：向乘法次数开刀

\(n \times n\) 矩阵四分块后，朴素分块法需要 8 次 \((n/2)\) 阶乘法与 4 次加法；Strassen（1969）观察到其中一块乘积可由其他块线性组合替代，于是只用 **7 次**递归乘法：

\[
\begin{aligned}
p_1&=(A_{11}+A_{22})(B_{11}+B_{22}), & p_2&=(A_{21}+A_{22})B_{11},\\
p_3&=A_{11}(B_{12}-B_{22}), & p_4&=A_{22}(B_{21}-B_{11}),\\
p_5&=(A_{11}+A_{12})B_{22}, & p_6&=(A_{21}-A_{11})(B_{11}+B_{12}),\\
p_7&=(A_{12}-A_{22})(B_{21}+B_{22}) &&
\end{aligned}
\]

\[
C=\begin{pmatrix} p_1+p_4-p_5+p_7 & p_3+p_5 \\ p_2+p_4 & p_1-p_2+p_3+p_6 \end{pmatrix}
\]

递推式 \(T(n) = 7T(n/2) + O(n^2)\) 由主定理给出 \(T(n) = O(n^{\log_2 7}) \approx O(n^{2.807})\)。教学实现通常要求 \(n\) 为 2 的幂（或设递归阈值回退朴素法）；实际收益要打个折——多出的加减法让常数变大、缓存行为变差，所以要到 \(n\) 数千以上才稳定跑赢调优过的 BLAS。

```java [Java]
public static double[][] strassen(double[][] a, double[][] b) {
    int n = a.length;
    if (n <= 64) return naiveMul(a, b);              // 小规模回退：递归开销不划算
    int m = n / 2;
    double[][] a11 = block(a, 0, 0, m), a12 = block(a, 0, m, m);
    double[][] a21 = block(a, m, 0, m), a22 = block(a, m, m, m);
    double[][] b11 = block(b, 0, 0, m), b12 = block(b, 0, m, m);
    double[][] b21 = block(b, m, 0, m), b22 = block(b, m, m, m);

    double[][] p1 = strassen(add(a11, a22), add(b11, b22));
    double[][] p2 = strassen(add(a21, a22), b11);
    double[][] p3 = strassen(a11, sub(b12, b22));
    double[][] p4 = strassen(a22, sub(b21, b11));
    double[][] p5 = strassen(add(a11, a12), b22);
    double[][] p6 = strassen(sub(a21, a11), add(b11, b12));
    double[][] p7 = strassen(sub(a12, a22), add(b21, b22));

    double[][] c = new double[n][n];
    writeBlock(c, add(sub(add(p1, p4), p5), p7), 0, 0);      // C11 = p1+p4-p5+p7
    writeBlock(c, add(p3, p5), 0, m);                          // C12
    writeBlock(c, add(p2, p4), m, 0);                          // C21
    writeBlock(c, add(sub(p1, p2), add(p3, p6)), m, m);        // C22 = p1-p2+p3+p6
    return c;
}

static double[][] naiveMul(double[][] a, double[][] b) {
    int n = a.length;
    double[][] c = new double[n][n];
    for (int i = 0; i < n; i++)
        for (int k = 0; k < n; k++) {
            double aik = a[i][k];
            if (aik == 0) continue;
            for (int j = 0; j < n; j++) c[i][j] += aik * b[k][j];
        }
    return c;
}

static double[][] add(double[][] x, double[][] y) {
    int n = x.length;
    double[][] r = new double[n][n];
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++) r[i][j] = x[i][j] + y[i][j];
    return r;
}

static double[][] sub(double[][] x, double[][] y) {
    int n = x.length;
    double[][] r = new double[n][n];
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++) r[i][j] = x[i][j] - y[i][j];
    return r;
}

static double[][] block(double[][] m, int r0, int c0, int size) {
    double[][] r = new double[size][size];
    for (int i = 0; i < size; i++)
        System.arraycopy(m[r0 + i], c0, r[i], 0, size);
    return r;
}

static void writeBlock(double[][] t, double[][] s, int r0, int c0) {
    for (int i = 0; i < s.length; i++)
        System.arraycopy(s[i], 0, t[r0 + i], c0, s.length);
}
```

```rust [Rust]
type Mat = Vec<Vec<f64>>;

pub fn strassen(a: &Mat, b: &Mat) -> Mat {
    let n = a.len();
    if n <= 64 {
        return naive_mul(a, b);
    }
    let m = n / 2;
    let a11 = block(a, 0, 0, m);
    let a12 = block(a, 0, m, m);
    let a21 = block(a, m, 0, m);
    let a22 = block(a, m, m, m);
    let b11 = block(b, 0, 0, m);
    let b12 = block(b, 0, m, m);
    let b21 = block(b, m, 0, m);
    let b22 = block(b, m, m, m);

    let p1 = strassen(&add(&a11, &a22), &add(&b11, &b22));
    let p2 = strassen(&add(&a21, &a22), &b11);
    let p3 = strassen(&a11, &sub(&b12, &b22));
    let p4 = strassen(&a22, &sub(&b21, &b11));
    let p5 = strassen(&add(&a11, &a12), &b22);
    let p6 = strassen(&sub(&a21, &a11), &add(&b11, &b12));
    let p7 = strassen(&sub(&a12, &a22), &add(&b21, &b22));

    let mut c = vec![vec![0.0; n]; n];
    write_block(&mut c, &add(&sub(&add(&p1, &p4), &p5), &p7), 0, 0);
    write_block(&mut c, &add(&p3, &p5), 0, m);
    write_block(&mut c, &add(&p2, &p4), m, 0);
    write_block(&mut c, &add(&sub(&p1, &p2), &add(&p3, &p6)), m, m);
    c
}

fn naive_mul(a: &Mat, b: &Mat) -> Mat {
    let n = a.len();
    let mut c = vec![vec![0.0; n]; n];
    for i in 0..n {
        for k in 0..n {
            let aik = a[i][k];
            if aik == 0.0 {
                continue;
            }
            for j in 0..n {
                c[i][j] += aik * b[k][j];
            }
        }
    }
    c
}

fn add(x: &Mat, y: &Mat) -> Mat {
    x.iter().zip(y)
        .map(|(xr, yr)| xr.iter().zip(yr).map(|(p, q)| p + q).collect())
        .collect()
}

fn sub(x: &Mat, y: &Mat) -> Mat {
    x.iter().zip(y)
        .map(|(xr, yr)| xr.iter().zip(yr).map(|(p, q)| p - q).collect())
        .collect()
}

fn block(m: &Mat, r0: usize, c0: usize, size: usize) -> Mat {
    m[r0..r0 + size].iter()
        .map(|row| row[c0..c0 + size].to_vec())
        .collect()
}

fn write_block(t: &mut Mat, s: &Mat, r0: usize, c0: usize) {
    for (i, row) in s.iter().enumerate() {
        let dst = &mut t[r0 + i][c0..c0 + row.len()];
        dst.copy_from_slice(row);
    }
}
```

```typescript [TypeScript]
function strassen(a: number[][], b: number[][]): number[][] {
  const n = a.length;
  if (n <= 64) return naiveMul(a, b);
  const m = n / 2;
  const block = (x: number[][], r0: number, c0: number) =>
    x.slice(r0, r0 + m).map(row => row.slice(c0, c0 + m));
  const add = (x: number[][], y: number[][]) =>
    x.map((row, i) => row.map((v, j) => v + y[i][j]));
  const sub = (x: number[][], y: number[][]) =>
    x.map((row, i) => row.map((v, j) => v - y[i][j]));

  const a11 = block(a, 0, 0), a12 = block(a, 0, m);
  const a21 = block(a, m, 0), a22 = block(a, m, m);
  const b11 = block(b, 0, 0), b12 = block(b, 0, m);
  const b21 = block(b, m, 0), b22 = block(b, m, m);

  const p1 = strassen(add(a11, a22), add(b11, b22));
  const p2 = strassen(add(a21, a22), b11);
  const p3 = strassen(a11, sub(b12, b22));
  const p4 = strassen(a22, sub(b21, b11));
  const p5 = strassen(add(a11, a12), b22);
  const p6 = strassen(sub(a21, a11), add(b11, b12));
  const p7 = strassen(sub(a12, a22), add(b21, b22));

  const put = (t: number[][], s: number[][], r0: number, c0: number) =>
    s.forEach((row, i) => row.forEach((v, j) => { t[r0 + i][c0 + j] = v; }));

  const c: number[][] = Array.from({ length: n }, () => new Array(n).fill(0));
  put(c, add(sub(add(p1, p4), p5), p7), 0, 0);
  put(c, add(p3, p5), 0, m);
  put(c, add(p2, p4), m, 0);
  put(c, add(sub(p1, p2), add(p3, p6)), m, m);
  return c;
}

function naiveMul(a: number[][], b: number[][]): number[][] {
  const n = a.length;
  const c = Array.from({ length: n }, () => new Array<number>(n).fill(0));
  for (let i = 0; i < n; i++)
    for (let k = 0; k < n; k++) {
      const aik = a[i][k];
      if (!aik) continue;
      for (let j = 0; j < n; j++) c[i][j] += aik * b[k][j];
    }
  return c;
}
```

```python [Python]
def strassen(a, b):
    """a, b 为 list[list[float]]；规模需为 2 的幂或达到回退阈值"""
    n = len(a)
    if n <= 64:
        return naive_mul(a, b)
    m = n // 2

    def block(x, r0, c0):
        return [row[c0:c0 + m] for row in x[r0:r0 + m]]

    def add(x, y):
        return [[p + q for p, q in zip(xr, yr)] for xr, yr in zip(x, y)]

    def sub(x, y):
        return [[p - q for p, q in zip(xr, yr)] for xr, yr in zip(x, y)]

    a11, a12 = block(a, 0, 0), block(a, 0, m)
    a21, a22 = block(a, m, 0), block(a, m, m)
    b11, b12 = block(b, 0, 0), block(b, 0, m)
    b21, b22 = block(b, m, 0), block(b, m, m)
```

## 矩阵求逆：一次消元同时解 n 个方程组

求 \(A^{-1}\) 等价于对 \(n\) 个单位向量右端项分别解 \(Ax = e_j\)。与其做 \(n\) 次消元，不如把 \(n\) 个右端项**并排成增广矩阵** \([A \mid I]\)，对 \(A\) 侧做的每一步行变换同步作用到 \(I\) 侧；当 \(A\) 侧被化为单位阵时，右侧已被同一批变换乘成了 \(A^{-1}\)。这正是 LU 思路的「多右端项」极限形态，只是这里右端项恰好构成单位阵，前代回代被折叠成同步消元（Gauss-Jordan）。

::: code-group

```java [Java]
public static double[][] inverse(double[][] a) {
    int n = a.length;
    double[][] m = new double[n][2 * n];
    for (int i = 0; i < n; i++) {
        System.arraycopy(a[i], 0, m[i], 0, n);
        m[i][n + i] = 1.0;
    }
    for (int col = 0; col < n; col++) {
        int pivot = col;
        for (int r = col + 1; r < n; r++)
            if (Math.abs(m[r][col]) > Math.abs(m[pivot][col])) pivot = r;
        if (Math.abs(m[pivot][col]) < 1e-12)
            throw new ArithmeticException("矩阵奇异，不存在逆");
        double[] t = m[col]; m[col] = m[pivot]; m[pivot] = t;
        double d = m[col][col];
        for (int j = 0; j < 2 * n; j++) m[col][j] /= d;      // 主元行归一
        for (int r = 0; r < n; r++) {
            if (r == col) continue;
            double f = m[r][col];
            for (int j = 0; j < 2 * n; j++) m[r][j] -= f * m[col][j];  // 全列消元
        }
    }
    double[][] inv = new double[n][n];
    for (int i = 0; i < n; i++) System.arraycopy(m[i], n, inv[i], 0, n);
    return inv;
}
```

```rust [Rust]
pub fn inverse(a: &[Vec<f64>]) -> Option<Vec<Vec<f64>>> {
    let n = a.len();
    let mut m: Vec<Vec<f64>> = a.iter()
        .enumerate()
        .map(|(i, row)| {
            let mut v: Vec<f64> = row.clone();
            v.extend((0..n).map(|j| if i == j { 1.0 } else { 0.0 }));
            v
        })
        .collect();
    for col in 0..n {
        let mut pivot = col;
        for r in col + 1..n {
            if m[r][col].abs() > m[pivot][col].abs() {
                pivot = r;
            }
        }
        if m[pivot][col].abs() < 1e-12 {
            return None;
        }
        m.swap(col, pivot);
        let d = m[col][col];
        for j in 0..2 * n {
            m[col][j] /= d;
        }
        for r in 0..n {
            if r == col {
                continue;
            }
            let f = m[r][col];
            for j in 0..2 * n {
                let p = m[col][j];
                m[r][j] -= f * p;
            }
        }
    }
    Some(m.iter().map(|row| row[n..2 * n].to_vec()).collect())
}
```

```typescript [TypeScript]
function inverse(a: number[][]): number[][] {
  const n = a.length;
  const m = a.map((row, i) => [...row, ...Array.from({ length: n }, (_, j) => (i === j ? 1 : 0))]);
  for (let col = 0; col < n; col++) {
```

```python [Python]
def inverse(a):
    n = len(a)
    m = [row[:] + [1.0 if i == j else 0.0 for j in range(n)]
         for i, row in enumerate(a)]
    for col in range(n):
        pivot = max(range(col, n), key=lambda r: abs(m[r][col]))
        if abs(m[pivot][col]) < 1e-12:
            raise ZeroDivisionError("矩阵奇异，不存在逆")
        m[col], m[pivot] = m[pivot], m[col]
        d = m[col][col]
        m[col] = [v / d for v in m[col]]                    # 主元行归一
        for r in range(n):
            if r != col:
                f = m[r][col]
                m[r] = [v - f * w for v, w in zip(m[r], m[col])]  # 全列消元
    return [row[n:] for row in m]
```

## 常见陷阱

1. **Strassen 不是「越快越好」的默认选项**：递归的块切分与临时矩阵分配吃掉大量缓存局部性，\(n \le 64\)（阈值依硬件而定）时反而比朴素三重循环慢数倍——务必设回退阈值；数值稳定性上也略逊朴素法（更多加减导致误差累积）。
2. **别显式求逆解方程组**：求 \(Ax=b\) 用 `inverse(A) @ b` 在数值上既慢（多算 \(n^2\) 个无用列）又不稳（误差被条件数平方级放大）。工程标准做法是 LU 分解后前代回代，或 `solve(A, b)`；显式逆矩阵只在需要反复换右端项、或表达式本身需要 \(A^{-1}\)（如协方差 \(\Sigma^{-1}\)）时使用。
3. **病态矩阵的逆不可信**：`cond(A) = ‖A‖·‖A⁻¹‖` 达到 \(10^{12}\) 时，双精度下求出的「逆」有效位数不足 4 位。先想正则化（岭回归给对角加 \(\lambda I\)）或换分解（QR、SVD，见 [050.奇异值分解SVD](./050.奇异值分解SVD.md)），而不是加大精度硬算。
4. **Gauss-Jordan 的消元对象是「全体行」**：与高斯消元只消下方不同，求逆每轮要消去除主元行外的所有行；写成三角回代的样子会得到半对半错的矩阵。
5. **Strassen 的减法块顺序**：\(C_{22} = p_1 - p_2 + p_3 + p_6\) 是最容易写错的一块（本文图解步骤 3 可逐块验算）；建议单测用随机小矩阵对拍朴素法。
6. **内存爆炸**：Java/C++ 里 \(n=10^5\) 的稠密矩阵已是 \(8\times10^{10}\) 字节——稠密算法的适用上限通常在 \(10^4\) 量级，更大规模必须走稀疏迭代路线（[010.线性方程组求解](./010.线性方程组求解.md) 的雅可比/共轭梯度分支）。

# 总结

Strassen 用「7 次乘法换 18 次加法」把矩阵乘法拉下 \(O(n^3)\) 神坛，与 [070.Karatsuba乘法](./070.Karatsuba乘法.md) 一起构成「减少乘法次数」分治家族的双璧——前者作用于矩阵块，后者作用于整数位段；它的现实教训（常数、缓存、稳定性）同样值钱：**渐近优不等于实测快**。矩阵求逆则展示了增广矩阵的「批处理」思想：一次 Gauss-Jordan 消元同时完成 \(n\) 个方程组的求解。两者与 [010.线性方程组求解](./010.线性方程组求解.md) 的 LU 分解互相咬合，共同支撑起 [040.主成分分析PCA](./040.主成分分析PCA.md) 与 [050.奇异值分解SVD](./050.奇异值分解SVD.md) 所需的矩阵工具链。
