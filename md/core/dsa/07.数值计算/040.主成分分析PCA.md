# 概述

主成分分析（Principal Component Analysis, PCA）把 \(d\) 维数据投影到方差最大的少数正交方向上，用 \(k \ll d\) 个「主成分」替代原始坐标，同时尽可能保留数据内部的几何结构。它是线性降维的定义性方法：协方差矩阵的特征分解（等价地，中心化数据矩阵的 SVD）给出主方向，投影即降维。

- 所属章节：[000.数值计算概述](./000.数值计算概述.md)
- 时间复杂度：协方差矩阵 \(O(md^2)\)（\(m\) 样本数）；特征分解 \(O(d^3)\)（或幂迭代取前 \(k\) 成分 \(O(kd^2 \cdot \text{iters})\)）；投影 \(O(mdk)\)
- 空间复杂度：\(O(d^2)\)（协方差矩阵）
- 应用场景：特征工程的标配预处理、Eigenfaces 人脸识别、图像压缩与去噪、高维数据 2D/3D 可视化（与 t-SNE/UMAP 等非线性方法对照使用，见 [08.机器学习算法/080.降维与可视化](../08.机器学习算法/080.降维与可视化.md)）、白化（whitening，神经网络输入预处理）、基因组主成分校正批次效应
- 前置：矩阵乘法与转置见 [020.矩阵运算算法](./020.矩阵运算算法.md)；二次型极值视角见 [030.数值优化方法](./030.数值优化方法.md)；SVD 视角见 [050.奇异值分解SVD](./050.奇异值分解SVD.md)

# 详解

## 从两个等价定义推导主成分

**视角一（最大方差）**：找单位向量 \(v\) 使投影 \(v^T\tilde x\) 的方差 \(\frac{1}{m-1}\sum (v^T\tilde x_i)^2 = v^T C v\) 最大。拉格朗日乘子法解 \(\max\ v^TCv\ \text{s.t.}\ v^Tv=1\)，得 \(Cv = \lambda v\)——**驻点恰是特征向量，目标值恰是特征值**。第一主成分取最大特征值方向；后续成分在与前者的正交补空间中递归同题。

**视角二（最小重构误差）**：找 \(k\) 维子空间使所有点到它的正交投影距离平方和最小。K-L 展开定理给出答案：取前 \(k\) 个特征向量组成 \(W \in \mathbb{R}^{d \times k}\)，重构 \( \hat x = WW^T\tilde x\)，总误差 \(= \sum_{i>k}\lambda_i\)。两个视角互补，实践中按需求使用：要「保留信息」看方差解释比 \(\lambda_i/\sum\lambda\)，要「可逆压缩」看重构误差。

**与 SVD 的关系**：对中心化数据矩阵 \(X \in \mathbb{R}^{m \times d}\) 做 SVD（[050.奇异值分解SVD](./050.奇异值分解SVD.md)）\(X = U\Sigma V^T\)，则 \(C = \frac{1}{m-1}V\Sigma^2V^T\)——**右奇异向量即主成分，\(\sigma_i^2/(m-1)\) 即特征值**。数值上 SVD 比「构造 \(C\) 再特征分解」稳定（避免平方条件数），scikit-learn 的 `PCA` 默认走全数据 SVD；当 \(d\) 极大而只需前几个成分时，协方差 + 幂迭代路线（下方代码）更省内存。

**最大化方差问题本身就是二次型极值**——约束优化的一阶条件与 [030.数值优化方法](./030.数值优化方法.md) 中「CG 极小化二次型」是同一族数学。

## 代码：中心化 + 协方差 + 幂迭代取第一主成分

幂迭代对对称正定 \(C\)：任取初值 \(v_0\)，反复 \(v \leftarrow Cv / \lVert Cv \rVert\)，以 \(|\lambda_2/\lambda_1|^t\) 速率压向第一特征向量。取多个成分时做 **deflation**：提取 \(v_1\) 后从矩阵中减去 \(\lambda_1 v_1 v_1^T\) 再迭代。

```java [Java]
public static double[][] covariance(double[][] x) { // x: m 行样本, d 列特征
    int m = x.length, d = x[0].length;
    double[] mean = new double[d];
    for (double[] row : x)
        for (int j = 0; j < d; j++) mean[j] += row[j];
    for (int j = 0; j < d; j++) mean[j] /= m;
    double[][] c = new double[d][d];
    for (double[] row : x)
        for (int i = 0; i < d; i++)
            for (int j = 0; j < d; j++)
                c[i][j] += (row[i] - mean[i]) * (row[j] - mean[j]);
    for (int i = 0; i < d; i++)
        for (int j = 0; j < d; j++) c[i][j] /= m - 1;
    return c;
}

/** 幂迭代返回第一主成分方向；多次调用 + deflation 可取前 k 个 */
public static double[] firstPrincipalComponent(double[][] cov, int iters) {
    int d = cov.length;
    double[] v = new double[d];
    v[0] = 1.0;
    for (int it = 0; it < iters; it++) {
        double[] cv = new double[d];
        for (int i = 0; i < d; i++) {
            double s = 0;
            for (int j = 0; j < d; j++) s += cov[i][j] * v[j];
            cv[i] = s;
        }
        double norm = 0;
        for (double x : cv) norm += x * x;
        norm = Math.sqrt(norm);
        for (int i = 0; i < d; i++) v[i] = cv[i] / norm;
    }
    return v;
}
// 图解例：firstPrincipalComponent(covariance(new double[][]{{2,1},{4,3},{6,4}}), 100)
// → (±0.796, ±0.605)
```

```rust [Rust]
pub fn covariance(x: &[Vec<f64>]) -> Vec<Vec<f64>> {
    let m = x.len();
    let d = x[0].len();
    let mut mean = vec![0.0; d];
    for row in x {
        for (j, &v) in row.iter().enumerate() {
            mean[j] += v;
        }
    }
    for j in 0..d {
        mean[j] /= m as f64;
    }
    let mut c = vec![vec![0.0; d]; d];
    for row in x {
        for i in 0..d {
            for j in 0..d {
                c[i][j] += (row[i] - mean[i]) * (row[j] - mean[j]);
            }
        }
    }
    for i in 0..d {
        for j in 0..d {
            c[i][j] /= (m - 1) as f64;
        }
    }
    c
}

/// 幂迭代求第一主成分方向
pub fn first_principal_component(cov: &[Vec<f64>], iters: usize) -> Vec<f64> {
    let d = cov.len();
    let mut v = vec![0.0; d];
    v[0] = 1.0;
    for _ in 0..iters {
        let cv: Vec<f64> = cov.iter()
            .map(|row| row.iter().zip(&v).map(|(a, b)| a * b).sum())
            .collect();
        let norm = cv.iter().map(|x| x * x).sum::<f64>().sqrt();
        for i in 0..d {
            v[i] = cv[i] / norm;
        }
    }
    v
}
// 图解例：first_principal_component(&covariance(&samples), 100) → (±0.796, ±0.605)
```

```typescript [TypeScript]
function covariance(x: number[][]): number[][] {
  const m = x.length, d = x[0].length;
  const mean = new Array<number>(d).fill(0);
  for (const row of x) row.forEach((v, j) => { mean[j] += v; });
  mean.forEach((v, j) => { mean[j] = v / m; });
  const c = Array.from({ length: d }, () => new Array<number>(d).fill(0));
  for (const row of x)
    for (let i = 0; i < d; i++)
      for (let j = 0; j < d; j++)
        c[i][j] += (row[i] - mean[i]) * (row[j] - mean[j]);
  for (let i = 0; i < d; i++)
    for (let j = 0; j < d; j++) c[i][j] /= m - 1;
  return c;
}

function firstPrincipalComponent(cov: number[][], iters: number): number[] {
  const d = cov.length;
  const v = new Array<number>(d).fill(0);
  v[0] = 1;
  for (let it = 0; it < iters; it++) {
    const cv = cov.map(row => row.reduce((s, a, j) => s + a * v[j], 0));
    const norm = Math.hypot(...cv);
    cv.forEach((x, i) => { v[i] = x / norm; });
  }
  return v;
}
```

```python [Python]
def covariance(x):
    m, d = len(x), len(x[0])
    mean = [sum(row[j] for row in x) / m for j in range(d)]
    c = [[0.0] * d for _ in range(d)]

def first_principal_component(cov, iters=100):
    d = len(cov)
    v = [1.0] + [0.0] * (d - 1)
    for _ in range(iters):
        cv = [sum(a * b for a, b in zip(row, v)) for row in cov]
        norm = sum(x * x for x in cv) ** 0.5
        v = [x / norm for x in cv]
    return v
```

## 使用前检查清单

1. **必须中心化**：主成分是绕数据均值转出来的轴；不减均值，第一「主成分」会指向原点到云团的方向而非方差方向（多数库帮你做了，手写时最容易漏）。
2. **量纲不一致要标准化**：身高（cm）与体重（kg）的方差差几个数量级，直接用协方差矩阵则大数维必然霸占第一成分；改用**相关矩阵**（每维先除以标准差）或等价地 z-score 标准化。
3. **PCA 是线性方法**：它只能找超平面。环形/流形结构（教科书例子：瑞士卷）会被压扁成一团，此时该上核 PCA、UMAP/t-SNE（[08.机器学习算法/080.降维与可视化](../08.机器学习算法/080.降维与可视化.md)）。
4. **符号不确定**：\(v_1\) 与 \(-v_1\) 同样合法，不同库/不同实现的投影坐标可能整体反号——比较结果时看 \(|v|\) 或先固定符号约定（如令最大分量为正）。
5. **选 \(k\) 讲依据**：累计方差解释比 ≥ 85%～95% 是常用启发；但「方差大 = 重要」只在信噪比均匀时成立，信号若恰好潜伏在小方差维（如叠加了强背景噪声的弱信号），PCA 保的是背景。
6. **对离群点敏感**：协方差是二阶矩，一个万倍离群点能扭断主轴；先做稳健估计或剔除离群。
7. **幂迭代取向量的坑**：初值不得与 \(v_1\) 正交（代码取 \(e_0\) 已规避）；\(\lambda_1\) 重根或 \(\lambda_1 \approx \lambda_2\) 时迭代方向在特征子空间里漂移，此时应取整个子空间或改用 LAPACK `dsyev`。

## 小结流程

::: info PCA 五步
1. 中心化（按需标准化）数据矩阵 \(X\)
2. 求 \(C = \frac{1}{m-1}X^TX\)（或直接对 \(X\) SVD）
3. 特征分解（或读奇异值），按特征值降序排 \(v_1 \dots v_d\)
4. 按方差解释比选 \(k\)，取 \(W = [v_1 \dots v_k]\)
5. 投影 \(Z = XW\)；需要时经 \(ZW^T\) 重构回原空间
:::

# 总结

PCA 把「降维」归约为一个干净的二次型极值问题：方差最大化的正交方向就是协方差矩阵的特征向量，损失的能量恰好是弃掉特征值之和。它的强项是**简单、可解释、无参数**（\(k\) 是唯一决定），代价是线性假设与均值/方差统计对异常结构的敏感。作为「降维问题的基线」，后续一切非线性方法（核技巧、流形学习、自编码器）都是在修补它看不见的曲率——先跑 PCA 再考虑更重的武器，是特征工程的正确姿势。数学上它与 [050.奇异值分解SVD](./050.奇异值分解SVD.md) 互为表里，工程上它是 [08.机器学习算法/080.降维与可视化](../08.机器学习算法/080.降维与可视化.md) 全家桶的第一块跳板。
