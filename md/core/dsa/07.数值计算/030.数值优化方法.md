# 概述

给定可微函数 \(f\)，寻找 \(x^\*\) 使 \(f(x^\*) = 0\)（求根）或 \(\min_x f(x)\)（最优化）——这是几乎一切「算到收敛」问题的统一形态：电路工作点、轨道方程、模型参数拟合，本质上都在解「某个梯度为零」。本篇三条主线恰好对应迭代的三种视野：**牛顿法**用二阶信息直线扑向目标（二次收敛但每步昂贵且挑剔初值）、**梯度下降**只看当下最陡方向小步走（每步廉价但线性收敛）、**共轭梯度法**在二次型问题上用「彼此共轭」的方向序列做到有限步精确收敛（迭代法里的优等生）。

**本篇收录**：**牛顿法**、**梯度下降**、**共轭梯度法**

- 所属章节：[000.数值计算概述](./000.数值计算概述.md)
- 时间复杂度：牛顿法每步 \(O(1)\)（一维求根）/ \(O(n^3)\)（多维需解 Hessian 系统），迭代 \(O(\log\log(1/\varepsilon))\) 步（二次收敛）；梯度下降每步一次梯度评估，迭代 \(O(1/\varepsilon)\)～\(O(\kappa \log(1/\varepsilon))\)（条件数 \(\kappa\) 主导）；共轭梯度每步一次矩阵-向量乘 \(O(n^2)\)，精确算术下 \(n\) 步收敛，实践中 \(O(\sqrt{\kappa})\) 步
- 空间复杂度：均 \(O(n)\)（牛顿多维版另需 Hessian \(O(n^2)\)）
- 应用场景：梯度下降是神经网络训练的引擎（[08.机器学习算法/050.神经网络与反向传播](../08.机器学习算法/050.神经网络与反向传播.md) 的算法内核，反向传播只负责算梯度、本篇决定怎么用）；牛顿/高斯-牛顿法用于逻辑回归（IRLS）、最小二乘拟合与物理仿真求解器；共轭梯度是大规模 SPD 稀疏系统（有限元、泊松方程）的工业标准
- 前置：线性方程组与残差概念见 [010.线性方程组求解](./010.线性方程组求解.md)；「迭代判停」的通用套路同篇

# 详解

## 牛顿法：用切线代替曲线

对 \(f\) 在当前点做一阶泰勒展开并令其为零：\(f(x_k) + f'(x_k)(x - x_k) = 0 \Rightarrow x_{k+1} = x_k - f(x_k)/f'(x_k)\)。几何上就是「切线求根」——用直线近似非线性曲线，每一步都把局部线性化的最优解当作下一站。若 \(f'(x^\*) \ne 0\) 且初值足够靠近单根，误差满足 \(e_{k+1} \approx \dfrac{f''(x^\*)}{2f'(x^\*)} e_k^2\)，即**二次收敛**。用于最优化（求 \(f'=0\)）时，把 \(f\) 换成 \(f'\) 即得迭代 \(x_{k+1} = x_k - f'(x_k)/f''(x_k)\)；多维版本为 \(x \leftarrow x - H^{-1}\nabla f\)，\(H\) 为 Hessian——直接解 \(H d = -\nabla f\) 而不是显式求逆（原因见 [020.矩阵运算算法](./020.矩阵运算算法.md) 陷阱 2），非正定 Hessian 还会把迭代推向鞍点，工程上常用拟牛顿（BFGS/L-BFGS）用梯度差构造正定近似。

::: code-group

```java [Java]
public static double newtonRoot(DoubleUnaryOperator f, DoubleUnaryOperator df,
                                double x0, double tol, int maxIter) {
    double x = x0;
    for (int i = 0; i < maxIter; i++) {
        double fx = f.applyAsDouble(x);
        if (Math.abs(fx) < tol) return x;
        double d = df.applyAsDouble(x);
        if (Math.abs(d) < 1e-14)
            throw new ArithmeticException("导数为零，牛顿法停摆");
        x = x - fx / d;
    }
    return x; // 达步数上限，返回当前最佳
}
// 用法：newtonRoot(x -> x*x - 2, x -> 2*x, 1.0, 1e-12, 20) → 1.41421356...
```

    }
    x
}

## 梯度下降：一阶方法的万能钥匙

沿负梯度方向走一步：\(x_{k+1} = x_k - \eta \nabla f(x_k)\)。对 \(L\)-光滑、\(\mu\)-强凸函数，取 \(\eta = 1/L\) 时函数值以 \(\big(1-\mu/L\big)^k\) 速率线性收敛——**收敛速度由条件数 \(\kappa = L/\mu\) 决定**，图解中的之字形就是 \(\kappa > 1\) 的直观代价。它不要求二阶可导、每步只需一次梯度评估，因此能吃下「参数量 \(10^9\) 的神经网络」这种牛顿法连 Hessian 都存不下的问题；反向传播（[08.机器学习算法/050.神经网络与反向传播](../08.机器学习算法/050.神经网络与反向传播.md)）提供梯度，本条目决定步法。随机梯度下降（SGD）只是把精确梯度换成小批量估计，骨架不变。

::: code-group

```java [Java]
public static double[] gradientDescent(java.util.function.Function<double[], double[]> grad,
                                       double[] x0, double eta, double tol, int maxIter) {
    double[] x = x0.clone();
    for (int i = 0; i < maxIter; i++) {
        double[] g = grad.apply(x);
        double norm = 0;
        for (double v : g) norm += v * v;
        if (Math.sqrt(norm) < tol) break;          // 梯度足够小即收敛
        for (int j = 0; j < x.length; j++) x[j] -= eta * g[j];
    }
    return x;
}
// f(x,y)=x²+3y² 的梯度： xy -> new double[]{2*xy[0], 6*xy[1]}
```

```rust [Rust]
pub fn gradient_descent<F>(grad: F, x0: &[f64], eta: f64, tol: f64, max_iter: usize) -> Vec<f64>
where
    F: Fn(&[f64]) -> Vec<f64>,
{
    let mut x = x0.to_vec();
    for _ in 0..max_iter {
        let g = grad(&x);
        let norm = g.iter().map(|v| v * v).sum::<f64>().sqrt();
        if norm < tol {
            break;
        }
        for (xi, gi) in x.iter_mut().zip(&g) {
            *xi -= eta * gi;
        }
    }
    x
}
// let g = |x: &[f64]| vec![2.0 * x[0], 6.0 * x[1]];
```

```typescript [TypeScript]
function gradientDescent(grad: (x: number[]) => number[], x0: number[],
                         eta: number, tol: number, maxIter: number): number[] {
  let x = [...x0];
  for (let i = 0; i < maxIter; i++) {
    const g = grad(x);
    const norm = Math.hypot(...g);
    if (norm < tol) break;
    x = x.map((v, j) => v - eta * g[j]);
  }
  return x;
}
// 例：grad = x => [2 * x[0], 6 * x[1]]（f = x² + 3y²）
```

## 共轭梯度法：迭代法里的「有限步精确解」

对 SPD（对称正定）矩阵 \(A\)，解 \(Ax=b\) 等价于极小化二次型 \(\varphi(x) = \tfrac{1}{2}x^TAx - b^Tx\)。最速下降的问题在于：新一轮的负梯度方向与上一轮步方向正交，在病态椭圆上反复「横切」。共轭梯度改为要求步方向两两 **\(A\)-共轭**（\(p_i^T A p_j = 0, i \ne j\)），沿每个方向精确线搜索一次；二维子空间互不干扰，精确算术下最多 \(n\) 步得到精确解，浮点实践通常在 \(\ll n\) 步内以 \(\sqrt{\kappa}\)（而非 \(1/\kappa\)）的速率收敛。经典三行循环体（Fletcher-Reeves 用于线性问题）：

\[
\alpha_k = \frac{r_k^T r_k}{p_k^T A p_k}, \qquad
\beta_k = \frac{r_{k+1}^T r_{k+1}}{r_k^T r_k}, \qquad
p_{k+1} = r_{k+1} + \beta_k p_k
\]

::: code-group

```java [Java]
public static double[] conjugateGradient(double[][] a, double[] b, double[] x0,
                                         double tol, int maxIter) {
    int n = b.length;
    double[] x = x0.clone();
    double[] r = new double[n];
    double[] p = new double[n];
    for (int i = 0; i < n; i++) {                  // r = b - A x
        double ax = 0;
        for (int j = 0; j < n; j++) ax += a[i][j] * x[j];
        r[i] = b[i] - ax;
        p[i] = r[i];
    }
    double rr = dot(r, r);
    for (int it = 0; it < maxIter && Math.sqrt(rr) > tol; it++) {
        double[] ap = matVec(a, p);
        double alpha = rr / dot(p, ap);
        for (int i = 0; i < n; i++) {
            x[i] += alpha * p[i];
            r[i] -= alpha * ap[i];
        }
        double newRR = dot(r, r);
        double beta = newRR / rr;
        for (int i = 0; i < n; i++) p[i] = r[i] + beta * p[i];
        rr = newRR;
    }
    return x;
}

static double[] matVec(double[][] a, double[] v) {
    int n = a.length;
    double[] out = new double[n];
    for (int i = 0; i < n; i++) {
        double s = 0;
        for (int j = 0; j < n; j++) s += a[i][j] * v[j];
        out[i] = s;
    }
    return out;
}

static double dot(double[] x, double[] y) {
    double s = 0;
    for (int i = 0; i < x.length; i++) s += x[i] * y[i];
    return s;
}
```

```rust [Rust]
pub fn conjugate_gradient(a: &[Vec<f64>], b: &[f64], x0: &[f64],
                          tol: f64, max_iter: usize) -> Vec<f64> {
    let n = b.len();
    let mat_vec = |v: &[f64]| -> Vec<f64> {
        a.iter().map(|row| row.iter().zip(v).map(|(x, y)| x * y).sum()).collect()
    };
    let dot = |x: &[f64], y: &[f64]| -> f64 {
        x.iter().zip(y).map(|(p, q)| p * q).sum()
    };
    let mut x = x0.to_vec();
    let av = mat_vec(&x);
    let mut r: Vec<f64> = (0..n).map(|i| b[i] - av[i]).collect();
    let mut p = r.clone();
    let mut rr = dot(&r, &r);
    for _ in 0..max_iter {
        if rr.sqrt() <= tol {
            break;
        }
        let ap = mat_vec(&p);
        let alpha = rr / dot(&p, &ap);
        for i in 0..n {
            x[i] += alpha * p[i];
            r[i] -= alpha * ap[i];
        }
        let new_rr = dot(&r, &r);
        let beta = new_rr / rr;
        for i in 0..n {
            p[i] = r[i] + beta * p[i];
        }
        rr = new_rr;
    }
    x
}
```

```typescript [TypeScript]
function conjugateGradient(a: number[][], b: number[], x0: number[],
                           tol: number, maxIter: number): number[] {
  const n = b.length;
  const matVec = (v: number[]) => a.map(row => row.reduce((s, x, j) => s + x * v[j], 0));
  const dot = (x: number[], y: number[]) => x.reduce((s, v, i) => s + v * y[i], 0);

  let x = [...x0];
  let r = b.map((bi, i) => bi - matVec(x)[i]);
  let p = [...r];
  let rr = dot(r, r);
  for (let it = 0; it < maxIter && Math.sqrt(rr) > tol; it++) {
    const ap = matVec(p);
    const alpha = rr / dot(p, ap);
    x = x.map((v, i) => v + alpha * p[i]);
    r = r.map((v, i) => v - alpha * ap[i]);
    const newRR = dot(r, r);
    const beta = newRR / rr;
    p = r.map((v, i) => v + beta * p[i]);
    rr = newRR;
  }
  return x;
}
```

```python [Python]
def conjugate_gradient(a, b, x0, tol=1e-10, max_iter=None):
    n = len(b)
    max_iter = max_iter or 2 * n
    def mat_vec(v):
        return [sum(aij * vj for aij, vj in zip(row, v)) for row in a]
    def dot(x, y):
        return sum(p * q for p, q in zip(x, y))

    x = list(x0)
    r = [b[i] - mat_vec(x)[i] for i in range(n)]
    p = list(r)
    rr = dot(r, r)
    for _ in range(max_iter):
        if rr ** 0.5 <= tol:
            break
        ap = mat_vec(p)
        alpha = rr / dot(p, ap)
        x = [xi + alpha * pi for xi, pi in zip(x, p)]
        r = [ri - alpha * ai for ri, ai in zip(r, ap)]
        new_rr = dot(r, r)
        beta = new_rr / rr
        p = [ri + beta * pi for ri, pi in zip(r, p)]
        rr = new_rr
    return x
```

## 常见陷阱

1. **CG 只能用于对称正定**：拿非对称或不定的 \(A\) 硬跑，残差不降反升或除零（\(p^TAp \le 0\)）。非对称系统请用 GMRES/BiCGSTAB，或解正规方程 \(A^TAx = A^Tb\)（代价：条件数平方）。
2. **牛顿法不保证收敛**：它只对「足够靠近」的根二次收敛。\(f(x)=\arctan x\) 从远处出发会极限环振荡，\(f'=0\) 处直接除零。工程做法：**阻尼牛顿**（\(\lambda \in (0,1]\) 线搜索）+ 与梯度下降混合（远处用 GD 逼近、近处切牛顿）。
3. **梯度下降的学习率是生死线**：\(\eta > 2/L\) 时对二次型直接发散（\(f=x^2+3y^2\) 中 \(L=6\)，\(\eta=0.4\) 起振）。调不上去就考虑带动量的 GD、Adam（[08.机器学习算法/050.神经网络与反向传播](../08.机器学习算法/050.神经网络与反向传播.md)）或换二阶方法。
4. **一阶方法在病态问题上蠕动**：\(\kappa\) 大时每步改善 \(\approx 1 - 2/\kappa\)，条件数 \(10^6\) 意味着亿级步——**预处理（preconditioning）** 是 CG 实战的半壁江山，先做对角/Jacobi 预处理再谈收敛。
5. **收敛判据别混用**：求根问题看 \(|f(x_k)|\)（残差），优化问题看 \(\|\nabla f\|\)（梯度范数）；对平坦区域 \(|f|\) 很小不代表 \(x\) 接近 \(x^\*\)。三者对非线性和非光滑都可能失真，监控多指标更稳。
6. **非凸世界没有全局保证**：梯度下降只收敛到驻点（可能是鞍点）；高维中鞍点指数多于极小点，靠扰动/动量逃离。全局优化属启发式领域（[08.机器学习算法/090.启发式优化](../08.机器学习算法/090.启发式优化.md)）。

# 总结

三条主线各有生态位：**牛顿法**用曲率信息买收敛速度（二次），适合小规模、导数便宜、初值靠谱的问题；**梯度下降**用「每步廉价 + 只要梯度」换下海量参数场景，是深度学习的肌肉记忆；**共轭梯度**在 SPD 二次型上以 \(\sqrt{\kappa}\) 速率逼近有限步精确解，撑起大规模稀疏求解。选择逻辑归结为三问：维度多高（Hessian 存不存得下）、矩阵什么结构（对称正定与否、病态程度）、梯度质量如何（精确还是含噪）。下一篇 [040.主成分分析PCA](./040.主成分分析PCA.md) 的正交投影视角与本篇的二次型极值正是同一枚硬币的两面。
