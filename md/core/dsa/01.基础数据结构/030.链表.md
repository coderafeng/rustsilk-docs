# 概述

链表（Linked List）用**指针把分散在堆上的节点串成线性序列**。与数组相反：不要求连续内存，因而**牺牲随机访问、换来 O(1) 的已知位置插删**，且天然按需增长无扩容成本。

- 时间复杂度：

  | 操作 | 链表 | 对比数组 |
  |------|:----:|:--------:|
  | 按下标访问 | O(n) | 数组 O(1) |
  | 头部插入/删除 | **O(1)** | 数组 O(n) |
  | 已知节点后插入/删除 | **O(1)** | 数组 O(n) |
  | 按值查找 | O(n) | O(n) |

- 空间复杂度：O(n)，且**每个节点多付出指针（单链表 1 个、双链表 2 个）+ 内存对齐**开销，缓存不友好。
- 应用场景：实现栈/队列/双端队列、LRU 缓存（哈希 + 双向链表，见 [090.哈希表应用](./090.哈希表应用.md)）、编辑器光标、多项式/大数、操作系统空闲内存块管理。

**本篇收录**：单向链表、双向链表、循环链表

**动画一：三种形态的结构差异** <!-- dsa.assets/linked-list/linked-list-forms.gif -->

1. **单链表**：每节点一个 `next`，只能从头向后走；
2. **双链表**：每节点 `prev` + `next`，可双向走、可 O(1) 删除已知节点；
3. **循环链表**：尾节点的 `next` 指回头部（或双向成环），无自然终点，适合轮转调度。

**动画二：在节点 p 之后插入新节点 x** <!-- dsa.assets/linked-list/linked-list-insert.gif -->

1. `x.next = p.next`（先把 x 接到 p 原后继）；
2. `p.next = x`（再把 p 指向 x）；
3. 双链表还要维护后继的 `prev`：`x.next.prev = x`、`x.prev = p`；
4. 强调**顺序不能反**：若先写 `p.next = x` 会丢失原后继导致断链。

# 详解

## 手写单链表与反转

反转是链表最经典操作（LeetCode 206），面试高频：

::: code-group
```java [Java]
class Node { int val; Node next; Node(int v) { val = v; } }

// 迭代反转：三指针前移
Node reverse(Node head) {
    Node prev = null, cur = head;
    while (cur != null) {
        Node nxt = cur.next;
        cur.next = prev;
        prev = cur;
        cur = nxt;
    }
    return prev;
}
```
```rust [Rust]
// 单链表用 Option<Box<Node>> 表达；反转需逐个把所有权取下
#[derive(Debug)]
struct Node { val: i32, next: Option<Box<Node>> }

fn reverse(mut head: Option<Box<Node>>) -> Option<Box<Node>> {
    let mut prev = None;
    while let Some(mut cur) = head {
        head = cur.next.take();   // 摘下 cur.next，所有权交给 head
        cur.next = prev.take();   // cur 反指 prev
        prev = Some(cur);
    }
    prev
}
```
```typescript [TypeScript]
type Node = { val: number; next: Node | null };
function reverse(head: Node | null): Node | null {
    let prev: Node | null = null;
    while (head) {
        const nxt = head.next;
        head.next = prev;
        prev = head;
        head = nxt;
    }
    return prev;
}
```
```python [Python]
class Node:
    def __init__(self, val):
        self.val, self.next = val, None

def reverse(head):
    prev = None
    while head:
        head.next, prev, head = prev, head, head.next  # 同元组赋值，顺序天然正确
    return prev
```
:::

## 哨兵节点与双指针技巧

- **虚拟头节点（dummy）**：在 `head` 前挂一个哨兵，统一处理"删除/插入首节点"的边界，省去大量 `if head` 特判。
- **快慢指针**：求中点、找环（Floyd 判环，见 [02.基础算法/170.双指针技巧](../02.基础算法/170.双指针技巧.md)）、倒数第 k 个节点。

## 常见陷阱

- **断链顺序**：插入必须先接后拆，删除必须先保存 `next` 再释放。
- **释放后访问**：C/C++ 删除节点后仍用其 `next` 是悬垂指针；带 GC 语言则易因忘了断链导致内存无法回收。
- **环导致死循环**：循环链表或意外成环时，`while (cur)` 永不终止——先判环。

# 总结

- 链表用「指针 + 非连续内存」换得**已知位置 O(1) 插删、按需增长**，代价是**无随机访问、额外指针、缓存差**；
- 频繁头/中插删或作为栈队列底座时选链表，随机访问多为 010.数组；
- 反转、合并、判环是链表基本功，善用 **dummy 哨兵**与**快慢指针**能消除绝大多数边界 bug。
