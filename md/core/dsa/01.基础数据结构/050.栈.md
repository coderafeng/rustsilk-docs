# 概述

栈（Stack）是只允许在**同一端**（栈顶）增删元素的受限线性表，遵循**后进先出 LIFO**。正因为操作面收窄到一端，它把"最近的东西优先处理"这一模式固化下来，成为函数调用、回溯、表达式求值的天然模型。

- 时间复杂度：

  | 操作 | 复杂度 | 说明 |
  |------|:------:|------|
  | push / pop | O(1) | 只在栈顶 |
  | peek（看顶） | O(1) | — |
  | 查找任意元素 | O(n) | 非栈的合法操作 |

- 空间复杂度：O(n)。
- 应用场景：函数调用栈与递归、括号/语法匹配、表达式求值与后缀转换、浏览器前进后退、撤销栈、DFS、单调栈求_next 更大元素、编译器作用域与虚拟机操作数栈。

- 所属章节：[000.基础数据结构概述](./000.基础数据结构概述.md)

# 详解

## 两种实现：顺序栈与链式栈

- **顺序栈**：动态数组 + 栈顶指针，连续内存、缓存友好、支持随机访问（若不需要可只用顶），扩容均摊 O(1)；
- **链式栈**：链表头做栈顶，头插头删 O(1)，无需扩容但每节点带指针。

绝大多数语言用**数组/双端队列**直接充当栈即可，无需手写：

::: code-group
```java [Java]
Deque<Integer> stack = new ArrayDeque<>(); // 栈首选 ArrayDeque，勿用过时的 Stack
stack.push(1);
stack.push(2);
System.out.println(stack.peek()); // 2，看顶不弹出
System.out.println(stack.pop());  // 2，弹出
// 括号匹配
boolean ok = true;
Deque<Character> st = new ArrayDeque<>();
for (char c : "([]{})".toCharArray()) {
    if (c == '(' || c == '[' || c == '{') st.push(c);
    else {
        if (st.isEmpty()) { ok = false; break; }
        char o = st.pop();
        if ((c == ')' && o != '(') || (c == ']' && o != '[') || (c == '}' && o != '{')) { ok = false; break; }
    }
}
ok = ok && st.isEmpty();
```
```rust [Rust]
// Vec 即栈：push / pop 都在末尾，O(1)
let mut stack: Vec<i32> = Vec::new();
stack.push(1);
stack.push(2);
println!("{}", stack.last().unwrap()); // peek = 2
println!("{}", stack.pop().unwrap());  // pop  = 2
```
```typescript [TypeScript]
const stack: number[] = [];
stack.push(1, 2);
console.log(stack.at(-1)); // peek = 2
console.log(stack.pop());  // pop  = 2
```
```python [Python]
# list 即栈：append / pop 都在末尾，O(1)
stack = []
stack.append(1)
stack.append(2)
print(stack[-1])   # peek = 2
print(stack.pop()) # pop  = 2
```
:::

## 递归与调用栈

每次函数调用都会在调用栈压入一个栈帧（局部变量、返回地址）。递归本质就是"用系统栈做回溯"，因此**任何递归都能用显式栈改写**——这既能规避栈溢出（深度过大），也是把递归转迭代的通用套路。

## 常见陷阱

- **栈上溢/下溢**：数组满时 push、空栈时 pop/peek 必须先判空/判容量。
- **递归过深爆栈**：Java 默认栈约 1MB，百万级递归需转迭代或加大 `-Xss`。
- **用错容器**：Java `Stack`/`Vector` 是历史包袱（继承自 Vector、暴露了非栈方法），应改用 `Deque`+`ArrayDeque`。

# 总结

- 栈以 LIFO 约束换来 push/pop/peek 均 O(1)，是"最近优先/嵌套匹配"的默认模型；
- 实现首选**顺序栈（动态数组/双端队列）**，无需手写除非特殊约束；
- 递归 = 系统栈，理解这一点即可在「递归」与「显式栈迭代」间自由转换，并规避爆栈。
