# 概述

哈希函数把**任意长度的输入**压缩到**固定范围的整数**（哈希值/桶下标），是哈希表 O(1) 定位的前提。好的哈希函数要同时满足：**计算快、分布均匀（少冲突）、对输入扰动敏感**。

- 时间复杂度：与输入规模成正比，数值型 O(1)，字符串/对象 O(k)（k 为键长度/字段数）。
- 空间复杂度：O(1)（函数本身），产出值域固定。
- 应用场景：哈希表/集合的定位、布隆过滤器、分片路由（一致性哈希，见 [10.应用与专题/070.一致性哈希](../10.应用与专题/070.一致性哈希.md)）、校验与指纹。注意与 [09.密码学算法/040.哈希算法](../09.密码学算法/040.哈希算法.md) 区分：**索引哈希求快、允许冲突；密码学哈希求不可逆、抗碰撞**。

# 详解

## 常用构造方法

- **直接定址**：`H(k) = a·k + b`，无冲突但要求键稀疏且范围小；
- **除留余数**：`H(k) = k % p`，`p` 取**不大于表长的素数**分布最均匀（最常用）；
- **数字分析/平方取中**：取中间位以放大差异，用于分布不均的键；
- **字符串多项式滚动哈希**：把字符串当 p 进制数 `h = h·base + c`，配合取模，是 Rabin-Karp、`String.hashCode` 的骨架（见 [06.字符串与数论/010.字符串匹配算法](../06.字符串与数论/010.字符串匹配算法.md)）。

## 多语言里的字符串哈希

::: code-group
```java [Java]
// String.hashCode：h = 31*h + c，31 为奇素数、便于 JIT 用移位优化、溢出自动模 2^32
int h = "rustsilk".hashCode();
int slot = Math.floorMod(h, tableSize); // 取模务必用 floorMod 处理负数
```
```rust [Rust]
// 标准库默认用 SipHash-1-3（抗 hashdos）；FNV/wyhash 等更快但无抗攻击性
use std::collections::Hasher;
use std::hash::{BuildHasherDefault, DefaultHasher};
let mut hasher = DefaultHasher::new();
std::hash::Hash::hash("rustsilk", &mut hasher);
println!("{}", hasher.finish());
```
```typescript [TypeScript]
// 简易 DJB2 字符串哈希（JS 对象键由引擎内部哈希，此处用于自实现哈希表）
function djb2(s: string): number {
    let h = 5381;
    for (let i = 0; i < s.length; i++) h = ((h << 5) + h + s.charCodeAt(i)) >>> 0; // *33
    return h >>> 0;
}
```
```python [Python]
# 内置 hash() 用带随机盐的 SipHash（防碰撞 DoS，故跨进程不稳定，不能持久化）
print(hash("rustsilk"))
# 需要稳定值时用 hashlib 或手写 FNV-1a
h = 0xcbf29ce484222325
for c in b"rustsilk":
    h = ((h ^ c) * 0x100000001b3) & 0xFFFFFFFFFFFFFFFF
print(h)
```
:::

## 关键设计点

- **乘数选素数**（31、131、0x100000001b3）：让低位也参与，分布更散、减少规律键的聚集。
- **取模 vs 与运算**：表长取 2 的幂可用 `h & (n-1)` 代替 `%`（Java HashMap 如此），快但要靠扰动函数 `h ^ (h >>> 16)` 把高位信息引入低位。
- **无符号/负数**：哈希值可能为负，落桶前必须 `floorMod`/`& mask`/`>>>0` 归一。

# 总结

- 哈希函数的目标是**快 + 均匀 + 敏感**，冲突越少哈希表越接近 O(1)；
- 数值键用 `k % 素数`，字符串键用多项式滚动哈希（乘素数 31/131）；
- 索引哈希与密码学哈希目标迥异，别把 `hashCode`/FNV 当摘要用，也别指望 MD5 做快速桶定位。
