# 概述

队列（Queue）是只允许**队尾入、队头出**的受限线性表，遵循**先进先出 FIFO**。它把"先来先服务"的顺序固化下来，是广度优先搜索、缓冲与削峰的基本结构。

- 时间复杂度：

  | 操作 | 复杂度 | 说明 |
  |------|:------:|------|
  | enqueue / dequeue | O(1) | 循环数组或链表 |
  | front / rear | O(1) | 看两端 |
  | 查找 | O(n) | 非法操作，队列不随机访问 |

- 空间复杂度：O(n)。
- 应用场景：BFS 层序遍历、生产者-消费者与消息队列（RabbitMQ/Kafka）、打印/任务调度、令牌桶限流、滑动窗口最值（单调队列）、缓冲区。

**本篇收录**：顺序/循环队列、双端队列、优先级队列、阻塞队列

# 详解

## 为什么需要循环队列

普通数组队列出队后前部空间被浪费，要么整体搬移（O(n)），要么用**循环数组**让头尾指针折返，把空间复用到底——这是顺序实现 O(1) 入出的关键技巧。

## 队列家族

- **双端队列 Deque**：两端都可入出，是栈和队列的超集，滑动窗口、限流的最爱；
- **优先级队列 PriorityQueue**：出队按"优先级"而非到达顺序，底层二叉堆（见 [03.树结构/030.堆与优先队列](../03.树结构/030.堆与优先队列.md)），出队 O(log n)；
- **阻塞队列 BlockingQueue**：满时入队阻塞、空时出队阻塞，是并发生产者-消费者的标准件。

## 循环队列与各语言容器

::: code-group
```java [Java]
// 循环数组核心：下标取模折返
int[] q = new int[8];
int front = 0, rear = 0, C = 8;
void enqueue(int v) {
    if ((rear + 1) % C == front) throw new IllegalStateException("full");
    q[rear] = v;
    rear = (rear + 1) % C;
}
int dequeue() {
    if (front == rear) throw new java.util.NoSuchElementException("empty");
    int v = q[front];
    front = (front + 1) % C;
    return v;
}
// 实际项目直接用双端队列：Queue/Deque
Deque<Integer> dq = new ArrayDeque<>();
dq.offer(1); dq.offer(2);
System.out.println(dq.poll()); // 1，FIFO
```
```rust [Rust]
// VecDeque 是环形双端队列，两端 O(1)
use std::collections::VecDeque;
let mut q = VecDeque::new();
q.push_back(1);
q.push_back(2);
println!("{:?}", q.pop_front()); // Some(1)，FIFO
```
```typescript [TypeScript]
// JS 无内置队列；Array 的 shift 是 O(n)，量大时用双端结构或下标指针
const q: number[] = [1, 2, 3];
let front = 0;
const size = () => q.length - front;
const enqueue = (v: number) => q.push(v);
const dequeue = () => (size() > 0 ? q[front++] : undefined);
console.log(dequeue()); // 1
```
```python [Python]
# 队列首选 deque，list.pop(0) 是 O(n)
from collections import deque
q = deque([1, 2, 3])
print(q.popleft())  # 1，O(1) FIFO
q.append(4)
```
:::

## 常见陷阱

- **满/空歧义**：循环队列 `front == rear` 既可能空也可能满，需"牺牲一格"或额外 `count` 字段区分。
- **用 List 头删当队列**：Java `ArrayList.remove(0)`、Python `list.pop(0)` 均 O(n)，应换 `ArrayDeque`/`deque`。

# 总结

- 队列以 FIFO 约束换来两端 O(1)，是**顺序处理与缓冲**的基本结构；
- 顺序实现靠**循环数组**折返指针避免空间浪费；
- 按需求选变体：两端操作选 Deque、按优先级出队选 PriorityQueue、并发缓冲选 BlockingQueue。
