# 概述

数据结构与算法（Data Structures and Algorithms）是程序员的「核心内力」：数据结构是组织数据的方式，算法是处理数据的方法，两者共同决定程序的时空效率。

本笔记**主线语言为 Java**，同时并置 **Rust、JS/TS、Python** 三种实现：凡涉及具体代码处，均以 VitePress `::: code-group` 代码组同时给出多语言版本（详见文末「写作约定」）。内容覆盖从基础数据结构到专业算法的完整谱系：

- **数据结构**：数组、链表、栈、队列、哈希表、树、图、并查集及各类高级结构
- **基础算法**：11 种排序、查找、枚举、双指针/滑动窗口/前缀和等技巧
- **算法思想**：算法分析基础、分治、动态规划、贪心、回溯、分支界定、启发式搜索
- **专业方向**：图论、字符串匹配与相似度、数论、计算几何、数值计算、机器学习、密码学与应用算法
