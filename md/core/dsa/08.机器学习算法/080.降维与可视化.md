# 概述

PCA 能拉直「一根棍子」，却拉不平「一卷纸」：线性降维只能保留全局方差方向，遇到流形卷曲、簇间嵌套的数据就力不从心。**t-SNE**（t-distributed Stochastic Neighbor Embedding）换了一条路——它不关心「整体朝哪拉伸」，只关心「谁和谁是邻居」：先把高维空间里的邻近关系翻译成概率分布，再在低维（通常 2D）摆点，用自由度为 1 的 t 分布做「软邻居」模型，通过梯度下降让两边的邻居结构尽量一致。结果是今天论文里最常见的二维彩色散点图：**局部簇看得清，全局尺度别当真**。

- 所属章节：[000.机器学习算法概述](./000.机器学习算法概述.md)
- 时间复杂度：朴素实现每轮梯度 \(O(n^2 d)\)（全点对距离）；大规模用 Barnes-Hut 树近似降至 \(O(n \log n)\)；迭代轮数经验 250～1000
- 空间复杂度：\(O(n^2)\)（稀疏化邻接后可降至 \(O(n \cdot k)\)，\(k\) 为近邻数）
- 应用场景：单细胞测序/图像嵌入（如 CNN 特征）的二维检视、聚类结果「肉眼验收」、高维数据的异常直观化
- 线性降维对照：PCA 见 [07.数值计算/040.主成分分析PCA](../07.数值计算/040.主成分分析PCA.md)；UMAP 是 t-SNE 的「工程提速版」，思路同源（近邻图 + 布局优化），本篇不展开

1. 非归一化相似度：\(p(2|1) \propto e^{-\lVert x_1-x_2\rVert^2/(2\sigma^2)} = e^{-1/2} \approx 0.6065\)；\(p(3|1) \propto e^{-16/2} = e^{-8} \approx 0.000335\)。
2. 归一化：\(p(2|1) = 0.6065/(0.6065+0.000335) \approx 0.99945\)，\(p(3|1) \approx 0.00055\)——\(x_1\) 的「邻居预算」几乎全给了 \(x_2\)。
3. 换到 \(x_3\) 视角：它离谁都远，若 \(\sigma\) 不变则两个邻居概率对半开；** perplexity 自动搜索**会挑一个更小的 \(\sigma_3\)，让 \(p(2|3)\) 一家独大——「孤点自己收紧半径」。
4. 对称化 \(p_{ij} = (p(j|i)+p(i|j))/(2n)\)：每对点的相似度是「互看对方顺不顺眼」的平均。

# 详解

## 从距离到概率：高维侧的「邻居预算」

t-SNE 第一步把硬距离变成软概率。对每个点 \(i\)，以自身为参照定义：

\[
p(j \mid i) = \frac{\exp\left(-\lVert x_i - x_j \rVert^2 / 2\sigma_i^2\right)}{\sum_{k \ne i} \exp\left(-\lVert x_i - x_k \rVert^2 / 2\sigma_i^2\right)}
\]

\(\sigma_i\) 不由用户定，而是**反解 perplexity**：

\[
P(P_i) = 2^{-H(P_i)}, \qquad H(P_i) = -\sum_j p(j \mid i)\log_2 p(j \mid i)
\]

给定目标困惑度（常用 5～50，直觉是「有效邻居数」），对 \(\sigma_i\) 做二分搜索直到 \(H = \log_2 \text{perplexity}\)。稠密区的点会被配大 \(\sigma\)（邻居多、摊得平），稀疏区的点配小 \(\sigma\)（只盯住最近的一两个）——这一步就是 t-SNE 「自适应局部尺度」的灵魂。

对称化并归一：\(p_{ij} = \dfrac{p(j|i) + p(i|j)}{2n}\)。

## 低维侧与代价：为什么是 t 分布

低维坐标 \(y_i\) 用**自由度 1 的 t 分布**（柯西核）度量相似度：

\[
q_{ij} = \frac{\left(1 + \lVert y_i - y_j \rVert^2\right)^{-1}}{\sum_{k \ne l}\left(1 + \lVert y_k - y_l \rVert^2\right)^{-1}}
\]

对比高维侧的高斯核（指数衰减），柯西核的尾巴**厚得多**：要在 2D 把一对 \(p_{ij}\) 不小的点拉近，\(q_{ij}\) 上升很快；而远处的点对 \(q\) 趋近 0 的速度却很慢。这带来著名的**拥挤问题**解法——高维中大量「不近不远」的点在 2D 会被强制摊开，否则损失函数不肯收敛；若用普通高斯核做低维模型（即原 SNE），外围点挤成一圈「糊边」，簇就分不开。

优化目标是 KL 散度 \(C = \sum_{ij} p_{ij}\log\dfrac{p_{ij}}{q_{ij}}\)，梯度有闭式：

\[
\frac{\partial C}{\partial y_i} = 4 \sum_j p_{ij}\left(q_{ij}\right)\left(y_i - y_j\right)
\]

吸引项 \(p_{ij}q_{ij}(y_i-y_j)\) 拉近邻居，排斥项藏在 \(q_{ij}\) 的全局归一化里把点推开。工程上配三件套：**早 exaggerated**（前 100～250 轮把 \(p_{ij}\) 乘 4～12，先粗粒度抱团）、**动量**（0.5 起步，第 250 轮升 0.8）、**学习率**（约 \(\max(n/\text{perplexity}, 50)\)，过大反而全糊成一点）。

```java [Java]
public static double[][] tsne(double[][] X, int dims, double perp,
                              double lr, int iters, long seed) {
    int n = X.length;
    Random rnd = new Random(seed);
    double[][] P = jointProbs(X, perp);                  // 高维联合概率（对称化后）
    double[][] Y = new double[n][dims];                  // 小高斯随机初始化
    for (double[] row : Y)
        for (int t = 0; t < dims; t++) row[t] = rnd.nextGaussian() * 1e-4;
    double[][] G = new double[n][dims], m = new double[n][dims];  // 动量缓存
    for (int it = 0; it < iters; it++) {
        double exag = it < 250 ? 4.0 : 1.0;              // 前段放大 P：先抱团
        double mu = it < 250 ? 0.5 : 0.8;                // 动量切换
        double[][] num = new double[n][n];               // q 的分子 (1+d²)⁻¹
        double sumQ = 0;
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++) if (i != j) {
                double d2 = 0;
                for (int t = 0; t < dims; t++) d2 += sq(Y[i][t] - Y[j][t]);
                num[i][j] = 1.0 / (1.0 + d2);
                sumQ += num[i][j];
            }
        for (int i = 0; i < n; i++)
            for (int t = 0; t < dims; t++) {
                double g = 0;
                for (int j = 0; j < n; j++) if (i != j) {
                    double q = num[i][j] / (sumQ + 1e-12);
                    g += 4 * (exag * P[i][j] - q) * (Y[i][t] - Y[j][t]);
                }
                G[i][t] = g;
                m[i][t] = mu * m[i][t] - lr * G[i][t];   // 动量更新
                Y[i][t] += m[i][t];
            }
        // 平移使均值为 0（去掉整体漂移自由度）
        for (int t = 0; t < dims; t++) {
            double mean = 0;
            for (int i = 0; i < n; i++) mean += Y[i][t];
            mean /= n;
            for (int i = 0; i < n; i++) Y[i][t] -= mean;
        }
    }
    return Y;
}
// jointProbs：对每个 i 二分搜索 σ 使 perplexity 命中目标，
// 再对称化 P = (P·Pᵀ)/(2Σp)，实现约 30 行。
static double sq(double v) { return v * v; }
```

```rust [Rust]
pub fn tsne(x: &[Vec<f64>], dims: usize, perp: f64, lr: f64,
            iters: usize, seed: u64) -> Vec<Vec<f64>> {
    let n = x.len();
    let p = joint_probs(x, perp);                        // 对称化联合概率
    let mut rng = Rng::new(seed);                        // 复刻 nextGaussian 的小 LCG
    let mut y: Vec<Vec<f64>> = (0..n)
        .map(|_| (0..dims).map(|_| rng.gaussian() * 1e-4).collect())
        .collect();
    let mut m = vec![vec![0.0; dims]; n];
    for it in 0..iters {
        let exag = if it < 250 { 4.0 } else { 1.0 };
        let mu = if it < 250 { 0.5 } else { 0.8 };
        let mut num = vec![vec![0.0; n]; n];
        let mut sum_q = 0.0;
        for i in 0..n {
            for j in 0..n {
                if i == j { continue; }
                let d2: f64 = y[i].iter().zip(&y[j]).map(|(a, b)| (a - b) * (a - b)).sum();
                num[i][j] = 1.0 / (1.0 + d2);
                sum_q += num[i][j];
            }
        }
        for i in 0..n {
            for t in 0..dims {
                let mut g = 0.0;
                for j in 0..n {
                    if i == j { continue; }
                    let q = num[i][j] / (sum_q + 1e-12);
                    g += 4.0 * (exag * p[i][j] - q) * (y[i][t] - y[j][t]);
                }
                m[i][t] = mu * m[i][t] - lr * g;
                y[i][t] += m[i][t];
            }
        }
        for t in 0..dims {                               // 去均值
            let mean: f64 = y.iter().map(|r| r[t]).sum::<f64>() / n as f64;
            for i in 0..n { y[i][t] -= mean; }
        }
    }
    y
}
```

```typescript [TypeScript]
function tsne(X: number[][], dims: number, perp: number,
              lr: number, iters: number, seed: number): number[][] {
  const n = X.length;
  const P = jointProbs(X, perp);
  let s = seed;
  const randn = () => {                                  // 线性同余 + Box-Muller
    s = (s * 1103515245 + 12345) & 0x7fffffff;
    const u = Math.max((s / 0x7fffffff) % 1, 1e-9);
    s = (s * 1103515245 + 12345) & 0x7fffffff;
    const v = Math.max((s / 0x7fffffff) % 1, 1e-9);
    return Math.sqrt(-2 * Math.log(u)) * Math.cos(2 * Math.PI * v);
  };
  const Y = Array.from({ length: n }, () => Array.from({ length: dims }, () => randn() * 1e-4));
  const M = Array.from({ length: n }, () => new Array(dims).fill(0));
  for (let it = 0; it < iters; it++) {
    const exag = it < 250 ? 4.0 : 1.0, mu = it < 250 ? 0.5 : 0.8;
    const num = Array.from({ length: n }, () => new Array(n).fill(0));
    let sumQ = 0;
    for (let i = 0; i < n; i++)
      for (let j = 0; j < n; j++) if (i !== j) {
        let d2 = 0;
        for (let t = 0; t < dims; t++) d2 += (Y[i][t] - Y[j][t]) ** 2;
        num[i][j] = 1 / (1 + d2);
        sumQ += num[i][j];
      }
    for (let i = 0; i < n; i++)
      for (let t = 0; t < dims; t++) {
        let g = 0;
        for (let j = 0; j < n; j++) if (i !== j) {
          const q = num[i][j] / (sumQ + 1e-12);
          g += 4 * (exag * P[i][j] - q) * (Y[i][t] - Y[j][t]);
        }
        M[i][t] = mu * M[i][t] - lr * g;
        Y[i][t] += M[i][t];
      }
    for (let t = 0; t < dims; t++) {                     // 去均值
      const mean = Y.reduce((a, r) => a + r[t], 0) / n;
      for (let i = 0; i < n; i++) Y[i][t] -= mean;
    }
  }
  return Y;
}
```

```python [Python]
def tsne(X, dims=2, perp=30.0, lr=200.0, iters=1000, seed=42):
    n = len(X)
    P = joint_probs(X, perp)                             # 对称化联合概率
    rng = random.Random(seed)
    Y = [[rng.gauss(0, 1e-4) for _ in range(dims)] for _ in range(n)]
    M = [[0.0] * dims for _ in range(n)]
    for it in range(iters):
        exag = 4.0 if it < 250 else 1.0                  # 早放大
        mu = 0.5 if it < 250 else 0.8                    # 动量
        num = [[0.0] * n for _ in range(n)]
        sum_q = 0.0
        for i in range(n):
            for j in range(n):
                if i == j:
                    continue
                d2 = sum((a - b) ** 2 for a, b in zip(Y[i], Y[j]))
                num[i][j] = 1.0 / (1.0 + d2)
                sum_q += num[i][j]
        for i in range(n):
            for t in range(dims):
                g = sum(4 * (exag * P[i][j] - num[i][j] / (sum_q + 1e-12))
                        * (Y[i][t] - Y[j][t])
                        for j in range(n) if j != i)
                M[i][t] = mu * M[i][t] - lr * g
                Y[i][t] += M[i][t]
        for t in range(dims):                            # 去均值
            mean = sum(Y[i][t] for i in range(n)) / n
            for i in range(n):
                Y[i][t] -= mean
    return Y
```

`joint_probs`（二分搜索 \(\sigma\) + 对称化）是所有语言的公共前置，约 30 行，逻辑即动画 2 的公式——逐点固定 \(\beta\) 二分，使 \(H(P_i)\) 命中 \(\log_2 \text{perplexity}\)，最后 \(P \leftarrow \dfrac{P + P^{\top}}{2\sum P}\) 归一。

## 常见陷阱

::: danger 陷阱清单
1. **跨簇距离与簇大小没有语义**：t-SNE 只保证「邻居是谁」，不保证「两团隔多远代表多不像」——不同运行、不同 perplexity 下簇间距完全不可比；把「簇看起来紧凑」当成「该类内聚度高」也是过度解读。
2. **同一次运行内也别比大小**：大簇往往被摊得比小簇更开，视觉面积与样本数不成正比。
3. **perplexity 要跑几组**：5、15、30、50 各出一图，结构稳定复现才算结论；某一 perplexity 下「刚好」分开的两条腿可能是假象。
4. **随机种子改变形态**：初始化与梯度路径含随机性，同数据不同种子可能簇的相对位置翻转——报告里固定种子并注明。
5. **高维先 PCA**：几百维直接上 t-SNE 既慢又容易被无关维度的距离噪声带偏；先 PCA 留 50 维左右是 sklearn 教程的标准做法。
6. **学习率过大反而糊成一团**：出现「所有点挤成一个毛球、中间空荡」的形态，第一反应是降学习率，而不是数据有问题。
7. **它是「可视化」不是「降维模型」**：t-SNE 没有 `transform` 新样本的能力（近似外推要用 Parametric t-SNE/UMAP）；把它当作可导出的特征工程步骤是误用——下游建模请用聚类标签或原始高维特征。
:::

::: info t-SNE 四步
1. 逐点二分搜索 \(\sigma_i\)，把距离变条件概率 \(p(j|i)\)（困惑度定「邻居预算」）；
2. 对称化得联合概率 \(p_{ij}\)；
3. 2D 随机摆点，用柯西核算 \(q_{ij}\)；
4. 梯度下降（早放大 + 动量）把 \(q\) 压向 \(p\)，读图只看局部结构。
:::

# 总结

- t-SNE 的世界观：**邻居关系即数据本质**——高维侧用自适应高斯核把「谁挨着谁」概率化，低维侧用重尾的 t 核摆点，KL 梯度把两张概率图对齐。
- 它解决的是线性方法的死穴：卷曲流形与尺度悬殊的局部密度；代价是全局几何失真、结果依赖 perplexity 与种子、无法外推新样本。
- 正确的打开方式：PCA 预降维 → 多个 perplexity 交叉验证 → 固定种子 → 只解读局部簇、不解读簇间距与大小。
- 与它配套：簇的形状好不好，先用 [070.聚类算法](./070.聚类算法.md) 跑一遍再画在 t-SNE 图上对答案；UMAP 是其快速替代，思想同源。
