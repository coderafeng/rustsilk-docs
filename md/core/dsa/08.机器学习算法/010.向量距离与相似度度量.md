# 概述

把对象表示成向量后，「相似度」就落实为向量间的距离或夹角。本篇四种度量构成机器学习与向量检索的通用语言：**欧氏距离**（\(L_2\)，直线距离）、**曼哈顿距离**（\(L_1\)，街区块距离）、**闵可夫斯基距离**（\(L_p\) 家族通则，前两者是特例）、**余弦相似度**（方向夹角，尺度无关）。选错度量比选错模型更常见：高维稀疏文本向量用欧氏会被「长度差」主导，归一化后的余弦才公平；含大量零的计数特征用 \(L_1\) 往往比 \(L_2\) 稳健。

**本篇收录**：**Euclidean（欧氏距离）**、**Manhattan / L1（曼哈顿距离）**、**Minkowski（闵可夫斯基距离）**、**Cosine（余弦相似度）**

- 所属章节：[000.机器学习算法概述](./000.机器学习算法概述.md)
- 时间复杂度：单对向量均为 \(O(d)\)（\(d\) 为维度）；批量 \(m \times n\) 对距离矩阵 \(O(mnd)\)
- 空间复杂度：\(O(1)\)（逐维累加）
- 应用场景：KNN 分类与回归（[030.监督学习算法](./030.监督学习算法.md)）、K-means/DBSCAN 簇内度量（[070.聚类算法](./070.聚类算法.md)）、向量数据库检索（Faiss/Milvus 的 \(L_2\)/内积索引）、推荐系统物品相似、图像指纹比对；集合层面的相似度另见 [020.集合相似度系数](./020.集合相似度系数.md)，字符串层面见 [06.字符串与数论/030.字符串相似度与编辑距离](../06.字符串与数论/030.字符串相似度与编辑距离.md)
- 前置：向量点积与模长（矩阵语言见 [07.数值计算/020.矩阵运算算法](../07.数值计算/020.矩阵运算算法.md)）

# 详解

## 定义与选型地图

\[
d_{L_p}(x, y) = \Big(\sum_{i=1}^d |x_i - y_i|^p\Big)^{1/p}, \quad
d_{L_1} = \sum |x_i - y_i|, \quad
d_{L_2} = \sqrt{\sum (x_i - y_i)^2}
\]

\[
\cos(x, y) = \frac{x \cdot y}{\lVert x \rVert \, \lVert y \rVert} = \frac{\sum x_i y_i}{\sqrt{\sum x_i^2} \sqrt{\sum y_i^2}} \in [-1, 1]
\]

四条实用结论：

1. **维度诅咒下 \(L_1\) 比 \(L_2\) 有区分度**：高维空间中 \(L_2\) 的相对对比度（最近/最远距离差）会坍缩，\(L_1\) 与「坐标差异更大」的场景（如直方图、计数向量）更稳。
2. **余弦与归一化欧氏同序**：对单位化向量，\(\lVert x - y \rVert_2 = \sqrt{2 - 2\cos\theta}\)——向量库常用「内积 + 归一」替代显式余弦，省一次除法。
3. **马氏距离**补上了「协方差」盲区：\(d_M(x,y) = \sqrt{(x-y)^T \Sigma^{-1} (x-y)}\)，旋转/尺度不变的椭圆度量，异常检测（与 [07.数值计算/040.主成分分析PCA](../07.数值计算/040.主成分分析PCA.md) 同源）常用。
4. **切比雪夫 \(L_\infty\)**：棋盘上车的移动、容差校验（每坐标误差均不超过 \(\varepsilon\)）的标准语言。

## 代码：四度量的正确姿势

实现层面三个共同注意点：\(L_2\) 先平方后开方可**延迟到最后**一次（批量比较距离平方即可保持同序，省 \(m\) 次开方）；余弦必须防**零向量**（模长为 0 时按约定返回 0 或抛异常，勿让它 NaN 扩散）；闵氏 \(p < 1\) 不再是度量（三角不等式不成立），仅作相似度启发式。

```java [Java]
public static double euclidean(double[] x, double[] y) {
    double s = 0;
    for (int i = 0; i < x.length; i++) {
        double d = x[i] - y[i];
        s += d * d;
    }
    return Math.sqrt(s);
}

public static double manhattan(double[] x, double[] y) {
    double s = 0;
    for (int i = 0; i < x.length; i++) s += Math.abs(x[i] - y[i]);
    return s;
}

public static double minkowski(double[] x, double[] y, double p) {
    double s = 0;
    for (int i = 0; i < x.length; i++)
        s += Math.pow(Math.abs(x[i] - y[i]), p);
    return Math.pow(s, 1.0 / p);
}

public static double cosine(double[] x, double[] y) {
    double dot = 0, nx = 0, ny = 0;
    for (int i = 0; i < x.length; i++) {
        dot += x[i] * y[i];
        nx += x[i] * x[i];
        ny += y[i] * y[i];
    }
    if (nx == 0 || ny == 0) return 0.0;             // 零向量约定：相似度 0
    return dot / (Math.sqrt(nx) * Math.sqrt(ny));
}
// (1,2,3) vs (4,5,6)：euclid=5.196, manhattan=9, minkowski3=4.327, cosine=0.975
```

```rust [Rust]
pub fn euclidean(x: &[f64], y: &[f64]) -> f64 {
    x.iter().zip(y).map(|(a, b)| (a - b) * (a - b)).sum::<f64>().sqrt()
}

pub fn manhattan(x: &[f64], y: &[f64]) -> f64 {
    x.iter().zip(y).map(|(a, b)| (a - b).abs()).sum()
}

pub fn minkowski(x: &[f64], y: &[f64], p: f64) -> f64 {
    x.iter().zip(y).map(|(a, b)| (a - b).abs().powf(p)).sum::<f64>().powf(1.0 / p)
}

pub fn cosine(x: &[f64], y: &[f64]) -> f64 {
    let mut dot = 0.0;
    let mut nx = 0.0;
    let mut ny = 0.0;
    for (a, b) in x.iter().zip(y) {
        dot += a * b;
        nx += a * a;
        ny += b * b;
    }
    if nx == 0.0 || ny == 0.0 {
        return 0.0;
    }
    dot / (nx.sqrt() * ny.sqrt())
}
```

```typescript [TypeScript]
function euclidean(x: number[], y: number[]): number {
  let s = 0;
  for (let i = 0; i < x.length; i++) {
    const d = x[i] - y[i];
    s += d * d;

function manhattan(x: number[], y: number[]): number {
```

## 常见陷阱

1. **相似度与距离混用导致排序方向错**：余弦是「越大越像」、欧氏是「越小越近」，Top-K 检索里一个 `largest=True/False` 全反——入库前先统一到「距离」或「分数」一种语义。
2. **忘记归一化就比余弦**：特征量纲不一致（年龄 0~100 vs 收入 0~10⁶）时，大数值维度绑架一切度量；标准化（z-score）或 min-max 后再算，或直接选马氏距离。
3. **`sqrt` 加在循环里**：批量找最近邻时比较 \(d^2\) 即可，开方只留给最终展示；\(L_1\) 无此烦恼但循环内每步 `abs` 也比「累加差再判断」慢，热点循环注意写法。
4. **稀疏向量别存成 dense 再算**：TF-IDF/one-hot 高维稀疏场景用稀疏点积（CSR + BLAS），否则 \(O(d)\) 里九成时间在乘零；Faiss 的 IVF/HNSW 索引都要求先按所选度量归一化。
5. **余弦对零向量返回 1**：某些实现写 `dot/(nx*ny)` 时忘除模长平方根（`nx` 是平方和）或漏判零，新向量恰为零向量（空文本的 embedding 常如此）时输出 `inf/nan` 毒化下游。
6. **闵可夫斯基参数 `p` 调参是玄学**：`scikit-learn` 的 `NearestNeighbors(p=1.5)` 没有标准答案——对比 1/2/∞ 三档做交叉验证，别在单个 `p` 上过度优化。

# 总结

四种度量是一条光谱：闵可夫斯基 \(L_p\) 统一了「坐标差如何聚合」（\(p\) 越大越看重最大单项差，\(L_\infty\) 只看最大值），余弦则干脆放弃「差」的概念改问「方向是否一致」。经验法则：**稠密、量纲一致、可解释数值 → \(L_2\)；稀疏计数、高维、对离群敏感 → \(L_1\)；文本 embedding 与词频画像 → 余弦；带协方差结构的多变量比对 → 马氏**。它们服务同一目标：为 KNN、聚类、检索选一把合适的尺子——下游算法见 [030.监督学习算法](./030.监督学习算法.md) 与 [070.聚类算法](./070.聚类算法.md)。
