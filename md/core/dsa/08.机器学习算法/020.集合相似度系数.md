# 概述

当对象被表示为**集合**（词袋、字符 n-gram、标签、特征子集）时，相似度不再是向量坐标的运算，而是交并关系的计数。本篇四个系数从不同角度裁剪「交集占了多少」：**Jaccard**（交集/并集，去重集合的黄金标准）、**Dice**（交集的两倍除以规模之和，对大小失衡更宽容）、**Overlap**（交集除以较小集合，专治「子串包含」）、**Simple Matching**（二元向量逐位匹配，唯一把「共同缺失」也计分的成员）。

**本篇收录**：**Jaccard 系数**、**Dice 系数**、**Overlap 系数**、**Simple Matching Coefficient（SMC）**

- 所属章节：[000.机器学习算法概述](./000.机器学习算法概述.md)
- 时间复杂度：单对集合 \(O(|A| + |B|)\)（哈希求交）；排序数组表示可 \(O(|A| \log |A| + |B| \log |B|)\) 预处理后线性合并
- 空间复杂度：\(O(\min(|A|, |B|))\)（对小集合建哈希表）
- 应用场景：近重复文档检测（shingle 化后算 Jaccard，大规模用 MinHash + 布隆过滤器加速，见 [10.应用与专题/060.布隆过滤器](../10.应用与专题/060.布隆过滤器.md)）、抄袭检测、实体对齐与拼写纠正、推荐系统的标签重合度；字符串序列层面的相似度见 [06.字符串与数论/030.字符串相似度与编辑距离](../06.字符串与数论/030.字符串相似度与编辑距离.md) 与 [06.字符串与数论/040.字符串近似匹配与语音相似度](../06.字符串与数论/040.字符串近似匹配与语音相似度.md)（二者互补：编辑距离保序，本篇系数不看顺序）
- 前置：哈希表与集合操作（[01.基础数据结构/090.哈希表应用](../01.基础数据结构/090.哈希表应用.md)）

**动画：韦恩图上的四种切法** <!-- dsa.assets/set-metrics/venn-four.gif -->

取 \(A = \{1,2,3,4\}\)、\(B = \{3,4,5,6\}\)（交集 \(\{3,4\}\)，并集 6 个元素）：

1. **Jaccard**：交集面积 / 并集面积 \(= 2/6 = 0.333\)——分母是「出现过的全部」，对规模变化敏感。
2. **Dice**：\(2 \times 2 / (4 + 4) = 0.5\)——分母是规模之和（交集被数了两次），同一数据下 Dice 恒 ≥ Jaccard。
3. **Overlap**：\(2 / \min(4,4) = 0.5\)——若把 \(B\) 扩成 \(\{1,2,3,4,5,6\}\)，Jaccard 跌到 \(4/6 \approx 0.667\)、Dice 跌到 \(8/10 = 0.8\)，而 Overlap 仍为 \(4/4 = 1.0\)：「A 是 B 的子集」这一事实在 Overlap 里满分——包含关系检测专用。
4. **SMC**：把论域扩到 8 个元素、\(A = \{1..4\}\)、\(B = \{3..6\}\)，二元向量逐位比较：共同存在 2 位、共同缺失 2 位（第 7、8 维）、单侧 4 位，\(SMC = (2+2)/8 = 0.5\)——**唯一给「共同没有」发分**的系数。

**动画：shingle 化的两句话** <!-- dsa.assets/set-metrics/shingle.gif -->

1. 句子 1「数据结构与算法」→ 3-gram 集合 {数据结构, 据结构, 结构与, 与算法}。
2. 句子 2「数据结构和算法」→ {数据结构和, 据结构和, 结构和算, 结构与算…}（集合完全不同！）。
3. 换成 2-gram 后交集变大，Jaccard 从 0 回升——**n-gram 粒度是集合相似度的第一调节旋钮**。

# 详解

## 定义与相互关系

\[
J = \frac{|A \cap B|}{|A \cup B|}, \quad
D = \frac{2|A \cap B|}{|A| + |B|}, \quad
O = \frac{|A \cap B|}{\min(|A|, |B|)}, \quad
SMC = \frac{a + d}{a + b + c + d}
\]

其中 \(a\) 为共同存在数、\(b/c\) 为只在 \(A\)/只在 \(B\) 数、\(d\) 为共同缺失数（SMC 按二元向量论域展开）。三个经典关系：

1. \(D = \dfrac{2J}{1 + J}\)——单调互推，Top-K 排序通常同序（对 \(J\) 的阈值可换算成 \(D\) 的阈值）。
2. \(O \ge D \ge J\)（一般情形）——从「宽容」到「严格」的排序几乎恒定。
3. SMC 与稀疏性相克：百万维 one-hot 特征里 \(d\) 高达 \(10^6\)，两个毫不相关的对象 SMC 也接近 1——**稀疏场景必须弃用 SMC**（这正是 Jaccard/Dice 无视 \(d\) 的原因）。

## 代码：一次遍历算全四个系数

实现思路：把较小集合哈希化，遍历较大集合同时统计 \(a, b, c, d\)（按并集论域）。Jaccard/Dice/Overlap 只需 \(a, |A|, |B|\)（\(b = |A| - a,\ c = |B| - a\)，\(d\) 需论域大小——SMC 单独传入 universe 尺寸）。

```java [Java]
public record Coefficients(double jaccard, double dice, double overlap, double smc) {}

/** universeSize：论域元素总数（如二元向量维度），用于 SMC 的共同缺失计数 */
public static Coefficients compare(Set<Integer> a, Set<Integer> b, int universeSize) {
    int inter = 0;
    Set<Integer> small = a.size() <= b.size() ? a : b;
    Set<Integer> large = small == a ? b : a;
    for (int x : large) if (small.contains(x)) inter++;
    int union = a.size() + b.size() - inter;
    double j = union == 0 ? 1.0 : (double) inter / union;   // 双空集约定：完全相似
    double d = (a.size() + b.size() == 0) ? 1.0
            : 2.0 * inter / (a.size() + b.size());
    double o = Math.min(a.size(), b.size()) == 0 ? 1.0
            : (double) inter / Math.min(a.size(), b.size());
    int bothAbsent = universeSize - union;
    double smc = universeSize == 0 ? 1.0 : (double) (inter + bothAbsent) / universeSize;
    return new Coefficients(j, d, o, smc);
}

public static void main(String[] args) {
    Set<Integer> a = Set.of(1, 2, 3, 4);
    Set<Integer> b = Set.of(3, 4, 5, 6);
    System.out.println(compare(a, b, 8));   // J=0.333, D=0.5, O=0.5, SMC=0.5
}
```

```rust [Rust]
use std::collections::HashSet;

#[derive(Debug)]
pub struct Coefficients {
    pub jaccard: f64,
    pub dice: f64,
    pub overlap: f64,
    pub smc: f64,
}

pub fn compare(a: &HashSet<i32>, b: &HashSet<i32>, universe_size: usize) -> Coefficients {
    let inter = a.iter().filter(|x| b.contains(x)).count();
    let union = a.len() + b.len() - inter;
    let jaccard = if union == 0 { 1.0 } else { inter as f64 / union as f64 };
    let dice = if a.len() + b.len() == 0 {
        1.0
    } else {
        2.0 * inter as f64 / (a.len() + b.len()) as f64
    };
    let overlap = if a.len().min(b.len()) == 0 {
        1.0
    } else {
        inter as f64 / a.len().min(b.len()) as f64
    };
    let both_absent = universe_size.saturating_sub(union);
    let smc = if universe_size == 0 {
        1.0
    } else {
        (inter + both_absent) as f64 / universe_size as f64
    };
    Coefficients { jaccard, dice, overlap, smc }
}
```

```typescript [TypeScript]
  jaccard: number; dice: number; overlap: number; smc: number;

function compare(a: Set<number>, b: Set<number>, universeSize: number): Coefficients {
  const [small, large] = a.size <= b.size ? [a, b] : [b, a];
  let inter = 0;
  for (const x of large) if (small.has(x)) inter++;
  const union = a.size + b.size - inter;
  const jaccard = union === 0 ? 1 : inter / union;
  const dice = a.size + b.size === 0 ? 1 : (2 * inter) / (a.size + b.size);
  const overlap = Math.min(a.size, b.size) === 0 ? 1
    : inter / Math.min(a.size, b.size);
  const bothAbsent = Math.max(0, universeSize - union);
  const smc = universeSize === 0 ? 1 : (inter + bothAbsent) / universeSize;
  return { jaccard, dice, overlap, smc };
}
```

```python [Python]
def compare(a, b, universe_size):
    """a, b 为 set；返回四个系数字典"""
    inter = len(a & b)
    union = len(a | b)
    jaccard = 1.0 if union == 0 else inter / union
    dice = 1.0 if len(a) + len(b) == 0 else 2 * inter / (len(a) + len(b))
    smaller = min(len(a), len(b))
    overlap = 1.0 if smaller == 0 else inter / smaller
    both_absent = max(0, universe_size - union)
    smc = 1.0 if universe_size == 0 else (inter + both_absent) / universe_size
    return {"jaccard": jaccard, "dice": dice, "overlap": overlap, "smc": smc}
```

## 规模化：MinHash 一瞥

百万级文档两两算 Jaccard 是 \(O(n^2)\) 场灾难。MinHash 的关键性质：**一个随机哈希函数下，两文档最小哈希值相等的概率恰等于其 Jaccard 相似度**——于是用 \(k\) 个哈希函数（或一份 + \(k\) 次置换）压缩成签名向量，比较签名匹配率即可估 Jaccard，误差 \(O(1/\sqrt{k})\)。再叠加 LSH 分桶（签名切段、段同则候选）把候选对数进一步砍掉。Dice/Overlap 无此性质，**MinHash 只服务 Jaccard**——选型时就要把度量钉死。工程加速的另一半见 [10.应用与专题/060.布隆过滤器](../10.应用与专题/060.布隆过滤器.md)。

## 常见陷阱

1. **多集（bag）当集合用**：「abracadabra」与「abracadabra」集合相同 J=1.0，但字符**计数**不同——文本去重场景 shingle 天然去重没问题；词频敏感场景要用 bag-Dice（\(\sum \min(c_A, c_B)\) 形式）而非 set 版本。
2. **空集约定不统一**：双空集 Jaccard 按惯例定为 1（都无特征=一致）还是 0（无信息）？库与库行为不同（`scipy` 返回 `nan`，`sklearn` 有专门约定）——业务代码里显式处理，别赌默认值。
3. **SMC 在稀疏二元向量上虚高**：前面算过 0 维特征也能贡献 99% 的 SMC——布尔特征关联分析请用 Jaccard 或专门剔除 \(d\) 的系数（如 \(\phi\) 系数），这是市场篮分析里的经典翻车点。
4. **n-gram 粒度凭感觉**：2-gram 对拼写变体宽容（相似虚高）、5-gram 对近重复苛刻（相似虚低）；抄袭检测按「改动容忍度」反推粒度，必要时多粒度取 max。
5. **论域大小拍脑袋**：SMC 的 \(d\) 依赖 universe 定义——用「两集合元素之并」当论域时 SMC 退化为 Jaccard！本篇代码显式传 `universeSize`，就是把口径交给调用方钉死。
6. **把 Overlap 当通用相似度**：它对「短文本是长文本子集」给满分——垃圾邮件模板检测很合适，但做去重会把「完全包含关系」误判为近重复；去重仍回 Jaccard/Dice。

# 总结

四个系数是「交集怎么归一化」的四种答案：除以并（Jaccard，规模化友好、可 MinHash）、除以规模均值（Dice，对失衡宽容）、除以较小规模（Overlap，包含关系满分）、除以论域（SMC，计入共同缺失，仅适合稠密二元向量）。选集合度量的三问：**数据是集合还是多集？规模差悬殊吗？需要上 MinHash 提速吗？**——三问定下 Jaccard/Dice/Overlap；再问一句「共同缺失有意义吗」决定 SMC 的存废。向量视角的同族度量见 [010.向量距离与相似度度量](./010.向量距离与相似度度量.md)。
