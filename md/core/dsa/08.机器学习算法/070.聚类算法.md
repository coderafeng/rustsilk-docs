# 概述

聚类是「无监督分组」：没有标签，只凭样本间的距离或密度，把数据切成若干内部相似、彼此相异的组。两大流派代表两条完全不同的假设——**K-means** 假设簇是凸的、大小相近的球状区域，用「迭代指派 + 质心更新」把样本揽入 \(k\) 个圆心；**DBSCAN** 假设簇是「密得连成片」的区域，用 \(\varepsilon\)-邻域把足够稠密的点串联起来，顺带天然识别噪声点。K-means 画不出月牙形，DBSCAN 调不好 \(\varepsilon\) 就碎成一地——选流派比调参数更重要。距离度量本身见 [010.向量距离与相似度度量](./010.向量距离与相似度度量.md)。

**本篇收录**：**K-means（Lloyd 迭代）**、**DBSCAN（密度聚类）**

- 所属章节：[000.机器学习算法概述](./000.机器学习算法概述.md)
- 时间复杂度：K-means 每轮 \(O(nkd)\)、迭代 \(t\) 轮共 \(O(nkdt)\)，工程上远小于最坏界；DBSCAN 朴素邻域查询 \(O(n^2 d)\)，用 R 树/KD 树索引可降至 \(O(n \log n \cdot d)\)
- 空间复杂度：K-means \(O(nd + kd)\)；DBSCAN \(O(nd)\)（邻接展开栈最深 \(O(n)\)）
- 应用场景：K-means——图像颜色量化、用户分群、作为 GMM/向量检索（IVF 索引）的前置粗聚类；DBSCAN——轨迹热点发现、异常检测、点云前景分割

**动画 2：DBSCAN 的三种点（\(\varepsilon=0.5, minPts=3\)）**

1. 点 \(p\) 的 \(\varepsilon\)-邻域内含自身共 5 个点 \(\geq minPts\) → \(p\) 标为**核心点**，开一个新簇。
2. 邻域内的点 \(q\)（邻域只有 2 个点）尚未归属 → 作为**边界点**并入该簇；\(q\) 不再向外扩张。
3. 孤立点 \(s\) 邻域仅 1 点、且不在任何核心点邻域内 → 标为**噪声**。
4. 两团密集区被一条稀疏「细颈」（间距 \(>\varepsilon\)）隔开 → 被切成两个簇——这正是 K-means 做不到、而 K-means 擅长的「两大球」在此同样轻松。

# 详解

## K-means：目标函数与两步交替

K-means 优化的是**惯性**（簇内平方距离和）：

\[
J(c, \mu) = \sum_{i=1}^{n} \lVert x_i - \mu_{c_i} \rVert^2
\]

对固定的指派 \(c\)，最优 \(\mu_k\) 是簇内均值（对 \(\mu\) 求导置零即得）；对固定的质心 \(\mu\)，最优指派是把每个点分给最近质心。因此**两步交替都保证 \(J\) 单调不增**，且指派组合有限 → 必收敛——但只收敛到**局部**极小，结果强烈依赖初始质心。这就是 Lloyd 算法，简单到 20 行，却也「简单到容易被误用」。

初始化用 **K-means++**：第一个质心均匀随机，之后每选一个质心，以「与已选质心集最短距离的平方」为权重加权采样——让初始质心彼此远离，期望能把 \(J\) 的保证从「任意差」提升到 \(O(\log k)\) 近似。

```java [Java]
public static double[][] kMeans(double[][] pts, double[][] centroids, int maxIter) {
    int k = centroids.length, d = pts[0].length;
    double[][] cent = copy(centroids);
    for (int iter = 0; iter < maxIter; iter++) {
        double[] sum = new double[k * d];
        int[] cnt = new int[k];
        for (double[] p : pts) {                       // E 步：指派给最近质心
            int best = 0; double bestD = Double.MAX_VALUE;
            for (int j = 0; j < k; j++) {
                double dd = 0;
                for (int t = 0; t < d; t++) dd += sq(p[t] - cent[j][t]);
                if (dd < bestD) { bestD = dd; best = j; }
            }
            for (int t = 0; t < d; t++) sum[best * d + t] += p[t];
            cnt[best]++;
        }
        boolean moved = false;
        for (int j = 0; j < k; j++) {                  // M 步：质心 = 簇均值
            if (cnt[j] == 0) continue;                 // 空簇：保留旧质心
            for (int t = 0; t < d; t++) {
                double v = sum[j * d + t] / cnt[j];
                if (Math.abs(v - cent[j][t]) > 1e-12) moved = true;
                cent[j][t] = v;
            }
        }
        if (!moved) break;                             // 收敛
    }
    return cent;
}
static double sq(double v) { return v * v; }
static double dist(double[] a, double[] b) {
    double s = 0;
    for (int t = 0; t < a.length; t++) s += sq(a[t] - b[t]);
    return Math.sqrt(s);
}
static double[][] copy(double[][] a) {
    return a.stream().map(double[]::clone).toArray(double[][]::new);
}
// 图解例：pts={{0,1},{1,0},{1,1},{3,4},{4,3},{4,4}}, init={{0,0},{3,3}}
// → {{0.667,0.667},{3.667,3.667}}
```

```rust [Rust]
pub fn k_means(pts: &[Vec<f64>], centroids: &[Vec<f64>], max_iter: usize) -> Vec<Vec<f64>> {
    let k = centroids.len();
    let d = pts[0].len();
    let mut cent = centroids.to_vec();
    for _ in 0..max_iter {
        let mut sum = vec![vec![0.0; d]; k];
        let mut cnt = vec![0usize; k];
        for p in pts {                                  // E 步：最近质心
            let mut best = 0;
            let mut best_d = f64::INFINITY;
            for (j, c) in cent.iter().enumerate() {
                let dd: f64 = p.iter().zip(c).map(|(a, b)| (a - b) * (a - b)).sum();
                if dd < best_d { best_d = dd; best = j; }
            }
            for t in 0..d { sum[best][t] += p[t]; }
            cnt[best] += 1;
        }
        let mut moved = false;
        for j in 0..k {                                 // M 步：均值更新
            if cnt[j] == 0 { continue; }
            for t in 0..d {
                let v = sum[j][t] / cnt[j] as f64;
                if (v - cent[j][t]).abs() > 1e-12 { moved = true; }
                cent[j][t] = v;
            }
        }
        if !moved { break; }
    }
    cent
}
```

```typescript [TypeScript]
  const k = centroids.length, d = pts[0].length;
  const cent = centroids.map(r => [...r]);
  for (let iter = 0; iter < maxIter; iter++) {
    const sum = Array.from({ length: k }, () => new Array(d).fill(0));

        let dd = 0;
        for (let t = 0; t < d; t++) dd += (p[t] - cent[j][t]) ** 2;
        if (dd < bestD) { bestD = dd; best = j; }

        const v = sum[j][t] / cnt[j];

        cent[j][t] = v;
      }
    }

  }
  return cent;
```

```python [Python]
def k_means(pts, centroids, max_iter=100):
    k, d = len(centroids), len(pts[0])
    cent = [row[:] for row in centroids]
    for _ in range(max_iter):
        sum_ = [[0.0] * d for _ in range(k)]
        cnt = [0] * k
        for p in pts:                                   # E 步：最近质心
            best = min(range(k), key=lambda j: sum((a - b) ** 2 for a, b in zip(p, cent[j])))
            for t in range(d):
                sum_[best][t] += p[t]
            cnt[best] += 1
        moved = False
        for j in range(k):                              # M 步：均值更新
            if cnt[j] == 0:
                continue
            for t in range(d):
                v = sum_[j][t] / cnt[j]
                if abs(v - cent[j][t]) > 1e-12:
                    moved = True
                cent[j][t] = v
        if not moved:
            break
    return cent
```

## DBSCAN：密度可达的连通分量

DBSCAN 只依赖一个操作——\(\varepsilon\)-邻域查询 \(N_\varepsilon(p) = \{q : d(p,q) \le \varepsilon\}\)，然后按三种点分类：

- **核心点**：\(|N_\varepsilon(p)| \ge minPts\)，自己「密得起来」；
- **边界点**：本身不是核心点，但落在某个核心点的邻域内，可以「被拖着入伙」；
- **噪声点**：既非核心也非边界，孤零零。

簇定义为：**至少含一个核心点，且对「密度可达」封闭的最大点集**。直观上就是沿着「核心点手拉手」做连通分量，边界点挂在触及它的核心点所在的簇上。

```java [Java]
public static int[] dbscan(double[][] pts, double eps, int minPts) {
    int n = pts.length;
    int[] label = new int[n];
    Arrays.fill(label, -2);                             // -2 = 未访问
    int cid = 0;
    for (int i = 0; i < n; i++) {
        if (label[i] != -2) continue;
        List<Integer> nbrs = regionQuery(pts, i, eps);
        if (nbrs.size() < minPts) { label[i] = -1; continue; }   // 噪声（暂）
        expandCluster(pts, nbrs, label, i, cid++, eps, minPts);
    }
    return label;                                       // -1 噪声，>=0 簇号
}

static List<Integer> regionQuery(double[][] pts, int i, double eps) {
    List<Integer> out = new ArrayList<>();
    for (int j = 0; j < pts.length; j++)
        if (dist(pts[i], pts[j]) <= eps) out.add(j);
    return out;
}

static void expandCluster(double[][] pts, List<Integer> nbrs, int[] label,
                          int i, int cid, double eps, int minPts) {
    label[i] = cid;
    for (int idx = 0; idx < nbrs.size(); idx++) {       // 队列式广度扩张
        int j = nbrs.get(idx);
        if (label[j] == -2) {                            // 未访问才处理
            label[j] = cid;                              // 核心/边界都入簇
            List<Integer> jn = regionQuery(pts, j, eps);
            if (jn.size() >= minPts) nbrs.addAll(jn);    // 核心点 → 继续扩张
        } else if (label[j] == -1) {                     // 先前判的噪声被翻案
            label[j] = cid;                              // 补入当前簇
        }
    }
}
```

```rust [Rust]
pub fn dbscan(pts: &[Vec<f64>], eps: f64, min_pts: usize) -> Vec<i32> {
    let n = pts.len();
    let mut label = vec![-2i32; n];                     // -2 未访问
    let mut cid = 0i32;
    for i in 0..n {
        if label[i] != -2 { continue; }
        let nbrs = region_query(pts, i, eps);
        if nbrs.len() < min_pts { label[i] = -1; continue; }
        expand(pts, nbrs, &mut label, i, cid, eps, min_pts);
        cid += 1;
    }
    label
}

fn dist(a: &[f64], b: &[f64]) -> f64 {
    a.iter().zip(b).map(|(x, y)| (x - y) * (x - y)).sum::<f64>().sqrt()
}

fn region_query(pts: &[Vec<f64>], i: usize, eps: f64) -> Vec<usize> {
    (0..pts.len()).filter(|&j| dist(&pts[i], &pts[j]) <= eps).collect()
}

fn expand(pts: &[Vec<f64>], mut nbrs: Vec<usize>, label: &mut [i32],
          i: usize, cid: i32, eps: f64, min_pts: usize) {
    label[i] = cid;
    let mut idx = 0;
    while idx < nbrs.len() {
        let j = nbrs[idx];
        if label[j] == -2 {
            label[j] = cid;
            let jn = region_query(pts, j, eps);
            if jn.len() >= min_pts { nbrs.extend(jn); } // 核心点继续扩张
        } else if label[j] == -1 {
            label[j] = cid;                              // 噪声翻案入簇
        }
        idx += 1;
    }
}
```

```typescript [TypeScript]
function dbscan(pts: number[][], eps: number, minPts: number): number[] {
  const n = pts.length;
  const label = new Array(n).fill(-2);
  const dist = (i: number, j: number) =>
    Math.hypot(...pts[i].map((v, t) => v - pts[j][t]));
  const region = (i: number) =>
    pts.map((_, j) => j).filter(j => dist(i, j) <= eps);
  let cid = 0;
  for (let i = 0; i < n; i++) {
    if (label[i] !== -2) continue;
    const nbrs = region(i);
    if (nbrs.length < minPts) { label[i] = -1; continue; }
    label[i] = cid;
    const queue = [...nbrs];
    for (let h = 0; h < queue.length; h++) {             // 广度扩张
      const j = queue[h];
      if (label[j] === -2) {
        label[j] = cid;
        const jn = region(j);
        if (jn.length >= minPts) queue.push(...jn);
      } else if (label[j] === -1) {
        label[j] = cid;
      }
    }
    cid++;
  }
  return label;
}
```

```python [Python]
def dbscan(pts, eps, min_pts):
    n = len(pts)
    label = [-2] * n                                    # -2 未访问
    def dist(i, j):
        return math.sqrt(sum((a - b) ** 2 for a, b in zip(pts[i], pts[j])))
    def region(i):
        return [j for j in range(n) if dist(i, j) <= eps]

    cid = 0
    for i in range(n):
        if label[i] != -2:
            continue
        nbrs = region(i)
        if len(nbrs) < min_pts:
            label[i] = -1
            continue
        label[i] = cid
        queue = list(nbrs)
        h = 0
        while h < len(queue):                             # 广度扩张
            j = queue[h]
            if label[j] == -2:
                label[j] = cid
                jn = region(j)
                if len(jn) >= min_pts:
                    queue.extend(jn)
            elif label[j] == -1:
                label[j] = cid
            h += 1
        cid += 1
    return label
```

## 常见陷阱

::: danger 陷阱清单
1. **K-means 的 \(k\) 要外部指定**：肘部法则（SSE 对 \(k\) 作图找拐点）与轮廓系数是两条常用经验曲线，但都只是「建议」；跑多个 \(k\) 分别看业务解释力更实际。
2. **K-means 对量纲敏感**：一个「收入（万级）」特征会碾压一个「年龄（十级）」特征——聚类前必须标准化（与 [07.数值计算/040.主成分分析PCA](../07.数值计算/040.主成分分析PCA.md) 的「先中心化/标准化」同理）。
3. **K-means 只会画圆**：非凸簇（月牙、同心环）、尺度悬殊的簇都会切错——这种数据请交给 DBSCAN 或谱聚类。
4. **空簇与局部最优**：随机初始化可能让某质心永远抢不到点；工程实现要么 K-means++ 初始化，要么重跑多个随机种子取 \(J\) 最小。
5. **DBSCAN 的边界点归属不唯一**：一个边界点同时落在两个核心点邻域内时，归哪个簇取决于**遍历顺序**——不同实现/不同顺序给出不同但同样合法的划分，别把边界簇号当稳定结论。
6. **噪声可以被「翻案」**：上面代码里 `label[j] == -1` 分支——先被判噪声的点后来进入某核心点邻域时应补入簇；写成「噪声永久」的实现会少分一批点。
7. **高维下 \(\varepsilon\) 几乎不可调**：维度升高后所有点对距离趋同（距离集中现象），DBSCAN 的密度语义失效；先用 PCA 降维再聚是常用救法。
8. **顺序依赖的假象**：K-means 与 DBSCAN 都有「过程随顺序/种子变」的一面——报告结论时固定种子并复跑验证，是聚类实验的基本素养。
:::

::: info 选流派速查
| 问题形态 | 首选 |
|---------|------|
| 簇呈球状、\(k\) 已知、数据量大 | K-means（+K-means++） |

| 要层次关系（先大组后细分） | 层次聚类（Agglomerative） |
:::

# 总结

- **K-means** 是最小化惯性的两步交替：指派 → 取均值，必收敛但只到局部最优；配 K-means++ 初始化、标准化特征、多随机种子重跑，是它的「工程三件套」。
- **DBSCAN** 用 \(\varepsilon\)-邻域与 \(minPts\) 把「密度可达」连成簇：自动定簇数、识别噪声、容忍任意形状，代价是参数对高维数据敏感、边界点归属依赖遍历顺序。
- 两者的分野是**假设**而非优劣：凸球状簇交给圆心模型，连绵稠密区交给密度模型；先画个二维散点（可用 [080.降维与可视化](./080.降维与可视化.md)）再选流派，胜过对着指标盲调。
- 软分配版本（GMM + EM）见 [060.期望最大化EM算法](./060.期望最大化EM算法.md)——当簇边界本该模糊时，硬指派让位于责任度。
