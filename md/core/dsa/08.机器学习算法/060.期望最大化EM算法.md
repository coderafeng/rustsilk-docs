# 概述

当数据里藏着「看不见的标签」——混合分布的类别归属、缺失值、词的主题——直接极大似然变成「对数里面有求和、求和下面有对数」的死结。EM（Expectation-Maximization）把联合对数似然拆成两步交替：**E 步**用当前参数估计隐变量的后验期望（软分配责任度），**M 步**在固定责任度下做加权极大似然更新参数。每轮交替保证似然单调不减（Jensen 不等式构造的下bound被抬高），收敛到局部极大——这是含隐变量概率模型的通用优化范式，也是 K-means 的「软化」上位。

- 所属章节：[000.机器学习算法概述](./000.机器学习算法概述.md)
- 时间复杂度：每轮 \(O(nKd)\)（\(n\) 样本、\(K\) 组件、\(d\) 维度）；轮数经验上 10～100，总 \(O(iter \cdot nKd)\)
- 空间复杂度：\(O(nK)\) 责任矩阵（可流式逐样本累加降至 \(O(Kd)\)）
- 应用场景：GMM 聚类与语音识别 HMM 训练（MFCC-GMM 声学时代）、缺失数据插补、推荐主题模型 LDA（变分 EM）、生物信息（序列 motif 的 Baum-Welch）、半监督学习；作为「交替优化」家族一员，与 [040.决策树与集成学习](./040.决策树与集成学习.md) 的前向分框、[07.数值计算/030.数值优化方法](../07.数值计算/030.数值优化方法.md) 的坐标下降共享方法论
- 前置：条件概率与贝叶斯后验；极大似然直觉（[030.监督学习算法](./030.监督学习算法.md) 的逻辑回归）

**动画：1D 两组件 GMM 的 EM 三轮迭代** <!-- dsa.assets/em/em-gmm-mixing.gif -->

数据 \(x = \{1, 2, 3, 8, 9, 10\}\)，初始 \(\mu = (2.5, 8.5)、\sigma = (1, 1)、\pi = (0.5, 0.5)\)：

1. **E 步**：算每个点属于组件 1 的后验 \(r_i = \frac{\pi_1 N(x_i \mid \mu_1, \sigma_1)}{\pi_1 N(x_i \mid \mu_1, \sigma_1) + \pi_2 N(x_i \mid \mu_2, \sigma_2)}\)——初始切点在 5.5 附近，左簇 \(r \approx 1\)、右簇 \(r \approx 0\)，颜色按责任度渐变。
2. **M 步**：加权均值 \(\mu_1 = \frac{\sum r_i x_i}{\sum r_i}\)、加权方差、\(\pi_1 = \frac{1}{n}\sum r_i\)——两条高斯曲线各自「吸」向所属点群，对数似然计数条上涨。
3. **第 2 轮 E 步**：切点移向簇间隙 \((3+8)/2 = 5.5\)（已稳定），责任度更尖锐；\(\mu \to (2.0, 9.0)\)，\(\sigma^2 \to (2/3, 2/3)\)。
4. 第 3 轮曲线几乎不动——**似然增量 < 阈值，收敛**。
5. 彩蛋镜头：把初始 \(\mu\) 换到同侧 \((1.5, 2.5)\)，两轮后两个组件纠缠在左簇、右簇无人认领——**局部最优**警告动画。

**动画：硬币故事（隐变量是什么）** <!-- dsa.assets/em/em-coins.gif -->

1. 两枚硬币 A/B，每次随机挑一枚抛 10 次，只记录「正面数」、**不记录用了哪枚**——「哪枚硬币」就是隐变量 \(z\)。
2. E 步：猜「这组 8 正来自 A 的程度」；M 步：按猜的比例分别重估 A、B 的正面率。
3. 交替直到两枚硬币的参数不再变化——Dempster-1977 原教旨案例。

# 详解

## 为什么 EM 保证单调

含隐变量 \(z\) 的完全数据对数似然 \(\ell(\theta) = \sum_i \log \sum_{z_i} p(x_i, z_i \mid \theta)\)。对任意「分布 \(q_i(z)\)」做 Jensen 分解（取 \(q_i\) 为当前后验时取等）：

\[
\ell(\theta) = \underbrace{\sum_i \sum_z q_i(z) \log \frac{p(x_i, z \mid \theta)}{q_i(z))}}_{\mathcal{L}(\theta, q) \text{（下界）}} + \underbrace{\sum_i KL(q_i \,\|\, p(\cdot \mid x_i, \theta))}_{\ge 0}
\]

E 步固定 \(\theta^{old}\)、令 \(q_i = p(z \mid x_i, \theta^{old})\)，KL 项归零、下界贴紧当前似然；M 步固定 \(q\) 抬高下界 \(\Rightarrow\) 真实似然不减。归纳到收敛点即（局部）极大。单峰高斯的「责任度」永远在 0/1 之间摆动直到参数就位——EM 的哲学是**先用猜的标签学好参数，再用好的参数学准标签**。

## GMM 的 EM 更新公式

对高斯混合 \(p(x) = \sum_{k=1}^K \pi_k \mathcal{N}(x \mid \mu_k, \Sigma_k)\)：

\[
r_{ik} = \frac{\pi_k \mathcal{N}(x_i \mid \mu_k, \Sigma_k)}{\sum_j \pi_j \mathcal{N}(x_i \mid \mu_j, \Sigma_j)}, \quad
\mu_k = \frac{\sum_i r_{ik} x_i}{\sum_i r_{ik}}, \quad
\Sigma_k = \frac{\sum_i r_{ik} (x_i - \mu_k)(x_i - \mu_k)^T}{\sum_i r_{ik}}, \quad
\pi_k = \frac{\sum_i r_{ik}}{n}
\]

**K-means 是硬分配特例**：\(r_{ik} \in \{0, 1\}\)（只认最近中心）+ 球面协方差 + 等权重——EM 给出「每个点以多大程度属于每个簇」的柔性版本，能拟合非球状、重叠簇。

```java [Java]
public static double[][] gmmEm1d(double[] data, double[] mu, double[] sigma,
                                 double[] pi, int iters) {
    int n = data.length, k = mu.length;
    for (int it = 0; it < iters; it++) {
        // E 步：责任度 r[i][j]
        double[][] r = new double[n][k];
        for (int i = 0; i < n; i++) {
            double sum = 0;
            for (int j = 0; j < k; j++) {
                double d = data[i] - mu[j];
                r[i][j] = pi[j] * Math.exp(-d * d / (2 * sigma[j] * sigma[j])) / sigma[j];
                sum += r[i][j];
            }
            for (int j = 0; j < k; j++) r[i][j] /= sum;
        }
        // M 步：加权更新
        for (int j = 0; j < k; j++) {
            double rk = 0, mx = 0;
            for (int i = 0; i < n; i++) { rk += r[i][j]; mx += r[i][j] * data[i]; }
            mu[j] = mx / rk;
            double v = 0;
            for (int i = 0; i < n; i++) {
                double d = data[i] - mu[j];
                v += r[i][j] * d * d;
            }
            sigma[j] = Math.sqrt(v / rk);
            pi[j] = rk / n;
        }
    }
    return new double[][]{mu, sigma, pi};
}
// 图解例：gmmEm1d(new double[]{1,2,3,8,9,10}, new double[]{2.5,8.5},
//                new double[]{1,1}, new double[]{0.5,0.5}, 10)
// → mu≈(2.0,9.0), sigma≈(0.816,0.816), pi≈(0.5,0.5)
```

```rust [Rust]
pub fn gmm_em_1d(data: &[f64], mu: &mut [f64], sigma: &mut [f64], pi: &mut [f64],
                 iters: usize) {
    let n = data.len();
    let k = mu.len();
    for _ in 0..iters {
        // E 步
        let mut r = vec![vec![0.0f64; k]; n];
        for i in 0..n {
            let mut sum = 0.0;
            for j in 0..k {
                let d = data[i] - mu[j];
                r[i][j] = pi[j] * (-d * d / (2.0 * sigma[j] * sigma[j])).exp() / sigma[j];
                sum += r[i][j];
            }
            for j in 0..k {
                r[i][j] /= sum;
            }
        }
        // M 步
        for j in 0..k {
            let rk: f64 = (0..n).map(|i| r[i][j]).sum();
            mu[j] = (0..n).map(|i| r[i][j] * data[i]).sum::<f64>() / rk;
            let v: f64 = (0..n).map(|i| r[i][j] * (data[i] - mu[j]) * (data[i] - mu[j])).sum();
            sigma[j] = (v / rk).sqrt();
            pi[j] = rk / n as f64;
        }
    }
}
```

```typescript [TypeScript]
function gmmEm1d(data: number[], mu: number[], sigma: number[], pi: number[],
                 iters: number): { mu: number[]; sigma: number[]; pi: number[] } {
  const n = data.length, k = mu.length;
  for (let it = 0; it < iters; it++) {
    const r = data.map(x => {
      const raw = mu.map((m, j) =>
        pi[j] * Math.exp(-(x - m) ** 2 / (2 * sigma[j] ** 2)) / sigma[j]);
      const sum = raw.reduce((a, b) => a + b, 0);
      return raw.map(v => v / sum);
    });
    for (let j = 0; j < k; j++) {
      const rk = r.reduce((s, ri) => s + ri[j], 0);
      mu[j] = r.reduce((s, ri, i) => s + ri[j] * data[i], 0) / rk;
      const v = r.reduce((s, ri, i) => s + ri[j] * (data[i] - mu[j]) ** 2, 0);
      sigma[j] = Math.sqrt(v / rk);
      pi[j] = rk / n;
    }
  }
  return { mu, sigma, pi };
}
```

```python [Python]
import math

def gmm_em_1d(data, mu, sigma, pi, iters=10):
    n, k = len(data), len(mu)
    mu, sigma, pi = list(mu), list(sigma), list(pi)
    for _ in range(iters):
        # E 步：后验责任度
        r = []
        for x in data:
            raw = [pi[j] * math.exp(-(x - mu[j]) ** 2 / (2 * sigma[j] ** 2)) / sigma[j]
                   for j in range(k)]
            s = sum(raw)
            r.append([v / s for v in raw])
        # M 步：加权更新
        for j in range(k):
            rk = sum(ri[j] for ri in r)
            mu[j] = sum(ri[j] * x for ri, x in zip(r, data)) / rk
            var = sum(ri[j] * (x - mu[j]) ** 2 for ri, x in zip(r, data)) / rk
            sigma[j] = math.sqrt(var)
            pi[j] = rk / n
    return mu, sigma, pi

# gmm_em_1d([1,2,3,8,9,10], [2.5,8.5], [1.0,1.0], [.5,.5], 10)
# → ([2.0, 9.0], [0.816…, 0.816…], [0.5, 0.5])
```

## 常见陷阱

1. **局部最优是常态**：EM 只保证爬到「最近的坑」；`sklearn` 默认 `n_init=1`，实战必须多初始化取似然最大——初始化用 [070.聚类算法](./070.聚类算法.md) 的 K-means++ 或分位数撒点。
2. **协方差奇异爆炸**：某组件中心恰好压在单个样本上时 \(\sigma \to 0\)、该点责任度 → 1、似然 → ∞，算法卡死在伪峰；给协方差加下限（`reg_covar=1e-6`）或约束对角/球面形态。
3. **组件数 K 没有免费答案**：似然对 K 单调递增，拿它选 K 必然选到最大；用 BIC/AIC 惩罚项，或看责任度矩阵的「实际占用组件数」。
4. **数值下溢**：\(d\) 维高斯密度连乘 \(e^{-\lVert x-\mu\rVert^2/2\sigma^2}\) 动辄 < \(10^{-300}\)；工程实现一律在 log 域算 + logsumexp 归一化责任度，本教学代码 1D 小数据侥幸没事。
5. **把收敛当全局**：似然曲线平了只说明到驻点——可能是鞍点/局部极大；关键业务对拍多种子、多 K，看解的稳定性而非单次收敛值。
6. **EM ≠ 万能隐变量**：真实后验 \(p(z \mid x, \theta)\) 算不动（如 LDA）时，要退到**变分 EM**——用可解的 \(q\) 族近似后验，牺牲下界紧度换可行性；概念上仍是「下界交替抬升」的兄弟。

# 总结

EM 把「不知道标签」的似然难题拆成「猜标签（E）→ 按标签估参（M）」的循环，Jensen 不等式为这个循环发放「似然不减」的通行证。GMM 是最干净的落地场景，硬币故事是最诚实的直觉教材，而 K-means（[070.聚类算法](./070.聚类算法.md)）就是它硬分配 + 球面约束的特例——学透 EM，聚类两兄弟和一半的生成式模型都成了推论。交替优化的姿态本篇与 [040.决策树与集成学习](./040.决策树与集成学习.md)（每轮拟合负梯度）已经见了两次；下一次它在 [060.布隆过滤器](../10.应用与专题/060.布隆过滤器.md) 所在的概率数据结构家族里，还将以坐标下降/吉布斯采样的形态继续出现。
