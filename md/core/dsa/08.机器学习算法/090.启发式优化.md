# 概述

梯度下降沿着「当前最陡的方向」走，遇到多峰地形就在第一个谷底躺平；而现实中大量优化问题——排班、布线、拟合多峰函数、超参搜索——连梯度都没有。**启发式优化**放弃「每步都变好」的执念，允许以一定概率接受更差的解，用随机性与全局搜索换取跳出局部最优的能力：**模拟退火（SA）**模仿金属降温，高温时大步乱走、低温时精细收敛，有渐近理论保证；**遗传算法（GA）**模仿进化，让一组候选解「优胜劣汰、交叉变异」，在解的种群上搜索。它们都不是精确算法，而是「在可接受的时间内给出足够好」的工程武器。梯度类方法见 [07.数值计算/030.数值优化方法](../07.数值计算/030.数值优化方法.md)。

- 所属章节：[000.机器学习算法概述](./000.机器学习算法概述.md)
- 时间复杂度：无多项式保证；SA/GA 按「评估预算」计——SA 为 \(O(iter \cdot C_{eval})\)，GA 为 \(O(gen \cdot pop \cdot C_{eval})\)（\(C_{eval}\) 为一次适应度评估成本）
- 空间复杂度：SA \(O(1)\)（只维护当前解）；GA \(O(pop \cdot |\text{个体}|)\)
- 应用场景：SA——作业车间调度、VLSI 布线、旅行商（配 2-opt 邻域）、模型超参精调；GA——特征子集选择、规则/结构编码搜索、游戏关卡自动生成

# 详解

## 模拟退火：Metropolis 准则 + 温度日程

SA 每步做三件事：扰动出邻域解 \(x'\)、算 \(\Delta = f(x') - f(x)\)（求最小化）、按概率决定是否接受：

\[
P(\text{接受}) = \begin{cases} 1, & \Delta \le 0 \\[4pt] \exp\left(-\dfrac{\Delta}{T}\right), & \Delta > 0 \end{cases}
\]

\(T\) 按几何日程衰减 \(T_{k+1} = \alpha T_k\)（\(\alpha \in [0.80, 0.99]\)）。理论（Hajec，1988）要求 \(T_k \ge \frac{C}{\log(k)}\) 级别的对数日程才能渐近收敛到全局最优——太慢无法实用；几何日程是「工程上够用」的折中，所以实践靠**多次重启 + 足够长的等温链**兜底。邻域扰动的幅度也应随温度缩小：高温大步探索，低温小步精修。

```java [Java]
public static double[] simulatedAnnealing(double[] x0, java.util.function.DoubleUnaryOperator f,
                                          double t0, double alpha, int chainLen, long seed) {
    Random rnd = new Random(seed);
    double x = x0[0], fx = f.applyAsDouble(x);
    double bestX = x, bestF = fx;
    for (double T = t0; T > 1e-8; T *= alpha) {
        for (int c = 0; c < chainLen; c++) {             // 等温链
            double step = (rnd.nextDouble() * 2 - 1) * T; // 扰动幅度 ∝ 温度
            double xn = x + step, fn = f.applyAsDouble(xn);
            double delta = fn - fx;
            if (delta <= 0 || rnd.nextDouble() < Math.exp(-delta / T)) {
                x = xn; fx = fn;                          // Metropolis 接受
                if (fx < bestF) { bestF = fx; bestX = x; }
            }
        }
    }
    return new double[]{bestX, bestF};
}
// 例：f(x)=(x-3)²·sin(8x)+x 从 x0=0 出发，多数种子收敛到全局低点附近
```

```rust [Rust]
pub struct Rng(u64);
impl Rng {
    fn new(seed: u64) -> Self { Rng(seed) }
    fn next_f64(&mut self) -> f64 {
        self.0 = self.0.wrapping_mul(6364136223846793005).wrapping_add(1442695040888963407);
        ((self.0 >> 11) as f64) / ((1u64 << 53) as f64)
    }
}

/// f: R^d -> R，x0 初值，返回 (最优解, 最优值)
pub fn simulated_annealing<F: Fn(&[f64]) -> f64>(
    x0: &[f64], f: F, t0: f64, alpha: f64, chain_len: usize, seed: u64,
) -> (Vec<f64>, f64) {
    let mut rng = Rng::new(seed);
    let mut x = x0.to_vec();
    let mut fx = f(&x);
    let (mut best_x, mut best_f) = (x.clone(), fx);
    let mut t = t0;
    while t > 1e-8 {
        for _ in 0..chain_len {
            let mut xn = x.clone();
            for v in xn.iter_mut() {
                *v += (rng.next_f64() * 2.0 - 1.0) * t;   // 步幅随温度收缩
            }
            let fn_ = f(&xn);
            let delta = fn_ - fx;
            let accept = delta <= 0.0
                || (delta / t).min(0.0) >= (rng.next_f64().max(1e-300)).ln(); // ⇔ rand < e^(-Δ/T)
            if accept {
                x = xn; fx = fn_;
                if fx < best_f { best_f = fx; best_x = x.clone(); }
            }
        }
        t *= alpha;
    }
    (best_x, best_f)
}
```

```typescript [TypeScript]
// 确定性伪随机：mulberry32
function makeRng(seed: number) {
  return () => {
    seed = (seed + 0x6d2b79f5) | 0;
    let t = Math.imul(seed ^ (seed >>> 15), 1 | seed);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

function simulatedAnnealing(x0: number[], f: (x: number[]) => number,
    t0: number, alpha: number, chainLen: number, seed: number): [number[], number] {
  const rnd = makeRng(seed);
  let x = [...x0], fx = f(x);
  let bestX = [...x], bestF = fx;
  for (let T = t0; T > 1e-8; T *= alpha)
    for (let c = 0; c < chainLen; c++) {
      const xn = x.map(v => v + (rnd() * 2 - 1) * T);
      const fn = f(xn);
      const delta = fn - fx;
      if (delta <= 0 || rnd() < Math.exp(-delta / T)) {   // Metropolis
        x = xn; fx = fn;
        if (fx < bestF) { bestF = fx; bestX = [...x]; }
      }
    }
  return [bestX, bestF];
}
```

```python [Python]
import math, random

def simulated_annealing(x0, f, t0=10.0, alpha=0.92, chain_len=50, seed=42):
    rnd = random.Random(seed)
    x, fx = list(x0), f(x0)
    best_x, best_f = x[:], fx
    T = t0
    while T > 1e-8:
        for _ in range(chain_len):                        # 等温链
            xn = [v + (rnd.random() * 2 - 1) * T for v in x]
            fn = f(xn)
            delta = fn - fx
            if delta <= 0 or rnd.random() < math.exp(-delta / T):
                x, fx = xn, fn                            # Metropolis 接受
                if fx < best_f:
                    best_f, best_x = fx, x[:]
        T *= alpha
    return best_x, best_f
```

## 遗传算法：选择、交叉、变异的三拍节奏

GA 搜索的是**种群**：个体 = 一个候选解的编码（二进制串、排列表、参数向量皆可），适应度 = 目标函数值。一代的流水线：

1. **选择**：锦标赛（随机抽 \(k\) 个取最优，\(k=2\sim3\)) 或轮盘赌（按适应度加权）——优胜者获得生育权，但只是「概率上占优」，保留多样性；
2. **交叉**：切两刀换段子（两点交叉）或逐位coin flip（均匀交叉）——把「好零件」重新组合，是 GA 主要的搜索力来源；
3. **变异**：逐位小概率翻转（经验值 \(p_m \approx 1/L\)，\(L\) 为编码长度）——防止种群过早同质化；
4. **精英保留**：直接克隆上代最优若干个体——保证最优值单调不降，配合终止条件（代数/评估预算/停滞）交付。

```java [Java]
public static int[] geneticAlgorithm(int bits, int popSize, int generations,
                                     double pc, double pm, long seed) {
    Random rnd = new Random(seed);
    int[][] pop = new int[popSize][bits];
    for (int[] ind : pop)
        for (int b = 0; b < bits; b++) ind[b] = rnd.nextInt(2);
    int[] best = null;
    for (int g = 0; g < generations; g++) {
        int[] fit = new int[popSize];
        int bi = 0;
        for (int i = 0; i < popSize; i++) {              // 适应度：OneMax 数 1
            for (int b : pop[i]) fit[i] += b;
            if (fit[i] > fit[bi]) bi = i;
        }
        best = pop[bi].clone();                           // 当代最优
        if (fit[bi] == bits) break;                       // 已达满分
        int[][] next = new int[popSize][bits];
        System.arraycopy(best, 0, next[0], 0, bits);      // 精英 1 名直通
        for (int i = 1; i < popSize; i += 2) {
            int p1 = tournament(pop, fit, rnd), p2 = tournament(pop, fit, rnd);
            int[] c1 = pop[p1].clone(), c2 = pop[p2].clone();
            if (rnd.nextDouble() < pc) {                  // 两点交叉
                int a = rnd.nextInt(bits), b = rnd.nextInt(bits);
                if (a > b) { int t = a; a = b; b = t; }
                for (int t = a; t <= b; t++) { int tmp = c1[t]; c1[t] = c2[t]; c2[t] = tmp; }
            }
            for (int t = 0; t < bits; t++) {              // 逐位变异
                if (rnd.nextDouble() < pm) c1[t] ^= 1;
                if (rnd.nextDouble() < pm) c2[t] ^= 1;
            }
            next[i] = c1;
            if (i + 1 < popSize) next[i + 1] = c2;
        }
        pop = next;
    }
    return best;
}

static int tournament(int[][] pop, int[] fit, Random rnd) {
    int a = rnd.nextInt(pop.length), b = rnd.nextInt(pop.length);
    return fit[a] >= fit[b] ? a : b;
}
// 20 位 OneMax、pop=20、gen=50、pc=0.9、pm=0.05 → 大概率收敛全 1
```

```rust [Rust]
/// OneMax 演示：最大化 1 的个数，返回最优个体
pub fn genetic_algorithm(bits: usize, pop_size: usize, generations: usize,
                         pc: f64, pm: f64, seed: u64) -> Vec<u8> {
    let mut rng = Rng::new(seed);                         // 同 SA 的 LCG
    let fit = |ind: &Vec<u8>| ind.iter().map(|&b| b as usize).sum::<usize>();
    let mut pop: Vec<Vec<u8>> = (0..pop_size).map(|_|
        (0..bits).map(|_| (rng.next_f64() < 0.5) as u8).collect()
    ).collect();
    let mut best = pop[0].clone();
    let mut best_f = 0usize;
    for _ in 0..generations {
        let fits: Vec<usize> = pop.iter().map(fit).collect();
        let bi = fits.iter().enumerate().max_by_key(|(_, f)| **f).unwrap().0;
        if fits[bi] > best_f { best_f = fits[bi]; best = pop[bi].clone(); }
        if best_f == bits { break; }
        let mut next = vec![pop[bi].clone()];             // 精英直通
        while next.len() < pop_size {
            let t = |rng: &mut Rng| {
                let a = (rng.next_f64() * pop_size as f64) as usize % pop_size;
                let b = (rng.next_f64() * pop_size as f64) as usize % pop_size;
                if fits[a] >= fits[b] { a } else { b }
            };
            let (p1, p2) = (t(&mut rng), t(&mut rng));
            let (mut c1, mut c2) = (pop[p1].clone(), pop[p2].clone());
            if rng.next_f64() < pc {                      // 两点交叉
                let (mut a, mut b) = (
                    (rng.next_f64() * bits as f64) as usize % bits,
                    (rng.next_f64() * bits as f64) as usize % bits);
                if a > b { std::mem::swap(&mut a, &mut b); }
                for k in a..=b { std::mem::swap(&mut c1[k], &mut c2[k]); }
            }
            for k in 0..bits {                            // 逐位变异
                if rng.next_f64() < pm { c1[k] ^= 1; }
                if rng.next_f64() < pm { c2[k] ^= 1; }
            }
            next.push(c1);
            if next.len() < pop_size { next.push(c2); }
        }
        pop = next;
    }
    best
}
```

```typescript [TypeScript]
function geneticAlgorithm(bits: number, popSize: number, generations: number,
                          pc: number, pm: number, seed: number): number[] {
  const rnd = makeRng(seed);                              // 复用 SA 的 mulberry32
  const fit = (ind: number[]) => ind.reduce((a, b) => a + b, 0);
  let pop = Array.from({ length: popSize }, () =>
    Array.from({ length: bits }, () => (rnd() < 0.5 ? 1 : 0)));
  let best: number[] = [], bestF = -1;
  const tourn = (fits: number[]) => {
    const a = Math.floor(rnd() * popSize), b = Math.floor(rnd() * popSize);
    return fits[a] >= fits[b] ? a : b;
  };
  for (let g = 0; g < generations; g++) {
    const fits = pop.map(fit);
    const bi = fits.indexOf(Math.max(...fits));
    if (fits[bi] > bestF) { bestF = fits[bi]; best = [...pop[bi]]; }
    if (bestF === bits) break;
    const next: number[][] = [[...pop[bi]]];              // 精英直通
    while (next.length < popSize) {
      const c1 = [...pop[tourn(fits)]], c2 = [...pop[tourn(fits)]];
      if (rnd() < pc) {                                   // 两点交叉
        let a = Math.floor(rnd() * bits), b = Math.floor(rnd() * bits);
        if (a > b) [a, b] = [b, a];
        for (let t = a; t <= b; t++) { const tmp = c1[t]; c1[t] = c2[t]; c2[t] = tmp; }
      }
      for (let t = 0; t < bits; t++) {                    // 逐位变异
        if (rnd() < pm) c1[t] ^= 1;
        if (rnd() < pm) c2[t] ^= 1;
      }
      next.push(c1, c2);
    }
    pop = next.slice(0, popSize);
  }
  return best;
}
```

```python [Python]
import random

def genetic_algorithm(bits=20, pop_size=20, generations=50, pc=0.9, pm=0.05, seed=42):
    rnd = random.Random(seed)
    fit = lambda ind: sum(ind)
    pop = [[rnd.randint(0, 1) for _ in range(bits)] for _ in range(pop_size)]
    best, best_f = None, -1

    def tourn(fits):
        a, b = rnd.randrange(pop_size), rnd.randrange(pop_size)
        return a if fits[a] >= fits[b] else b

    for _ in range(generations):
        fits = list(map(fit, pop))
        bi = max(range(pop_size), key=lambda i: fits[i])
        if fits[bi] > best_f:
            best_f, best = fits[bi], pop[bi][:]
        if best_f == bits:
            break
        nxt = [pop[bi][:]]                                # 精英直通
        while len(nxt) < pop_size:
            c1, c2 = pop[tourn(fits)][:], pop[tourn(fits)][:]
            if rnd.random() < pc:                         # 两点交叉
                a, b = sorted((rnd.randrange(bits), rnd.randrange(bits)))
                for t in range(a, b + 1):
                    c1[t], c2[t] = c2[t], c1[t]
            for t in range(bits):                         # 逐位变异
                if rnd.random() < pm: c1[t] ^= 1
                if rnd.random() < pm: c2[t] ^= 1
            nxt.extend((c1, c2))
        pop = nxt[:pop_size]
    return best
```

## 常见陷阱

::: danger 陷阱清单
1. **降温太快 ≈ 贪心**：几何日程 \(\alpha\) 取 0.5 这类激进值，等温链又短，SA 会在第一个谷底冻住——与「不加退火」几乎无差；宁可多花评估预算。
2. **接受概率里用了「当前能量」而非「最优」**：`best` 更新只用于交付，Metropolis 判断永远基于当前解 \(f(x)\)——两者混用会破坏细致平衡，接受率虚高。
3. **GA 编码决定一切**：TSP 用二进制串表示路径，交叉几乎必然产生非法解；必须用排列编码 + OX/PMX 等保序交叉——「遗传」的前提是基因真的可遗传。
4. **变异率两端的坑**：\(p_m\) 太大（如 0.1 每位）等于随机重启，种群永远不收敛；太小（0）则早熟收敛——两个最优个体交配出的后代全是同一套零件。
5. **没有免费午餐**：SA/GA 对「所有问题」的平均表现与随机猜测相同（Wolpert）；它们的优势来自**与问题结构匹配的邻域/编码**——设计邻域比调参更重要。
6. **不记录评估预算就吹嘘收敛**：启发式的「好」以有限时间计——报告里写「10⁵ 次评估内最优值 X」，而不是「跑了 100 代到了 X」。
7. **能精确解就别启发式**：背包有 DP（见 [04.核心算法思想](../04.核心算法思想/000.核心算法思想概述.md)）、最短路有 Dijkstra——SA/GA 是给「没有有效精确算法」的问题准备的最后手段。
:::

::: info SA vs GA 选型
| 维度 | 模拟退火 | 遗传算法 |
|------|---------|---------|
| 搜索载体 | 单点游走 | 种群并行 |
| 参数 | \(t_0, \alpha\)，链长 | \(p_c, p_m\), pop, 代数 |
| 理论保证 | 对数日程下渐近全局 | 无（收敛性仅经验） |
| 适配场景 | 连续/单解结构、邻域易定义 | 组合/编码可拆解、零件可重组 |
| 调参直觉 | 先保证「够慢」，再谈邻域 | 先保证「编码合法」，再谈算子 |
:::

# 总结

- **SA** 的核心是 Metropolis 准则 \(\exp(-\Delta/T)\) 与温度日程：高温探索、低温 exploitation，实现 20 行、理论最硬，适合「邻域好定义」的单解优化。
- **GA** 把优化变成繁殖：选择给方向、交叉重组零件、变异注入新奇、精英保住战果——上限取决于**编码是否让好零件可遗传**，而不是种群开多大。
- 两者共享一条铁律：启发式只保证「够快够好」，不保证「最优」——能精确解的问题交给精确算法，启发式是处理 NP-hard 与黑盒多峰地形的工程武器。
- 与邻居的关系：贪心（[04.核心算法思想/080.贪心算法](../04.核心算法思想/080.贪心算法.md)）是 \(T \to 0\) 的 SA；梯度下降是「有导数时更快的贪心」——启发式优化是确定性方法失效之后的兜底艺术。
