# 概述

监督学习从「输入-标签」对 \(\{(x_i, y_i)\}\) 中学习映射 \(f: x \to y\)：标签连续叫**回归**，离散叫**分类**。它的三个支柱问题是——**模型族**（假设空间选多大）、**准则**（损失函数衡量什么）、**优化**（怎么在训练误差与泛化之间权衡）。本篇用最小完备的视角过一遍框架：线性回归/逻辑回归给出「闭式解与凸优化」的原型，KNN 给出「零训练、全查询」的对偶原型，评估指标体系则是贯穿一切的门面。

- 所属章节：[000.机器学习算法概述](./000.机器学习算法概述.md)
- 时间复杂度：训练各模型差异极大——线性回归正规方程 \(O(md^2 + d^3)\)（\(m\) 样本、\(d\) 特征）或梯度下降 \(O(iter \cdot md)\)；逻辑回归无闭式解，迭代 \(O(iter \cdot md)\)；KNN 训练 \(O(1)\)、查询 \(O(m d)\)（KD 树/ANN 索引可降至约 \(O(\log m)\)）
- 空间复杂度：线性/逻辑模型 \(O(d)\)；KNN \(O(md)\)（存全部训练集）
- 应用场景：房价/销量预测（回归）、垃圾邮件与风控（分类）、广告 CTR（逻辑回归至今是工业基线）、推荐召回（KNN/ANN）；进阶模型见 [040.决策树与集成学习](./040.决策树与集成学习.md) 与 [050.神经网络与反向传播](./050.神经网络与反向传播.md)
- 前置：距离度量见 [010.向量距离与相似度度量](./010.向量距离与相似度度量.md)；梯度下降见 [07.数值计算/030.数值优化方法](../07.数值计算/030.数值优化方法.md)；正规方程与矩阵求逆见 [07.数值计算/010.线性方程组求解](../07.数值计算/010.线性方程组求解.md)

# 详解

## 框架四件套

1. **模型族**：从「常数」到「K 近邻」到「十万参数神经网络」，假设空间越大越能拟合训练集、也越容易记住噪声——偏差-方差权衡是监督学习的第一根轴。
2. **损失函数**：回归用平方损失（对应高斯噪声下的极大似然）、分类用 0-1 损失不可导，于是退到可导替代——逻辑回归的对数损失、SVM 的合页损失、神经网络的交叉熵。
3. **优化器**：线性回归有闭式解 \(\hat\beta = (X^TX)^{-1}X^Ty\)（正规方程，数值上应解 \(X^TX\hat\beta = X^Ty\) 而非显式求逆，见 [07.数值计算/020.矩阵运算算法](../07.数值计算/020.矩阵运算算法.md) 陷阱 2）；逻辑回归与神经网络靠梯度族（[07.数值计算/030.数值优化方法](../07.数值计算/030.数值优化方法.md)）。
4. **泛化评估**：留出法/交叉验证切分训练与验证；欠拟合加模型容量，过拟合加正则（岭回归 \(\lambda\lVert\beta\rVert^2\)、LASSO \(\lambda\lVert\beta\rVert_1\)）、早停或降容量。

## 模型本体速览

**线性回归**：\(\hat y = \beta_0 + \beta^T x\)， MSE 损失下正规方程一步解；特征相关时 \(X^TX\) 病态，岭回归 \(\hat\beta = (X^TX + \lambda I)^{-1}X^Ty\) 用对角加 \(\lambda\) 稳住（呼应 [07.数值计算/020.矩阵运算算法](../07.数值计算/020.矩阵运算算法.md) 的「先正则再求逆」）。

**逻辑回归**：把线性输出压成概率 \(p = \sigma(\beta_0 + \beta^T x) = 1/(1+e^{-z})\)，对数损失凸、无闭式解；决策边界仍是超平面——它是「线性分类器 + 概率标定」的组合，工业基线与可解释性标杆。

**KNN**：不训练，查询时「取距离前 K 投票/平均」。它把监督学习的三个旋钮暴露得最彻底：**K**（模型复杂度）、**距离**（[010.向量距离与相似度度量](./010.向量距离与相似度度量.md)）、**权重**（等权 vs 距离反比加权）；同时是维度诅咒的活教材——高维下距离对比度消失，KNN 退化。

```java [Java]
interface Metric { double apply(double[] a, double[] b); }

public record Sample(double[] x, int label) {}

public static int knnClassify(List<Sample> train, double[] q, int k, Metric dist) {
    // 全量按距离排序取前 k，再多数表决（教学版；工程用快速选择或 ANN 索引）
    Sample[] near = train.stream()
            .sorted(Comparator.comparingDouble(s -> dist.apply(s.x(), q)))
            .limit(k)
            .toArray(Sample[]::new);
    Map<Integer, Integer> votes = new HashMap<>();
    for (Sample s : near) votes.merge(s.label(), 1, Integer::sum);
    return votes.entrySet().stream()
            .max(Map.Entry.comparingByValue())
            .map(Map.Entry::getKey).orElse(-1);
}
// 调用：knnClassify(train, new double[]{3, 2}, 3,
//        (a, b) -> Math.sqrt((a[0]-b[0])*(a[0]-b[0]) + (a[1]-b[1])*(a[1]-b[1]))) → 0
```

```rust [Rust]
#[derive(Clone, Copy)]
pub struct Sample {
    pub x: [f64; 2],
    pub label: i32,
}

pub fn knn_classify(train: &[Sample], q: [f64; 2], k: usize) -> i32 {
    let mut dists: Vec<(f64, i32)> = train
        .iter()
        .map(|s| {
            let dx = s.x[0] - q[0];
            let dy = s.x[1] - q[1];
            ((dx * dx + dy * dy).sqrt(), s.label)
        })
        .collect();
    dists.sort_by(|a, b| a.0.partial_cmp(&b.0).unwrap());
    let mut votes: std::collections::HashMap<i32, u32> = std::collections::HashMap::new();
    for &(_, label) in dists.iter().take(k) {
        *votes.entry(label).or_insert(0) += 1;
    }
    votes.into_iter()
        .max_by_key(|(_, c)| *c)
        .map(|(l, _)| l)
        .unwrap_or(-1)
}

mod tests {
```

```typescript [TypeScript]
interface Sample { x: number[]; label: number }

function knnClassify(train: Sample[], q: number[], k: number,
                     dist: (a: number[], b: number[]) => number): number {
  const scored = train
    .map(s => ({ label: s.label, d: dist(s.x, q) }))
    .sort((a, b) => a.d - b.d);
  const votes = new Map<number, number>();
  for (const s of scored.slice(0, k))
    votes.set(s.label, (votes.get(s.label) ?? 0) + 1);
  let best = -1, cnt = -1;
  for (const [label, c] of votes) if (c > cnt) { best = label; cnt = c; }
  return best;
}

const euclid = (a: number[], b: number[]) =>
  Math.hypot(...a.map((v, i) => v - b[i]));
// knnClassify(train, [3, 2], 3, euclid) → 0（● 类）
```

```python [Python]
import math
from collections import Counter

def knn_classify(train, q, k=3):
    """train: [(x_tuple, label), ...]；距离用欧氏（可换 [010] 篇任一度量）"""
    dists = sorted(
        (math.dist(x, q), label) for x, label in train
    )
    votes = Counter(label for _, label in dists[:k])
    return votes.most_common(1)[0][0]

train = [((1, 1), 0), ((2, 2), 0), ((1, 3), 0), ((5, 5), 1), ((6, 4), 1)]
# knn_classify(train, (3, 2), k=3) → 0
```

## 评估指标速查

| 任务 | 指标 | 定义与适用 |
|------|------|-----------|
| 回归 | MSE / RMSE | \(\frac{1}{m}\sum(y-\hat y)^2\)；对离群敏感，可配 Huber 损失 |
| 回归 | MAE | 绝对误差；稳健、量纲同原值 |
| 回归 | \(R^2\) | \(1 - SSE/SST\)；0=只预测均值，1=完美 |
| 分类 | Accuracy | 对 Balanced 数据尚可，99:1 不平衡时毫无意义 |
| 分类 | Precision / Recall | 查准/查全；风控怕漏（重召回）、营销怕扰（重精确） |
| 分类 | F1 | \(2PR/(P+R)\)；单值权衡 |
| 分类 | ROC-AUC | 阈值无关的排序质量；不平衡场景比 Accuracy 诚实 |
| 分类 | PR-AUC | 极端不平衡（欺诈、检索）时比 ROC-AUC 更能暴露问题 |

## 常见陷阱

1. **测试集泄漏**：归一化参数（均值/方差）在「全量数据」上拟合再交叉验证，等于提前偷看——所有预处理必须只 fit 训练折、再 transform 验证折。
2. **类别不平衡看 Accuracy**：99% 负样本全预测负也有 0.99 准确率；先看类分布，选 PR-AUC/F1，或重采样/改类权重。
3. **不标准化就开跑**：距离类（KNN）与梯度类（逻辑回归/NN）模型对量纲同样敏感，树模型（[040.决策树与集成学习](./040.决策树与集成学习.md)）则免疫——预处理清单因模型而异。
4. **KNN 的 K 用默认 3**：K 必须交叉验证调；数据规模大时 `sklearn` 默认 `algorithm='auto'` 会切 BallTree/KDTree，高维（>16 维）自动退回暴力——感知不到这一层就会抱怨「KNN 突然变慢」。
5. **正则强度当摆设**：逻辑回归默认 `C=1.0` 隐含 L2 正则，数据小、特征共线时调 `C` 能显著改结论；对比实验时锁死同一正则口径。
6. **把线性模型的概率当校准**：逻辑回归输出的概率在重采样后系统性偏移（正例比例变了，先验就变了）；需要「这个样本真有 80% 会点」这种可解释数字时，做 Platt/Isotonic 校准。

# 总结

监督学习的骨架一句话可以说完：**在模型族里挑假设、用损失函数定对错、靠交叉验证防自欺**。线性/逻辑回归贡献了「凸优化 + 可解释」的原型，KNN 贡献了「度量决定一切」的非参原型，二者覆盖了大半工业基线；当特征交互复杂到线性族拟合不动时，树集成（[040.决策树与集成学习](./040.决策树与集成学习.md)）与神经网络（[050.神经网络与反向传播](./050.神经网络与反向传播.md)）接棒——而评估指标与数据划分的纪律，到哪一步都是同一套。
