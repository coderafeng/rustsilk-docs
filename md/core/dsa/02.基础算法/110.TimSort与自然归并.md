# 概述

TimSort 是**归并 + 插入**的混合自适应排序，由 Tim Peters 为 Python 设计，现被 Python `sorted`、Java `Arrays.sort(对象)`、Android、V8 等广泛采用。它先识别/构造**天然有序游程（run）**，用插入排序把短 run 扩到最小长度，再按栈规则**归并**相邻 run。

- 时间复杂度：最好 **O(n)**（已有序）、平均/最坏 **O(n log n)**
- 空间复杂度：O(n)（归并临时数组，实际用 galloping 优化）
- 稳定性：**稳定**
- 应用场景：真实世界数据常含部分有序性，TimSort 正是为此优化——它是多数标准库对象排序的默认实现。

**动画：识别 run → 插入扩 run → 栈式归并** <!-- dsa.assets/sort/timsort.gif -->

1. 顺序扫描，找出天然升序/降序**游程 run**（降序则原地反转）；
2. run 长度不足 `minRun`（通常 32~64）时，用**二分插入排序**补齐到 minRun；
3. 把 run 压栈，按**不变式**（栈中相邻 run 长度交错、满足 A>B>C 比例）触发**归并**；
4. 反复归并直到栈清空，全程利用已有有序性。

# 详解

## 三个核心设计

1. **利用有序性**：真实数据很少完全乱序，识别 run 让最好情况达 O(n)；
2. **minRun 权衡**：太小→归并层数多，太大→插入排序 O(n²) 变重，取 n 的二进制高位使其为 2 的幂附近值；
3. **galloping（跳跃模式）**：一方连续胜出时改为指数搜索批量搬运，把归并常数进一步压低。

## 各语言直接调用

::: code-group
```java [Java]
// 对象数组：Arrays.sort 用 TimSort（稳定）；基本类型用双轴快排
Integer[] arr = {5, 2, 9, 1};
Arrays.sort(arr);                              // 稳定
// 自定义比较
Arrays.sort(people, Comparator.comparingInt(p -> p.age));
```
```rust [Rust]
// Rust 1.81+ 提供 slice::sort（TimSort，稳定）；更早版为 pattern-defeating quicksort
let mut v = vec![5, 2, 9, 1];
v.sort();          // 稳定排序（TimSort）
v.sort_unstable(); // 更快但不稳定（pdqsort）
```
```typescript [TypeScript]
// V8 的 Array.prototype.sort 自 7.0 起为稳定 TimSort
const arr = [5, 2, 9, 1];
arr.sort((a, b) => a - b);   // 数值：必须传比较器，默认按字符串排
console.log(arr);            // [1, 2, 5, 9]
```
```python [Python]
# sorted / list.sort 即 TimSort，稳定，默认带 key
data = [(2, "b"), (1, "a"), (1, "c")]
print(sorted(data, key=lambda x: x[0]))  # 相等键保持原序：稳定
```
:::

## 常见陷阱

- **JS 默认排序按字符串**：`[10,9,2].sort()` → `[10,2,9]`，数值排序务必传比较器。
- **Java 基本类型非稳定**：`Arrays.sort(int[])` 用双轴快排（不稳定），要稳定得转 `Integer[]` 或用对象数组。

# 总结

- TimSort = **归并骨架 + 插入填充 + run 识别 + galloping**，自适应、稳定、最坏 O(n log n)；
- 强项是**部分有序数据**下逼近 O(n)，故成为多语言标准库默认；
- 用它理解工程排序的真谛：**不追求单次最优，而是压榨输入分布中的已有秩序**。
