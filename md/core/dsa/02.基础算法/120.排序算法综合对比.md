# 详解

## 全景对比表

| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定 | 备注 |
|------|:----:|:----:|:----:|:----:|:----:|------|
| 冒泡 | O(n) | O(n²) | O(n²) | O(1) | ✅ | 教学 |
| 选择 | O(n²) | O(n²) | O(n²) | O(1) | ❌ | 交换最少 |
| 插入 | O(n) | O(n²) | O(n²) | O(1) | ✅ | 近有序/小数据最优 |
| 希尔 | O(n log n) | ~O(n^1.3) | O(n²) | O(1) | ❌ | 依赖增量序列 |
| 归并 | O(n log n) | O(n log n) | O(n log n) | O(n) | ✅ | 外部/链表排序 |
| 快排 | O(n log n) | O(n log n) | O(n²) | O(log n) | ❌ | 平均最快、原地 |
| 堆排 | O(n log n) | O(n log n) | O(n log n) | O(1) | ❌ | 最坏保证、原地 |
| TimSort | O(n) | O(n log n) | O(n log n) | O(n) | ✅ | 自适应、库默认 |
| 计数 | O(n+k) | O(n+k) | O(n+k) | O(k) | ✅ | 小值域整数 |
| 桶 | O(n+k) | O(n+k) | O(n²) | O(n+k) | 取决于桶内 | 均匀分布 |
| 基数 | O(d(n+k)) | O(d(n+k)) | O(d(n+k)) | O(n+k) | ✅ | 定长键 |

## 三条选型经验

1. **通用内存排序**：直接 `Arrays.sort`/`sort()`（背后是 TimSort/双轴快排/pdqsort），别手写；
2. **要稳定或需最坏保证 + 省空间**：稳定选归并/TimSort，原地最坏保证选堆排；
3. **整数/定长键且值域可控**：上计数/基数，突破比较下界 O(n log n)——理论依据见 [04.核心算法思想/010.算法分析基础](../04.核心算法思想/010.算法分析基础.md)（比较排序 Ω(n log n) 下界）。

## 库调用速记

::: code-group
```java [Java]
Arrays.sort(intArr);            // 基本类型：双轴快排（不稳定）
Arrays.sort(objArr);            // 对象：TimSort（稳定）
Collections.sort(list);         // 归并系稳定
```
```rust [Rust]
v.sort();            // 稳定（TimSort）
v.sort_unstable();   // 更快（pdqsort），非稳定
```
```typescript [TypeScript]
arr.sort((a, b) => a - b); // 稳定 TimSort；数值必传比较器
```
```python [Python]
sorted(a)            # TimSort，稳定
a.sort(key=...)      # 原地、稳定
```
:::

# 总结

- 比较排序存在 **Ω(n log n) 下界**，要更快只能靠"非比较 + 值域受限"（计数/桶/基数）；
- **稳定性**决定能否多关键字排序、**原地性**决定空间、**是否自适应**决定真实数据表现；
- 工程默认交给标准库（TimSort/双轴快排/pdqsort），手写的价值在于理解权衡与应对特殊约束。
