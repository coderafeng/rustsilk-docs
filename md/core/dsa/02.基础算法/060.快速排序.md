# 概述

快速排序（Quick Sort）**选一个基准 pivot**，一次分区把小于 pivot 的放左、大于的放右，再对两侧递归。平均最快的原地排序，是绝大多数语言标准库的默认主角。

- 时间复杂度：平均 **O(n log n)**、最坏 **O(n²)**（数组已有序 + 选首/尾为基准）
- 空间复杂度：O(log n)（递归栈）
- 稳定性：**不稳定**
- 应用场景：通用内存排序、`Arrays.sort(基本类型)`、`sort` 系实现、Top-K/快速选择。

1. 取区间末元素为 `pivot`，`i = l-1` 指向"小于区"的边界；
2. `j` 从 l 扫到 r-1：`a[j] < pivot` 则 `i++` 并交换 `a[i]`、`a[j]`；
3. 结束把 `pivot`（末位）与 `a[i+1]` 交换，pivot 归位；
4. 对 `pivot` 左右两个子区间递归。

# 详解

::: code-group
```java [Java]
void quickSort(int[] a, int l, int r) {
    if (l >= r) return;
    int p = partition(a, l, r);
    quickSort(a, l, p - 1);
    quickSort(a, p + 1, r);
}
int partition(int[] a, int l, int r) {
    int mid = (l + r) >>> 1;                 // 三数取中选基准，规避最坏
    if (a[l] > a[mid]) { int t = a[l]; a[l] = a[mid]; a[mid] = t; }
    if (a[mid] > a[r]) { int t = a[mid]; a[mid] = a[r]; a[r] = t; }
    if (a[l] > a[mid]) { int t = a[l]; a[l] = a[mid]; a[mid] = t; }
    int pivot = a[mid];
    int i = l, j = r;
    while (i <= j) {
        while (a[i] < pivot) i++;
        while (a[j] > pivot) j--;
        if (i <= j) { int t = a[i]; a[i] = a[j]; a[j] = t; i++; j--; } // Hoare 双指针
    }
    return i; // 返回分割点
}
```
```rust [Rust]
fn quick_sort(a: &mut [i32]) {
    let n = a.len();
    if n < 2 { return; }
    let pivot = a[n / 2];
    let (mut i, mut j) = (0isize, n as isize - 1);
    while i <= j {
        while a[i as usize] < pivot { i += 1; }
        while a[j as usize] > pivot { j -= 1; }
        if i <= j { a.swap(i as usize, j as usize); i += 1; j -= 1; }
    }
    if j > 0 { quick_sort(&mut a[..(j + 1) as usize]); }
    quick_sort(&mut a[i as usize..]);
}
```

```typescript [TypeScript]
function quickSort(a: number[], l = 0, r = a.length - 1): void {
    if (l >= r) return;
    const pivot = a[(l + r) >> 1];
    let i = l, j = r;
    while (i <= j) {
        while (a[i] < pivot) i++;
        while (a[j] > pivot) j--;
        if (i <= j) { [a[i], a[j]] = [a[j], a[i]]; i++; j--; }
    }
    quickSort(a, l, j);
    quickSort(a, i, r);
}
```

```python [Python]
def quick_sort(a):
    if len(a) < 2:
        return a
    pivot = a[len(a) // 2]
    less = [x for x in a if x < pivot]
    equal = [x for x in a if x == pivot]
    greater = [x for x in a if x > pivot]
    return quick_sort(less) + equal + quick_sort(greater)  # 三路划分，天然处理重复
```

## 应对最坏与重复元素

- **基准选取**：随机化或**三数取中**，避免有序数据触发 O(n²)；
- **三路划分（荷兰国旗）**：把区间分成 `< = >` 三段，大量重复键时等于段一次到位；
- **尾递归优化**：先递归较小的一侧、较大侧用循环，保证栈深 O(log n)。

# 总结

- 快排：选基准 + 分区 + 递归，平均最快、原地、缓存友好；
- 最坏 O(n²) 靠**随机化/三数取中**规避，重复多靠**三路划分**；
- 不稳定，工程常与归并/插入混用（IntroSort、TimSort）来兜底最坏与小区间。
