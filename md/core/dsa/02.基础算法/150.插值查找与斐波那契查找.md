# 概述

插值查找与斐波那契查找都是二分查找的改进：二分机械地取中点，而**插值查找**按 `target` 在区间中的**数值比例**预估位置（对均匀分布极快），**斐波那契查找**用斐波那契数划分区间（把除法变加法、分割点恒定，利于某些硬件/磁盘场景）。

- 时间复杂度：普通二分 O(log n)；**插值查找**均匀分布下 **O(log log n)**、最坏 O(n)；**斐波那契查找** O(log n)
- 空间复杂度：O(1)
- 应用场景：电话簿/字典式**分布均匀且可计算位置**的数据（插值）；减少比较代价、顺序访问友好（斐波那契）。

# 详解

## 插值查找

把折半的"1/2"换成按值的比例。分母 `a[hi]-a[lo]` 为 0（全相等）时需特判避免除零。

::: code-group
```java [Java]
int interpolationSearch(int[] a, int target) {
    int lo = 0, hi = a.length - 1;
    while (lo <= hi && target >= a[lo] && target <= a[hi]) {
        if (lo == hi) return a[lo] == target ? lo : -1;
        int pos = lo + (int) ((long)(target - a[lo]) * (hi - lo) / (a[hi] - a[lo]));
        if (a[pos] == target) return pos;
        if (a[pos] < target) lo = pos + 1; else hi = pos - 1;
    }
    return -1;
}
```
```rust [Rust]
fn interpolation(a: &[i32], target: i32) -> Option<usize> {
    let (mut lo, mut hi) = (0isize, a.len() as isize - 1);
    while lo <= hi && target >= a[lo as usize] && target <= a[hi as usize] {
        if lo == hi {
            return if a[lo as usize] == target { Some(lo as usize) } else { None };
        }
        let span = (a[hi as usize] - a[lo as usize]) as f64;
        let pos = lo as f64 + (target - a[lo as usize]) as f64 / span * (hi - lo) as f64;
        let p = pos as isize;
        if a[p as usize] == target { return Some(p as usize); }
        if a[p as usize] < target { lo = p + 1; } else { hi = p - 1; }
    }
    None
}
```

```python [Python]
def interpolation_search(a, target):
    lo, hi = 0, len(a) - 1
    while lo <= hi and a[lo] <= target <= a[hi]:
        if lo == hi:
            return lo if a[lo] == target else -1
        pos = lo + (target - a[lo]) * (hi - lo) // (a[hi] - a[lo])
        if a[pos] == target:
            return pos
        if a[pos] < target:
            lo = pos + 1
        else:
            hi = pos - 1
    return -1
```

## 斐波那契查找要点

用相邻斐波那契数 `F(k)` 决定切分点 `mid = lo + F(k-1) - 1`，使两次子区间长度都是斐波那契数，逐步退化用加法递推 `F(k)=F(k-1)+F(k-2)` 替代除法/移位，历史上用于规避 costly 运算并让访问局部性更好。实际收益有限，了解思想即可。

# 总结

- 插值查找：按比例估算探查点，**均匀分布 O(log log n)**，但依赖有序且分布均匀，最坏退化 O(n)；
- 斐波那契查找：用斐波那契分割把除法换加法，复杂度仍 O(log n)，属优化技巧；
- 三者本质都是"利用有序/分布缩小区间"，默认场景用**普通二分**最稳，本专题用于理解改进方向。
