# 概述

桶排序（Bucket Sort）把数据按值域**均匀划分到若干个桶**，每个桶内部单独排序（可用插入排序或递归桶排序），再按桶序拼接。适合**均匀分布的连续数据**。

- 时间复杂度：最好/平均 **O(n + k)**（k 个桶），最坏 **O(n²)**（全落一个桶）
- 空间复杂度：O(n + k)
- 稳定性：取决于桶内排序算法（用插入排序则稳定）
- 应用场景：浮点数均匀分布（如 [0,1) 成绩/坐标）、外部排序的分桶阶段。

3. 依次倒出各桶即全局有序。

# 详解

::: code-group
```java [Java]
void bucketSort(float[] a) {
    List<List<Float>> buckets = new ArrayList<>();
    for (int i = 0; i < a.length; i++) buckets.add(new ArrayList<>());
    for (float x : a) buckets.get((int) (x * a.length)).add(x); // 设 x∈[0,1)
    for (List<Float> b : buckets) Collections.sort(b);          // 桶内排序
    int k = 0;
    for (List<Float> b : buckets) for (float x : b) a[k++] = x;
}
```
```rust [Rust]
fn bucket_sort(a: &mut [f64]) {           // 假设数据在 [0,1)
    let n = a.len();
    let mut buckets = vec![Vec::new(); n];
    for &x in a.iter() { buckets[(x * n as f64) as usize].push(x); }
    for b in buckets.iter_mut() { b.sort_by(|p, q| p.partial_cmp(q).unwrap()); }
    let mut k = 0;
    for b in buckets.iter() { for &x in b.iter() { a[k] = x; k += 1; } }
}
```
```typescript [TypeScript]
function bucketSort(a: number[], bucketSize = 5): number[] {
    if (a.length < 2) return a;
    const min = Math.min(...a), max = Math.max(...a);
    const count = Math.floor((max - min) / bucketSize) + 1;
    const buckets: number[][] = Array.from({ length: count }, () => []);
    for (const x of a) buckets[Math.floor((x - min) / bucketSize)].push(x);
    const out: number[] = [];
    for (const b of buckets) out.push(...b.sort((p, q) => p - q));
    return out;
}
```
```python [Python]
def bucket_sort(a, bucket_size=5):
    if len(a) < 2:
        return a
    lo, hi = min(a), max(a)
    n = (hi - lo) // bucket_size + 1
    buckets = [[] for _ in range(n)]
    for x in a:
        buckets[(x - lo) // bucket_size].append(x)
    out = []
    for b in buckets:
        out.extend(sorted(b))
    return out
```

## 与计数排序的关系

计数排序可看作**每个可能取值一个桶**的极端桶排序；桶排序的桶可以容纳一段区间，桶内再用别的排序，因而能处理浮点与分布数据。

# 总结

- 桶排序：映射分桶 + 桶内排序 + 拼接，均匀分布下平均近线性；
- 关键在**映射函数让数据均匀入桶**，否则退化为 O(n²)；
- 最适合连续均匀分布，是外部排序与并行排序的分治前件。
