# 概述

归并排序（Merge Sort）用**分治**：递归地把数组二分、各自排好，再**合并**两个有序子数组。它是**稳定**且最坏也有 O(n log n) 的代表，代价是需要 O(n) 额外空间。

- 时间复杂度：最好/平均/最坏均 **O(n log n)**
- 空间复杂度：O(n)（合并用的临时数组）
- 稳定性：**稳定**（合并时相等取左侧先出）
- 应用场景：外部排序（大文件归并）、链表排序（无需随机访问）、需要稳定性的场景、求逆序对。

1. 递归 `mid = (l+r)/2` 二分，直到区间长度 1（天然有序）；
2. 合并两个有序子区间：双指针各取较小者放入临时数组；
3. 一侧耗尽则把另一侧整段接上；
4. 拷回原数组，逐层回溯完成排序。

# 详解

::: code-group
```java [Java]
void mergeSort(int[] a, int l, int r) {
    if (l >= r) return;
    int mid = (l + r) >>> 1;
    mergeSort(a, l, mid);
    mergeSort(a, mid + 1, r);
    merge(a, l, mid, r);
}
void merge(int[] a, int l, int mid, int r) {
    int[] tmp = new int[r - l + 1];
    int i = l, j = mid + 1, k = 0;
    while (i <= mid && j <= r) tmp[k++] = a[i] <= a[j] ? a[i++] : a[j++]; // <= 保证稳定
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= r)   tmp[k++] = a[j++];
    System.arraycopy(tmp, 0, a, l, tmp.length);
}
```

```rust [Rust]
fn merge_sort(a: &mut Vec<i32>) {
    let n = a.len();
    if n < 2 { return; }
    let mid = n / 2;
    let mut left = a[..mid].to_vec();
    let mut right = a[mid..].to_vec();
    merge_sort(&mut left);
    merge_sort(&mut right);
    let (mut i, mut j, mut k) = (0, 0, 0);
    while i < left.len() && j < right.len() {
        if left[i] <= right[j] { a[k] = left[i]; i += 1; } else { a[k] = right[j]; j += 1; }
        k += 1;
    }
    while i < left.len() { a[k] = left[i]; i += 1; k += 1; }
    while j < right.len() { a[k] = right[j]; j += 1; k += 1; }
}
```
```typescript [TypeScript]
function mergeSort(a: number[]): number[] {
    if (a.length < 2) return a;
    const mid = a.length >> 1;
    const L = mergeSort(a.slice(0, mid));
    const R = mergeSort(a.slice(mid));
    const out: number[] = [];
    let i = 0, j = 0;
    while (i < L.length && j < R.length)
        out.push(L[i] <= R[j] ? L[i++] : R[j++]);
    return out.concat(L.slice(i), R.slice(j));
}
```
```python [Python]
def merge_sort(a):
    if len(a) < 2:
        return a
    mid = len(a) // 2
    L, R = merge_sort(a[:mid]), merge_sort(a[mid:])
    out, i, j = [], 0, 0
    while i < len(L) and j < len(R):
        if L[i] <= R[j]:            # <= 保证稳定
            out.append(L[i]); i += 1
        else:
            out.append(R[j]); j += 1
    return out + L[i:] + R[j:]
```

## 关键细节：为什么用 `<=`

合并取元素时相等必须优先左半边的元素（`a[i] <= a[j]`），否则两等值元素相对顺序翻转、稳定性丢失。

## 自底向上与外部排序

迭代版从相邻 2 个合并、4 个、8 个……倍增，省去递归栈；**外部排序**中内存放不下时，分块内排 + 多路归并是标准打法（见 [04.核心算法思想/050.分治算法](../04.核心算法思想/050.分治算法.md)）。

# 总结

- 归并：二分递归 + 合并有序子数组，**O(n log n)、稳定**，代价 O(n) 空间；
- 合并时 `<=` 是稳定性的命门；
- 大数据/链表/外部排序首选，因为性能不随输入分布退化、且天然支持流式归并。
