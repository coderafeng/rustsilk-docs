# 概述

枚举（穷举）是把**候选答案空间**逐个列举并验证的基本方法——所有算法的"暴力解"都源于它。关键是**界定枚举对象与范围**、并用二分/三分/剪枝压缩规模。它是理解复杂度上限与后续优化（分治、DP、搜索）的参照系。

- 时间复杂度：取决于解空间大小，常为多项式 O(n²)/O(n³) 或指数 O(2ⁿ)
- 空间复杂度：O(1)~O(n)
- 应用场景：小规模可行性验证、作为其他算法的正确性基准（对拍）、组合问题骨架。

**本篇收录**：线性枚举、二分枚举（枚举答案 + 判定）、三分枚举（单峰极值）

# 详解

## 三种枚举范式

- **线性枚举**：直接遍历，如枚举所有子数组 `for i, for j` O(n²)；
- **二分枚举（枚举答案）**：答案具备单调可行性时，对答案值二分 + 贪心判定，把"求最优"变"判定 x 是否可行"（同 [140.二分查找](./140.二分查找.md) 的二分答案）；
- **三分枚举**：目标函数**单峰**（凸/凹）时三分区间求极值，每次弃掉 1/3。

::: code-group
```java [Java]
// 线性枚举：最大子数组和的 O(n²) 暴力（对照 Kadane O(n)）
int best = Integer.MIN_VALUE;
for (int i = 0; i < n; i++) {
    int sum = 0;
    for (int j = i; j < n; j++) { sum += a[j]; best = Math.max(best, sum); }
}
// 三分枚举：单峰函数求极大值点
double ternaryMax(double l, double r) {
    for (int it = 0; it < 100; it++) {
        double m1 = l + (r - l) / 3, m2 = r - (r - l) / 3;
        if (f(m1) < f(m2)) l = m1; else r = m2;
    }
    return (l + r) / 2;
}
```

## 枚举的边界

先算解空间规模：`≤ 1e8` 可暴力；再大必须找单调性（二分枚举）、结构（前缀和把区间和降到 O(1)）或剪枝。**"枚举 + 前缀和 + 哈希"** 是化简枚举的三板斧。

# 总结

- 枚举是所有算法的暴力基线，价值在于界定解空间与充当对拍标准；
- 提速靠**答案单调性（二分枚举）/单峰性（三分枚举）/剪枝**；
- 记住经验阈值：超过约 1e8 次操作就不能纯暴力，需换结构或思想。
