# 概述

前缀和与差分是一对**互逆**的区间工具：前缀和把「区间求和」预处理成 O(1) 查询，差分把「区间批量加减」预处理成 O(1) 修改，最后做一次前缀和还原即可。两者都以「多次查询/修改摊薄一次预处理」为核心思想。

- 时间复杂度：

  | 工具 | 预处理 | 单次操作 | 还原 |
  |------|:------:|:--------:|:----:|
  | 前缀和 | O(n) | 区间查询 O(1) | — |
  | 差分数组 | O(n) | 区间修改 O(1) | O(n) 一次前缀和 |

- 空间复杂度：O(n)（二维前缀和/差分为 O(nm)）
- 应用场景：
  - **前缀和**：LeetCode 560「和为 K 的子数组」、区间和/区间统计报表、`itertools.accumulate`（Python）、NumPy `cumsum`、图像处理中的**积分图**（Haar 特征、矩形区域求和）；
  - **二维前缀和**：矩阵区域和（LeetCode 304）、棋盘格任意子矩形快速求和；
  - **差分**：公交车/地铁多个上下客区间统计（LeetCode 1094）、航班预订汇总（1109）、区间染色、扫描线求区间覆盖次数；差分思想也是一维**差分约束**与图论最短路建模的基础。

**本篇收录**：一维前缀和、二维前缀和、差分数组

**动画：前缀和建表 → 区间查询，差分打点 → 还原**
<!-- dsa.assets/prefix-sum/prefix-diff.gif -->

以 `a = [3, 1, 4, 1, 5]` 为例：

1. **建前缀和**：`pre[i] = pre[i-1] + a[i-1]`，得到哨兵开头的 `[0, 3, 4, 8, 9, 14]`——`pre[i]` 表示前 `i` 个元素之和；
2. **区间查询**：求 `a[1..3] = 1+4+1` 的和，用 `pre[4] - pre[1] = 8 - 3 = 5`，两步相减即得，无需遍历；
3. **建差分数组**：`diff[i] = a[i] - a[i-1]`，得到 `[3, -2, 3, -3, 4]`（等价于对 `a` 做「减法」，与前缀和互为逆运算）；
4. **区间修改**：要给 `a[1..3]` 全部 `+2`，只需动两个端点——`diff[1] += 2`、`diff[4] -= 2`，O(1) 完成；
5. **还原**：对修改后的 `diff` 再做一次前缀和，得到 `[3, 1, 4, 1, 5] → [3, 3, 6, 3, 5]`，区间内元素恰好都加了 2，区间外不变。

# 详解

## 一维前缀和

核心公式（约定 `pre[0] = 0`，`pre` 长度 `n+1`）：

```text
pre[i] = a[0] + a[1] + ... + a[i-1]
sum(l, r] = pre[r] - pre[l]      // 半开区间，下标从 pre 的哨兵 0 起算
sum[l, r] = pre[r+1] - pre[l]    // 闭区间
```

哨兵 `pre[0] = 0` 让「从头开始的区间」不需要特判，是写出无边界 bug 代码的关键。

::: code-group

```java [Java]
public record PrefixSum(long[] pre) {
    public PrefixSum(int[] a) {
        this(new long[a.length + 1]);
        for (int i = 0; i < a.length; i++) {
            pre[i + 1] = pre[i] + a[i];
        }
    }
    // 闭区间 [l, r] 的和
    public long rangeSum(int l, int r) {
        return pre[r + 1] - pre[l];
    }
}
```

### 进阶：前缀和 + 哈希表

「和为 K 的子数组个数」无法用双指针（数组含负数），但可转化为：对每个 `j`，统计有多少个 `i < j` 满足 `pre[j] - pre[i] = K`，即查哈希表中 `pre[j] - K` 出现过的次数。这就是 LeetCode 560 的标准解法，O(n) 时间、O(n) 空间。

## 二维前缀和

设 `pre[i][j]` 为左上角 `(0,0)` 到 `(i-1,j-1)` 矩形内所有元素之和（同样带哨兵行列），则：

```text
构建：pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + a[i-1][j-1]
查询：sum = pre[r2+1][c2+1] - pre[l1][c2+1] - pre[r2+1][c1] + pre[l1][c1]
```

构建时减去重叠的左上角小矩形（容斥原理），查询时两个大条相减会把左上角小矩形多减一次，再加回来。

::: code-group

```java [Java]
public record Matrix2DPrefix(long[][] pre) {
    public Matrix2DPrefix(int[][] a) {
        this(new long[a.length + 1][a[0].length + 1]);
        for (int i = 1; i < pre.length; i++) {
            for (int j = 1; j < pre[0].length; j++) {
                pre[i][j] = pre[i - 1][j] + pre[i][j - 1]
                        - pre[i - 1][j - 1] + a[i - 1][j - 1];
            }
        }
    }
    // 左上角到右下角的闭区间矩形和
    public long rangeSum(int r1, int c1, int r2, int c2) {
        return pre[r2 + 1][c2 + 1] - pre[r1][c2 + 1]
                - pre[r2 + 1][c1] + pre[r1][c1];
    }
}
```

    }

      }
    }
  }

    return this.pre[r2 + 1][c2 + 1] - this.pre[r1][c2 + 1]
      - this.pre[r2 + 1][c1] + this.pre[r1][c1];
  }
}

                - self.pre[r2 + 1][c1] + self.pre[r1][c1])

## 差分数组

差分数组 `diff` 是原数组的「逆前缀和」：对区间 `[l, r]` 全体加 `v`，只需 `diff[l] += v`、`diff[r+1] -= v`（当 `r+1 < n`）。所有修改完成后做一次前缀和还原，得到最终数组。

适用判定：**多次区间修改 + 最后一次查询**。若需要「边改边查」任意区间和，差分无能为力，要上[线段树与树状数组](../03.树结构/070.线段树与树状数组.md)。

::: code-group

```java [Java]
public class DifferenceArray {
    private final long[] diff;
    public DifferenceArray(int[] a) {
        diff = new long[a.length + 1];          // 多开一位容纳 r+1 哨兵
        for (int i = 0; i < a.length; i++) {
            diff[i + 1] = a[i] - (i == 0 ? 0 : a[i - 1]);
        }
    }
    // 闭区间 [l, r] 全体 +v
    public void add(int l, int r, long v) {
        diff[l] += v;
        diff[r + 1] -= v;
    }
    // 前缀和还原最终数组
    public long[] restore() {
        long[] res = new long[diff.length - 1];
        long cur = 0;
        for (int i = 0; i < res.length; i++) {
            cur += diff[i];
            res[i] = cur;
        }
        return res;
    }
}
```

```rust [Rust]
pub struct DiffArray {
    diff: Vec<i64>,
}

impl DiffArray {
    pub fn new(a: &[i32]) -> Self {
        let mut diff = vec![0i64; a.len() + 1];
        for i in 0..a.len() {
            diff[i + 1] = a[i] as i64 - if i == 0 { 0 } else { a[i - 1] as i64 };
        }
        Self { diff }
    }
    /// 闭区间 [l, r] 全体 +v
    pub fn add(&mut self, l: usize, r: usize, v: i64) {
        self.diff[l] += v;
        self.diff[r + 1] -= v;
    }
    /// 前缀和还原最终数组
    pub fn restore(&self) -> Vec<i64> {
        let mut res = Vec::with_capacity(self.diff.len() - 1);
        let mut cur = 0i64;
        for &d in &self.diff[..self.diff.len() - 1] {
            cur += d;
            res.push(cur);
        }
        res
    }
}
```

```python [Python]
class DiffArray:
    def __init__(self, a: list[int]):
        self.diff = [0] * (len(a) + 1)   # 多开一位容纳 r+1 哨兵
        for i, x in enumerate(a):
            self.diff[i + 1] = x - (a[i - 1] if i else 0)

    def add(self, l: int, r: int, v: int) -> None:
        """闭区间 [l, r] 全体 +v"""
        self.diff[l] += v
        self.diff[r + 1] -= v

    def restore(self) -> list[int]:
        """前缀和还原最终数组"""
        res, cur = [], 0
        for d in self.diff[:-1]:
            cur += d
            res.append(cur)
        return res
```

## 常见陷阱

- **哨兵位与开闭区间要全程统一**：前缀和用 `pre[0]=0`、`sum[l,r] = pre[r+1]-pre[l]`；差分多开一位 `diff[n]` 存「-v」。混用下标是最高频 bug 来源。
- **数值溢出**：前缀和累加易爆 int，Java/Rust 中用 `long`/`i64` 存储；Python 无此问题。
- **差分不支持动态查询**：差分只在「全部修改结束后」还原一次有效；修改与查询交错时改用树状数组/线段树。
- **二维差分**同样存在：`rect(l1,c1,r2,c2) += v` 打四个角——`d[l1][c1]+=v, d[r2+1][c1]-=v, d[l1][c2+1]-=v, d[r2+1][c2+1]+=v`，还原时做两次前缀和（先行后列）。
- **静态数组才划算**：数组频繁增删元素时前缀和要整体重建（O(n)），此时考虑树状数组等动态结构。

# 总结

- 前缀和与差分互为逆运算：一个把「区间查询」降为 O(1)，一个把「区间修改」降为 O(1)，本质都是用「一次累积/打点」换「多次操作」；
- 哨兵位 `pre[0]=0` 与差分数组多开一位，是避免边界特判、写出干净代码的关键；
- 选择依据：只查不改用前缀和，只改不（中间）查用差分，边改边查上线段树/树状数组。
