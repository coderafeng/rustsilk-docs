# 概述

插入排序（Insertion Sort）像整理扑克牌：把当前元素插入到**左侧已排序区间的正确位置**，其后元素整体右移让位。对近乎有序或小规模数据表现极佳。

- 时间复杂度：最好 **O(n)**（已有序）、平均/最坏 **O(n²)**
- 空间复杂度：O(1)
- 稳定性：**稳定**
- 应用场景：小规模数据、近乎有序的数据；是**希尔排序**与工业级 **TimSort** 的底层小组件（小区间切给插入排序）。

# 图解

**动画：把 a[i] 插入左侧有序区** <!-- dsa.assets/sort/insertion.gif -->

1. 取出 `key = a[i]`，`j = i-1`；
2. 只要 `a[j] > key` 就把 `a[j]` 右移一格、`j--`；
3. 找到 `a[j] <= key` 的位置，把 `key` 放入 `j+1`；
4. i 右移重复。

# 详解

::: code-group
```java [Java]
void insertionSort(int[] a) {
    for (int i = 1; i < a.length; i++) {
        int key = a[i], j = i - 1;
        while (j >= 0 && a[j] > key) { a[j + 1] = a[j]; j--; } // 整体后移
        a[j + 1] = key;
    }
}
```
```rust [Rust]
fn insertion_sort(a: &mut [i32]) {
    for i in 1..a.len() {
        let key = a[i];
        let mut j = i;
        while j > 0 && a[j - 1] > key { a[j] = a[j - 1]; j -= 1; }
        a[j] = key;
    }
}
```

```python [Python]
def insertion_sort(a):
    for i in range(1, len(a)):
        key, j = a[i], i - 1
        while j >= 0 and a[j] > key:
            a[j + 1] = a[j]; j -= 1
        a[j + 1] = key
```

## 二分插入优化

定位插入点可用二分查找降到 O(log n) 比较，但**移动元素仍 O(n)**，故总复杂度不变，只是比较更少——适合比较代价高的场景。

# 总结

- 插入排序：把 a[i] 插入左侧有序区，右移让位；
- **稳定、原地、最好 O(n)**，对近乎有序/小数组是常数级最优解；
- 因此被 TimSort/希尔采纳为"小区间收尾"武器，也是理解增量排序思路的基础。
