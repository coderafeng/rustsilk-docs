# 概述

基数排序（Radix Sort）**不做比较**，而是按数字的每一位（个位、十位……从低位到高位 LSD，或从高位到低位 MSD）**依次用稳定的计数排序**分发再收集，若干轮后整体有序。适合定长键（整数、定长字符串）。

- 时间复杂度：**O(d·(n + k))**（d 为最大位数，k 为基数/进制，常取 10 或 256）
- 空间复杂度：O(n + k)
- 稳定性：**稳定**（每一位都依赖稳定的子排序）
- 应用场景：整数/字符串字典序、定长记录（学号、日期）、按字节的多关键字排序。

1. 以个位为关键字，用计数排序把数组按个位重排；
2. 以十位为关键字，**再次稳定排序**（个位次序得以保留）；
3. 依次处理百位、千位……直到最高位；
4. 每一轮"稳定"是全局最终有序的前提。

# 详解

::: code-group
```java [Java]
void radixSortLSD(int[] a) {
    int max = a[0];
    for (int x : a) max = Math.max(max, x);
    for (int exp = 1; max / exp > 0; exp *= 10) {   // 逐位（十进制）
        int[] out = new int[a.length];
        int[] cnt = new int[10];
        for (int x : a) cnt[(x / exp) % 10]++;
        for (int i = 1; i < 10; i++) cnt[i] += cnt[i - 1];
        for (int i = a.length - 1; i >= 0; i--) {    // 逆序保稳定
            int d = (a[i] / exp) % 10;
            out[--cnt[d]] = a[i];
        }
        System.arraycopy(out, 0, a, 0, a.length);
    }
}
```
```rust [Rust]
fn radix_sort_lsd(a: &mut [u32]) {
    let &mx = a.iter().max().unwrap_or(&0);
    let mut exp = 1u32;
    while mx / exp > 0 {
        let mut buckets = vec![Vec::new(); 10];
        for &x in a.iter() { buckets[((x / exp) % 10) as usize].push(x); }
        let mut k = 0;
        for b in buckets.iter() { for &x in b.iter() { a[k] = x; k += 1; } } // 桶内保持原序=稳定
        exp *= 10;
    }
}
```
```typescript [TypeScript]
function radixSortLSD(a: number[]): number[] {
    const max = Math.max(...a);
    for (let exp = 1; Math.floor(max / exp) > 0; exp *= 10) {
        const cnt = new Array(10).fill(0);
        const out = new Array(a.length);
        for (const x of a) cnt[Math.floor(x / exp) % 10]++;
        for (let i = 1; i < 10; i++) cnt[i] += cnt[i - 1];
        for (let i = a.length - 1; i >= 0; i--) {
            const d = Math.floor(a[i] / exp) % 10;
            out[--cnt[d]] = a[i];
        }
        a.splice(0, a.length, ...out);
    }
    return a;
}
```
```python [Python]
def radix_sort_lsd(a):
    if not a:
        return a
    exp = 1
    while max(a) // exp > 0:
        a = sorted(a, key=lambda x, e=exp: (x // e) % 10)  # Python sorted 稳定
        exp *= 10
    return a
```

## LSD vs MSD

- **LSD**（低位优先）：从最低位到最高位，每位稳定排序，适合**定长键**；
- **MSD**（高位优先）：从最高位递归分桶，适合**变长字符串**，但递归 + 小桶切换插入排序更复杂。

## 前提与非负

上述实现针对非负整数；含负数需先分离正负或做偏移；基数取 256（按字节）通常比取 10 轮次更少。

# 总结

- 基数排序：借**稳定**子排序逐位分发收集，O(d·(n+k)) 线性；
- 要求键可拆位且**每位排序必须稳定**；
- 与计数/桶排序构成"非比较三兄弟"，在定长整数/字符串上以空间换时间超越比较下界 O(n log n)。
