# 概述

希尔排序（Shell Sort）是插入排序的改进版：先按**间隔 gap** 把数组分成若干子序列各自插入排序，再逐步缩小 gap（常取 `gap = gap/3 + 1` 或 `gap/2`），最后 gap=1 时整体近乎有序，插入排序极快。它是**第一个突破 O(n²)** 的排序。

- 时间复杂度：取决于增量序列，介于 **O(n log n) 与 O(n²)** 之间（Knuth 序列约 O(n^1.5)）
- 空间复杂度：O(1)
- 稳定性：**不稳定**（跨间隔移动破坏次序）
- 应用场景：无额外内存、中等规模数据；嵌入式等对空间敏感场景。

1. 取 `gap = n/2`，对每个起点 `i in [gap, n)`，把 `a[i]` 在它所属的"间隔 gap 子序列"里做插入排序；
2. `gap /= 2` 或 `gap = gap/3+1` 后重复；
3. 最终 `gap = 1` 即普通插入排序，此时数组已近乎有序，一轮扫完。

# 详解

::: code-group
```java [Java]
void shellSort(int[] a) {
    int n = a.length;
    for (int gap = n / 2; gap > 0; gap /= 2) {
        for (int i = gap; i < n; i++) {
            int key = a[i], j = i - gap;
            while (j >= 0 && a[j] > key) { a[j + gap] = a[j]; j -= gap; }
            a[j + gap] = key;
        }
    }
}
```
```rust [Rust]
fn shell_sort(a: &mut [i32]) {
    let n = a.len();
    let mut gap = n / 2;
    while gap > 0 {
        for i in gap..n {
            let key = a[i];
            let mut j = i;
            while j >= gap && a[j - gap] > key { a[j] = a[j - gap]; j -= gap; }
            a[j] = key;
        }
        gap /= 2;
    }
}
```

    }
}

```python [Python]
def shell_sort(a):
    n = len(a)
    gap = n // 2
    while gap:
        for i in range(gap, n):
            key, j = a[i], i - gap
            while j >= 0 and a[j] > key:
                a[j + gap] = a[j]; j -= gap
            a[j + gap] = key
        gap //= 2
```

## 增量序列的影响

最坏 O(n²) 主要因 `gap = n/2` 序列存在公因数导致元素"互不相见"。改用 **Knuth(3x+1)**、**Sedgewick** 或 **Ciura** 序列可显著改善；但无论哪种都拿不到 O(n log n) 的确定保证。

# 总结

- 希尔排序 = **分组插入 + 间隔递减**，用"先粗后细"让数据提前基本有序；
- 原地、突破 O(n²)（经验约 O(n^1.5)），但**不稳定**、复杂度依赖增量序列；
- 是"预排序/基本有序"思想的鼻祖，理解了它就理解了 TimSort 为何先归并出有序 run。
