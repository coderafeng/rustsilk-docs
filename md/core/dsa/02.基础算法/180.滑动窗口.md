# 概述

滑动窗口（Sliding Window）维护一个随右边界推进、必要时收缩左边界的**动态区间**，用两个指针各扫一遍数组/字符串，把"满足某条件的连续子序列"问题从 O(n²) 降到 O(n)。它是双指针的特化。

- 时间复杂度：**O(n)**（每个元素至多进出窗口各一次）
- 空间复杂度：O(k)（窗口内用于计数的哈希/数组）
- 应用场景：最长/最短满足条件的子串或子数组、无重复字符最长子串、最小覆盖子串、定长窗口最值（配合单调队列）。

1. `right` 每步纳入一个新元素，更新窗口状态（计数/和）；
2. 当窗口**违反约束**（如出现重复、和超过 target），`left` 右移移出元素直到重新合法；
3. 每步在合法窗口上更新答案（最大长度 / 最小长度）。

# 详解

## 通用模板

```
left = 0
for right in 0..n:
    加入 a[right]，更新窗口状态
    while 窗口不合法:            # 收缩条件决定求"最长"还是"最短"
        移除 a[left]，left++
    用 [left, right] 更新答案
```

求**最长**在收缩后更新答案；求**最短**在满足条件时尽量收缩再更新。

## 例：无重复字符的最长子串

::: code-group
```java [Java]
int lengthOfLongestSubstring(String s) {
    Map<Character, Integer> cnt = new HashMap<>();
    int left = 0, ans = 0;
    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        cnt.merge(c, 1, Integer::sum);
        while (cnt.get(c) > 1) {                 // 有重复就缩左界
            char d = s.charAt(left++);
            cnt.merge(d, -1, Integer::sum);
        }
        ans = Math.max(ans, right - left + 1);
    }
    return ans;
}
```
```rust [Rust]
fn length_of_longest_substring(s: &str) -> usize {
    let bytes = s.as_bytes();
    let mut last = vec![-1i32; 128];              // ASCII：记录字符上次位置
    let (mut left, mut ans) = (0i32, 0usize);
    for (right, &b) in bytes.iter().enumerate() {
        let r = right as i32;
        if last[b as usize] >= left { left = last[b as usize] + 1; }
        last[b as usize] = r;
        ans = ans.max((r - left + 1) as usize);
    }
    ans
}
```
```typescript [TypeScript]
function lengthOfLongestSubstring(s: string): number {
    const idx = new Map<string, number>();
    let left = 0, ans = 0;
    for (let right = 0; right < s.length; right++) {
        const c = s[right];
        if (idx.has(c) && idx.get(c)! >= left) left = idx.get(c)! + 1;
        idx.set(c, right);
        ans = Math.max(ans, right - left + 1);
    }
    return ans;
}
```
```python [Python]
def length_of_longest_substring(s):
    last, left, ans = {}, 0, 0
    for right, c in enumerate(s):
        if c in last and last[c] >= left:
            left = last[c] + 1
        last[c] = right
        ans = max(ans, right - left + 1)
    return ans
```

## 定长窗口与单调队列

固定长度 k 的窗口最值，可用**单调队列**（双端队列维护递减/递增）做到 O(n) 出每个窗口的最大/最小值，是"滑动窗口最大值"(LeetCode 239) 的标准解。

## 常见陷阱

- **收缩条件写反**：`while` 里的"不合法"判定决定求最长/最短，写错则答案全反。
- **计数清理时机**：left 右移时必须同步移除旧元素的贡献，否则窗口状态脏。

# 总结

- 滑动窗口 = 双指针 + 窗口状态增量维护，把连续子区间问题降到 O(n)；
- 核心是**收缩条件**（何时动左界）与**答案更新时机**（缩前还是缩后）；
- 定长最值升级为单调队列，是最值型滑动窗口的通解。
