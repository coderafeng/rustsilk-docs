# 概述

选择排序（Selection Sort）每轮从未排序区间**选出最小值的下标**，与未排序区间首位交换，使已排序区间从左到右逐步增长。它是**交换次数最少**的 O(n²) 排序。

- 时间复杂度：最好/平均/最坏均 **O(n²)**（比较次数固定）
- 空间复杂度：O(1)
- 稳定性：**不稳定**（跨距离交换会打乱相等元素次序）
- 应用场景：交换代价高、比较代价低的场景（每轮只交换一次）。

1. 设 `min = i`，扫描 `i+1..n` 找更小的元素更新 `min`；
2. 扫描结束若 `min != i`，交换 `a[i]` 与 `a[min]`；
3. `i` 右移，已排序前缀加长。

# 详解

::: code-group
```java [Java]
void selectionSort(int[] a) {
    for (int i = 0; i < a.length - 1; i++) {
        int min = i;
        for (int j = i + 1; j < a.length; j++) if (a[j] < a[min]) min = j;
        if (min != i) { int t = a[i]; a[i] = a[min]; a[min] = t; }
    }
}
```
```rust [Rust]
fn selection_sort(a: &mut [i32]) {
    let n = a.len();
    for i in 0..n.saturating_sub(1) {
        let mut min = i;
        for j in i + 1..n { if a[j] < a[min] { min = j; } }
        if min != i { a.swap(i, min); }
    }
}
```
```typescript [TypeScript]
function selectionSort(a: number[]): void {
```

```python [Python]
def selection_sort(a):
    n = len(a)
    for i in range(n - 1):
        m = min(range(i, n), key=a.__getitem__)
        if m != i:
            a[i], a[m] = a[m], a[i]
```

## 不稳定的例子

`[5a, 5b, 2]` 第一轮把 2 与 5a 交换 → `[2, 5b, 5a]`，两个 5 的相对次序被打破。

# 总结

- 选择排序：每轮选最小、一次交换；比较 O(n²) 固定、**交换最少 O(n)**；
- **不稳定**，不适合相等元素需保序的场景；
- 优点是实现简单、写入次数可控（闪存的写放大考量下偶有使用）。
