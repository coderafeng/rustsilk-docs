# 概述

二分查找（Binary Search）在**有序**数组上每次比较中间元素、把搜索区间折半，O(log n) 定位目标。看似简单，边界与"查找变体"却是全场最高频的 bug 源。

- 时间复杂度：**O(log n)**；空间 O(1)（迭代版）
- 前提：数据有序，或答案具备**单调性**可被判定
- 应用场景：有序数组查找、求平方根、二分答案（最小化最大值）、`lower_bound`/`upper_bound`。

**本篇收录**：标准二分、左边界二分（lower_bound）、右边界二分（upper_bound）

1. `lo=0, hi=n-1`，取 `mid = lo + (hi-lo)/2`（防溢出）；
2. `a[mid] == target` 命中；
3. `a[mid] < target` → 弃左半，`lo = mid+1`；否则 `hi = mid-1`；
4. 直到 `lo > hi` 区间为空。

# 详解

## 三种形态

- **标准二分**：找是否存在，命中即返回；
- **左边界（lower_bound）**：找第一个 `>= target` 的位置——即使有重复也能定位插入点；
- **右边界（upper_bound）**：找第一个 `> target` 的位置；二者相减即 target 出现次数。

**统一心法**：把循环写成"区间 `[lo, hi)` 左闭右开 + `hi = mid` 收缩"，可无脑处理边界，不易错。

::: code-group
```java [Java]
// 左边界：第一个 >= target 的下标（等价 Collections 里没有，需手写 / Arrays.binarySearch 变体）
int lowerBound(int[] a, int target) {
    int lo = 0, hi = a.length;                 // [lo, hi)
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] < target) lo = mid + 1; else hi = mid;
    }
    return lo;                                  // 第一个 >= target
}
int upperBound(int[] a, int target) {           // 第一个 > target
    int lo = 0, hi = a.length;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] <= target) lo = mid + 1; else hi = mid;
    }
    return lo;
}
```
```rust [Rust]
// 标准库直接提供二分（Rust 1.52+）
fn lower_bound(a: &[i32], target: i32) -> usize {
    a.partition_point(|&x| x < target)          // 第一个 >= target
}
fn binary_search(a: &[i32], target: i32) -> Option<usize> {
    a.binary_search(&target).ok()               // 内置：Result<usize, usize>
}
```
```typescript [TypeScript]
function lowerBound(a: number[], target: number): number {
    let lo = 0, hi = a.length;
    while (lo < hi) {
        const mid = (lo + hi) >> 1;
        if (a[mid] < target) lo = mid + 1; else hi = mid;
    }
    return lo;
}
```
```python [Python]
import bisect
def lower_bound(a, target):
    return bisect.bisect_left(a, target)    # 第一个 >= target
def upper_bound(a, target):
    return bisect.bisect_right(a, target)   # 第一个 > target
# 次数 = bisect_right - bisect_left
```
:::

## 三大经典坑

1. **mid 溢出**：必须 `lo + (hi-lo)/2`，不能 `(lo+hi)/2`（Java/C++ int 溢出）；
2. **死循环**：区间更新若 `lo = mid`（而非 `mid+1`）在 `hi = lo+1` 时会原地踏步；
3. **循环不变量**：闭区间 `[lo,hi]` 用 `lo<=hi`，左闭右开 `[lo,hi)` 用 `lo<hi`——混用必错。

# 总结

- 二分靠**有序/单调判定**把 O(n) 降到 O(log n)，重复元素用**左右边界**精确框定；
- 难点全在**边界**：防溢出 mid、区间开闭与循环条件一致、收缩步长 +1；
- 进阶形态"**二分答案**"把"求最值"转成"判定某答案是否可行"，是竞赛与工程的高频套路。
