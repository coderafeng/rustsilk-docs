# 概述

计数排序（Counting Sort）不开比较，而是**统计每个值出现的次数**，再按值域顺序还原。适用于**整数且取值范围 k 不大**的场景，是 O(n+k) 的线性排序。

- 时间复杂度：**O(n + k)**（k 为值域大小）
- 空间复杂度：O(k)（计数数组）
- 稳定性：**稳定**（配合输出数组从后往前放置）
- 应用场景：年龄/分数/字符 ASCII 等小值域整数排序，也是**基数排序**的一轮内部排序。

**动画：计数 → 前缀和 → 回填** <!-- dsa.assets/sort/counting.gif -->

1. 遍历输入，`cnt[v]++` 统计每个值出现次数；
2. 对 `cnt` 求**前缀和**，得到每个值在输出中的结束位置；
3. **从后往前**遍历原数组，把每个元素放到 `cnt[v]-1` 处并 `cnt[v]--`（从后保证稳定）；
4. 输出数组即有序。

# 详解

::: code-group
```java [Java]
void countingSort(int[] a) {
    int max = a[0], min = a[0];
    for (int x : a) { max = Math.max(max, x); min = Math.min(min, x); }
    int[] cnt = new int[max - min + 1];
    for (int x : a) cnt[x - min]++;               // 偏移 min 处理负数
    for (int i = 1; i < cnt.length; i++) cnt[i] += cnt[i - 1]; // 前缀和
    int[] out = new int[a.length];
    for (int i = a.length - 1; i >= 0; i--) {      // 逆序保证稳定
        int v = a[i] - min;
        out[--cnt[v]] = a[i];
    }
    System.arraycopy(out, 0, a, 0, a.length);
}
```
```rust [Rust]
fn counting_sort(a: &mut [usize]) {
    let &max = a.iter().max().unwrap_or(&0);
    let mut cnt = vec![0usize; max + 1];
    for &x in a.iter() { cnt[x] += 1; }
    let mut k = 0;
    for (v, &c) in cnt.iter().enumerate() {
        for _ in 0..c { a[k] = v; k += 1; }        // 直接按值域展开回写
    }
}
```
```typescript [TypeScript]
function countingSort(a: number[]): number[] {
    const max = Math.max(...a), min = Math.min(...a);
    const cnt = new Array(max - min + 1).fill(0);
    for (const x of a) cnt[x - min]++;
    const out: number[] = [];
    for (let i = 0; i < cnt.length; i++)
        for (let c = 0; c < cnt[i]; c++) out.push(i + min);
    return out;
}
```
```python [Python]
def counting_sort(a):
    if not a:
        return a
    lo, hi = min(a), max(a)
    cnt = [0] * (hi - lo + 1)
    for x in a:
        cnt[x - lo] += 1
    out, i = [], 0
    for v, c in enumerate(cnt):
        out.extend([v + lo] * c)
    return out
```

## 与普通版 vs 前缀和版

只关心"结果多重排序"可直接按值域展开（如上 Rust/Python 版）；需要**稳定**且携带附属信息时，必须用**前缀和 + 逆序回填**。

# 总结

- 计数排序：统计频次 + 前缀和定位，**O(n+k) 线性、稳定**；
- 前提是值域 k 与 n 同阶，k 过大（如 32 位全整数）内存爆炸则不可用；
- 它是基数排序的"单位稳定内核"。
