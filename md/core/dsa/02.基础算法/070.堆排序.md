# 概述

堆排序（Heap Sort）先把数组建成**大顶堆**，再反复"取堆顶（最大值）与末尾交换、缩小堆、下沉调整"，从而原地排序。它保证最坏 O(n log n) 且不需额外空间。

- 时间复杂度：最好/平均/最坏均 **O(n log n)**
- 空间复杂度：O(1)，原地
- 稳定性：**不稳定**
- 应用场景：需要**最坏保证 + 原地**的场景、Top-K（用小顶堆，见 [03.树结构/030.堆与优先队列](../03.树结构/030.堆与优先队列.md)）、IntroSort 里作快排退化后的兜底。

- 所属章节：[000.基础算法概述](./000.基础算法概述.md)

1. **建堆**：从最后一个非叶节点 `n/2-1` 往前逐个 `siftDown`，O(n) 建成大顶堆；
2. 堆顶（最大）与当前末尾交换，堆尺寸 -1（末尾已就位于全局最大）；
3. 对新堆顶 `siftDown` 恢复堆序；
4. 重复 2-3 直到堆空，数组即升序。

# 详解

::: code-group
```java [Java]
void heapSort(int[] a) {
    int n = a.length;
    for (int i = n / 2 - 1; i >= 0; i--) siftDown(a, i, n);   // O(n) 建大顶堆
    for (int end = n - 1; end > 0; end--) {
        int t = a[0]; a[0] = a[end]; a[end] = t;              // 堆顶换到已排序区
        siftDown(a, 0, end);                                  // 在缩小后的堆里下沉
    }
}
void siftDown(int[] a, int i, int n) {
    while (2 * i + 1 < n) {
        int child = 2 * i + 1;
        if (child + 1 < n && a[child + 1] > a[child]) child++; // 取较大子
        if (a[i] >= a[child]) break;
        int t = a[i]; a[i] = a[child]; a[child] = t;
        i = child;
    }
}
```
```rust [Rust]
fn sift_down(a: &mut [i32], mut i: usize, n: usize) {
    loop {
        let l = 2 * i + 1;
        if l >= n { break; }
        let r = l + 1;
        let mut big = l;
        if r < n && a[r] > a[l] { big = r; }
        if a[i] >= a[big] { break; }
        a.swap(i, big);
        i = big;
    }
}
fn heap_sort(a: &mut [i32]) {
    let n = a.len();
    for i in (0..n / 2).rev() { sift_down(a, i, n); }
    for end in (1..n).rev() { a.swap(0, end); sift_down(a, 0, end); }
}
```
```typescript [TypeScript]
function heapSort(a: number[]): void {
    const n = a.length;
    const sift = (i: number, size: number) => {
        while (2 * i + 1 < size) {
            let c = 2 * i + 1;
            if (c + 1 < size && a[c + 1] > a[c]) c++;
            if (a[i] >= a[c]) break;
            [a[i], a[c]] = [a[c], a[i]];
            i = c;
        }
    };
    for (let i = (n >> 1) - 1; i >= 0; i--) sift(i, n);
    for (let end = n - 1; end > 0; end--) { [a[0], a[end]] = [a[end], a[0]]; sift(0, end); }
}
```
```python [Python]
def heap_sort(a):
    n = len(a)
    def sift(i, size):
        while 2 * i + 1 < size:
            c = 2 * i + 1
            if c + 1 < size and a[c + 1] > a[c]:
                c += 1
            if a[i] >= a[c]:
                break
            a[i], a[c] = a[c], a[i]
            i = c
    for i in range(n // 2 - 1, -1, -1):
        sift(i, n)
    for end in range(n - 1, 0, -1):
        a[0], a[end] = a[end], a[0]
        sift(0, end)
```

## 建堆为什么是 O(n)

对高度 h 的层，节点数约 n/2^(h+1)，每节点下沉代价 O(h)，求和 `Σ n·h/2^(h+1) = O(n)`（错位相减），并非直觉的 O(n log n)。

# 总结

- 堆排序：建大顶堆 + 反复取顶下沉，**O(n log n) 最坏保证、O(1) 原地**；
- **不稳定**，缓存不友好（跳跃访问），实测常数比快排大，故通用排序里多作兜底；
- 与"优先队列/Top-K"共用同一套堆调整逻辑，是堆结构最直接的应用。
