# 概述

双指针（Two Pointers）用**两个下标协同移动**代替嵌套循环，把 O(n²) 降到 O(n)。两大流派：**对撞指针**（有序数组两端向中间）与**快慢指针**（同向、速度不同，用于链表判环/原地去重）。

- 时间复杂度：多数问题从 O(n²) 优化到 **O(n)**
- 空间复杂度：O(1)，原地
- 应用场景：两数之和（有序）、盛水最多的容器、链表判环与找环入口、原地移除元素、回文判定。

**本篇收录**：对撞指针、快慢指针

# 详解

## 对撞指针：两数之和（有序）

::: code-group
```java [Java]
int[] twoSumSorted(int[] a, int target) {
    int l = 0, r = a.length - 1;
    while (l < r) {
        int s = a[l] + a[r];
        if (s == target) return new int[]{l, r};
        if (s < target) l++; else r--;
    }
    return new int[]{-1, -1};
}
```
```rust [Rust]
fn two_sum_sorted(a: &[i32], target: i32) -> Option<(usize, usize)> {
    let (mut l, mut r) = (0, a.len() - 1);
    while l < r {
        let s = a[l] + a[r];
        if s == target { return Some((l, r)); }
        if s < target { l += 1; } else { r -= 1; }
    }
    None
}
```
```typescript [TypeScript]
function twoSumSorted(a: number[], target: number): [number, number] | [-1, -1] {
    let l = 0, r = a.length - 1;
    while (l < r) {
        const s = a[l] + a[r];
        if (s === target) return [l, r];
        if (s < target) l++; else r--;
    }
    return [-1, -1];
}
```
```python [Python]
def two_sum_sorted(a, target):
    l, r = 0, len(a) - 1
    while l < r:
        s = a[l] + a[r]
        if s == target:
            return l, r
        if s < target:
            l += 1
        else:
            r -= 1
    return -1, -1
```

## 快慢指针：链表判环

快慢指针是链表专属技巧（见 [01.基础数据结构/030.链表](../01.基础数据结构/030.链表.md)）。`fast` 每次两步、`slow` 一步，`fast` 能追上有环、`null` 则无环；数学可证再相遇点为环入口。

## 常见陷阱

- **移动方向与终止条件**：对撞要 `l < r`，快慢要防 `fast.next` 为空时再走两步导致空指针——先判 `fast && fast.next`。
- **别用于无序**：对撞指针依赖有序或单调性，乱序需先排序或换哈希。

# 总结

- 双指针把"两个位置的组合"从 O(n²) 压到 O(n)，前提是**移动具有单调/不回头性**；
- 对撞指针用于有序区间配对，快慢指针用于链表环/原地去重；
- 与滑动窗口（[180](./180.滑动窗口.md)）同源，都是"用两个游标的相对运动编码状态"。
