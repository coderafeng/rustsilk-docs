# 概述

冒泡排序（Bubble Sort）反复遍历数组，**比较相邻两元素、逆序则交换**，每一轮把当前未排序部分的最大值"冒泡"到右端。它是最直观的排序，价值在教学而非性能。

- 时间复杂度：最好 **O(n)**（已有序 + 提前退出优化）、平均/最坏 **O(n²)**
- 空间复杂度：O(1)，原地
- 稳定性：**稳定**（相等不交换）
- 应用场景：教学演示、数据规模极小或近乎有序的场景；"相邻交换"思想在链表局部调整中复用。

4. 若整轮**无交换**则提前退出（已有序）。

# 详解

## 关键优化：提前退出

加一个 `swapped` 标志，若某轮没发生任何交换，说明已有序，直接结束——把最好情况从 O(n²) 拉到 O(n)。

::: code-group
```java [Java]
void bubbleSort(int[] a) {
    for (int i = a.length - 1; i > 0; i--) {
        boolean swapped = false;
        for (int j = 0; j < i; j++) {
            if (a[j] > a[j + 1]) { int t = a[j]; a[j] = a[j + 1]; a[j + 1] = t; swapped = true; }
        }
        if (!swapped) break; // 本轮无交换 → 已有序
    }
}
```
```rust [Rust]
fn bubble_sort(a: &mut [i32]) {
    let n = a.len();
    for i in (1..n).rev() {
        let mut swapped = false;
        for j in 0..i {
            if a[j] > a[j + 1] { a.swap(j, j + 1); swapped = true; }
        }
        if !swapped { break; }
    }
}
```
```typescript [TypeScript]
function bubbleSort(a: number[]): void {
    for (let i = a.length - 1; i > 0; i--) {
        let swapped = false;
        for (let j = 0; j < i; j++) {
            if (a[j] > a[j + 1]) { [a[j], a[j + 1]] = [a[j + 1], a[j]]; swapped = true; }
        }
        if (!swapped) break;
    }
}
```
```python [Python]
def bubble_sort(a):
    n = len(a)
    for i in range(n - 1, 0, -1):
        swapped = False
        for j in range(i):
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
                swapped = True
        if not swapped:
            break
```

## 常见陷阱

- **比较符号与稳定性**：必须用严格 `>` 而非 `>=`，相等不交换才稳定。
- **边界**：内层 `j < i`，每轮比较范围递减，越界或多比都错。

# 总结

- 冒泡：相邻比较交换，每轮定一个最大值到尾部；
- O(n²) 但**稳定、原地**，加提前退出后最好 O(n)；
- 实践几乎不用，但它是理解"交换类排序"和稳定性概念的起点。
