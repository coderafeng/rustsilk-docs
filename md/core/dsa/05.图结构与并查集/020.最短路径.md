# 概述

最短路径按查询范围分**单源**（一个起点到所有点：Dijkstra、Bellman-Ford）与**多源**（任意两点：Floyd）。三者代表三种思想：Dijkstra 是**贪心**（每步敲定最近未定点）、Bellman-Ford 是**松弛迭代**（可处理负权、能查负环）、Floyd 是**动态规划**（经中间点 k 改善 i→j）——把 [04.核心算法思想](../04.核心算法思想/000.核心算法思想概述.md) 的三大范式在图上各落了一子。

**本篇收录**：Dijkstra、Bellman-Ford、Floyd

- 所属章节：[000.图结构与并查集概述](./000.图结构与并查集概述.md)

- 选型对照：

  | 算法 | 适用 | 时间 | 负权 | 思想 |
  |------|------|:----:|:----:|------|
  | Dijkstra（堆优化） | 单源、**非负权** | O((V+E) log V) | ❌ | 贪心 + 优先队列 |
  | Dijkstra（朴素） | 单源、稠密非负 | O(V²) | ❌ | 贪心 + 线性找最小 |
  | Bellman-Ford | 单源、**可负权**、查负环 | O(V·E) | ✅ | 反复松弛全部边 |
  | SPFA（队列优化 BF） | 单源、负权，均摊快 | 最坏 O(V·E) | ✅ | 队列 + in-queue 剪枝 |
  | Floyd | **多源**、稠密/V 小 | O(V³) | ✅（无负环） | 区间型 DP |

- 应用场景：地图导航路网（Dijkstra/A\*，见 [110.A星与启发式搜索](../04.核心算法思想/110.A星与启发式搜索.md)）、IP 路由（OSPF 用 Dijkstra、距离矢量协议用 Bellman-Ford 家族）、汇率套利检测（负环）、网络延迟计算、VLSI 布线、游戏 AI 寻路、社交网络最短关系链（BFS=Dijkstra 特例）、 Floyd 用于传递闭包与小型全对问题。

**动画：Dijkstra——从源向外「敲定」节点**
<!-- dsa.assets/shortest-path/dijkstra.gif -->

带权非负图，源 s：

1. 初始化 `dist[s]=0`，其余 `∞`；全部点入优先队列（按 dist）；
2. 弹出 dist 最小的未定点 u（初始是 s），**敲定**它——因无负权，此刻 `dist[u]` 已是最终最短路（贪心选择性质）；
3. **松弛** u 的每条出边 `(u,v,w)`：若 `dist[u]+w < dist[v]` 则更新并入队；
4. 重复 2-3：每次敲定的点恰是「离源最近且尚未敲定」的，敲定顺序即 dist 单调不减；
5. 遇到已在队列里更小的旧条目用惰性删除跳过（`if d > dist[u] continue`）；全部点敲定即得单源最短路树。

**动画：Bellman-Ford——V-1 轮全边松弛**
<!-- dsa.assets/shortest-path/bellman-ford.gif -->

1. 同样 `dist[s]=0` 其余 `∞`；
2. 每一轮**遍历所有边**做一次松弛——一轮结束至少让「跳数 ≤1」的点多走一步正确；
3. 最短路至多 V-1 条边 ⇒ 松弛 V-1 轮后所有 dist 必收敛；
4. **额外再扫一轮**：若仍有边能被松弛 ⇒ 存在**负权环**（最短路可无限降，无解）——这是 BF 独有的负环检测能力。

# 详解

## Dijkstra（堆优化，非负权单源）

::: code-group

```java [Java]
// 邻接表存 (to, weight)；返回 dist[]，负权图不要用
int[] dijkstra(List<int[]>[] adj, int s) {
    int n = adj.length;
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[s] = 0;
    // 小顶堆按 dist；节点重复入队，靠弹出时惰性删除
    var pq = new java.util.PriorityQueue<int[]>((a, b) -> a[0] - b[0]);
    pq.offer(new int[]{0, s});
    while (!pq.isEmpty()) {
        int[] cur = pq.poll();
        int d = cur[0], u = cur[1];
        if (d > dist[u]) continue;              // 陈旧条目
        for (int[] e : adj[u]) {                // e = {v, w}
            int v = e[0], w = e[1];
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.offer(new int[]{dist[v], v});
            }
        }
    }
    return dist;
}
```

```rust [Rust]
use std::collections::{BinaryHeap, HashMap};
use std::cmp::Reverse;

pub fn dijkstra(adj: &HashMap<usize, Vec<(usize, i64)>>, s: usize, n: usize) -> Vec<i64> {
    let mut dist = vec![i64::MAX; n];
    dist[s] = 0;
    let mut pq = BinaryHeap::new();
    pq.push(Reverse((0i64, s)));                 // 小顶堆按 dist
    while let Some(Reverse((d, u))) = pq.pop() {
        if d > dist[u] { continue; }             // 惰性删除
        if let Some(edges) = adj.get(&u) {
            for &(v, w) in edges {
                if dist[u] + w < dist[v] {
                    dist[v] = dist[u] + w;
                    pq.push(Reverse((dist[v], v)));
                }
            }
        }
    }
    dist
}
```

```typescript [TypeScript]
function dijkstra(adj: [number, number][][], s: number): number[] {
  const n = adj.length, dist = new Array(n).fill(Infinity);
  dist[s] = 0;
  // 教学用简单堆：数组 sort；生产换二叉堆/优先队列库
  const pq: [number, number][] = [[0, s]];
  while (pq.length) {
    pq.sort((a, b) => a[0] - b[0]);
    const [d, u] = pq.shift()!;
    if (d > dist[u]) continue;
    for (const [v, w] of adj[u]) {
      if (dist[u] + w < dist[v]) {
        dist[v] = dist[u] + w;
        pq.push([dist[v], v]);
      }
    }
  }
  return dist;
}
```

```python [Python]
import heapq

def dijkstra(adj, s):
    """adj[u] = [(v, w), ...]；要求非负权"""
    dist = {s: 0}
    pq = [(0, s)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist.get(u, float("inf")):        # 惰性删除陈旧条目
            continue
        for v, w in adj[u]:
            nd = d + w
            if nd < dist.get(v, float("inf")):
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist
```

## Bellman-Ford（负权 + 负环检测）

::: code-group

```java [Java]
// edges 存 (u, v, w)；返回 null 表示存在负环
double[] bellmanFord(int[][] edges, int n, int s) {
    double[] dist = new double[n];
    java.util.Arrays.fill(dist, Double.POSITIVE_INFINITY);
    dist[s] = 0;
    for (int round = 0; round < n - 1; round++) {       // V-1 轮
        boolean any = false;
        for (int[] e : edges) {
            int u = e[0], v = e[1]; double w = e[2];
            if (dist[u] != Double.POSITIVE_INFINITY && dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w; any = true;
            }
        }
        if (!any) break;                                // 提前收敛
    }
    for (int[] e : edges) {                             // 第 V 轮仍可松弛 ⇒ 负环
        if (dist[e[0]] + e[2] < dist[e[1]]) return null;
    }
    return dist;
}
```

```python [Python]
def bellman_ford(edges, n, s):
    """edges = [(u,v,w), ...]；返回 dist，负环返回 None"""
    INF = float("inf")
    dist = [INF] * n
    dist[s] = 0
    for _ in range(n - 1):                 # V-1 轮全边松弛
        updated = False
        for u, v, w in edges:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                updated = True
        if not updated:
            break
    for u, v, w in edges:                  # 再一轮仍可松弛 ⇒ 负环
        if dist[u] + w < dist[v]:
            return None
    return dist
```

```rust [Rust]
pub fn bellman_ford(edges: &[(usize, usize, i64)], n: usize, s: usize) -> Option<Vec<i64>> {
    let mut dist = vec![i64::MAX; n];
    dist[s] = 0;
    for _ in 0..n - 1 {
        let mut updated = false;
        for &(u, v, w) in edges {
            if dist[u] != i64::MAX && dist[u] + w < dist[v] {
                dist[v] = dist[u] + w;
                updated = true;
            }
        }
        if !updated { break; }
    }
    for &(u, v, w) in edges {              // 负环检测
        if dist[u] != i64::MAX && dist[u] + w < dist[v] { return None; }
    }
    Some(dist)
}
```

```typescript [TypeScript]
function bellmanFord(edges: [number, number, number][], n: number, s: number): number[] | null {
  const dist = new Array(n).fill(Infinity);
  dist[s] = 0;
  for (let round = 0; round < n - 1; round++) {
    let updated = false;
    for (const [u, v, w] of edges) {
      if (dist[u] + w < dist[v]) { dist[v] = dist[u] + w; updated = true; }
    }
    if (!updated) break;
  }
  for (const [u, v, w] of edges) {         // 第 V 轮仍可松弛 ⇒ 负环
    if (dist[u] + w < dist[v]) return null;
  }
  return dist;
}
```

## Floyd-Warshall（多源，三重循环 DP）

`dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])`，**k 必须在最外层**（k 是「允许作为中间点」的阶段维度）。

::: code-group

```java [Java]
// dist 为 V×V 邻接矩阵初始化（无边为 INF，dist[i][i]=0）
void floyd(int[][] dist) {
    int n = dist.length;
    int INF = Integer.MAX_VALUE;
    for (int k = 0; k < n; k++)                       // k 最外层！
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                if (dist[i][k] < INF && dist[k][j] < INF)
                    dist[i][j] = Math.min(dist[i][j], dist[i][k] + dist[k][j]);
}
```

```python [Python]
def floyd(dist):
    n = len(dist)
    for k in range(n):                # 中间点维度放最外层
        for i in range(n):
            for j in range(n):
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]
    return dist
```

```rust [Rust]
pub fn floyd(dist: &mut Vec<Vec<i64>>) {
    let n = dist.len();
    const INF: i64 = i64::MAX / 2;
    for k in 0..n {
        for i in 0..n {
            for j in 0..n {
                if dist[i][k] < INF && dist[k][j] < INF
                    && dist[i][k] + dist[k][j] < dist[i][j] {
                    dist[i][j] = dist[i][k] + dist[k][j];
                }
            }
        }
    }
}
```

```typescript [TypeScript]
function floyd(dist: number[][]): void {
  const n = dist.length, INF = Number.MAX_SAFE_INTEGER;
  for (let k = 0; k < n; k++)                  // k 最外层！
    for (let i = 0; i < n; i++)
      for (let j = 0; j < n; j++)
        if (dist[i][k] < INF && dist[k][j] < INF)
          dist[i][j] = Math.min(dist[i][j], dist[i][k] + dist[k][j]);
}
```

:::

> Floyd 的 k 循环放最外层是关键——它对应 DP 的「阶段」：处理完 k 后，`dist[i][j]` 表示「只允许 0..k 作为中间点时 i→j 的最短路」。放内层则退化为一次松弛，不保证正确。

## 负权与负环

- Dijkstra 失效根因：它假定「敲定的点 dist 已最终」，负权边可能从后面提供更优路径推翻已定点 → 错。带负权一律走 Bellman-Ford/SPFA。
- 负环 = 绕一圈总权为负的回路：单源最短路**不存在的良定义**（可无限绕环压低距离）。BF 靠「V-1 轮后再松弛仍改善」检测；判可达负环还能从负环点 DFS 标记。
- 应用：汇率图取 `-log(rate)` 边权，负环即**套利机会**；约束图（差分约束）用 BF 求可行解。

## 常见陷阱

- Dijkstra 忘惰性删除（`if d > dist[u] continue`）会重复扩展、复杂度爆炸；忘初始化 dist=∞ 与 dist[s]=0 是入门错。
- Floyd 三重循环顺序写反（i/j 在外、k 在内）是最经典的隐蔽 bug——用小三角图即可反证。
- BF 未判 `dist[u] != INF` 就松弛，导致 INF 参与加法溢出/污染，把不可达点算成有限值。
- 溢出：多源/长路径 dist 累加可能爆 int，用 long；INF 取 `max/2` 防 `INF+w` 反溢。
- 需要**路径**而非仅距离：三算法都要额外记 `pre[v]` 前驱再反向重建；Floyd 重建路径需另开 `next[i][j]` 表。

# 总结

- 单源非负 → 堆优化 Dijkstra（O((V+E)logV)）；可能有负权/要查负环 → Bellman-Ford（O(VE)，加一轮判负环）；多源/V 小/要传递闭包 → Floyd（O(V³)，k 在最外层）；
- 三者分别是贪心、迭代松弛、DP 在图上的化身——算法思想与 [04.核心算法思想](../04.核心算法思想/000.核心算法思想概述.md) 一一对应；
- 实操记忆：Dijkstra 靠「非负」保证敲定即最优，BF 靠「V-1 轮」保证收敛并借第 V 轮验负环，Floyd 靠「阶段 k」把 O(V⁴) 枚举降到 O(V³)。
