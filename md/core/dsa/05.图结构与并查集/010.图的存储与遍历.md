# 概述

图（Graph）由顶点集 V 与边集 E 构成，是比树更一般的结构（树是无环连通图）。表示一个图先要选**存储结构**（邻接矩阵 / 邻接表），随后所有图算法都跑在**两种遍历骨架**（DFS 深度优先 / BFS 广度优先）之上——选对存储、写对遍历，剩下的只是往骨架里塞不同的处理逻辑。

**本篇收录**：邻接矩阵、邻接表、DFS、BFS

- 所属章节：[000.图结构与并查集概述](./000.图结构与并查集概述.md)

- 时间与空间对照（V=顶点数、E=边数）：

  | 结构/操作 | 邻接矩阵 | 邻接表 |
  |-----------|:-------:|:------:|
  | 存储空间 | O(V²) | O(V+E) |
  | 判边 `(u,v)` 是否存在 | **O(1)** | O(deg(u)) |
  | 遍历 u 的所有邻居 | O(V)（扫整行） | **O(deg(u))** |
  | 加/删边 | O(1) | O(deg) 或摊销 O(1) |
  | 适合 | 稠密图、需频繁判边、Floyd/图论矩阵运算 | **稀疏图（工程默认）** |

- DFS/BFS 复杂度：两者均 **O(V+E)**（邻接表）；DFS 空间 O(V) 递归栈，BFS 空间 O(V) 队列。
- 应用场景：社交网络好友推荐（BFS 求「几度人脉」）、地图路网（邻接表 + 最短路）、网页爬虫（BFS 按层抓取）、依赖检测（DFS 判环）、洪水填充/图像处理（DFS/BFS）、编译器的可达性分析（从入口 DFS 标记活跃变量）、网络连通性检查（Kruskal/DFS 判连通分量）。

**动画：同一个图在两种存储下的样子**
<!-- dsa.assets/graph-storage/repr.gif -->

无向图 `0-1, 0-2, 1-3, 2-3`（4 顶点 4 边）：

1. **邻接矩阵**：4×4 方阵，`mat[u][v]=1` 表示有边；无向图沿对角线**对称**；要访问 0 的邻居得扫完第 0 行（哪怕只有 2 个邻居）；
2. **邻接表**：长度 4 的数组，每格挂一个链表 `adj[0]=[1,2]、adj[1]=[0,3]…`；访问 0 的邻居只遍历它真正连出的 2 个；
3. 判「0 和 3 是否相邻」：矩阵 O(1) 直接读 `mat[0][3]=0`；邻接表要扫 `adj[0]`；
4. 稀疏图（E 远小于 V²）用邻接表省海量空间——工程里除非稠密或需矩阵运算，**默认邻接表**。

**动画：DFS vs BFS 走遍同一张图**
<!-- dsa.assets/graph-storage/dfs-bfs.gif -->

以下图为例（起点 0）：`0→1, 0→2, 1→3, 1→4, 2→5`：

1. **BFS**（队列）：访问 0 → 邻居 1、2 入队 → 弹出 1 访问其邻居 3、4 → 弹出 2 访问 5……得层序 `0,1,2,3,4,5`——一圈圈向外扩，**首次到达某点的路径即最短跳数**；
2. **DFS**（栈/递归）：访问 0 → 一头扎进 1 → 再扎进 3（3 无未访问邻居，**回溯**）→ 回 1 试 4 → 回 1 回 0 → 0 再试 2 → 2 试 5，得 `0,1,3,4,2,5`——不撞墙不回头，撞了墙才退回上个岔路；
3. 对比：求「最少步数」用 BFS；求「是否存在路径/找环/拓扑/连通块」常用 DFS；两者遍历序列不同但**访问节点集合相同**。

## DFS：递归与显式栈

DFS 骨架 = 「标记 + 递归未访问邻居」。递归版最简洁，但深图（链状 n=10⁵）会爆系统栈，工程用显式栈。

::: code-group

```java [Java]
// 递归版
void dfs(int u, List<Integer>[] adj, boolean[] visited) {
    visited[u] = true;
    // visit(u)：在此处理当前节点（前序位置）
    for (int v : adj[u]) {
        if (!visited[v]) dfs(v, adj, visited);
    }
    // 后序位置：子树处理完再汇总（判环/拓扑用）
}

// 显式栈版（防深图爆栈）
void dfsIter(int s, List<Integer>[] adj, boolean[] visited) {
    Deque<Integer> stack = new ArrayDeque<>();
    stack.push(s);
    while (!stack.isEmpty()) {
        int u = stack.pop();
        if (visited[u]) continue;         // 关键：弹出时判重（允许重复入栈）
        visited[u] = true;
        for (int v : adj[u]) if (!visited[v]) stack.push(v);
    }
}
```

```python [Python]
def dfs(u, adj, visited):
    visited[u] = True
    for v in adj[u]:                      # 递归版
        if not visited[v]:
            dfs(v, adj, visited)

def dfs_iter(s, adj):
    visited, stack = set(), [s]
    while stack:
        u = stack.pop()
        if u in visited:                  # 弹出判重，允许惰性入栈
            continue
        visited.add(u)
        stack.extend(adj[u] - visited if isinstance(adj[u], set) else adj[u])
    return visited
```

```rust [Rust]
fn dfs(u: usize, adj: &[Vec<usize>], visited: &mut [bool]) {
    visited[u] = true;
    for &v in &adj[u] {
        if !visited[v] { dfs(v, adj, visited); }
    }
}

fn dfs_iter(start: usize, adj: &[Vec<usize>]) -> Vec<usize> {
    let mut visited = vec![false; adj.len()];
    let mut order = Vec::new();
    let mut stack = vec![start];
    while let Some(u) = stack.pop() {
        if visited[u] { continue; }
        visited[u] = true;
        order.push(u);
        stack.extend(adj[u].iter().copied());
    }
    order
}
```

```typescript [TypeScript]
function dfs(u: number, adj: number[][], visited: boolean[]): void {
  visited[u] = true;
  for (const v of adj[u]) if (!visited[v]) dfs(v, adj, visited);
}

function dfsIter(s: number, adj: number[][]): number[] {
  const n = adj.length, visited = new Array(n).fill(false), order: number[] = [];
  const stack = [s];
  while (stack.length) {
    const u = stack.pop()!;
    if (visited[u]) continue;
    visited[u] = true; order.push(u);
    for (const v of adj[u]) if (!visited[v]) stack.push(v);
  }
  return order;
}
```

## BFS：队列求层/求最短跳数

BFS 骨架 = 「起点入队 + 弹出处理未访问邻居并入队」。要按层分组就在循环内锁定 `queue.size()`；要记录最短跳数就在入队时写 `dist[v]=dist[u]+1`。

::: code-group

```java [Java]
int[] bfsDist(int s, List<Integer>[] adj) {
    int n = adj.length, dist[] = new int[n];
    Arrays.fill(dist, -1);
    Queue<Integer> q = new ArrayDeque<>();
    q.offer(s); dist[s] = 0;
    while (!q.isEmpty()) {
        int u = q.poll();
        for (int v : adj[u]) {
            if (dist[v] == -1) {          // 未访问即最短，标记入队
                dist[v] = dist[u] + 1;
                q.offer(v);
            }
        }
    }
    return dist;                          // s 到各点的最少边数
}
```

```python [Python]
from collections import deque

def bfs_dist(s, adj):
    dist = {s: 0}
    q = deque([s])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if v not in dist:             # 未访问即最短
                dist[v] = dist[u] + 1
                q.append(v)
    return dist
```

```rust [Rust]
use std::collections::VecDeque;

fn bfs_dist(start: usize, adj: &[Vec<usize>]) -> Vec<i32> {
    let mut dist = vec![-1; adj.len()];
    let mut q = VecDeque::new();
    dist[start] = 0;
    q.push_back(start);
    while let Some(u) = q.pop_front() {
        for &v in &adj[u] {
            if dist[v] == -1 {
                dist[v] = dist[u] + 1;
                q.push_back(v);
            }
        }
    }
    dist
}
```

```typescript [TypeScript]
function bfsDist(s: number, adj: number[][]): number[] {
  const n = adj.length, dist = new Array(n).fill(-1);
  const q: number[] = [s]; dist[s] = 0;
  for (let head = 0; head < q.length; head++) {
    const u = q[head];
    for (const v of adj[u]) {
      if (dist[v] === -1) { dist[v] = dist[u] + 1; q.push(v); }
    }
  }
  return dist;
}
```

## DFS 的应用变形（用「时机」而非新算法）

- **判环**（有向）：三色标记——白(未访问)/灰(在当前递归栈上)/黑(已完成)；DFS 中遇到**灰**节点 ⇒ 存在后向边 ⇒ 有环。
- **连通分量**：对未访问点逐个起 DFS，每次 DFS 覆盖的点集是一个分量。
- **二分图判定**：DFS/BFS 染色，遇同色邻边即非二分（详见 [070.二分图与匹配](./070.二分图与匹配.md)）。
- **拓扑排序**：DFS 后序的逆序（详见 [050.拓扑排序](./050.拓扑排序.md)）。
- 这些都不离 DFS 骨架，只是往「前序 / 后序 / 遇到已访问节点」三个时机里塞不同判断。

## 常见陷阱

- **忘标记 visited 导致死循环**：无向图每条边被走两次，不在进入前标记就会来回横跳；标记要在**入队/入栈时**或处理前，别拖到出队后再标（会重复入队爆炸）。
- 显式栈 DFS「入栈时判重 vs 出栈时判重」：出栈时判重（`if visited continue`）实现简单但同一节点可能多次入栈（内存换简洁）；入栈时判重省内存但需小心逻辑顺序。
- BFS 求最短路仅适用**无权图/边权相同**；边权不一要上 [020.最短路径](./020.最短路径.md) 的 Dijkstra（BFS 是其边权全 1 的特例）。
- 邻接表存无向图要成对加两条边；只加一条会让反向 DFS/BFS 漏达。
- 稠密图硬上邻接表反而因链表指针/cache miss 变慢；V 很小且需频繁判边时邻接矩阵更实在。
- 递归 DFS 在深链图（如 n=10⁵ 的一条路径）爆 StackOverflow——生产/竞赛改显式栈或提高栈上限。

# 总结

- 存储二分天下：邻接矩阵 O(1) 判边、O(V²) 空间适合稠密；邻接表 O(V+E) 空间、遍历邻居高效，是稀疏图工程默认；
- DFS 与 BFS 是同一「标记 + 扩散」思想的两副面孔——BFS 逐层保证最少跳数，DFS 一条道走到黑适合判环/连通/拓扑等结构性问题；
- 几乎所有图算法都是这两套骨架换「处理时机」的变形：把前序/后序/遇已访问三个插入点吃透，图论题就不再是新算法而是老骨架。
