# 概述

拓扑排序：给**有向图**排出一个顶点线性序，使每条有向边 `u→v` 都满足 u 排在 v 前——即把依赖关系「拉平」成一维执行计划。它只对**有向无环图（DAG）**存在（有环则互相等待、无解），因此拓扑排序顺带是**判环**工具。两种解法同复杂度 O(V+E)：**Kahn 入度法**（BFS 骨架：反复摘除入度为 0 的点）与 **DFS 逆后序法**（后序收集、整体反转）。

**本篇收录**：Kahn 入度法、DFS 逆后序法

- 所属章节：[000.图结构与并查集概述](./000.图结构与并查集概述.md)

- 时间复杂度：O(V+E)（两法相同）；空间复杂度：O(V)。
- 拓扑序通常**不唯一**（同层多个入度 0 点任选即产生不同合法序）。
- 应用场景：课程表/先修课安排、构建系统（Make/Bazel/pnpm 按依赖序编译任务）、Spark/Flink 的 DAG 作业调度、Excel 单元格重算顺序、编译器的指令调度与变量使用-定序（SSA）、任务编排平台（Airflow DAG 解析）、Linux 包管理依赖安装序（apt/dnf）、前端 JS 模块加载顺序。

**动画：Kahn——不断摘「无人依赖」的点**
<!-- dsa.assets/toposort/kahn.gif -->

DAG：`5→0, 5→2, 4→0, 4→1, 2→3, 3→1`（入度：0:2, 1:2, 2:1, 3:1, 4:0, 5:0）：

1. 统计入度，0 入度的 `{4, 5}` 进队；
2. 弹出 4 → 输出 `4`；它的出边 `4→0`、`4→1` 入度减一（0:1, 1:1）——相当于「4 这门课学完了，解锁对它的依赖」；
3. 弹出 5 → 输出 `4,5`；`5→0` 使 0 入度归零**入队**，`5→2` 使 2 入度归零入队；
4. 依次弹 0、2 → 弹 0 时 1 入度还剩 1（等 3）；弹 2 后 3 入度归零入队；弹 3 → 1 归零入队；最后弹 1；
5. 输出 `4,5,0,2,3,1` 是合法拓扑序；若某步**队空但还有点未输出** ⇒ 剩余点泡在环里 → 图有环（课程表无解的判据）。

**动画：DFS 逆后序——「所有下游都排完才轮到我」**
<!-- dsa.assets/toposort/dfs-post.gif -->

1. 从任意未访问点起 DFS，灰（在栈）标记防环；
2. 一个点的**所有邻居都处理完**（后序位置）才把它压入结果表——意味着它排在所有下游之后；
3. 全部点访问完，把结果表**整体反转**即拓扑序；
4. 与 Kahn 对照：DFS 法递归易爆栈但代码短，且「遇到灰节点即有环」的判环时机更早。

# 详解

## Kahn 入度法（BFS 骨架）

::: code-group

```java [Java]
// adj 邻接表；返回拓扑序，长度为 n 表示成功，否则图有环
int[] topoKahn(List<Integer>[] adj) {
    int n = adj.length;
    int[] indeg = new int[n];
    for (int u = 0; u < n; u++)
        for (int v : adj[u]) indeg[v]++;
    Deque<Integer> q = new ArrayDeque<>();
    for (int i = 0; i < n; i++) if (indeg[i] == 0) q.offer(i);
    int[] order = new int[n];
    int idx = 0;
    while (!q.isEmpty()) {
        int u = q.poll();
        order[idx++] = u;                      // 出队即输出
        for (int v : adj[u])
            if (--indeg[v] == 0) q.offer(v);   // 依赖被摘光才解锁
    }
    return idx == n ? order : new int[0];      // 空数组 = 有环
}
```

```rust [Rust]
use std::collections::VecDeque;

pub fn topo_kahn(adj: &[Vec<usize>]) -> Option<Vec<usize>> {
    let n = adj.len();
    let mut indeg = vec![0usize; n];
    for u in 0..n {
        for &v in &adj[u] { indeg[v] += 1; }
    }
    let mut q: VecDeque<usize> = (0..n).filter(|&i| indeg[i] == 0).collect();
    let mut order = Vec::with_capacity(n);
    while let Some(u) = q.pop_front() {
        order.push(u);
        for &v in &adj[u] {
            indeg[v] -= 1;
            if indeg[v] == 0 { q.push_back(v); }
        }
    }
    if order.len() == n { Some(order) } else { None }   // None = 有环
}
```

```typescript [TypeScript]
function topoKahn(adj: number[][]): number[] | null {
  const n = adj.length, indeg = new Array(n).fill(0);
  for (const u of adj) for (const v of u) indeg[v]++;
  const q = n ? Array.from({ length: n }, (_, i) => i).filter(i => indeg[i] === 0) : [];
  const order: number[] = [];
  for (let head = 0; head < q.length; head++) {     // 数组模拟队列
    const u = q[head];
    order.push(u);
    for (const v of adj[u]) if (--indeg[v] === 0) q.push(v);
  }
  return order.length === n ? order : null;         // null = 有环
}
```

```python [Python]
from collections import deque

def topo_kahn(adj):
    """adj[u] = [v, ...]；返回拓扑序 list，None 表示有环"""
    n = len(adj)
    indeg = [0] * n
    for u in range(n):
        for v in adj[u]:
            indeg[v] += 1
    q = deque(i for i in range(n) if indeg[i] == 0)
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return order if len(order) == n else None
```

## DFS 逆后序法

::: code-group

```java [Java]
boolean[] visited;
Deque<Integer> stack;          // 头插式结果表
boolean hasCycle;

List<Integer> topoDfs(List<Integer>[] adj) {
    int n = adj.length;
    visited = new boolean[n];
    boolean[] onStack = new boolean[n];   // 灰标记：当前递归路径
    stack = new ArrayDeque<>();
    hasCycle = false;
    for (int i = 0; i < n && !hasCycle; i++)
        if (!visited[i]) dfs(i, adj, onStack);
    return hasCycle ? List.of() : new ArrayList<>(stack);  // 逆序输出
}

void dfs(int u, List<Integer>[] adj, boolean[] onStack) {
    visited[u] = true;
    onStack[u] = true;
    for (int v : adj[u]) {
        if (onStack[v]) { hasCycle = true; return; }   // 遇灰 = 后向边
        if (!visited[v]) dfs(v, adj, onStack);
    }
    onStack[u] = false;
    stack.addFirst(u);          // 后序位置：下游都排完才轮到自己
}
```

```python [Python]
def topo_dfs(adj):
    n = len(adj)
    WHITE, GRAY, BLACK = 0, 1, 2
    color = [WHITE] * n
    order = []

    def dfs(u):
        color[u] = GRAY
        for v in adj[u]:
            if color[v] == GRAY:              # 后向边 → 有环
                raise ValueError("cycle")
            if color[v] == WHITE:
                dfs(v)
        color[u] = BLACK
        order.append(u)                       # 后序收集

    for i in range(n):
        if color[i] == WHITE:
            dfs(i)
    return order[::-1]                        # 逆后序 = 拓扑序
```

```rust [Rust]
// Rust 借用检查下递归 DFS 需改写；这里用显式栈 + 每点邻居游标数组的迭代三色标记
pub fn topo_dfs(adj: &[Vec<usize>]) -> Option<Vec<usize>> {
    let n = adj.len();
    let mut color = vec![0u8; n];             // 0 白 1 灰 2 黑
    let mut idx = vec![0usize; n];            // 每个点的邻居遍历进度
    let mut order = Vec::with_capacity(n);
    for start in 0..n {
        if color[start] != 0 { continue; }
        color[start] = 1;
        let mut path = vec![start];           // 显式「递归栈」
        while !path.is_empty() {
            let u = *path.last().unwrap();    // 拷出栈顶，不持有借用
            if idx[u] < adj[u].len() {
                let v = adj[u][idx[u]];
                idx[u] += 1;
                match color[v] {
                    1 => return None,                       // 灰 = 环
                    0 => { color[v] = 1; path.push(v); }
                    _ => {}                                 // 黑：已完成，跳过
                }
            } else {
                color[u] = 2;
                order.push(u);                // 后序收集
                path.pop();
            }
        }
    }
    order.reverse();                          // 逆后序
    Some(order)
}
```

```typescript [TypeScript]
function topoDfs(adj: number[][]): number[] | null {
  const n = adj.length;
  const WHITE = 0, GRAY = 1, BLACK = 2;
  const color = new Array<number>(n).fill(WHITE);
  const order: number[] = [];
  const dfs = (u: number): boolean => {          // 返回 false = 发现环
    color[u] = GRAY;
    for (const v of adj[u]) {
      if (color[v] === GRAY) return false;
      if (color[v] === WHITE && !dfs(v)) return false;
    }
    color[u] = BLACK;
    order.push(u);                                 // 后序
    return true;
  };
  for (let i = 0; i < n; i++)
    if (color[i] === WHITE && !dfs(i)) return null;
  return order.reverse();
}
```

## 两法对比与扩展

| 维度 | Kahn 入度法 | DFS 逆后序 |
|------|------------|-----------|
| 骨架 | BFS（队列） | DFS（递归/栈） |
| 判环时机 | 结束时「输出数 < n」 | DFS 中遇灰节点，**即时** |
| 层序直觉 | 天然按「依赖层」推进 | 需理解后序反转 |
| 求字典序最小拓扑序 | 队列换**小顶堆**即可 | 不适用 |
| 深图 | 安全（无递归） | 递归版可能爆栈 |

- **判环/求环**：Kahn 结束后未输出的点构成「环及其下游」；要精确找出环上节点，用 DFS 灰路径回 traceback。课程表 II（LeetCode 210）即拓扑排序，课程表 I（207）判环可提前终止。
- **关键路径**：在拓扑序上顺推 `earliest[v] = max(earliest[u] + w)`，即 DAG 最长路径/项目工期（PERT）——拓扑排序 + DP 的经典组合（DP 按拓扑序递推的通用范式见 [060.动态规划基础](../04.核心算法思想/060.动态规划基础.md)）。
- **传递闭包/可达性**：逆拓扑序上 `reach[u] = ∪ reach[v] ∪ {v}`，用 bitset 合并。
- **稳定拓扑序**：入度 0 点按原始编号进队（优先级队列），可得字典序最小解。

## 常见陷阱

- 拓扑排序**存在 ⇔ 图是 DAG**：对无向图谈拓扑排序是错题（任何一条边都互为依赖）。
- Kahn 判环写成「队列为空即有环」——应为「队列空 **且输出数 < n**」；一开始就无入度 0 点也是环的征兆。
- DFS 法忘灰/黑区分：只记 visited 会把「已完成的黑点」误判成环；三色标记缺一不可。
- 忘初始化入度数组或把出度当入度（方向反了），输出序完全错乱——拿小 DAG 手推一遍保平安。
- 多源点/多汇点很正常，全部入度 0 点都要入队；「只能从一个点起 DFS」是误解。

# 总结

- 拓扑排序 = 依赖图的合法执行序，Kahn 摘入度 0 点（BFS、好判环、可换堆求字典序最小）、DFS 逆后序（代码短、判环即时），两者同为 O(V+E)；
- 「排出 n 个点」与「图无环」互为充要条件——拓扑排序同时是调度器与环检测器；
- 更大的图景：DAG 上一切顺推/逆推的 DP（关键路径、可达性、计数）都以拓扑序为遍历顺序——先拓排、再递推，是处理无环依赖的万能两步。
