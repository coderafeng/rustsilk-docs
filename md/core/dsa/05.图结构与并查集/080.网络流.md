# 概述

网络流：在**带容量的有向图**上求源 s 到汇 t 的最大流量——每条边流量 ≤ 容量、每个中间点流入=流出（守恒）。**最大流最小割定理**（Ford & Fulkerson）：最大流 = 割断 s-t 的最小割容量，把「往河里放水」与「筑最省钱堤坝」两个问题焊在一起。求解算法都是同一骨架——**找增广路、加流、直到无可增**：Ford-Fulkerson（DFS 找路，含 BFS 特化 Edmonds-Karp）与工业级 **Dinic**（分层图 + 当前弧指针，一次 BFS 榨干多层增广路）。

**本篇收录**：Ford-Fulkerson（含 Edmonds-Karp）、Dinic

- 所属章节：[000.图结构与并查集概述](./000.图结构与并查集概述.md)

- 复杂度：

  | 算法 | 时间 | 说明 |
  |------|:----:|------|
  | Ford-Fulkerson（DFS） | O(E·f\*) | f\*=最大流值，**整数容量才终止**；容量大可指数级慢 |
  | Edmonds-Karp（BFS 最短增广路） | O(V·E²) | 与容量无关，好写好讲 |
  | Dinic | O(V²·E)；单位网络 O(E√V) | 实战主力；二分匹配即单位网络特例 |

- 对偶产出：跑完最大流后，从 s 在**残余网络**可达的点集 S，`(S, V−S)` 就是最小割。
- 应用场景：多源汇运输/管道调度、图像分割（Graph Cut 前后景，能量=割容量）、棒球淘汰赛（baseball elimination）、服务器带宽与请求分配、项目管理资源调度、匹配问题的统一框架（二分匹配=网络流）、广告流量分配、灾害疏散规划。

**动画：Ford-Fulkerson——沿增广路推流、留反向边**
<!-- dsa.assets/flow/augmenting.gif -->

网络：`s→A(3), s→B(2), A→B(1), A→t(2), B→t(2)`：

1. 找一条路 `s→A→t`，瓶颈 `min(3,2)=2` → 推 2；各边残余：`s→A:1, A→t:0`；**同时给每条用过的边建反向容量**（`A→s:2, t→A:2`）——反悔通道；
2. 再找 `s→B→t`，瓶颈 `min(2,2)=2` → 推 2；此时 `s→B:0, B→t:0`；
3. 想走 `s→A→B→t`？`A→B` 有 1 但 `B→t` 已满——**用反向边 `t→B` 不行（方向不对），此路不通**；换路：`s→A→B` 后借 `B` 的反向边…发现 `s→B` 也满 → 无增广路；
4. 总流 4；从 s 沿残余可达 `{s,A,B}`，割 `{s,A,B}|{t}` 容量 = `A→t(2)+B→t(2)` = 4 = 最大流 ✓；
5. 核心顿悟：反向边让后来的流可以「退回」前人的占用——增广路因此总能表达全局调整。

**动画：Dinic——BFS 分层，DFS 在分层图上拍阻塞流**
<!-- dsa.assets/flow/dinic.gif -->

1. BFS 按残余容量 >0 的边给全图编号层次（s=0）；t 不可达即结束；
2. 只在「严格下一层」的边上进 DFS（`level[to]==level[v]+1`）——同层/回层边一概不走，一轮 BFS 可以同时喂很多条增广路；
3. 每条饱和边被「当前弧指针」`it[v]` 永久跳过（本阶段内不会再有用），DFS 把分层图榨到**阻塞流**（再没有 s-t 通路）；
4. 回到 1 重新分层——t 的层次**严格递增**，至多 V 层，所以重分层 ≤ V 次；
5. 对比 FF：Edmonds-Karp 每推一流一次 BFS；Dinic 每次 BFS 推「一批」，这正是 V²E 与 VE² 差距的来源。

## Ford-Fulkerson / Edmonds-Karp

```java [Java]
// 邻接表存边对象；Edmonds-Karp = BFS 找最短增广路，O(V·E²)
class FlowNetwork {
    static class Edge {
        int to, rev, cap;
        Edge(int to, int rev, int cap) { this.to = to; this.rev = rev; this.cap = cap; }
    }
    List<Edge>[] g;
    FlowNetwork(int n) {
        g = new ArrayList[n];
        for (int i = 0; i < n; i++) g[i] = new ArrayList<>();
    }
    void addEdge(int u, int v, int cap) {         // 反向边容量 0（残差网络标配）
        g[u].add(new Edge(v, g[v].size(), cap));
        g[v].add(new Edge(u, g[u].size() - 1, 0));
    }

    int maxFlow(int s, int t) {
        int flow = 0, n = g.length;
        while (true) {
            int[] preNode = new int[n];           // 增广路回溯：父点 + 入边下标
            int[] preEdge = new int[n];
            Arrays.fill(preNode, -1);
            preNode[s] = s;
            Queue<Integer> q = new ArrayDeque<>();
            q.offer(s);
            while (!q.isEmpty() && preNode[t] == -1) {
                int u = q.poll();
                for (int i = 0; i < g[u].size(); i++) {
                    Edge e = g[u].get(i);
                    if (e.cap > 0 && preNode[e.to] == -1) {
                        preNode[e.to] = u; preEdge[e.to] = i;
                        q.offer(e.to);
                    }
                }
            }
            if (preNode[t] == -1) break;          // 无增广路 → 已最大
            int bottleneck = Integer.MAX_VALUE;   // ① 回溯求瓶颈
            for (int v = t; v != s; v = preNode[v])
                bottleneck = Math.min(bottleneck, g[preNode[v]].get(preEdge[v]).cap);
            for (int v = t; v != s; v = preNode[v]) {   // ② 沿路扣容量、加反向容量
                Edge e = g[preNode[v]].get(preEdge[v]);
                e.cap -= bottleneck;
                g[e.to].get(e.rev).cap += bottleneck;
            }
            flow += bottleneck;
        }
        return flow;
    }
}
```

```python [Python]
from collections import deque

class FlowNetwork:
    def __init__(self, n):
        self.n = n
        # graph[u] = [to, cap, 反向边在 graph[to] 里的下标]
        self.graph = [[] for _ in range(n)]

    def add_edge(self, u, v, cap):
        self.graph[u].append([v, cap, len(self.graph[v])])
        self.graph[v].append([u, 0, len(self.graph[u]) - 1])

    def max_flow(self, s, t):
        """Edmonds-Karp：BFS 找增广路"""
        flow = 0
        while True:
            pre = [-1] * self.n              # pre[v] = (父点, 边下标)
            pre[s] = (s, -1)
            q = deque([s])
            while q and pre[t] == -1:
                u = q.popleft()
                for i, (v, cap, _) in enumerate(self.graph[u]):
                    if cap > 0 and pre[v] == -1:
                        pre[v] = (u, i)
                        q.append(v)
            if pre[t] == -1:
                break                        # 无增广路 → 已最大
            # ① 求瓶颈
            path, v = [], t
            while v != s:
                u, i = pre[v]
                path.append((u, i))
                v = u
            bottleneck = min(self.graph[u][i][1] for u, i in path)
            # ② 沿路扣容量、加反向容量
            for u, i in path:
                v, cap, rev = self.graph[u][i]
                self.graph[u][i][1] -= bottleneck
                self.graph[v][rev][1] += bottleneck
            flow += bottleneck
        return flow
```

## Dinic（分层 + 当前弧）

::: code-group

```java [Java]
class Dinic {
    static class Edge {
        int to, rev, cap;
        Edge(int to, int rev, int cap) { this.to = to; this.rev = rev; this.cap = cap; }
    }
    List<Edge>[] g;
    int[] level, it;

    public Dinic(int n) {
        g = new ArrayList[n];
        for (int i = 0; i < n; i++) g[i] = new ArrayList<>();
        level = new int[n]; it = new int[n];
    }
    public void addEdge(int u, int v, int cap) {
        g[u].add(new Edge(v, g[v].size(), cap));
        g[v].add(new Edge(u, g[u].size() - 1, 0));   // 反向边成对存，rev 互指
    }

    boolean bfs(int s, int t) {                       // 分层：t 可达才有增广路
        Arrays.fill(level, -1);
        Queue<Integer> q = new ArrayDeque<>();
        level[s] = 0; q.offer(s);
        while (!q.isEmpty()) {
            int u = q.poll();
            for (Edge e : g[u])
                if (e.cap > 0 && level[e.to] < 0) {
                    level[e.to] = level[u] + 1;
                    q.offer(e.to);
                }
        }
        return level[t] >= 0;
    }

    int dfs(int u, int t, int f) {                    // 分层图 DFS 推流
        if (u == t) return f;
        int pushed = 0;
        for (; it[u] < g[u].size() && f > 0; it[u]++) {   // 当前弧指针
            Edge e = g[u].get(it[u]);
            if (e.cap > 0 && level[e.to] == level[u] + 1) {
                int d = dfs(e.to, t, Math.min(f, e.cap));
                if (d > 0) {
                    e.cap -= d;
                    g[e.to].get(e.rev).cap += d;
                    f -= d; pushed += d;
                }
            }
        }
        return pushed;
    }

    public long maxFlow(int s, int t) {
        long flow = 0;
        while (bfs(s, t)) {
            Arrays.fill(it, 0);
            int f;
            while ((f = dfs(s, t, Integer.MAX_VALUE)) > 0) flow += f;
        }
        return flow;
    }
}
```

```rust [Rust]
// 结构体持状态，递归 dfs 合法；图用 Vec<Vec<(to, cap, rev)>>
pub struct Dinic {
    graph: Vec<Vec<(usize, i64, usize)>>,
    level: Vec<i32>,
    it: Vec<usize>,
}

impl Dinic {
    pub fn new(n: usize) -> Self {
        Self { graph: vec![Vec::new(); n], level: vec![0; n], it: vec![0; n] }
    }
    pub fn add_edge(&mut self, u: usize, v: usize, cap: i64) {
        self.graph[u].push((v, cap, self.graph[v].len()));
        self.graph[v].push((u, 0, self.graph[u].len() - 1));
    }

    fn bfs(&mut self, s: usize, t: usize) -> bool {
        use std::collections::VecDeque;
        self.level = vec![-1; self.graph.len()];
        self.level[s] = 0;
        let mut q = VecDeque::new();
        q.push_back(s);
        while let Some(u) = q.pop_front() {
            for &(to, cap, _) in &self.graph[u] {
                if cap > 0 && self.level[to] < 0 {
                    self.level[to] = self.level[u] + 1;
                    q.push_back(to);
                }
            }
        }
        self.level[t] >= 0
    }

    fn dfs(&mut self, u: usize, t: usize, f: i64) -> i64 {
        if u == t { return f; }
        while self.it[u] < self.graph[u].len() {
            let (to, cap, rev) = self.graph[u][self.it[u]];
            if cap > 0 && self.level[to] == self.level[u] + 1 {
                let d = self.dfs(to, t, f.min(cap));
                if d > 0 {
                    self.graph[u][self.it[u]].1 -= d;
                    self.graph[to][rev].1 += d;
                    return d;
                }
            }
            self.it[u] += 1;                          // 此弧已榨干
        }
        0
    }

    pub fn max_flow(&mut self, s: usize, t: usize) -> i64 {
        let mut flow = 0i64;
        while self.bfs(s, t) {
            self.it = vec![0; self.graph.len()];
            loop {
                let d = self.dfs(s, t, i64::MAX);
                if d == 0 { break; }            // 本阶段已达阻塞流
                flow += d;
            }
        }
        flow
    }
}
```

```typescript [TypeScript]
class Dinic {
  private g: { to: number; rev: number; cap: number }[][];
  private level: number[];
  private it: number[];

  constructor(n: number) {
    this.g = Array.from({ length: n }, () => []);
    this.level = new Array(n).fill(0);
    this.it = new Array(n).fill(0);
  }
  addEdge(u: number, v: number, cap: number): void {
    this.g[u].push({ to: v, rev: this.g[v].length, cap });
    this.g[v].push({ to: u, rev: this.g[u].length - 1, cap: 0 });
  }

  private bfs(s: number, t: number): boolean {
    this.level.fill(-1);
    this.level[s] = 0;
    const q: number[] = [s];
    for (let h = 0; h < q.length && this.level[t] < 0; h++) {
      const u = q[h];
      for (const e of this.g[u])
        if (e.cap > 0 && this.level[e.to] < 0) {
          this.level[e.to] = this.level[u] + 1;
          q.push(e.to);
        }
    }
    return this.level[t] >= 0;
  }

  private dfs(u: number, t: number, f: number): number {
    if (u === t) return f;
    while (this.it[u] < this.g[u].length) {
      const e = this.g[u][this.it[u]];
      if (e.cap > 0 && this.level[e.to] === this.level[u] + 1) {
        const d = this.dfs(e.to, t, Math.min(f, e.cap));
        if (d > 0) {
          e.cap -= d;
          this.g[e.to][e.rev].cap += d;
          return d;
        }
      }
      this.it[u]++;
    }
    return 0;
  }

  maxFlow(s: number, t: number): number {
    let flow = 0;
    while (this.bfs(s, t)) {
      this.it.fill(0);
      let d: number;
      while ((d = this.dfs(s, t, Infinity)) > 0) flow += d;
    }
    return flow;
  }
}
```

```python [Python]
from collections import deque

class Dinic:
    def __init__(self, n):
        self.n = n
        self.graph = [[] for _ in range(n)]   # 边: [to, cap, 反向边下标]

    def add_edge(self, u, v, cap):
        self.graph[u].append([v, cap, len(self.graph[v])])
        self.graph[v].append([u, 0, len(self.graph[u]) - 1])

    def _bfs(self, s, t):
        self.level = [-1] * self.n
        self.level[s] = 0
        q = deque([s])
        while q:
            u = q.popleft()
            for to, cap, _ in self.graph[u]:
                if cap > 0 and self.level[to] < 0:
                    self.level[to] = self.level[u] + 1
                    q.append(to)
        return self.level[t] >= 0

    def _dfs(self, u, t, f):
        if u == t:
            return f
        g = self.graph
        while self.it[u] < len(g[u]):
            e = g[u][self.it[u]]
            to, cap, rev = e
            if cap > 0 and self.level[to] == self.level[u] + 1:
                d = self._dfs(to, t, min(f, cap))
                if d > 0:
                    e[1] -= d
                    g[to][rev][1] += d
                    return d
            self.it[u] += 1                   # 当前弧榨干，永久跳过
        return 0

    def max_flow(self, s, t):
        flow = 0
        INF = float("inf")
        while self._bfs(s, t):
            self.it = [0] * self.n
            while True:
                d = self._dfs(s, t, INF)
                if d == 0:
                    break
                flow += d
        return flow
```

## 最大流最小割定理

- **弱对偶**：任何 s-t 割 (S,T) 的容量 ≥ 任何可行流值（流跨割「净超出」≤ 割边容量和）→ 最大流 ≤ 最小割。
- **取等**：FF 终止时残余网络中 s 不可达 t；令 S=从 s 可达点集，则 S→T 的原图边全饱和、T→S 的原图边流量全为 0 → 割容量恰等于流值 → 两者同取最大/最小。
- **求最小割方案**：跑完最大流后从 s 沿残余边 BFS，可达集即 S；割边 = 从 S 指向 V−S 的**原图**满流边。
- 图割（Graph Cut）做图像分割即此应用：像素为点、邻接像素连容量边（相似度高→容量大→不倾向切断），最小割 = 最优前背景分界。

## 建模套路（网络流的难点在建模）

| 问题 | 建法 |
|------|------|
| 二分最大匹配 | s→左(1)，边(1)，右→t(1)；最大流=匹配数（单位网络 → Dinic O(E√V)） |
| 点容量 | 点拆成 `in→out` 容量=点容量，原边挂 out→in |
| 多源多汇 | 虚源连各源（容量=源供给）、虚汇收各汇 |
| 最小割方案数/重要边 | 割边计数 + 残余可达性分析 |
| 费用流（流量给定求最小费用） | 在 Dinic/BF 骨架上换 SPFA 最短路增广（SSP）或 primal-dual |
| 棒球淘汰、项目选课冲突 | 「保留可行 ⇔ 某网络满流」判据，转化为最大流=常数验证 |

## 常见陷阱

- **忘建反向边/反向边容量加错**：残差网络的灵魂是 `cap += d` 的反向操作，成对边 `rev` 互下标必须严格对称。
- 浮点/超大容量用 FF-DFS：容量 10⁹ 的图可能被「挤牙膏」式增广到天荒地老——要么 Edmonds-Karp 要么 Dinic。
- Dinic 忘每阶段重置 `it[]`：当前弧指针跨分层失效，会漏掉新分层图里重新可用的路。
- 递归 dfs 深图爆栈：超大规模改迭代或用 `stacker`；Python 同样要抬 `setrecursionlimit`。
- 无向边当流量边：无向容量边要**两条方向各建一条容量为 cap 的边**（各带 0 容量反向），只建一条等于单向。
- 割的是「边」不是「点」——点障碍类问题先拆点再谈割。

# 总结

- 网络流 = 容量图上的「守恒运输」，一族增广算法共享同一终止判据：残余网络无 s-t 路即最大流，且此时可达集切出的割恰好等值——最大流最小割；
- FF/Edmonds-Karp 是原理教科书（O(VE²) 稳但慢），Dinic 用「BFS 分层 + 当前弧拍阻塞流」把每次 BFS 的产出从一条路放大到一整个网络层，是实战默认；
- 会写 Dinic 只是及格线，真正的功夫在**建模**：拆点、虚源汇、单位网络退化匹配——把应用题翻译成「往哪灌水」，网络流替你算出哪里该筑堤。
