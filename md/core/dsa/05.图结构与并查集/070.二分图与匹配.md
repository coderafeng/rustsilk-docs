# 概述

二分图（Bipartite Graph）：顶点可划分为左右两套 L、R，**每条边都横跨两套**（内部无边）。等价判据：图无奇环。「给 L 中工人派活、R 中任务给人，一人一职一任务」即**最大匹配**问题——在二分图上用增广路反复改良。本篇两件套：**染色法判二分图**（BFS/DFS 二着色）与**匈牙利算法**（O(V·E) 增广匹配，KM 算法的前置）。

**本篇收录**：染色判定、匈牙利算法

- 所属章节：[000.图结构与并查集概述](./000.图结构与并查集概述.md)

- 复杂度：染色 O(V+E)；匈牙利（DFS 版）O(V·E)，BFS 增广（Hopcroft-Karp）可降至 O(E√V)。
- 理论基石：**Kőnig 定理**——二分图中 最大匹配数 = 最小点覆盖数；由此衍生 最大独立集 = V − 最小点覆盖、最小边覆盖 = 最大匹配（无孤立点时）。
- 应用场景：任务分配/招聘面试配对（求职者×岗位）、约会匹配（Grindr/Tinder 类配对建模）、广告竞价（曝光×广告位）、键盘按键冲突检测（电气矩阵扫描即二分图匹配）、图着色与编译寄存器分配（干预图二分性）、棋盘覆盖（黑白格自然二分）、在线判题「谁适合哪道题」。

**动画：BFS 染色——红蓝互斥，撞色即非二分**
<!-- dsa.assets/bipartite/coloring.gif -->

1. 任取未染色点涂**红**入队；弹出 u 时，其所有邻居必须涂**蓝**（与 u 相异色）；
2. 若某邻居**已涂且与 u 同色** → 存在冲突边 → 图含奇环，**不是二分图**，报告失败；
3. 若邻居未染色则涂反色入队，重复；
4. 图不连通时**每个连通块都要另起一次**染（可能整块是孤点）；
5. 例：三角形 0-1-2-0：0 红 → 1 蓝 → 2 与 1 邻得红 → 检查 2-0 边两端同红，冲突——奇环无处遁形。

**动画：匈牙利——「腾挪」增广路**
<!-- dsa.assets/bipartite/hungarian.gif -->

L={A,B,C}，R={1,2}，边：`A-1, B-1, B-2, C-1`：

1. A 尝试：1 空闲 → 直接配对 `A-1`（匹配数 1）；
2. B 尝试：1 被 A 占 → **游说 A 让位**：递归给 A 找替补…A 只有 1，失败；B 转试 2 → 空闲 → `B-2`（匹配数 2）；
3. C 尝试：1 被 A 占 → 给 A 找替补：A 也只连着 1（本轮已访问）→ 失败；C 没有其他出边 → 本轮增广失败；
4. 最大匹配 = 2；关键视角：一次 DFS 找的是「一条交替路：未匹配边→匹配边→未匹配边…」，走通就把沿途匹配/未匹配**整体翻转**，匹配数 +1；
5. 每轮尝试都要**重置 visited**（R 侧或双边，防同一轮内绕圈死循环）。

# 详解

## 染色法判定

::: code-group

```java [Java]
// 邻接表；返回是否二分图，color[]∈{0未染,1,2}
boolean isBipartite(List<Integer>[] adj) {
    int n = adj.length;
    int[] color = new int[n];
    for (int s = 0; s < n; s++) {              // 每个连通块都要起染
        if (color[s] != 0) continue;
        Deque<Integer> q = new ArrayDeque<>();
        color[s] = 1;
        q.offer(s);
        while (!q.isEmpty()) {
            int u = q.poll();
            for (int v : adj[u]) {
                if (color[v] == 0) {
                    color[v] = 3 - color[u];   // 反色：1↔2
                    q.offer(v);
                } else if (color[v] == color[u]) {
                    return false;              // 同色邻边 = 奇环
                }
            }
        }
    }
    return true;
}
```

```rust [Rust]
use std::collections::VecDeque;

pub fn is_bipartite(adj: &[Vec<usize>]) -> bool {
    let n = adj.len();
    let mut color = vec![0u8; n];               // 0 未染, 1/2 两色
    for s in 0..n {
        if color[s] != 0 { continue; }
        color[s] = 1;
        let mut q = VecDeque::new();
        q.push_back(s);
        while let Some(u) = q.pop_front() {
            for &v in &adj[u] {
                if color[v] == 0 {
                    color[v] = 3 - color[u];
                    q.push_back(v);
                } else if color[v] == color[u] {
                    return false;
                }
            }
        }
    }
    true
}
```

```typescript [TypeScript]
function isBipartite(adj: number[][]): boolean {
  const n = adj.length, color = new Array(n).fill(0);
  for (let s = 0; s < n; s++) {
    if (color[s]) continue;
    color[s] = 1;
    const q: number[] = [s];
    for (let head = 0; head < q.length; head++) {
      const u = q[head];
      for (const v of adj[u]) {
        if (!color[v]) { color[v] = 3 - color[u]; q.push(v); }
        else if (color[v] === color[u]) return false;
      }
    }
  }
  return true;
}
```

```python [Python]
from collections import deque

def is_bipartite(adj):
    n = len(adj)
    color = [0] * n                    # 0 未染，1/2 两色
    for s in range(n):
        if color[s]:
            continue
        color[s] = 1
        q = deque([s])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == 0:
                    color[v] = 3 - color[u]   # 反色
                    q.append(v)
                elif color[v] == color[u]:
                    return False              # 同色邻边：奇环
    return True
```

## 匈牙利算法（DFS 增广）

约定：左部点 `0..nl-1`，右部点 `0..nr-1`；`adj[u]` 是左点 u 的右邻居表；`matchR[v]` = v 当前匹配的左点（-1 空闲）。

::: code-group

```java [Java]
class Hungarian {
    List<Integer>[] adj;        // 左部邻接表
    final int nr;               // 右部点数
    int[] matchR;               // 右部匹配：matchR[v] = u 或 -1
    boolean[] seenR;            // 每轮重置：本轮右点是否试过的

    Hungarian(List<Integer>[] adj, int nr) {
        this.adj = adj; this.nr = nr;
        matchR = new int[nr];
        java.util.Arrays.fill(matchR, -1);
    }

    boolean tryKuhn(int u) {
        for (int v : adj[u]) {
            if (seenR[v]) continue;
            seenR[v] = true;
            // v 空闲，或 v 的现配方可被说动腾位置
            if (matchR[v] < 0 || tryKuhn(matchR[v])) {
                matchR[v] = u;
                return true;
            }
        }
        return false;
    }

    int maxMatching() {
        int m = 0;
        for (int u = 0; u < adj.length; u++) {
            seenR = new boolean[nr];              // 每个左点单独一轮
            if (tryKuhn(u)) m++;
        }
        return m;
    }
}
```

```rust [Rust]
pub fn hungarian(adj: &[Vec<usize>], nr: usize) -> usize {
    // adj[u] = 左点 u 可连的右点表；返回最大匹配数
    let mut match_r = vec![-1i32; nr];
    fn dfs(u: usize, adj: &[Vec<usize>], seen: &mut [bool], match_r: &mut [i32]) -> bool {
        for &v in &adj[u] {
            if seen[v] { continue; }
            seen[v] = true;
            if match_r[v] < 0 || dfs(match_r[v] as usize, adj, seen, match_r) {
                match_r[v] = u as i32;
                return true;
            }
        }
        false
    }
    let mut result = 0;
    for u in 0..adj.len() {
        let mut seen = vec![false; nr];          // 每轮重置
        if dfs(u, adj, &mut seen, &mut match_r) { result += 1; }
    }
    result
}
```

```typescript [TypeScript]
function hungarian(adj: number[][], nr: number): number {
  const matchR = new Array(nr).fill(-1);
  const tryKuhn = (u: number, seen: boolean[]): boolean => {
    for (const v of adj[u]) {
      if (seen[v]) continue;
      seen[v] = true;
      if (matchR[v] < 0 || tryKuhn(matchR[v], seen)) {
        matchR[v] = u;
        return true;
      }
    }
    return false;
  };
  let m = 0;
  for (let u = 0; u < adj.length; u++) {
    const seen = new Array(nr).fill(false);      // 每轮重置
    if (tryKuhn(u, seen)) m++;
  }
  return m;
}
```

```python [Python]
def hungarian(adj, nr):
    """adj[u] = 左点 u 的右邻居表；返回最大匹配数与 matchR"""
    match_r = [-1] * nr

    def try_kuhn(u, seen):
        for v in adj[u]:
            if seen[v]:
                continue
            seen[v] = True                       # 本轮该右点已尝试
            if match_r[v] == -1 or try_kuhn(match_r[v], seen):
                match_r[v] = u                   # 腾挪成功，v 改配 u
                return True
        return False

    matching = 0
    for u in range(len(adj)):
        if try_kuhn(u, [False] * nr):            # 每个左点单起一轮
            matching += 1
    return matching
```

## 为什么正确：增广路定理

- 一条**增广路**：从未匹配的左点出发，沿「非匹配边、匹配边」交替，终于未匹配的右点。沿路翻转（非匹配边变匹配、匹配边变非匹配），匹配数恰好 +1。
- **Berge 定理**：匹配最大 ⇔ 不存在增广路。匈牙利算法就是对每个左点找一条增广路；全部找完即最大匹配。
- DFS 递归 `tryKuhn(matchR[v])` 正是「沿匹配边退一步继续找」的实现——seen 防同一轮内绕圈。
- **优化点**：① 贪心预处理（右点空闲直接配）常数收益大；② 随机打乱左部顺序；③ 大规模上 **Hopcroft-Karp**：每轮 BFS 分层找**所有**最短增广路并一次翻转，复杂度降到 O(E√V)——竞赛数据范围 >10⁵ 边的首选。

## 常用转化（建模比算法难）

| 问题 | 转化 |
|------|------|
| 最少工人完成任务 | 直接最大匹配 |
| 最少路径覆盖 DAG（点不相交） | 拆点二分图：每点拆 u'/u″，边 `u→v` 连 `u'-v″`；答案 = V − 最大匹配 |
| 棋盘放最多车互不攻击 | 行×列二分图匹配 |
| 最小点覆盖 | = 最大匹配（Kőnig），并由染色遍历从交错路构造 |
| 最大权匹配（基数不换权重） | KM 算法 O(V³)（匈牙利带顶标的加强版） |
| 稳定婚姻 | GS 婚姻算法（与匹配不同目标：无嫉妒对） |

## 常见陷阱

- **seen 每轮必须重置**（且重置的是右部数组）——忘重置直接匹配数偏小；跨轮复用则是错的「贪心」。
- 对非二分图跑匈牙利没有意义：奇环上「腾挪」可能循环吞掉别人的位置却总数不增——先染色判定。
- 左右两套编号重叠时务必分开邻接表/加偏移，`matchR` 只按右部下标开。
- DFS 版匈牙利最坏 O(V·E)，稠密大图（10⁵ 级）会 TLE——换 Hopcroft-Karp。
- 匹配「数」好求，恢复「方案」要从 `matchR` 反读：`matchR[v]=u` 即边 (u,v) 在匹配中；别丢了这个数组。

# 总结

- 二分图 = 可二着色 = 无奇环——BFS 染色一遍 O(V+E) 既判定又顺手拿到两套划分；
- 匈牙利算法的本质是「每人一轮的礼貌游说」：沿交替路递归腾挪，一次成功即匹配 +1，Berge 定理保证游说尽时即最大；
- 再往上两跳：规模大换 Hopcroft-Karp（O(E√V)），带权换 KM，要覆盖用 Kőnig——二分图匹配是一整族「配对问题」的公共底座。
