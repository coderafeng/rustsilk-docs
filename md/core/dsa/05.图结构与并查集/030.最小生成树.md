# 概述

最小生成树（MST, Minimum Spanning Tree）：给**连通无向带权图**，选 V-1 条边把所有点连起来且总权最小（树 = 连通且无环）。两大算法都建立在**切分性质**（跨割的最小边必属某棵 MST）这一「安全边」定理上——是 [080.贪心算法](../04.核心算法思想/080.贪心算法.md) 最漂亮的应用之一：Prim 从**点**扩张（维护已并入点集，每次取离点集最近的边），Kruskal 从**边**扩张（按权排序取边，用 [040.并查集](./040.并查集.md) 判环）。

**本篇收录**：Prim、Kruskal

- 所属章节：[000.图结构与并查集概述](./000.图结构与并查集概述.md)

- 复杂度对照：

  | 算法 | 时间 | 适合 | 依赖结构 |
  |------|:----:|:----:|---------|
  | Prim（堆优化） | O((V+E) log V) | **稠密图**、从某点生长 | 优先队列 |
  | Prim（邻接矩阵朴素） | O(V²) | 极稠密图 | 线性扫最小 key |
  | Kruskal | O(E log E) | **稀疏图**、边已排序 | **并查集** |

- 性质：MST 一般不唯一（边权有重复时），但**总权唯一**；若所有边权互异则 MST 唯一。
- 应用场景：铺设光缆/公路/电网的最小成本骨干网、聚类的 single-linkage（把 MST 最长边删掉即分类）、游戏地图自动寻路预计算、电路布线（EDA）、连接感测节点、近似 TSP（MST 的 2 倍是 TSP 最优的界，见 [030.NP完全与近似算法](../04.核心算法思想/030.NP完全与近似算法.md)）、图片分割（MST 最大边割）。

<!-- dsa.assets/mst/prim.gif -->

图：`A-B(1), A-C(4), B-C(2), B-D(5), C-D(3)`，从 A 起：

1. 已选点集 `{A}`，候选边 = A 的出边 `{AB:1, AC:4}`；
2. 取最小候选 **AB(1)** → 点集 `{A,B}`，候选补入 B 的出边：`{AC:4, BC:2, BD:5}`（注意指向已选点 A 的边永不入选）；
3. 取最小 **BC(2)** → 点集 `{A,B,C}`，候选 `{AC:4, BD:5, CD:3}`（CD/CB 连内点跳过）；
4. 取 **CD(3)** → 全点入选，MST = {AB, BC, CD}，总权 6；
5. 每次取的都是「横跨 已选/未选 割」的最小边——由切分性质保证每步安全。

**动画：Kruskal——升序扫边、并查集判环**
<!-- dsa.assets/mst/kruskal.gif -->

同上图，边升序：`AB(1), BC(2), CD(3), AC(4), BD(5)`：

1. 取 AB(1)：A、B 不同分量 → **并入**（union）；已选 1 条；
2. 取 BC(2)：B、C 不同分量 → 并入；已选 2 条；
3. 取 CD(3)：C、D 不同分量 → 并入；已选 3 条 = V-1 → **提前收工**；
4. 若轮到 AC(4)：A、C 已同分量（find 相同）→ 成环，**丢弃**——这就是「只看不连的边」；
5. Kruskal 长出的可能是**多棵小树**中途并存（不要求图连通时即得最小生成森林）。

# 详解

## Prim（堆优化）

::: code-group

```java [Java]
// 邻接表 adj[u] = {v, w}；返回 MST 总权（图不连通时结果只对连通块有效）
long prim(List<int[]>[] adj) {
    int n = adj.length;
    boolean[] inTree = new boolean[n];
    var pq = new java.util.PriorityQueue<int[]>((a, b) -> a[0] - b[0]); // {w, u}
    long total = 0;
    int picked = 0;
    pq.offer(new int[]{0, 0});                       // 从 0 号点起，入边权 0
    while (!pq.isEmpty() && picked < n) {
        int[] cur = pq.poll();
        int u = cur[1];
        if (inTree[u]) continue;                     // 惰性删除
        inTree[u] = true;
        total += cur[0];
        picked++;
        for (int[] e : adj[u]) {                     // 未入树邻居的候选边入堆
            if (!inTree[e[0]]) pq.offer(new int[]{e[1], e[0]});
        }
    }
    return total;
}
```

use std::collections::BinaryHeap;
use std::cmp::Reverse;

pub fn prim(adj: &[Vec<(usize, i64)>]) -> i64 {
    let n = adj.len();
    let mut in_tree = vec![false; n];
    let mut pq = BinaryHeap::new();
    pq.push(Reverse((0i64, 0usize)));                // (w, u) 小顶堆
    let (mut total, mut picked) = (0i64, 0usize);
    while let Some(Reverse((w, u))) = pq.pop() {
        if in_tree[u] { continue; }                  // 惰性删除
        in_tree[u] = true;
        total += w;
        picked += 1;
        for &(v, ew) in &adj[u] {
            if !in_tree[v] { pq.push(Reverse((ew, v))); }
        }
    }
    total
}

```typescript [TypeScript]
function prim(adj: [number, number][][]): number {
  const n = adj.length, inTree = new Array(n).fill(false);
  const pq: [number, number][] = [[0, 0]];           // [w, u]
  let total = 0, picked = 0;
  while (pq.length && picked < n) {
    pq.sort((a, b) => a[0] - b[0]);                  // 教学堆
    const [w, u] = pq.pop()!;
    if (inTree[u]) continue;
    inTree[u] = true; total += w; picked++;
    for (const [v, ew] of adj[u]) if (!inTree[v]) pq.push([ew, v]);
  }
  return total;
}
```

```python [Python]
import heapq

def prim(adj):
    """adj[u] = [(v, w), ...]；返回 MST 总权"""
    n = len(adj)
    in_tree = [False] * n
    pq = [(0, 0)]                       # (权重, 节点)
    total = picked = 0
    while pq and picked < n:
        w, u = heapq.heappop(pq)
        if in_tree[u]:                  # 惰性删除陈旧候选边
            continue
        in_tree[u] = True
        total += w
        picked += 1
        for v, ew in adj[u]:
            if not in_tree[v]:
                heapq.heappush(pq, (ew, v))
    return total
```

## Kruskal（排序 + 并查集）

::: code-group

```java [Java]
record Edge(int u, int v, int w) {}

long kruskal(List<Edge> edges, int n) {
    edges.sort((a, b) -> a.w() - b.w());             // ① 升序
    UnionFind uf = new UnionFind(n);                 // 见 040.并查集
    long total = 0;
    int picked = 0;
    for (Edge e : edges) {                           // ② 逐条试
        if (uf.union(e.u(), e.v())) {                // ③ 不同分量才并入
            total += e.w();
            if (++picked == n - 1) break;            // V-1 条即成树
        }
    }
    return picked == n - 1 ? total : -1;             // -1 表示不连通
}
```

```python [Python]
def kruskal(edges, n):
    """edges = [(w, u, v), ...]；返回 (总权, 边列表)，不连通返回 (None, [])"""
    parent = list(range(n))
    def find(x):                           # 路径压缩版并查集（内联）
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    edges.sort()                           # 按权升序
    total, mst, cnt = 0, [], 0
    for w, u, v in edges:
        ru, rv = find(u), find(v)
        if ru != rv:                       # 不成环才取
            parent[ru] = rv
            total += w
            mst.append((w, u, v))
            cnt += 1
            if cnt == n - 1:
                return total, mst
    return (None, [])                      # 边取完仍不足 V-1：不连通
```

```rust [Rust]
pub fn kruskal(edges: &[(i64, usize, usize)], n: usize) -> Option<(i64, Vec<(i64, usize, usize)>)> {
    // parent/rank 版并查集，见 040.并查集
    let mut uf = crate::union_find::UnionFind::new(n);
    let mut sorted = edges.to_vec();
    sorted.sort_unstable_by_key(|&(w, _, _)| w);
    let (mut total, mut mst) = (0i64, Vec::new());
    for &(w, u, v) in &sorted {
        if uf.union(u, v) {                          // union 返回是否真的合并
            total += w;
            mst.push((w, u, v));
            if mst.len() == n - 1 { return Some((total, mst)); }
        }
    }
    None                                            // 不连通
}
```

```typescript [TypeScript]
function kruskal(edges: [number, number, number][], n: number): number | null {
  // [u, v, w] 三元组；UnionFind 见 040.并查集
  const uf = new UnionFind(n);
  const sorted = [...edges].sort((a, b) => a[2] - b[2]);
  let total = 0, picked = 0;
  for (const [u, v, w] of sorted) {
    if (uf.union(u, v)) {
      total += w;
      if (++picked === n - 1) return total;
    }
  }
  return null;                                     // 不连通
}
```

## 正确性：切分性质（Cut Property）

- 任取图的一个**割**（点集划分为 S 与 V−S）：横跨割的所有边中权最小者，必属于某棵 MST。
- 证明（交换论证）：设最小横跨边 e 不在 MST T 中，把 e 加入 T 成环，环上必有另一条横跨割的边 f（权 ≥ e），用 e 换 f 总权不增——得含 e 的更优/等优生成树。
- **Prim** 每一步取的正是「S=已入树点集」这个割的最小横跨边；**Kruskal** 每步取的边是「某个由已选边构成的连通分量割」的最小横跨边（若它连接两个分量）。两大算法是同一定理的两构造。

## Prim 与 Kruskal 的选择

- 稠密图（E≈V²）：Prim 朴素 O(V²) 或堆优化都稳；Kruskal 排序 E log E 吃亏。
- 稀疏图/边已有序/分布式场景：Kruskal 更友好——边可分片排序后归并，union 操作天然易并行（Borůvka 甚至可全并行，是 MST 并行算法的基石）。
- 需要**显式判连通**（生成森林）：Kruskal 顺手（find 相同即同分量）；Prim 需对每个未达点再起一次。
- 变体：最小**瓶颈**生成树（最小化最大边）两者都给出；度约束 MST 是 NP 难。

## 常见陷阱

- Kruskal 忘判连通：跑完 picked ≠ V-1 说明图不连通，返回的是**森林**，别当树用。
- Prim 的堆里塞的是「入边权」，若误把点的所有出边无条件入堆而不在弹出时查 `inTree`，会重复计权——惰性删除是正确性的一部分。
- 带负权边不影响 MST（MST 只比边权和、与路径无关，无「负环」概念）——这是它与最短路的重要区别。
- 自环与重边：Kruskal 里自环 find 相同自动丢弃、重边按排序自然取最小；Prim 的重边会多次入堆但被惰性删除吸收。
- 图不连通时问「最小生成树」是病题——先确认连通（一次 DFS/BFS），或直接按最小生成森林处理。

# 总结

- 一个定理两只手：切分性质保证「每步取安全边」，Prim 从点集向外够边、Kruskal 给边排序靠并查集防环，同为贪心且互不优劣、各挑战场；
- 选型速记：稠密 → Prim，稀疏/要森林/要并行 → Kruskal；
- MST 是贪心正确性的教科书案例——交换论证三步（反证不含安全边 → 加入成环 → 环上换边不劣）值得背下来，它能复用到调度、拟阵等一切「为什么贪心对」的追问上。
