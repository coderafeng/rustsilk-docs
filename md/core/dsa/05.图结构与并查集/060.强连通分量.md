# 概述

强连通分量（SCC, Strongly Connected Component）：有向图中极大的点集，集内任意两点**互相可达**（u→v 与 v→u 都有路径）。把每个 SCC 缩成一个点，剩下的「缩点图」必是 **DAG**——于是有向图上的一堆难题（2-SAT、博弈分析、依赖闭环检测）先缩点再在 DAG 上处理就柳暗花明。两大算法同为 O(V+E)：**Tarjan**（一次 DFS，low-link 判根）与 **Kosaraju**（两次 DFS，靠逆图与完成序）。

**本篇收录**：Tarjan、Kosaraju

- 所属章节：[000.图结构与并查集概述](./000.图结构与并查集概述.md)

- 时间复杂度：两法均 O(V+E)；空间 O(V)。Tarjan 一趟、常数小但递归+栈难懂；Kosaraju 两趟、逻辑好证但要多存一张**逆图**。
- 应用场景：编译器/运行时循环依赖检测（ESLint `import/no-cycle`、pnpm 依赖环分析）、代码调用图分析（识别互相调用的函数簇）、社交网络「互关社区」挖掘、状态机可达性分析、**2-SAT 求解**（SCC 判可满足并构造赋值）、博弈图必胜态分析、任务系统中循环阻塞检测（死锁图缩点）、Wiki 词条链接图分析。

**动画：Tarjan——dfs 序 + low 值 + 辅助栈**
<!-- dsa.assets/scc/tarjan.gif -->

有向图：`0→1, 1→2, 2→0`（环），`2→3, 3→4, 4→3`（第二个环）：

1. DFS 进入 0：`dfn[0]=low[0]=1`，0 压栈（栈是「当前未归队的路径点集」）；
2. 进 1（dfn=low=2）、进 2（dfn=low=3）——栈 `[0,1,2]`；
3. 2 的邻居 0 **在栈中**（还是"灰"的祖先）→ `low[2] = min(low[2], dfn[0]) = 1`——说明 2 能爬回 0，同属一个分量；
4. 回溯：`low[1]=min(2, low[2]=1)=1`，`low[0]=min(1,1)=1`；回到 0 时 **`low[0]==dfn[0]`** → 0 是 SCC 根！从栈顶一路弹到 0：弹出 `{2,1,0}` 即第一个分量；
5. 继续 2→3→4，4 的邻居 3 在栈中使 `low[4]=dfn[3]=4`；回溯中 3 满足 `low[3]==dfn[3]` → 弹出 `{4,3}` 为第二个分量。
6. 规则一句话：**「能爬到的最早祖先」== 「自己」** 时，栈里从自己往上的所有点构成一个 SCC。

**动画：Kosaraju——原图完成序 + 逆图扩散**
<!-- dsa.assets/scc/kosaraju.gif -->

1. 第一趟在**原图**上 DFS，只关心「完成顺序」：完成谁就压谁（逆后序）；环内点互相指向，最后完成的是**出口方向的上游点**；
2. 第二趟在**逆图**（所有边反向）上，按完成序**从晚到早**依次起 DFS：每个连通块恰是一个 SCC；
3. 直觉：完成序最晚的点 c 在缩点 DAG 中是「汇」——逆图里汇变源，从它开始 DFS 只能困在自己的 SCC 里，绝不越界。

# 详解

## Tarjan（一次 DFS）

::: code-group

```java [Java]
int[] dfn, low, stack;            // stack 为辅助栈
boolean[] inStack;
int time = 0, top = 0, sccCount = 0;
int[] sccId;                      // 每个点属于第几个 SCC

void tarjan(int u, List<Integer>[] adj) {
    dfn[u] = low[u] = ++time;
    stack[top++] = u;
    inStack[u] = true;
    for (int v : adj[u]) {
        if (dfn[v] == 0) {                 // 树边：递归后取子 low
            tarjan(v, adj);
            low[u] = Math.min(low[u], low[v]);
        } else if (inStack[v]) {           // 回边/交叉边指向栈中祖先
            low[u] = Math.min(low[u], dfn[v]);   // 注意用 dfn 不是 low
        }
    }
    if (low[u] == dfn[u]) {                // u 是某 SCC 的根
        while (true) {
            int x = stack[--top];
            inStack[x] = false;
            sccId[x] = sccCount;
            if (x == u) break;             // 弹到根为止
        }
        sccCount++;
    }
}
```

```rust [Rust]
pub fn tarjan_scc(adj: &[Vec<usize>]) -> Vec<Vec<usize>> {
    let n = adj.len();
    let (mut dfn, mut low) = (vec![0u32; n], vec![0u32; n]);
    let mut idx = vec![0usize; n];             // 每点邻居游标（代替递归帧里的循环变量）
    let (mut st, mut in_stack) = (Vec::with_capacity(n), vec![false; n]);
    let mut path = Vec::with_capacity(n);      // 显式 DFS 调用栈
    let mut comps = Vec::new();
    let mut time = 0u32;
    for root in 0..n {
        if dfn[root] != 0 { continue; }
        time += 1;
        dfn[root] = low[root] = time;
        st.push(root); in_stack[root] = true;
        path.push(root);
        while !path.is_empty() {
            let u = *path.last().unwrap();    // 拷出栈顶，不持有借用
            if idx[u] < adj[u].len() {
                let v = adj[u][idx[u]];
                idx[u] += 1;
                if dfn[v] == 0 {
                    time += 1;
                    dfn[v] = low[v] = time;
                    st.push(v); in_stack[v] = true;
                    path.push(v);
                } else if in_stack[v] {
                    low[u] = low[u].min(dfn[v]);    // 栈中祖先：用 dfn
                }
            } else {
                path.pop();
                if let Some(&p) = path.last() {
                    low[p] = low[p].min(low[u]);    // 回溯更新父 low
                }
                if low[u] == dfn[u] {               // SCC 根：弹出一个分量
                    let mut comp = Vec::new();
                    loop {
                        let x = st.pop().unwrap();
                        in_stack[x] = false;
                        comp.push(x);
                        if x == u { break; }
                    }
                    comps.push(comp);
                }
            }
        }
    }
    comps
}
```

```typescript [TypeScript]
function tarjanScc(adj: number[][]): number[][] {
  const n = adj.length;
  const dfn = new Array(n).fill(0), low = new Array(n).fill(0);
  const inStack = new Array(n).fill(false), st: number[] = [], comps: number[][] = [];
  let time = 0;
  const dfs = (u: number): void => {
    dfn[u] = low[u] = ++time;
    st.push(u); inStack[u] = true;
    for (const v of adj[u]) {
      if (!dfn[v]) { dfs(v); low[u] = Math.min(low[u], low[v]); }
      else if (inStack[v]) low[u] = Math.min(low[u], dfn[v]);
    }
    if (low[u] === dfn[u]) {                 // u 是 SCC 根
      const comp: number[] = [];
      while (true) {
        const x = st.pop()!;
        inStack[x] = false;
        comp.push(x);
        if (x === u) break;
      }
      comps.push(comp);
    }
  };
  for (let i = 0; i < n; i++) if (!dfn[i]) dfs(i);
  return comps;
}
```

```python [Python]
import sys

def tarjan_scc(adj):
    sys.setrecursionlimit(max(sys.getrecursionlimit(), len(adj) * 3 + 1000))
    n = len(adj)
    dfn, low = [0] * n, [0] * n
    stack, in_stack, comps = [], [False] * n, []
    time = 0

    def dfs(u):
        nonlocal time
        time += 1
        dfn[u] = low[u] = time
        stack.append(u); in_stack[u] = True
        for v in adj[u]:
            if dfn[v] == 0:
                dfs(v)
                low[u] = min(low[u], low[v])
            elif in_stack[v]:                # 只认栈中节点，用 dfn
                low[u] = min(low[u], dfn[v])
        if low[u] == dfn[u]:                 # SCC 根：弹出一个分量
            comp = []
            while True:
                x = stack.pop(); in_stack[x] = False
                comp.append(x)
                if x == u: break
            comps.append(comp)

    for i in range(n):
        if dfn[i] == 0:
            dfs(i)
    return comps
```

## Kosaraju（两次 DFS + 逆图）

::: code-group

```java [Java]
void kosaraju(List<Integer>[] adj, List<Integer>[] radj) {
    int n = adj.length;
    boolean[] vis = new boolean[n];
    Deque<Integer> order = new ArrayDeque<>();       // 完成序（头插）
    // 第一趟：原图，记录逆后序
    for (int i = 0; i < n; i++) if (!vis[i]) dfs1(i, adj, vis, order);
    // 第二趟：逆图，按完成序从晚到早，每次 DFS 到一个 SCC
    Arrays.fill(vis, false);
    List<List<Integer>> comps = new ArrayList<>();
    while (!order.isEmpty()) {
        int u = order.pollFirst();
        if (!vis[u]) {
            List<Integer> comp = new ArrayList<>();
            dfs2(u, radj, vis, comp);
            comps.add(comp);
        }
    }
}
void dfs1(int u, List<Integer>[] adj, boolean[] vis, Deque<Integer> order) {
    vis[u] = true;
    for (int v : adj[u]) if (!vis[v]) dfs1(v, adj, vis, order);
    order.addFirst(u);                               // 完成后压头 → 表头即最晚完成
}
void dfs2(int u, List<Integer>[] radj, boolean[] vis, List<Integer> comp) {
    vis[u] = true;
    comp.add(u);
    for (int v : radj[u]) if (!vis[v]) dfs2(v, radj, vis, comp);
}
```

```rust [Rust]
pub fn kosaraju(adj: &[Vec<usize>]) -> Vec<Vec<usize>> {
    let n = adj.len();
    let mut radj = vec![Vec::new(); n];              // 逆图
    for u in 0..n {
        for &v in &adj[u] { radj[v].push(u); }
    }
    // 第一趟：原图迭代 DFS，记录完成序（每点邻居游标数组防借用冲突）
    let mut vis = vec![false; n];
    let mut idx = vec![0usize; n];
    let mut order = Vec::with_capacity(n);
    for root in 0..n {
        if vis[root] { continue; }
        vis[root] = true;
        let mut path = vec![root];
        while !path.is_empty() {
            let u = *path.last().unwrap();    // 拷出栈顶，不持有借用
            if idx[u] < adj[u].len() {
                let v = adj[u][idx[u]];
                idx[u] += 1;
                if !vis[v] { vis[v] = true; path.push(v); }
            } else {
                order.push(u);           // 完成
                path.pop();
            }
        }
    }
    // 第二趟：逆图上按逆完成序 DFS，每块即 SCC
    let mut vis = vec![false; n];
    let mut comps = Vec::new();
    for &s in order.iter().rev() {
        if vis[s] { continue; }
        let (mut comp, mut stack) = (Vec::new(), vec![s]);
        vis[s] = true;
        while let Some(u) = stack.pop() {
            comp.push(u);
            for &v in &radj[u] {
                if !vis[v] { vis[v] = true; stack.push(v); }
            }
        }
        comps.push(comp);
    }
    comps
}
```

```python [Python]
import sys

def kosaraju(adj):
    n = len(adj)
    radj = [[] for _ in range(n)]
    for u in range(n):
        for v in adj[u]:
            radj[v].append(u)               # 建逆图

    sys.setrecursionlimit(max(sys.getrecursionlimit(), 3 * n + 1000))
    vis = [False] * n
    order = []
    def dfs1(u):
        vis[u] = True
        for v in adj[u]:
            if not vis[v]:
                dfs1(v)
        order.append(u)                     # 后序

    vis = [False] * n
    comps = []
    def dfs2(u, comp):
        vis[u] = True
        comp.append(u)
        for v in radj[u]:
            if not vis[v]:
                dfs2(v, comp)

    for i in range(n):
        if not vis[i]:
            dfs1(i)
    for u in reversed(order):               # 最晚完成优先
        if not vis[u]:
            comp = []
            dfs2(u, comp)
            comps.append(comp)
    return comps
```

```typescript [TypeScript]
function kosaraju(adj: number[][]): number[][] {
  const n = adj.length;
  const radj: number[][] = Array.from({ length: n }, () => []);
  adj.forEach((nbrs, u) => nbrs.forEach(v => radj[v].push(u)));

  const vis = new Array(n).fill(false), order: number[] = [];
  const dfs1 = (u: number): void => {
    vis[u] = true;
    for (const v of adj[u]) if (!vis[v]) dfs1(v);
    order.push(u);                                // 后序
  };
  for (let i = 0; i < n; i++) if (!vis[i]) dfs1(i);

  const comps: number[][] = [];
  const vis2 = new Array(n).fill(false);
  const dfs2 = (u: number, comp: number[]): void => {
    vis2[u] = true;
    comp.push(u);
    for (const v of radj[u]) if (!vis2[v]) dfs2(v, comp);
  };
  for (let i = n - 1; i >= 0; i--) {              // 逆完成序
    const s = order[i];
    if (!vis2[s]) { const comp: number[] = []; dfs2(s, comp); comps.push(comp); }
  }
  return comps;
}
```

## 正确性直觉与缩点

- **Tarjan 不变量**：`low[u]` = 从 u 的子树出发、走至多一条回边能到达的**栈中最小 dfn**。`low[u]==dfn[u]` ⇔ 子树无法爬回 u 的任何真祖先 ⇔ u 是「能独立成环」的最高点 ⇔ SCC 根。
- **Kosaraju 定理**：缩点 DAG 中按第一趟完成序，**最晚完成的 SCC 必是 DAG 的汇**（无出边指向未访问分量）；逆图中汇变源，从它 DFS 恰好吞掉整个分量而不泄漏——归纳即得。
- **缩点用法**：`compId[v]` 标号后重建分量间边集（去重去自环）得 DAG，之后在其上做 DP/拓扑/传递闭包；「任意两点是否互达」= 缩点后是否同点或可达。

## 两法对比

| 维度 | Tarjan | Kosaraju |
|------|--------|----------|
| DFS 趟数 | 1 | 2 |
| 额外空间 | 辅助栈 | **逆图** O(V+E) |
| 实现难度 | low 语义绕、易错在用 dfn/low 混 | 逻辑直白、好证明 |
| 常数 | 小 | 建逆图 + 两趟，略大 |
| 竞赛首选 | ✅（模板成熟） | 教学/对拍验证 |

## 常见陷阱

- Tarjan 回边更新写成 `low[u] = min(low[u], low[v])`——**栈中祖先要用 `dfn[v]`**（用 low[v] 会把已归队分量的信息串进来，结果错乱）。
- 弹出条件忘 `inStack[v]`：对「已完成但非本分量」的黑点也更新 low，会把不同 SCC 粘一起。
- Kosaraju 第二趟顺序写反（按完成后正序起 DFS）——必须**逆后序**（最晚完成最先）。
- 忘对外层循环每个未访问点都起 DFS：图不（强）连通时只跑一个源点会漏分量。
- 深图递归爆栈：Python 记得 `setrecursionlimit`（且上限太大会 C 栈溢出，稳妥做法改迭代版，如上文 Rust）。

# 总结

- SCC 把有向图拆成「互相可达」的极大块，缩点后即 DAG——2-SAT、循环依赖、可达性统计的通用第一步；
- Tarjan 一趟靠 `dfn/low` + 辅助栈，判据「low==dfn 即根、弹栈到根」；Kosaraju 两趟靠「原图逆后序 + 逆图扩散」，好证好懂但多养一张逆图；
- 模板题三件套背熟：判有向图是否「强连通」（分量数==1）、缩点后跑 DAG DP（如最长链、可达点数）、2-SAT（`x` 与 `¬x` 同分量即不可满足）。
