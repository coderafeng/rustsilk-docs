# 概述

并查集（DSU, Disjoint Set Union / Union-Find）维护一组**不相交的集合**，只支持两种近乎 O(1) 的操作：`find(x)`（查 x 所在集合的代表元）、`union(x, y)`（合并两个集合）。「两元素是否同集合」= 两次 find 比代表元。它用**森林**表示集合：每棵树根节点即代表元，两大优化——**路径压缩**（find 时把途经点直接挂到根）与**按秩/按大小合并**（矮树挂高树）——把单操作摊减压到近常数。

- 所属章节：[000.图结构与并查集概述](./000.图结构与并查集概述.md)

- 时间复杂度：m 次操作（含 n 次建集）摊还 **O(m·α(n))**，α 为反阿克曼函数，n ≤ 2⁶⁴ 时 α(n) ≤ 4，实际即 O(1)。仅路径压缩无按秩、或仅按秩无压缩，均为 O(log n) 摊还。
- 空间复杂度：O(n)（parent 数组 + rank/size 数组）。
- 应用场景：Kruskal 判环（见 [030.最小生成树](./030.最小生成树.md)）、无向图连通分量/朋友圈问题、网格类游戏（岛屿数量、俄罗斯方块消行检测）、等价类合并（变量约束 `x==y`）、最近公共祖先离线算法（Tarjan LCA）、网络连通性（客服询问两站点是否可达）、SQL/编译器里的 union-find 等价传播、图像连通域标注。

1. `union(0,1)`：按大小，1 挂到 0 下 → 树 `0←1`；`union(2,3)`、`union(4,5)` 同理得三棵小树；
2. `union(0,2)`：大小相同，令 2 挂 0 → `0←{1, 2←3}`；`union(0,4)` → `0←{1, 2←3, 4←5}`，整棵 6 点树根为 0；
3. `find(5)`：沿 `5→4→0` 爬到根 0，**沿途 5、4 直接改挂到根**（压缩）→ 此后 `find(5)` 一步到位；
4. 观察树高：无优化时按 `union(1,0), union(2,1), union(3,2)…` 顺序会退化成**链**（find O(n)）；按秩合并保证树高 O(log n)，配合压缩降到 α(n)；
5. 「按大小合并」时 rank 可省，直接借 size 数组当秩用，还顺便能查集合规模。

# 详解

## 标准实现（路径压缩 + 按大小合并）

::: code-group

```java [Java]
class UnionFind {
    private final int[] parent, size;
    private int count;                     // 连通分量个数

    public UnionFind(int n) {
        parent = new int[n];
        size = new int[n];
        count = n;
        for (int i = 0; i < n; i++) { parent[i] = i; size[i] = 1; }
    }

    public int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]]; // 路径减半（迭代版压缩）
            x = parent[x];
        }
        return x;
    }

    public boolean union(int a, int b) {
        int ra = find(a), rb = find(b);
        if (ra == rb) return false;        // 已同集合（成环信号）
        if (size[ra] < size[rb]) { int t = ra; ra = rb; rb = t; }
        parent[rb] = ra;                   // 小树挂大树
        size[ra] += size[rb];
        count--;
        return true;
    }

    public boolean connected(int a, int b) { return find(a) == find(b); }
    public int  setSize(int x)             { return size[find(x)]; }
    public int  components()               { return count; }
}
```

```rust [Rust]
pub struct UnionFind {
    parent: Vec<usize>,
    size: Vec<usize>,
}

impl UnionFind {
    pub fn new(n: usize) -> Self {
        Self { parent: (0..n).collect(), size: vec![1; n] }
    }

    pub fn find(&mut self, x: usize) -> usize {
        if self.parent[x] != x {                       // 递归压缩
            let p = self.parent[x];
            self.parent[x] = self.find(p);
        }
        self.parent[x]
    }

    pub fn union(&mut self, a: usize, b: usize) -> bool {
        let (ra, rb) = (self.find(a), self.find(b));
        if ra == rb { return false; }
        let (big, small) = if self.size[ra] >= self.size[rb] { (ra, rb) } else { (rb, ra) };
        self.parent[small] = big;                      // 小树挂大树
        self.size[big] += self.size[small];
        true
    }

    pub fn connected(&mut self, a: usize, b: usize) -> bool { self.find(a) == self.find(b) }
    pub fn set_size(&mut self, x: usize) -> usize { let r = self.find(x); self.size[r] }
}
```

```typescript [TypeScript]
class UnionFind {
  private parent: number[];
  private size: number[];
  count: number;                                     // 连通分量数

  constructor(n: number) {
    this.parent = Array.from({ length: n }, (_, i) => i);
    this.size = new Array(n).fill(1);
    this.count = n;
  }

  find(x: number): number {
    while (this.parent[x] !== x) {
      this.parent[x] = this.parent[this.parent[x]];   // 路径减半
      x = this.parent[x];
    }
    return x;
  }

  union(a: number, b: number): boolean {
    const ra = this.find(a), rb = this.find(b);
    if (ra === rb) return false;
    const [big, small] = this.size[ra] >= this.size[rb] ? [ra, rb] : [rb, ra];
    this.parent[small] = big;
    this.size[big] += this.size[small];
    this.count--;
    return true;
  }

  connected(a: number, b: number): boolean { return this.find(a) === this.find(b); }
}
```

```python [Python]
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n
        self.count = n                    # 连通分量个数

    def find(self, x):
        root = x
        while self.parent[root] != root:  # 先找根
            root = self.parent[root]
        while self.parent[x] != root:     # 再全程压缩
            self.parent[x], x = root, self.parent[x]
        return root

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return False                  # 已连通：成环信号
        if self.size[ra] < self.size[rb]:
            ra, rb = rb, ra               # 大树作根
        self.parent[rb] = ra
        self.size[ra] += self.size[rb]
        self.count -= 1
        return True

    def connected(self, a, b):
        return self.find(a) == self.find(b)
```

## 两大优化各自做了什么

- **按秩（大小）合并**：保证任何节点到根的距离 ≤ log n——矮树永远挂到高树下，树高被钉死在对数级。这是「无压缩时 find 为 O(log n)」的原因。
- **路径压缩**：find 途中所有节点直接改挂树根，把访问路径「拍扁」。单次看是 O(深度)，但一个节点被拍扁后短期内不再产生深路径。
- 两者叠加后不能独立分析——**联合摊还界 O(α(n))** 由 Tarjan 1975 证明，是 [020.摊还分析](../04.核心算法思想/020.摊还分析.md) 的招牌结论；下界方面 Fredman-Saxon 证明任何比较型 DSU 需 Ω(α(n))，故该界本质最优。
- 工程注意：**递归 find 在千万级元素可能爆栈**，用迭代「减半压缩」（`parent[x] = parent[parent[x]]`）版；Hal 2017「路径减半 + 按秩」同样 O(α(n)) 且迭代实现最稳。

## 典型应用模式

- **判环（无向）**：逐边 union，`union` 返回 false（两端已同集合）即发现环——Kruskal 的核心过滤器。
- **连通分量计数**：初始 count=n，每次成功 union 减一，最终 count 即分量数（「朋友圈」「岛屿」类题）。
- **带权并查集**：在节点上额外维护到**根**的相对量（如食物链问题的 0/1/2 关系、`x-y=d` 约束传播），find 时同步更新 `dist[x] += dist[parent[x]]`——本质是给每个节点发一个相对树根的「坐标」。
- **可撤销并查集**：只按秩合并、不做路径压缩（树高 O(log n)），union 记录改动栈、支持 rollback，配合线段树分治处理「时间轴上加删边」问题。
- **虚点/降维**：把「同组全员互连」建模成挂一个虚拟点，union 成本从 O(k²) 降到 O(k)（社交群组、同类合并）。

## 常见陷阱

- find 忘压缩写成裸爬链：顺序 union（`union(1,0), union(2,1)…`）退化成 O(n) 链，TLE 常源于此。
- 只在 `union` 时压缩、`connected` 里裸 find——同样慢；**所有 find 路径都该压缩**。
- 可撤销场景手滑加了路径压缩：parent 被永久改写，回滚栈失效——回滚版禁压缩。
- 下标映射漏网：并查集是 0..n-1 稠密整数结构，字符串/坐标要先离散化或编码 `x*m+y`，越界检查必须有。
- 「按秩」与「按大小」别混用两套数组——rank（近似高度，同秩才 +1）与 size（真实规模，恒累加）更新规则不同，写串了 α 不降反升。

# 总结

- 并查集 = 「只合并不拆分」的连通性账本：森林表示集合、find 认根、union 挂根，路径压缩 + 按秩合并联手把 m 次操作压到 O(m·α(n))；
- 它是 Kruskal、连通分量、等价类合并诸问题的底座，四种进阶形态（带权、可撤销、虚点、离线 LCA）覆盖大半图论/约束题；
- 记忆锚点：union 返回 false 就是环、count 就是分量数、size[find(x)] 就是朋友圈规模——三行代码解决一半面试题。
