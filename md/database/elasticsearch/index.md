# 概述

Elasticsearch 是一个基于 Apache Lucene 的**分布式、RESTful、近实时的搜索与分析引擎**。它用 JSON 文档存储数据，擅长全文检索、结构化查询、聚合分析和大规模日志/指标分析。常被用于站内搜索、电商搜索、日志分析、可观测性、安全分析、企业搜索以及向量检索/RAG 等场景。

# 核心概念

- **集群 Cluster**：一个或多个节点组成，对外提供搜索和存储服务。
- **节点 Node**：集群中的一台服务器进程，角色包括 master、data、ingest、coordinating、ml 等。
- **索引 Index**：一类文档的集合，类似数据库中的“表”。
- **文档 Document**：一条 JSON 数据，类似一行记录。
- **字段 Field**：文档中的属性。
- **映射 Mapping**：定义字段类型、分词器、是否索引等，类似表结构。
- **分片 Shard**：索引被切分成多个分片，分布到不同节点，实现水平扩展。
- **副本 Replica**：主分片的拷贝，用于高可用和提升读吞吐。
- **倒排索引**：核心数据结构，记录“词项 → 文档”的映射，支持快速全文搜索。
- **近实时 NRT**：写入后默认约 1 秒可被搜索到，不是严格实时。

# 架构与原理

Elasticsearch 是分布式的：

1. 写入文档时，先写入内存缓冲和 translog 日志。
2. 经过 refresh 生成新的 segment，文档变得可搜索。
3. flush 将数据持久化到磁盘。
4. 后台不断合并小 segment，优化查询性能。

查询时，协调节点把请求分发到相关分片，各分片返回结果，协调节点合并、排序并返回。集群健康状态通常用：

- **green**：主分片和副本都正常。
- **yellow**：主分片正常，但副本未分配。
- **red**：有主分片未分配，部分数据不可用。

# 主要能力

- **全文检索**：分词、相关性评分、高亮、拼写建议、同义词。
- **结构化查询**：term、range、bool、wildcard 等。
- **聚合分析**：metrics、bucket、pipeline 聚合，类似 GROUP BY 但更灵活。
- **地理搜索**：地理位置查询、距离排序、范围搜索。
- **向量搜索**：dense_vector、kNN、混合搜索，可用于语义搜索和 RAG。
- **安全与运维**：认证、授权、TLS、审计、告警、监控。
- **机器学习**：异常检测、数据转换等。
- **生态成熟**：Elastic Stack 包括 Elasticsearch、Kibana、Logstash、Beats，常称 ELK。

# 典型使用场景

- 应用内搜索、电商商品搜索、站内搜索。
- 日志、指标、链路追踪分析，如 ELK/Elastic Observability。
- 安全信息与事件管理，如 SIEM。
- 企业知识库、文档搜索。
- 向量数据库与 RAG 检索层。
- 业务数据分析与可视化。

# 优缺点

**优点：**

- 搜索快，支持复杂查询和聚合。
- 分布式、易水平扩展、高可用。
- RESTful API + JSON，使用方便。
- 生态完善，社区和文档丰富。
- 支持全文、结构化、地理、向量等多种检索。

**缺点：**

- 资源消耗较高，尤其是内存和磁盘。
- JVM 调优、分片设计、集群运维有一定门槛。
- 近实时而非强实时，分布式下是一致性偏最终一致。
- 不适合作为强事务型主数据库，不能替代 MySQL/PostgreSQL 这类 OLTP 数据库。
- 许可证经历过变化，使用前需确认版本和授权；AWS 的 OpenSearch 就是从 Elasticsearch 7.10 分叉而来。

# 简单示例

创建/写入文档：

```bash
PUT /products/_doc/1
{
  "name": "iPhone",
  "price": 6999,
  "tags": ["手机", "苹果"]
}
```

搜索：

```bash
GET /products/_search
{
  "query": {
    "match": {
      "name": "iPhone"
    }
  }
}
```

# 总结

Elasticsearch 本质上是“**分布式 Lucene + REST API + JSON 文档 + 聚合分析 + 生态工具**”。它最擅长从大量数据中快速检索、过滤、排序和聚合，是现代搜索和日志分析领域非常主流的基础设施。但它不是传统关系型数据库的替代品，通常与 MySQL、PostgreSQL、Kafka、对象存储等配合使用。
