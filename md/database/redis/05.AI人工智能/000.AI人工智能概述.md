# 概述

Redis 是一个内存数据平台，为满足 AI 应用所需的速度和结构而构建。它存储并索引向量嵌入以及结构化元数据，从而能够以毫秒级延迟实现语义搜索、实时检索和代理内存管理——并且支持任何规模。

- 向量搜索——使用 KNN 和范围查询，结合元数据过滤器，跨哈希和 JSON 文档存储和查询向量嵌入。
- 语义缓存——通过 LangCache 重用语义相似提示的缓存响应，降低 LLM API 的成本。
- 智能体记忆——赋予智能体短期会话记忆和跨交互持续存在的长期持久记忆。
- 结构化数据访问— 使用 Context Retriever 将您的业务数据转换为受控工具，代理可以可靠地查询这些数据。
- 实时数据同步——将关系数据库中的更改近乎实时地传输到 Redis，以便代理始终使用最新信息。

# 操作指南

1. **创建向量索引**：Redis 会根据定义的模式（包括向量字段和元数据）维护一个二级索引。Redis 支持FLAT多种HNSW向量索引类型。
2. **存储和更新向量**：Redis 将向量和元数据存储在哈希或 JSON 对象中。
3. **使用向量进行搜索**：Redis 支持使用向量字段的几种高级查询策略，包括 k 近邻 ( **KNN** )、**向量范围查询**和**元数据过滤器**。
4. **运行时配置向量查询**：选择最佳过滤模式以优化查询执行。
5. **构建 AI 代理**：使用交互式代理构建器生成完整的对话助手和推荐引擎的工作代码。
6. **添加语义缓存**：通过缓存和重用语义相似查询的响应来减少 LLM API 调用。
7. **添加代理内存**：使用代理内存 REST API 为您的代理提供持久会话和长期记忆。
8. **访问结构化业务数据**：使用 Context Retriever 将您的业务数据定义为受控工具，任何代理都可以可靠地查询这些工具。
9. **将实时数据同步到 Redis**：使用数据集成，通过变更数据捕获 (CDC) 使您的 Redis Cloud 数据库与您的主关系数据库保持同步。
