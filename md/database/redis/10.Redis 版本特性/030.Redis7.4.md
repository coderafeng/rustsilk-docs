# 概述

> 官方文档：<https://redis.io/docs/latest/develop/whats-new/7-4/>

Redis 7.4 聚焦于**内存效率、性能与易用性**：支持 Hash 字段级过期、面向 AI 工作负载的新内存高效数据类型（`BFLOAT16`/`FLOAT16`）、简化的二级索引，以及时序数据的插入过滤器优化。

# 新特性

## Hash 字段过期支持

Redis 7.4 支持为**单个 Hash 字段**设置过期时间，或调整其剩余 TTL。这是社区长期呼吁的功能，在缓存与会话存储场景下显著改善内存效率与性能。

## 面向 AI 工作负载的内存高效数据类型

面对 AI 应用的增长需求，Redis 7.4 引入 `BFLOAT16` 与 `FLOAT16` 两种数据类型：

- 内存占用最高降低 **47%**；
- 负载下延迟最高降低 **59%**；

非常适合存储与处理**向量嵌入（vector embeddings）**，应用于向量数据库与 RAG（检索增强生成）系统。

## 时序插入过滤器（Insertion filters）

时序数据新增插入过滤器：当新测量值与已有数据在**时间或数值上的差异极小**时可忽略该值，从而缩减时序数据体积、提升效率（典型场景：传感器数据）。

# 改进

## 简化的二级索引

Redis Search 新增 `TAG` 索引类型，让二级索引更简单直接：

- 查询含特殊字符（如 `@`、`.`）的 tag 时**无需转义**，用双引号包裹查询词即可；
- 改进对空值与缺失字段的处理，数据模型更灵活；
- 地理空间搜索新增 `INTERSECT`、`DISJOIN` 等操作符；
- 索引内存占用的报告更加完善。

# 变更

## 行为变更

- Lua VM 代码的内存分配从 libc 改为 **jemalloc**，减少内存碎片并提升性能；
- `ACL LOAD` 命令调整：仅断开**受影响用户**的客户端连接，减少不必要的服务中断。

# 组件版本

Redis 7.4 由以下组件构建：

| 组件 | 版本 |
|------|------|
| Redis CE | 7.4 |
| Search | 2.10 |
| JSON | 2.8 |
| Time series | 1.12 |
| Bloom | 2.8 |

# 总结

- **Hash 字段过期**是 7.4 最核心的基础能力，缓存/会话场景无需再为字段过期设计绕行方案；
- `BFLOAT16`/`FLOAT16` 让 Redis 在 AI 向量存储上更省内存、更低延迟；
- TAG 索引简化与地理操作符增强了 Search 的易用性；
- 行为变更（jemalloc、`ACL LOAD`）整体向后兼容，升级风险低。
