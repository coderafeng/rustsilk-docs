# 概述

本章按版本记录 Redis 的重要更新，内容以官方 What's New 页面（`redis.io/docs/latest/develop/whats-new/<版本>/`）为准，统一采用「概述 / 新特性 / 改进 / 变更 / 组件版本 / 总结」的 H1 分节模板（8.8 起扩展操作系统、安全修复、缺陷修复、配置参数、指标、CLI 等小节）。
