# 概述

> 官方文档：<https://redis.io/docs/latest/develop/whats-new/8-2/>

Redis 8.2 在 8.0 的基础上继续打磨：**Streams 消费组管理**、**集群按 slot 监控**、**向量搜索压缩算法**、**位图高级操作**与**键空间通知增强**是本次更新的主线，同时交付了 15+ 项性能与资源利用率优化，并修复了多个重要安全漏洞。

# 安全改进

Redis 8.2 修复了重要安全问题：

- **CVE-2025-27151**：修复 redis-check-aof 中潜在的栈溢出与 RCE 漏洞；
- **CVE-2025-32023**：修复 HyperLogLog 命令中的越界写漏洞；
- **CVE-2025-48367**：改进连接处理，即使 accept 出错也会重试接受连接。

# 新特性

## 增强的 Redis Streams

新增两条简化消费组管理与流生命周期操作的命令：

- `XDELEX`：删除 stream 条目，支持高级的消费组引用处理选项；
- `XACKDEL`：**原子地**确认并删除 stream 条目。

两条命令均提供 `KEEPREF`、`DELREF`、`ACKED` 选项，精确控制删除条目时消费组引用的处理方式，简化"多消费组场景下清理已确认条目"的常见模式。`XADD` 与 `XTRIM` 也已扩展同样的选项，所有删除条目的命令行为保持一致。

## 集群监控改进

新命令 `CLUSTER SLOT-STATS` 提供**按 slot 的详细使用指标**：

- 每个 slot 的 key 数量；
- CPU 时间消耗；
- 网络入口与出口流量。

帮助优化集群性能、定位数据分布中的热点。

## 向量搜索增强

`VSIM` 命令的过滤表达式支持 `IN` 操作符，在复杂过滤条件下做向量相似度搜索更灵活。

## 增强的位图操作

`BITOP` 命令新增运算符：

| 运算符 | 说明 |
|--------|------|
| `DIFF` | 位图间按位差集 |
| `DIFF1` | 优化的单 bit 差集运算 |
| `ANDOR` | 单条命令内组合 AND 与 OR |
| `ONE` | 面向单 bit 场景的特化运算 |

这些运算符可以简化此前需要多条命令组合的复杂位图工作流。

## 改进的键空间通知

新增两类事件：

- `OVERWRITTEN`：key 的值被完全覆盖时触发；
- `TYPE_CHANGED`：key 的数据类型发生变化时触发。

更细粒度的数据变更可见性，便于构建响应更灵敏的应用。

# 改进

## 性能优化

- `BITCOUNT`：预取（prefetching）优化，位计数更快；
- `SCAN`：仅在存在易失 key 的库上执行过期检查，减少无效开销；
- 列表操作：`LREM`、`LPOS`、`LINSERT` 复用 `quicklistCompare` 中缓存的 `string2ll` 结果；
- 有序集合：`ZRANK` 等命令同样受益于该缓存优化；
- key 操作：`COPY`、`RENAME`、`RESTORE` 在带 TTL 时得到优化；
- 客户端管理：降低 client cron 开销，避免阻塞主线程；
- 向量操作：vector set 存储最差链路信息，提升 RDB 加载与 RESTORE 速度。

## 内存效率改进

- JSON：数字内联（number inlining）降低内存占用；
- 内存跟踪：降低 malloc 可用内存跟踪的开销；
- 过期处理：优化 scan 回调中的过期检查；
- 向量压缩：SVS-VAMANA 向量索引新增压缩变体，进一步降低内存占用。

## 向量搜索性能

引入 `SHARD_K_RATIO` 参数用于集群中的 KNN 向量查询（**不稳定特性**）：允许用精度换网络延迟，在对精确度不敏感的场景下获得更快响应。

## 增强的指标

新增监控与排障指标：

- 内存：`used_memory_peak_time`（达到 `used_memory_peak` 的时间戳）；
- 复制：`master_current_sync_attempts`（上次断连以来的同步尝试次数）、`master_total_sync_attempts`（向主节点同步的总尝试次数）、`master_link_up_since_seconds`（复制链路已建立的时长）、`total_disconnect_time_sec`（副本断连累计时长）。

# 组件版本

Redis 8.2 为一体化发行版（Redis Open Source），无独立模块组件清单。

# 总结

- Streams 的 `XACKDEL`/`XDELEX` 与统一的 `KEEPREF`/`DELREF`/`ACKED` 选项是本版本最实用的落地点；
- `CLUSTER SLOT-STATS` 补齐了按 slot 观测热点的长期短板；
- 位图新运算符、键空间新事件、向量压缩变体等体现了对 8.0 新能力的持续打磨；
- 本版本包含 RCE 级别 CVE 修复（redis-check-aof），生产环境建议及时升级。
