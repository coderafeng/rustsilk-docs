# 概述

> 官方文档：<https://redis.io/docs/latest/develop/whats-new/6-2/>

Redis 6.2 带来了数据索引、查询与分析方面的新能力：支持多值索引与查询、扩展通配符查询、新增 t-digest 概率数据结构用于分位数估计，并对 Redis Streams 与时序（Time Series）数据处理做了大幅增强。本次更新共新增 **25+ 条命令**，回应了社区长期以来的功能诉求。

# 新特性

## 多值索引与查询（Multi-value indexing and querying）

Redis 现在支持对**所有字段类型**（`TEXT`、`TAG`、`NUMERIC`、`GEO`、`VECTOR`）的多值属性建立索引与查询。开发者可以使用 JSONPath 表达式指向数组或多个标量值，突破了此前只能索引单个标量属性的限制。

## 通配符查询支持（Wildcard query support）

Redis Search 支持对 `TEXT` 与 `TAG` 字段进行**后缀通配**与**中间通配**查询，显著提升了数据检索与过滤的灵活性。

## t-digest：用于分位数估计的新概率数据结构

Redis 引入 t-digest 概率数据结构，可以高效地对大规模数据集或持续数据流进行**分位数（quantile）估计**，特别适合分析与监控类应用。

## 获取未闭合时序桶的聚合结果

新增能力允许在时序数据压缩（compaction）过程中，读取**最新的、仍处于打开状态的时间桶**的聚合结果。

## 时序时间加权平均聚合器（Time-weighted average）

新增时间加权平均聚合器，提高了"随时间求平均"计算的准确性，对**采样间隔不规则**的时序数据尤其有价值。

## 时序数据缺口填充（Gap-filling）

引入缺口填充能力：对缺失的时间桶可以进行**插值**或**重复上一个已知值**，保证时序分析的连续性。

# 改进

## 既有数据结构

Redis 6.2 新增 25+ 条命令，兑现了社区长期诉求，重点包括：

- `ZUNION` / `ZINTER`：直接返回计算结果，不像 `ZUNIONSTORE` / `ZINTERSTORE` 必须将结果存入 key；
- Redis Streams 增强：
  - 支持**排他范围查询**（exclusive range query），检索控制更精细；
  - `XPENDING` 可按**空闲时长（idle time）**过滤待处理消息；
  - 新增 `XAUTOCLAIM` 机制，可自动将超过空闲超时的待处理消息从旧消费者**转移所有权**给新消费者，无需手工逐个 ACK。

# 组件版本

Redis 6.2 由以下组件构建：

| 组件 | 版本 |
|------|------|
| Redis | 6.2 |
| Search | 2.6 |
| JSON | 2.4 |
| Time series | 1.8 |
| Bloom | 2.4 |
| Graph | 2.10 |

# 总结

- Redis 6.2 的主线是**索引查询能力 + 时序分析能力**的升级：多值索引、通配符查询、t-digest、时序加权平均与缺口填充；
- 基础数据结构层面新增 25+ 命令，`ZUNION`/`ZINTER` 与 Streams 的 `XAUTOCLAIM`、排他范围查询是最实用的落地点；
- 该版本仍包含 Graph 组件（RedisGraph 于 7.2 起被移除）。
