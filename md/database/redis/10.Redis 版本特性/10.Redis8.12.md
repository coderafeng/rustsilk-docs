# 发布节奏参考

Redis 8.x 自 8.0 起采用约 **2 个月一个 minor 版本** 的迭代节奏：

| 版本 | GA 时间 |
|------|---------|
| Redis 8.0 | 2025 年 5 月 |
| Redis 8.2 | 2025 年 7 月 |
| Redis 8.4 | 2025 年 10 月 |
| Redis 8.6 | 2026 年 1 月 |
| Redis 8.8 | 2026 年 4 月（Q2） |
| Redis 8.10 | 2026 年 8 月（Q3） |
| Redis 8.12 | 预计 2026 年底（Q4） |
