# 概述

> 官方文档：<https://redis.io/docs/latest/develop/whats-new/8-4/>

Redis 8.4 在 8.2 的基础上重点增强了**集群操作、字符串操作与流处理**能力：原子槽迁移实现零停机运维、`SET` 支持比较并设置（CAS）、混合检索（hybrid search）登场，并通过 SIMD 优化带来显著性能提升。

# 新特性

## 原子集群操作

新命令 `CLUSTER MIGRATION` 支持集群节点间的**原子槽迁移**：在单个原子操作内迁移 slot 及其数据，消除了以往槽迁移期间短暂不可用的窗口，实现零停机集群运维。

## 增强的字符串操作

新增支持原子比较并设置（compare-and-set）的命令：

- `DELEX`：仅当 key 的值满足指定条件时才删除；
- `DIGEST`：生成 key 值的密码学摘要，用于完整性校验；
- `SET` 扩展：支持**原子 CAS 与比较删除**操作，可用于实现无锁数据结构与乐观并发控制模式。

## 多 key 过期管理

新命令 `MSETEX`：在**单个原子操作**中设置多个 key 并更新其过期时间，简化需要为一组相关 key 保持一致 TTL 的批量场景。

## 高级流处理

`XREADGROUP` 新增 `CLAIM min-idle-time` 选项：消费组可在**一次操作**中自动认领并处理空闲的待确认条目与新到来条目，简化消费组管理、提升处理效率。

## 混合搜索能力

新命令 `FT.HYBRID` 支持混合查询：使用 **RRF（Reciprocal Rank Fusion）**或**线性组合**方法融合多个排序算法，将语义相似度与传统文本匹配结合，构建更精细的搜索体验。

## 增强的 AOF 可靠性

启动时支持对损坏的 AOF 尾部进行**自动修复**：新配置参数 `aof-load-corrupt-tail-max-size` 允许 Redis 自动修复轻微 AOF 损坏，提升系统韧性、减少人工干预。

# 改进

## 性能优化（SIMD）

- `BITCOUNT`：x86 上使用 AVX2/AVX512 popcount 实现，ARM 上使用 Neon SIMD 向量化；
- HyperLogLog：无分支比较 + ARM Neon SIMD 向量化，基数估计更快；
- 向量操作：`VADD`、`VSIM` 受益于 AVX2/AVX512 点积实现；
- 命令处理：新增**前瞻预取（lookahead prefetching）**管线，提前解析多条命令，降低处理延迟。

## 内存效率改进

- JSON：同构数组优化与短字符串内联（short string inlining）降低内存占用；
- Lua：新配置 `decode_array_with_array_mt` 改进 JSON 数组（含空数组）的解码与内存利用。

## 搜索与索引增强

- 新参数 `search-default-scorer`：默认文本/tag 打分器设为 **BM25STD**，开箱即得更好的相关性排序；
- 新参数 `search-on-oom`：控制 OOM 时的查询行为（忽略 / 失败 / 返回部分结果）；
- 新参数 `search-io-threads`：为集群 manager 协调配置通信线程，提升集群环境搜索性能；
- 原子槽迁移期间搜索索引**可持续更新**，集群操作期间保持搜索可用。

## 增强的配置

| 参数 | 说明 |
|------|------|
| `lookahead` | 命令预取的前瞻深度，运行时可调，默认 16 |
| `aof-load-corrupt-tail-max-size` | AOF 自动修复允许的损坏尾部最大尺寸 |
| `decode_array_with_array_mt` | 控制 Lua 如何处理空 JSON 数组 |

# 组件版本

Redis 8.4 延续一体化发行版（单一 Redis Open Source 包，无独立模块），内置能力包括：

- **RedisTimeSeries**：时序命令支持 `HELP` 与 `COMMAND DOCS`；
- **RedisBloom**：概率数据结构命令支持 `HELP` 与 `COMMAND DOCS`；
- **RediSearch**：混合搜索能力与集群协调改进。

# 已知限制

- 原子槽迁移期间，搜索命令（`FT.SEARCH`、`FT.AGGREGATE`、`FT.CURSOR`、`FT.HYBRID`）与时序命令（`TS.MGET`、`TS.MRANGE`、`TS.MREVRANGE`、`TS.QUERYINDEX`）可能返回**部分结果或重复项**；
- `FT.PROFILE`、`FT.EXPLAIN`、`FT.EXPLAINCLI` 尚不支持 `FT.HYBRID` 选项；
- `FT.HYBRID` 的指标未显示在 `FT.INFO` 与 `INFO` 中；
- `FT.HYBRID` 的部分选项（`EXPLAINSCORE`、`SHARD_K_RATIO`、`YIELD_DISTANCE_AS`、`WITHCURSOR`）尚不可用；
- 暂不支持在 `COMBINE` 步骤后用 `FILTER` 做后过滤。

# 总结

- **运维视角**：`CLUSTER MIGRATION` 原子槽迁移 + AOF 自动修复，显著提升集群与持久化可靠性；
- **开发视角**：`SET` 的 CAS 能力使 Redis 可直接支撑无锁/乐观并发模式；`XREADGROUP CLAIM` 简化流消费组；
- **搜索视角**：`FT.HYBRID` 混合检索 + BM25STD 默认打分，向生产级搜索引擎更进一步；
- 性能层面 SIMD（AVX2/AVX512/Neon）与 lookahead 预取是本版本的隐形红利；
- 注意 `FT.HYBRID` 仍是新命令，多项选项与可观测性支持尚未完整。
