# 概述

> 官方文档：<https://redis.io/docs/latest/develop/whats-new/8-6/>

Redis 8.6 在 8.4 的基础上重点增强了**流可靠性、内存管理与安全**：Streams 幂等（至多一次投递）、新型淘汰策略（LRM）、热 key 检测、TLS 证书自动认证、时序 NaN 支持等，同时交付 20+ 项性能与资源利用优化，hash/有序集合内存显著下降。

# 安全改进

- **隐私保护**：ACL 日志与服务端日志（核心与模块）不再暴露个人可识别信息（PII）；
- **ACL 修复**：修复 `MSETEX` 命令的 key-pattern 绕过漏洞；
- **模块安全**：修复 RedisBloom 加载非法 RDB 文件时的越界读漏洞。

# 新特性

## 流幂等性（Stream idempotency）

Redis Streams 引入幂等特性，提供**至多一次（at-most-once）投递保证**：

- `IDMPAUTO` 参数：为 `XADD` 操作自动生成幂等标识；
- `IDMP` 参数：手动指定幂等标识。

可防止 stream 中出现重复条目，适合重复处理会造成问题的关键数据处理管线。

## 增强的内存管理：LRM 淘汰策略

新增两种淘汰策略：

- `volatile-lrm`：按**最近最少修改**（least recently modified）淘汰带过期时间的 key；
- `allkeys-lrm`：按 LRM 淘汰任意 key。

与既有 LRU（按访问模式）互补，LRM 关注**修改模式**，对写重负载的内存控制更精准。

## 热 key 检测

新命令 `HOTKEYS` 支持实时检测与报告高频访问的 key，帮助定位性能瓶颈、优化集群环境下的数据分布。

## TLS 证书认证

引入基于 TLS 证书的**自动客户端认证**：证书自动映射到 Redis 用户，在启用证书的环境中减少对有密码认证的依赖。

## 增强的时序能力

- **NaN 值支持**：时序可存储与处理 Not-a-Number 值，表达不完整或无效的数据点；
- **新聚合器**：`COUNTNAN` 与 `COUNTALL`，针对含 NaN 数据集的分析。

## 内存监控与分析

- **key 内存大小直方图**：按数据类型收集内存消耗直方图，掌握内存使用分布；
- **按 slot 统计**：集群 slot 级统计，洞察各节点资源消耗。

# 改进

## 性能优化

- **回复优化**：bulk string 回复走免拷贝路径，列表节点分配优化；
- **数据结构**：hash 与有序集合采用字段/值、score/值**统一结构**，内存大幅降低；
- **迭代器**：listpack 迭代器在 hash 字段操作上性能更好；
- **命令**：`ZRANK`、`XREADGROUP CLAIM` 增强，带过期的集合命令优化；
- **预取**：预取逻辑与容量算法改进；
- **硬件利用**：ARM AArch64 默认使用硬件时钟；可用硬件单调时钟时复用缓存时间，减少每命令 syscall；
- **ACL**：用户权限校验优化，访问控制更快；
- **向量**：vector set 距离计算针对 Intel/AMD/ARM 优化。

## 复制改进

- **无盘复制**：diskless replication 期间关闭 RDB 压缩，提升传输速度；
- **配置灵活性**：`repl-diskless-load` 新增 `flushdb` 选项，更好控制复制期间的数据集处理。

# 配置增强

| 参数 | 说明 |
|------|------|
| `stream-idmp-duration` / `stream-idmp-maxsize` | 幂等流生产的默认时长与容量控制 |
| `tls-auth-clients-user` | 启用证书自动客户端认证 |
| `volatile-lrm` / `allkeys-lrm` | 新淘汰策略 |
| `cluster-slot-stats-enabled` | 启用按 slot 的资源消耗统计 |
| `key-memory-histograms` | 启用按数据类型的内存消耗直方图 |

# 模块 API 增强

新增 key 元数据（key metadata）API，供模块开发者为 key 关联自定义元数据：

- `RM_CreateKeyMetaClass` / `RM_ReleaseKeyMetaClass`：定义与释放元数据类；
- `RM_SetKeyMeta` / `RM_GetKeyMeta`：挂载与读取指定元数据类下的 key 元数据值。

# 增强的监控指标

- 内存分布：`db0_distrib_lists_sizes`、`db0_distrib_sets_sizes`、`db0_distrib_hashes_sizes`、`db0_distrib_zsets_sizes`；
- TLS 认证：`acl_access_denied_tls_cert` 记录证书认证失败次数，用于安全监控。

# 组件版本

Redis 8.6 延续一体化发行版（单一 Redis Open Source 包），内置：

- **RedisTimeSeries**：NaN 支持与新聚合器；
- **RedisBloom**：RDB 加载安全修复、支持原子槽迁移；
- **RedisJSON**：隐私保护增强与原子槽迁移能力增强。

# 已知限制

- **Redis Search**：负载再平衡（如原子槽迁移）期间，游标可能因节点间数据移动而**漏掉部分结果**；
- **流幂等**：在 `appendonly yes` 且 `aof-use-rdb-preamble no`（非默认配置）下，避免使用带 `IDMP`/`IDMPAUTO` 的 `XADD`，官方称下一补丁版本将解除此限制。

# 总结

- **可靠性**：Streams 幂等（`IDMP`/`IDMPAUTO`）补齐至多一次投递语义，数据管线去重不再依赖应用层；
- **内存治理**：LRM 淘汰策略、hash/zset 统一结构、内存直方图三者分别从"淘汰、存储、观测"入手；
- **安全**：TLS 证书自动认证与 PII 隐藏是企业合规向的关键一步；
- **可观测性**：`HOTKEYS` 与 per-slot 统计让热点定位开箱即用；
- 升级注意：使用流幂等前先确认 AOF 配置不落入已知限制场景。
