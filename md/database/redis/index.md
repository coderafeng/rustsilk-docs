# 概述

Redis（REmote DIctionary Server）是一个开源的高性能内存键值数据库，也常被当作缓存系统使用。你可以把它理解为一个“超快的、支持多种数据结构的分布式 Map”。

主要特点：

- **基于内存**：读写速度非常快，延迟低，常用于提升系统性能。
- **数据结构丰富**：支持 String、Hash、List、Set、Sorted Set、Bitmap、HyperLogLog、Stream、GEO 等。
- **持久化**：支持 RDB 快照和 AOF 日志，可把内存数据保存到磁盘。
- **高可用与扩展**：支持主从复制、Sentinel 哨兵、Cluster 集群分片。
- **附加能力**：过期键、发布订阅、事务、Lua 脚本、分布式锁、限流等。

典型用途：

- 缓存数据库查询结果、页面数据
- 会话 Session 存储
- 计数器、排行榜、点赞数
- 分布式锁、限流
- 轻量消息队列，如 Pub/Sub、Stream
- 向量检索

> [!note]
> Redis 数据主要放内存，容量受内存限制，成本相对较高；缓存场景要考虑穿透、击穿、雪崩；持久化也不能保证绝对不丢数据。
