# 概述

本章讲 Redis 的**工程化实操**：数据可靠性（持久化）、高可用（复制/哨兵/集群）、并发正确性（事务与分布式锁），以及生产环境最常见的缓存故障治理（穿透/击穿/雪崩、大 key/热 key）。

> [!note] 章节定位调整
> 原计划散落在"09.原理与源码"的工程视角内容（如复制流程、故障转移）统一放在本章「原理 → 配置与实操 → 避坑」结构中讲解；纯源码剖析仍归 09 章。

# 学习路径建议

1. 先持久化，再复制/哨兵/集群（三者递进：单机可靠 → 主从可靠 → 自动转移 → 分片扩展）；
2. 事务与分布式锁配合 [06.可编程性](../06.可编程性/000.可编程性概述.md) 的 Lua 章节一起读；
3. 缓存故障与大热 key 是面试与生产双高频，治理手段均依赖前 5 篇的机制理解。
