# 概述

本章收录**跨数据类型的通用命令**——即不针对某一具体类型、作用于键（Key）本身或服务器本身的命令。

> [!tip] 与「数据类型和命令」章的边界
> - **类型专属命令**（如 `HGET`、`ZADD`、`XADD`、`BF.ADD`）：在 [02.Redis 数据类型和命令](../02.Redis%20数据类型和命令/000.数据类型概述.md) 各类型文档的「命令速查」小节中讲解；
> - **通用/运维命令**（键级操作、服务器诊断、连接管理等）：在本章讲解；
> - 事务、发布订阅、脚本/函数、集群相关命令分别归口 [08.工程化](../08.工程化/000.工程化概述.md)、[04.发布订阅](../04.发布订阅/000.发布订阅概述.md)、[06.可编程性](../06.可编程性/000.可编程性概述.md) 章节，本章只做索引。

- 命令官方速查：<https://redis.io/docs/latest/develop/commands/>
- 单命令参考：`https://redis.io/commands/<命令名>/`

# 命令分组

按官方命令表（command table）分组，本章后续文档按此组织：

| 分组 | 代表命令 | 说明 |
|------|----------|------|
| Generic（键级通用） | `DEL`、`EXISTS`、`EXPIRE`、`TTL`、`TYPE`、`SCAN`、`RENAME`、`DUMP`/`RESTORE` | 对任意键生效，与 value 类型无关；`SCAN` 是生产环境遍历键空间的唯一推荐方式 |
| Connection（连接） | `PING`、`ECHO`、`SELECT`、`AUTH`、`HELLO`、`CLIENT` | 连接会话管理，含 RESP2/RESP3 协议握手 |
| Server（服务器） | `INFO`、`DBSIZE`、`CONFIG`、`SLOWLOG`、`MONITOR`、`DEBUG`、`SHUTDOWN`、`LATENCY` | 服务器状态、配置与诊断 |
| Command（命令表） | `COMMAND`、`COMMAND DOCS/COUNT/GETKEYS/INFO` | 自省命令，查询命令元数据 |
| ACL（访问控制） | `ACL SETUSER/WHOAMI/LIST/LOG` | 用户与命令权限（6.0+） |
| Tenant（多租户） | 隔离相关命令（8.0+，企业特性） | 了解即可 |

# 学习建议

1. 优先掌握 Generic 分组 + `SCAN` 族（游标思想），这是日常运维和面试的高频内容；
2. `MONITOR`、`KEYS`、`FLUSHALL` 等危险命令务必理解其在生产环境的后果（见各文档「避坑」小节）；
3. 分组与官方 command-table 保持同步，新增分组时在上表补行即可。
