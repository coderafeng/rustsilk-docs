# 概述

统一所有文档的演示样本数据

给 Redis 各数据类型提供**同一套业务数据**的演示样本。

所有数据都是虚构的；`C1 = 初三(1)班`、`S001~S008 = 学号`、`SUB1~SUB5 = 科目`、`E1~E3 = 考试`。

# 样本数据场景

| 项目 | 内容 |
|---|---|
| 学校 | 阳光中学（`school_id = SCH1`） |
| 学期 | 2024 学年第一学期（`term = 2024S1`） |
| 班级 | 初三(1)班 `C1`（5 人）、初三(2)班 `C2`（3 人） |
| 学生 | 8 人，学号 `S001` ~ `S008` |
| 科目 | 语文 `SUB1`、数学 `SUB2`、英语 `SUB3`、物理 `SUB4`、化学 `SUB5` |
| 考试 | 第一次月考 `E1`（2024-09-28）、期中考试 `E2`（2024-11-08）、第二次月考 `E3`（2024-12-06） |
| 成绩规模 | 8 学生 × 5 科目 × 3 次考试 = 120 条成绩记录（本文主体以 C1 期中 25 条为例） |

# 不同Redis数据类型的样本数据

## string

缓存、计数器、锁

**取值视角**：一个 key 对应一个字符串值。

| key | 语义 | value 示例 | 说明 |
|---|---|---|---|
| school:name | 学校名称 | `"阳光中学"` | 普通短字符串（embstr） |
| student:S001:name | 学生姓名 | `"张伟"` | 短字符串（embstr） |
| class:C1:score_sum:E2 | C1 期中总分 | `"2282"` | `INCRBY` 累加的计数器 |
| exam:E2:SUB2:avg | 数学平均分 | `"93.4"` | 浮点字符串 |
| exam:E2:SUB2:pass_rate | 数学及格率 | `"0.8"` | 浮点字符串 |
| lock:score:import:C1 | 导入成绩的分布式锁 | `"a7f3c1e2-8b45-4d1a-9c77-2f6b8d0e1a34"` | `SET NX PX 60000` |
| cache:class:C1:profile | 班级信息缓存 | `"{\"class_id\":\"C1\",\"name\":\"初三(1)班\"}"` | 序列化后的 JSON 文本 |

**命令示例：**

```bash
SET   student:S001:name "张伟"                 # OK
GET   student:S001:name                        # "张伟"
INCRBY class:C1:score_sum:E2 505               # (integer) 505 → 累加到 2282
SET   lock:score:import:C1 <token> NX PX 60000 # OK（拿到锁）
OBJECT ENCODING student:S001:name              # "embstr"
OBJECT ENCODING class:C1:score_sum:E2          # "int"
```

## bitmaps

出勤、作业提交

**取值视角**：位偏移 `offset` ↔ 一个 0/1 状态；底层就是一个字符串。

| key | bit offset | 对应学生 / 含义 | 值 |
|---|---|---|---|
| class:C1:attendance:20240902 | 0 | S001 到校 | 1 |
| class:C1:attendance:20240902 | 1 | S002 到校 | 1 |
| class:C1:attendance:20240902 | 2 | S003 到校 | 1 |
| class:C1:attendance:20240902 | 3 | S004 到校 | 0 |
| class:C1:attendance:20240902 | 4 | S005 到校 | 1 |
| class:C1:attendance:20240903 | 0~4 | S001~S005 到校 | 1 0 1 1 1 |
| student:S001:homework:2024S1 | 0~19 | 第 1~20 次作业是否提交 | 前 18 次为 1，后 2 次为 0 |

```bash
SETBIT class:C1:attendance:20240902 3 0     # (integer) 1（S004 缺勤；返回原值）
GETBIT class:C1:attendance:20240902 3       # (integer) 0
BITCOUNT class:C1:attendance:20240902       # (integer) 4（出勤 4 人）
BITCOUNT student:S001:homework:2024S1       # (integer) 18（提交 18 次）
BITPOS class:C1:attendance:20240902 0       # (integer) 3（第一个缺勤位）
# 字节视角：offset 0..4 = 1,1,1,0,1 → 第 0 字节 = 0b11101000 = 0xE8
# （Redis 位图是 MSB-first：offset 0 对应字节的最高位 bit7；offset4 的 S004 缺勤记为 0）
```

## bitfields

把班级统计压进一个字符串

**取值视角**：在同一个字符串上按 (offset, type) 切出多个不同宽度的整数字段。

| 字段 | 类型 | bit offset | 位宽 | 含义 | 样本值 |
|---|---|---|---|---|---|
| math_pass | u8 | 0 | 8 | 数学及格人数（≥72） | 4 |
| math_excellent | u8 | 8 | 8 | 数学优秀人数（≥96） | 3 |
| total_avg_x10 | u16 | 16 | 16 | 班级平均总分 ×10 | 4564 |
| top_student | u4 | 32 | 4 | 第一名学号尾号 | 1 |
| attendance | u4 | 36 | 4 | 出勤人数 | 5 |
| class_level | u4 | 40 | 4 | 班级评级（0–15） | 12 |

```bash
BITFIELD class:C1:stats:E2 SET u8 0 4 SET u8 8 3 SET u16 16 4564 \
                     SET u4 32 1 SET u4 36 5 SET u4 40 12   # 1) 0 2) 0 ...
BITFIELD class:C1:stats:E2 GET u8 0                          # 1) (integer) 4
BITFIELD class:C1:stats:E2 INCRBY u8 0 1 OVERFLOW SAT        # 1) (integer) 5
BITFIELD_RO class:C1:stats:E2 GET u16 16                     # 1) (integer) 4564
```

## vector-set

学情画像、相似学生
**取值视角**：`element → 向量`，支持相似度检索（插入时做 L2 归一化，余弦相似度 = 点积）。

| key | element | 向量（前 4 维示例） | dim | 说明 |
|---|---|---|---|---|
| vset:student:profile | S001 | `[0.82, 0.91, 0.15, 0.44, …]` | 64 | 数学强、文科中 |
| vset:student:profile | S002 | `[0.55, 0.62, 0.71, 0.40, …]` | 64 | 均衡型 |
| vset:student:profile | S003 | `[0.79, 0.88, 0.35, 0.52, …]` | 64 | 理科强 |
| vset:student:profile | S004 | `[0.31, 0.28, 0.42, 0.22, …]` | 64 | 待提升 |
| vset:student:profile | S005 | `[0.60, 0.55, 0.66, 0.61, …]` | 64 | 均衡型 |

```bash
VADD vset:student:profile VALUES 64 0.82 0.91 0.15 0.44 ... S001   # (integer) 1
VSIM vset:student:profile ELE S001 COUNT 3 WITHSCORES              # 与 S001 最相似的 3 人
VEMB vset:student:profile S001                                     # 向量分量
VINFO vset:student:profile                                         # 维度/量化/数量

```

## hyperloglog

独立人数统计
**取值视角**：把元素塞进 16384 个 6 位寄存器，固定 12 KB 估算基数（标准误差 0.81%）。

| key | 统计口径 | 估算基数 | 标准误差 | 内存 | 说明 |
|---|---|---|---|---|---|
| hll:exam:E2:uv:student | 期中考试参与学生 | 5 | 0.81% | 12 KB | C1 参考人数 |
| hll:exam:E1:uv:student | 第一次月考参与学生 | 5 | 0.81% | 12 KB | |
| hll:school:2024S1:active | 全校活跃学生 | 8 | 0.81% | 12 KB | S001~S008 |
| hll:subject:SUB2:visitors | 数学答疑参与人数 | 6 | 0.81% | 12 KB | 含 C2 学生 |
| hll:daily:20240928:uv | 单日访问学生 | 5 | 0.81% | 12 KB | 按天切分 |

```bash
PFADD hll:exam:E2:uv:student S001 S002 S003 S004 S005   # (integer) 1
PFCOUNT hll:exam:E2:uv:student                          # (integer) 5（估算值）
PFMERGE hll:2024S1:uv:student hll:exam:E1:uv:student hll:exam:E2:uv:student

```

## bloom-filter

注册/提交判重（不删除）

**取值视角**：位数组 + k 个哈希函数，判断“可能存在 / 一定不存在”。

| key | 容量 | 误差率 | 已插入 | 判定示例 |
|---|---|---|---|---|
| bf:student:phone:registered | 1000 | 0.01 | 8 | `BF.EXISTS … 13800000001` → 1 |
| bf:school:guardian_phone | 2000 | 0.01 | 8 | `BF.EXISTS … 13900000000` → 0 |
| bf:exam:E2:submitted | 500 | 0.001 | 5 | C1 五人均已提交 → 1 |
| bf:class:C1:homework:done | 1000 | 0.01 | 18 | S001 的 18 次作业 |
| bf:knowledge:asked:E2 | 300 | 0.01 | 12 | 期中已考知识点 |

```bash
BF.RESERVE bf:student:phone:registered 0.01 1000      # OK
BF.ADD bf:student:phone:registered 13800000001        # (integer) 1
BF.EXISTS bf:student:phone:registered 13800000001     # (integer) 1
BF.EXISTS bf:student:phone:registered 13900000000     # (integer) 0（一定不存在）
BF.INFO bf:student:phone:registered                   # Capacity / Size / Number of filters ...
BF.MADD bf:student:phone:registered 13800000002 13800000003
```

## cuckoo-filter

判重且**支持删除**

**取值视角**：桶数组 + 指纹，可比布隆过滤器更低的空间开销，并支持删除。

| key | 操作 | 结果 | 说明 |
|---|---|---|---|
| cf:student:id:used | `CF.ADD student:S001` | 1 | 学号占用登记 |
| cf:student:id:used | `CF.ADDNX student:S001` | 0 | 已存在，不再插入 |
| cf:student:id:used | `CF.EXISTS student:S001` | 1 | 判定存在 |
| cf:student:id:used | `CF.DEL student:S004` | 1 | 删除（转学） |
| cf:student:id:used | `CF.EXISTS student:S004` | 0 | 删除后判定为不存在 |
| cf:phone:used | `CF.ADDNX 13800000009` | 1 | 家长手机号判重 |

```bash
CF.RESERVE cf:student:id:used 1000          # OK
CF.ADD cf:student:id:used student:S001      # (integer) 1
CF.EXISTS cf:student:id:used student:S001   # (integer) 1
CF.DEL cf:student:id:used student:S004      # (integer) 1
CF.COUNT cf:student:id:used student:S001    # (integer) 1
CF.INFO cf:student:id:used                  # Size / Number of buckets / Bucket size ...
```

## count-min-sketch

知识点答题频次

**取值视角**：`width × depth` 计数器矩阵，多哈希取值取最小；**只高估、不低估**。

| key | 元素（知识点） | 估算频次 | 真实频次 | 说明 |
|---|---|---|---|---|
| cms:exam:E2:knowledge_freq | 一元二次方程 | 128 | 128 | 与真实值一致 |
| cms:exam:E2:knowledge_freq | 二次函数图像 | 96 | 95 | 高估 1 |
| cms:exam:E2:knowledge_freq | 相似三角形 | 88 | 88 | |
| cms:exam:E2:knowledge_freq | 圆的切线 | 74 | 73 | 高估 1 |
| cms:exam:E2:knowledge_freq | 概率初步 | 62 | 62 | |

```bash
CMS.INITBYDIM cms:exam:E2:knowledge_freq 2000 5      # OK（width=2000, depth=5）
```

## top-k

**取值视角**：HeavyKeeper 桶 + 最小堆，维护 k 个最高频元素（无需精确计数）。

## t-digest

成绩分布

**取值视角**：把样本聚成若干 centroid，用固定内存估算分位数（默认 `compression = 100`）。

| 查询 | 结果 | 说明 |
|---|---|---|
| `TDIGEST.MIN` | 70 | 数学最低分（S004） |
| `TDIGEST.MAX` | 108 | 数学最高分（S001） |
| `TDIGEST.QUANTILE 0.5` | 96 | 中位数 |
| `TDIGEST.QUANTILE 0.9` | 108 | 90 分位 |
| `TDIGEST.CDF 96` | 0.6 | ≤96 分的比例 |
| `TDIGEST.TRIMMED_MEAN 0.1 0.9` | 95.0 | 去掉两端 10% 后的均值 |
| `TDIGEST.RANK 108` | 5 | 108 分的升序名次 |

```bash
TDIGEST.CREATE tdigest:exam:E2:SUB2:score COMPRESSION 100   # OK
TDIGEST.ADD tdigest:exam:E2:SUB2:score 108 96 102 70 91     # OK
TDIGEST.QUANTILE tdigest:exam:E2:SUB2:score 0.5             # 96
TDIGEST.CDF tdigest:exam:E2:SUB2:score 96                   # 0.6
TDIGEST.BYRANK tdigest:exam:E2:SUB2:score 0                 # 最小值 70
TDIGEST.INFO tdigest:exam:E2:SUB2:score                     # Compression / Merged nodes ...
```

# Key命名规范总表

命名建议：`业务:实体:标识:维度`，用冒号分层，便于 `SCAN` 按前缀遍历（例如 `SCAN 0 MATCH student:* COUNT 100`）。

| 前缀 | 数据类型 | 含义 | 示例 |
|---|---|---|---|
| `school:` / `class:` / `student:` / `subject:` / `exam:` | 视场景而定 | 业务实体 | `student:S001`（hash 档案） |
| `cache:` | string | 缓存（序列化后的对象） | `cache:class:C1:profile` |
| `lock:` | string | 分布式锁 | `lock:score:import:C1` |
| `stream:` | stream | 事件流 | `stream:score:events` |
| `ts:` | timeseries | 时间序列 | `ts:S001:SUB2` |
| `vset:` | vector-set | 向量集合 | `vset:student:profile` |
| `hll:` | hyperloglog | 基数估算 | `hll:exam:E2:uv:student` |
| `bf:` | bloom-filter | 布隆过滤器 | `bf:student:phone:registered` |
| `cf:` | cuckoo-filter | 布谷鸟过滤器 | `cf:student:id:used` |
| `cms:` | count-min-sketch | 频次估算 | `cms:exam:E2:knowledge_freq` |
| `topk:` | top-k | Top-K 榜单 | `topk:exam:E2:wrong_knowledge` |
| `tdigest:` | t-digest | 分位数估算 | `tdigest:exam:E2:SUB2:score` |
