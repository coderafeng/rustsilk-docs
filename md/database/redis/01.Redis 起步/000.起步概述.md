# 环境要求

- 任意支持 Docker 的操作系统，或 Ubuntu 22.04+/24.04+；
- 建议直接使用 Redis 8.x 最新版（新特性见 [10.Redis 版本特性](../10.Redis%20版本特性/000.版本特性概述.md)）。
