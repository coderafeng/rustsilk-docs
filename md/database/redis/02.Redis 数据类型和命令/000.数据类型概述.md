# 概述

Redis 是一个数据结构服务器。其核心功能是提供一系列原生数据类型。

> [!note] 关于"归属 / 可用性"
> 部分类型并非安装即有：**Stack 模块**类型在旧版本需额外安装 Redis Stack；自 **Redis 8.0** 起，RedisJSON、RedisTimeSeries、RedisBloom、Query Engine（搜索/向量）等模块已全部并入 Redis 开源版。使用低版本前请确认命令是否可用（`COMMAND DOCS <命令>` 可查询）。

Redis 实现了以下数据类型：

| 分类 | 专业术语 | 中文术语 | 归属 / 可用性 | 主要作用 | 使用场景 |
|------|----------|----------|----------------|----------|----------|
| 核心通用类型 | **[String](./010.String%20字符串.md#概述)** | 字符串 | OSS 核心 · 1.0+ | 二进制安全的字节序列，可存储文本、二进制数据、整数或浮点数，最大 512MB | 缓存对象、计数器、分布式锁、会话令牌、Feature Flag |
| | **[Hash](./020.Hash%20哈希.md#概述)** | 哈希 | OSS 核心 · 1.0+ | 在单个键内存储字段-值对的记录类型，类似 Java HashMap 或 Python 字典 | 用户会话建模、对象属性存储、购物车、配置管理 |
| | **[List](./030.List%20列表.md#概述)** | 列表 | OSS 核心 · 1.0+ | 按插入顺序排列的字符串序列，底层为快速链表（quicklist），支持两端压入/弹出 | 消息队列、任务队列、最新动态时间线、栈/队列实现 |
| | **[Set](./040.Set%20无序集合.md#概述)** | 无序集合 | OSS 核心 · 1.0+ | 无序的唯一字符串集合，支持交、并、差等集合运算 | 标签系统、好友关系、去重统计、共同关注 |
| | **[Sorted Set](./050.Sorted%20Set%20有序集合.md#概述)** | 有序集合 | OSS 核心 · 1.0+ | 每个元素关联一个分数（score），按分数自动排序，支持范围查询和排名操作 | 排行榜、优先级队列、延迟任务调度、范围查询 |
| | **[Stream](./060.Stream%20流.md#概述)** | 流 | OSS 核心 · 5.0+ | 按时间顺序排列的条目序列，每个条目包含字段-值对，支持消费者组模式 | 事件溯源、消息总线、日志聚合、实时数据处理 |
| 字符串派生类型 | **[Bitmaps](./070.Bitmaps%20位图.md#概述)** | 位图 | OSS 核心 · 2.6+ | 在 String 上以位为单位进行操作的集合，每个 bit 表示一个布尔值，支持 SETBIT/GETBIT/BITCOUNT/BITOP 等命令，1 bit 即可存储一个状态 | 用户签到、在线状态统计、活跃用户分析、布隆过滤器的底层实现 |
| | **[Bitfields](./080.Bitfields%20位域.md#概述)** | 位域 | OSS 核心 · 3.2+ | 将 String 视为位数组，对任意位宽（1~64 位有符号、1~63 位无符号）的整数字段进行读写和原子增减操作，支持多种溢出策略 | 紧凑计数器、游戏状态编码、多标志位管理、实时指标聚合 |
| 索引序列类型 | **[Array](./090.Array%20数组.md#概述)** | 数组 | Stack 模块（Redis Array），开源版需自行加载 | 稀疏的、可按整数索引寻址的字符串序列，支持 O(1) 随机访问、范围读取和服务端聚合，设置高位索引不会分配大量内存 | 事件日志、环形缓冲区、传感器读数、追加密集型序列 |
| 地理空间类型 | **[Geospatial](./100.Geospatial%20地理空间.md#概述)** | 地理空间 | OSS 核心 · 3.2+（基于 Sorted Set） | 基于 Sorted Set 实现（使用 Geohash 算法编码经纬度到 score），支持半径查询、边界框查询和距离计算，底层并非独立数据类型 | 附近商家推荐、打车距离计算、位置围栏、地理围栏告警 |
| 文档类型 | **[JSON](./110.JSON.md#概述)** | JSON 文档 | 原 RedisJSON 模块 · 8.0+ 并入开源版 | 原生存储符合 ECMA-404 标准的结构化 JSON 文档，支持 JSONPath 语法进行细粒度访问和原子更新部分文档，无需序列化/反序列化 | 会话管理（层级数据）、产品目录、用户档案、配置中心、文档数据库 |
| 时序类型 | **[Time Series](./120.Time%20Series%20时间序列.md#概述)** | 时间序列 | 原 RedisTimeSeries 模块 · 8.0+ 并入开源版 | 专为时序数据优化的数据结构，支持自动降采样、保留策略、标签过滤和内置聚合函数（avg/sum/min/max/range/count/first/last） | IoT 传感器监控、系统遥测、股票价格追踪、应用性能指标、实时分析仪表盘 |
| 向量类型 | **[Vector Set](./130.Vector%20Set%20向量集合.md#概述)** | 向量集合 | OSS 核心 · 8.0 新增 | 由 Redis 创始人 Salvatore Sanfilippo 开发的基于 HNSW 的数据结构，将字符串元素与高维向量关联，支持相似性搜索、量化、降维和属性过滤 | 语义搜索、RAG（检索增强生成）、推荐系统、图像相似性匹配、文本分类 |
| 概率数据类型 | **[HyperLogLog](./140.HyperLogLog%20基数估计.md#概述)** | 基数估计 | OSS 核心 · 2.8+ | 以固定 12KB 内存估算集合中不重复元素的基数（Cardinality），标准误差约 0.81%，可统计 2^64 个元素 | UV/DAU/MAU 统计、独立 IP 计数、搜索词去重、广告触达人数估算 |
| | **[Bloom Filter](./150.Bloom%20Filter%20布隆过滤器.md#概述)** | 布隆过滤器 | 原 RedisBloom 模块 · 6.2 起并入开源版 | 判断元素是否在集合中，存在可调误判率，不支持删除 | 用户名/邮箱唯一性预检、URL 去重、垃圾内容过滤、缓存穿透防护 |
| | **[Cuckoo Filter](./160.Cuckoo%20Filter%20布谷鸟过滤器.md#概述)** | 布谷鸟过滤器 | 原 RedisBloom 模块 · 6.2 起并入开源版 | 相比布隆过滤器支持删除操作，同样以低内存判断集合成员关系 | 动态增删的成员判断、广告去重、实时黑名单 |
| | **[Count-Min Sketch](./170.Count-Min%20Sketch%20计数最小略图.md#概述)** | 计数最小略图 | 原 RedisBloom 模块 · 6.2 起并入开源版 | 亚线性空间内近似统计元素出现频率 | 热点数据检测、流量统计、重击者检测 |
| | **[Top-K](./180.Top-K.md#概述)** | Top-K | 原 RedisBloom 模块 · 6.2 起并入开源版 | 高效维护数据流中出现频率最高的 K 个元素 | 热搜榜、热门商品排行、异常 IP 检测 |
| | **[t-digest](./190.t-digest.md#概述)** | t-摘要 | 原 RedisBloom 模块 · 6.2 起并入开源版 | 估计数据流的百分位数和分位数，支持合并操作 | 延迟百分位（P50/P95/P99）监控、SLA 统计、性能指标分析 |
