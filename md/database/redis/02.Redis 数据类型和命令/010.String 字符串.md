# 概述

String 是二进制安全的字节序列，可存储文本、二进制数据、整数或浮点数，单个 value 最大 512MB。

- 归属与可用性：Redis 开源核心类型（1.0+）
- 官方文档：<https://redis.io/docs/latest/develop/data-types/strings/>

底层以 **SDS（Simple Dynamic String）** 存储：O(1) 取长度、杜绝缓冲区溢出、预留空间减少重分配。按内容分三种编码：纯整数用 `int`，短字符串（≤44 字节）用 `embstr`（一次分配、读写一体），其余用 `raw`。可用 `OBJECT ENCODING key` 查看。

# 命令速查

| 命令 | 说明 | 复杂度 |
|------|------|--------|
| `SET key value [EX s \| PX ms \| EXAT ts \| PXAT ts] [NX \| XX] [KEEPTTL] [GET]` | 写入，可原子携带过期与条件（`GET` 7.0+；8.4 起支持 CAS 比较并设置） | O(1) |
| `GET key` | 读取 | O(1) |
| `GETEX key [EX/PX/...]` | 读取并刷新过期（6.2+） | O(1) |
| `GETDEL key` | 取出并删除，原子"读一次"（6.2+） | O(1) |
| `MSET k1 v1 ...` / `MGET k1 ...` | 批量读写，整批原子 | O(N) |
| `SETNX key value` / `SETEX key s value` | 旧式写法，等价 `SET ... NX` / `SET ... EX` | O(1) |
| `INCR` / `INCRBY n` / `INCRBYFLOAT f` / `DECR` / `DECRBY n` | 原子增减（整数 64 位，超界报错） | O(1) |
| `APPEND key value` / `STRLEN key` | 追加 / 取长度 | O(1)* |
| `SETRANGE` / `GETRANGE` | 按偏移写 / 读子串 | O(len) |
| `TYPE` / `TTL` / `EXPIRE` / `PERSIST` | 键级通用操作 | O(1) |

*APPEND 均摊 O(1)。

# 典型场景

1. **缓存对象**：`SET art:1024 '<json>' EX 300`——缓存必须带 TTL，避免脏数据永驻。
2. **计数器**：`INCR page:view:1024`；限流场景 8.8+ 可直接用原子窗口限流命令 `INCREX`（见 [Redis 8.8 版本特性](../10.Redis%20版本特性/080.Redis8.8.md)）。
3. **分布式锁**：`SET lock:order NX PX 30000`，value 存"随机令牌"，解锁用 Lua 比较令牌后删除——详见 [020.事务与分布式锁](../08.工程化/020.事务与分布式锁.md)。
4. **一次性令牌/验证码**：`GETDEL` 原子取出，天然防重放。
5. **局部更新**（不落整对象）：`INCRBYFLOAT balance 10.5`。

# 避坑

- **MSET/MGET 在 Cluster 下**跨槽键会报 CROSSSLOT，用 hash tag（如 `{user:1000}:name`）把关联键约束到同槽，但注意热点槽倾斜。
- **SETNX + EXPIRE 两条命令非原子**：中间宕机留下"永不失效的死锁"——必须用单条 `SET ... NX EX`。
- **大 value（MB 级）**：拖慢网络与主从复制、过期删除时阻塞——拆字段转 Hash 或压缩存储，删除用 `UNLINK`。参见 [070.大key与热key](../08.工程化/070.大key与热key.md)。
- **INCR 到 2^63-1 报错** `ERR increment would produce NaN`；负数用 DECRBY。
- 对非 String 键执行 `GET` 返回 `WRONGTYPE`——先 `TYPE` 判断或保证键空间隔离。
- `GETRANGE`/`SETRANGE` 越界读返回空、越界写自动补零扩展，注意恶意撑大键。

# 总结

- String 是最基础也最高频的类型：缓存、计数、锁、令牌四大件离不开它；
- 写操作优先用带选项的单条 `SET`（NX/XX/EX/KEEPTTL），拒绝多命令拼装；
- 原子性是 Redis 的价值所在——凡"判断再修改"，先查有没有单命令方案（SET NX、GETDEL、INCREX、CAS）。
