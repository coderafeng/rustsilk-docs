# 概述

本篇覆盖官方 9.15 节 **XML 函数**。PostgreSQL 有 `xml` 类型，配套三类能力：**构造/拼接 XML**、**类型转换与校验**、**SQL/XML 查询与生成**（`XMLEXISTS`、`XMLTABLE`、`table_to_xml` 等）。

用之前明确：

- **`xmlconcat` 会自动去掉多余的 XML 声明**，只在最外层用 `xmlroot` 统一加版本；直接拼带 `<?xml?>` 的片段会报错或产生非法文档。
- **`xmlelement`/`xmlforest`/`xmlpi` 是"生成式"语法**（要写 `NAME`、`AS` 这类 SQL/XML 关键字），和函数式风格不同，容易在语法上翻车，示例照抄最稳。
- **`XMLTABLE` 才是把 XML 拆回关系行的主力**，相当于 JSON 里的 `json_to_record`。

> 现代项目里 XML 已大量被 JSON 取代（见 **[JSON函数](./015.JSON函数.md)**）；本篇按官方清单覆盖常用项，冷门函数给签名与最小示例。

# xmlagg

`xmlagg(xml [ORDER BY ...]) → xml`

**聚合函数**：把多行的 xml 值按序拼接成一个。

```sql
SELECT xmlagg(x) FROM test;
SELECT xmlagg(x ORDER BY y DESC) FROM test;
```

# xmlcomment

`xmlcomment(text) → xml`

生成 **XML 注释** `<!--...-->`；文本里不能含 `--`。

```sql
SELECT xmlcomment('hello');   -- <!--hello-->
```

# xmlconcat

`xmlconcat(xml [, ...]) → xml`

**拼接多个 XML 片段**为一个（自动剥离多余的 XML 声明，NULL 被忽略）。

```sql
SELECT xmlconcat('<abc/>', '<bar>foo</bar>');   -- <abc/><bar>foo</bar>
```

# xmlelement

`xmlelement(NAME name [, XMLATTRIBUTES(...)] [, content [, ...]]) → xml`

按 SQL/XML 语法**构造一个元素**，可带属性与内容。

```sql
SELECT xmlelement(name foo, 'content');           -- <foo>content</foo>
SELECT xmlelement(name foo, xmlattributes('xyz' AS bar));   -- <foo bar="xyz"/>
```

# xmlexists

`XMLEXISTS(text PASSING [BY REF|VALUE] xml ...) → boolean`

判断 **XPath 表达式**是否匹配到结果（返回 boolean）。

```sql
SELECT xmlexists('//town[text() = ''Toronto'']'
  PASSING BY VALUE '<towns><town>Toronto</town></towns>');   -- true
```

# xmlforest

`xmlforest(content [AS name] [, ...]) → xml`

把**表达式/列生成一组同名元素**（NULL 值对应的元素会被省略），常嵌在 `xmlelement` 里。

```sql
SELECT xmlforest('abc' AS foo, 123 AS bar);   -- <foo>abc</foo><bar>123</bar>
```

# xmlisdocument

`xmlisdocument(xml) → boolean`；同义 `xml_is_well_formed_document`

判断字符串是否为**格式良好且声明合法的 XML 文档**。

```sql
SELECT xmlisdocument('<a><b/></a>');   -- true
```

# xmlparse

`XMLPARSE({DOCUMENT|CONTENT} value) → xml`

把**文本显式解析**为 xml 类型；`DOCUMENT` 要求完整文档，`CONTENT` 允许片段。

```sql
SELECT xmlparse(document '<?xml version="1.1"?><content>abc</content>');
```

# xmlpi

`xmlpi(NAME name [, content]) → xml`

生成 **XML 处理指令** `<?name content?>`。

```sql
SELECT xmlpi(name php, 'echo "hello";');   -- <?php echo "hello";?>
```

# xmlroot

`xmlroot(xml, VERSION {text|NO VALUE} [, STANDALONE {YES|NO|NO VALUE}]) → xml`

为 xml **设置/覆盖 XML 声明**（版本、standalone）。

```sql
SELECT xmlroot(xmlparse(document '<content>abc</content>'), version '1.0');
```

# xmlserialize

`XMLSERIALIZE({DOCUMENT|CONTENT} xml AS type [VERSION ...]) → type`

把 xml **序列化为文本/bytea** 输出（常用于导出）。

```sql
SELECT xmlserialize(document '<a/> ' AS text);
```

# xmltext

`xmltext(text) → xml`

把一段**文本按 XML 内容解析**（自动转义 `&`、`<` 等），比手工拼字符串安全。

```sql
SELECT xmltext('< foo & bar >');   -- &lt; foo &amp; bar &gt;
```

# XMLTABLE

`XMLTABLE(rows_xpath PASSING xml COLUMNS col type PATH ...)`

**表函数**：按 XPath 把 XML 文档拆成**多行多列**关系结果。

```sql
SELECT * FROM XMLTABLE('/root/item'
  PASSING '<root><item>1</item><item>2</item></root>'
  COLUMNS val text PATH '.');   -- 两行
```

# table_to_xml

`table_to_xml(table regclass, nulls bool, tableforest bool, targetns text) → xml`

把**整张表**转成 XML；同族还有 `query_to_xml`、`cursor_to_xml`、`schema_to_xml`、`database_to_xml`，及带 `_schema`/`_and_xmlschema` 后缀的连 XSD 版本。

```sql
SELECT table_to_xml('emp', false, true, '');
```

> 这些"关系→XML"函数适合老系统集成导出；新接口一般直接 `json_agg`/`jsonb_build_object` 输出 JSON。
