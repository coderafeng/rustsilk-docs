# 概述

本篇覆盖官方 9.12 节**网络地址函数**。`inet`（IP + 可选掩码，可存主机地址）、`cidr`（网络段，掩码右侧必须为 0）、`macaddr`/`macaddr8`（MAC 地址）三类类型配套一批函数。

先理清 `inet` 与 `cidr`：

- **任何 `cidr` 可隐式转 `inet`**；把 `inet` 转 `cidr` 时，掩码右侧的位会被**静默清零**。所以存"具体主机 IP"用 `inet`，存"网段/CIDR 路由"用 `cidr`。
-  subnet 包含判断更多用**操作符** `<<` `<<=` `>>` `>>=` `&&`（只看网络部分），比函数直观；位运算 `~ & |` 和地址加减 `inet ± bigint` 也常用。

> `inet` 上的 `<<=`/`&&` 等可走 **B-tree `inet_ops`** 或 **GiST `gist_inet_ops`** 索引（见 **[操作符类和操作符族](../06.PostgreSQL%20索引/050.操作符类和操作符族.md)**）。

# abbrev

`abbrev(inet) → text`；`abbrev(cidr) → text`

生成**缩写显示文本**：`inet` 会省略 `/32` 之类冗余掩码；`cidr` 会去掉掩码右侧的全零字节。

```sql
SELECT abbrev(inet '10.1.0.0/32');   -- 10.1.0.0
SELECT abbrev(cidr '10.1.0.0/16');   -- 10.1/16
```

# broadcast

`broadcast(inet) → inet`

计算该地址所在网络的**广播地址**。

```sql
SELECT broadcast(inet '192.168.1.5/24');   -- 192.168.1.255/24
```

# family

`family(inet) → integer`

返回地址**族**：`4`（IPv4）或 `6`（IPv6）。

```sql
SELECT family(inet '::1');   -- 6
```

# host

`host(inet) → text`

返回**纯 IP 文本**，忽略掩码。

```sql
SELECT host(inet '192.168.1.0/24');   -- 192.168.1.0
```

# hostmask

`hostmask(inet) → inet`

计算**主机掩码**（netmask 取反）。

```sql
SELECT hostmask(inet '192.168.23.20/30');   -- 0.0.0.3
```

# inet_merge

`inet_merge(inet, inet) → cidr`

返回**同时包含两个网络的最小网络**（聚合路由，PG18 新增）。

```sql
SELECT inet_merge(inet '192.168.1.5/24', inet '192.168.2.5/24');   -- 192.168.0.0/22
```

> 做路由汇总/网段合并的利器，省去手算前缀长度。

# inet_same_family

`inet_same_family(inet, inet) → boolean`

判断两个地址是否**同属一个 IP 族**（IPv4/IPv6 不能混算，很多 `inet` 运算会先要求同族）。

```sql
SELECT inet_same_family(inet '192.168.1.5/24', inet '::1');   -- false
```

# masklen

`masklen(inet) → integer`

返回**掩码位数**。

```sql
SELECT masklen(inet '192.168.1.5/24');   -- 24
```

# netmask

`netmask(inet) → inet`

计算**子网掩码**。

```sql
SELECT netmask(inet '192.168.1.5/24');   -- 255.255.255.0
```

# network

`network(inet) → cidr`

返回**网络部分**（掩码右侧清零），等价于把 `inet` 转成 `cidr`。

```sql
SELECT network(inet '192.168.1.5/24');   -- 192.168.1.0/24
```

# set_masklen

`set_masklen(inet, integer) → inet`；`set_masklen(cidr, integer) → cidr`

**改掩码长度**。`inet` 版只改前缀、地址部分不动；`cidr` 版会把新掩码右侧清零。

```sql
SELECT set_masklen(inet '192.168.1.5/24', 16);    -- 192.168.1.5/16
SELECT set_masklen(cidr '192.168.1.0/24', 16);    -- 192.168.0.0/16
```

# text

`text(inet) → text`

返回**不缩写**的完整地址 + 掩码文本（等同显式转 `text`）。

```sql
SELECT text(inet '192.168.1.5');   -- 192.168.1.5/32
```

# trunc

`trunc(macaddr) → macaddr`；`trunc(macaddr8) → macaddr8`

把 MAC 地址**后 3 字节（macaddr）/ 后 5 字节（macaddr8）清零**，只留厂商标识前缀。

```sql
SELECT trunc(macaddr '12:34:56:78:90:ab');       -- 12:34:56:00:00:00
SELECT trunc(macaddr8 '12:34:56:78:90:ab:cd:ef'); -- 12:34:56:00:00:00:00:00
```

# macaddr8_set7bit

`macaddr8_set7bit(macaddr8) → macaddr8`

把第 7 位置 1，生成 **modified EUI-64** 地址（用于嵌入 IPv6 接口标识）。

```sql
SELECT macaddr8_set7bit(macaddr8 '00:11:22:33:44:55:66:77');
```
