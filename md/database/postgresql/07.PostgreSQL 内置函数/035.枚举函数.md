# 概述

本篇覆盖官方 9.9 节末尾的**枚举支持函数**。用户自定义枚举类型（`CREATE TYPE ... AS ENUM`）本质是一组有序标签，PostgreSQL 提供少量函数在"某个枚举值"与"整个枚举类型/范围"之间转换。

- 枚举的**排序按定义顺序**，不是字母序，改顺序要 `ALTER TYPE ... ADD VALUE`/重建。
- 这几个函数主要用于**动态获取枚举全部取值**（做校验、下拉字典）或比较相邻标签。

> 枚举类型定义见 **[枚举类型](../04.PostgreSQL%20数据类型/035.枚举类型.md)**。

# enum_first

`enum_first(anyenum) → anyenum`

返回该枚举类型的**第一个标签**，与入参具体是哪个值无关（只看类型）。

```sql
CREATE TYPE mood AS ENUM ('sad', 'ok', 'happy');
SELECT enum_first(NULL::mood);   -- sad
```

> 入参只需能确定类型即可，常写 `NULL::mood`。

# enum_last

`enum_last(anyenum) → anyenum`

返回该枚举类型的**最后一个标签**。

```sql
SELECT enum_last(NULL::mood);   -- happy
```

# enum_range

`enum_range(anyenum) → anyarray`；`enum_range(anyenum, anyenum) → anyarray`

无边界参数时返回**全部标签**组成的数组；给定起止两个值时返回该**闭区间内**的标签数组（顺序错会自动反向，越界部分裁剪）。

```sql
SELECT enum_range(NULL::mood);                 -- {sad,ok,happy}
SELECT enum_range('ok'::mood, 'happy'::mood); -- {ok,happy}
SELECT enum_range('happy'::mood, 'sad'::mood);-- {sad,ok,happy}（自动反向）
```

> 实用技巧：`enum_range` + `unnest` 是把枚举转成"字典表行"做权限/校验列表的标准写法。集合展开见 **[集合返回函数](./040.集合函数.md)**。
