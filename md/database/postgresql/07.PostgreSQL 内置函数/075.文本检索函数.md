# 概述

本篇覆盖官方 9.13 节**全文检索函数**。全文检索把文档解析成 `tsvector`（规范化词位 + 位置 + 权重），把查询解析成 `tsquery`（词位 + 布尔/位置运算），再用 `@@` 匹配、`ts_rank` 打分。

必须先建立两个心智模型：

- **`tsvector` 是被"分析过的文档"，`tsquery` 是被"分析过的查询"**：两者都要经过 **configuration（解析器 + 词典链）** 处理，英文走词干化（`rats`→`rat`），中文需专门配置或 `zhparser` 分词扩展。
- **生成 `tsvector` 一定要带 config**：`to_tsvector('english', doc)`；生产上几乎都会建 **GIN 索引**（见 **[索引类型](../06.PostgreSQL%20索引/005.索引类型.md)**）并配合触发器维护，别每次查询现算。

> `plainto_`/`phraseto_`/`websearch_to_tsquery` 是为了**安全接收用户自由输入**而生——直接 `to_tsquery(用户输入)` 会因语法符号报错或被注入布尔逻辑。

# to_tsvector

`to_tsvector([config regconfig,] document text|jsonb) → tsvector`

把文档**分析为 tsvector**（词位、位置、权重）。

```sql
SELECT to_tsvector('english', 'The Fat Rats');   -- 'fat':2 'rat':3
```

> 省略 config 会用会话 `default_text_search_config`；跨环境部署务必显式写 config，否则分词结果随库配置漂移。

# to_tsquery

`to_tsquery([config regconfig,] query text) → tsquery`

按**检索语法**（`&`、`|`、`!`、`<->` 等）解析查询串，符号非法即报错。

```sql
SELECT to_tsquery('english', 'The & Fat & Rats');   -- 'fat' & 'rat'
```

> 只用于程序构造的、已规范化的表达式；用户输入用下面的 `*to_tsquery` 变体。

# plainto_tsquery

`plainto_tsquery([config,] query text) → tsquery`

把输入当**纯文本**、用 AND 连接词位，忽略所有操作符——适合"关键词框"。

```sql
SELECT plainto_tsquery('english', 'The Fat Rats');   -- 'fat' & 'rat'
```

# phraseto_tsquery

`phraseto_tsquery([config,] query text) → tsquery`

把输入解析成**短语查询**（词位用 `<->` 相邻连接），要求词序相邻。

```sql
SELECT phraseto_tsquery('english', 'Fat Rats');   -- 'fat' <-> 'rat'
```

# websearch_to_tsquery

`websearch_to_tsquery([config,] query text) → tsquery`

按**搜索引擎习惯**解析：双引号=短语、`or`、`-`/`!`=排除、其余 AND。最贴合"给用户一个搜索框"。

```sql
SELECT websearch_to_tsquery('english', '"fat rat" or cat dog');
-- 'fat' <-> 'rat' | 'cat' & 'dog'
```

# ts_headline

`ts_headline([config,] document, query [, options text]) → text`

生成**命中片段高亮**（默认用 `<b>` 包裹匹配词）。

```sql
SELECT ts_headline('The fat cat ate the rat.', 'cat');   -- The fat <b>cat</b> ate the rat.
```

# ts_rewrite

`ts_rewrite(query tsquery, target tsquery, replacement tsquery) → tsquery`

在已有 `tsquery` 里**替换子表达式**（做查询扩展/同义词改写）。

```sql
SELECT ts_rewrite('a & b'::tsquery, 'a'::tsquery, 'foo|bar'::tsquery);
-- 'b' & ( 'foo' | 'bar' )
```

# ts_stat

`ts_stat(docurl text [, weights text [, config regconfig]]) → setof(word text, ndoc integer, nfreq integer)`

对一批文档（或一段 SQL 返回的 tsvector/text）**统计词频**，每行一个词位：`ndoc` 出现它的文档数，`nfreq` 总出现次数。做词云/停用词分析用。

```sql
SELECT word, ndoc FROM ts_stat('SELECT body FROM articles') ORDER BY ndoc DESC LIMIT 20;
```

# ts_debug

`ts_debug([config,] text) → setof(alias, description, token, dictionaries, dictionary, parts)`

**逐步调试**分词：把输入切成 token，展示每个 token 命中的词典与归一结果。排查"为什么这个词搜不到"的首选。

```sql
SELECT * FROM ts_debug('english', 'The Brightest supernovaes');
```

# ts_lexize

`ts_lexize(dict regdictionary, token text) → text[]`

用**单个词典**对一个 token 做处理（看词干化/同义词展开结果）。

```sql
SELECT ts_lexize('english_stem', 'stars');   -- {star}
```

# ts_parse

`ts_parse(parser_name|oid, text) → setof(tid integer, token text)`

只跑**解析器**（不接词典），把文本按 token 类型切分，用于理解 parser 行为。

```sql
SELECT * FROM ts_parse('default', 'foo - bar');
```

# ts_token_type

`ts_token_type(parser_name|oid) → setof(tid, alias, description)`

列出某**解析器支持的 token 类型**。

```sql
SELECT * FROM ts_token_type('default');
```

# setweight

`setweight(vector tsvector, weight "char" [, positions smallint[]]) → tsvector`

给 tsvector（或其指定词位）设置**权重 A/B/C/D**，供 `ts_rank` 加权排序。

```sql
SELECT setweight(to_tsvector('title'), 'A') || setweight(to_tsvector('body'), 'B');
```

> 典型：标题权重 A、正文权重 B，标题命中排更前。

# length

`length(tsvector) → integer`

返回 tsvector 中**不同词位的个数**。

```sql
SELECT length('fat:2,4 cat:3 rat:5A'::tsvector);   -- 3
```

# numnode

`numnode(tsquery) → integer`

返回 tsquery **语法树的节点数**（词位 + 运算符），可用于判断查询是否"实质为空"（如只有停用词返回 0）。

```sql
SELECT numnode('(fat & rat) | cat'::tsquery);   -- 5
```

# numunique

`numunique(tsvector) → integer`

返回 tsvector 中**去重后的词位数**（与 `length` 语义一致，历史保留）。

```sql
SELECT numunique('fat:2,4 cat:3 fat:5'::tsvector);   -- 2
```

# weight

`weight(tsvector) → "char"`

返回 tsvector 的**最高权重**（A/B/C/D；空为 D）。

```sql
SELECT weight(setweight('cat:3'::tsvector, 'A'));   -- A
```

# strip

`strip(tsvector) → tsvector`

**去掉位置和权重**，只留词位（索引/比较更粗粒度时用）。

```sql
SELECT strip('fat:2,4 cat:3 rat:5A'::tsvector);   -- 'cat' 'fat' 'rat'
```

# ts_delete

`ts_delete(vector tsvector, word text) → tsvector`；数组版删多个

从 tsvector 里**删除指定词位**。

```sql
SELECT ts_delete('fat:2,4 cat:3 rat:5A'::tsvector, 'fat');   -- 'cat':3 'rat':5A
```

# ts_filter

`ts_filter(vector tsvector, weights "char"[]) → tsvector`

只**保留指定权重**的词位。

```sql
SELECT ts_filter('cat:3B rat:5A'::tsvector, '{a,b}');   -- 保留 A/B 权重
```

# ts_rank

`ts_rank(vector tsvector, query tsquery [, weights real[]]) → real`

按**词频/权重**给文档打分排序（不考虑词间距离）。

```sql
SELECT ts_rank(to_tsvector('raining cats and dogs'), 'cat'::tsquery);   -- 0.06079271
```

# ts_rank_cd

`ts_rank_cd(vector, query [, weights]) → real`

**覆盖密度（cover density）排序**：额外考虑命中词的相邻紧密程度，短语/邻近查询更准。

```sql
SELECT ts_rank_cd(to_tsvector('raining cats and dogs'), 'cat'::tsquery);   -- 0.1
```

# get_current_ts_config

`get_current_ts_config() → regconfig`

返回当前会话的**默认文本搜索配置**。

```sql
SELECT get_current_ts_config();   -- english
```

# tsvector_concat

`tsvector_concat(tsvector, tsvector) → tsvector`（操作符 `||`）

**合并两个 tsvector**。

```sql
SELECT to_tsvector('a b') || to_tsvector('c d');
```
