# 概述

本篇覆盖官方 9.20 节**集合返回函数**（Set Returning Functions, SRF）。这类函数"一次调用返回多行"，可直接放在 `FROM` 里当表用，也能放进 `SELECT` 列表（每值展开一行）。

- 它们是把"数字序列 / 数组下标"**变成行集**的主力，替代了很多游标、循环写法。
- 放在 `SELECT` 列表时，若还有其他普通列，PostgreSQL 会按行对齐补齐（多值列决定行数）。

> 数组打平成行还可用 `unnest`，见 **[数组函数](./020.数组函数.md)**。

# generate_series

`generate_series(start, stop [, step]) → setof integer|bigint|numeric`
`generate_series(start, stop [, step interval]) → setof timestamp|timestamptz`

生成一个**从 start 到 stop、步长 step 的等差序列**，每个值一行。数值版与日期时间版重载。

```sql
SELECT generate_series(1, 5);                 -- 1 2 3 4 5（五行）
SELECT generate_series(1, 10, 3);             -- 1 4 7 10
SELECT generate_series(2, 5) * 10;            -- 20 30 40 50
-- 按小时铺时间轴：
SELECT generate_series('2026-01-01'::timestamp, '2026-01-01 03:00', '1 hour');
```

> 高频用法：**造日历/补齐断档**——用 `generate_series` 生成连续日期再 `LEFT JOIN` 业务表，把没有数据的日期也显示成 0。step 为负可实现倒序；start>stop 且 step 正时会返回 0 行。

# generate_subscripts

`generate_subscripts(anyarray, int dimension) → setof integer`

返回指定维度上**所有存在元素的下标序列**（含空洞，锯齿数组按该行实际范围给），常与 `arr[i]` 配合手动遍历。

```sql
SELECT generate_subscripts(ARRAY['a','b','c'], 1);         -- 1 2 3
SELECT i, ARRAY['a','b','c'][i]
  FROM generate_subscripts(ARRAY['a','b','c'], 1) AS i;    -- 1|a 2|b 3|c
```

> 对比：只想要"值"用 `unnest` 更简洁；需要"**下标 + 值**"或自定义下标边界（配合 `array_lower`）时 `generate_subscripts` 才更合适。
