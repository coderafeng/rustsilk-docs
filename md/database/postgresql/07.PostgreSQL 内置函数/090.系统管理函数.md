# 概述

本篇覆盖官方 9.27 节**服务器管理函数**：终止/取消会话、重载配置、基础备份与 WAL 控制、读写服务器文件、咨询锁、复制槽、恢复状态等运维级能力。多数需要**超级用户或相应权限**，日常多由监控脚本、备份工具、DBA 使用。

按用途分组记忆：

- **进程/会话控制**：`pg_cancel_backend`（取消当前语句，温和）vs `pg_terminate_backend`（断开整个连接，强硬）。
- **配置生效**：改完 `postgresql.conf` 用 `pg_reload_conf()` 热加载，不用重启。
- **WAL/备份**：物理备份与 PITR 依赖 `pg_backup_start/stop`、`pg_switch_wal`、LSN 计算。
- **咨询锁**：`pg_advisory_lock` 用应用自定义 bigint 做互斥，不锁表行，适合任务去重/防并发跑批。

> 只读监控视图 `pg_stat_activity`、`pg_stat_replication` 见 **[日常维护](../05.PostgreSQL%20数据库管理/065.日常维护.md)**；`pg_stat_user_indexes` 见 **[检查索引使用情况](../06.PostgreSQL%20索引/060.检查索引使用情况.md)**。

# pg_cancel_backend

`pg_cancel_backend(pid integer) → boolean`

**取消**指定后端当前正在执行的查询（相当于发 `Ctrl-C`），连接保留。

```sql
SELECT pg_cancel_backend(12345);
```

# pg_terminate_backend

`pg_terminate_backend(pid integer [, timeout integer]) → boolean`

**终止**整个后端会话，强制断开连接并回滚其事务；比 cancel 强硬。

```sql
SELECT pg_terminate_backend(pid) FROM pg_stat_activity
 WHERE state='idle' AND state_change < now() - interval '1 hour';   -- 清理久闲连接
```

> 别误杀自己：常加 `AND pid <> pg_backend_pid()`。

# pg_reload_conf

`pg_reload_conf() → boolean`

让所有后端**重新读取配置文件**（`postgresql.conf`/`pg_hba.conf`），对支持热加载的参数即时生效。

```sql
SELECT pg_reload_conf();
```

# pg_rotate_logfile

`pg_rotate_logfile() → boolean`

**轮转服务器日志文件**（配合 `logging_collector`），便于按大小切割。

```sql
SELECT pg_rotate_logfile();
```

# pg_create_restore_point

`pg_create_restore_point(name text) → pg_lsn`

在当前 WAL 位置打一个**命名恢复点**，之后 PITR 可 `recovery_target_name` 精确回滚到这里。

```sql
SELECT pg_create_restore_point('before_bulk_delete');
```

# pg_current_wal_lsn

`pg_current_wal_lsn() → pg_lsn`

返回当前 WAL **写入位置（LSN）**，监控复制延迟的基准。

```sql
SELECT pg_current_wal_lsn();
```

# pg_walfile_name

`pg_walfile_name(lsn pg_lsn) → text`

把某个 LSN 换算成对应的 **WAL 段文件名**。

```sql
SELECT pg_walfile_name(pg_current_wal_lsn());
```

# pg_wal_lsn_diff

`pg_wal_lsn_diff(lsn1 pg_lsn, lsn2 pg_lsn) → numeric`

计算两个 LSN 之间的**字节差**，量化主从复制落后多少。

```sql
SELECT pg_wal_lsn_diff(pg_current_wal_lsn(), replay_lsn) AS lag_bytes
FROM pg_stat_replication;
```

# pg_switch_wal

`pg_switch_wal() → pg_lsn`

强制**切换到一个新的 WAL 段文件**（当前段立即写满归档），常配合备份/复制触发切段。

```sql
SELECT pg_switch_wal();
```

# pg_backup_start

`pg_backup_start(label text, fast boolean DEFAULT false) → text`

开始一次**底层物理基础备份**，返回备份起始标签；配套 `pg_backup_stop` 结束（旧名 `pg_start_backup`）。

```sql
SELECT pg_backup_start('nightly', false);
```

# pg_backup_stop

`pg_backup_stop(wait_for_archive boolean DEFAULT true) → record`

结束基础备份，返回结束 LSN 与 WAL 文件名，用于把备份点定界。

```sql
SELECT (pg_backup_stop()).lsn;
```

# pg_read_file

`pg_read_file(location text [, offset bigint, length integer]) → text`

读取**数据目录内受允许的文件**（超级用户，受 `read_file_func_extra` 等约束）；同族二进制版 `pg_read_binary_file`。

```sql
SELECT pg_read_file('log/postgresql-2026-01-01.log', 0, 4096);
```

# pg_stat_file

`pg_stat_file(location text [, missing_ok boolean]) → record(size, access, modification, change, creation, isreg)`

返回数据目录内某文件的**元信息**（大小、时间戳等）。`pg_ls_dir` 则列出目录内容。

```sql
SELECT * FROM pg_stat_file('PG_VERSION');
```

# pg_ls_logdir / pg_ls_waldir

`pg_ls_logdir() → setof(name, size, modification)`；`pg_ls_waldir()` 同构

列出**日志目录** / **WAL 目录** 下文件，监控体积增长、定位待归档 WAL。

```sql
SELECT sum(size) FROM pg_ls_waldir();
```

# pg_advisory_lock

`pg_advisory_lock(key bigint) / pg_advisory_lock(key1 int, key2 int)`

获取**咨询锁**（应用自定义键，不存在则阻塞等待）。用于跨会话互斥而不锁真实对象。

```sql
SELECT pg_advisory_lock(42);        -- 拿不到就等
-- 做一批只允许单实例跑的活
SELECT pg_advisory_unlock(42);
```

# pg_try_advisory_lock

`pg_try_advisory_lock(key ...) → boolean`

**尝试**获取咨询锁，拿不到立即返回 false 而不阻塞——"抢不到就跳过"的跑批去重首选。

```sql
DO $$ BEGIN
  IF pg_try_advisory_lock(100) THEN
    -- 只有抢到的实例执行
    PERFORM pg_advisory_unlock(100);
  END IF;
END $$;
```

> 共享版 `pg_advisory_lock_shared`/`pg_try_advisory_lock_shared`；会话/事务级、加/解锁成套，务必成对释放防泄漏。

# pg_is_in_recovery

`pg_is_in_recovery() → boolean`

实例当前是否处于**恢复/只读（standby）状态**。

```sql
SELECT pg_is_in_recovery();   -- 主库 false，备库 true
```

# pg_last_wal_replay_lsn

`pg_last_wal_replay_lsn() → pg_lsn`

备库**已回放的最后 WAL 位置**，配合主库 LSN 度量延迟。

```sql
SELECT pg_last_wal_replay_lsn();
```

# pg_last_xact_replay_timestamp

`pg_last_xact_replay_timestamp() → timestamptz`

备库**最后一个已回放事务的提交时间**，直观看"从库落后多少时间"。

```sql
SELECT now() - pg_last_xact_replay_timestamp() AS replication_lag;
```

# pg_promote

`pg_promote(wait boolean DEFAULT true, wait_seconds integer DEFAULT 60) → boolean`

把 standby **提升为主库**（故障切换）。

```sql
SELECT pg_promote();
```

# pg_get_replication_slots

`pg_get_replication_slots() → setof(...)`

列出当前**复制槽**（逻辑/物理）及其状态；同族 `pg_create_*_replication_slot`、`pg_drop_replication_slot`。

```sql
SELECT slot_name, slot_type, active FROM pg_get_replication_slots();
```

> 复制槽若长期不用会**钉住 WAL 不被回收**，撑爆磁盘——监控 `active=false` 的槽并及时 `pg_drop_replication_slot`。

# pg_tablespace_location

`pg_tablespace_location(tablespace_oid oid) → text`

返回表空间在磁盘上的**绝对路径**。

```sql
SELECT pg_tablespace_location('pg_default'::regclass);
```
