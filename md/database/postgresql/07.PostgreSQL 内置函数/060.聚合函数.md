# 概述

本篇覆盖官方 9.20 节**聚合函数**。聚合把多行折叠成一个值，配合 `GROUP BY` 使用；几乎每个聚合都能加 `OVER ()` 当窗口函数用（见 **[窗口函数](./050.窗口函数.md)**）。

几条通用规则先说清：

- **除 `count(*)` 外，聚合默认忽略 NULL**。`count(col)` 只数非 NULL；`count(*)` 数所有行。
- **`FILTER (WHERE ...)`**（SQL 标准）替代 `CASE WHEN` 做条件聚合，更清晰：`count(*) FILTER (WHERE ok)`。
- **空输入组**：`sum`/`avg`/`min`/`max` 等返回 NULL（不是 0），要 0 就 `COALESCE(sum(x),0)`。
- **`ORDER BY`/`DISTINCT` 可写进聚合参数**：`string_agg(x, ',' ORDER BY y)`、`count(DISTINCT col)`。

> 统计类（`stddev`/`variance`）成对给 `_pop`（总体）和 `_samp`（样本）两版，差别是分母 n 还是 n-1。

# array_agg

`array_agg(anyelement [ORDER BY ...]) → array`

把一组的值**收集成数组**；可内嵌 `ORDER BY` 控制元素顺序。

```sql
SELECT department, array_agg(name ORDER BY name) FROM emp GROUP BY department;
```

> 元素含 NULL 会保留在数组里；要拼接成字符串用 `string_agg`。

# avg

`avg(numeric|int|bigint|interval [FILTER ...]) → numeric|double precision|interval`

**算术平均**，忽略 NULL。整数输入返回 `numeric`，浮点返回 `double precision`。

```sql
SELECT avg(salary) FROM emp;
SELECT avg(salary) FILTER (WHERE dept='sales') FROM emp;
```

# bit_and

`bit_and(integral) → 同类型`

对整数列做**按位与**聚合。空组返回该类型全 1（与的单位元）。

```sql
SELECT bit_and(flags) FROM rows;   -- 所有行 flags 的公共置位
```

# bit_or

`bit_or(integral) → 同类型`

**按位或**聚合（任一行置位即置位）。

```sql
SELECT bit_or(flags) FROM rows;
```

# bit_xor

`bit_xor(integral) → 同类型`

**按位异或**聚合。

```sql
SELECT bit_xor(flags) FROM rows;
```

# bool_and

`bool_and(boolean [FILTER ...]) → boolean`

**所有**非 NULL 值都为 true 才返回 true（SQL 里也写作 `every`）。空组返回 NULL。

```sql
SELECT bool_and(status='active') FROM account;   -- 是否全部激活
```

# bool_or

`bool_or(boolean) → boolean`

**存在**任一 true 即返回 true。

```sql
SELECT bool_or(has_vip) FROM user;   -- 是否有 VIP
```

# count

`count(*) → bigint`；`count(expr) → bigint`；`count(DISTINCT expr) → bigint`

**计数**。`count(*)` 数所有行（含 NULL）；`count(expr)` 只数 expr 非 NULL 的行。

```sql
SELECT count(*) FROM t;                      -- 全部行
SELECT count(middle_name) FROM person;       -- 非 NULL 的 middle_name 行数
SELECT count(DISTINCT city) FROM address;    -- 不同城市数
```

> 性能：`count(*)` 在大表上仍需扫描（MVCC 可见性），没有免扫优化；估算行数用 `pg_class.reltuples` 或 `EXPLAIN`。

# every

`every(boolean) → boolean`

`bool_and` 的 **SQL 标准同义词**。

```sql
SELECT every(col > 0) FROM t;   -- 是否全部为正
```

# json_agg

`json_agg(anyelement) → json`；`jsonb_agg` 见下条

把每行聚合成 **JSON 数组**元素。

```sql
SELECT json_agg(row_to_json(t)) FROM (SELECT id,name FROM emp) t;
```

# json_object_agg

`json_object_agg(key text, value anyelement) → json`

把**键值对行**聚合成一个 **JSON 对象**（key 必须非 NULL 文本）。

```sql
SELECT json_object_agg(dept, cnt) FROM (SELECT dept, count(*) cnt FROM emp GROUP BY dept) s;
```

# jsonb_agg

`jsonb_agg(anyelement) → jsonb`

`json_agg` 的 jsonb 版，返回可索引、去重的二进制 JSON。

```sql
SELECT jsonb_agg(t) FROM (SELECT id,name FROM emp) t;
```

# jsonb_object_agg

`jsonb_object_agg(key, value) → jsonb`

`json_object_agg` 的 jsonb 版。

```sql
SELECT jsonb_object_agg(dept, cnt) FROM (...) s;
```

# max

`max(anyelement) → 同类型`

组内**最大值**（按类型的排序规则），忽略 NULL。

```sql
SELECT max(created_at) FROM orders;
```

# min

`min(anyelement) → 同类型`

组内**最小值**。

```sql
SELECT min(price) FROM product;
```

# range_agg

`range_agg(anyrange) → anyrange`；multirange 版 `range_agg(anymultirange) → anymultirange`

把多个**范围合并**成覆盖它们的最小区间（对 multirange 输入则合并成多范围）。

```sql
SELECT range_agg(valid) FROM subscription;   -- 所有有效期的并集包络
```

> 与 `range_merge`（见 **[范围函数](./045.范围函数.md)**）同源；填洞行为按范围类型规范化。

# range_intersect_agg

`range_intersect_agg(anyrange) → anyrange`

返回多个范围的**交集**（无交集为空范围）。

```sql
SELECT range_intersect_agg(during) FROM bookings WHERE room=5;
```

# stddev

`stddev(double precision) → double precision`

**样本标准差**（= `stddev_samp`）。

```sql
SELECT stddev(score) FROM students;
```

# stddev_pop

`stddev_pop(double precision) → double precision`

**总体标准差**（分母 n）。

```sql
SELECT stddev_pop(score) FROM students;
```

# stddev_samp

`stddev_samp(double precision) → double precision`

**样本标准差**（分母 n-1），是 `stddev` 的显式名。

```sql
SELECT stddev_samp(score) FROM students;
```

# string_agg

`string_agg(expr text, delimiter text [ORDER BY ...]) → text`

用**分隔符**拼接非 NULL 值为一个字符串。

```sql
SELECT department, string_agg(name, ', ' ORDER BY name) FROM emp GROUP BY department;
```

> 坑：`delimiter` 不能省（与 `concat_ws` 不同）；要保留 NULL 位置得自己 `coalesce`；超长字符串注意结果仍是 text。

# sum

`sum(numeric|int|bigint|double|interval) → 对应更宽类型`

**求和**，忽略 NULL；整数输入会被提升到 `numeric`/`bigint` 防溢出。

```sql
SELECT sum(amount) FROM payment;
SELECT sum(amount) FILTER (WHERE status='paid') FROM payment;
```

# var_pop

`var_pop(double precision) → double precision`

**总体方差**（n）。

```sql
SELECT var_pop(score) FROM students;
```

# var_samp

`var_samp(double precision) → double precision`

**样本方差**（n-1），是 `variance` 的显式名。

```sql
SELECT var_samp(score) FROM students;
```

# variance

`variance(double precision) → double precision`

**样本方差**（= `var_samp`）。

```sql
SELECT variance(score) FROM students;
```
