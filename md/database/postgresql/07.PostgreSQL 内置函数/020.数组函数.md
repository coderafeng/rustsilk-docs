# 概述

本篇覆盖官方 9.18 节**数组函数与操作符**。PostgreSQL 的数组是真正的数组类型（可多维、可含 NULL），写法用 `ARRAY[...]` 或 `'{...}'` 字面量。

用之前先记住几条数组的"反直觉"规律：

- **下标默认从 1 开始**：`arr[1]` 是第一个元素；但**下标可以是负数或任意范围**（`array_lower`/`array_upper` 才是真实边界），所以别硬编码从 1 遍历。
- **`array_length` 对高维返回 NULL**：它只数指定维度上"存在"的元素；多维数组越界维度返回 NULL，用 `cardinality` 数总元素更稳。
- **NULL 敏感**：`array_position`/`array_remove` 能匹配普通值，但**不能**用来找 SQL NULL（要用 `array_position(arr, NULL)` 明确传 NULL）。
- **`||` 是拼接操作符**：数组与数组、数组与元素都能 `||`，方向决定前插还是后插。

> 数组的**索引支持**（GIN、`@>`/`&&` 操作符）见 **[索引类型](../06.PostgreSQL%20索引/005.索引类型.md)**；聚合出数组用 `array_agg`，见 **[聚合函数](./060.聚合函数.md)**。

# array_append

`array_append(anyarray, anyelement) → anyarray`

在数组**末尾追加一个元素**，等价于 `arr || elem`。

```sql
SELECT array_append(ARRAY[1,2], 3);   -- {1,2,3}
SELECT ARRAY[1,2] || 3;                -- {1,2,3}（等价写法）
```

> 坑：追加的元素类型必须与数组元素类型兼容；给 `text[]` 追加一个未加引号的整数会触发隐式转换或直接报错。

# array_cat

`array_cat(anyarray, anyarray) → anyarray`

**拼接两个数组**，等价于 `arr1 || arr2`。只升一维，不会把二维拍平。

```sql
SELECT array_cat(ARRAY[1,2], ARRAY[3,4]);        -- {1,2,3,4}
SELECT array_cat(ARRAY[[1,2]], ARRAY[[3,4]]);    -- {{1,2},{3,4}}
```

# array_dims

`array_dims(anyarray) → text`

以**文本**描述每一维的下标范围，形如 `[1:2]`。

```sql
SELECT array_dims(ARRAY[[1,2],[3,4]]);   -- [1:2][1:2]
```

> 需要程序可读的边界用 `array_lower`/`array_upper`；要维度个数用 `array_ndims`。

# array_fill

`array_fill(anyelement, int[]) → anyarray`

按指定**维度长度**生成一个用同一值填满的数组。

```sql
SELECT array_fill(0, ARRAY[4]);             -- {0,0,0,0}
SELECT array_fill('x', ARRAY[2,2]);         -- {{x,x},{x,x}}
```

# array_length

`array_length(anyarray, int dimension) → integer`

返回**指定维度**的元素个数；该维度不存在时返回 **NULL**。

```sql
SELECT array_length(ARRAY[1,2,3,4], 1);        -- 4
SELECT array_length(ARRAY[[1,2],[3,4]], 2);    -- 2
SELECT array_length(ARRAY[1,2], 2);            -- NULL（没有第 2 维）
```

> 坑：多维各维长度不一致（锯齿数组）时，`array_length` 只反映第一行，别用来做安全边界，改用 `array_lower`+`array_upper`。

# array_lower

`array_lower(anyarray, int dimension) → integer`

返回**指定维度的下界**（最小下标）。

```sql
SELECT array_lower('[0:2]={1,2,3}'::int[], 1);   -- 0（自定义下标起点）
SELECT array_lower(ARRAY[10,20], 1);             -- 1
```

# array_ndims

`array_ndims(anyarray) → integer`

返回数组的**维度数**。

```sql
SELECT array_ndims(ARRAY[1,2]);         -- 1
SELECT array_ndims(ARRAY[[1,2],[3,4]]); -- 2
```

# array_position

`array_position(anyarray, anyelement [, from]) → integer`

返回**首次匹配**元素的下标（可选从第几个开始找）；找不到返回 NULL。

```sql
SELECT array_position(ARRAY['a','b','c'], 'b');       -- 2
SELECT array_position(ARRAY[1,2,1], 1, 2);            -- 3（从第 2 个起找）
SELECT array_position(ARRAY['a',NULL], NULL);          -- 2（可显式匹配 NULL）
```

# array_positions

`array_positions(anyarray, anyelement) → integer[]`

返回**所有匹配**元素的下标数组；无匹配返回 NULL。

```sql
SELECT array_positions(ARRAY[1,2,1,3,1], 1);   -- {1,3,5}
```

> 只能匹配非 NULL 值；要找 NULL 的位置得用 `array_position(arr, NULL)` 循环或 `generate_subscripts` 手写。

# array_prepend

`array_prepend(anyelement, anyarray) → anyarray`

在数组**开头插入一个元素**，等价于 `elem || arr`。

```sql
SELECT array_prepend(0, ARRAY[1,2]);   -- {0,1,2}
```

# array_remove

`array_remove(anyarray, anyelement) → anyarray`

删除数组中**所有等于**指定值的元素（保留顺序）。

```sql
SELECT array_remove(ARRAY[1,2,2,3], 2);   -- {1,3}
```

> 坑：无法用它删除 NULL（`=` 对 NULL 恒为 unknown）；删 NULL 要绕道 `unnest + WHERE` 再 `array_agg`。

# array_replace

`array_replace(anyarray, from anyelement, to anyelement) → anyarray`

把数组中**所有 from 值替换为 to 值**。

```sql
SELECT array_replace(ARRAY[1,2,1,3], 1, 9);   -- {9,2,9,3}
```

# array_to_string

`array_to_string(anyarray, text delimiter [, null_string]) → text`

用**分隔符**连接数组元素为字符串；第 3 个参数指定 NULL 的替代文本（省略则跳过 NULL）。

```sql
SELECT array_to_string(ARRAY['a','b','c'], '-');        -- a-b-c
SELECT array_to_string(ARRAY['a',NULL,'b'], ',');        -- a,b（NULL 被跳过）
SELECT array_to_string(ARRAY['a',NULL,'b'], ',', 'NA');  -- a,NA,b
```

> 逆操作：字符串切数组用 `string_to_array`，见 **[字符串函数](./000.字符串函数.md)**。

# array_upper

`array_upper(anyarray, int dimension) → integer`

返回**指定维度的上界**（最大下标）。

```sql
SELECT array_upper(ARRAY[10,20,30], 1);   -- 3
```

> 遍历数组安全写法：`FOR i IN array_lower(a,1)..array_upper(a,1)`，而非假设 1..length。

# cardinality

`cardinality(anyarray) → integer`

返回数组**所有元素的总数**（跨所有维度），空数组返回 0，比逐维 `array_length` 更好用。

```sql
SELECT cardinality(ARRAY[[1,2],[3,4]]);   -- 4
SELECT cardinality(ARRAY[]::int[]);        -- 0
```

# trim_array

`trim_array(anyarray, int n) → anyarray`

从数组**末尾移除 n 个元素**（只操作最后一维）。

```sql
SELECT trim_array(ARRAY[1,2,3,4], 2);   -- {1,2}
```

> n 大于数组长度会报错；要删开头元素没有内置函数，需 `array_slice` 式手写或 `unnest`。

# unnest

`unnest(anyarray) → setof anyelement`

把数组**展开为多行**（集合返回函数），是最常用的"数组打平"手段。

```sql
SELECT unnest(ARRAY[1,2,3]);                 -- 3 行：1 / 2 / 3
SELECT * FROM unnest(ARRAY['a','b']) WITH ORDINALITY;   -- a|1  b|2（带序号列）
```

> 配合 `WITH ORDINALITY` 可同时得到元素值和位置；多个 `unnest` 放在同一 `SELECT` 里会**并行对齐**展开（zip 语义）。集合返回函数详见 **[集合返回函数](./040.集合函数.md)**。
