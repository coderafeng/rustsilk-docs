# 概述

本篇覆盖官方 9.22–9.24 节**信息函数**：读取系统目录、查询对象/列注释、判断权限、读写运行期配置、把名字解析成 OID 等"自省"能力。写工具、做迁移、排查权限时离不开它们。

几条贯穿的规律：

- **`to_reg*` 系列是"安全解析器"**：`to_regclass('t')` 对象不存在时返回 **NULL** 而非报错，适合判断"表/类型是否存在"。对应的 `reg*::oid` 直接转型则会在不存在时抛错。
- **`has_*_privilege` / `pg_has_role` 返回布尔**，是行级安全、权限审计脚本的基础；参数可省当前用户。
- **注释要用 OID 查**：`obj_description`/`col_description` 需要系统目录 OID，不能直接传表名（先 `to_regclass` 拿 OID）。
- **`current_setting` / `set_config` 操作 GUC**：等价 `SHOW` / `SET`，但能在 SQL 里当表达式用。

> 管理类（备份、复制、后台任务、实例控制）见 **[系统管理函数](./090.系统管理函数.md)**；会话级身份/进程信息见 **[会话信息函数](./055.会话信息函数.md)**。

# current_setting

`current_setting(setting_name text [, missing_ok boolean]) → text`

读取一个**运行期配置参数（GUC）**当前值；`missing_ok=true` 时参数不存在返回 NULL 而非报错。

```sql
SELECT current_setting('work_mem');
SELECT current_setting('nonexistent.guc', true);   -- NULL
```

> 读任意 schema 下自定义 GUC 时，`missing_ok` 很关键；等价 `SHOW xxx`，但可嵌进表达式。

# set_config

`set_config(setting_name, new_value text, is_local boolean) → text`

设置一个 GUC 的值；`is_local=true` 仅当前事务有效（等价 `SET LOCAL`），否则为会话级。

```sql
SELECT set_config('statement_timeout', '30s', true);   -- 本事务内限制 30s
```

# pg_typeof

`pg_typeof(any) → regtype`

返回参数值的**运行时数据类型名**（对 `unknown`/混型排查有用）。

```sql
SELECT pg_typeof(1), pg_typeof('x'), pg_typeof(null);   -- integer | text | unknown
```

# pg_get_expr

`pg_get_expr(pg_node_tree, relation_oid) → text`；带 pretty 版

把系统目录里存的**表达式树反解析为 SQL 文本**（读列默认值、检查约束、索引表达式）。

```sql
SELECT pg_get_expr(d.adbin, d.adrelid) FROM pg_attrdef d;   -- 还原 DEFAULT 表达式
```

> 直接 `SELECT adbin` 得到的是内部序列化名，必须经 `pg_get_expr` 才是可读 SQL。

# to_regclass

`to_regclass(text) → regclass`

把**表/视图/序列等关系名**解析为 `regclass`（OID）；不存在返回 **NULL**。常用于"表是否存在"判断。

```sql
SELECT to_regclass('public.film');       -- film
SELECT to_regclass('public.not_exist');  -- NULL
```

# to_regproc

`to_regproc(text) → regproc`；`to_regprocedure(text) → regprocedure`

把**函数名**解析为 OID；`to_regprocedure` 需带参数签名，能区分重载。不存在返回 NULL。

```sql
SELECT to_regprocedure('sum(integer)');   -- sum(integer)
```

# to_regtype

`to_regtype(text) → regtype`

把**类型名**解析为 `regtype`；不存在返回 NULL。

```sql
SELECT to_regtype('integer[]');   -- integer[]
```

# to_regnamespace

`to_regnamespace(text) → regnamespace`

把 **schema 名**解析为 OID；不存在返回 NULL。

```sql
SELECT to_regnamespace('public');   -- public
```

> 同族还有 `to_regcollation`、`to_regoper`、`to_regrole`、`to_regclass`，行为一致：解析成功给 OID，失败给 NULL。

# obj_description

`obj_description(object_oid, catalog_name text) → text`

返回某个**数据库对象**（表、函数等）的 `COMMENT`；无注释返回 NULL。

```sql
SELECT obj_description('film'::regclass, 'pg_class');
```

> 需要 catalog 名（如 `pg_class`）；全局共享对象用 `shobj_description`。

# shobj_description

`shobj_description(object_oid, catalog_name) → text`

返回**共享对象**（数据库、表空间、角色）的注释。

```sql
SELECT shobj_description('postgres'::regdatabase, 'pg_database');
```

# col_description

`col_description(table_oid, column_number smallint) → text`

返回某**列的注释**。

```sql
SELECT col_description('film'::regclass, 1);
```

# pg_get_serial_sequence

`pg_get_serial_sequence(table_name text, column_name text) → text`

返回某列关联的**序列名**（`serial`/`identity` 列），拿到后可 `setval` 校准。

```sql
SELECT pg_get_serial_sequence('orders', 'id');   -- public.orders_id_seq
```

# pg_get_userbyid

`pg_get_userbyid(role_oid oid) → name`

把**角色 OID** 转成用户名，连接系统目录时把 `oid` 列变可读。

```sql
SELECT pg_get_userbyid(relowner) FROM pg_class WHERE relname='film';
```

# has_table_privilege

`has_table_privilege(user, table, privilege text) → boolean`

判断用户对表是否拥有某权限（`SELECT`/`INSERT`/`UPDATE`/`DELETE`/`TRUNCATE`/`REFERENCES`/`TRIGGER`）。可省略 user 用当前用户。

```sql
SELECT has_table_privilege('analyst', 'film', 'SELECT');   -- true/false
```

# has_schema_privilege

`has_schema_privilege(user, schema, privilege) → boolean`

判断 schema 上的 `CREATE`/`USAGE` 权限。

```sql
SELECT has_schema_privilege('public', 'USAGE');
```

# has_database_privilege

`has_database_privilege(user, database, privilege) → boolean`

判断库上的 `CONNECT`/`CREATE`/`TEMPORARY` 权限。

```sql
SELECT has_database_privilege('app', 'CONNECT');
```

# has_function_privilege

`has_function_privilege(user, function, privilege) → boolean`

判断函数 `EXECUTE` 权限。

```sql
SELECT has_function_privilege('my_fn(int)', 'EXECUTE');
```

# has_sequence_privilege

`has_sequence_privilege(user, sequence, privilege) → boolean`

判断序列 `USAGE`/`SELECT`/`UPDATE` 权限。

```sql
SELECT has_sequence_privilege('orders_id_seq', 'USAGE');
```

# pg_has_role

`pg_has_role(user, role, privilege) → boolean`

判断角色成员关系/权限（`MEMBER`/`USAGE`），考虑角色继承，是权限诊断常用入口。

```sql
SELECT pg_has_role('app', 'readonly', 'MEMBER');
```

# pg_collation_actual_version

`pg_collation_actual_version(collation_oid oid) → text`

返回排序规则在**操作系统/ICU 层当前的实际版本**，用于检测 collation 版本漂移（`REFRESH COLLATION` 前后对照）。

```sql
SELECT pg_collation_actual_version('C'::regcollation);
```

# pg_encoding_to_char

`pg_encoding_to_char(encoding integer) → name`

把内部**编码编号**转成编码名（如 `UTF8`）。

```sql
SELECT pg_encoding_to_char(6);   -- UTF8
```

# pg_partition_tree

`pg_partition_tree(parent_oid oid) → setof(relid, parentrelid, isleaf, level)`

列出某分区表的**完整分区树**（每个分区一行，带层级与是否叶子）。

```sql
SELECT * FROM pg_partition_tree('measurement');
```

# pg_current_xact_id

`pg_current_xact_id() → xid8`；`pg_current_xact_id_if_assigned() → xid8`

返回**当前事务的事务 ID**（PG13+ 取代旧 `txid_current`，后者已废弃）。未分配时 `..._if_assigned` 返回 NULL。

```sql
SELECT pg_current_xact_id();
```
