# 概述

本篇覆盖官方 9.15 节 **JSON 函数与操作符**。PostgreSQL 有 `json`（原样文本）和 `jsonb`（二进制分解存储）两种类型，**函数几乎都成对出现**（`json_*` 与 `jsonb_*`），差别只在返回/处理 `json` 还是 `jsonb`。

选型的三条主线：

- **绝大多数场景用 `jsonb`**：支持索引（`@>`、GIN，见 **[索引类型](../06.PostgreSQL%20索引/005.索引类型.md)**）、键去重、可就地修改（`jsonb_set`）。代价是丢失键顺序与空白格式、写入略慢。
- **需要保留原始文本/键序/精确数字**才用 `json`。
- **构造函数**（`to_json`、`row_to_json`、`json_build_object`、`json_agg`）把关系数据变 JSON；**读取函数**（`->`、`->>`、`jsonb_path_query`、`json_to_record`）把 JSON 变回可查询的值/行。

> 记法：`->` 返回 json/jsonb，`->>` 返回 text。多数 `json_xxx` 都有对应的 `jsonb_xxx`，下文 jsonb 版若与 json 版语义相同，只标注差异。

# array_to_json

`array_to_json(anyarray [, pretty bool]) → json`

把 PostgreSQL **数组转为 JSON 数组**；`pretty=true` 时格式化缩进。

```sql
SELECT array_to_json(ARRAY[[1,2],[3,4]]);       -- [[1,2],[3,4]]
SELECT array_to_json('{{a,b},{c,d}}'::text[]);  -- [["a","b"],["c","d"]]
```

# json_array_elements

`json_array_elements(json) → setof json`

把 JSON **数组的每个元素展开为一行**（集合返回）。非数组会报错。

```sql
SELECT * FROM json_array_elements('[1,true,[1,2]]');   -- 3 行：1 / true / [1,2]
```

# json_array_elements_text

`json_array_elements_text(json) → setof text`

同 `json_array_elements`，但元素以 **text** 返回（自动去掉字符串引号）。

```sql
SELECT * FROM json_array_elements_text('["foo","bar"]');   -- foo / bar（两行 text）
```

# json_array_length

`json_array_length(json) → integer`

返回 JSON **数组长度**；非数组返回 NULL。

```sql
SELECT json_array_length('[1,2,3,{"f1":1}]');   -- 4
```

# json_build_array

`json_build_array(VARIANY) → json`

用参数**构造一个 JSON 数组**，NULL 会变 JSON null。

```sql
SELECT json_build_array(1,2,'foo',NULL);   -- [1, 2, "foo", null]
```

# json_build_object

`json_build_object(VARIANY) → json`

以**键值交替**参数构造 JSON 对象（参数须为偶数个）。

```sql
SELECT json_build_object('a',1,'b',ARRAY[1,2,3]);   -- {"a" : 1, "b" : [1, 2, 3]}
```

> 相关：`json_strip_nulls` 可去掉构造出的 null；要聚合成对象用 `json_object_agg`（见 **[聚合函数](./060.聚合函数.md)**）。

# json_each

`json_each(json) → setof key text, value json`

把 JSON **对象的每个键展开为一行**（key 为 text，value 保持 json）。

```sql
SELECT * FROM json_each('{"a":"foo","b":"bar"}');   -- a | "foo"  ;  b | "bar"
```

# json_each_text

`json_each_text(json) → setof key text, value text`

同 `json_each`，value 以 **text** 返回。

```sql
SELECT * FROM json_each_text('{"a":"foo","b":null}');   -- b 行 value 为 SQL NULL
```

# json_extract_path

`json_extract_path(from_json json, VARIANY path text) → json`

按**路径**取嵌套值（等价于 `#>` 操作符）。

```sql
SELECT json_extract_path('{"f2":{"f3":1}}', 'f2', 'f3');   -- 1
```

# json_extract_path_text

`json_extract_path_text(...) → text`

按路径取值并以 **text** 返回（等价 `#>>`）。

```sql
SELECT json_extract_path_text('{"f2":"bar"}', 'f2');   -- bar
```

# json_object

`json_object(text[][] [, bool]) → json`

把**二维数组**（每行两个元素：键、值）转成 JSON 对象。

```sql
SELECT json_object('{{k1,v1},{k2,v2}}');   -- {"k1" : "v1", "k2" : "v2"}
```

# json_object_keys

`json_object_keys(json) → setof text`

返回 JSON 对象**所有键**，每键一行。

```sql
SELECT json_object_keys('{"f1":"9","f2":"b"}');   -- f1 / f2（两行）
```

# json_populate_record

`json_populate_record(base anyelement, from_json json) → setof base`

把 JSON 对象**映射成一个匹配 base 结构的行/记录**（多出的键忽略，缺失的键为 NULL）。

```sql
SELECT * FROM json_populate_record(NULL::shipments, '{"f1":1,"f3":"3days"}');
```

# json_populate_recordset

`json_populate_recordset(base anyelement, from_json json) → setof base`

把 **JSON 数组**里的每个对象映射成一行记录集。

```sql
SELECT * FROM json_populate_recordset(NULL::mytype, '[{"a":1},{"a":2}]');  -- 两行
```

> 相关：不传 base 结构、要在查询里显式声明列用 `json_to_record`/`json_to_recordset`。

# json_strip_nulls

`json_strip_nulls(from_json json) → json`

递归删除对象/数组里值为 **JSON null** 的键（SQL NULL 字段不受影响）。

```sql
SELECT json_strip_nulls('[{"f1":null,"f2":2}]');   -- [{"f2" : 2}]
```

# json_to_record

`json_to_record(from_json json, definition) → record`

把 JSON 对象转成一行记录，**在调用处声明列结构**。

```sql
SELECT * FROM json_to_record('{"a":1,"b":[1,2]}') AS x(a int, b int[]);
```

# json_to_recordset

`json_to_recordset(from_json json, definition) → setof record`

把 **JSON 数组**转成多行记录集。

```sql
SELECT * FROM json_to_recordset('[{"a":1},{"a":2}]') AS x(a int);   -- 两行
```

# json_typeof

`json_typeof(json) → text`

返回 JSON 值的**类型名**：`object/array/string/number/boolean/null`。

```sql
SELECT json_typeof('[1,2]');   -- array
```

# jsonb_array_elements

`jsonb_array_elements(jsonb) → setof jsonb`

`json_array_elements` 的 **jsonb 版**，返回 `setof jsonb`。

```sql
SELECT * FROM jsonb_array_elements('[1,true]');   -- 1 / true（jsonb）
```

# jsonb_array_elements_text

`jsonb_array_elements_text(jsonb) → setof text`

jsonb 数组元素展开为 **text 行**。

```sql
SELECT * FROM jsonb_array_elements_text('["foo","bar"]');   -- foo / bar
```

# jsonb_array_length

`jsonb_array_length(jsonb) → integer`

jsonb **数组长度**。

```sql
SELECT jsonb_array_length('[1,2,3]');   -- 3
```

# jsonb_build_array

`jsonb_build_array(VARIANY) → jsonb`

构造 **jsonb 数组**，NULL→jsonb null。

```sql
SELECT jsonb_build_array(1,'foo');   -- [1, "foo"]
```

# jsonb_build_object

`jsonb_build_object(VARIANY) → jsonb`

构造 **jsonb 对象**（键值交替）。

```sql
SELECT jsonb_build_object('a',1);   -- {"a": 1}
```

# jsonb_each

`jsonb_each(jsonb) → setof key text, value jsonb`

jsonb 对象每键一行（value 为 jsonb）。

```sql
SELECT * FROM jsonb_each('{"a":"foo","b":"bar"}');   -- a | "foo" ; b | "bar"
```

# jsonb_each_text

`jsonb_each_text(jsonb) → setof key text, value text`

value 以 **text** 返回。

```sql
SELECT * FROM jsonb_each_text('{"a":"foo"}');   -- a | foo
```

# jsonb_extract_path

`jsonb_extract_path(from_jsonb jsonb, VARIANY path text) → jsonb`

按路径取 jsonb 值（等价 `#>`）。

```sql
SELECT jsonb_extract_path('{"f2":{"f3":1}}', 'f2', 'f3');   -- 1
```

# jsonb_extract_path_text

`jsonb_extract_path_text(...) → text`

按路径取值转 **text**（等价 `#>>`）。

```sql
SELECT jsonb_extract_path_text('{"f2":"bar"}', 'f2');   -- bar
```

# jsonb_insert

`jsonb_insert(target jsonb, path text[], new_value jsonb [, insert_after bool]) → jsonb`

在指定路径**插入**值（默认插在目标之前，`insert_after=true` 插其后）。路径指向的中间对象须存在。

```sql
SELECT jsonb_insert('{"a":[0,1,2]}', '{a,1}', '"new"');   -- {"a": [0, "new", 1, 2]}
```

> 与 `jsonb_set` 区别：insert 是"插进数组/新键"，set 是"替换已有值"。

# jsonb_object

`jsonb_object(text[][] [, bool]) → jsonb`

二维数组转 **jsonb 对象**。

```sql
SELECT jsonb_object('{{k1,v1},{k2,v2}}');   -- {"k1": "v1", "k2": "v2"}
```

# jsonb_object_keys

`jsonb_object_keys(jsonb) → setof text`

jsonb 对象所有**键**逐行返回。

```sql
SELECT jsonb_object_keys('{"f1":"9","f2":"b"}');   -- f1 / f2
```

# jsonb_path_exists

`jsonb_path_exists(target jsonb, path jsonpath [, vars jsonb [, silent bool]]) → boolean`

用 **JSONPath** 判断目标是否存在匹配项，返回布尔。

```sql
SELECT jsonb_path_exists('{"a":1}', '$.a ? (@ == 1)');   -- true
```

> JSONPath 是 PG12+ 引入的强大查询语法，`?(@ ...)` 为过滤表达式。带时区版见 `*_tz`。

# jsonb_path_exists_tz

`jsonb_path_exists_tz(...) → boolean`

`jsonb_path_exists` 的**带时区**版：JSONPath 里时间戳按会话时区处理。

```sql
SELECT jsonb_path_exists_tz('{"ts":"2020-01-01"}', '$.ts ? (@.datetime() > now())');
```

# jsonb_path_match

`jsonb_path_match(target jsonb, path jsonpath [, vars, silent]) → boolean`

要求 JSONPath **结果收敛为单个 SQL-布尔可判定值**（用于"整体是否满足条件"）。

```sql
SELECT jsonb_path_match('{"a":1}', 'exists($.a)');   -- true
```

> 与 exists 区别：match 会真正求值路径末端的布尔；exists 只问"有没有命中"。

# jsonb_path_match_tz

`jsonb_path_match_tz(...) → boolean`

`jsonb_path_match` 的**带时区**版。

```sql
SELECT jsonb_path_match_tz('{"ts":"2020-01-01"}', 'exists($.ts ? (@.datetime() < now()))');
```

# jsonb_path_query

`jsonb_path_query(target jsonb, path jsonpath [, vars, silent]) → setof jsonb`

用 JSONPath **返回所有匹配项**，每项一行。

```sql
SELECT * FROM jsonb_path_query('[1,2,3]', '$[*] ? (@ > 1)');   -- 2 / 3
```

> 传参：`vars` 传入外部变量，路径里用 `$.var` / `$var` 引用；`silent=true` 让错误转为 NULL 而非抛异常。

# jsonb_path_query_array

`jsonb_path_query_array(...) → jsonb`

把 JSONPath 匹配结果**收进一个 JSON 数组**返回。

```sql
SELECT jsonb_path_query_array('[1,2,3]', '$[*] ? (@ > 1)');   -- [2, 3]
```

# jsonb_path_query_array_tz

`jsonb_path_query_array_tz(...) → jsonb`

`jsonb_path_query_array` 的**带时区**版。

```sql
SELECT jsonb_path_query_array_tz('{"ts":1}', '$');   -- [{"ts": 1}]
```

# jsonb_path_query_first

`jsonb_path_query_first(...) → jsonb`

只返回 JSONPath 匹配的**第一个**结果。

```sql
SELECT jsonb_path_query_first('[1,2,3]', '$[*] ? (@ > 1)');   -- 2
```

# jsonb_path_query_first_tz

`jsonb_path_query_first_tz(...) → jsonb`

`jsonb_path_query_first` 的**带时区**版。

```sql
SELECT jsonb_path_query_first_tz('[10,20]', 'lax $.a');   -- 错误被吞时返回 NULL
```

# jsonb_path_query_tz

`jsonb_path_query_tz(...) → setof jsonb`

`jsonb_path_query` 的**带时区**版。

```sql
SELECT * FROM jsonb_path_query_tz('{"ts":"2020-01-01"}', '$.ts');
```

# jsonb_populate_record

`jsonb_populate_record(base anyelement, from_json jsonb) → setof base`

`json_populate_record` 的 **jsonb 版**。

```sql
SELECT * FROM jsonb_populate_record(NULL::mytype, '{"a":1}');
```

# jsonb_populate_recordset

`jsonb_populate_recordset(base anyelement, from_json jsonb) → setof base`

jsonb 数组 → 记录集（对应 `json_populate_recordset`）。

```sql
SELECT * FROM jsonb_populate_recordset(NULL::mytype, '[{"a":1},{"a":2}]');
```

# jsonb_pretty

`jsonb_pretty(jsonb) → text`

把 jsonb **缩进格式化**输出为多行文本，便于人读。

```sql
SELECT jsonb_pretty('{"a":[1,2]}');
-- {
--     "a": [
--         1,
--         2
--     ]
-- }
```

# jsonb_set

`jsonb_set(target jsonb, path text[], new_value jsonb [, create_missing bool]) → jsonb`

**替换/更新**指定路径的值（数组元素会**覆盖**而非插入）。`create_missing=false` 则不新建缺失对象字段（仍会新建数组越界项）。

```sql
SELECT jsonb_set('{"b":[0,1,2]}', '{b,0}', 'null');   -- {"b": [null, 1, 2]}
```

> 坑：路径中的数组下标越界会**按边界处理**；要"插入"用 `jsonb_insert`。

# jsonb_set_lax

`jsonb_set_lax(target jsonb, path text[], new_value jsonb [, create_missing bool, null_value_treatment text]) → jsonb`

允许 `new_value` 为 **SQL NULL** 并可指定处理方式：`raise_exception`/`use_json_null`/`delete_key`/`return_target`。

```sql
-- new_value 为 NULL 时删除目标键
SELECT jsonb_set_lax('{"a":1,"b":2}', '{a}', NULL, true, 'delete_key');   -- {"b": 2}
```

# jsonb_strip_nulls

`jsonb_strip_nulls(jsonb) → jsonb`

jsonb 版去 null：删除值为 **JSON null** 的键。

```sql
SELECT jsonb_strip_nulls('{"a":null,"b":2}');   -- {"b": 2}
```

# jsonb_to_record

`jsonb_to_record(from_jsonb jsonb, definition) → record`

jsonb 对象 → 一行记录，声明式列结构。

```sql
SELECT * FROM jsonb_to_record('{"a":1,"b":"x"}') AS x(a int, b text);
```

# jsonb_to_recordset

`jsonb_to_recordset(from_jsonb jsonb, definition) → setof record`

jsonb 数组 → 多行记录。

```sql
SELECT * FROM jsonb_to_recordset('[{"a":1},{"a":2}]') AS x(a int);
```

# jsonb_typeof

`jsonb_typeof(jsonb) → text`

返回 jsonb 值类型名。

```sql
SELECT jsonb_typeof('{}');   -- object
```

# row_to_json

`row_to_json(row anyelement [, bool pretty]) → json`

把一行（或复合类型）转成 **JSON 对象**。

```sql
SELECT row_to_json(f) FROM film f LIMIT 1;   -- {"film_id":1,"title":"..."}
```

> 坑：数组字段会被展开成 `[]` 里的元素、NULL 变 JSON null。想要 jsonb 用 `to_jsonb`。

# to_json

`to_json(anyelement [, bool pretty]) → json`

把任意值转 json：标量原样、数组→JSON 数组、行/复合→JSON 对象（**不递归转复合类型嵌套**，与 `row_to_json` 略差异）。

```sql
SELECT to_json(row(1,'foo'));   -- [1, "foo"]
```

# to_jsonb

`to_jsonb(anyelement) → jsonb`

`to_json` 的 **jsonb 版**，返回可索引的 jsonb。

```sql
SELECT to_jsonb(ARRAY[1,2]);   -- [1, 2]（jsonb）
```

> 提示：与 `jsonb_agg`（见 **[聚合函数](./060.聚合函数.md)**）配合，可把多行聚合成一个 jsonb 数组。
