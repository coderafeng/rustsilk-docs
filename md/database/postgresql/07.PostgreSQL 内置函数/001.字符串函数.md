# 概述

PostgreSQL 提供了丰富的**字符串函数与操作符**（对应官方 9.4 节）。本篇按"每个函数一个标题"组织，涵盖长度、大小写、截取、拼接、查找替换、正则、编码转换等常用能力。

先记住几条贯穿全局的规律，能少踩很多坑：

- **下标从 1 开始**：`substr`、`position`、`overlay` 等的起点/长度都按 1 计数，起点为 0 会被当错误处理。
- **字符 vs 字节**：`length`/`char_length`/`character_length` 数的是**字符**（受编码/排序规则影响），`octet_length` 数的是**字节**。中文字符串两者结果不同。
- **NULL 传染**：绝大多数函数任一参数为 NULL 即返回 NULL；例外是 `concat`/`concat_ws`（把 NULL 当空串）与 `format`。
- **别名**：`substr` 与 `substring`、`char_length` 与 `character_length`、`strpos` 与 `position`、`btrim` 与 `trim` 是等价实现，选顺手的即可。

> 日期/数字的格式化 `to_char` / `to_number` 虽列在本篇，但其格式模板细节更多属于 **[日期时间函数](./010.日期时间函数.md)** 与 **[数字类型](../04.PostgreSQL%20数据类型/005.数字类型.md)** 的范畴。

# ascii

`ascii(text) → integer`

返回字符串**第一个字符**的编码值（ASCII/Unicode 码点）。空串返回 0。

```sql
SELECT ascii('A');       -- 65
SELECT ascii('ab');      -- 97
SELECT ascii('中');       -- 20013
```

> 提示：与 `chr()` 互为逆运算。要逐字符处理需先配合 `generate_series` + `substr` 拆出单字符。

# bit_length

`bit_length(text) → integer`

返回字符串的**位长度**，等于 `octet_length × 8`。

```sql
SELECT bit_length('jose');   -- 32
```

# btrim

`btrim(text [, characters text]) → text`

去除字符串**两端的空白或指定字符集**。不带第二参数时等价于 `trim(both from x)` 去空格。

```sql
SELECT btrim('  abc  ');         -- abc
SELECT btrim('xyxcatzxy', 'xyz');  -- cat
```

> 相关：`ltrim` 只去左端、`rtrim` 只去右端、`trim` 是标准 SQL 写法（可指定 `LEADING/TRAILING/BOTH`）。

# char_length

`char_length(text) → integer`

返回**字符数**（不是字节数）。与 `character_length`、`length` 完全等价。

```sql
SELECT char_length('聚沙成塔');   -- 4
```

# character_length

`character_length(text) → integer`

`char_length` 的**全称别名**，行为一致。标准 SQL 里更常见这个拼写。

```sql
SELECT character_length('abc');   -- 3
```

# chr

`chr(integer) → text`

返回给定**码点对应的字符**（编码需与字符集兼容）。`ascii` 的逆运算。

```sql
SELECT chr(65);          -- A
SELECT chr(128169);      -- 💩（Unicode 码点）
```

> 提示：PostgreSQL 允许在 `chr` 中使用 Unicode 码位，常用于构造特殊字符/换页符等。

# concat

`concat(ANY) → text`

拼接所有参数，**NULL 被当作空字符串忽略**（这是它与 `||` 操作符最大的区别）。至少需 2 个参数。

```sql
SELECT concat('pg', NULL, 'sql');    -- pgsql
SELECT 'pg' || NULL || 'sql';        -- NULL（|| 遇到 NULL 整体为 NULL）
```

> 坑：需要"NULL 参与拼接就整体变 NULL"的语义时用 `||`；否则一律优先 `concat`/`concat_ws`，省心。

# concat_ws

`concat_ws(separator TEXT, [value "any"]) → text`

按**分隔符**拼接（`ws` = with separator）。分隔符为 NULL 返回 NULL，其余 NULL 参数被跳过。

```sql
SELECT concat_ws(', ', 'Anne', 'Smith');        -- Anne, Smith
SELECT concat_ws(', ', NULL, 'Smith');          -- Smith
SELECT concat_ws(NULL, 'Anne', 'Smith');        -- NULL
```

> 实战：拼接不定长的地址、标签列表时，`concat_ws` 天然帮你过滤 NULL 并加分隔符，比手写 `||` 干净得多。

# format

`format(formatstr text [, formatarg "any" [, ...] ]) → text`

类 C/`printf` 的**格式化字符串**构造，适合安全地拼接 SQL/日志文本。

```sql
SELECT format('Hello %s', 'World');               -- Hello World
SELECT format('%s %s', 'a', 'b');                 -- a b
SELECT format('%*s', 5, 'x');                     --     x（宽度）
SELECT format('Hello %I', 'World');               -- Hello "World"（标识符加引号）
SELECT format('Hello %L', 'World');               -- Hello 'World'（字面量加引号转义）
```

> 占位符：`%s` 值、`%I` 标识符（自动加双引号）、`%L` 字面量（自动加单引号并转义，防注入）；`%1$s` 可指定第 N 个参数复用。动态拼接 DDL/表名时用 `%I`/`%L` 而非手动加引号。

# initcap

`initcap(text) → text`

把每个**单词首字母大写**、其余转小写（单词按字母/非字母边界切分）。

```sql
SELECT initcap('hi THOMAS');   -- Hi Thomas
```

> 坑：它会**强制小写非首字母**，`initcap('de LAFONTAINE')` → `De Lafontaine`，对专有名词不一定安全。

# left

`left(text, int) → text`

返回前 `n` 个字符；`n` 为负则**去掉末尾 |n| 个**、返回其余；源串短于 n 时返回全部。

```sql
SELECT left('abcdefg', 3);     -- abc
SELECT left('abcdefg', -2);    -- abcde（去掉末尾 2 个字符）
```

> 相关：`right` 从右侧取。二者都是"按字符"而非按字节。

# length

`length(text) → integer`

返回**字符数**。`length(text) = char_length(text) = character_length(text)`。

```sql
SELECT length('聚沙成塔');      -- 4
SELECT octet_length('聚沙成塔'); -- 12（UTF-8 下每个汉字 3 字节）
```

# lower

`lower(text) → text`

转**小写**。遵循当前排序规则（collation）的大小写映射。

```sql
SELECT lower('TOM');   -- tom
```

> 实战与坑：大小写不敏感检索的经典写法 `WHERE lower(email) = lower($1)` 想走索引，必须为其建 **[表达式索引](../06.PostgreSQL%20索引/035.表达式索引.md)**。非确定性排序规则下可考虑 `citext` 扩展。相关 `upper`、`initcap`。

# lpad

`lpad(text, int [, fill text]) → text`

在**左侧填充**使总长度达到 n。`fill` 默认为空格；结果超长会被**截断到 n**。

```sql
SELECT lpad('hi', 4, 'xy');   -- xyhi
SELECT lpad('hi', 5);         --    hi
SELECT lpad('hi', 1, 'xy');   -- h（截断）
```

> 相关：`rpad` 右侧填充。常用于编号补零 `lpad(id::text, 6, '0')`。

# ltrim

`ltrim(text [, characters text]) → text`

去除**左端**空白或指定字符。

```sql
SELECT ltrim('zzzytest', 'xyz');   -- test
```

# md5

`md5(string text) → text`

计算 MD5 摘要并以**十六进制**返回。输入若以 `\x` 开头按字节处理，否则按文本。

```sql
SELECT md5('abc');   -- 900150983cd24fb0d6963f7d28e17f72
```

> 安全提醒：MD5 **不应再用于密码/签名等安全场景**（易碰撞）。存储密码用 `pgcrypto` 的 `crypt()`/`bcrypt` 或应用层方案；做校验和也建议 SHA-256。`md5()` 目前需要 `md5` 系统安全提供器在 FIPS 模式下不可用。

# normalize

`normalize(string text [, form text]) → text`

按 **Unicode NFC / NFD / NFKC / NFKD** 之一做标准化，缺省 NFC。用于消除"同一字符的不同字节表示"带来的比较问题。

```sql
SELECT normalize('A');                       -- NFC
SELECT normalize('\u00C5', NFD);             -- 分解形式
SELECT normalize('A') = normalize('\u212B');  -- t（Kang 罗马字符归一后相等）
```

> 相关：`is_normalized(string, form) → boolean` 检查是否已标准化。跨来源文本比较（如文件名、姓名）先 normalize 更稳。

# octet_length

`octet_length(text) → integer`

返回字符串的**字节数**。多字节字符集下 ≥ `length`。

```sql
SELECT octet_length('jose');   -- 4
```

> 实战：估算行/字段实际存储占用、限长校验（如 API 请求体按字节限制）时用 `octet_length` 而非 `length`。

# overlay

`overlay(text placing text from int [for int]) → text`

在指定位置**覆盖/替换**一段子串。起点从 1 计；`for n` 指定被覆盖长度，省略则按放置串长度覆盖。

```sql
SELECT overlay('Txxxxas' placing 'hom' from 3 for 4);   -- Thomas
```

# parse_ident

`parse_ident(text) → text[]`

把**限定的标识符**（如 `"schema"."table"`）解析并拆分为数组，各部分去除引号。

```sql
SELECT parse_ident('"some_schema"."some_table"');   -- {some_schema,some_table}
```

> 相关：`quote_ident` 是其反向操作（加引号）。动态拼接前先 `parse_ident` 校验合法性，能挡下很多注入/语法错误。

# pg_client_encoding

`pg_client_encoding() → name`

返回**当前客户端编码名**（如 `UTF8`）。

```sql
SHOW client_encoding;              -- UTF8
SELECT pg_client_encoding();       -- UTF8
```

# position

`position(substring text in string text) → integer`

返回子串首次出现的**位置**（从 1 计），未找到返回 0。这是 SQL 标准写法。

```sql
SELECT position('om' in 'Thomas');   -- 3
```

> 等价：`strpos(string, substring)` 参数顺序相反（串在前、子串在后）。二者都是**区分大小写**的精确匹配。

# quote_ident

`quote_ident(text) → text`

把字符串安全地转成 **SQL 标识符**：需要时加双引号并转义内部双引号。

```sql
SELECT quote_ident('foo');       -- foo
SELECT quote_ident('Foo Bar');   -- "Foo Bar"
SELECT quote_ident('a"b');       -- "a""b"
```

> 实战：动态 `CREATE TABLE`/拼接列名时对每个标识符套 `quote_ident`，防止大小写、空格、关键字、注入问题。字符串字面量用 `quote_literal`。

# quote_literal

`quote_literal(text) → text`

把值安全地包成 SQL **字符串字面量**（加单引号并转义内部引号）。

```sql
SELECT quote_literal('O''neill');   -- 'O''''neill'
```

> 注意：入参是 `anynonarray`，NULL 返回 NULL 字符串。动态拼 SQL 里的值用它，别手动拼引号。更推荐直接用 `format('%L', val)`。

# quote_nullable

`quote_nullable(text) → text`

同 `quote_literal`，但 **NULL 返回字符串 `'NULL'`** 而非 NULL，便于拼出合法 SQL。

```sql
SELECT quote_nullable('O''Neill');   -- '''O''''Neill'''
SELECT quote_nullable(NULL);         -- NULL（作为文本 NULL）
```

# regexp_match

`regexp_match(string text, pattern text [, flags text]) → text[]`

返回**第一个**匹配的子串捕获组数组；无匹配返回 NULL。

```sql
SELECT regexp_match('foobarbequebaz', '(bar)(beque)');   -- {bar,beque}
```

> 相关：要返回**所有**匹配用 `regexp_matches`（集合返回）；只要布尔判断用 `~` 操作符或 `regexp_like`（PG18 新增）。

# regexp_matches

`regexp_matches(string text, pattern text [, flags text]) → setof text[]`

对每个匹配**返回一行**捕获组数组（集合返回函数）。默认全局匹配。

```sql
SELECT regexp_matches('foobarbequebaz', 'ba.', 'g');   -- 三行: {bar},{beq},{baz}
```

> flags：`g` 全局、`i` 忽略大小写、`n` 让 `.` 不匹配换行、`m` 多行、`s` 让 `.` 匹配换行、`x` 扩展（忽略空白与 # 注释）。不带 `g` 时只返回第一组。

# regexp_replace

`regexp_replace(string text, pattern text, replacement text [, flags text]) → text`

用正则替换。`replacement` 里可用 `\1`、`\2` 引用捕获组。

```sql
SELECT regexp_replace('Thomas', '.[mN]a.', 'M');   -- ThM
```

> 相关：`replace` 是**字面量**替换（非正则）。要"每处都换"记得加 `g` 标志，否则只替换第一处——这是最常见的疏漏。

# regexp_split_to_array

`regexp_split_to_array(string text, pattern text [, flags text]) → text[]`

按正则切分，返回**数组**。

```sql
SELECT regexp_split_to_array('a..b...c....d', '\.+');   -- {a,b,c,d}
```

> 相关：`regexp_split_to_table` 返回多行而非数组；固定分隔符用 `string_to_array`。

# regexp_split_to_table

`regexp_split_to_table(string text, pattern text [, flags text]) → setof text`

按正则切分，每个片段**返回一行**。

```sql
SELECT regexp_split_to_table('a,b,c', ',');   -- 三行 a / b / c
```

# repeat

`repeat(text, int) → text`

把字符串**重复 n 次**。

```sql
SELECT repeat('Pg', 4);   -- PgPgPgPg
```

# replace

`replace(text, from text, to text) → text`

**字面量**（非正则）替换所有子串。

```sql
SELECT replace('abcdefabcdef', 'cd', 'XX');   -- abXXefabXXef
```

> 相关：需要模式匹配用 `regexp_replace`。`replace` 会替换**全部**出现位置，且 from 为空串时原样返回。

# reverse

`reverse(text) → text`

字符**逆序**。

```sql
SELECT reverse('abc');   -- cba
```

> 坑：按字符逆序，但对组合字符（带声调、emoji 修饰）不感知，可能打乱语义。

# right

`right(text, int) → text`

返回后 `n` 个字符；`n` 为负则**去掉前 |n| 个**、返回其余。`left` 的镜像。

```sql
SELECT right('abcdefg', 3);    -- efg
SELECT right('abcdefg', -4);   -- efg（去掉前 4 个字符 abcd）
```

> 提醒：`left(x, -k)` 去掉**末尾** k 个，`right(x, -k)` 去掉**开头** k 个，两者负数方向相反，别记混。

# rpad

`rpad(text, int [, fill text]) → text`

在**右侧填充**至长度 n，超长截断。

```sql
SELECT rpad('hi', 4, 'xy');   -- hixy
```

# rtrim

`rtrim(text [, characters text]) → text`

去除**右端**空白或指定字符。

```sql
SELECT rtrim('testxxzx', 'xyz');   -- test
```

# split_part

`split_part(string text, delimiter text, n integer) → text`

按分隔符切分并取**第 n 段**（从 1 计）；无第 n 段返回空串。

```sql
SELECT split_part('abc~@~def~@~ghi', '~@~', 2);   -- def
```

> 坑：分隔符是**字面量**（非正则）。要拆成数组用 `string_to_array`；要按正则拆分用 `regexp_split_to_array`。取"最后一段"没有负索引，需配合 `array_length`。

# starts_with

`starts_with(text, text) → boolean`

判断是否以指定前缀开头。可用普通 **B-tree 索引**加速（这点优于 `LIKE 'x%'` 在非 C locale 下的麻烦）。

```sql
SELECT starts_with('high', 'hi');   -- t
```

# string_to_array

`string_to_array(string text, delimiter text [, null_string text]) → text[]`

按字面分隔符切分为数组。NULL 分隔符返回 NULL；把某字段解析为数组时把 `null_string` 设为空可保留空元素。

```sql
SELECT string_to_array('xx~^~yy~^~zz', '~^~');   -- {xx,yy,zz}
```

> 反向：`array_to_string`。要转成行用 `string_to_table`。

# string_to_table

`string_to_table(string text, delimiter text [, null_string text]) → setof text`

切分后**每个元素一行**（集合返回，PG14+）。

```sql
SELECT string_to_table('foo|bar', '|');   -- 两行 foo / bar
```

# strpos

`strpos(string text, substring text) → integer`

返回子串首次出现位置（从 1 计），等价于 `position(substring in string)` 但**参数顺序相反**。

```sql
SELECT strpos('high', 'ig');   -- 2
```

# substr

`substr(text, start [, count]) → text`

截取子串，`start` 从 1 计，`count` 省略则到结尾。`substring` 的简写别名。

```sql
SELECT substr('alphabet', 3, 2);   -- ab
```

# substring

`substring(string from pattern) / substring(string [from int] [for int]) → text`

支持**两种形态**：SQL 标准 `from ... for ...`，以及带**正则捕获**的 `substring(text from pattern)`。

```sql
SELECT substring('alphabet' from 3 for 2);          -- ab
SELECT substring('Thomas' from '...([A-Z][a-z]*)'); -- 正则捕获
```

> 区别：`substr` 只能按位置；`substring` 额外支持正则。需要正则提取但只取一段时 `substring` 更直接。

# to_ascii

`to_ascii(text [, encoding]) → text`

把非 ASCII 字符**转写成 ASCII 近似形式**（如带重音字母去掉重音），常用于按 ASCII 排序/匹配。

```sql
SELECT to_ascii('karel');   -- karel（取决于编码）
```

> 坑：只处理特定编码的重音折叠，**对中文无效**。做拼音排序请用 ICU 排序规则或 `pinyin` 类扩展。

# to_char

`to_char(timestamp/date/interval/time, text) → text`

把时间/间隔**格式化为字符串**。格式模板如 `YYYY-MM-DD HH24:MI:SS`。

```sql
SELECT to_char(now(), 'HH12:MI');          -- 09:15
SELECT to_char(interval '18:20:00', 'HH24:MI:SS');  -- 18:20:00
```

> 详细格式符号见 **[日期时间函数](./010.日期时间函数.md)** 的 `to_char` 说明与官方 Table 9.10。数字版 `to_char(numeric, text)` 见 `to_number`。

# to_hex

`to_hex(integer | bigint) → text`

把整数转**十六进制字符串**。

```sql
SELECT to_hex(123456789);   -- 75bcd15
```

# to_number

`to_number(text, text) → numeric`

按格式模板把字符串**解析回数字**（`to_char(numeric)` 的逆）。

```sql
SELECT to_number('8,423.005', '8,423.005');   -- 8423.005
SELECT to_number('$1,300.00', 'L999,999.99');  -- 1300.00
```

> 坑：格式模板里的分隔符/小数位必须与文本对齐，否则解析出错。

# translate

`translate(text, from text, to text) → text`

**逐字符映射**替换：`from` 中每个字符按位置替换成 `to` 中对应字符；`to` 中多出的位置对应字符被删除。

```sql
SELECT translate('12345', '143', 'ax');   -- a2x5（1→a,4→,3→x）
SELECT translate('12345', '134', 'ax');   -- a25（4 无对应被删）
```

> 与 `replace` 区别：`replace` 按**子串整体**替换，`translate` 按**单字符一一对应**。做字符集转换/去重音用 `translate` 更简洁。

# trim

`trim([leading|trailing|both] [characters] from string) → text`

SQL 标准去除端点字符，默认去空格。`from` 子句可指定要去除的字符集。

```sql
SELECT trim('    trim me');                -- trim me
SELECT trim(leading 'x' from 'xxxbarxxx'); -- barxxx
SELECT trim(both 'xyz' from 'yyxbarzz');   -- bar
```

> 等价：`btrim`(both)/`ltrim`(leading)/`rtrim`(trailing)。

# unistr

`unistr(text [, esc char]) → text`

把字符串中的 **Unicode 转义**（`\XXXX`、`\+XXXXXX`）转换为实际字符，可自定义转义引导符。

```sql
SELECT E'D\0673l\00E9\0061';                 -- Dàoàéa?（含转义）
SELECT unistr('D\0061\006F');                -- Dao
SELECT unistr(U&'\0061\0062');               -- ab
```

> 实战：在无法直接输入特殊字符的 SQL 里构造换页、制表符、任意 Unicode 字符。

# upper

`upper(text) → text`

转**大写**，遵循当前排序规则。

```sql
SELECT upper('tom');   -- TOM
```

> 相关：`lower`、`initcap`。大小写不敏感比较优先用排序规则或表达式索引，而非对每行套 `upper()`（后者会让普通索引失效）。
