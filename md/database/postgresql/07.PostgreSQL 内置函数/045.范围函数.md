# 概述

本篇覆盖官方 9.11 节**范围类型函数**。范围类型（`int4range`、`numrange`、`tsrange`、`tstzrange`、`daterange` 及 PG14+ 的多范围 `multirange`）表示一段连续区间，常用于排期、价格区间、有效期。

核心心智模型——**规范化区间 `[lower, upper)`**：

- 默认**含下界、不含上界**（`[)`）。`'[3,8)'` 覆盖 3~7.999…。
- `lower_inc`/`upper_inc` 告诉你边界到底**包不包含**；`lower_inf`/`upper_inf` 告诉你是不是**无穷**（未设界）。
- 存进列时 PG 常做 `range_normalize`，把 `(a,b]` 之类规整成 `[)`，所以查出来的边界可能和你写入时"看起来"不同。

> 范围上的**包含/重叠操作符** `@>` `&&` `<<` `&<` 等，以及 GiST 排期冲突索引，见 **[索引类型](../06.PostgreSQL%20索引/005.索引类型.md)**。

# isempty()

`isempty(anyrange) → boolean`

区间是否为**空**（上界 ≤ 下界导致无任何值，写作 `'empty'`）。

```sql
SELECT isempty(int4range(5, 5));    -- true（[5,5) 不含任何整数）
SELECT isempty(int4range(3, 8));    -- false
```

# lower_inc()

`lower_inc(anyrange) → boolean`

**下界是否闭合**（包含）。

```sql
SELECT lower_inc(numrange('[3,8)'));   -- true
SELECT lower_inc(numrange('(3,8]'));   -- false
```

# lower_inf()

`lower_inf(anyrange) → boolean`

**下界是否为无穷**（无下界）。

```sql
SELECT lower_inf(int4range(NULL, 10));   -- true
```

# lower()

`lower(anyrange) → anyelement`

返回**下界值**；下界为无穷或区间为空时返回 NULL。

```sql
SELECT lower(int4range(3, 8));   -- 3
```

# multirange()

`multirange(anyrange) → anymultirange`；聚合版 `multirange(VARIADIC anyrange[])`

把**单个范围包成多范围**（multirange）；PG14+ 的多范围类型可存多段不连续区间并自动合并相邻/重叠段。

```sql
SELECT multirange(int4range(3, 8));             -- {[3,8)}
SELECT '{[1,3),[10,15)}'::int4multirange
    - '{[2,4)}'::int4multirange;                -- 多范围集合运算
```

> 多范围是"若干个两两不相交、已排序的范围"；做班次、可用时段合并很顺手，`range_merge` 只能并两段相邻的，multirange 能表达离散多段。

# range_merge()

`range_merge(anyrange, anyrange) → anyrange`

返回**同时包含两个范围的最小范围**（两端并起来的包围盒，中间的洞会被填上）。

```sql
SELECT range_merge(int4range(1,5), int4range(7,9));   -- [1,9)（洞被填平）
```

> 想要"保留两段的分离结构"应转成 multirange，而不是 `range_merge`。

# unnest()

`unnest(anyrange) → setof anyrange`；`unnest(anymultirange) → setof anyrange`

把**多范围拆开**，每段范围一行。

```sql
SELECT unnest('{[1,3),[10,15)}'::int4multirange);   -- [1,3) / [10,15) 两行
```

> 与数组的 `unnest`（见 **[数组函数](./020.数组函数.md)**）、`range_array` 等互为展开工具。

# upper_inc()

`upper_inc(anyrange) → boolean`

**上界是否闭合**（包含）。

```sql
SELECT upper_inc(numrange('[3,8)'));   -- false
SELECT upper_inc(numrange('[3,8]'));   -- true
```

# upper_inf()

`upper_inf(anyrange) → boolean`

**上界是否为无穷**（无上界）。

```sql
SELECT upper_inf(tsrange('2026-01-01', NULL));   -- true
```

# upper()

`upper(anyrange) → anyelement`

返回**上界值**；上界无穷或空区间返回 NULL。

```sql
SELECT upper(int4range(3, 8));   -- 8（但不含 8）
```
