# 概述

本篇覆盖官方 9.5 节**数学函数**。要点先记住：

- **返回类型随输入类型变化**：对 `integer` 输入，`/`、`%`、`div`、`mod` 走**整数**运算（截断）；对 `double precision` 走浮点。想避免整数除法陷阱，先把一侧转成 `numeric`/`float`。
- **三角函数的参数/返回值单位是弧度**；带后缀 `d` 的版本（`sind`、`cosd`、`atand`…）单位是**角度**，省去手动 `radians()`/`degrees()` 转换。
- **hyperbolic 系列**（`sinh`/`cosh`/`tanh` 及反函数）处理双曲/反双曲。
- `round` 的"银行家舍入 vs 四舍五入"：对 `numeric` 是**四舍五入（远离零）**，对浮点是**就近舍入**，涉及金额一律用 `numeric`。

> 相关操作符：`+ - * / % ^ |/ ||/ ! !!` 等，见官方 Table 9.3。

# abs

`abs(numeric|int|bigint|real|double precision) → 同类型`

绝对值。

```sql
SELECT abs(-17.4);   -- 17.4
SELECT abs(-33);     -- 33
```

# acos

`acos(double precision) → double precision`

反余弦，返回**弧度**，定义域 `[-1,1]`，值域 `[0,π]`。

```sql
SELECT acos(1);   -- 0
```

# acosd

```sql
SELECT acosd(1);   -- 0
```

# acosh

```sql
SELECT acosh(1);   -- 0
```

`atan(double precision) → double precision`

```sql

```

# atan2

`atan2(y double precision, x double precision) → double precision`

两参数反正切，返回**弧度**，按象限给出 `y/x` 的正确角度，值域 `[-π, π]`。计算方位角/极角的首选。

```sql
SELECT atan2(-1, -1);   -- 弧度，落在第三象限
```

> 坑：参数顺序是 **(y, x)**，别写反。x、y 同为 0 时报错。

# atan2d

`atan2d(y double precision, x double precision) → double precision`

`atan2` 的**角度**版本。

```sql
SELECT atan2d(-1, -1);   -- -135
```

# cot

`cot(double precision) → double precision`

余切，参数为**弧度**（= 1/tan）。


# div

`div(numeric|int|bigint, 同类型) → 同类型`

**整数除法**（截断取整，向零）。与 `/` 对整数等价，但对浮点 `/` 保留小数、`div` 仍截断。

```sql
SELECT div(9, 4);       -- 2
SELECT div(9.0, 4.0);   -- 2（即使是浮点也截断）
SELECT 9/4;             -- 2（整数）  vs  9.0/4 → 2.25
```

# gcd

`gcd(numeric|int|bigint, 同类型) → numeric`

**最大公约数**，任一为 0 时返回另一个的绝对值。

```sql
SELECT gcd(48, 18);   -- 6
```

> PG 14+ 提供；对 NULL 返回 NULL。与 `lcm` 配对。

# lcm

`lcm(numeric|int|bigint, 同类型) → numeric`

**最小公倍数**，任一为 0 时返回 0。

```sql

```

# ln

`ln(double precision|numeric) → 同类型`

**自然对数**（底 e）。参数必须 > 0。

```sql
SELECT ln(2.718281828459045);   -- 1
```

# log

`log(b numeric, x numeric) → numeric`

**以 b 为底** x 的对数（PG 14+ 的两参数版）。

```sql
SELECT log(2, 4096);   -- 12
```

> 注意：单参数 `log(x)`（PG 旧行为/标准 SQL）是**常用对数底 10**（等价 `log10`），"ln 才是自然对数"。别把 `log(x)` 当自然对数——这是 Java/JS 开发者最常犯的错。

# log10

`log10(double precision|numeric) → 同类型`

**以 10 为底**的对数。

```sql
SELECT log10(100);   -- 2
```

# min_scale

`min_scale(numeric) → integer`

去除**多余小数 0** 后所需的最小标度（小数位数）。用于判断 numeric 尾部有多少可省略的 0。

```sql
SELECT min_scale(8.4100);   -- 2
```

> 相关：`trim_scale` 实际去掉这些 0；`scale` 返回当前标度。

# mod

`mod(numeric|int|bigint|real|double precision, 同类型) → 同类型`

**取模（余数）**，符号与被除数一致。等价于 `%` 操作符。

```sql
SELECT mod(5, 4);   -- 1
SELECT mod(-5, 4);  -- -1
```

> 坑：结果符号跟随**被除数**（第一个参数），与某些语言"跟随除数"不同。

# pi

`pi() → double precision`

返回圆周率 π。

```sql
SELECT pi();   -- 3.14159265358979
```

# power

`power(a numeric|double precision, b 同类型) → 同类型`

求 a 的 b 次幂（a^b），`^` 操作符的函数形式。参数为整型时结果转 `double precision`。

```sql
SELECT power(9, 0.5);   -- 3（开平方）
SELECT power(2, 10);    -- 1024（整型入参→double）
```

> 相关：`^` 操作符；开平方用 `sqrt`，立方根用 `cbrt`。

# radians

`radians(double precision) → double precision`

**角度 → 弧度**，`degrees` 的逆。

```sql
SELECT radians(180);   -- pi()
```

# random

`random() → double precision`

返回 `[0, 1)` 均匀分布的**伪随机数**。

```sql
SELECT random();                       -- 0.3752...
SELECT floor(random() * 10 + 1);       -- 1..10 随机整数
```

> 实战：要加密安全随机数用 `pgcrypto` 的 `gen_random_bytes`；`random` 每次调用都不同，非 IMMUTABLE，**不能直接用于索引表达式**。可配合 `setseed` 复现序列。

# round

`round(v numeric [, s integer]) → numeric`
`round(v double precision) → double precision`

四舍五入到整数，或对 `numeric` **保留 s 位小数**。

```sql
SELECT round(42.4);          -- 42
SELECT round(cast(42.45 as numeric), 1);   -- 42.5
```

> 坑：**两参数版只对 `numeric` 有效**，浮点 `round(double, int)` 不存在，需先 `::numeric`。浮点单参数版是"就近偶数"舍入，金额计算务必转 numeric。

# scale

`scale(numeric) → integer`

返回 numeric 的**标度**（小数点后的数字位数）。

```sql
SELECT scale(8.41);   -- 2
```

# setseed

`setseed(double precision) → void`

为 `random()` 设置**随机种子**（`[-1, 1]`），使后续随机序列可复现。种子是**会话级**的。

```sql
SELECT setseed(0.1728);
SELECT random();   -- 每次跑这段，第一句 random 值稳定
```

> 提醒：跨会话/版本不保证完全一致，用于"可复现抽样"够用，别当严格随机数测试依据。

# trim_scale

`trim_scale(numeric) → numeric`

去掉 numeric 尾部**多余的 0**，值不变但标度更小（用 `min_scale` 可知去掉几位）。


# trunc

`trunc(numeric [, s integer]) → numeric`
`trunc(double precision) → double precision`

向零**截断**小数（不四舍五入），或对 numeric 截断到 s 位小数。

```sql
SELECT trunc(42.8);   -- 42
SELECT trunc(-42.8);  -- -43
SELECT trunc(cast(42.4382 as numeric), 2);   -- 42.43
```

> 与 `round` 区别：`trunc` 直接砍掉小数、向零靠拢；`round` 会进位。

# width_bucket

`width_bucket(operand numeric|double, low, high, count int) → bigint`

把值映射到 `[low, high)` 划分的 `count` 个等宽桶中，返回**桶号**（从 1 到 count）；低于 low 返回 0，高于等于 high 返回 count+1。做**直方图/分箱**的利器。

```sql
SELECT width_bucket(5.7, 1.0, 9.0, 4);   -- 落进哪个桶
-- 统计成绩分布
SELECT width_bucket(score, 0, 100, 10) AS bucket, count(*)
FROM exams GROUP BY 1 ORDER BY 1;
```

> 提示：`count` 必须为正整数。配合 `generate_series` 生成桶标签即可画出分箱直方图。
