# 概述

在编写 **Markdown** 文档内容时，需要使用表格的形式，记录数据库表结构信息。

# SQL模版

- **param_table_name**：表名，必填

```sql
WITH cols AS (
  SELECT
    a.attnum AS ordinal_position,
    a.attname AS column_name,
    pg_catalog.format_type(a.atttypid, a.atttypmod) AS column_type,
    CASE WHEN a.attnotnull THEN 'NO' ELSE 'YES' END AS is_nullable,
    pg_get_expr(ad.adbin, ad.adrelid) AS column_default,
    col_description(a.attrelid, a.attnum) AS column_comment
  FROM pg_attribute a
  LEFT JOIN pg_attrdef ad
    ON ad.adrelid = a.attrelid
   AND ad.adnum = a.attnum
  WHERE a.attrelid = format('%I.%I', current_schema(), '#{param_table_name}')::regclass
    AND a.attnum > 0
    AND NOT a.attisdropped
)
SELECT
  '| 序号 | 字段名 | 类型 | 允许空 | 默认值 | 注释 |' || E'\n' ||
  '|---:|---|---|---|---|---|' || E'\n' ||
  string_agg(
    '| ' || ordinal_position ||
    ' | ' || replace(column_name, '|', E'\\|') ||
    ' | ' || replace(column_type, '|', E'\\|') ||
    ' | ' || is_nullable ||
    ' | ' || replace(COALESCE(column_default, ''), '|', E'\\|') ||
    ' | ' || replace(COALESCE(column_comment, ''), '|', E'\\|') ||
    ' |',
    E'\n' ORDER BY ordinal_position
  ) AS markdown
FROM cols;
```

# 示例

查询 **[actor](../01.PostgreSQL%20起步/04.PostgreSQL%20示例数据库.md#演员表)** 表结构信息。

```sql
WITH cols AS (
  SELECT
    a.attnum AS ordinal_position,
    a.attname AS column_name,
    pg_catalog.format_type(a.atttypid, a.atttypmod) AS column_type,
    CASE WHEN a.attnotnull THEN 'NO' ELSE 'YES' END AS is_nullable,
    pg_get_expr(ad.adbin, ad.adrelid) AS column_default,
    col_description(a.attrelid, a.attnum) AS column_comment
  FROM pg_attribute a
  LEFT JOIN pg_attrdef ad
    ON ad.adrelid = a.attrelid
   AND ad.adnum = a.attnum
  WHERE a.attrelid = format('%I.%I', current_schema(), 'actor')::regclass
    AND a.attnum > 0
    AND NOT a.attisdropped
)
SELECT
  '| 序号 | 字段名 | 类型 | 允许空 | 默认值 | 注释 |' || E'\n' ||
  '|---:|---|---|---|---|---|' || E'\n' ||
  string_agg(
    '| ' || ordinal_position ||
    ' | ' || replace(column_name, '|', E'\\|') ||
    ' | ' || replace(column_type, '|', E'\\|') ||
    ' | ' || is_nullable ||
    ' | ' || replace(COALESCE(column_default, ''), '|', E'\\|') ||
    ' | ' || replace(COALESCE(column_comment, ''), '|', E'\\|') ||
    ' |',
    E'\n' ORDER BY ordinal_position
  ) AS markdown
FROM cols;
```

查询结果：

```text
| 序号 | 字段名 | 类型 | 允许空 | 默认值 | 注释                               |
|---:|---|---|---|---|------------------------------------|
| 1 | actor_id | integer | NO | nextval('actor_actor_id_seq'::regclass) | 用于唯一标识表中每个演员的代理主键 |
| 2 | first_name | character varying(45) | NO |  | 演员的名字                         |
| 3 | last_name | character varying(45) | NO |  | 演员姓                             |
| 4 | last_update | timestamp without time zone | NO | now() | 该行的创建时间或最近更新时间       |
```

复制结果，粘贴到 **Markdown** 文档中，即可渲染为表格。
