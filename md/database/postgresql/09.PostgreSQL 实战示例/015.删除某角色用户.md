# 概述

删除某角色用户，并转移该角色用户拥有的数据库对象和权限到 postgres 角色。

# SQL模版

- **role_name**: 用户角色
- **database_owned**: 数据库名称

```sql
-- 查询该角色拥有的数据库（需改 owner 的）
SELECT datname AS database_owned
FROM pg_database
WHERE datdba = (SELECT oid FROM pg_roles WHERE rolname = '#{role_name}');

-- 在 postgres 库
\c postgres

-- 改数据库 owner
ALTER DATABASE #{database_owned} OWNER TO postgres;

-- 进入 database_owned
\c #{database_owned}

-- 转移对象 + 清理权限
REASSIGN OWNED BY gitea TO postgres;
DROP OWNED BY gitea;

-- 回到 postgres 删除角色
\c postgres
DROP ROLE #{role_name};
```

\c testdb
