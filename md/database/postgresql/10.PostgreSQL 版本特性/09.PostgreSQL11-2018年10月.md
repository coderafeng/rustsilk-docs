这个版本在 PostgreSQL 10 的基础上进行了“查漏补缺”和深度优化，重点提升了**大数据量**和**高计算负载**下的表现 [^1]。

- **分区表功能完善：** 新增了**哈希分区**。同时支持在分区表上创建**主键、外键、索引和触发器**（并自动应用到所有分区），支持**默认分区**以及分区键更新后的**自动行迁移**，让分区表真正具备了生产级可用性 [^2]。
- **存储过程：** 引入了 SQL 标准的 CREATE PROCEDURE，首次支持在过程内部进行**事务控制**（如部分提交）。这对于从 Oracle 等数据库迁移的用户来说，是一个关键的兼容性补全 [^1] [^2]。
- **JIT 编译：** 引入了基于 **LLVM** 的即时编译技术，用于加速 WHERE 条件、目标列表、聚合等表达式的计算。虽然默认关闭，但为后续版本的性能提升打下了基础 [^1] [^3]。
- **并行能力扩展：** 支持了**并行创建 B-tree 索引、并行哈希连接**，以及并行执行 CREATE TABLE AS、SELECT INTO 等数据定义操作 [^1] [^3]。
