# 概述

在日常使用 PostgreSQL 时，除了通过 **[SELECT](../02.PostgreSQL%20基础/000.SELECT.md#概述)**、**[INSERT](../02.PostgreSQL%20基础/130.INSERT%20插入新行.md#概述)**、**[UPDATE](../02.PostgreSQL%20基础/140.UPDATE%20更新行.md#概述)**、**[DELETE](../02.PostgreSQL%20基础/150.DELETE%20删除行.md#概述)** 等语句操作数据之外，我们还需要对数据库实例本身进行管理与维护，例如查看有哪些数据库、查看表结构、监控占用空间、备份与恢复数据、重置用户密码、分析查询性能等。这些操作统称为 **数据库管理**。

PostgreSQL 的管理能力主要由以下三类工具协同提供：

- **psql 元命令（Meta-Command）**：以反斜杠 **\\** 开头的命令，只在 **psql** 客户端中被解释，不会被发送到服务器。它们是对系统目录查询的封装，用于快速列出数据库、表、索引、用户等对象，例如 **\l**、**\dt**、**\d**。
- **SQL 语句**：标准的 SQL 命令，会发送到服务端执行。既包括 **CREATE DATABASE**、**ALTER ROLE** 等管理型 DDL 语句，也包括对系统目录表（**pg_database**、**pg_class** 等）和系统函数（**pg_database_size()**、**pg_size_pretty()** 等）的查询。
- **操作系统命令行工具**：随服务端一起安装的可执行程序，在 psql 之外运行，用于备份、恢复、批量维护等，例如 **pg_dump**、**pg_restore**、**pg_dumpall**、**pg_basebackup**。

# 三类工具的分工

| 维度 | psql 元命令 | SQL 语句 | 命令行工具 |
| --- | --- | --- | --- |
| 运行位置 | psql 客户端本地 | 服务端 | 操作系统 Shell |
| 是否需要连接 | 需要（已在 psql 中） | 需要（已在 psql 中） | 部分需要（如 pg_dump），部分不需要（如 pg_basebackup 之外的本地操作） |
| 典型用途 | 快速查看对象信息 | 精确查询/修改系统状态 | 备份、恢复、迁移 |
| 举例 | **\dt**、**\d**、**\l** | **SELECT**、**CREATE DATABASE**、**pg_size_pretty()** | **pg_dump**、**pg_restore** |

一般规律是：**查看**用元命令最省事，**精确控制**用 SQL，**整库备份与迁移**用命令行工具。

# 总结

PostgreSQL 的数据库管理由 **psql 元命令**、**SQL 语句** 和 **命令行工具** 三类手段构成。元命令擅长快速查看，SQL 擅长精确查询与修改系统状态，命令行工具则负责备份、恢复与迁移等重活。掌握它们的分工，是高效管理 PostgreSQL 实例的基础。
