# 概述

在连接到某个数据库后，我们经常需要查看它包含哪些表。PostgreSQL 提供了从 **psql 元命令** 到 **系统目录 / information_schema 查询** 等多种方式，可以从"快速浏览"到"脚本化处理"满足不同需求。

# 使用 \dt 列出表

**\dt** 是最快捷的方式，列出当前数据库中 **public** 架构下的所有普通表：

```text
sakila=# \dt
                List of relations
 Schema |      Name       | Type  |  Owner
--------+-----------------+-------+----------
 public | actor           | table | postgres
 public | address         | table | postgres
 public | category        | table | postgres
 public | city            | table | postgres
 public | country         | table | postgres
 public | customer        | table | postgres
 public | film            | table | postgres
 public | inventory       | table | postgres
 public | language        | table | postgres
 public | payment         | table | postgres
 public | rental          | table | postgres
 ...
```

## 常用变体

模式参数与 `\dt` 之间用空格分隔；其中 `*` 是通配符（匹配任意名字），`.` 是 schema 与表名的分隔符。

| 写法 | 作用 |
| --- | --- |
| `\dt` | 仅 search_path（默认 public）架构下的表 |
| `\dt+` | 附加显示大小、描述等 |
| `\dt *.*` | 所有架构下的所有表 |
| `\dt film*` | 以 film 开头的表 |
| `\dt sales.*` | sales 架构下的所有表 |
| `\dv` | 列出视图（view） |
| `\dm` | 列出物化视图（materialized view） |
| `\di` | 列出索引（index） |
| `\ds` | 列出序列（sequence） |

> 说明：多个模式可用逗号分隔，例如 `\dt t1*,t2*` 匹配名字以 t1 或 t2 开头的表。

列出所有架构的表：

```text
sakila=# \dt *.*

                     List of relations
       Schema       |       Name       | Type  |  Owner
--------------------+------------------+-------+----------
 hr                 | departments      | table | postgres
...
 public              | actor            | table | postgres
 public              | film             | table | postgres
```

# 查询 information_schema

标准视图 **information_schema.tables** 适合跨数据库可移植的脚本查询。列出当前用户可访问的基本表：

```sql
SELECT
    table_schema,
    table_name
FROM information_schema.tables
WHERE table_type = 'BASE TABLE'
ORDER BY table_schema, table_name;
```

```text
 table_schema | table_name
--------------+------------
 public       | actor
 public       | address
 public       | category
 public       | film
 ...
```

- **table_type** 取值 **BASE TABLE**（普通表）或 **VIEW**（视图）。
- **table_schema** 为架构名，可加 **WHERE table_schema = 'public'** 过滤。

# 查询 pg_class 系统目录

PostgreSQL 特有的 **pg_class** 保存了所有"关系"（表、索引、视图、序列等）的元信息，配合 **pg_namespace** 可查到更底层、更全的信息：

```sql
SELECT
    n.nspname AS schema_name,
    c.relname AS table_name,
    CASE c.relkind
        WHEN 'r' THEN 'table'
        WHEN 'v' THEN 'view'
        WHEN 'm' THEN 'materialized view'
        WHEN 'i' THEN 'index'
        WHEN 'S' THEN 'sequence'
        ELSE c.relkind::text
    END AS object_type
FROM pg_class c
JOIN pg_namespace n ON n.oid = c.relnamespace
WHERE c.relkind IN ('r', 'v', 'm')
  AND n.nspname NOT LIKE 'pg_%'
  AND n.nspname <> 'information_schema'
ORDER BY schema_name, table_name;
```

说明：

- **relkind** 用单字符标识对象类型，**r** = 普通表，**v** = 视图，**m** = 物化视图。
- 过滤掉 **pg_%** 与 **information_schema** 可隐藏系统内部对象，只留用户表。
- 便捷视图 **pg_stat_user_tables** / **pg_tables** 已帮你完成这些过滤，直接 **SELECT tablename FROM pg_tables WHERE schemaname='public';** 也可列出表名。

# 总结

列出表有三种主流方式：psql 元命令 `\dt`（及 `\dt+`、`\dt *.*` 等变体）最快；**information_schema.tables** 适合可移植脚本；**pg_class / pg_tables** 提供最底层、最灵活的系统目录查询。按是否需要脚本化、是否需要跨架构选择对应方式即可。
