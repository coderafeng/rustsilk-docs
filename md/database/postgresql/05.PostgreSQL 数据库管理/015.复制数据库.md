# 概述

**复制数据库** 指的是创建一个与已有数据库结构（甚至数据）相同的新数据库。常见场景有：从模板库派生新项目库、把生产库的结构复制到测试库、重命名数据库（PostgreSQL 没有直接重命名整个库内容的方式时常用先建后导）。

PostgreSQL 提供两种主要手段：

- 基于 **TEMPLATE** 的 `CREATE DATABASE`：复制一个模板库的**全部对象定义和数据**（要求模板库当前无其他连接）。
- 基于 **pg_dump | psql** 管道：先转储源库，再导入到新库，可跨版本、可选择性复制。

# 使用 CREATE DATABASE ... TEMPLATE

创建数据库时通过 **TEMPLATE** 子句指定模板，新库会成为模板库的一份拷贝（含数据）：

```sql
CREATE DATABASE new_db TEMPLATE existing_db;
```

语法要点：

- 新库会复制 **existing_db** 中的所有表、索引、约束以及**表中的数据**。
- 执行时必须保证 **existing_db 当前没有任何其他连接**，否则会报错：
  ```text
  ERROR:  source database "existing_db" is being accessed by other users
  ```
  可先断开其连接：`SELECT pg_terminate_backend(pid) FROM pg_stat_activity WHERE datname = 'existing_db';`
- 若省略 **TEMPLATE**，默认使用 **template1**；使用 **TEMPLATE template0** 可创建一个"干净"的、可指定不同编码/排序规则的库。

## 示例：从 template0 创建带指定编码的库

因为 **template1** 可能已被装入扩展、且编码固定，若要创建不同编码的库必须从 **template0** 复制：

```sql
CREATE DATABASE myapp
    TEMPLATE template0
    ENCODING 'UTF8'
    LC_COLLATE 'en_US.utf8'
    LC_CTYPE 'en_US.utf8';
```

**myapp** 是一个不含任何用户对象的干净库，仅带有默认初始化内容。

## 示例：完整复制一个业务库

假设要把 **sakila** 库整体复制一份为 **sakila_copy**（含数据），且当前无人连接 sakila：

```sql
CREATE DATABASE sakila_copy TEMPLATE sakila;
```

随后用 **\l** 即可看到新库出现，**查看空间**（见 **[查看空间](./020.查看空间.md)**）可确认二者大小一致。

# 使用 pg_dump | psql 管道复制

当源库无法断开连接、或需要跨服务器/跨版本复制时，用逻辑转储更灵活。核心思想是把 **pg_dump** 的输出直接管进 **psql**：

```bash
# 1. 先创建空目标库（CREATE DATABASE 也可以省略，取决于脚本内容）
psql -U postgres -c "CREATE DATABASE sakila_copy;"

# 2. 转储源库并即时导入目标库
pg_dump -U postgres sakila | psql -U postgres sakila_copy
```

在 Windows PowerShell 中，管道用法一致：

```powershell
pg_dump -U postgres sakila | psql -U postgres sakila_copy
```

方式对比：

| 方式 | 是否要求源库空闲 | 可跨版本/主机 | 可选择性复制 | 复杂度 |
| --- | --- | --- | --- | --- |
| **CREATE DATABASE TEMPLATE** | 是 | 否（同实例内） | 否（整库） | 低 |
| **pg_dump \| psql** | 否 | 是 | 是（配合 pg_dump 选项） | 中 |

关于 **pg_dump** 的更多选项，见 **[备份和恢复](./040.备份和恢复.md)**。

# 通过复制实现"重命名数据库"

PostgreSQL 没有直接重命名整个数据库内容并保留数据的简单操作（**ALTER DATABASE ... RENAME TO** 会重命名，但仍需无连接）。更通用的"改名"做法是复制后再删旧库：

```bash
# 用新名字建库并导入旧库数据
psql -U postgres -c "CREATE DATABASE new_name;"
pg_dump -U postgres old_name | psql -U postgres new_name
# 确认无误后删除旧库
psql -U postgres -c "DROP DATABASE old_name;"
```

# 总结

复制数据库有两条路径：**CREATE DATABASE ... TEMPLATE** 在同实例内整库拷贝，简单但要求源库无连接；**pg_dump \| psql** 通过逻辑转储实现跨连接、跨版本、可选择性的复制，更灵活。需要"重命名"数据库时，通常采用"新建 + 导入 + 删除旧库"的复制组合完成。
