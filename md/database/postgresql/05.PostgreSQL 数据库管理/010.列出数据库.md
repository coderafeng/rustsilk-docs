# 概述

一个 PostgreSQL **实例（cluster）** 中可以包含多个 **数据库（database）**。要查看实例中当前有哪些数据库，既可以使用 psql 的元命令 **\l**，也可以直接查询系统目录表 **pg_database**。

> 注意：数据库列表是**实例级**的，与当前连接的是哪个数据库无关——在任何一个库里执行下列操作，看到的都是同一份列表。

# 使用 \l 列出数据库

**\l**（即 **\list**）是 psql 提供的元命令，一条命令即可列出所有数据库及其关键属性：

```text
postgres=# \l
                                                   List of databases
   Name    |  Owner   | Encoding |  Collate   |   Ctype    | ICU Locale | Locale Provider|   Access privileges
-----------+----------+----------+------------+------------+------------+----------------+-----------------------
 ui        | postgres | UTF8     | en_US.utf8 | en_US.utf8 |            | libc           | =Tc/postgres +
           |          |          |            |            |            |                | postgres=CTc/postgres
 postgres  | postgres | UTF8     | en_US.utf8 | en_US.utf8 |            | libc           | =Tc/postgres +
           |          |          |            |            |            |                | postgres=CTc/postgres
 sakila    | postgres | UTF8     | en_US.utf8 | en_US.utf8 |            | libc           | =Tc/postgres +
           |          |          |            |            |            |                | postgres=CTc/postgres
 template0 | postgres | UTF8     | en_US.utf8 | en_US.utf8 |            | libc           | =Tc/postgres +
           |          |          |            |            |            |                | postgres=CTc/postgres +
           |          |          |            |            |            |                | template0 =Tc/postgres
 template1 | postgres | UTF8     | en_US.utf8 | en_US.utf8 |            | libc           | =Tc/postgres +
           |          |          |            |            |            |                | postgres=CTc/postgres +
           |          |          |            |            |            |                | template1 =Tc/postgres
(5 rows)
```

输出各列的含义：

| 列名                  | 含义                                                  |
|-----------------------|-------------------------------------------------------|
| **Name**              | 数据库名                                              |
| **Owner**             | 数据库属主（角色）                                    |
| **Encoding**          | 字符编码（推荐 **UTF8**）                             |
| **Collate**           | 字符串排序规则                                        |
| **Ctype**             | 字符分类规则（大小写、数字判断等）                    |
| **Access privileges** | 访问权限，**CTc** 分别表示 CREATE、TEMP、CONNECT 权限 |

带 **+** 号使用 **\l+**，可以额外显示每个库的大小（Size）、owner 的注释等信息：

```text
postgres=# \l+
```

## 模板数据库

列表中默认包含两个特殊数据库：

- **template1**：创建新数据库时的默认模板，`CREATE DATABASE xx` 实际就是复制 template1。
- **template0**：纯净的原始模板，不允许被连接，用于恢复或创建不同编码的数据库（见 **[复制数据库](./015.复制数据库.md)**）。

其余的都是普通业务数据库。刚安装好的实例通常还会有一个 **postgres** 库（默认维护库）和一个 **ui** 库（部分发行版附带）。

# 查询 pg_database

系统目录表 **pg_database** 保存了所有数据库的元信息，用 **SELECT** 查询它可以获得更灵活、更适合脚本处理的结果。

列出所有数据库的名称、编码和 owner：

```sql
SELECT
    datname AS database_name,
    pg_encoding_to_char(encoding) AS encoding,
    pg_get_userbyid(datdba) AS owner
FROM pg_database
ORDER BY datname;
```

执行结果如下：

```text
 database_name | encoding |  owner
---------------+----------+----------
 postgres      | UTF8     | postgres
 sakila        | UTF8     | postgres
 template0     | UTF8     | postgres
 template1     | UTF8     | postgres
 ui            | UTF8     | postgres
(5 rows)
```

说明：

- **pg_encoding_to_char(encoding)** 把编码的整数编号转成可读名称（如 UTF8）。
- **pg_get_userbyid(datdba)** 把 owner 的用户 ID 转成角色名。
- 字段 **datallowconn** 表示是否允许连接（**template0** 为 **false**）；**datconnlimit** 表示最大允许连接数（**-1** 为不限制）。

如果只想看可连接的业务库，可以过滤掉模板库：

```sql
SELECT datname
FROM pg_database
WHERE datallowconn AND datname NOT IN ('template0', 'template1')
ORDER BY datname;
```

# 命令行一步列出

不进入 psql 交互界面，也可以直接在 Shell 中用 **-l** 选项一步列出所有数据库（等价于 **\l**）：

```bash
psql -U postgres -l
# 显示详细信息
psql -U postgres -l+
```

# 总结

列出数据库有两种主要方式：psql 元命令 **\l**（详细信息用 **\l+**）适合快速查看，系统目录表 **pg_database** 配合 **SELECT** 适合精确查询和脚本处理。理解 **template0** / **template1** 两个模板库的作用，是掌握 **[复制数据库](./015.复制数据库.md)** 和创建新库的前提。
