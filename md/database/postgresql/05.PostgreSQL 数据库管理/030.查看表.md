# 概述

**查看表** 指的是检查一张表的**定义结构**：列名与数据类型、约束、索引、触发器、外键关系等。最常用的工具是 psql 元命令 **\d**，此外也可以通过查询 **information_schema** 与系统目录获得可编程的结构信息。

# 使用 \d 查看表结构

**\d 表名** 输出该表的完整结构定义：

```text
sakila=# \d film

     Column      |  Type   | Collation | Nullable |          Default
-----------------+---------+-----------+----------+---------------------------
 film_id         | integer |           | not null | nextval('film_id_seq')
 title           | text    |           | not null |
 description     | text    |           |          |
 release_year    | year    |           |          |
 language_id     | integer |           | not null |
 rental_duration | smallint|           | not null |
 rental_rate     | numeric |           | not null |
 length          | integer |           |          |
 replacement_cost| numeric |           | not null |
 rating          | rating  |           |          | 'G'
 special_features| text[]  |           |          |
 last_update     | timestam|           | not null | now()
Indexes:
    "film_pkey" PRIMARY KEY, btree (film_id)
    "film_fulltext_idx" gist (to_tsvector(...))
    "idx_fk_language_id" btree (language_id)
Foreign-key constraints:
    "film_language_id_fkey" FOREIGN KEY (language_id) REFERENCES language(language_id)
Referenced by:
    TABLE "film_actor" CONSTRAINT "film_actor_film_id_fkey" FOREIGN KEY (film_id) REFERENCES film(film_id)
    TABLE "inventory" CONSTRAINT "inventory_film_id_fkey" FOREIGN KEY (film_id) REFERENCES film(film_id)
Triggers:
    last_update BEFORE UPDATE ON film FOR EACH ROW EXECUTE FUNCTION film_last_update()
```

输出各部分含义：

| 段落                        | 内容                                                                              |
|-----------------------------|-----------------------------------------------------------------------------------|
| **Table "..."**             | 列定义：**Column** 列名、**Type** 类型、**Nullable** 是否可空、**Default** 默认值 |
| **Indexes**                 | 表上的所有索引及其方法（btree / gist / gin 等）                                   |
| **Foreign-key constraints** | 本表定义的外键                                                                    |
| **Referenced by**           | 引用本表的外键（反向关系）                                                        |
| **Triggers**                | 表上的触发器                                                                      |
| **Check constraints**       | CHECK 约束                                                                        |

## \d 的变体

| 写法          | 作用                         |
|---------------|------------------------------|
| `\d 表名`     | 表结构                       |
| `\d+ 表名`    | 附加存储参数、列注释、总大小 |
| `\d 视图名`   | 视图定义（含 SELECT 语句）   |
| `\d 序列名`   | 序列的当前值、增量等         |
| `\d 索引名`   | 索引定义                     |
| `\dS pattern` | 包含系统对象                 |
| `\dC`         | 仅列出 CAST                  |
| `\df 函数名`  | 函数签名与定义               |

列太多导致横向截断时，用 **\x** 切换到扩展显示模式，每个字段纵向展开：

```text
sakila=# \x
Expanded display is on.
sakila=# \d film
```

# 查询列定义（information_schema）

需要可编程地获取列信息时，查询标准视图 **information_schema.columns**：

```sql
SELECT
    ordinal_position AS pos,
    column_name,
    data_type,
    is_nullable,
    column_default
FROM information_schema.columns
WHERE table_schema = 'public'
  AND table_name = 'film'
ORDER BY ordinal_position;
```

```text
 pos |   column_name    |     data_type     | is_nullable |            column_default
-----+------------------+-------------------+-------------+------------------------------------
   1 | film_id          | integer           | NO          | nextval('film_id_seq'::regclass)
   2 | title            | text              | NO          |
   3 | description      | text              | YES         |
   4 | release_year     | integer           | YES         |
   5 | language_id      | integer           | NO          |
 ...
```

# 快速查看列名的技巧

只想看列名清单时，psql 提供两个便捷元命令：

- **\d 表名** 已含列信息，但输出较冗长。
- **SELECT \* FROM 表 LIMIT 0;** 配合列头，可返回一行不带头数据但列出所有列名。
- 或直接查询 **pg_attribute**：

```sql
SELECT attname
FROM pg_attribute
WHERE attrelid = 'film'::regclass
  AND attnum > 0
  AND NOT attisdropped
ORDER BY attnum;
```

其中 **attrelid = 'film'::regclass** 用 **regclass** 把表名解析为其 OID，**attnum > 0** 过滤掉系统隐藏列，**NOT attisdropped** 排除已删除列。

# 总结

查看表结构首选 psql 元命令 **\d 表名**（详细信息用 **\d+**，宽表用 **\x** 切换扩展模式），它一次性列出列、索引、约束、触发器与外键关系。需要脚本化或只取部分元数据时，改用 **information_schema.columns** 或 **pg_attribute** 查询。
