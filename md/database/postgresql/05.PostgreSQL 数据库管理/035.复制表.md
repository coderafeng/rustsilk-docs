# 概述

**复制表** 指基于已有表快速创建一个新表。根据是否需要复制**数据**、是否复制**约束/索引/默认值**，PostgreSQL 提供两类语法：

- **CREATE TABLE ... (LIKE 源表 ...)**：只复制**列定义**（结构），可选地带上默认值、约束、索引，但**不复制数据**。
- **CREATE TABLE ... AS SELECT / SELECT ... INTO**：把查询结果作为**数据**写入新表，会带列名与数据类型，但**不复制约束、索引、默认值**。

两者可以组合使用，实现"复制结构 + 复制数据"的完整需求。

# CREATE TABLE ... LIKE

**LIKE** 子句按源表的列结构创建一张空表：

```sql
CREATE TABLE new_table (LIKE source_table);
```

默认只复制列名和数据类型。通过 **INCLUDING** 选项可额外复制更多属性：

| 选项 | 额外复制的内容 |
| --- | --- |
| INCLUDING DEFAULTS | 列的默认值 |
| INCLUDING CONSTRAINTS | CHECK 约束、非空约束 |
| INCLUDING INDEXES | 索引、主键、唯一约束 |
| INCLUDING COMMENTS | 列注释与表注释 |
| INCLUDING STATISTICS | 列统计信息 |
| INCLUDING GENERATED | 生成列定义 |
| INCLUDING IDENTITY | 标识列定义 |
| INCLUDING STORAGE | 存储参数（如 TOAST 策略） |
| INCLUDING ALL | 以上全部 |

## 示例：仅复制结构

基于 **film** 表创建一张结构相同的空表 **film_backup**：

```sql
CREATE TABLE film_backup (LIKE film);
```

**film_backup** 拥有与 **film** 相同的列与类型，但没有主键、没有索引、没有数据。

## 示例：复制结构 + 全部约束与索引

```sql
CREATE TABLE film_full (LIKE film INCLUDING ALL);
```

**film_full** 会带上 **film** 的列、默认值、主键、索引、约束、注释等（仍不含数据）。

> 注意：**LIKE** 复制的是"定义快照"，复制完成后两表互不影响——给源表加列不会自动同步到已创建的副本。

# CREATE TABLE ... AS SELECT（复制数据）

**CTAS** 把一条 **SELECT** 的结果写入新建的表，**会复制数据**，但**不复制**主键、索引、默认值、约束：

```sql
CREATE TABLE film_action AS
SELECT * FROM film
WHERE rating = 'PG-13';
```

执行后 **film_action** 拥有与查询结果相同的列与数据行，但没有主键等约束。可用 **[查看表](./030.查看表.md)** 的 **\d film_action** 验证：列在、数据在，但 **Indexes** 为空。

# SELECT ... INTO（等价于 CTAS）

在 psql / PL/pgSQL 中，**SELECT INTO** 与 CTAS 效果相同，都是"查询结果建新表并灌入数据"：

```sql
SELECT * INTO film_action_copy
FROM film
WHERE rating = 'PG-13';
```

> 提醒：**SELECT INTO** 与游标场景含义不同（在某些客户端里 INTO 表示取到变量）。在纯 SQL 建表用途上，它与 CTAS 等价，官方更推荐显式的 **CREATE TABLE ... AS**。（另见 [SELECT INTO](../03.PostgreSQL%20数据库和表/110.SELECT%20INTO.md)）

# 完整复制：结构 + 数据

若要同时复制结构（含约束索引）和数据，组合使用两步：

```sql
-- 1. 复制结构（含全部属性）
CREATE TABLE film_copy (LIKE film INCLUDING ALL);
-- 2. 复制数据
INSERT INTO film_copy SELECT * FROM film;
```

或者数据量大时直接用 CTAS 再补建约束：

```sql
CREATE TABLE film_copy AS SELECT * FROM film;
ALTER TABLE film_copy ADD PRIMARY KEY (film_id);
-- 按需再补 CREATE INDEX / 默认值 ...
```

方式对比：

| 需求 | 推荐语法 | 复制数据 | 复制约束/索引/默认值 |
| --- | --- | --- | --- |
| 只要空结构 | `CREATE TABLE (LIKE)` | 否 | 看 INCLUDING 选项 |
| 只要数据快照 | `CREATE TABLE AS SELECT` | 是 | 否 |
| 结构 + 数据 | 两者组合 | 是 | 是 |

# 总结

复制表有两个互补的工具：**CREATE TABLE ... (LIKE ...)** 复制结构（用 **INCLUDING ALL** 带全约束、索引、默认值，但不带数据），**CREATE TABLE ... AS SELECT**（或 **SELECT INTO**）复制数据但不带约束。需要"原样连数据一起复制"时，把 LIKE 建表与 INSERT SELECT（或 CTAS 后补约束）组合使用即可。
