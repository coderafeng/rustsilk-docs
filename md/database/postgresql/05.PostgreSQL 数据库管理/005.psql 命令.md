# 概述

**psql** 是 PostgreSQL 自带的命令行客户端，是我们与管理数据库实例交互的主要入口。它既能执行 SQL 语句，也提供大量以反斜杠 **\\** 开头的 **元命令（meta-command）** 来快速查看数据库对象。

本教程后续所有管理操作，绝大多数都在 **psql** 中进行，因此先掌握它的连接方式与常用选项至关重要。

# psql 语法

启动 psql 并连接到数据库的基本语法如下（在操作系统 Shell 中执行）：

```bash
psql -h 主机 -p 端口 -U 用户名 -d 数据库名
```

常用选项说明：

| 选项   | 长选项               | 说明                                            | 默认值                     |
|--------|----------------------|-------------------------------------------------|----------------------------|
| **-h** | --host               | 数据库服务器主机名或 IP                         | 本地（localhost / 套接字） |
| **-p** | --port               | 服务器监听端口                                  | 5432                       |
| **-U** | --username           | 登录的用户名（角色）                            | 当前操作系统用户名         |
| **-d** | --dbname             | 要连接的目标数据库                              | 与用户名同名               |
| **-W** | --password           | 强制提示输入密码                                | 不强制                     |
| **-c** | --command            | 执行一条 SQL 或元命令后退出                     | —                          |
| **-f** | --file               | 执行指定 SQL 脚本文件后退出                     | —                          |
| **-l** | --list               | 列出所有数据库后退出（等价于元命令 **\l**）     | —                          |
| **-1** | --single-transaction | 把 **-c** / **-f** 的所有语句放在一个事务中执行 | —                          |

> 说明：连接参数也可以写成 **conninfo** 连接串形式，例如 `psql "host=localhost port=5432 dbname=sakila user=postgres"`。此外，PostgreSQL 会读取 **PGHOST**、**PGPORT**、**PGUSER**、**PGDATABASE**、**PGPASSWORD** 等环境变量作为各选项的默认值。

# 连接示例

连接到本机默认端口上的 **postgres** 数据库，使用 **postgres** 用户：

```bash
psql -h localhost -p 5432 -U postgres -d postgres
```

输入密码后，看到提示符即表示连接成功：

```text
psql (18.0)
Type "help" for help.

postgres=#
```

提示符含义：`数据库名=#`（超级用户）或 `数据库名=>`（普通用户）。

只执行一条命令并立即退出，例如查看所有数据库：

```bash
psql -U postgres -c "SELECT datname FROM pg_database;"
```

执行一个 SQL 脚本文件：

```bash
psql -U postgres -d sakila -f init.sql
```

# 常用元命令

进入 psql 交互界面后，可以使用元命令。下表是最常用的几个：

| 元命令              | 作用                                            |
|---------------------|-------------------------------------------------|
| **\conninfo**       | 显示当前连接信息（用户、数据库、主机、端口）    |
| **\l** 或 **\list** | 列出所有数据库                                  |
| **\dt**             | 列出当前数据库中的所有表                        |
| **\d 表名**         | 查看表（或视图、序列）的详细结构                |
| **\du**             | 列出所有角色（用户）                            |
| **\dn**             | 列出所有架构（schema）                          |
| **\c 数据库名**     | 连接到另一个数据库                              |
| **\password 用户**  | 修改指定用户的密码                              |
| **\i 文件名**       | 执行本地 SQL 文件                               |
| **\q**              | 退出 psql                                       |
| **\? / \h**         | **\?** 查看元命令帮助，**\h** 查看 SQL 命令帮助 |

查看当前连接信息：

```text
postgres=# \conninfo
You are connected to database "postgres" as user "postgres" on host "localhost" at port "5432".
```

切换到 **sakila** 数据库：

```text
postgres=# \c sakila
You are now connected to database "sakila" as user "postgres".
sakila=#
```

# 输出与编辑控制

| 元命令 | 作用 |
| --- | --- |
| **\pset pager off** | 关闭分页器，结果一次性全部输出（便于复制） |
| **\x** | 切换扩展显示模式，字段纵向排列，适合列很多的表 |
| **\timing** | 打开/关闭每条语句执行耗时统计 |
| **\e** | 用编辑器打开查询缓冲区 |
| **\g** | 执行当前缓冲区内容 |
| **\qecho** | 向输出重定向文件写入文本 |

当某条查询返回很多行、屏幕被分页器截断时，可用 **\pset pager off** 关闭分页：

```text
sakila=# \pset pager off
Pager usage is off.
```

# 总结

**psql** 是 PostgreSQL 的核心命令行客户端。使用 **psql -h -p -U -d** 连接数据库，用 **-c** / **-f** 执行单条命令或脚本，用 **\conninfo**、**\l**、**\dt**、**\d**、**\c**、**\password** 等元命令快速查看和管理数据库对象。熟练使用 psql 是进行后续一切数据库管理操作的前提。
