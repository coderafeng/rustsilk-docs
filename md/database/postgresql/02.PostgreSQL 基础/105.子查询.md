# 概述

通常情况下，我们会使用子查询构建更复杂的 SQL 语句。比如，您可以将子查询使用在 **[EXISTS](./060.EXISTS%20是否存在.md#概述)**, **[IN](./040.IN%20值列表是否包含指定值.md#概述)**, **[ANY](./070.ANY%20一组值至少存在一个值.md#概述)**, **[ALL](./065.ALL%20一个值与一组值比较.md#概述)** 等表达式中，也可以将子查询的结果直接和值比较。

# EXISTS 运算符中使用子查询

**EXISTS** 运算符需要一个子查询作为操作数，以检查此子查询是否返回行。

比如，要从 Sakila 数据库中的 **[language](../01.PostgreSQL%20起步/04.PostgreSQL%20示例数据库.md#语言表)** 表查找那些在 **[film](../01.PostgreSQL%20起步/04.PostgreSQL%20示例数据库.md#影片表)** 表中用到的语言，您可以使用如下语句：

```sql
SELECT *
FROM language
WHERE EXISTS(
    SELECT *
    FROM film
    WHERE film.language_id = language.language_id
  );
```

执行结果如下：

```text
 language_id |         name         |     last_update
-------------+----------------------+---------------------
           1 | English              | 2006-02-15 05:02:19
(1 row)
```

在上面的语句中，下面的查询就是一个子查询：

```sql
SELECT *
FROM film
WHERE film.language_id = language.language_id
```

# IN 运算符中使用子查询

PostgreSQL **IN** 运算符也需要一个集合作为操作数，因此您也可以使用 子查询 作为 **IN** 运算符右侧的操作数。

比如，您可以使用如下带有 **IN** 运算符和子查询的语句达到上面的目的：

```sql
SELECT *
FROM language
WHERE language_id in(
    SELECT DISTINCT language_id
    FROM film
  );
```

执行结果如下：

```text
 language_id |         name         |     last_update
-------------+----------------------+---------------------
           1 | English              | 2006-02-15 05:02:19
(1 row)
```

这里，下面的语句就是一个子查询，以查询出所有的影片用到的 **language_id**:

```sql
SELECT DISTINCT language_id
FROM film
```

# 子查询直接和值进行比较

比如，要计算租金高于平均租金的影片的数量，您可以使用一下语句实现：

```sql
SELECT count(*)
FROM film
WHERE rental_rate > (
    SELECT avg(rental_rate)
    FROM film
  );
```

执行结果如下：

```text
 count
-------
   659
```

这里，我们使用了下面的子查询计算影片的平均租金：

```sql
SELECT avg(rental_rate)
FROM film
```

然后，将租金 **rental_rate** 和上面子查询的结果进行比较，从而得到租金比平均租金大的影片的数量。

# 总结

PostgreSQL 子查询可以帮助您构建更复杂的 SQL 语句。
