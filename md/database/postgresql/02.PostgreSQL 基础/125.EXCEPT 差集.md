# 概述

在 PostgreSQL 中， **EXCEPT** 是一个集合运算符，它用于从一个集合中减去出现在另外一个集合中的行。

其他的集合操作运算符还有： **[UNION](./115.UNION%20并集.md#概述)** 和 **[INTERSECT](./120.INTERSECT%20交集.md#概述)**。

# EXCEPT 语法

要从一个结果集中减去另一个结果集，请按照以下语法使用 **EXCEPT** 运算符：

```sql
SELECT_statement_1
EXCEPT
SELECT_statement_2
[ORDER BY ...];
```

或者您可以减去多个结果集，如下：

```sql
SELECT_statement_1
EXCEPT
SELECT_statement_2
EXCEPT
SELECT_statement_3
EXCEPT
...
[ORDER BY ...];
```

- **SELECT_statement_N** 都是个独立 **SELECT** 语句。
- 参与 **EXCEPT** 运算的所有的结果集应该具有相同的列，并且列的数据类型和顺序应该相同。
- **[ORDER BY](./010.ORDER%20BY%20排序.md#概述)** 子句用于对最终结果进行排序，它是可选的。

比如，下面的语句：

```sql
SELECT generate_series(1, 5)
EXCEPT
SELECT generate_series(3, 6);
```

执行结果如下：

```text
 generate_series
-----------------
               1
               2
```

这里， **[generate_series()](../07.PostgreSQL%20内置函数/040.集合函数.md#generate_series)** 函数用来生成结果集。

先看一下第一个结果集：

```sql
SELECT generate_series(1, 5);
```

执行结果如下：

```text
 generate_series
-----------------
               1
               2
               3
               4
               5
```

再看一下第二个结果集：

```sql
SELECT generate_series(3, 6);
```

执行结果如下：

```text
 generate_series
-----------------
               3
               4
               5
               6
```

**EXCEPT** 运算符从第一个结果集中的所有的行中删除同时位于第二个结果集中的行，并返回了第一个结果集中剩下的行。

# 总结

PostgreSQL **EXCEPT** 是一个集合运算符，它用于从一个集合中减去出现在另外一个集合中的行。 其他的集合操作运算符还有： **UNION** 和 **INTERSECT**。
