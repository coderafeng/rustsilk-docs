9.2 在**垂直扩展能力**和**NoSQL 支持**上迈出了一大步，原生 JSON 支持开始萌芽。

- **原生 JSON 支持：** 查询结果可以直接以 JSON 数据类型返回，标志着 PostgreSQL 开始拥抱半结构化数据 [^1] [^2]。
- **范围类型 (Range Types)：** 引入了 Range Types，用于智能处理时间段和数值块，是日历、金融应用的基础 [^1]。
- **性能大幅提升：** 通过**仅索引扫描**（Index-Only Scans）优化数据仓库查询，速度提升 **2-20 倍**；线性扩展能力提升至 64 核，读取性能提升 **4 倍以上** [^1] [^2]。
- **级联复制：** 支持级联复制，构建更大规模的复制集群 [^1]。
