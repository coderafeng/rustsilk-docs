# 概述

PostgreSQL 提供了丰富的原生数据类型。

每种数据类型都有一种由其输入和输出函数决定的外部表示。 许多内置类型的外部格式都很直观。不过，也有一些类型是 PostgreSQL所特有的，例如几何路径； 还有一些类型可能存在多种可能的格式，例如日期/时间类型。 有些输入和输出函数并不可逆，也就是说，输出函数的结果与原始 输入相比可能会丢失精度。

| 名字 | 别名 | 描述 | Java对应类型 | Rust对应类型 |

| `bytea` |  | 二进制数据（“字节数组”） | `byte[]` | `Vec<u8>` / `&[u8]` |

| `uuid` |  | 通用唯一标识符 | `java.util.UUID` | `uuid::Uuid` |
| `xml` |  | XML 数据 | `String` / `javax.xml.transform.Source` | `String` |

**说明：**
- **Java**：映射基于 PostgreSQL JDBC 驱动标准类型；几何类型使用 `org.postgresql.geometric` 包，网络类型使用 `org.postgresql.net` 包，JSONB 需借助 Jackson 或 Hibernate 等框架序列化为 POJO。
- **Rust**：映射基于 `sqlx`、`postgres-types`、`rust-postgres` 等主流 crate；时间类型需搭配 `chrono` feature，网络类型需搭配 `postgres-inet`，UUID 需搭配 `uuid` crate，位串需搭配 `bit-vec`。
- 部分类型（如 `cidr`、`inet`、`macaddr`）在 JDBC 中无原生对应类型，通常以 `String` 或自定义 `PGobject` 子类处理；Rust 中则依赖第三方 crate 或自定义结构体。
- 实际映射可能因驱动程序版本和框架有所不同，建议以项目所用技术栈的官方文档为准。
