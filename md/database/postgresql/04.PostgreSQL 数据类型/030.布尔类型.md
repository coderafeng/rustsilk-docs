# 概述

核心结论

- PostgreSQL 提供标准 SQL 类型 **`boolean`**，别名 **`bool`**。
- `boolean` 有 **3 种状态**：
    - **true**：真
    - **false**：假
    - **unknown**：未知，用 SQL **`NULL`** 表示
- 存储空间：**1 字节**。
- SQL 查询中布尔常量写作 **`TRUE`、`FALSE`、`NULL`**。
- **`WHERE` 条件只保留结果为 `TRUE` 的行**。
- **`NULL` 不是 `FALSE`，也不是 `TRUE`**——这是三值逻辑最大的坑。
- 如果业务不需要“未知”状态，建议加 **`NOT NULL DEFAULT FALSE`**。

> [!warning]
> 布尔列默认可为 `NULL` 时，`WHERE flag` 会同时过滤掉 `false` 和 `null` 两种行，容易与业务预期不符。明确状态语义时优先 `NOT NULL DEFAULT FALSE`。

# 类型速查

| 名字	    | 别名	 | 存储	   | 描述                 |
|---------|------|--------|----------------------|
| boolean | bool | 1 字节 | 真、假或未知（NULL） |

示例：

```sql
CREATE TABLE demo
(
    flag  boolean,
    flag2 bool
);
```

# 布尔值表示

## SQL 常量

```sql
TRUE
FALSE
NULL
```

说明：

- TRUE 和 FALSE 会被语法分析器自动识别为 boolean 类型。
- NULL 不会自动识别为 boolean，因为它可以是任意类型。
- 必要时显式转换：
  ```sql
  SELECT NULL::boolean;
  ```

## 输入规则

boolean 输入函数接受以下表示“真”的字符串：

```text
true
yes
on
1
```

以及以下表示“假”状态的字符串：

```text
false
no
off
0
```

规则：

- 这些字符串的唯一前缀也可以接受，例如 t、n。
- 前导和尾随空白会被忽略。
- 大小写不敏感。
- 推荐使用完整写法，避免歧义。

示例：

```sql
SELECT 'true'::boolean; -- t
SELECT 'yes'::boolean; -- t
SELECT 'on'::boolean; -- t
SELECT '1'::boolean; -- t

SELECT 'false'::boolean; -- f
SELECT 'no'::boolean; -- f
SELECT 'off'::boolean; -- f
SELECT '0'::boolean; -- f
```

注意：

- 'o'::boolean 可能失败，因为 on 和 off 都以 o 开头，不是唯一前缀。
- 不要依赖缩写前缀，业务代码中写完整值更安全。

# 使用boolean类型

```sql
CREATE TABLE test1
(
    a boolean,
    b text
);
INSERT INTO test1
VALUES (TRUE, 'sic est');
INSERT INTO test1
VALUES (FALSE, 'non est');
SELECT *
FROM test1;
```

## 输出规则

- 非 NULL 的 boolean 值输出函数总是产生 t 或 f。
- 在 psql 中，NULL 通常显示为空。
- 不要把 t / f 当作业务文本直接展示给用户。

示例：

```sql
SELECT TRUE; -- t
SELECT FALSE; -- f
SELECT NULL::boolean; -- 空
```

# 三值逻辑：boolean

SQL 的 NULL 表示 unknown，因此 boolean 不是简单的二值逻辑，而是三值逻辑。

## AND 真值表

| AND   | TRUE  | FALSE | NULL  |
|-------|-------|-------|-------|
| TRUE	  | TRUE	  | FALSE | NULL  |
| FALSE | FALSE | FALSE | FALSE |
| NULL	  | NULL	  | FALSE | NULL  |

## OR 真值表

| OR    | TRUE | FALSE | NULL |
|-------|------|-------|------|
| TRUE	  | TRUE	 | TRUE	  | TRUE |
| FALSE | TRUE	 | FALSE | NULL |
| NULL	  | TRUE	 | NULL	  | NULL |

## NOT 真值表

| NOT   | 结果  |
|-------|-------|
| TRUE	  | FALSE |
| FALSE | TRUE  |
| NULL	  | NULL  |

## WHERE 只保留 TRUE

这是最容易踩坑的地方：

```sql
SELECT *
FROM test1
WHERE a;
```

等价于：

```sql
SELECT *
FROM test1
WHERE a IS TRUE;
```

它只返回 a 为 TRUE 的行。FALSE 和 NULL 都不会被返回。

# 建表与基础使用

```sql
CREATE TABLE test1
(
    a boolean,
    b text
);

INSERT INTO test1
VALUES (TRUE, 'sic est');
INSERT INTO test1
VALUES (FALSE, 'non est');
INSERT INTO test1
VALUES (NULL, 'unknown');

SELECT *
FROM test1;
```

输出示例：

```text
 a |    b
---+---------
 t | sic est
 f | non est
   | unknown
```

查询：

```sql
-- 只返回 a 为 TRUE 的行
SELECT *
FROM test1
WHERE a;

-- 只返回 a 为 FALSE 的行；NULL 不会返回
SELECT *
FROM test1
WHERE NOT a;

-- 只返回 a 为 NULL 的行
SELECT *
FROM test1
WHERE a IS NULL;
```

# 查询布尔列的推荐写法

| 目的   | 推荐写法                   | 说明               |
|--------|----------------------------|--------------------|
| 为真   | WHERE a 或 WHERE a IS TRUE | 只匹配 TRUE        |
| 为假   | WHERE a IS FALSE           | 只匹配 FALSE       |
| 为未知 | WHERE a IS NULL            | 只匹配 NULL        |
| 非真   | WHERE a IS NOT TRUE        | 匹配 FALSE 和 NULL |
| 非假   | WHERE a IS NOT FALSE       | 匹配 TRUE 和 NULL  |
| 非空   | WHERE a IS NOT NULL        | 匹配 TRUE 和 FALSE |

示例：

```sql
SELECT *
FROM test1
WHERE a IS TRUE;
SELECT *
FROM test1
WHERE a IS FALSE;
SELECT *
FROM test1
WHERE a IS NULL;
SELECT *
FROM test1
WHERE a IS NOT TRUE;
SELECT *
FROM test1
WHERE a IS NOT FALSE;
```

避免：

```sql
-- 永远不返回 TRUE
SELECT *
FROM test1
WHERE a = NULL;

-- 不返回 NULL 行
SELECT *
FROM test1
WHERE a <> TRUE;
```

# 类型转换

字符串字面量在上下文中可以被推断为 boolean：

```sql
SELECT 'yes'::boolean; -- t
SELECT 'no'::boolean; -- f
```

显式转换 NULL：

```sql
SELECT NULL::boolean;
```

如果语法分析器能判定字符串一定是 boolean，也可以省略转换，但推荐显式写法。

```sql
-- 可读性更好
SELECT 'yes'::boolean;

-- 依赖上下文推断，不推荐
SELECT 'yes';
```

# 最佳实践

1. 使用 TRUE / FALSE 常量

- 不要用 1 / 0 或 'yes' / 'no' 作为业务常量。

2. 区分“二值”和“三态”

- 只需要真/假：boolean NOT NULL DEFAULT FALSE
- 需要未知：允许 NULL

3. 查询 NULL 用 IS NULL

- 不要写 = NULL。

4. 明确表达业务意图

- WHERE a 只匹配 TRUE。
- 如果想匹配 FALSE 和 NULL，应该写 WHERE a IS NOT TRUE。

5. 布尔列索引要谨慎

- 普通 B-tree 索引对低选择性布尔列通常效果有限。
- 如果有大量查询只查 WHERE is_active，可以考虑部分索引：
  ```sql
  CREATE INDEX idx_active ON users (id) WHERE is_active;
  ```

6. 聚合时注意 NULL

- bool_and ()：所有非 NULL 值都为 TRUE 时返回 TRUE。
- bool_or ()：任一非 NULL 值为 TRUE 时返回 TRUE。
- every () 是 bool_and () 的别名。
- 它们通常忽略 NULL。

  ```sql
  SELECT bool_and(done), bool_or(done)
  FROM task;
  ```

# 常见踩坑清单

1. WHERE a 不返回 NULL 行。 
2. WHERE NOT a 不返回 NULL 行。 
3. a = NULL 永远不返回 TRUE，应该用 a IS NULL。 
4. a <> TRUE 不返回 NULL 行。 
5. NULL 不是 FALSE。
6. 'o'::boolean 可能失败，因为 on / off 歧义。 
7. 输出是 t / f，不是 true / false。 
8. COUNT(a) 不统计 NULL。 
9. boolean 列默认允许 NULL，不写 NOT NULL 就是三态。 
10. 不要把布尔值存成 varchar 或 int，除非有明确理由。

# 速查 SQL

```sql
-- 建表：二值布尔
CREATE TABLE task (
    id serial PRIMARY KEY,
    title text NOT NULL,
    done boolean NOT NULL DEFAULT FALSE
);

-- 建表：三态布尔
CREATE TABLE task2 (
    id serial PRIMARY KEY,
    title text NOT NULL,
    reviewed boolean
);

-- 插入
INSERT INTO task (title, done) VALUES
('写文档', TRUE),
('改 bug', FALSE);

INSERT INTO task2 (title, reviewed) VALUES
('写文档', NULL),
('改 bug', TRUE),
('发版本', FALSE);

-- 查询 TRUE
SELECT * FROM task WHERE done;
SELECT * FROM task WHERE done IS TRUE;

-- 查询 FALSE
SELECT * FROM task WHERE done IS FALSE;

-- 查询 NULL
SELECT * FROM task2 WHERE reviewed IS NULL;

-- 查询非 TRUE，包括 FALSE 和 NULL
SELECT * FROM task2 WHERE reviewed IS NOT TRUE;

-- 转换
SELECT 'yes'::boolean, 'no'::boolean, NULL::boolean;

-- 聚合
SELECT bool_and(done) AS all_done,
       bool_or(done) AS any_done
FROM task;
```

# 总结

boolean 看起来简单，但它有 TRUE、FALSE、NULL 三种状态；NULL 表示未知，不是假。查询时优先使用 IS TRUE、IS FALSE、IS NULL 明确表达意图，避免三值逻辑带来的意外结果。
