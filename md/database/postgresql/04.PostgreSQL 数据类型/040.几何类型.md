# 概述

- PostgreSQL 内置几何类型用于表示二维空间物体。
- 坐标统一使用 double precision（float8）存储。
- 常用类型：point、line、lseg、box、path、polygon、circle。
- 提供丰富的函数和操作符，支持缩放、平移、旋转、求交、距离等操作。
- 输入语法灵活，输出会规范化。
- 适合简单二维几何、教学、轻量空间查询。
- 复杂 GIS 需求（地图、经纬度、投影、SRID、球面计算）应使用 PostGIS。

# 类型速查表

| 名字    | 存储       | 描述                     | 表示                    | 备注                         |
|---------|------------|--------------------------|-------------------------|------------------------------|
| point   | 16字节     | 平面上的点               | (x,y)                   | 几何基础构造块               |
| line    | 24字节     | 无限直线                 | {A,B,C}                 | 方程 Ax + By + C = 0         |
| lseg    | 32字节     | 有限线段                 | [(x1,y1),(x2,y2)]       | 两点确定                     |
| box     | 32字节     | 矩形框                   | (x1,y1),(x2,y2)         | 存储为右上角和左下角         |
| path    | 16+16n字节 | 封闭路径（类似于多边形） | ((x1,y1),...)           | 方括号开放，圆括号封闭       |
| path    | 16+16n字节 | 开放路径                 | [(x1,y1),...]           | 方括号开放，圆括号封闭       |
| polygon | 40+16n字节 | 多边形（类似于封闭路径） | ((x1,y1),...)           | 包含内部区域，存储最小包围框 |
| circle  | 24字节     | 圆                       | <(x,y),r>（圆心和半径） | 圆心和半径                   |

说明：

- n 表示点或顶点的数量。
- 单个坐标以 double precision 存储。
- 输出格式可能与输入格式不同，PostgreSQL 会规范化。

# 坐标与精度

- 坐标类型是 double precision，即 float8。
- 浮点数存在精度误差。
- 不要直接用 = 比较两个几何坐标或计算结果。
- 比较距离时，建议使用容差或距离操作符。

示例：

```sql
SELECT '(1.0, 2.0)'::point;
```

# 各类型详解

## 点

表示平面上的一个点。

输入语法：

```sql
( x , y)
x , y
```

输出语法：

```text
(x,y)
```

示例：

```sql
SELECT '(1,2)'::point;
-- (1,2)

SELECT point(1, 2);
-- (1,2)
```

用途：

- 表示位置。
- 作为其他几何类型的基础。
- 常用于距离计算

## 无限直线

表示一条无限延伸的直线。

方程：

```text
Ax + By + C = 0
```

其中 A 和 B 不能同时为 0。

标准输入输出：

```sql
{ A, B, C }
```

其它输入形式：

```sql
[ ( x1 , y1 ) , ( x2 , y2 ) ]
( ( x1 , y1 ) , ( x2 , y2 ) )
  ( x1 , y1 ) , ( x2 , y2 )
    x1 , y1   ,   x2 , y2
```

其中 (x1,y1) 和 (x2,y2) 是直线上的两个不同点。

示例：

```sql
SELECT '{1,-1,0}'::line;
-- {1,-1,0}

SELECT '[(0,0),(1,1)]'::line;
-- {1,-1,0}
```

注意：

- line 是无限直线，不是线段。
- 表示线段应使用 lseg。

## 线段

表示两个端点之间的有限线段。

输入语法：

```sql
[ ( x1 , y1 ) , ( x2 , y2 ) ]
( ( x1 , y1 ) , ( x2 , y2 ) )
  ( x1 , y1 ) , ( x2 , y2 )
    x1 , y1   ,   x2 , y2
```

输出语法：

```sql
[(x1,y1),(x2,y2)]
```

示例：

```sql
SELECT '[(0,0),(1,1)]'::lseg;
-- [(0,0),(1,1)]
```

用途：

- 表示有限长度的线段。
- 可计算长度、交点等。

## 矩形框

用两个对角点表示矩形。

```sql
( ( x1 , y1 ) , ( x2 , y2))
( x1 , y1 ) , ( x2 , y2 )
    x1 , y1   ,   x2 , y2
```

输出语法：

```sql
(x1,y1)
,(x2,y2)
```

规则：

- 输入时可以给任意两个对角点。
- 存储时会重新排列为右上角和左下角。
- 输出顺序固定为右上角、左下角。

示例：

```sql
SELECT '((0,0),(1,1))'::box;
-- (1,1),(0,0)
```

用途：

- 表示矩形范围。
- 可用于边界框、区域查询。

## 路径

表示一系列连接的点。

路径有两种：

- 开放路径：第一个点和最后一个点不连接。
- 封闭路径：第一个点和最后一个点连接。

输入语法：

```sql
[ ( x1 , y1 ) , ... , ( xn , yn ) ]
( ( x1 , y1 ) , ... , ( xn , yn ) )
  ( x1 , y1 ) , ... , ( xn , yn )
  ( x1 , y1   , ... ,   xn , yn )
    x1 , y1   , ... ,   xn , yn
```

规则：

- 方括号 [] 表示开放路径。
- 圆括号 () 表示封闭路径。
- 当最外层圆括号被省略时，路径假定为封闭。
- 输出时视情况使用第一种或第二种语法。

示例：

```sql
-- 开放路径
SELECT '[(0,0),(1,0),(1,1)]'::path;
-- [(0,0),(1,0),(1,1)]

-- 封闭路径
SELECT '((0,0),(1,0),(1,1))'::path;
-- ((0,0),(1,0),(1,1))
```

注意：

- path 不包含内部区域。
- 封闭路径只是首尾相连，不表示实心区域。

## 多边形

由顶点列表表示的多边形。

与封闭路径类似，但语义不同：

- polygon 被认为包含其内部区域。
- path 不包含内部区域。

输入语法：

```sql
( ( x1 , y1 ) ,..., ( xn , yn))
( x1 , y1 ) , ... , ( xn , yn )
  ( x1 , y1   , ... ,   xn , yn )
    x1 , y1   , ... ,   xn , yn
```

输出语法：

```sql
((x1,y1),...)
```

示例：

```sql
SELECT '((0,0),(1,0),(1,1),(0,1))'::polygon;
-- ((0,0),(1,0),(1,1),(0,1))
```

实现细节：

- 多边形存储中包含其最小包围框。
- 最小包围框可以加快某些搜索操作。
- 构造新多边形时，计算包围框会带来额外开销。

用途：

- 表示区域、地块、多边形范围。
- 可计算面积、中心、包含关系等。

## 圆

由圆心和半径表示。

输入语法：

```sql
< ( x , y ) , r >
( ( x , y ) , r )
  ( x , y ) , r
    x , y   , r
```

输出语法：

```sql
<(x,y),r>
```

示例：

```sql
SELECT '<(0,0),5>'::circle;
-- <(0,0),5>
```

用途：

- 表示圆形区域。
- 可计算面积、直径、半径、中心等。

# 输入输出规范总结

| 类型    | 常见输入           | 输出形式                    |
|---------|--------------------|-----------------------------|
| point   | (x,y) 或 x,y       | (x,y)                       |
| line    | {A,B,C} 或两点形式 | {A,B,C}                     |
| lseg    | 两点形式           | [(x1,y1),(x2,y2)]           |
| box     | 对角点形式         | (x1,y1),(x2,y2)，右上、左下 |
| path    | [] 开放，() 封闭   | [] 或 ()                    |
| polygon | 顶点列表           | ((x1,y1),...)               |
| circle  | < (x,y),r > 等     | <(x,y),r>                   |

注意：

- 几何字面量通常需要单引号。
- 可以显式类型转换：
```sql
SELECT '(1,2)'::point;
SELECT '((0,0),(1,1))'::box;
```

# 常用操作符与函数（了解）

PostgreSQL 为几何类型提供了许多操作符和函数。

常见操作符：

| 操作符 | 含义         |
|--------|--------------|
| +      | 平移         |
| -      | 平移         |
| *      | 缩放、旋转等 |
| /      | 缩放         |
| <->    | 距离         |
| &&     | 重叠         |
| @>     | 包含         |
| <@     | 被包含       |
| ~=     | 相同         |
| ?#     | 相交         |

常见函数：

| 函数       | 作用                                 |
|------------|--------------------------------------|
| area()     | 面积，适用于 box、circle、polygon 等 |
| center()   | 中心点                               |
| diameter() | 直径，适用于 circle                  |
| height()   | 高度，适用于 box                     |
| width()    | 宽度，适用于 box                     |
| length()   | 长度，适用于 lseg、path 等           |
| npoints()  | 点数，适用于 path、polygon           |
| isclosed() | 路径是否封闭                         |
| isopen()   | 路径是否开放                         |
| pclose()   | 转为封闭路径                         |
| popen()    | 转为开放路径                         |
| radius()   | 半径，适用于 circle                  |

示例：

```sql
SELECT area('((0,0),(1,0),(1,1),(0,1))'::polygon);
SELECT center('<(0,0),5>'::circle);
SELECT radius('<(0,0),5>'::circle);
SELECT length('[(0,0),(3,4)]'::lseg);
```

具体行为以 PostgreSQL 官方文档为准。

# 与 PostGIS 的区别

PostgreSQL 内置几何类型：

- 简单二维几何。
- 坐标是普通 double precision。
- 不包含 SRID、投影、地理坐标系。
- 不支持球面距离、复杂空间分析。
- 适合轻量、教学、简单二维场景。

PostGIS：

- 提供 geometry、geography 类型。
- 支持 SRID、投影、经纬度、球面计算。
- 支持复杂空间函数、空间索引、栅格等。
- 适合地图、GIS、位置服务、空间分析。

选择建议：

- 简单二维几何：用 PostgreSQL 内置类型。
- 真实地理空间：用 PostGIS。

# 最佳实践

1. 选对类型
  - 点用 point。
  - 线段用 lseg。
  - 无限直线用 line。
  - 矩形用 box。
  - 开放/封闭折线用 path。
  - 区域用 polygon。
  - 圆用 circle。
2. 不要混淆 line 和 lseg
  - line 是无限直线。
  - lseg 是有限线段。
3. 注意 box 输出顺序
  - 输入任意对角，输出固定为右上、左下。
4. 区分 path 和 polygon
  - 封闭 path 不表示实心区域。
  - polygon 表示包含内部区域。
5. 浮点比较用容差
  - 避免直接 = 比较坐标。
6. 大量空间查询考虑索引
  - 内置几何类型可以建 GiST 索引。
  - 示例：
    ```sql
    CREATE INDEX idx_shapes_p ON shapes USING gist (p);
    ```
7. 复杂 GIS 用 PostGIS
  - 需要 SRID、投影、经纬度、球面距离时，不要用内置几何类型硬做。
8. 使用标准输入形式
  - 可读性更好，也更容易跨版本兼容。

# 常见踩坑

1. line 是无限直线，不是线段。
2. box 输入顺序不重要，输出顺序会重排。
3. path 省略最外层括号时，默认按封闭路径处理。
4. polygon 包含内部区域，path 不包含。
5. polygon 构造时会计算最小包围框，有额外开销。
6. 坐标是 double precision，有浮点误差。
7. 几何类型没有 SRID 和投影。 
8. 输出格式可能和输入格式不同。
9. 跨类型比较不一定支持，必要时显式转换。
10. 复杂地理计算不要用内置几何类型代替 PostGIS。

# 速查 SQL

```sql
-- 类型转换
SELECT '(1,2)'::point;
SELECT '{1,-1,0}'::line;
SELECT '[(0,0),(1,1)]'::lseg;
SELECT '((0,0),(1,1))'::box;
SELECT '[(0,0),(1,0),(1,1)]'::path;       -- 开放路径
SELECT '((0,0),(1,0),(1,1))'::path;       -- 封闭路径
SELECT '((0,0),(1,0),(1,1),(0,1))'::polygon;
SELECT '<(0,0),5>'::circle;

-- 建表
CREATE TABLE shapes (
    id serial PRIMARY KEY,
    p point,
    b box,
    c circle
);

-- 插入
INSERT INTO shapes (p, b, c)
VALUES ('(1,2)', '((0,0),(1,1))', '<(0,0),5>');

-- 查询
SELECT * FROM shapes;

-- 距离
SELECT * FROM shapes
WHERE p <-> '(3,4)'::point < 10;

-- 函数
SELECT area(b), center(b), width(b), height(b) FROM shapes;
SELECT area(c), radius(c), center(c) FROM shapes;

-- GiST 索引
CREATE INDEX idx_shapes_p ON shapes USING gist (p);
```

# 总结

PostgreSQL 内置几何类型适合表示简单二维点、线、框、路径、多边形和圆；输入灵活、输出规范，但不支持 SRID、投影和复杂 GIS 分析。简单二维场景可直接使用，真实地理空间场景应交给 PostGIS。
