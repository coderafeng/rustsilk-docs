# 概述

- PostgreSQL 提供网络地址类型，用于存储 IPv4、IPv6 和 MAC 地址。
- 比用纯文本存储更好： 
  - 有输入格式检查。 
  - 有专门的操作符和函数。 
  - 存储更紧凑。 
  - 支持包含、相等、排序等网络语义。
- 常用类型： 
  - inet：IPv4/IPv6 主机地址，可带子网掩码。
  - cidr：IPv4/IPv6 网络地址。 
  - macaddr：6 字节 MAC 地址。 
  - macaddr8：8 字节 EUI-64 MAC 地址。
- 存单个 IP 或“IP + 掩码”用 inet。 
- 存严格网段用 cidr。 
- 存 MAC 地址用 macaddr 或 macaddr8，不要用 text。

# 类型速查表

网络地址类型如下：

| 名字     | 存储      | 描述                   | 典型示例                           |
|----------|-----------|------------------------|------------------------------------|
| cidr     | 7或19字节 | IPv4和IPv6网络         | 192.168.1.0/24、2001:4f8:3:ba::/64 |
| inet     | 7或19字节 | IPv4和IPv6主机以及网络 | 192.168.1.10/24、2001:db8::1       |
| macaddr  | 6字节     | MAC地址                | 08:00:2b:01:02:03                  |
| macaddr8 | 8字节     | MAC地址（EUI-64格式）  | 08:00:2b:01:02:03:04:05            |

说明：

- IPv4 地址约 7 字节，IPv6 地址约 19 字节。
- macaddr8 接受 6 字节或 8 字节输入，但统一存为 8 字节。

# 如何选择 inet 与 cidr

| 需求                            | 推荐类型 |
|---------------------------------|----------|
| 存单个主机 IP                   | inet     |
| 存“IP + 掩码”，且主机位可以非零 | inet     |
| 存严格网络地址                  | cidr     |
| 想表达“这个 IP 属于哪个网段”    | inet     |
| 想表达“这是一个网段本身”        | cidr     |

本质区别：

- inet 接受网络掩码右侧仍有非零位的值。
- cidr 不接受网络掩码右侧有非零位的值。

示例：

```sql
-- inet 有效：192.168.0.1/24 的主机位非零
SELECT '192.168.0.1/24'::inet;

-- cidr 报错：/24 网络中，192.168.0.1 不是网络最低地址
SELECT '192.168.0.1/24'::cidr;
-- ERROR: invalid cidr value
```

所以：

- 192.168.0.1/24 对 inet 有效。
- 192.168.0.0/24 对 cidr 有效。
- 如果你只想接受网络地址，用 cidr，不要用 inet。

# inet

inet 保存 IPv4 或 IPv6 主机地址，以及可选的子网信息。

输入格式：

```text
address/y
```

- address：IPv4 或 IPv6 地址。
- y：网络掩码位数。
- 省略 /y 时：
  - IPv4 默认 /32。
  - IPv6 默认 /128。
  - 表示单个主机。

显示规则：

- 如果 /y 表示单个主机，输出时不显示。
- 例如 192.168.1.1/32 显示为 192.168.1.1。
- IPv6 单主机同理，不显示 /128。

示例：

```sql
SELECT '192.168.1.10'::inet;
-- 192.168.1.10

SELECT '192.168.1.10/24'::inet;
-- 192.168.1.10/24

SELECT '2001:db8::1'::inet;
-- 2001:db8::1

SELECT '2001:db8::1/64'::inet;
-- 2001:db8::1/64
```

注意：

- inet 可以表示主机，也可以表示“主机 + 所在网络”。
- 如果只想严格表示网络，用 cidr。

# cidr

cidr 保存 IPv4 或 IPv6 网络说明，遵循无类别域间路由约定。

输入格式：

```text
address/y
```

- address：网络最低地址。
- y：网络掩码位数。
- 如果省略 y，按旧式分类网络编号系统推断，但至少覆盖输入中写出的所有八位组。
- 如果网络地址在掩码右侧仍有置位，报错。

示例：

| cidr输入                             | cidr输出                             | abbrev(cidr)                         |
|--------------------------------------|--------------------------------------|--------------------------------------|
| 192.168.100.128/25                   | 192.168.100.128/25                   | 192.168.100.128/25                   |
| 192.168/24                           | 192.168.0.0/24                       | 192.168.0/24                         |
| 192.168/25                           | 192.168.0.0/25                       | 192.168.0.0/25                       |
| 192.168.1                            | 192.168.1.0/24                       | 192.168.1/24                         |
| 192.168                              | 192.168.0.0/24                       | 192.168.0/24                         |
| 128.1                                | 128.1.0.0/16                         | 128.1/16                             |
| 128                                  | 128.0.0.0/16                         | 128.0/16                             |
| 128.1.2                              | 128.1.2.0/24                         | 128.1.2/24                           |
| 10.1.2                               | 10.1.2.0/24                          | 10.1.2/24                            |
| 10.1                                 | 10.1.0.0/16                          | 10.1/16                              |
| 10                                   | 10.0.0.0/8                           | 10/8                                 |
| 10.1.2.3/32                          | 10.1.2.3/32                          | 10.1.2.3/32                          |
| 2001:4f8:3:ba::/64                   | 2001:4f8:3:ba::/64                   | 2001:4f8:3:ba/64                     |
| 2001:4f8:3:ba:2e0:81ff:fe22:d1f1/128 | 2001:4f8:3:ba:2e0:81ff:fe22:d1f1/128 | 2001:4f8:3:ba:2e0:81ff:fe22:d1f1/128 |
| ::ffff:1.2.3.0/120                   | ::ffff:1.2.3.0/120                   | ::ffff:1.2.3/120                     |
| ::ffff:1.2.3.0/128                   | ::ffff:1.2.3.0/128                   | ::ffff:1.2.3.0/128                   |

注意：

- cidr 输出会补全为网络地址。
- abbrev() 可以缩短显示。
- 省略掩码时，推断结果可能和你预期不同，建议显式写 /y。

# inet与cidr的本质区别

一句话：

- inet：可以包含主机位非零，表示“某个主机，可能带掩码”。
- cidr：必须网络位之后全为 0，表示“某个网段”。

示例：

```sql
-- inet：有效
SELECT '192.168.0.1/24'::inet;

-- cidr：无效
SELECT '192.168.0.1/24'::cidr;

-- cidr：有效
SELECT '192.168.0.0/24'::cidr;
```

如果你不喜欢 inet 或 cidr 的输出格式，可用：

- host()
- text()
- abbrev()

# 排序规则

对 inet 或 cidr 排序时：

- IPv4 地址总是排在 IPv6 地址之前。
- 即使 IPv6 地址是封装或映射 IPv4 的地址，例如 ::10.2.3.4 或 ::ffff:10.4.3.2，也仍然排在 IPv4 后面。

示例：

```sql
SELECT *
FROM hosts
ORDER BY ip;
```

不要假设 IPv6 映射地址会按 IPv4 排序。

# macaddr

macaddr 存储 6 字节 MAC 地址，例如以太网卡硬件地址。

可接受的输入格式：

```text
'08:00:2b:01:02:03'
'08-00-2b-01-02-03'
'08002b:010203'
'08002b-010203'
'0800.2b01.0203'
'0800-2b01-0203'
'08002b010203'
```

这些示例都表示同一个地址。

规则：

- 十六进制数字 a 到 f 大小写均可。
- 输出总是采用第一种形式：08:00:2b:01:02:03。
- PostgreSQL 不提供位反转功能。
- 所有接受的格式都使用规范的 LSB 顺序。

关于 IEEE 标准：

- IEEE 802-2001 指定连字符形式为规范形式。
- 冒号形式用于位反转、最高位在前的表示法。
- 例如 08-00-2b-01-02-03 = 10:00:D4:80:40:C0。
- 这种约定现在被广泛忽略，仅适用于过时网络协议。
- PostgreSQL 不提供位反转，统一按规范 LSB 顺序处理。

# macaddr8

macaddr8 以 EUI-64 格式存储 MAC 地址，占 8 字节。

特点：

- 接受 6 字节或 8 字节 MAC 地址。
- 统一以 8 字节格式存储。
- 6 字节转 8 字节时，第 4 和第 5 个字节分别设置为 FF 和 FE。

示例：

```sql
SELECT '08:00:2b:01:02:03'::macaddr8;
-- 08:00:2b:ff:fe:01:02:03

SELECT '08:00:2b:01:02:03:04:05'::macaddr8;
-- 08:00:2b:01:02:03:04:05
```

可接受的输入格式示例：

```text
'08:00:2b:01:02:03:04:05'
'08-00-2b-01-02-03-04-05'
'08002b:0102030405'
'08002b-0102030405'
'0800.2b01.0203.0405'
'0800-2b01-0203-0405'
'08002b01:02030405'
'08002b0102030405'
```

规则：

- 十六进制数字总数必须是 16 个（8 字节）或 12 个（6 字节）。
- 分隔符可选，但必须统一使用 :、- 或 . 中的一种。
- 前导和尾随空白会被忽略。
- 输出总是第一种形式：08:00:2b:01:02:03:04:05。

IPv6 修改版 EUI-64：

- 从 EUI-48 转换后，第 7 位应置为 1。
- 使用 macaddr8_set7bit() 完成。

示例：

```sql
SELECT macaddr8_set7bit('08:00:2b:01:02:03');
-- 0a:00:2b:ff:fe:01:02:03
```

# 常用操作符与函数

## 常用操作符

| 操作符 | 含义         |
|--------|--------------|
| <<     | 包含于       |
| <<=    | 包含于或等于 |
| >>     | 包含         |
| >>=    | 包含或等于   |
| =      | 相等         |
| <>     | 不相等       |

示例：

```sql
SELECT inet '192.168.1.10' << inet '192.168.1.0/24';
-- true

SELECT inet '192.168.1.0/24' >> inet '192.168.1.10';
-- true
```

## 常用函数

| 函数                       | 作用                |
|----------------------------|---------------------|
| abbrev(inet/cidr)          | 缩写显示            |
| host(inet)                 | 提取主机地址文本    |
| text(inet)                 | 转为文本            |
| network(inet)              | 返回网络部分        |
| netmask(inet)              | 返回网络掩码        |
| masklen(inet)              | 返回掩码长度        |
| set_masklen(inet, int)     | 设置掩码长度        |
| broadcast(inet)            | 返回广播地址        |
| family(inet)               | 返回 4 或 6         |
| hostmask(inet)             | 返回主机掩码        |
| macaddr8_set7bit(macaddr8) | 设置 EUI-64 第 7 位 |

具体行为以 PostgreSQL 官方文档为准。

# 实战 SQL

```sql
-- 类型转换
SELECT '192.168.1.10'::inet;
SELECT '192.168.1.10/24'::inet;
SELECT '192.168.1.0/24'::cidr;
SELECT '08:00:2b:01:02:03'::macaddr;
SELECT '08:00:2b:01:02:03:04:05'::macaddr8;

-- 建表
CREATE TABLE hosts (
    id serial PRIMARY KEY,
    ip inet,
    net cidr,
    mac macaddr,
    mac8 macaddr8
);

-- 插入
INSERT INTO hosts (ip, net, mac, mac8)
VALUES (
    '192.168.1.10/24',
    '192.168.1.0/24',
    '08:00:2b:01:02:03',
    '08:00:2b:01:02:03:04:05'
);

-- 查询某 IP 是否属于某网段
SELECT *
FROM hosts
WHERE ip <<= inet '192.168.1.0/24';

-- 查看网络信息
SELECT
    host(ip) AS host,
    text(ip) AS full_text,
    network(ip) AS network,
    netmask(ip) AS netmask,
    masklen(ip) AS masklen
FROM hosts;

-- 缩写显示
SELECT abbrev(net) FROM hosts;

-- MAC 地址转换
SELECT macaddr8_set7bit('08:00:2b:01:02:03');
-- 0a:00:2b:ff:fe:01:02:03
```

# 最佳实践

1. 存 IP 用 inet，不要用 text。
2. 存网段用 cidr，不要用 inet。
3. 存 MAC 用 macaddr 或 macaddr8，不要用 text。
4. 需要严格网络地址时用 cidr。 
  - 192.168.0.1/24 对 cidr 无效。
5. 需要“主机 + 掩码”时用 inet。
  - 192.168.0.1/24 对 inet 有效。
6. 显式写掩码长度。
  - 省略 /y 时，cidr 会按分类网络推断，可能不符合预期。
7. 用 abbrev()、host()、text() 控制显示。
8. 用操作符做包含查询。
  - <<、<<=、>>、>>=。
9. 注意排序规则。
  - IPv4 总是排在 IPv6 之前。
10. 需要索引时可正常建索引。
  - 具体索引类型和效果按查询模式选择。
11. MAC 地址用标准输出格式。
  - 输出固定为冒号分隔形式。
12. IPv6 接口标识用 macaddr8_set7bit()。
  - 不要手动改位。

# 常见坑

1. inet 和 cidr 混淆。
2. cidr 输入 192.168.0.1/24 会报错。
3. inet 省略掩码时，IPv4 默认 /32，IPv6 默认 /128。
4. inet 单主机输出不显示 /32 或 /128。
5. cidr 省略掩码时按分类网络推断。
6. IPv4 总是排在 IPv6 之前。
7. macaddr 不提供位反转功能。
8. macaddr8 接受 6 字节输入，但会插入 FF FE 转为 8 字节。
9. macaddr8_set7bit() 用于 IPv6 修改版 EUI-64。
10. 输入格式灵活，但输出格式固定。
11. 不要用 text 存网络地址。
12. 不要假设 inet 输出一定包含掩码。

# 总结

- 主机 IP 用 inet。
- 严格网段用 cidr。
- MAC 地址用 macaddr。
- EUI-64 / IPv6 接口标识用 macaddr8。
- 网络地址优先用专用类型，而不是文本；查询包含关系用 <<、<<=、>>、>>=。
