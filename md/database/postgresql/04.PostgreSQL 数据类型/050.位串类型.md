# 概述

- 位串是由 0 和 1 组成的字符串，常用于存储位掩码。
- SQL 提供两种位类型：
  - bit(n)：定长位串，长度必须正好是 n。 
  - bit varying(n)：变长位串，最大长度为 n。
- 不写长度的 bit 等价于 bit(1)。
- 不写长度的 bit varying 表示长度不受限。
- 直接插入时长度不匹配会报错；只有显式类型转换才会自动补零或截断。
- 位串常量用 B'1001' 或十六进制 X'1FF' 表示。

# 类型规则

| 类型           | 长度规则      | 超长/过短处理    |
|----------------|---------------|------------------|
| bit(n)         | 必须正好 n 位 | 直接插入报错     |
| bit varying(n) | 最多 n 位     | 直接插入超长报错 |
| bit            | 等价 bit(1)   | 只能 1 位        |
| bit varying    | 不限长度      | 可变长           |

示例：

```sql
CREATE TABLE test (
    a BIT(3),
    b BIT VARYING(5)
);

INSERT INTO test VALUES (B'101', B'00');  -- 成功
INSERT INTO test VALUES (B'10', B'101'); -- 失败：a 需要 3 位
-- ERROR: bit string length 2 does not match type bit(3)
```

显式转换可以改变长度：

```sql
INSERT INTO test VALUES (B'10'::bit(3), B'101');

SELECT * FROM test;
```

结果：

```text
  a  |  b
-----+-----
 101 | 00
 100 | 101
```

说明：B'10'::bit(3) 右侧补零，变成 B'100'。

# 位串常量

- 二进制形式：B'1001'，大小写 B 均可，字符只能是 0 和 1。
- 十六进制形式：X'1FF'，大小写 X 均可。
  - 每个十六进制位替换成 4 个二进制位。
  - 例如 X'1FF' 是 12 位位串。
- 两种常量都可以像普通字符串常量一样跨行继续。
- 美元引用不能用于位串常量。

# 显式转换规则

```sql
SELECT B'10'::bit(3);          -- 100，右侧补零
SELECT B'101'::bit(2);         -- 10，右侧截断
SELECT B'101'::bit varying(2); -- 10，右侧截断
```

要点：

- 转成 bit(n)：右侧截断或补零，直到正好 n 位，不报错。
- 转成 bit varying(n)：超过 n 位时右侧截断。
- 直接插入不会自动补齐，必须显式转换。

# 存储开销

- 每 8 位需要 1 字节。
- 额外有 5 或 8 字节开销，取决于串长度。
- 长值可能被压缩或移到行外存储，类似字符类型。

# 可用操作

- 支持位逻辑操作符，例如：
  - & 按位与
  - | 按位或
  - \# 按位异或
  - ~ 按位非
  - << 左移
  - \>> 右移
- 也可使用部分字符串操作函数，如 **[length()](../07.PostgreSQL%20内置函数/000.字符串函数.md#length)**、**[substring()](../07.PostgreSQL%20内置函数/000.字符串函数.md#substring)** 等。
- 具体函数和操作符以 PostgreSQL 官方文档为准。

# 常见坑

1. bit(n) 直接插入长度不匹配会报错，不会自动补零。
2. 只有显式 ::bit(n) 才会补零或截断。
3. 不写长度的 bit 是 bit(1)，不是不限长度。
4. 不写长度的 bit varying 才是不限长度。
5. X'1FF' 的长度是 12 位，不是 3 位。
6. 位串常量不能使用美元引用。
7. 不要和普通字符串、十六进制字符串混淆。
8. bit varying(n) 直接插入超长会拒绝，显式转换才截断。

# 总结

定长位掩码用 bit(n)，变长位串用 bit varying(n)；插入时长度严格校验，显式转换才会补零或截断。
