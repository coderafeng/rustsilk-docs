# 概述

https://github.com/timescale/pgvectorscale

用于向量搜索的 Postgres 扩展 (DiskANN)，是对 **[pgvector](./025.pgvector.md#概述)** 的有力补充，提升了性能和扩展性。

为 **pgvector** 数据引入了以下关键创新：

- 一种名为 StreamingDiskANN 的新型索引类型，其灵感来源于 **[DiskANN](https://github.com/microsoft/DiskANN)** 算法，基于微软的研究成果。
- 统计二进制量化：由 Timescale 研究人员开发，这种压缩方法改进了标准二进制量化。
- 基于标签的过滤向量搜索：基于微软的过滤 DiskANN 研究，它允许您将向量相似性搜索与标签过滤相结合，以获得更精确、更高效的结果。
