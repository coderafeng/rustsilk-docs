# 概述

https://github.com/pgpartman/pg_partman

pg_partman 是一个用于创建和管理基于时间和基于编号的表分区集的扩展。从 5.0.1 版本开始，仅支持内置的声明式分区，旧的基于触发器的分区方法已被弃用。

PostgreSQL 内置的声明式分区功能提供了创建分区表及其子表的命令。pg_partman 利用 PostgreSQL 提供的内置声明式功能，并在此基础上添加了额外的功能和增强特性，从而简化了分区管理。pg_partman 扩展 PostgreSQL 分区功能的一个关键方式是提供了一种自动化子表维护的方法（例如，根据保留策略添加新子表或删除旧子表）。pg_partman 还具备将现有表转换为分区表或反之亦然的功能。
