# 概述

> 官方仓库：**[pgroonga/pgroonga](https://github.com/pgroonga/pgroonga)**（基于 Groonga 全文搜索引擎）

PostgreSQL 内置的全文搜索只支持以空格分词的字母语言——这意味着不支持中文、日语等语言的全文搜索。**PGroonga** 把 [Groonga](https://groonga.org/) 搜索引擎作为索引类型嵌入 Postgres，支持所有语言的**零 ETL 超高速全文搜索**：数据还放在普通的 `text` 列里，只是给它挂一个 `pgroonga` 索引，就能获得多语言分词、关键词高亮、相关度排序、按需部分索引等搜索引擎能力——不需要把数据同步到 Elasticsearch/OpenSearch 再查回来。

它的三个差异化能力：

- **任意语言**：内置基于 Bigram 的日/中/韩切分（无需词典），也可接入 MeCab 等分词器；
- **类 SQL 原生**：查询就是 `WHERE content &~ '关键词'`，与 `WHERE` 里任何条件自由组合，走同一个索引；
- **渐进式全文检索**（narrow search）：先由普通 B-tree 缩小候选集，再做全文匹配，避免大表全文索引的冷启动开销。

# 安装

PGroonga 需要为每个 PG 大版本安装对应的包（以官方安装文档为准）：

```bash
# Debian/Ubuntu（PGDG + PGroonga 源）
apt install postgresql-18-pgroonga
# CentOS/RHEL
dnf install postgresql18-pgroonga
```

在目标库启用：

```sql
CREATE EXTENSION pgroonga;
```

> Windows 无官方预编译包，一般通过 Docker（`groonga/pgroonga`）或 WSL 使用。

# 快速上手

标准的"建表 → 灌数 → 挂索引 → 查"流程，表结构完全普通：

```sql
CREATE TABLE memos (
    id     serial PRIMARY KEY,
    content text
);

INSERT INTO memos (content) VALUES
('PostgreSQL is a relational database management system.'),
('Groonga is a full text search engine.'),
('PostgreSQL と Groonga を組み合わせて全文検索を使う'),
('pgroonga は PostgreSQL 用の全文検索用拡張モジュールです。');

-- pgroonga 是一种索引访问方法，可覆盖任意多列
CREATE INDEX memos_content_idx ON memos USING pgroonga (content);

-- &~ 运算符：命中查询词即返回（布尔语义）
SELECT * FROM memos WHERE content &~ 'PostgreSQL';

-- 多词查询（Groonga 查询语法：空格默认表示 AND）
SELECT * FROM memos WHERE content &~ 'database Groonga';
```

中文同样直接可用（默认 Bigram 切分，无需词典）：

```sql
INSERT INTO memos (content) VALUES (' PostgreSQL 支持中文全文搜索。');
SELECT * FROM memos WHERE content &~ '中文全文搜索';
```

# 相关度排序与高亮

`pgroonga_score()` 提供每条命中的 BM25-like 分数，`pgroonga_highlight_html()` 直接输出 `<span class="hit">` 高亮片段：

```sql
-- 按相关度取前 10
SELECT id, content, score
FROM (
    SELECT *, pgroonga_score(tableoid, ctid) AS score
    FROM memos
    WHERE content &~ 'PostgreSQL'
) t
ORDER BY score DESC
LIMIT 10;

-- 结果页高亮
SELECT pgroonga_highlight_html(
    content, ARRAY['PostgreSQL', 'Groonga']
) FROM memos WHERE content &~ 'PostgreSQL';
```

高级用法：`pgroonga_match_vocabulary()` 可以对词表做前缀/相似匹配（自动补全、分词调试），打分器（BM25/TF-IDF）与查询选项的启用方式以官方文档为准。

# 索引参数与部分索引

```sql
-- 指定列的切分器（如 TokenMecab 需要装 libmecab；WITH 参数写法以版本文档为准）
CREATE INDEX memos_content_idx ON memos
USING pgroonga (content)
WITH (tokenizer = 'TokenBigram');

-- 部分索引：只给活跃行建全文索引
CREATE INDEX active_memos_idx ON memos
USING pgroonga (content) WHERE active;
```

# 避坑

- **索引体积可观**：全文索引保存词表 + 位置信息，大文本表索引膨胀明显，上线前量一下 `pg_relation_size`；
- **写入放大**：每次 UPDATE text 列都要重打全文索引，高频改写的大文本考虑"只索引摘要列"或走窄搜索路径（先 B-tree 过滤后 `&~` 现算）；
- **切分器一致性**：同一查询不要混用不同 tokenizer 建的索引；日文装 TokenMecab 前确认 libmecab 与用户词典路径配置；
- 与 pg_jieba 的区别：pg_jieba 把结果接进**内置 tsvector 体系**（可与 pg_textsearch BM25 组合），PGroonga 是**自带完整索引与查询算子**的独立引擎，二选一即可，叠加使用多为浪费；
- 大版本升级后扩展二进制必须重装对应版本包。

# 总结

PGroonga 的定位是"Postgres 里的 Elasticsearch"：多语言全文搜索、高亮、相关度排序一揽子解决，且数据零搬迁、查询零学习成本（就是个索引类型 + `&~`）。英文为主的关键词搜索用内置 tsvector（配 **[pg_textsearch](./050.pg_textsearch.md)** 排序）更轻；中日韩文或混合语言的站内搜索，PGroonga 是 Postgres 生态里最完整的单体答案。
