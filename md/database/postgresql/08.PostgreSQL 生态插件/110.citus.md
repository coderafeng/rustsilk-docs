# 概述

https://github.com/citusdata/citus

https://learn.microsoft.com/zh-cn/postgresql/citus/?view=citus-14

Citus 是一个开源 PostgreSQL 扩展，可水平缩放 PostgreSQL。 可以在单个节点上启动并增长到分布式群集。 由于 Citus 是一个扩展（而不是分支），因此可以保留本机 PostgreSQL 兼容性、功能、生态系统工具和扩展。

关键功能包括：

- 分布式表（基于行的分片和基于架构的分片）
- 维度/共享数据的引用表
- 并置联接和分布式查询规划器
- 跨工作线程的并行查询执行
- 列式存储选项
- 从 MX 模式下的任何节点进行查询（自 Citus 11.0 起）

通常，采用 Citus 来提高多租户 SaaS、实时分析仪表板、时序和微服务状态管理的性能和可伸缩性。
