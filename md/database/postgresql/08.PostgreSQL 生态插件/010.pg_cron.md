# 概述

基于 cron 的简单 PostgreSQL（10 或更高版本）作业调度程序，它作为数据库扩展在数据库内部运行。

该扩展程序会创建一个后台工作进程来跟踪cron.job表中的任务。

```sql
CREATE TABLE cron.job (
    jobid bigint primary key default pg_catalog.nextval('cron.jobid_seq'),
    schedule text not null,
    command text not null,
    nodename text not null default 'localhost',
    nodeport int not null default pg_catalog.inet_server_port(),
    database text not null default pg_catalog.current_database(),
    username text not null default current_user
);
```

根据您的配置，要执行作业，该扩展程序会建立 Postgres 连接或生成数据库工作进程。

pg_cron 可以并行运行多个作业，但同一时间只能运行每个特定作业的一个实例。如果第二个实例在第一个实例完成之前被触发，它会被放入队列，并在第一个实例完成后立即启动。
