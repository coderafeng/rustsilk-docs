# 概述

可自动完成文本到嵌入向量的转换与编排，并提供对接主流大语言模型（LLM）的接口。它能帮助您快速启动并实现向量搜索、全文搜索和混合搜索的自动化维护，从而在 Postgres 上高效构建 RAG 系统和搜索引擎。

该项目大量依赖于**[pgvector](030.pgvector.md#概述)**的向量相似性搜索、**[pgmq](120.pgmq.md#概述)**的后台工作程序编排以及**[SentenceTransformers](https://huggingface.co/sentence-transformers)**。

**pg_vectorize** 提供了两种方式，可以为任何 Postgres 数据库添加语义搜索、全文搜索和混合搜索功能，从而轻松构建基于**检索增强生成 (RAG)** 的 Postgres 数据库

- HTTP 服务器（推荐用于托管数据库）：运行一个连接到 Postgres 并公开 REST API 的独立服务（POST /api/v1/table，GET /api/v1/search）。
- Postgres 扩展（SQL）：将扩展安装到 Postgres 中，并使用 SQL 函数，例如 **vectorize.table()**（vectorize.search()需要对 Postgres 的文件系统访问权限）。
