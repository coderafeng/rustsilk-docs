# 概述

https://github.com/powa-team/powa-archivist

https://powa.readthedocs.io/en/latest/architecture.html

https://powa.readthedocs.io/en/latest/quickstart.html

PoWA是一个依赖于多个组件的工具。它的主要目的是收集来自多个数据源的指标，将它们存储在中央存储库中，并提供一个用户界面来呈现这些数据，以便于排查问题。

主要组成有：

- powa-archivist 是 PostgreSQL 的扩展，用于收集统计信息，它有两个用途：
  - 以节省空间的方式存储各种指标，并提供任何其他相关功能（例如用户留存率等）。
  - 提供一致的指标视图，隐藏不同版本 PostgreSQL 或任何其他数据源之间的任何不兼容性。
- powa-collector 是一个守护进程，用于从专用存储库服务器上的远程 PostgreSQL 实例（可选）收集性能指标。
- powa-web 是 powa 收集的指标的web图形用户界面。

主要数据源是 **[pg_stat_statements](./090.pg_stat_statements.md#概述)**，它是 PostgreSQL 提供的一个扩展，必须启用。其他所有数据源都是可选的，可以根据需要动态添加或移除。
