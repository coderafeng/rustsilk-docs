### 日志相关

```text
# 启用日志收集器
logging_collector = on

# 日志目录（相对于 PGDATA）
log_directory = 'log'

# 使用静态文件名，方便 logrotate 匹配
log_filename = 'postgresql.log'

# 禁用 PostgreSQL 内置的轮转（交由 logrotate 处理）
log_rotation_age = 0
log_rotation_size = 0

# 轮转时是否截断同名文件（设为 off）
log_truncate_on_rotation = off

# 可选：记录慢查询（根据实际需求调整）
log_min_duration_statement = 5000   # 记录超过 5 秒的查询
```

## 创建 logrotate 配置文件

### 创建编辑文件

```bash
sudo vim /etc/logrotate.d/postgresql
```

### 填写以下内容

根据实际日志路径填写

```bash
/opt/postgresql/data/log/*.log {
    daily
    rotate 7
    maxsize 100M
    compress
    missingok
    notifempty
    create 640 postgres postgres
    sharedscripts
    postrotate
        /usr/bin/kill -HUP `cat /opt/postgresql/data/postmaster.pid` 2>/dev/null || true
    endscript
}
```

配置项说明：

| 指令                             | 说明                                      |
|--------------------------------|-----------------------------------------|
| `daily`                        | 每天轮转一次                                  |
| `rotate 10`                    | 保留最近 10 个归档文件                           |
| `maxsize 100M`                 | 文件超过 100MB 时立即轮转                        |
| `compress`                     | 轮转后压缩旧日志（gzip）                          |
| `missingok`                    | 日志文件不存在时不报错                             |
| `notifempty`                   | 空文件不轮转                                  |
| `create 640 postgres postgres` | 轮转后创建新文件，权限 640，属主 postgres             |
| `sharedscripts`                | `postrotate` 脚本只执行一次                    |
| `postrotate ... endscript`     | 轮转后向 PostgreSQL 发送 `SIGHUP`，通知其重新打开日志文件 |


### 测试运行

debug模式，测试执行命令

```bash
sudo logrotate -d /etc/logrotate.d/postgresql
```

强制执行一次，查看目录中的文件变化：`/opt/postgresql/data/log`

```bash
sudo logrotate -f /etc/logrotate.d/postgresql
```

### 总结

1. **职责分离**：PostgreSQL 只负责写入日志（logging_collector = on），轮转交由 logrotate 管理。
2. **禁用内置轮转**：将 log_rotation_age 和 log_rotation_size 设为 0，避免与 logrotate 冲突。
3. **使用静态文件名**：log_filename = 'postgresql.log'，方便 logrotate 精确匹配。
4. **发送 SIGHUP**：postrotate 脚本通过 kill -HUP 通知 PostgreSQL 重新打开日志文件。
5. **测试验证**：配置完成后务必用 -d 和 -f 模式测试，确保轮转正常。
