# 概述

Zed 内置一套 **Vim 模拟层（vim mode）**。这是很多新用户「复制不是 `Ctrl+C`」困惑的根源——一旦启用 `vim_mode`，编辑器就变成模态编辑：普通模式下 `y` 才是复制、`p` 才是粘贴。本文系统讲清楚如何开关、核心 motion、text object、可视模式、宏、Vim 命令行与设置。

> [!important] 默认是关闭的
> Zed **默认不启用** Vim 模式（`vim_mode` 默认 `false`），默认键位下 `Ctrl+C` 就是复制。如果你「装完发现变成了 Vim」，通常是在欢迎页勾选了 Vim，或引导时选了 Vim keymap。想回到普通编辑，执行 `workspace: toggle vim mode` 或把设置里的 `vim_mode` 改为 `false` 即可。

## Zed 的 Vim 模式设计理念

Zed 的 vim mode **不是** 1:1 复刻 Vim，而是「在合理处精确复刻 Vim 的 motion 与命令，在 Zed 更强的地方用 Zed 自己的能力」。它把 Vim 的模态设计与 Zed 的现代特性（Tree-sitter 语义解析、多光标、语言服务器）融合，开箱即用、无需大量配置。

四类与 Vim 有差异的地方：

1. **Motions（移动）**：借助 Tree-sitter 按语言调优。例如 Rust 中 `%` 跳匹配括号能识别管道符 `|`；JavaScript 中 `w` 把 `$` 当作单词字符。
2. **Visual block（可视块）**：用 Zed 的多光标模拟，块选更灵活——块选后插入的内容会实时同步到每一行，可随时增减光标。
3. **Macros（宏）**：用 Zed 的录制系统，可录制并回放更复杂的动作（如自动补全）。
4. **Search & Replace（查找替换）**：用 Zed 的搜索系统，正则语法与 Vim 略有不同（见文末）。

## 启用 / 关闭

- 欢迎页勾选 vim mode。
- 命令面板：`workspace: toggle vim mode`。
- 设置文件：

```jsonc
{ "vim_mode": true }
```

### 内置的「插件」能力

Zed 的 vim mode 直接内置了很多 Vim 生态里要靠插件才有的功能：

- **surround**：`ys` 添加环绕、`cs` 修改环绕、`ds` 删除环绕。
- **注释**：可视模式 `gc`、普通模式 `gcc` 切换注释。
- **netrw 式文件树操作**：Project Panel 里用 `hjkl` 导航、`o` 打开、`t` 新标签打开等。
- **ReplaceWithRegister**：`gR`。
- **vim-exchange**：`cx`（可视模式默认无绑定，可自加）。

## 命令面板（Vim 命令行）

Vim 模式下用 `:` 打开 Zed 命令面板，并为常见 Vim 命令提供了别名。注意：目前**命令不支持参数**。

### 文件与窗口管理

| 命令 | 说明 |
|------|------|
| `:w[rite][!]` | 保存当前文件 |
| `:wq[!]` | 保存并关闭 buffer |
| `:q[uit][!]` | 关闭 buffer |
| `:wa[ll][!]` | 保存所有文件 |
| `:qa[ll][!]` | 关闭所有 buffer |
| `:bd[elete][!]` | 在所有 pane 关闭当前文件 |
| `:vs[plit]` / `:sp[lit]` | 垂直 / 水平拆分 pane |
| `:tabn[ext]` / `:tabp[rev]` | 下一个 / 上一个标签 |
| `:ls` | 显示所有 buffer |

`!` 表示强制执行（不保存 / 不提示覆盖）。

## 自定义 Vim 键位与上下文

Vim 模式在 `Editor` 上下文里增加了若干 context，用于精确限定绑定生效的模式：

| Context | 含义 |
|---------|------|
| `VimControl` | normal / visual / operator 模式都生效 |
| `vim_mode == normal` | 普通模式 |
| `vim_mode == visual` | 可视模式 |
| `vim_mode == insert` | 插入模式 |
| `vim_mode == replace` | 替换模式 |
| `vim_mode == operator` | 等待操作符目标（如按了 `d` 之后） |

一个常用模板（复制到 `keymap.json`）：

```jsonc
[
  {
    "context": "VimControl && !menu",
    "bindings": {
      // normal 与 visual 模式都生效的键位
    }
  },
  {
    "context": "vim_mode == insert",
    "bindings": {
      "j k": "vim::NormalBefore"   // 插入模式 jk 退出到普通模式
    }
  }
]
```

### 在 Windows/Linux 上找回被覆盖的常用键

Vim 模式会覆盖一些你离不开的键（`ctrl+v` 粘贴、`ctrl+f` 查找等）。想找回它们，把下面加进 keymap：

```jsonc
{
  "context": "Editor && !menu",
  "bindings": {
    "ctrl-f": "buffer_search::Deploy",   // vim 默认：下翻页
    "ctrl-c": "editor::Copy",            // vim 默认：回到普通模式
    "ctrl-x": "editor::Cut",             // vim 默认：递减
    "ctrl-v": "editor::Paste",           // vim 默认：可视块模式
    "ctrl-a": "editor::SelectAll",       // vim 默认：递增
    "ctrl-y": "editor::Undo",            // vim 默认：上滚一行
    "ctrl-s": "workspace::Save",         // vim 默认：显示签名
    "ctrl-b": "workspace::ToggleLeftDock"// vim 默认：下
  }
}
```

### 启用子词导航（camelCase / snake_case）

默认未启用，可加：

```jsonc
{
  "context": "VimControl && !menu && vim_mode != operator",
  "bindings": {
    "w": "vim::NextSubwordStart",
    "b": "vim::PreviousSubwordStart",
    "e": "vim::NextSubwordEnd",
    "g e": "vim::PreviousSubwordEnd"
  }
}
```

## Vim 模式设置

在 `settings.json` 的 `vim` 对象下配置：

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `default_mode` | 起始模式：normal/insert/replace/visual/visual_line/visual_block/helix_normal | `"normal"` |
| `use_system_clipboard` | 系统剪贴板用法：`always`/`never`/`on_yank` | `"always"` |
| `use_smartcase_find` | `f`/`t` 目标为小写时忽略大小写 | `false` |
| `use_regex_search` | Vim 搜索使用正则模式 | `true` |
| `gdefault` | `:substitute` 默认替换整行所有匹配 | `false` |
| `toggle_relative_line_numbers` | 普通模式相对行号、插入模式绝对行号 | `false` |
| `highlight_on_yank_duration` | yank 高亮动画时长（ms），`0` 关闭 | `200` |
| `custom_digraphs` | 自定义 digraph | `{}` |

示例：

```jsonc
{
  "vim": {
    "default_mode": "normal",
    "use_system_clipboard": "never",
    "use_smartcase_find": true,
    "toggle_relative_line_numbers": true,
    "highlight_on_yank_duration": 50
  }
}
```

## 正则差异（与 Vim 相比）

Zed 用的正则引擎（Rust `regex` crate）与 Vim 不同：

- **捕获组**：Vim 用 `\(` `\)`，Zed 用 `(` `)`；反过来，字面括号在 Zed 里要写成 `\(` `\)`。
- **替换引用**：Vim 用 `\1`，Zed 用 `$1`；整个匹配 Vim 是 `\0`，Zed 是 `$0`。
- **全局**：Vim 默认只匹配每行第一个（需加 `/g`），Zed **默认全局**。
- **忽略大小写**：Vim 用 `/i`，Zed 用 `(?i)` 前缀或快捷键切换。

> [!tip] 过渡辅助
> 写 Vim 风格的 `:%s//` 替换命令时，命令面板会自动帮你把 Vim 的括号与 `\1` 引用转换成 Zed 语法。
