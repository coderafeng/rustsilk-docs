# 概述

Zed 的键位系统**完全可定制**：可以重绑任意动作、创建按键序列（chord）、定义与上下文（context）相关的绑定。如果你不适应默认键位，最简单的办法是先切换 `base_keymap`，再针对个别键做覆盖。

## 预置键位方案（base_keymap）

在设置里改 `base_keymap`，一键套用某个编辑器的键位习惯。目前支持：

- **Zed**（默认）
- **VS Code**
- **Atom**
- **Emacs**（Beta）
- **JetBrains**
- **Sublime Text**
- **TextMate**
- **Cursor**
- **None**（禁用所有键位）

切换方式：设置编辑器搜 `base keymap`、命令面板 `zed: toggle base keymap selector`，或在 `settings.json` 里：

```jsonc
{ "base_keymap": "VSCode" }
```

此外可叠加 `vim_mode` 或 `helix_mode` 获得模态编辑，见 [040.Vim模式](./040.Vim模式.md) 与 [050.Helix模式](./050.Helix模式.md)。

## 键位编辑器与 keymap.json

- **键位编辑器（图形）**：`Ctrl+K Ctrl+S`，或命令面板 `zed: open keymap`。可看到所有动作及其默认绑定，点击铅笔图标 / 双击行 / 按回车即可修改，改动会同步写入 `keymap.json`。
- **keymap 文件位置**：
  - macOS / Linux：`~/.config/zed/keymap.json`
  - Windows：`~\AppData\Roaming\Zed\keymap.json`

`keymap.json` 是一个 JSON 数组，每个元素含一个 `bindings` 对象；可选 `context` 限定生效范围：

```jsonc
[
  {
    "bindings": {
      "ctrl-right": "editor::SelectLargerSyntaxNode",
      "ctrl-left": "editor::SelectSmallerSyntaxNode"
    }
  },
  {
    "context": "ProjectPanel && not_editing",
    "bindings": {
      "o": "project_panel::Open"
    }
  }
]
```

Zed 各平台的默认键位可在源码仓库查看：[default-macos.json](https://github.com/zed-industries/zed/blob/main/assets/keymaps/default-macos.json)、[default-windows.json](https://github.com/zed-industries/zed/blob/main/assets/keymaps/default-windows.json)、[default-linux.json](https://github.com/zed-industries/zed/blob/main/assets/keymaps/default-linux.json)。

## 按键语法（Keybinding Syntax）

Zed 不仅能匹配单个按键，还能匹配**按键序列**（用空格分隔）。每个按键是「修饰符 + 键」：

| 修饰符 | 含义 |
|--------|------|
| `ctrl-` | Control 键 |
| `cmd-` / `win-` / `super-` | 平台主修饰键（macOS 的 Command / Windows 键 / Linux 的 Super） |
| `alt-` | Alt（macOS 的 Option） |
| `shift-` | Shift |
| `fn-` | Function 键 |
| `secondary-` | macOS 上等价 `cmd`，Windows/Linux 上等价 `ctrl` |

键可以是任意单个 Unicode 码点（`a`、`0`、`£`、`ç`），或命名键（`tab`、`f1`、`shift`、`cmd`）。示例：

```jsonc
{
  "bindings": {
    "cmd-k cmd-s": "zed::OpenKeymap",       // 先 ⌘-k 再 ⌘-s（chord）
    "space e": "editor::ShowCompletions",   // 先按空格再按 e
    "shift shift": "file_finder::Toggle"    // 双击 shift（JetBrains 式 Search Everywhere）
  }
}
```

> [!note] shift- 与标点
> `shift-` 修饰符只用于字母表示大写，如 `shift-g` 匹配输入 `G`。标点符号（如 `(`）虽常需 shift 打出，但不算「被 shift 修饰」，所以 `shift-(` 不匹配。

## 上下文（Contexts）

带 `context` 的绑定只在当前上下文匹配时生效。Zed 的上下文是一棵树，根是 `Workspace`，其下有 `Pane`、`Editor`、`Dock`、`ProjectPanel`、`Terminal` 等。用命令面板 `dev: open key context view` 可实时查看当前激活的上下文。

上下文表达式支持：

- `X && Y`、`X || Y`：与 / 或
- `!X`：非
- `(X)`：分组
- `X > Y`：祖先节点匹配 X 且本层匹配 Y

示例：

```jsonc
{ "context": "Editor", "bindings": { /* 任意编辑器内生效 */ } }
{ "context": "Editor && mode == full", "bindings": { /* 主代码编辑器 */ } }
{ "context": "!Editor && !Terminal", "bindings": { /* 除编辑器/终端外 */ } }
{ "context": "os == macos > Editor", "bindings": { /* macOS 上的编辑器 */ } }
```

## 动作（Actions）

Zed 几乎所有功能都以 action 暴露。绑定方式：

```jsonc
"ctrl-a": "language_selector::Toggle",                       // 无参数，字符串
"cmd-1": ["workspace::ActivatePane", 0],                     // 单参数，数组
"ctrl-a": ["pane::DeploySearch", { "replace_enabled": true }] // 带对象参数
```

动作名可在命令面板、默认 keymap 文件里查到，或在 `keymap.json` 里用 Zed 的自动补全提示。

## 优先级（Precedence）

同一按键有多个绑定且都生效时：

1. **上下文树中更低的节点优先**：`Editor` 的绑定压过 `Workspace`；无 context 的绑定在最低层匹配。
2. **同层后定义者优先**：用户 keymap 在系统 keymap 之后加载，因此用户绑定压过内置绑定。

当一个绑定是另一个的前缀时（如 `ctrl-w` 与 `ctrl-w left`），Zed 会等待约 1 秒看你是否要继续输入后续键。

## 实用技巧

### 禁用某个绑定

用 `null` 作为动作，让某键在某上下文里什么都不做：

```jsonc
[
  { "context": "Workspace", "bindings": { "cmd-r": null } }
]
```

### 一键映射为按键序列

用 `workspace::SendKeystrokes` 把单键映射成一串按键：

```jsonc
[
  {
    "bindings": {
      "alt-down": ["workspace::SendKeystrokes", "down down down down"]
    }
  },
  {
    "context": "Editor && vim_mode == insert",
    "bindings": {
      "j k": ["workspace::SendKeystrokes", "escape"]  // 插入模式下 jk 退出到普通模式
    }
  }
]
```

限制：异步操作（打开文件、命令面板、访问语言服务器/网络）要等所有绑定派发完才发生；单次最多模拟 100 个按键。

### 把按键转发给终端

Linux/Windows 上，某些组合（如 `ctrl-n`）会被 Zed 拦截。想让终端聚焦时把它转发给终端：

```jsonc
{
  "context": "Terminal",
  "bindings": {
    "ctrl-n": ["terminal::SendKeystroke", "ctrl-n"]
  }
}
```

### 子词（Subword）导航

Zed 把 word 与 subword motion 分成不同动作。subword 会在 `camelCase`、`snake_case` 内部停顿：

```jsonc
[
  {
    "context": "Editor",
    "bindings": {
      "alt-left": "editor::MoveToPreviousSubwordStart",
      "alt-right": "editor::MoveToNextSubwordEnd",
      "shift-alt-left": "editor::SelectToPreviousSubwordStart",
      "shift-alt-right": "editor::SelectToNextSubwordEnd"
    }
  }
]
```

### 非 QWERTY 键盘

若使用非 ASCII 键盘布局，可在 keymap 里设 `"use_key_equivalents": true`，让 Zed 按 ASCII 等价键匹配。详见官方 [Keybindings 文档](https://zed.dev/docs/key-bindings)。
