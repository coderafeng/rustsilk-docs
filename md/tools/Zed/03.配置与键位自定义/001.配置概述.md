# 概述

Zed 的配置 philosophy 是「**JSON 文件为主，图形设置为辅**」。几乎所有行为都可以通过编辑 `settings.json` 精确控制；同时 Zed 也提供了一个可搜索的**设置编辑器（Settings Editor）**方便快速改常见项。键位则单独放在 `keymap.json`。本章讲清楚配置体系、主题外观、键位绑定、两种模态编辑（Vim 模式与 Helix 模式），最后给出一套可直接复制投产的[多语言最佳实践完整配置](./060.最佳实践完整配置.md)。

## 两类配置文件

| 文件 | 作用 | 打开方式 |
|------|------|----------|
| `settings.json` | 所有设置项 | `Ctrl+,`（设置编辑器）/ `Ctrl+Alt+,`（直接编辑文件）/ 命令面板 `zed: open settings` |
| `keymap.json` | 键位绑定 | `Ctrl+K Ctrl+S` / 命令面板 `zed: open keymap` |

配置文件位置：

- macOS / Linux：`~/.config/zed/`
- Windows：`~\AppData\Roaming\Zed\`

> [!tip] 设置编辑器 vs 设置文件
> `Ctrl+,` 打开的是**可视化设置编辑器**，可搜索、点选、直接改；`Ctrl+Alt+,` 或 `zed: open settings` 打开的是**原始 `settings.json`**，适合批量编辑与版本管理。两者改的是同一份文件。

## 为什么「操作方式和常见编辑器不同」

Zed 提供了 **base_keymap（基础键位方案）**，可一键切换成 VS Code / Atom / JetBrains / Sublime / Emacs / Cursor 等你熟悉的键位；也可以额外开启 `vim_mode` 或 `helix_mode` 获得模态编辑。如果你不适应默认键位，先换 base_keymap 通常比逐个改键更省事。详见 [030.键位绑定Keybindings](./030.键位绑定Keybindings.md)。
