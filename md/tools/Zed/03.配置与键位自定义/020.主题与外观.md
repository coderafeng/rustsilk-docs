# 概述

Zed 的界面外观高度可定制：主题、图标主题、字体、UI 密度、滚动条、小地图、缩进参考线等都能在 `settings.json` 里精确控制。所有更改**即时生效**，无需重启。

## 切换主题

- 快捷键：`Ctrl+K Ctrl+T`（macOS `Cmd+K Cmd+T`）打开主题选择器（`theme selector: toggle`）。
- 命令面板：搜 `theme selector: toggle`。
- 设置文件：`"theme"` 字段。

### 主题跟随系统

让主题随系统明暗自动切换：

```jsonc
{
  "theme": {
    "mode": "system",
    "light": "One Light",
    "dark": "One Dark"
  }
}
```

`mode` 可选 `"light"` / `"dark"` / `"system"` / `"system_appearance"`。

### 安装更多主题

Zed 内置了 One Dark、One Light、Solarized、Gruvbox、Ayu 等主题。更多主题通过扩展安装：`Ctrl+Shift+X` 打开扩展面板，搜索主题名（如 Catppuccin、Tokyo Night）安装后即可在主题选择器里选用。详见 [07.扩展与语言支持](../07.扩展与语言支持/001.扩展概述.md)。

## 图标主题（Icon Theme）

Zed 自带一套内置图标主题，也可通过扩展安装（如 Material Icon Theme、Catppuccin Icons）。在 `settings.json` 里设置：

```jsonc
{
  "icon_theme": "Material Icon Theme"
}
```

同样支持按明暗分别指定：

```jsonc
{
  "icon_theme": {
    "mode": "system",
    "light": "Catppuccin Latte",
    "dark": "Catppuccin Mocha"
  }
}
```

## 字体

Zed 区分**编辑区字体**与 **UI 字体**：

```jsonc
{
  // 代码编辑区
  "buffer_font_family": "JetBrains Mono",
  "buffer_font_size": 15,
  "buffer_font_weight": 400,
  "buffer_font_features": {
    "calt": false        // 关闭连字等 OpenType 特性
  },
  "buffer_line_height": { "custom": 1.6 },

  // 界面（面板、菜单等）
  "ui_font_family": "Zed Plex Sans",
  "ui_font_size": 16,

  // 终端
  "terminal": {
    "font_family": "JetBrains Mono",
    "font_size": 14,
    "line_height": "standard"
  }
}
```

> [!note] 默认字体
> Zed 默认使用自带的 `Zed Mono` / `Zed Plex Mono`，无需额外安装即可正常显示。想换成自己喜欢的等宽字体，改 `buffer_font_family` 即可（字体需已安装在系统中）。

## UI 密度与视觉微调

| 设置项 | 作用 |
|--------|------|
| `cursor_blink` | 光标是否闪烁（`true`/`false`） |
| `cursor_shape` | 光标形状：`bar` / `block` / `underline` / `hollow` |
| `current_line_highlight` | 是否高亮当前行 |
| `tab_bar.show` | 是否显示标签栏 |
| `tabs.file_icons` | 标签是否显示文件图标 |
| `toolbar.breadcrumbs` | 面包屑导航开关 |
| `scrollbar.show` | 滚动条显示策略：`auto` / `always` / `never` |
| `minimap.show` | 小地图显示策略 |
| `indent_guides.enabled` | 缩进参考线 |
| `wrap_guides` | 竖排换行参考线（如 `[80, 120]`） |
| `git.inline_blame.enabled` | 行内 git blame |
| `inlay_hints.enabled` | 内联类型提示（依赖 LSP） |
| `status_bar.show` | 状态栏显示 |

示例：隐藏滚动条、开启相对行号、关闭光标闪烁（Vim 用户常见配置）：

```jsonc
{
  "cursor_blink": false,
  "relative_line_numbers": "enabled",
  "scrollbar": { "show": "never" },
  "vertical_scroll_margin": 0,
  "scroll_beyond_last_line": "off"
}
```

## 面板透明度与聚焦

多 pane 时可让非聚焦 pane 变暗，突出当前焦点：

```jsonc
{
  "active_pane_modifiers": {
    "inactive_opacity": 0.8
  }
}
```

## 主题定制（进阶）

如果想微调某个主题的配色，可用 `theme_overrides` 覆盖具体颜色令牌，或编写完整的自定义主题扩展。主题扩展开发见 [030.开发与发布扩展](../07.扩展与语言支持/030.开发与发布扩展.md)。
