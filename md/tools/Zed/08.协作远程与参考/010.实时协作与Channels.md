# 概述

Zed 内置**实时协作**能力：多人可以像 Google Docs 那样同时编辑同一份代码、看到彼此的光标、语音通话、共享屏幕。协作有两种组织方式：

- **Contacts / Private Calls**：一对一/临时性的私人通话与项目共享。
- **Channels（频道）**：持久的团队房间，可长期存在、分子频道、带笔记，适合团队常驻协作。

> [!warning] 协作需要登录
> 使用任何协作功能前必须登录 Zed 账号（GitHub 授权）。Collaboration Panel 用 `Ctrl+Shift+C`（macOS `Cmd+Shift+C`）打开。

## Collaboration Panel

打开后分为两个区域：

```text
┌────────────────────────────┐
│  Channels                  │  ← 频道列表（持久房间）
│   # team                   │
│     └ # backend            │
├────────────────────────────┤
│  Contacts                  │  ← 联系人
│  Private Calls             │  ← 私人通话
└────────────────────────────┘
```

> [!important] 共享项目 = 暴露本地文件系统
> 当你**共享一个项目**时，协作者获得的是你机器上该项目的访问权。谨慎选择共享哪个目录，不要意外暴露敏感文件。

## 共享项目

在打开的项目里点顶部工具栏的 **Share** 按钮，或通过 Collaboration Panel 共享当前项目：

- 被邀请者可以查看、（在你授予写权限后）编辑**你机器上的代码**。
- guest（访客）默认可能只读，你可以选择 "Allowing Write Access" 放开写权限。
- 所有编辑操作实际发生在**你的机器**上，协作者是通过网络操作你的 buffer。

## Channels（频道）

频道是**持久的协作房间**，比一次性通话更适合团队。

### 创建与管理

| 操作 | 方式 |
|------|------|
| 创建频道 | Channels 区旁的 `+` 按钮 |
| 创建子频道 | 右键频道 → `New Subchannel` |
| 邀请成员 | 频道 → `Manage members`（子频道**继承**父频道权限） |
| 公开频道 | 可设为 public，允许 guest 只读加入 |

### 频道能力

- **共享项目**：频道内点 Share 共享项目，成员协作编辑。
- **语音通话**：点麦克风图标加入频道语音；可用 `mute_on_join` 设置加入时默认静音。
- **Channel Notes（频道笔记）**：点文档图标，用 Markdown 写团队共享笔记。
- **屏幕共享**：共享你的屏幕给频道成员。

## 跟随协作者

结对编程时想"看着对方操作"，可以跟随某个协作者：

- 点击对方头像，或
- `Ctrl+Alt+Shift+F`（对应动作 `workspace: follow next collaborator`）

跟随是 **pane 级**的：你当前 pane 会同步滚动到对方的光标位置。每位协作者的光标用**不同颜色描边**区分。再次执行跟随动作或点自己可取消跟随。

## 音频设置

语音/音频属于实验特性：

- 打开路径：Settings → `Collaboration` → `Experimental`。
- 相关设置：`audio.experimental.output_audio_device` 指定输出设备。

## 离开通话

在通话/频道里点 **Leave call** 即可退出当前协作会话，但保留本地项目打开状态。

> [!tip] 协作 vs 远程开发
> 协作是"多人共享同一台机器上的项目"；[远程开发](./020.远程开发SSH.md)是"一个人的 UI 连接远程机器"。两者可叠加：在远程项目里也能邀请他人协作。
