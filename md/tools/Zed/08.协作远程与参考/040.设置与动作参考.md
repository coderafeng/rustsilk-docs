# 概述

本页是 Zed 配置体系的**速查参考**：settings.json 的组织方式与常用设置项分类、Actions（动作）的概念与查询方法、keymap 与 snippets 的位置。命令面板里每条命令都对应一个 action——第 02 章 [020.命令面板](../02.界面与核心操作/020.命令面板.md) 已说明这一点，本页告诉你如何系统地查阅它们。

## settings.json 概览

Zed 的全部设置都在 JSON 文件里（没有图形设置界面的时代设计），打开方式：

- 快捷键 `Ctrl+,`（macOS `Cmd+,`），或
- 命令面板执行 `zed: open settings`。

设置文件分三层，**后层覆盖前层**：

```text
1. 默认设置（defaults）     ← Zed 内置，只读
2. 用户设置 settings.json    ← 你的全局配置
3. 项目设置 .zed/settings.json ← 项目内配置（可提交进 Git 共享给团队）
```

> [!tip] 查看默认值
> 命令面板执行 `zed: open default settings` 可以看到全部内置默认设置，照着键名抄进自己的 settings.json 修改即可。

## Actions（动作）

Zed 的一切操作都是 **action**：命令面板里看到的每条命令、keymap.json 里绑定的每个目标、gpui 内部派发的每个事件，都是一个 action。命名约定是 `域: 动词短语`，小写空格分隔：

```text
editor: delete                        ← 删除选区
pane: close_item                      ← 关闭当前 editor
workspace: toggle_left_panel          ← 开关左侧面板
project: open                        ← 打开项目
zed: about                            ← 查看版本信息
```

### 查询动作的三种方式

1. **命令面板**（`Ctrl+Shift+P` / macOS `Cmd+Shift+P`）：输入关键词即可看到"命令名 + 当前绑定键"，这是最日常的查法。
2. **官方 All Actions 参考页**：<https://zed.dev/docs/reference/all-actions> —— 全量清单与默认绑定。
3. **keymap 调试**：修改 `keymap.json` 时按 `Ctrl+K` 打开（`zed: open keymap`），动作名就是绑定的 value 字符串。

### 自定义键位引用 action

`keymap.json` 里给 action 绑定按键（更多写法见第 03 章 [030.键位绑定Keybindings](../03.配置与键位自定义/030.键位绑定Keybindings.md)）：

```jsonc
[
  {
    "context": "workspace",
    "bindings": {
      "ctrl-alt-l": "editor: toggle inlay hints"
    }
  }
]
```

> [!note] context 决定动作可用性
> 同一 action 只在特定 `context`（如 `editor`、`workspace`、`terminal`）下可触发。绑定了却没反应，多半是 context 写错。

## snippets 与 tasks 的位置

| 文件 | 位置 | 说明 |
|------|------|------|
| `settings.json` | `~/.config/zed/`（Linux/Windows 为 `%LOCALAPPDATA%\Zed\`） | 用户全局设置 |
| `keymap.json` | 同上 | 自定义键位 |
| `tasks.json` | 同上或项目 `.zed/tasks.json` | Tasks，见 [020.Tasks任务](../05.运行调试与Git/020.Tasks任务.md) |
| snippets | `~/.config/zed/snippets/` | 全局与按语言 snippets |
| `agents/`、`skills/`、`AGENTS.md` | 同上或项目 `.zed/` | AI 配置，见 [040.Skills与Instructions](../06.AI与Agent/040.Skills与Instructions.md) |

> [!tip] settings.json 是 JSONC
> Zed 的设置文件支持注释（JSONC），在 `zed: open settings` 打开的文件里直接写 `//` 注释做备忘。
