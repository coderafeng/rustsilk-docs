# 概述

本文按场景整理 Zed 的**默认快捷键速查表**。表中以 **Windows / Linux** 键位为主，括号内为 macOS 对应键（`Ctrl`→`Cmd`、`Alt`→`Option`）。

> [!important] 先搞清楚：默认模式 vs Vim 模式
> Zed 默认**不是** Vim 模式（`vim_mode` 默认 `false`）。默认模式下，复制就是 `Ctrl+C`、粘贴 `Ctrl+V`、保存 `Ctrl+S`，和常见编辑器一致。
>
> **只有当你在设置里开启了 `vim_mode`（或首次引导时选择了 Vim keymap）**，编辑器才进入模态编辑：普通模式下 `y` 复制（yank）、`p` 粘贴（put）、`d` 删除、`Ctrl+C` 不再是复制。如果你「装完发现复制不是 Ctrl+C」，几乎可以确定是 Vim 模式被启用了——去设置里搜 `vim_mode` 关掉即可，或到 [040.Vim模式](../03.配置与键位自定义/040.Vim模式.md) 学清楚它。

> [!tip] 不确定就查命令面板
> 键位可能因平台、版本、你的自定义 keymap 而异。任何动作都能在命令面板（`Ctrl+Shift+P`）里搜到，并显示当前绑定的按键。也可运行 `zed: open default keymap` 查看完整默认键位。

## Vim 模式核心键位对照（启用 vim_mode 后）

启用 `vim_mode` 后进入模态编辑，常用键位如下（这也是「复制不是 Ctrl+C」的根源）：

| 操作 | 默认模式 | Vim 普通模式 |
|------|----------|-------------|
| 复制（yank） | `Ctrl+C` | `y`（配合 motion，如 `yy` 复制整行） |
| 粘贴（put） | `Ctrl+V` | `p`（后方）/ `P`（前方） |
| 删除（delete） | `Delete` | `d`（如 `dd` 删整行、`dw` 删词） |
| 剪切整行 | `Ctrl+X` | `dd` 或 `D` |
| 撤销 / 重做 | `Ctrl+Z` | `u` / `Ctrl+R` |
| 进入插入模式 | 直接输入 | `i` / `a` / `o` / `I` / `A` / `O` |
| 打开命令面板 | `Ctrl+Shift+P` | `:`（Vim 命令行，支持 `:w` `:q` 等别名） |

完整的 Vim motion、text object、可视模式、宏等见 [040.Vim模式](../03.配置与键位自定义/040.Vim模式.md)。
