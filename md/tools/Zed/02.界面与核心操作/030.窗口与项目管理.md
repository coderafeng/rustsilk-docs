# 概述

Zed 的项目/窗口模型与 VS Code 明显不同：**它可以在一个窗口里同时打开多个项目**，项目列在左侧的 **threads sidebar（线程侧边栏）** 中，切换项目时会保留各自的布局与 agent 线程上下文。理解这套模型，能避免「打开新文件夹结果覆盖了当前工作」的困惑。

## 项目默认如何打开

默认情况下，你在 Zed 里打开一个文件夹，它会作为**当前窗口 threads sidebar 里的一个新项目**打开，而不是新开窗口。这样相关工作聚在一起，并保留你的 agent 线程与布局。

| 操作 | 结果 |
|------|------|
| File > Open | 在当前窗口打开（threads sidebar） |
| File > Open Recent | 在当前窗口打开（threads sidebar） |
| 拖拽文件夹到 Zed | 在当前窗口打开（threads sidebar） |
| `zed ~/project` | 在当前窗口打开（threads sidebar） |

## 同时管理多个项目

当有多个项目打开时：

- **点击项目标题**可折叠/展开它的线程；**Ctrl+点击**（macOS `Cmd+点击`）切换到该项目。
- 每个项目有自己的**文件树、Git 状态、搜索范围**。
- Agent 线程与所属项目上下文绑定。
- 你的工作区布局（拆分、标签）**按项目分别保留**。

可以把 threads sidebar 里的项目理解成「浏览器标签页，但对象是代码仓库」。

## 在新窗口打开

有时你确实想要一个完全独立的窗口：

### 从 Open Recent

用 File > Open Recent（`Ctrl+R`）时：

- `Enter` 或点击：在当前窗口打开
- `Ctrl+Enter` 或 `Ctrl+点击`（macOS `Cmd+Enter`）：在**新窗口**打开

### 从 CLI

用 `-n` 强制新窗口：

```sh
zed -n ~/projects/other-project
```

| 参数 | 行为 |
|------|------|
| `-n`, `--new` | 总是在新窗口打开 |
| `-a`, `--add` | 添加到当前窗口的 threads sidebar |
| `-r`, `--reuse` | 替换现有窗口中的当前项目 |

### 通过设置改默认行为

两个设置控制默认打开方式：

```json
{
  "default_open_behavior": "new_window",
  "cli_default_open_behavior": "new_window"
}
```

- `existing_window`（默认）：在当前窗口的 threads sidebar 打开。
- `new_window`：优先新窗口。

`cli_default_open_behavior` 控制 CLI 打开；`default_open_behavior` 控制 UI 打开与外部请求（如 macOS Finder 的「Open With > Zed」）。显式 CLI 参数（如 `-n`）会覆盖设置。

## 向当前项目添加文件夹（多根）

如果你想把某个文件夹加入**当前项目**（而不是作为 threads sidebar 里的独立项目），有几种方式，效果类似 VS Code 的多根工作区：

- **File 菜单**：File > Add Folder to Project
- **Project Panel**：在文件树里右键 → "Add Folders to Project"
- **Open Recent**：选中一个最近项目，点 "Add Folder to this Project"

这会把该文件夹作为当前项目文件树里的一个额外根目录。

## 项目级设置

在项目根目录下放一个 `.zed/settings.json`，即可覆盖全局设置，实现「每个项目一套配置」。例如某项目单独指定格式化器或语言服务器。设置体系详见 [010.settings配置体系](../03.配置与键位自定义/010.settings配置体系.md)。

## Classic 与 Agentic 布局

- **Classic**：编辑器优先的传统布局。
- **Agentic**：把 Threads Sidebar 与 Agent Panel 并排放左侧，适合频繁在多个项目间跑 AI agent 的场景。

切换见标题栏用户菜单的 Panel Layout，或动作 `workspace: use classic layout` / `workspace: use agentic layout`。
