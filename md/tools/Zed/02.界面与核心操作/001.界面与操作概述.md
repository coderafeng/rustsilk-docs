# 概述

Zed 的界面刻意做得「极简、以代码为中心」：辅助面板默认收起，导航主要靠键盘搜索而非鼠标点击文件树。刚上手时你可能一时找不到「熟悉的按钮」，本章帮你把界面各区域、命令面板、窗口/项目模型和核心快捷键一次性理清。

## 一句话心智模型

> **Zed 的一切都是「动作（action）」，一切动作都能从命令面板（`Ctrl+Shift+P`）搜到并执行。**

当你在文档里看到形如 `zed: ...`、`editor: ...`、`workspace: ...` 的命令时，意思都是「到命令面板里搜索并执行它」。记住这一点，你就永远不会在 Zed 里「迷路」。
