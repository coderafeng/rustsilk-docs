# 概述

本章带你完成 Zed 的「从零到能上手」：理解它是什么、为什么快，如何在 Windows / macOS / Linux 上安装与更新，第一次启动看到什么，以及如何从 VS Code、IntelliJ IDEA 等编辑器平滑迁移过来。

Zed 是一款**开源、跨平台、用 Rust 从零编写**的代码编辑器，官方定位是「the editor for what's next」——面向人与 AI 协作的下一代编辑器。它把三件事作为核心卖点：

- **Fast（快）**：纯 Rust 实现，直接使用多核 CPU 与 GPU 渲染，启动、输入、滚动几乎没有可感知延迟。
- **Agentic（智能体原生）**：内置 Agent Panel，可并行运行多个 AI agent 线程，直接改文件、跑命令、导航代码。
- **Collaborative（协作）**：内置实时协作，多人共享项目、光标、语音，无需第三方插件。

## 关键提醒：为什么「复制不是 Ctrl+C」

很多用户第一次装完 Zed 会困惑：默认情况下 Zed 的编辑快捷键自成一套，而一旦在设置里开启 `vim_mode`，编辑器就变成**模态编辑**——普通模式下 `y` 才是复制（yank）、`p` 才是粘贴（put）、`d` 是删除，`Ctrl+C` 反而不再是复制。这是 Zed「Vim-friendly」设计的一部分，并非 bug。详见 [040.Vim 模式](../03.配置与键位自定义/040.Vim模式.md)。
