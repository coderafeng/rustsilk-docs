# 概述

第一次打开 Zed，你会看到一个简洁的**欢迎页（Welcome Page）**。本文带你认识首屏、打开第一个项目、掌握几条最关键的命令，并理解 Zed 的面板布局。

## 欢迎页

当你没有打开任何文件夹时，Zed 会在主编辑区显示欢迎页。欢迎页提供几个快捷动作：打开文件夹、克隆仓库、查看文档。一旦你打开了文件夹或文件，欢迎页就会消失。

如果你把编辑器拆分成多个 pane（窗格），欢迎页只在**中间那个空 pane** 显示，其它 pane 显示标准空状态。

想重新打开欢迎页：关闭中间 pane 里的所有条目，或在命令面板（`Ctrl+Shift+P`）里搜索 "Welcome"。

首次启动时，Zed 通常会引导你做几件事：选择主题、选择键位方案（默认 / VS Code / Atom 等）、是否从 VS Code 导入设置、是否登录账号。

## 1. 打开一个项目

从命令行打开：

```sh
zed ~/projects/my-app
```

或在 Zed 内用 `Ctrl+O`（macOS 为 `Cmd+O`）打开文件夹。

默认情况下，新项目会打开在**当前窗口的 threads sidebar（线程侧边栏）**里，这样你可以在一个窗口内同时处理多个项目而不必来回切窗口。若想在新窗口打开，用 `zed -n ~/projects/my-app`，或在 "Open Recent" 里选中后按 `Cmd+Enter`（macOS）。

> [!note] Zed 没有 workspace 文件
> 与 VS Code 不同，Zed 没有 `.code-workspace` 这种工作区文件概念。**打开一个文件夹，它就是你的项目上下文**。详见 [030.窗口与项目管理](../02.界面与核心操作/030.窗口与项目管理.md)。

## 2. 记住这几条 essential 命令

Zed 的一切动作都能从**命令面板**触达。先记住下面这几条，就能应付 80% 的日常：

| 动作 | Windows / Linux | macOS |
|------|-----------------|-------|
| 命令面板（Command Palette） | `Ctrl+Shift+P` | `Cmd+Shift+P` |
| 跳转到文件（Go to file） | `Ctrl+P` | `Cmd+P` |
| 跳转到符号（Go to symbol） | `Ctrl+Shift+O` | `Cmd+Shift+O` |
| 项目内查找（Find in project） | `Ctrl+Shift+F` | `Cmd+Shift+F` |
| 切换终端（Toggle terminal） | `` Ctrl+` `` | `` Ctrl+` `` |
| 打开设置（Open settings） | `Ctrl+,` | `Cmd+,` |

> [!tip] 忘了快捷键就搜命令面板
> 命令面板（`Ctrl+Shift+P`）是通往 Zed 每一个动作的入口。任何功能忘了快捷键，直接在里面搜英文名即可，搜到的结果还会显示对应按键。

## 3. 配置你的编辑器

用 `Ctrl+,`（macOS `Cmd+,`）打开**设置编辑器（Settings Editor）**，可以直接搜索任意设置项并修改。第一次常见的三项调整：

- **主题（Theme）**：`Ctrl+K Ctrl+T`（macOS `Cmd+K Cmd+T`）打开主题选择器。
- **字体（Font）**：在设置里搜索 `buffer_font_family`。
- **保存时格式化（Format on save）**：搜索 `format_on_save`，设为 `on`。

## 4. 面板布局（Panel Layout）

Zed 提供两种整体布局，可在标题栏的用户菜单里切换，或用命令面板搜索对应动作：

- **Classic（经典布局）**：面向编辑器本身，Project Panel（文件树）在左，是传统开发者的默认选择。动作：`workspace: use classic layout`。
- **Agentic（智能体布局）**：把 Agent Panel 与 Threads Sidebar 并排放在左侧，适合重度使用 AI agent 的人。动作：`workspace: use agentic layout`。

Zed 的界面由若干可折叠的 **dock（停靠区）** 组成：

- **左 dock**：Project Panel（文件树）、Outline Panel（大纲）、Collab Panel（协作）
- **右 dock**：Agent Panel（AI）、Chat Panel
- **底部 dock**：Terminal（终端）

常用切换键：`Ctrl+B` 切换左 dock，`Ctrl+J` 切换底部 dock，`Ctrl+R` 或 `Ctrl+Alt+B` 切换右 dock。详见 [010.界面布局总览](../02.界面与核心操作/010.界面布局总览.md)。

## 5. 试一试 AI

Zed 内置 AI 助手。用 `Ctrl+Shift+A`（macOS `Cmd+Shift+A`）打开 Agent Panel 开始对话，或用 `Ctrl+Enter`（macOS `Cmd+Enter`）在光标处进行内联辅助（Inline Assistant）。AI 的完整用法见 [06.AI与Agent](../06.AI与Agent/001.AI概述.md)。
