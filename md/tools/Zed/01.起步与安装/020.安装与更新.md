# 概述

Zed 支持 macOS、Linux、Windows 三大平台，安装方式非常简单。安装后 Zed 会**自动保持更新**，一般无需手动升级。本文给出各平台的安装命令、系统要求与卸载方法。

## 下载渠道

- 稳定版（Stable）：<https://zed.dev/download>
- 预览版（Preview，比稳定版早约一周收到更新）：<https://zed.dev/releases/preview>
-  nightly（每日构建）：面向尝鲜与开发者

> [!tip] 三条发布通道
> Zed 有 stable / preview / nightly 三条通道。普通用户用 stable 即可；想提前体验新特性可用 preview；参与开发或复现 bug 用 nightly。

## Windows 安装

从[下载页](https://zed.dev/download)获取最新稳定版安装包，或用 winget 安装：

```sh
winget install -e --id ZedIndustries.Zed
```

安装后可在开始菜单找到 Zed，安装程序通常也会把 `zed` 命令加入 PATH，方便在终端里用 `zed .` 打开当前目录。

### Windows 系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 11（22H2 及以后）或 Windows 10（1903 及以后），必须 64 位 |
| 处理器 | x64（Intel/AMD）或 Arm64（Qualcomm） |
| 显卡 | 支持 DirectX 11 的 GPU（2012 年后的大多数 PC） |
| 驱动 | 当前版本的 NVIDIA/AMD/Intel/Qualcomm 驱动（**不能是** Microsoft Basic Display Adapter） |

> [!warning] 虚拟机 / 远程桌面注意
> 如果 Zed 启动即崩溃或黑屏，多半是显卡驱动问题。Zed 依赖 GPU 渲染（DirectX 11），在缺少硬件加速的虚拟机、远程桌面或「Microsoft 基本显示适配器」环境下可能无法正常运行，需安装真实的 GPU 驱动。

## macOS 安装

从[下载页](https://zed.dev/download)下载 `.dmg`，或用 Homebrew：

```sh
# 稳定版
brew install --cask zed

# 预览版
brew install --cask zed@preview
```

### macOS 系统要求

支持 macOS 12（Monterey）及以上；macOS 11（Big Sur）与 10.15（Catalina）为「部分支持」，不支持通过 Zed Collaboration 进行屏幕共享（该功能依赖 macOS 12+ 的 ScreenCaptureKit）。硬件支持 2015 年后的 MacBook Pro/Air、2013 年后的 Mac Pro 等 Intel 与 Apple Silicon 机型。

## Linux 安装

对大多数 Linux 用户，官方安装脚本最简单：

```sh
curl -f https://zed.dev/install.sh | sh
```

可通过环境变量指定版本或通道：

```sh
# 安装指定版本
curl -f https://zed.dev/install.sh | ZED_VERSION=0.216.0 sh

# 安装预览版
curl -f https://zed.dev/install.sh | ZED_CHANNEL=preview sh
```

脚本支持 `x86_64` 与 `AArch64`，覆盖 Ubuntu、Arch、Debian、RedHat、CentOS、Fedora 等常见发行版。

### Linux 系统要求

- 64 位 Intel/AMD（x86_64）或 64 位 Arm（aarch64）处理器
- **Vulkan 1.3** 驱动
- 以下 desktop portals：
  - `org.freedesktop.portal.FileChooser`
  - `org.freedesktop.portal.OpenURI`
  - `org.freedesktop.portal.Secret` 或 `org.freedesktop.Secrets`

## 自动更新

首次手动安装后，Zed 会**定期检查并自动安装更新**，你通常什么都不用做。该行为可在设置中调整（见 `auto_update` 相关设置）。若想手动检查，可在命令面板（`Ctrl+Shift+P`）搜索 `zed: check for updates`。

## 卸载

- **Linux（脚本安装）**：运行 `zed --uninstall`，脚本会询问是否保留你的偏好设置（settings、keymap 等），选择后即完成卸载。
- **Windows**：通过「设置 → 应用」或 winget（`winget uninstall ZedIndustries.Zed`）卸载。
- **macOS**：把 Zed 拖入废纸篓；如需彻底清理，删除配置目录（见下）。

### 配置文件位置

卸载后若想彻底清理，或想在多台机器间同步配置，需要知道 Zed 的配置目录：

| 平台 | 配置目录 |
|------|----------|
| macOS | `~/.config/zed/` |
| Linux | `~/.config/zed/` |
| Windows | `%LOCALAPPDATA%\Zed\` 或 `%APPDATA%\Zed\`（`settings.json`、`keymap.json` 等） |

其中主要有 `settings.json`（设置）、`keymap.json`（键位）、`tasks.json`（任务）、`snippets/`（片段）等。详见 [03.配置与键位自定义](../03.配置与键位自定义/001.配置概述.md)。

## 命令行工具 zed

安装后终端里可用的 `zed` 命令常用姿势：

```sh
zed .                      # 用 Zed 打开当前目录
zed ~/projects/my-app      # 打开指定项目
zed -n ~/projects/my-app   # 在新窗口打开
zed file1.rs file2.rs      # 打开若干文件
```

更多 CLI 参数见 [050.故障排查与CLI](../08.协作远程与参考/050.故障排查与CLI.md)。
