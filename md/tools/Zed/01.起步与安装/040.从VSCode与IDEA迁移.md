# 概述

Zed 官方为从其它编辑器迁移的用户提供了专门的指南。本文以 **VS Code** 为主、兼顾 **IntelliJ IDEA / JetBrains 系**，讲清楚：哪些设置能自动导入、快捷键如何对照、UI 差异在哪、以及迁移的推荐路径。

官方迁移指南：

- [VS Code](https://zed.dev/docs/migrate/vs-code)
- [IntelliJ IDEA](https://zed.dev/docs/migrate/intellij)
- [PyCharm](https://zed.dev/docs/migrate/pycharm)
- [WebStorm](https://zed.dev/docs/migrate/webstorm)
- [RustRover](https://zed.dev/docs/migrate/rustrover)

## 从 VS Code 导入设置

首次启动的引导流程里有 **Import Settings from VS Code** 选项；如果当时跳过了，之后仍可通过命令面板手动导入：

```
Ctrl+Shift+P → zed: import vs code settings
```

Zed 会自动映射大量编辑器设置，例如：

| VS Code 设置 | Zed 设置 |
|--------------|----------|
| `editor.fontFamily` | `buffer_font_family` |
| `editor.fontSize` | `buffer_font_size` |
| `editor.tabSize` | `tab_size` |
| `editor.insertSpaces` | `hard_tabs`（取反） |
| `editor.wordWrap` | `soft_wrap` |
| `editor.cursorStyle` | `cursor_shape` |
| `editor.minimap.enabled` | `minimap.show` |
| `editor.formatOnSave` | `format_on_save` |
| `editor.inlineSuggest.enabled` | `show_edit_predictions` |
| `files.autoSave` | `autosave` |
| `terminal.integrated.fontFamily` | `terminal.font_family` |
| `mcp` | `context_servers` |

> [!warning] 导入不包含扩展和键位
> Zed **不会**导入 VS Code 的扩展和 keybindings，只导入核心编辑器行为设置。扩展需要在 Zed 里重新安装（见 [07.扩展与语言支持](../07.扩展与语言支持/001.扩展概述.md)），键位需要手动配置或选用 VS Code keymap。

## 快捷键对照

如果在引导时选择了 **VS Code keymap**，大部分快捷键会立刻变得熟悉。以下是默认键位下的对照（macOS 键位，Windows/Linux 把 `Cmd` 换成 `Ctrl`、`Opt` 换成 `Alt`）。

### Zed 与 VS Code 相同的键位

| 动作 | 快捷键 |
|------|--------|
| 查找文件 | `Cmd+P` |
| 运行命令 | `Cmd+Shift+P` |
| 项目内搜索文本 | `Cmd+Shift+F` |
| 项目内查找符号 | `Cmd+T` |
| 文件内查找符号 | `Cmd+Shift+O` |
| 切换左侧 dock | `Cmd+B` |
| 切换底部 dock | `Cmd+J` |
| 打开终端 | `` Ctrl+` `` |
| 打开文件树 | `Cmd+Shift+E` |
| 关闭当前 buffer | `Cmd+W` |
| 重命名符号 | `F2` |
| 切换主题 | `Cmd+K` `Cmd+T` |

### Zed 与 VS Code 不同的键位

| 动作 | VS Code | Zed |
|------|---------|-----|
| 打开最近项目 | `Ctrl+R` | `Cmd+Alt+O` |
| 上下移动整行 | `Alt+↑/↓` | `Cmd+Ctrl+↑/↓` |
| 拆分窗格 | `Cmd+\` | `Cmd+K` 然后方向键 |
| 扩大选区 | `Shift+Alt+→` | `Alt+↑` |

### Zed 独有的键位

| 动作 | 快捷键 | 说明 |
|------|--------|------|
| 切换右侧 dock | `Cmd+R` 或 `Cmd+Alt+B` | |
| 语法选择 | `Alt+↑/↓` | 按代码结构选择（如花括号内部），依赖 Tree-sitter |

> [!note] Zed 也支持组合键（chord）
> 和 VS Code 一样，Zed 支持多键序列，如 `Cmd+K Cmd+C`。自定义键位见 [030.键位绑定Keybindings](../03.配置与键位自定义/030.键位绑定Keybindings.md)。

## 从 IntelliJ IDEA / JetBrains 迁移

JetBrains 系用户迁移时，最大的心智转变是**导航与重构的方式**：

- **导航以键盘搜索为中心**：IDEA 里你可能习惯左侧常驻的 Project 面板双击浏览；Zed 更鼓励用 `Ctrl+P` 模糊找文件、`Ctrl+Shift+O` 跳符号、`Ctrl+T` 全局找符号，Project Panel 只是可选辅助。
- **重构通过 LSP**：重命名（`F2`）、查找引用、code action 等能力来自语言服务器，覆盖面取决于对应语言的 LSP，而非 IDEA 那种深度内建索引。
- **没有 IDEA 的「一切皆对话框」**：Zed 的入口是命令面板（`Ctrl+Shift+P`），把 IDEA 的 Find Action（`Ctrl+Shift+A`）换成它即可。
- **可启用熟悉键位**：JetBrains 用户若离不开 IDEA 键位，可在 keymap 里自定义，或直接启用 Vim 模式获得高效的模态编辑。

## UI 与理念差异小结

| 维度 | VS Code / IDEA | Zed |
|------|----------------|-----|
| 项目模型 | Workspace / 多根工作区文件 | 打开文件夹即项目；可 Add Folder to Project 增加根 |
| 多项目 | 多窗口 | 单窗口内多项目（threads sidebar 切换） |
| 项目级设置 | `.vscode/settings.json` | `.zed/settings.json`（可选） |
| 导航中心 | 常驻侧边栏文件树 | 命令面板 + File Finder 为主，文件树为辅 |
| 扩展生态 | 庞大 | 精简，很多能力内置（协作/AI/终端/搜索/任务） |

## 迁移推荐路径

1. 安装 Zed，首次引导时**选择 VS Code keymap** 并执行 **Import Settings from VS Code**。
2. 打开一个真实项目，用 `Ctrl+P` / `Ctrl+Shift+O` / `Ctrl+Shift+F` 熟悉键盘导航。
3. 安装你主力语言的扩展（`Ctrl+Shift+X`）。
4. 按需微调 `settings.json`（字体、format on save、主题）。
5. 如果你本就是 Vim 用户，考虑直接开 `vim_mode`，见 [040.Vim模式](../03.配置与键位自定义/040.Vim模式.md)。
6. 配置 AI：把 Copilot / Claude 等接入，见 [06.AI与Agent](../06.AI与Agent/001.AI概述.md)。
