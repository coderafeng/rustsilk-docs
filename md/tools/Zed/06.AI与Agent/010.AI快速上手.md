# 概述

本页帮你在 Zed 里**选对 AI 配置路径**并快速跑起来。Zed 的 AI 配置分几件事：用哪个 agent、用哪些模型、开哪些功能。理清这几件事，就不会在设置里迷路。

## 第一步：决定用哪种 agent

| 你的需求 | 选择 |
|----------|------|
| 让 Zed 原生 agent 读、改、搜、跑你项目的代码 | **Zed Agent**（在 Agent Panel 里用） |
| 接入 Claude / Codex / OpenCode / Copilot / Cursor / Gemini CLI 等，且它支持 ACP | **External Agents** |
| agent 以 CLI / TUI 形式运行 | **Terminal Threads** |

> [!note] 本笔记聚焦 Zed Agent
> External Agents 与 Terminal Threads 通常自带认证、模型、订阅、工具、instructions 与 MCP 配置，Zed 只是宿主。本章后续文档以 **Zed Agent** 为主。

## 第二步：为 Zed Agent 配置模型

Zed Agent 与其它模型驱动的 Zed AI 功能，使用通过 **LLM Providers** 配置的模型。按你的情况选一条路径：

| 你的情况 | 路径 |
|----------|------|
| 想用由 Zed 计费的托管模型 | Zed-Hosted Models（登录 Zed 账号） |
| 自带 provider API key / 额度 / 用量计费 | Use API Access |
| 已付费订阅 ChatGPT / Claude / Copilot 等 | Use an Existing Subscription |
| 走 OpenRouter / Vercel AI Gateway / Amazon Bedrock 等网关 | Use a Gateway |
| 用 Ollama / LM Studio / 本地 OpenAI 兼容服务 / 自托管模型 | Use a Local Model |

> [!important] API key 存哪
> 通过 Zed 保存的 provider key 存放在**系统 keychain**（Windows 凭据管理器 / macOS 钥匙串），**不在** `settings.json` 里。详见 [060.LLMProviders与本地模型](./060.LLMProviders与本地模型.md)。

最省事的入门方式是**登录 Zed 账号**使用 Zed-Hosted Models：无需自己管理各家 API key，开箱即用（Edit Prediction 的 Zeta 也需要登录）。

## 第三步：按需配置 agent 能力

| 你想做什么 | 用哪个 |
|------------|--------|
| 控制工具与权限 | Agent Profiles |
| 逐个批准/拒绝工具 | Tool Permissions |
| 添加可复用的任务指令 | [Skills](./040.Skills与Instructions.md) |
| 添加常驻的个人/项目上下文 | [Instructions](./040.Skills与Instructions.md) |
| 连接外部工具与上下文 | [MCP servers](./030.MCP服务器.md) |

## AI 设置入口

Zed 把 AI 设置分散在三处，记住对应动作就不乱：

| 你想做什么 | 去哪 |
|------------|------|
| 配置 LLM providers、External Agents、MCP servers | `agent: open settings`（Settings → AI） |
| 关闭 AI、配置工具权限、设置 edit prediction provider | Settings Editor（`zed: open settings`，`Ctrl+,`） |
| 编辑仅 JSON 的高级设置 | `zed: open settings file` |

## 具体功能入口速查

| 你想做什么 | 用哪个 | 快捷键 |
|------------|--------|--------|
| 提示 agent、加上下文、审阅改动 | Agent Panel | `Ctrl+Shift+A`（macOS `Cmd+Shift+A`） |
| 打字时接受 AI 补全 | Edit Prediction | `Tab` / `Alt+Tab` |
| 改写选中代码或终端文本 | Inline Assistant | `Ctrl+Enter` |
| 同时跑多个 AI 任务 | Parallel Agents（Threads Sidebar） | `Ctrl+Alt+J` |
| 生成提交信息 | Git commit generation | `Alt+L`（见 [050.Git集成](../05.运行调试与Git/050.Git集成.md)） |

## 关闭 AI

如果想完全不用 AI，在 Settings Editor（`zed: open settings`）搜索 `Disable AI` 并启用，或在设置文件里加：

```jsonc
{ "disable_ai": true }
```

关闭后所有 AI 功能都会禁用，包括 Threads Sidebar、Agent Panel、Edit Prediction、Inline Assistant。

> [!tip] 只想关掉某一部分？
> 不想全关，可分别控制：Edit Prediction 设 `"edit_predictions": { "provider": "none" }`；不想让 agent 自动跑工具，把 `agent.tool_permissions.default` 设为 `"confirm"` 或 `"deny"`。详见 [050](./050.InlineAssistant与EditPrediction.md) 与 [070](./070.AI隐私与安全.md)。

## 首次上手最短路径

1. 登录 Zed 账号（启用 Zed-Hosted Models 与 Zeta）。
2. `Ctrl+Shift+A` 打开 Agent Panel，输入一句需求，回车。
3. agent 提出改动后，点 **Review Changes**（`Ctrl+Shift+R`）逐个 hunk 接受/拒绝。
4. 打字时留意灰色的 Edit Prediction，`Tab` 接受。
5. 选中一段代码 `Ctrl+Enter`，用 Inline Assistant 改写。
