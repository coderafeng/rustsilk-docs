# 概述

本页说明 Zed AI 功能的隐私与信任边界，覆盖 Zed Agent、Edit Prediction、Inline Assistant、Git 提交信息生成。

> [!important] 一句话结论
> **Zed 默认不保留你的 prompt 或代码上下文。** 只有当你显式分享反馈或选择加入训练数据收集时，Zed 才会保留 AI 数据。

## AI 请求路径与经手方

不同的模型访问路径，请求由谁处理、适用什么条款各不相同：

| 路径 | 谁处理模型请求 | 要点 |
|------|----------------|------|
| **Zed-Hosted Models** | Zed 路由到托管 provider | provider 协议禁止用你的 prompt/代码训练，并要求推理请求零数据保留（除指定的安全保留模型） |
| **Provider API keys** | 你配置的 provider | provider 按其条款处理；经 Zed 保存的 key 存系统 keychain，不在 settings.json |
| **Existing subscriptions** | 订阅 provider | 按订阅条款处理 |
| **Gateways** | 网关及上游 provider | 按网关与上游各自条款处理 |
| **Local models** | 本地/自托管端点 | 按你配置该服务器的方式处理，数据不出本机 |
| **External Agents** | 该 agent 及其 provider | 按 agent 自身条款；工具与 MCP 行为取决于 agent 与 ACP 配置 |
| **Terminal Threads** | 终端里运行的 CLI/TUI | CLI/TUI 自持认证、模型路由、工具、指令、MCP 与数据处理 |
| **Edit Prediction** | 所选预测 provider | 每次按键可能把本地编辑上下文发给 provider；Zeta 请求瞬时处理（除非开启训练数据收集），第三方按其条款 |
| **Agent 工具 / MCP / 集成** | Zed、配置的 MCP servers、外部系统 | 工具可依 profile、MCP server、权限设置读取、编辑、搜索、跑命令、抓 URL、调外部系统 |
| **项目信任与指令** | Zed 与受信任 worktree | 项目本地指令与技能从受信任 worktree 加载 |

## Zed 托管模型的承诺

对 Zed-Hosted Models，Zed 有来自模型 provider 的承诺：**禁止**用你的 prompt 或代码上下文训练，并对推理请求要求**零数据保留**——除下列「安全保留」的指定模型外。

| Provider | 不训练 | 零数据保留 |
|----------|--------|------------|
| Anthropic | 是 | 是（covered models 除外） |
| Google | 是 | 是 |
| OpenAI | 是 | 是 |

### 指定模型的 Provider 安全保留

某些 provider 把「有限数据保留」作为提供特定模型的条件，在其提供这些模型的**所有平台**上都适用。例如 Anthropic 对其 designated 的 Covered Models 会保留 prompt 与输出**至少 30 天**用于信任与安全，Zed 无法退出——它随这些模型在任何地方被提供时都适用。

对这些模型：

- **不训练承诺仍然适用**，保留数据用于安全审查而非模型训练。
- **Zed 不保留**你的 prompt 或输出，保留发生在 provider 侧，遵循其访问控制与删除时限。
- 其余所有 Zed 托管模型仍保持零数据保留。

> [!warning] 换 key 也躲不开 covered models 的保留
> 若不想要 provider 侧保留，请选未被指定为安全保留的模型。对 covered models，改用你自己的 API key 或订阅**并不能**规避该保留，因为 provider 在提供这些模型的每个平台都施加它。

## Zed 保留的 AI 数据

Zed 仅在你**显式分享或选择加入**时才保留 AI 数据：

- **响应评分与反馈**：会把对话线程发给 Zed 供审查改进。
- **Edit Prediction 训练数据**：仅当你选择加入、项目为开源、且文件未被排除时才收集。

> [!important] 不想被收集就别评分
> 给 AI 响应点赞/点踩会上传整个对话线程（你的消息、AI 响应、元数据）。**若不希望数据存到 Zed 服务器，就不要评分。** Zed 不会在你未显式评分时收集数据用于改进 agent。

## 工具权限即隐私控制

Agent 的工具能读文件、改文件、跑命令、抓 URL、调外部系统——这既是能力也是风险面。用两道闸门控制：

- **Agent Profiles**：决定线程里哪些内置工具与 MCP 工具可用。
- **Tool Permissions**：`agent.tool_permissions.default` 设 `"confirm"`（默认，逐个批准）/ `"allow"` / `"deny"`。

对不受信任的项目，保持 `confirm` 并留意项目本地 [Skills 与 Instructions 的信任机制](./040.Skills与Instructions.md#skills-存放位置)——项目本地技能只从受信任 worktree 加载，防止恶意项目在你审阅前注入指令。

## 追求最大隐私的实操建议

1. 不想让任何代码离开本机 → 用 **Local Model**（Ollama / LM Studio / 本地 OpenAI 兼容服务）。
2. 用托管模型但介意保留 → 避开 provider 的 covered/safety-retention 模型，选零保留模型。
3. 绝不上传对话 → **不要给响应评分**，不主动开启 Edit Prediction 训练数据收集。
4. 控制 agent 能碰什么 → Tool Permissions 设 `confirm`，用 Agent Profiles 收窄工具集。
5. 彻底不用 AI → `disable_ai: true`。
