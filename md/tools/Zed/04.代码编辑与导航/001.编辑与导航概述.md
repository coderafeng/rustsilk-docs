# 概述

Zed 的编辑能力由三套机制协同：**语言服务器（LSP）** 提供补全、诊断、重构；**Edit Prediction（编辑预测）** 在你输入时给出多字符/多行建议；**Multibuffers（多缓冲）** 让你在一个可编辑视图里同时改多个文件。配合多光标，跨文件重构会非常高效。

## 它们如何协同

一次典型的重构流程：

1. 用语言服务器的 rename 重构重命名一个函数（`F2`）。
2. 在 Multibuffer 里查看所有受影响的文件。
3. 用多光标在所有位置做额外修改。
4. 立即获得诊断反馈，若破坏了对应报错。
