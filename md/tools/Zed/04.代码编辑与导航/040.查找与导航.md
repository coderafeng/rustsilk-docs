# 概述

Zed 提供多种在代码库中快速移动的方式。它的导航哲学是「**键盘搜索优先**」：File Finder 找文件、Project Search 找文本、Go to Symbol 找符号、Go to Definition 跳定义。

## 快速参考

| 任务 | Windows / Linux | macOS | Vim 模式 |
|------|-----------------|-------|----------|
| 命令面板 | `Ctrl+Shift+P` | `Cmd+Shift+P` | `:` |
| File Finder（打开文件） | `Ctrl+P` | `Cmd+P` | — |
| Project Search（全项目搜索） | `Ctrl+Shift+F` | `Cmd+Shift+F` | `g /` |
| Text Finder（快速文本查找） | `Ctrl+Alt+F` | `Alt+Cmd+F` | — |
| 跳转到定义 | `F12` | `F12` | `g d` |
| 查找引用 | `Alt+Shift+F12` | `Alt+Shift+F12` | `g A` |
| 文件内查找符号 | `Ctrl+Shift+O` | `Cmd+Shift+O` | `g s` |
| 项目内查找符号 | `Ctrl+T` | `Cmd+T` | `g S` |
| Outline Panel | `Ctrl+Shift+B` | `Cmd+Shift+B` | — |
| Project Panel | `Ctrl+Shift+E` | `Cmd+Shift+E` | `:E` |
| Tab Switcher | `Ctrl+Tab`（按住连按） | `Ctrl+Tab` | — |

## File Finder（文件查找器）

`Ctrl+P` 打开，输入文件名或路径的一部分即可模糊匹配。它是打开文件最快的方式。File Finder 也能跳到符号与命令。

## Project Search（项目搜索）

`Ctrl+Shift+F` 打开，跨所有文件搜索文本。回车执行搜索，结果以 **Multibuffer** 呈现——每个匹配行一个 excerpt，可**就地编辑**所有匹配，非常适合批量重命名文本。支持正则、大小写敏感、按文件过滤等选项。

## Text Finder（快速文本查找）

`Ctrl+Alt+F`（macOS `Alt+Cmd+F`）在项目中快速查找任意字符串并打开文件。若需要带过滤器的详细搜索，可通过右下角 Actions 菜单切换到 Project Search。

## Go to Definition（跳转定义）

- `F12`，或 `Ctrl+点击`（macOS `Cmd+点击`）符号跳转到定义。
- 若有多个定义，它们会在一个 Multibuffer 里打开。
- 相关：`editor: go to type definition`、`editor: go to implementation`（Vim 模式 `g y`、`g I`）。
- 「查看定义」（peek，不离开当前文件）：`Alt+F12`。

## Go to Symbol（符号跳转）

- **当前文件**：`Ctrl+Shift+O` 打开当前文件符号大纲。
- **整个项目**：`Ctrl+T` 跨所有文件搜索符号。

## Call Hierarchy（调用层级）

光标停在函数上：

- `call hierarchy: show incoming calls`（`Ctrl+K Ctrl+H`）：列出调用它的函数。
- `call hierarchy: show outgoing calls`：列出它调用的函数。

选择条目跳到调用点；picker 打开时可用 `call hierarchy: toggle direction` 切换 callers/callees，`menu: select child` 深入一层，`menu: select parent` 回上一层。需要语言服务器支持 call hierarchy。

## 导航历史（后退 / 前进）

在跳转之间来回：

- Windows / Linux：`Alt+←` / `Alt+→`
- macOS：`Ctrl+-` / `Ctrl+Shift+-`

## Tab Switcher（标签切换器）

`Ctrl+Tab` 打开，标签按最近使用排序。按住 `Ctrl` 连续按 `Tab` 在列表中循环，松开即切换。

## Outline Panel（大纲面板）

`Ctrl+Shift+B` 打开，持久显示当前文件的符号树，配合 Multibuffer 浏览搜索结果或诊断时尤其有用。详见 [050.大纲面板与项目面板](./050.大纲面板与项目面板.md)。
