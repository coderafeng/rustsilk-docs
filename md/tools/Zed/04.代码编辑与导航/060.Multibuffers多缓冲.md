# 概述

**Multibuffer（多缓冲）** 是 Zed 的一项「超能力」：把来自代码库不同位置的多段内容（excerpt）组合进**同一个可编辑视图**。配合多光标，能让大范围的跨文件重构快得惊人。

## 什么是 Multibuffer

普通编辑器一次只编辑一个文件；Multibuffer 则把多个文件（或同一文件的多处）的片段并列在一个 buffer 里，你可以像编辑普通文件一样**直接在其中修改**，改动会实时反映到编辑器里打开的对应文件副本。

Multibuffer 常见于以下场景：

- **Project Search 结果**：`Ctrl+Shift+F`（Vim `g /`）搜索后，每个匹配行成为一个 excerpt。
- **诊断面板**：`Ctrl+Shift+M`（Vim `:clist`）列出全项目错误。
- **查找所有引用**：`Ctrl+点击` / `Alt+Shift+F12`（Vim `g A`）。
- **多定义的跳转**：`editor: go to definition` 有多个结果时。

## 在 Multibuffer 中编辑

编辑方式与普通文件完全一样：

1. 用**多光标**同时编辑多个 excerpt。
   - 鼠标选择：`Alt+点击`（macOS `Option+点击`）加光标。
   - 键盘：`Ctrl+D`（Vim `g l`）选中光标处单词的下一个匹配。
   - 选中全部匹配：命令 `editor: select all matches`（`Ctrl+Shift+L`，Vim `g a`）。
2. 保存全部：`workspace: save`（`Ctrl+S`，Vim `:w`）会保存 Multibuffer 涉及的所有文件。

这就是「一次搜索 → 全选匹配 → 一起改 → 一键保存」的跨文件重构流程。

## 跳转回源文件

虽然在 Multibuffer 里编辑很方便，但有时需要回到源文件查看完整上下文：

- **点击任意 excerpt 之间的分隔线**，或
- 光标置于某 excerpt 内，执行 `editor: open excerpts`。

若使用多光标，该命令会打开每个光标所在的源文件。

想让**双击 excerpt** 直接打开源文件，可设置：

```jsonc
{ "double_click_in_multibuffer": "open" }
```

## 典型工作流：全局重命名一个标识符

1. `Ctrl+Shift+F` 搜索旧名字。
2. 在结果 Multibuffer 里，选中一个匹配，`Ctrl+Shift+L` 选中所有匹配。
3. 输入新名字，所有 excerpt 同步更新。
4. `Ctrl+S` 保存全部。
5. 查看诊断面板确认没有引入错误。

> [!note] 优先用 LSP rename
> 如果语言服务器支持，重命名符号优先用 `F2`（rename），它基于语义而非文本匹配，更准确、不会误伤同名字符串。Multibuffer 的文本批改更适合非符号场景或 LSP 不覆盖的情况。
