# 概述

本文覆盖 Zed 日常编辑的核心操作：基础编辑、多光标、语法结构化选择、代码折叠、code action 与重构。快捷键以 Windows / Linux 为主，括号为 macOS。

## 基础编辑

| 操作 | Windows / Linux | macOS |
|------|-----------------|-------|
| 复制 / 剪切 / 粘贴 | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | `Cmd+C` / `Cmd+X` / `Cmd+V` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Shift+Z` | `Cmd+Z` / `Cmd+Shift+Z` |
| 保存 | `Ctrl+S` | `Cmd+S` |
| 行内查找 | `Ctrl+F` | `Cmd+F` |
| 行内查找替换 | `Ctrl+H` | `Cmd+Alt+F` |
| 上下移动整行 | `Ctrl+Alt+↑/↓` | `Cmd+Ctrl+↑/↓` |
| 复制整行到下方 | `Ctrl+Shift+D` | `Cmd+Shift+D` |
| 删除整行 | `Ctrl+Shift+K` | `Cmd+Shift+K` |
| 切换行注释 | `Ctrl+/` | `Cmd+/` |
| 格式化文档 | 命令面板 `editor: format` | 同左 |
| 切换软换行 | `Alt+Z` | `Opt+Z` |

## 多光标（Multi-cursor）

多光标是 Zed 的强力特性，可在多处同时输入/编辑。

| 操作 | Windows / Linux | macOS | Vim 模式 |
|------|-----------------|-------|----------|
| 选中下一个相同词（加光标） | `Ctrl+D` | `Cmd+D` | `g l` |
| 选中所有相同匹配 | `Ctrl+Shift+L` | `Cmd+Shift+L` | `g a` |
| 鼠标添加光标 | `Alt+点击` | `Option+点击` | — |
| 撤销上一次光标操作 | `Ctrl+U`（或命令面板 `editor: undo selection`） | 同左 | — |

> [!note] 多光标修饰键
> 设置项 `multi_cursor_modifier` 决定用 `Alt` 还是 `Cmd/Ctrl` 点击添加光标。默认 `alt`。

典型用法：选中一个变量名，连按 `Ctrl+D` 逐个把相同词加入选区，然后一起改名；或 `Ctrl+Shift+L` 一次选中全部。

## 语法结构化选择（Tree-sitter）

Zed 借助 Tree-sitter 理解代码结构，可「按语法块」扩大/缩小选区，而不是简单按词：

| 操作 | Windows / Linux | macOS |
|------|-----------------|-------|
| 扩大选区到更大语法节点 | `Alt+↑`（或 `Ctrl+→` 视 keymap） | `Alt+↑` |
| 缩小选区 | `Alt+↓` | `Alt+↓` |

例如把光标放在函数体里，反复按 `Alt+↑` 会依次选中语句块 → 整个函数体 → 整个函数定义。这依赖语言扩展提供的 Tree-sitter 语法。

## 代码折叠

| 操作 | Windows / Linux | macOS |
|------|-----------------|-------|
| 折叠当前块 | `Ctrl+Alt+{`（或命令面板 `editor: fold`） | `Cmd+Opt+{` |
| 展开当前块 | `Ctrl+Alt+}` | `Cmd+Opt+}` |
| 折叠/展开全部 | 命令面板 `editor: fold all` / `unfold all` | 同左 |

也可点击行号旁 gutter 里的折叠箭头（由 `gutter.folds` 设置控制）。

## Code Action 与快速修复

当语言服务器提供 code action（如「导入缺失的包」「提取变量」「添加缺失的实现」）时，行号旁会出现灯泡提示：

- 触发：`Ctrl+.`（macOS `Cmd+.`），或命令面板 `editor: toggle code actions`，或点击灯泡。
- 弹出的菜单列出当前上下文可用的所有动作，回车执行。

## 重构（Refactoring）

主要重构能力来自 LSP：

| 操作 | 快捷键 |
|------|--------|
| 重命名符号（rename） | `F2` |
| 查找所有引用 | `Alt+Shift+F12`（或 `Ctrl+点击`） |
| 跳转到定义 | `F12` |
| 格式化 | 命令面板 `editor: format` |

重命名（`F2`）会跨文件更新所有引用，结果常以 Multibuffer 呈现，可进一步用多光标微调，见 [060.Multibuffers多缓冲](./060.Multibuffers多缓冲.md)。

> [!note] 重构深度取决于语言服务器
> Zed 本身不内建语言索引，重构能力（rename、extract、inline 等）由对应语言的 LSP 提供，覆盖度因语言而异。

## 自动格式化与保存行为

在 `settings.json` 里控制：

```jsonc
{
  "format_on_save": "on",              // 保存时自动格式化
  "remove_trailing_whitespace_on_save": true,
  "ensure_final_newline_on_save": true
}
```

`format_on_save` 也可设为 `"language_server"` 或指定外部格式化器。详见 [020.语言支持配置](../07.扩展与语言支持/020.语言支持配置.md)。
