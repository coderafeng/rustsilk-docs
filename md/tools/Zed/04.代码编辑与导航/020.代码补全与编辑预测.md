# 概述

Zed 的补全来自两个来源：**语言服务器（LSP）提供的 Code Completions**，以及 **Edit Predictions（编辑预测）**——后者由 Zed 自研的开源开放数据模型 **Zeta** 或外部 provider（如 GitHub Copilot）提供。

## 语言服务器补全（Code Completions）

当有可用的语言服务器时，Zed 会自动补全当前文件里的变量名、函数、符号等。

- **手动触发**：`Ctrl+Space`，或命令面板 `editor: show completions`。
- **输入时自动弹出**：由设置 `show_completions_on_input` 控制。

```jsonc
{ "show_completions_on_input": false }  // 关闭输入时自动补全
```

> [!note] macOS 上 Ctrl+Space 冲突
> 在 macOS 使用 `Ctrl+Space` 需要关闭系统全局快捷键：**System Settings > Keyboard > Keyboard Shortcuts > Input Sources**，取消勾选 "Select the previous input source"。

### 相关补全设置

| 设置项 | 作用 |
|--------|------|
| `show_completions_on_input` | 输入时是否自动显示补全 |
| `completions.words` | 是否把当前文档的词纳入补全 |
| `auto_signature_help` | 是否自动显示函数签名提示 |
| `show_completion_documentation` | 补全列表是否显示文档 |

## Edit Predictions（编辑预测）

Edit Prediction 是 Zed 的 AI 补全，能预测**多字符乃至多行**的修改，在你输入时以灰色幽灵文本出现，多数情况下按 `Tab` 接受。

- 内置模型：**Zeta**（Zed 开源开放数据模型，托管在 [Hugging Face](https://huggingface.co/zed-industries/zeta)）。
- 也支持 **GitHub Copilot**、Codestral、Mercury Coder 等外部 provider。

### 开启与配置

在设置编辑器（`Ctrl+,`）里进入 **AI → Edit Predictions**，或在 `settings.json`：

```jsonc
{
  "show_edit_predictions": true,
  "features": {
    "edit_prediction_provider": "zed"   // 或 "copilot" / "none" 等
  }
}
```

配置 GitHub Copilot：

1. `Ctrl+,` 打开设置，进入 **AI → Edit Predictions**。
2. 在 "Configure Providers" 旁点 **Configure**。
3. 在 **GitHub Copilot** 下点 **Sign in to GitHub**，完成授权后即可用。

Edit Prediction 的完整设置、隐私与本地模型方案见 [050.InlineAssistant与EditPrediction](../06.AI与Agent/050.InlineAssistant与EditPrediction.md)。

## 补全 vs 编辑预测：区别

| 维度 | Code Completions（LSP） | Edit Predictions（AI） |
|------|------------------------|------------------------|
| 来源 | 语言服务器 | Zeta / Copilot 等模型 |
| 内容 | 符号名、API、成员 | 多字符/多行的下一步编辑 |
| 触发 | 输入或 `Ctrl+Space` | 输入时自动出现幽灵文本 |
| 接受 | 从列表选择 | 按 `Tab` |
| 联网 | 否（本地 LSP） | 取决于 provider |

两者可同时启用、互补使用。
