# 概述

Snippets（代码片段）让你把常用的代码模板一键插入，支持 tab stop、占位符与变量。Zed 的 snippet 采用与 VS Code 兼容的 JSON 格式，因此你可以把 VS Code 的 snippet 直接拷过来用。

## 创建与位置

- 用命令面板 `snippets: configure snippets` 为指定 scope 创建或编辑 snippet 文件。
- snippet 存放在 `~/.config/zed/snippets` 目录，可用 `snippets: open folder` 打开该目录。

## 示例配置

```jsonc
{
  // 每个 snippet 必须有 name 和 body；prefix 与 description 可选。
  // prefix 用于触发 snippet，省略时用 name 触发。
  // 用 $1、$2 或 ${1:defaultValue} 定义 tab stop。
  // $0 决定最终光标位置。
  // 相同编号的占位符是联动的。
  // 若 snippet 里有非占位符的 $ 符号，需用两个反斜杠转义（如 \\$var）。
  "Log to console": {
    "prefix": "log",
    "body": ["console.info(\"Hello, ${1:World}!\")", "$0"],
    "description": "Logs to console"
  }
}
```

## 使用

在对应语言的 buffer 里输入 snippet 的 `prefix`（如 `log`），补全列表会出现该 snippet，选择后展开，光标落在第一个 tab stop（`$1`）。按 `Tab` 在各 tab stop 间跳转，`$0` 是结束位置。

## Tab Stop 与占位符语法

| 语法 | 含义 |
|------|------|
| `$1`、`$2` … | tab stop，按 `Tab` 依次跳转 |
| `${1:defaultValue}` | 带默认值的占位符 |
| `$0` | 最终光标位置 |
| 相同编号（如两处 `$1`） | 联动，一处改多处同步 |
| `\\$` | 转义字面 `$` |

## Scopes（作用域）

scope 由**语言名小写**决定文件名，例如 Python 用 `python.json`、Shell Script 用 `shell script.json`。几个例外：

| Scope | 文件名 |
|-------|--------|
| Global（全局，所有语言可用） | `snippets.json` |
| JSX | `javascript.json` |
| Plain Text | `plaintext.json` |

> [!note] JSX 的特殊之处
> 创建 JSX snippet 要用 `javascript.json` 而不是 `jsx.json`；但 TSX 与 TypeScript 遵循常规规则（`tsx.json` / `typescript.json`）。

文件名里的路径分隔符（`/` 和 `\`）会被移除，因此名为 `PL/X` 的语言使用 `plx.json`。

## 已知限制

- 传入 prefix 列表时，只使用第一个 prefix。
- 目前只支持 `json` 格式的 snippet 文件。

## 从 VS Code 迁移 snippet

直接把 VS Code 的 snippet JSON 内容拷进 Zed 对应 scope 的文件即可（格式兼容）。用 `snippets: configure snippets` 打开对应文件粘贴。
