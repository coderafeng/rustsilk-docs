# 概述

Zed 的诊断（diagnostics）来自语言服务器，兼容 LSP 的 push 与 pull 两种模式，因此支持所有现存语言服务器。诊断包括错误（error）、警告（warning）、信息（info）、提示（hint）四级。

## 诊断的显示位置

默认情况下，Zed 在**编辑器内以下划线**标注诊断，并在**滚动条**上用色块标出位置。

- **悬停**任意诊断可查看完整、渲染后的诊断消息。
- **在诊断间跳转**：`editor: go to diagnostic` / `editor: go to previous diagnostic`（Vim 模式 `] d` / `[ d`），跳转时会弹出当前诊断的 popover。

## 诊断面板（Diagnostics Panel）

打开全项目诊断列表：

- 点击状态栏上的诊断图标，或
- 命令面板 `diagnostics: deploy`（`Ctrl+Shift+M`，macOS `Cmd+Shift+M`，Vim 模式 `:clist`）。

诊断面板以 **Multibuffer** 形式列出所有错误，可直接在其中编辑修复，见 [060.Multibuffers多缓冲](./060.Multibuffers多缓冲.md)。

## 快速修复（Quick Fixes）

语言服务器常为诊断附带修复建议：

- 光标停在有诊断的行，按 `Ctrl+.`（macOS `Cmd+.`）打开 code actions 菜单。
- 选择对应的 quick fix（如「导入缺失符号」「移除未使用变量」）回车执行。

## 过滤与显示配置

### 编辑器内诊断严重级别

```jsonc
{ "diagnostics_max_severity": null }
```

可选值：`"off"`、`"error"`、`"warning"`、`"info"`、`"hint"`、`null`（默认，全部）。例如设为 `"error"` 只显示错误。

### 滚动条上的诊断标记

```jsonc
{
  "scrollbar": {
    "diagnostics": "all"   // none / error / warning / information / all（默认）
  }
}
```

## 内联诊断（Error Lens）

Zed 支持把诊断以「lens」形式显示在代码右侧（类似 VS Code 的 Error Lens）。默认关闭：

```jsonc
{
  "diagnostics": {
    "inline": {
      "enabled": true,
      "max_severity": null   // 取值同 diagnostics_max_severity
    }
  }
}
```

也可在编辑器菜单里临时开关。

## 其它 UI 位置的诊断着色

### Project Panel（文件树）

按文件内诊断的最高严重级别给条目着色：

```jsonc
{
  "project_panel": {
    "show_diagnostics": "all"   // off / errors / all（默认）
  }
}
```

### 编辑器标签（Tabs）

```jsonc
{
  "tabs": {
    "show_diagnostics": "off"   // off（默认）/ errors / all
  }
}
```
