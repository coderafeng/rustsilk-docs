# 概述

Zed 左 dock 里有两个常用的导航面板：**Project Panel（项目/文件树面板）** 和 **Outline Panel（大纲面板）**。虽然 Zed 更鼓励用 File Finder / Project Search 做键盘导航，但这两个面板在浏览结构、批量文件操作时仍很有用。

## Project Panel（项目面板 / 文件树）

`Ctrl+Shift+E`（macOS `Cmd+Shift+E`，Vim 模式 `:E`）打开。它以树状视图展示工作区的文件与目录，支持浏览、创建、重命名、移动、删除文件，并**一目了然地显示 Git 状态与诊断着色**。

### 文件操作

在 Project Panel 聚焦时，可用如下键盘操作（借鉴 Vim 的 netrw 插件；具体键位以你的 keymap 为准，可在命令面板确认）：

| 操作 | 键 |
|------|----|
| 上下导航 | `↑` `↓` 或 `j` `k` |
| 折叠 / 展开目录 | `←` `→` 或 `h` `l` |
| 打开文件 | `Enter` 或 `o` |
| 在新标签打开 | `t` |
| 新建文件 | `a` |
| 新建目录 | `A`（输入以 `/` 结尾的名字） |
| 重命名 | `r` |
| 移动到回收站（trash） | `d` |
| 永久删除 | `D` |
| 剪切 / 复制 / 粘贴 | `x` / `c` / `p` |

也可右键任意条目打开上下文菜单，包含 "Add Folders to Project"、"Reveal in File Manager"、"Copy Path" 等。

### 相关设置

```jsonc
{
  "project_panel": {
    "auto_fold_dirs": true,        // 折叠只有单个子目录的层级（类似 VS Code compactFolders）
    "auto_reveal_entries": true,   // 打开文件时自动在树中定位
    "hide_gitignore": false,       // 是否隐藏 .gitignore 忽略的文件
    "git_status": true,            // 显示 git 状态着色
    "show_diagnostics": "all"      // off / errors / all
  }
}
```

## Outline Panel（大纲面板）

`Ctrl+Shift+B`（macOS `Cmd+Shift+B`）打开。它持久显示**当前文件的符号树**（函数、类、方法等，来自 Tree-sitter / LSP），点击即可跳转。

大纲面板在与 **Multibuffer** 配合时尤其强大：浏览 Project Search 结果或诊断列表时，大纲能帮你在多个 excerpt 间快速定位符号结构。

### 特性

- 跟随光标：编辑区光标移动时，大纲会高亮对应符号。
- 可从大纲跳转到定义、在 Multibuffer 里浏览。
- 支持过滤/搜索符号。

### 相关设置

```jsonc
{
  "outline_panel": {
    "file_icons": true,
    "folder_indicator": true
  }
}
```

## 两者与 File Finder 的取舍

| 场景 | 推荐 |
|------|------|
| 知道文件名、想快速打开 | File Finder（`Ctrl+P`） |
| 浏览目录结构、批量增删改文件 | Project Panel |
| 在长文件里按符号跳转 | Outline Panel 或 `Ctrl+Shift+O` |
| 跨文件找文本 | Project Search（`Ctrl+Shift+F`） |

> [!tip] Zed 的导航取向
> Zed 刻意让辅助面板「靠边站」，把中心留给代码。熟练用户往往很少打开文件树，而依赖 `Ctrl+P` / `Ctrl+T` / `Ctrl+Shift+F` 这套键盘搜索。你可以按自己习惯取舍。
