# 概述

Zed 内置 **REPL**，基于 [Jupyter kernels](https://docs.jupyter.org/en/latest/projects/kernels.html)，让你直接在普通编辑器文件里**交互式运行代码**——运行一段、看一段输出，无需切到单独的 notebook 界面。它甚至能让 Markdown 文档里的代码块变成可执行的「notebook」。

## 安装 kernel

要用某语言的 REPL，先为它安装对应 kernel。当前支持：

- Python（ipykernel）
- TypeScript（Deno）
- R（Ark）
- R（Xeus）
- Julia
- Scala（Almond）

安装后，在对应语言文件（或 Markdown 等支持这些语言的地方）即可使用。若刚添加 kernel，运行 `repl: refresh kernelspecs` 让编辑器识别。

## 使用 REPL

打开目标语言的文件，用 `repl: run` 命令（macOS 默认 `Ctrl+Shift+Enter`）运行一个代码块、选区或单行，结果显示在选区下方。也可点击工具栏的 REPL 图标。

- 清除输出：`repl: clear outputs`，或工具栏 REPL 菜单。
- 查看会话：`repl: sessions`。
- 刷新可用 kernel：`repl: refresh kernelspecs`。

## Cell 模式（脚本即 notebook）

Zed 支持 [notebooks as scripts](https://jupytext.readthedocs.io/en/latest/formats-scripts.html)：用 `# %%`（Python）或 `// %%`（TypeScript）作为 cell 分隔符，就能在单个文件里像 notebook 一样逐 cell 运行。`repl: run` 会把每对 `# %%` 之间的代码作为独立 cell 执行。

```python
# %% Cell 1
import time
import numpy as np

# %% Cell 2
import matplotlib.pyplot as plt
from matplotlib import style
style.use('ggplot')
```

## 各语言安装说明

### Python

全局环境：

```sh
pip install ipykernel
python -m ipykernel install --user
```

Conda 环境：

```sh
source activate myenv
conda install ipykernel
python -m ipykernel install --user --name myenv --display-name "Python (myenv)"
```

Virtualenv（pip）：

```sh
source activate myenv
pip install ipykernel
python -m ipykernel install --user --name myenv --display-name "Python (myenv)"
```

> [!warning] macOS 系统 Python 不可用
> macOS 上系统自带 Python **无法**直接作为 kernel。请用 [pyenv](https://github.com/pyenv/pyenv) 或虚拟环境。Zed 对 Python 的 **toolchain** 与 **REPL kernel** 是分开选择的；若诊断与 REPL 表现不一致，用 `toolchain: select` 把 toolchain 与 kernel 对齐。

### TypeScript（Deno）

安装 [Deno](https://docs.deno.com/runtime/manual/getting_started/installation/) 后：

```sh
deno jupyter --install
```

### R（Ark）

下载 [Ark](https://github.com/posit-dev/ark/releases) 对应系统的 release，把 `ark` 二进制放进 `/usr/local/bin`，然后：

```sh
ark --install
```

### R（Xeus）

- 安装 [Xeus-R](https://github.com/jupyter-xeus/xeus-r)
- 在 Zed 扩展里搜索并安装 `R` 扩展

### Julia

- 从[官网](https://julialang.org/downloads/)安装 Julia
- 在 Zed 扩展里搜索并安装 `Julia` 扩展

### Scala（Almond）

- 用 Coursier 安装 Scala：`brew install coursier/formulas/coursier && cs setup`
- 按 [Almond](https://almond.sh/docs/quick-start-install) 说明安装：
  - `brew install --cask temurin`
  - `coursier launch --use-bootstrap almond -- --install`

## 选择每种语言用哪个 kernel

Zed 自动检测可用 kernel 并在 kernel picker 里分组：

- **Recommended**：与当前活动 toolchain 匹配的 Python 环境（若检测到）。
- **Python Environments**：各类虚拟环境（venv、virtualenv、Poetry、Pipenv、Conda、uv 等）。
- **Jupyter Kernels**：已安装的 Jupyter kernelspecs。
- **Remote Servers**：已连接的远程 Jupyter 服务器。

### 自动安装 ipykernel

Python 环境即使没装 ipykernel 也会出现在 picker 里，只是变灰并标注 "ipykernel not installed"。选中时 Zed 会自动在该环境跑 `pip install ipykernel`，装完即激活。

### Zed 如何推荐 kernel

运行代码时自动选择顺序：

1. **活动 toolchain 匹配**：若某 Python 环境匹配活动 toolchain 且装了 ipykernel，用它。
2. **第一个可用 Python 环境**：否则用第一个装了 ipykernel 的 Python 环境。
3. **按语言回退**：没有就绪的 Python 环境时，选一个匹配代码块语言的 Jupyter kernel。

可在 picker 里手动指定以覆盖。

### 设置默认 kernel

在 `settings.json` 里为各语言指定默认 kernel：

```jsonc
{
  "jupyter": {
    "kernel_selections": {
      "python": "conda-env",
      "typescript": "deno",
      "javascript": "deno",
      "r": "ark"
    }
  }
}
```

## 交互式输入

当代码执行需要用户输入（如 Python 的 `input()`），REPL 会在 cell 输出下方显示输入提示。在文本框输入并按 `Enter` 提交，kernel 收到输入后继续执行。密码输入会以星号掩码显示。若执行在输入提示激活时被中断，kernel 回到 idle 状态时提示会自动清除。

## 调试 kernelspec

- `repl: sessions` 查看可用 kernel。
- `repl: refresh kernelspecs` 刷新。
- 若装了 `jupyter`，`jupyter kernelspec list` 可列出全部 kernel 及其路径。

> [!note] kernel 查找机制
> Zed 会尽力利用 `sys.prefix` 和 `CONDA_PREFIX` 在 Python 环境中查找 kernel。想显式控制，可在环境内运行 `python -m ipykernel install --user --name myenv --display-name "Python (myenv)"` 直接安装 kernel。
