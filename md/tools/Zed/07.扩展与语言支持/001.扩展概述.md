# 概述

Zed 通过**扩展（Extensions）** 添加新功能。扩展是包含 `extension.toml` 清单的 Git 仓库，可以提供语言、主题、图标主题、调试器、代码片段（snippets）与 MCP servers。Zed 会根据扩展提供的功能，自动把它归类到扩展页的对应分类里（一个多功能扩展可能出现在多个分类）。

> [!note] Zed 扩展的定位
> Zed 内置能力已经很强（多数主流语言、Tree-sitter、LSP、调试、Git、AI 都开箱可用），扩展主要用于**补充**：新增冷门语言、更换主题/图标、接入特定 debugger 或 MCP server。与 VS Code 那种「几乎什么都靠扩展」的生态不同，Zed 更倾向把常用能力做进内核。

| 能力 | 说明 | 开发文档 |
|------|------|----------|
| **Languages** | 新语言的语法高亮、LSP 集成 | Developing Language Extensions |

| **Icon Themes** | 文件图标主题 | Developing Icon Themes |

| **MCP Servers** | 把 MCP server 打包成扩展 | Developing MCP Servers |

## 技术底座：Rust + WebAssembly

Zed 扩展的**过程性代码用 Rust 编写并编译成 WebAssembly**（`wasm32-wasip2` target）。这带来两个好处：

- **安全沙箱**：扩展在 WASM 沙箱里运行，不能随意访问系统。
- **跨平台**：一次编译，各平台通用。

> [!important] 多数扩展不需要 Rust 代码
> 只有 **language server、context server（MCP）、debugger** 这三类扩展需要自定义 Rust 代码才能正常工作。纯主题、图标主题、snippets 扩展只需声明式文件（JSON/TOML），无需写 Rust。
