# 概述

扩展为 Zed 添加功能，包括语言、主题与 AI 工具。你可以从 **Extension Gallery（扩展画廊）** 浏览并安装它们。

## 打开 Extension Gallery

- 快捷键：`Ctrl+Shift+X`（macOS `Cmd+Shift+X`）
- 命令面板：`zed: extensions`
- 菜单栏：Zed > Extensions

画廊里可按分类筛选（语言、主题、图标主题、调试器、MCP servers 等），也能搜索关键词。点击某个扩展查看说明、来源仓库，再点安装。

> [!tip] MCP server 也能从这里装
> 许多 MCP server 以扩展形式分发。在画廊里筛选 context-servers，或到 **Settings → AI → MCP Servers** 点 `Add Server` → `Install from Extensions`。详见 [030.MCP服务器](../06.AI与Agent/030.MCP服务器.md)。

## 安装位置

| 平台 | 路径 |
|------|------|
| macOS | `~/Library/Application Support/Zed/extensions` |
| Linux | `$XDG_DATA_HOME/zed/extensions` 或 `~/.local/share/zed/extensions` |
| Windows | `%LOCALAPPDATA%\Zed\extensions` |

该目录含两个子目录：

- `installed`：每个扩展的**源代码**。
- `work`：扩展自身创建的文件，如**下载的 language server**。

> [!note] 别手动改这两个目录
> `installed` 与 `work` 由 Zed 管理，增删扩展应通过画廊 UI。手动删文件可能导致状态不一致；要卸载请在扩展页操作。

## 自动安装扩展

可以用 `auto_install_extensions` 设置，让 Zed 在打开特定类型文件时**自动安装/卸载**所需扩展，适合团队统一环境或在多机间同步。完整选项见官方 All Settings 的 `auto_install_extensions` 一节。

配合项目级 `.zed/settings.json`，可以让「打开本项目就自动装齐所需语言扩展」，减少新成员的手动配置。settings 分层机制见 [010.settings配置体系](../03.配置与键位自定义/010.settings配置体系.md)。

## Dev Extension（开发用扩展）

开发扩展时，无需发布即可在 Zed 里使用——把它作为 **dev extension** 安装：

- 在扩展页点 `Install Dev Extension` 按钮，或执行 `zed: install dev extension` 动作，选择包含扩展的目录。

若你已安装该扩展的发布版，安装 dev extension 前会先卸载发布版；安装成功后扩展页会标注上游扩展 "Overridden by dev extension"。开发细节见 [030.开发与发布扩展](./030.开发与发布扩展.md)。

## 管理已安装扩展

在扩展页（`Ctrl+Shift+X`）切到已安装列表，可对每个扩展：

- 查看版本、来源仓库、提供的能力分类。
- 更新到新版本（有新版本时提示）。
- 卸载。
- 若是 dev extension，看到它覆盖了哪个上游扩展。

## 排错

扩展或 language server 出问题时：

1. 命令面板执行 `zed: open log` 查看 Zed.log 的额外输出。
2. 需要更详细的 INFO 级日志时，从命令行以 `zed --foreground` 关闭并重启 Zed，输出更啰嗦。
3. 确认扩展依赖的外部工具（如 language server 二进制、formatter）已安装并在 PATH 中。

更多故障排查见 [050.故障排查与CLI](../08.协作远程与参考/050.故障排查与CLI.md)。
