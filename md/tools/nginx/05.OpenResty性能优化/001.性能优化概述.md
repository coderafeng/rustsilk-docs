# 优化的顺序

```text
先测（wrk / stapxx / 火焰图）
   ↓ 拿到瓶颈
再改代码级（阻塞 / 字符串 / table / 编码）
   ↓ 若瓶颈在数据
上缓存（shared_dict + LRU + 多级）
   ↓ 若瓶颈在下游
加限流（漏桶 / 令牌桶 / 动态）
```

**永远不要跳过第一步直接改代码**——绝大多数"性能优化"失败是猜错了瓶颈。
