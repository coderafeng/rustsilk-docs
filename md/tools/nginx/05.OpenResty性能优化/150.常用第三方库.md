# 概述

OpenResty 生态有 100+ 个 `lua-resty-*` 库；本文挑**必用**的一批分类介绍：HTTP 客户端、Redis、MySQL、Websocket、序列化、加密、日志、服务发现、限流、监控。

# 分类速查

## HTTP 客户端

| 库 | 说明 |
|----|------|
| **lua-resty-http** | 官方；GET/POST/流式；支持 keepalive 池 |
| lua-resty-http2 | HTTP/2 客户端；配 h2c 上游 |
| resty.jwt | JWT 签发/校验；常用于网关鉴权 |

```lua
local http = require "resty.http"
local res, err = http.request_uri("http://api.local/v1", {
    method = "POST",
    headers = { ["Content-Type"] = "application/json" },
    body = cjson.encode(payload),
    timeout = 5000,
    keepalive_timeout = 60000,
    keepalive_pool = 32,
})
```

## 数据库 / KV

| 库 | 说明 |
|----|------|
| **lua-resty-redis** | Redis RESP 协议；支持 pipeline |
| **lua-resty-mysql** | MySQL 4.1+；prepared statement |
| lua-resty-postgres / lua-resty-pg | PostgreSQL；社区维护 |
| lua-resty-mongo | MongoDB；较薄 |
| lua-resty-kafka | Kafka producer |
| lua-resty-elasticsearch | ES 客户端 |

```lua
local redis = require "resty.redis"
local r = redis:new()
r:settimeouts(1000, 3000, 3000)
r:connect("127.0.0.1", 6379)
r:init_pipeline()
r:mget({ "k1", "k2", "k3" })
r:hgetall("user:1")
local results, err = r:commit_pipeline()
r:setkeepalive(10000, 64)
```

# 首选三个必装库

如果只装三个，选：

1. **lua-resty-http**：网关要发外部 HTTP 请求全靠它；
2. **lua-resty-redis**：shared_dict 之外的持久/跨机存储；
3. **lua-resty-lock**：分布式互斥，配合 shdict 用；

## 装法

```bash
opm get ledidante/lua-resty-http      # 或 openresty/lua-resty-http
opm get openresty/lua-resty-redis
opm get openresty/lua-resty-lock
```

**注意**：`lua-resty-core`、`lua-resty-lrucache` 是 OpenResty 发行版**自带**，不用装。

# 选型三条原则

## 1. 官方 > 社区

**openresty org** 下的仓库经过章玉峰团队 review；社区库质量参差。装之前先看 owner。

## 2. 有 t/ 用例 > 无用例

`lua-resty-*` 库**必须有 `t/` 目录**——见 [03 章 020.文档与测试案例](../03.OpenResty核心API/020.文档与测试案例.md)。没测试的库不上生产。

## 3. 最近一年有 commit

Lua 生态更新慢；但库**如果 2 年没动**——大概率不兼容新版 OpenResty，或已有更优替代。

# 避坑

- **别用 LuaSocket**：`socket.tcp` 阻塞 worker（见 [010.阻塞函数](./010.阻塞函数.md)）；一律 cosocket；
- **别混 opm/luarocks**：见 [01 章 080.包管理](../01.OpenResty起步/080.包管理opm与luarocks.md)；一套项目锁定一种；
- **`resty.websocket` 长连接不 yield**：给读操作加超时；见 010；
- **lua-resty-openssl 与系统 openssl 版本冲突**：OpenResty 自带 openssl；混用会 segfault；
- **`cjson.safe.decode` 与 `cjson.decode` 语义差**：前者 `nil, err`；后者抛异常。

# 总结

- 生态覆盖：HTTP / 数据库 / 加密 / 缓存 / 观测 / 服务发现 / 网关；
- 三大必装：`lua-resty-http` / `lua-resty-redis` / `lua-resty-lock`；
- 三条选型原则：官方 > 社区、有测试、活跃维护；
- 永远避开：LuaSocket / 无测试的库 / 版本冲突。
