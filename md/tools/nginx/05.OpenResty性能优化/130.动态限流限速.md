# 概述

上一文（120）给了限流算法；这一文把它做到**生产级**：规则来自配置中心、支持热更新、可打指标、能限下游也能限上游、能限速也能限流。

# 需求清单

生产限流必须覆盖：

- [ ] **多维度**：IP / user / tenant / API / URI 组合；
- [ ] **动态阈值**：从配置中心拉；改配置秒级生效，不 reload；
- [ ] **多种粒度**：QPS、并发数、带宽（bytes/s）、响应速率；
- [ ] **可观测**：hit / reject / 剩余配额打指标；
- [ ] **降级**：Redis 挂时本地兜底；配置拉不到时用旧值；
- [ ] **友好响应**：429 + `Retry-After` + JSON 错误体；
- [ ] **白名单**：内部调用、健康检查、监控不计数。

# 规则结构

配置中心（Consul / Apollo / Nacos）里存一段 JSON：

```json
{
  "version": "2026-11-13",
  "rules": [
    {
      "key": "tenant:acme:/api/orders*",
      "algorithm": "token_bucket",
      "rate": 1000,
      "capacity": 2000,
      "reject_code": 429,
      "reject_body": {"code": 42901, "msg": "too many"}
    },
    {
      "key": "user_id:*",
      "algorithm": "leaky",
      "rate": 10,
      "whitelist_from": "10.0.0.0/8"
    }
  ]
}
```

**匹配规则**：`prefix:pattern` 语法；`*` 通配；按数组顺序，第一个命中即用。

# 完整实现骨架

```lua
-- lib/ratelimit.lua
local sh_cfg   = ngx.shared.rules       -- 配置缓存
local sh_state = ngx.shared.rl_state    -- 桶状态
local cjson    = require "cjson.safe"

local _M = {}

local function load_rules()
    local raw, _ = sh_cfg:get("current")
    if not raw then
        -- 从配置中心拉（cosocket 走 timer 或直接 fetch）
        raw = fetch_from_config_center() or '{"rules":[]}'
        sh_cfg:set("current", raw, 60)
    end
    local data = cjson.decode(raw) or { rules = {} }
    return data.rules
end

local function match(rules, ctx)
    for _, r in ipairs(rules) do
        if _M._match_key(r.key, ctx) then return r end
    end
end

local function _match_key(pattern, ctx)
    -- 简单 glob：* 匹配任意
    local re = "^" .. ngx.re.gsub(pattern, "[.+?()\\[\\]{}|^$]", "\\\0", "jo")
                  :gsub("%*", ".*") .. "$"
    local subject = table.concat({ ctx.tenant, ":", ctx.path }, "")
    return ngx.re.find(subject, re, "jo") ~= nil
end

-- 令牌桶：state 用两条 shdict 项存 tokens 与 last
local function token_bucket(key, rate, capacity)
    local now_ms = ngx.now() * 1000
    local tokens, last_ms = sh_state:get("tb:" .. key)
    if not tokens then
        tokens, last_ms = capacity, now_ms
    end
    tokens = math.min(capacity, tokens + (now_ms - last_ms) / 1000 * rate)
    if tokens >= 1 then
        tokens = tokens - 1
        sh_state:set("tb:" .. key, tokens, 300)
        sh_state:set("tb:" .. key .. ":ts", now_ms, 300)
        return true
    else
        sh_state:set("tb:" .. key, tokens, 300)
        return false
    end
end

local function leaky(key, rate)
    local now = ngx.now()
    local last = sh_state:get("lb:" .. key) or 0
    if now - last >= 1 / rate then
        sh_state:set("lb:" .. key, now, 300)
        return true
    end
    return false
end

local ALGOS = {
    token_bucket = token_bucket,
    leaky        = leaky,
}

function _M.check(ctx)
    local rules = load_rules()
    local rule = match(rules, ctx)
    if not rule then return true end                   -- 无规则：放行

    if rule.whitelist_from
       and ip_in_cidr(ctx.client_ip, rule.whitelist_from) then
        return true
    end

    local algo = ALGOS[rule.algorithm]
    if not algo then return true end

    local key = rule.key .. "|" .. (ctx.tenant or "") .. "|" .. (ctx.user or "")
    local ok = algo(key, rule.rate, rule.capacity)
    if ok then
        sh_state:incr("metric:allow:" .. rule.key, 1, 0)
    else
        sh_state:incr("metric:reject:" .. rule.key, 1, 0)
    end
    return ok, rule
end

return _M
```

## 在 access 阶段调用

```lua
access_by_lua_block {
    local rl = require "ratelimit"
    local ok, rule = rl.check({
        tenant    = ngx.var.http_x_tenant,
        user      = ngx.var.http_x_user,
        path      = ngx.var.uri,
        client_ip = ngx.var.remote_addr,
    })
    if not ok then
        ngx.status = rule.reject_code or 429
        ngx.header["Retry-After"] = "1"
        ngx.header["Content-Type"] = "application/json"
        return ngx.print(rule.reject_body or { code = 42900, msg = "too many" })
    end
}
```

# 配置热更新：worker 拉 or push 推

## Pull（定时拉）

```lua
init_worker_by_lua_block {
    if ngx.worker.pid() == 0 or ngx.shared.roles:get("owner") == ngx.worker.pid() then
        ngx.timer.every(15, function(prem)
            if prem then return end
            local raw = fetch_from_config_center()
            if raw then
                ngx.shared.rules:set("current", raw, 60)
            end
        end)
    end
end
```

**简单可靠**；15s 更新周期；worker 崩溃无影响。

## Push（长轮询 / WebSocket）

配置中心支持长轮询：agent 侧 `sock:receive` 阻塞读；有新配置立即写 shdict。见 [03 章 050.cosocket](../03.OpenResty核心API/050.cosocket核心精髓.md)。

**优点**：秒级生效；**代价**：连接稳定性、断线重连。

# 观测指标

```lua
-- /metrics
local sh = ngx.shared.rl_state
local keys = sh:get_keys(1000)
for _, k in ipairs(keys) do
    if k:sub(1, 14) == "metric:allow" or k:sub(1, 15) == "metric:reject" then
        ngx.say("openresty_rl_total{rule=\"", k, "\"} ", sh:get(k))
    end
end
```

**Prometheus 抓取 + Grafana 面板**：按 rule 分 allow/reject 曲线；reject 突增告警。

# 降级策略

- **Redis 挂**：本地 `sh_state` 已经能撑住；Redis 全局计数失败时静默 fallback 本地；
- **配置中心挂**：`sh_cfg:get("current")` 命中旧值，即使 pull 失败也能生效；TTL 设 5 分钟；
- **shdict 满**：`incr` 时 `premature = true`；监控告警；容量翻倍。

# 限速（bytes/s）

QPS 之外的另一维度：

```lua
-- body_filter_by_lua_block
local total = (ngx.ctx.bytes_out or 0) + tonumber(ngx.arg[1] and #ngx.arg[1] or 0)
ngx.ctx.bytes_out = total

-- 与 rate_limit 类似；shared_dict 记 timestamp 与累计字节
```

**用途**：下载站、CDN 回源、防止个别用户占带宽。

# 避坑

- **`get_keys(1000)` 会 stall**：只用于 metrics 端点、频率限制；见 03 章 040；
- **规则爆炸**：每 URI 一条规则、URL 又动态 → shdict key 数量爆；给 key 上限 + 定期清；
- **`ngx.re.gsub` 拼 regex 忘转义**：见 03 章 080；生产用固定 enum 匹配；
- **`retry-after` 单位**：秒整数；小数无效。

# 总结

- 规则存配置中心 → shdict 缓存 → worker 命中；
- 算法：`token_bucket` / `leaky`；扩展：`sliding_window` / `gcra`；
- 观测：allow / reject 计数；
- 降级：本地兜底、pull 失败仍能用；
- 覆盖：QPS / 并发 / 带宽 三种粒度。
