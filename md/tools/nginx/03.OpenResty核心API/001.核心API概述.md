# 概述

本章把 OpenResty 提供的**核心 API 家族**逐个讲透：请求响应动态处理、`lua_shared_dict`、`cosocket`、`timer`、`ssl.*`、`balancer.*`、四层 `stream.*`、以及围绕它们生态的 `lua-resty-*` 库。起步章告诉你"Lua 代码写在哪个阶段"，本章告诉你"这些阶段能拿什么 API、拿它做什么"。

# 版本口径

本章所有示例基于 **OpenResty 1.31.8.1**（nginx core 1.31.8 + `ngx_http_lua_module` 0.10.27+ + `lua-resty-core` 0.1.28+）；部分 API（如 `ngx.socket.stream`、`balancer.set_more_tries`）与更早版本语义略有差异，落到旧版本请先看 [01 章 010.OpenResty 是什么](../01.OpenResty起步/010.OpenResty是什么.md) 尾节的版本节奏表。
