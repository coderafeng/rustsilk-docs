# 概述

OpenResty 的 `stream` 模块（四层）能承载**任意 TCP 协议**——不只是转发，还能在 Lua 里**充当服务端**。本文造一个能处理 `get/set/incr` 三条指令的最小 Memcached 兼容服务，把 `stream` API 走通一遍。

# 目录

```text
memcached-mini/
├── conf/nginx.conf
├── lua/memcached.lua       -- 协议解析 + 命令分派
└── README.md
```

# nginx.conf

```nginx
worker_processes auto;
error_log logs/error.log info;

events { worker_connections 10240; }

stream {
    lua_shared_dict kv 16m;

    init_worker_by_lua_block {
        -- 定时扫过期
        ngx.timer.every(1, function(prem)
            if prem then return end
            ngx.shared.kv:flush_expired(1000)
        end)
    }

    server {
        listen 11211 reuseport;
        prereload_buffer off;
        content_by_lua_file lua/memcached.lua;
    }
}
```

关键点：
- **stream 里用 `content_by_lua*`**（对应七层的同名指令）；
- `reuseport` 让多 worker 各自 bind socket，减少 accept 争抢；
- shared dict `kv` 存 key/value，`flush_expired` 定期回收。

# 协议解析

Memcached ASCII 协议每条命令一行；`set` 后面紧跟一块数据：

```text
set foo 0 60 5\r\n
hello\r\n
get foo\r\n
incr foo 2\r\n
```

## 完整实现

```lua
-- lua/memcached.lua
local sh = ngx.shared.kv

local function readline()
    local line, err = ngx.socket.tcp():receiveLine()  -- 注意：stream 里用 ngx.req 拿不到；用 sock
    return line, err
end

-- 但 stream 里更 idiomatic 的是"从当前连接读"：
local sock = ngx.req.socket()                          -- 拿到客户端连接
sock:settimeouts(nil, 30000, 30000)

local function read_line()
    return sock:receiveLine()
end

local function write(...)
    for _, s in ipairs({...}) do sock:send(s) end
end

while true do
    local line, err = read_line()
    if not line then break end                          -- 客户端断开 / 超时

    local cmd, rest = line:match("^(%S+)%s*(.*)$")
    if cmd == "get" then
        -- 支持多个 key
        for key in rest:gmatch("%S+") do
            local val = sh:get(key)
            if val then
                write("VALUE ", key, " 0 ", #val, "\r\n", val, "\r\n")
            end
        end
        write("END\r\n")

    elseif cmd == "set" then
        -- set <key> <flags> <exptime> <bytes> [noreply]\r\n<data>\r\n
        local key, _, exptime, bytes = rest:match("^(%S+)%s+%S+%s+(%d+)%s+(%d+)")
        exptime = tonumber(exptime) or 0
        bytes = tonumber(bytes) or 0
        if not key or not bytes then
            write("ERROR\r\n")
        else
            local data = sock:receive(bytes + 2)        -- +2 吃掉 \r\n
            local ttl = exptime > 0 and exptime or 0
            sh:set(key, (data or ""):sub(1, bytes), ttl)
            write("STORED\r\n")
        end

    elseif cmd == "incr" then
        local key, delta = rest:match("^(%S+)%s+(%d+)$")
        if not key then write("ERROR\r\n")
        else
            local newval, err = sh:incr(key, tonumber(delta))
            if newval then write(newval, "\r\n")
            elseif err == "not found" then write("NOT_FOUND\r\n")
            else write("SERVER_ERROR\r\n") end
        end

    elseif cmd == "delete" then
        local key = rest:match("^(%S+)")
        local removed = key and sh:delete(key)
        write(removed and "DELETED\r\n" or "NOT_FOUND\r\n")

    elseif cmd == "quit" then
        break

    else
        write("ERROR\r\n")
    end
end

sock:close()
```

# 关键要点回顾

## stream 与 http 上下文差异

| API | http | stream |
|-----|------|--------|
| 客户端 socket | `ngx.req.socket()` | `ngx.req.socket()`（同名） |
| 上游 socket | `ngx.balancer` / `proxy_pass` | `ngx.socket.tcp` 手工连 |
| `ngx.say/print` | ✅ | ❌（用 `sock:send`） |
| `ngx.header` | ✅ | ❌ |
| `ngx.location.capture` | ✅ | ❌ |

**stream 里没有 HTTP 语义**——所有响应都要手工 `send`。

## 无 `eof`：连接由代码控制

`while true` + `receiveLine` 直到客户端断开；不要提前 `return`——`return` 就等于关闭当前 stream 会话。

## 复用 shared dict

`kv` 存字符串 value，跟真 Memcached 语义一致；要存二进制 → 直接原样字符串（Lua string 是字节串）。

# 避坑

- **`receive(bytes + 2)` 少了 `+2`**：Memcached 数据块结尾 `\r\n`，不吞掉会污染下一条命令。
- **`incr` 在 key 不存在时**：Memcached 语义返 `NOT_FOUND`；shared dict `incr` 返 `"not found"` — 需要显式判。
- **`exptime > 30 天`**：真 Memcached 当绝对 unix 时间戳；mini 版没实现，扩展时记得处理。
- **`noreply` 后缀**：真实协议里 `set ... noreply` 后**不返 STORED**；例子里没实现，做严格兼容要加。
- **不要每命令 `setkeepalive`**：客户端连接由 `content_by_lua` 拥有，`sock:close()` 由框架管；乱 `setkeepalive` 会破坏会话。

# 总结

- stream 侧 `content_by_lua` + `ngx.req.socket` = 完整 TCP 服务；
- 协议解析要点：**分行读、按命令分派、二进制块按长度读**；
- shared dict 提供 KV 存储 + TTL；`flush_expired` 定期回收；
- 生产用 mini 协议要加：`noreply`、`cas`、`stats`、二进制 `exptime` 判定。
