# 为什么 Test::Nginx 而不是 pytest + requests

- **在真 nginx 上跑**：不是 mock，能捕获到 nginx 层行为（location 匹配、header 顺序、`_by_lua` 阶段）；
- **用例本身可执行**：`.t` 文件既是文档又是测试；
- **性能可接受**：一个用例几十毫秒，几百个用例一分钟；
- **生态贴合**：lua-nginx-module、lua-resty-* 全部用它；官方用例可参考。

# 上手最短路径

```bash
# 1. 装 Perl + Test::Nginx
sudo apt install -y perl cpanminus
sudo cpanm --notest Test::Nginx

# 2. 写一个 t/000-smoke.t
# 3. 跑：TEST_NGINX_BINARY=/usr/local/openresty/bin/openresty prove -v t/000-smoke.t
```

详见 [010.Test-Nginx 简介](./010.Test-Nginx简介.md)。
