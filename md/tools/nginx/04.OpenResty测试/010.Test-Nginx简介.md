# 概述

`Test::Nginx` 是 OpenResty 生态**事实标准**的测试框架，由章玉峰维护，位于 <https://github.com/openresty/test-nginx>。它的形态有点特别：一个 Perl 模块 + 一种自定义 DSL（`.t` 文件里的 `--- config` / `--- request` / `--- response_body`）。理解它的定位，才能理解为什么 lua-nginx-module 里 500+ 个用例都是这么写的。

# 它是什么

一句话：**"用一段 Perl 脚本 + 一段结构化文本，把 nginx 拉起来跑请求，然后校验响应"**。

拆开：
- **Perl 脚本**负责"启动/停止 nginx、发送请求、比对期望"；
- **结构化文本**（`__DATA__` 后面的 `=== TEST N: xxx` 段落）负责"用声明式的方式描述配置、请求、期望"；
- **Test::More 生态**负责断言和聚合。

跑起来是 Perl 的 `prove` 命令：

```bash
prove -v t/
```

输出兼容标准 TAP 协议，能对接 CI。

# 三种 Test::Nginx 模块

| 模块 | 场景 |
|------|------|
| `Test::Nginx::Socket` | 通用 HTTP，不涉及 Lua |
| `Test::Nginx::Socket::Lua` | 有 `_by_lua` 指令时使用；额外支持 `--- lua` / `--- http_config` 里的 Lua |
| `Test::Nginx::Lua::Stream` | stream 模块四层测试 |

**OpenResty 项目 99% 用第二种**。

# 与相邻生态的分工

```text
Test::Nginx           ← 单个 nginx 实例的功能测试
lua-resty-test        ← 纯 Lua 层的单元断言库（少用）
busted                ← 通用 Lua 单测框架；纯 Lua 库可用
resty               ← OpenResty 官方命令行 REPL；适合手工冒烟
wrk / wrk2 / ab      ← 压测；见 040.wrk 压测悍马
Veewah / Vagrant       ← 多机集成测试；重型项目才用
```

**推荐组合**：Test::Nginx 做接口测试 + wrk 做基准 + busted 做纯 Lua 库的单元测试。

# 一次典型用例长什么样

```text
use Test::Nginx::Socket::Lua 'no_plan';
log_level('debug');
run_tests();

__DATA__

=== TEST 1: add works
--- config
    location = /t {
        content_by_lua_block {
            local sh = ngx.shared.store
            sh:set("k", 1, 60)
            local v = sh:incr("k", 2)
            ngx.say("v=", v)
        }
    }
--- request
GET /t
--- response_body
v=3
--- error_code: 200
```

四个固定 section：`config` / `request` / `response_body` / `error_code`。跑一次不到 100ms。

# 一个可运行的最小项目骨架

```text
my-openresty-lib/
├── lib/mylib.lua
├── t/
│   ├── 000-sanity.t
│   ├── 010-basic.t
│   └── 020-error.t
├── Makefile
├── README.markdown
└── mylib-0.1.0-1.rockspec
```

**Makefile**：

```makefile
.PHONY: test
test:
	export TEST_NGINX_BINARY=/usr/local/openresty/bin/openresty; \
	export PATH=/usr/local/openresty/luajit/bin:$$PATH; \
	prove -v -I . t/*.t
```

`make test` 就能跑全部。

# 环境要求

- Perl 5.16+；
- `Test::Nginx` 0.32+；
- `Test::More`（Perl core）；
- 一个编译好且带 Lua 模块的 nginx 二进制（用 OpenResty 官方发行即可）；
- Linux / macOS 都能跑；**Windows 走 WSL**。

# 避坑

- **不要自己 new 一个 `Test::Nginx::Socket`**：模块顶层用 `run_tests()` 就够；
- **`no_plan` vs `tests => N`**：写死 N 会漏跑；用 `no_plan` 让框架算；
- **`TEST_NGINX_BINARY` 忘设**：框架会试图从源码编译 nginx，卡 5 分钟；先 `export` 好；
- **`--- config` 里的 Lua 代码块必须缩进**：至少 4 空格，Test::Nginx 用它识别段落。

# 总结

- Test::Nginx = Perl + 声明式 DSL + 真 nginx 实例；
- Lua 场景一律 `Test::Nginx::Socket::Lua`；
- 用例骨架固定：`config / request / response_body / error_code`；
- 与其他框架分工：Test::Nginx 管接口，busted 管纯 Lua 单元，wrk 管性能。
