# 概述

本章把 OpenResty 的"引擎盖"掀开：**LuaJIT 的 trace JIT 是怎么把工作负载优化的**、**哪些 API 会掉进 NYI 让 JIT 失效**、**FFI 为什么比传统 C 绑定快一个数量级**、**table / metatable / string 这些 Lua 数据结构在内部是什么样**、**协程如何与 Nginx 事件循环配合**、**共享字典怎么跨 worker 通信**、以及**在 OpenResty 里写 Lua 与 standalone Lua 有哪些约束差异**。

这些不是"知道更好"，而是"不知道就写不出毫秒级代码"。01 起步章解决"跑起来"，02 内幕章解决"跑得快、跑得稳、跑得可预测"。

# 阅读建议

- **性能调优**：010 → 030 → 040 → 050 → 060，配合 05 章性能优化篇实践。
- **API 选型**：040 → 070 → 080，理解 `require "resty.core"` 到底改变了什么。
- **代码规范落地**：020 → 090，把"Lua 与 LuaJIT 差异"、"OpenResty 禁用 API"沉淀进 luacheck 规则。
- **排查诡异现象**（比如"改了没生效"、"worker 卡住"）：070 → 080 → 090。

# 版本口径

本章所有示例基于 **OpenResty 1.31.8.1 + LuaJIT 2.1（openresty/luajit2 fork）+ lua-resty-core 0.1.28+**；老版本（1.21/1.25）的 LuaJIT 分支差异见 [020.标准 Lua 与 LuaJIT 差异](./020.标准Lua与LuaJIT差异.md) 尾节。
